# A large-scale assessment of sequence database search tools for homology-based protein function prediction

- **DOI：** [10.1093/bib/bbae349](https://doi.org/10.1093/bib/bbae349)

## 研究问题

序列数据库搜索+同源功能转移是蛋白功能预测（GO注释）最古老且仍是主流方法的基石（也是多数深度学习预测器的组件），但搜索工具选择与参数配置对功能预测的影响从未被系统研究。

## 作者主张的贡献

大规模评估主流序列搜索工具（BLASTp/PSI-BLAST/MMseqs2/DIAMOND/jackhmmer/phmmer/HHblits等）及其参数对GO功能预测的影响：默认参数下BLASTp与MMseqs2持续优于包括DIAMOND在内的其他工具，但DIAMOND经正确参数设置可达到可比性能；新提出bitscore×序列 identity 双权重打分函数（S2），在11种打分方案中一致最优，可轻松嵌入几乎所有蛋白功能预测算法的同源组件。

## 创新边界

各搜索工具与同源转移均为既有技术；评估工作与S2打分函数是增量贡献（S2本质是两个既有量的乘积加权，工程性创新）。'搜索参数重要'的结论对社区有价值但属实证而非概念创新。

## 创新点证据卡

- **[p1]** 首次大规模系统评估序列搜索工具选择与参数对同源功能预测的影响
  - 原文："previous studies have scarcely explored how to select the optimal sequence search tools and configure their parameters to achieve the best function prediction"
- **[p1]** 发现默认参数下BLASTp/MMseqs2持续优于DIAMOND，但调参后可持平——参数设置被普遍忽视
  - 原文："BLASTp and MMseqs2 consistently exceed the performance of other tools, including DIAMOND... with the correct parameter settings, DIAMOND can perform comparably"
- **[p3]** 提出bitscore×序列identity双权重打分函数S2，一致优于既有10种GO转移打分方案
  - 原文："the template is weighted by both the bit-score and sequence identity"
- **[p1]** 证明少数易实现的同源组件改动即可提升几乎所有蛋白功能预测算法
  - 原文："enable the improvement of almost all protein function prediction algorithms with a few easily implementable changes"

## 方法

- 统一大基准上系统对比7+搜索工具×参数设置×11种GO转移打分函数
- 新打分函数S2：bitscore与序列identities（按查询/模板长度较大者归一）乘积加权
- HHblits数据库构建：kClust 30%聚类+Clustal Omega多序列比对→HMM库
- Fmax/wFmax（CAFA标准指标）评估

## 数据与基准

- 大基准GO注释数据集（含实验确定GO term的模板库）
- CAFA评估框架（Fmax定义）

## 结果证据

- 默认参数下BLASTp与MMseqs2持续超过其他工具（含DIAMOND）
- DIAMOND正确调参后可与BLASTp/MMseqs2可比
- S2（bitscore×ID）打分函数一致优于此前提出的10种打分方案（含BLAST-KNN/Diamond-Score）
- 结论：改动同源组件的少数实现即可提升几乎所有蛋白功能预测算法

## 比较基线

- BLASTp
- PSI-BLAST(-num_iterations 3)
- MMseqs2
- DIAMOND（默认与调参）
- GHOSTX
- RAPsearch2
- phmmer/jackhmmer
- HHblits
- 既有打分函数S1/S3-S11（含MetaGO等）

## 已知限制

- 评估限于同源转移组件，未端到端评估完整深度学习预测器
- GO标签的实验注释偏倚（多数蛋白无实验注释）未深入讨论
- S2在新颖远缘同源场景的增益幅度待量化（正文后部）

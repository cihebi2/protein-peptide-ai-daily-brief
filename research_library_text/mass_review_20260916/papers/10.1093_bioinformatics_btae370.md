# RCSB protein Data Bank: exploring protein 3D similarities via comprehensive structural alignments

- **DOI：** [10.1093/bioinformatics/btae370](https://doi.org/10.1093/bioinformatics/btae370)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

蛋白质三维结构两两比对工具众多（FATCAT/CE/TM-align 等）但缺乏浏览器端一站式、可同时展示 1D 序列与 3D 结构比对结果的易用入口。

## 作者主张的贡献

在 RCSB.org 门户上线交互式成对结构比对工具（rcsb.org/alignment）：集成 jFATCAT（刚性/柔性）、jCE、jCE-CP、TM-align、Smith-Waterman 3D 五种成熟算法；支持 PDB 存档+百万级计算结构模型（AlphaFold DB/ModelArchive）+自定义上传/URL 结构；异步 API（alignment.rcsb.org）带 ticket 跟踪；结果可书签/分享，1D/3D 联动可视化。

## 创新边界

应用注记（Applications Note）：比对算法全部为既有方法，无新算法；贡献是工程整合与 UI/API 服务化。不能作为任何比对方法学首创引用，只能作为基础设施/资源引用。

## 创新点证据卡

- **[p1]** 首个集成于 PDB 门户的浏览器端 1D/3D 联动成对结构比对工具
  - 原文："a novel pairwise structure alignment tool (rcsb.org/alignment) that seamlessly integrates into the RCSB Protein Data Bank"
- **[p2]** 单一入口封装五种成熟比对算法并支持自定义结构上传
  - 原文："users can choose from a range of established methods, including jFATCAT, jCE, jCE-CP, Smith-Waterman 3D, and TM-align"
- **[p3]** 异步 ticket 化比对 API 支持程序化访问
  - 原文："The Pairwise Structure Alignment tool is built atop a public API (alignment.rcsb.org)"

## 方法

- Web 工具封装既有比对算法（jFATCAT 刚性/柔性、jCE、jCE-CP、TM-align、SW3D），算法参数可自由设置
- 输入支持：PDB ID、mmCIF/BinaryCIF/PDB 格式 URL、本地文件上传（token 保护 90 天）、UniProt/AlphaFold DB/ESM Metagenomic Atlas 标识符
- 异步任务 API：ticket 机制跟踪比对进度
- RCSB Sequence Annotations Viewer + Mol* 3D viewer 联动展示比对结果，多格式导出

## 数据与基准

- PDB 实验结构存档 + >100 万计算结构模型（AlphaFold DB、ModelArchive）

## 结果证据

- 数秒级完成典型成对比对并以 1D/3D 双视图呈现
- 支持多链对一条参考链的批量比对与序列范围限定
- 前后端代码开源（rcsb-pecos-app、molstar）

## 比较基线

- 各算法原始独立工具/服务器（FATCAT、CE、TM-align、SW3D）

## 已知限制

- 无新算法贡献；比对质量取决于底层既有算法
- 成对（pairwise）比对，非多结构联配/大规模数据库搜索
- 大结构计算仍可能耗时（异步排队）
- 上传文件 token 有效期 90 天

## 待复核未知项

- API 速率限制与批量配额未说明
- 比对结果的计算可重复性版本控制策略未说明

# Comprehensive machine learning boosts structure-based virtual screening for PARP1 inhibitors

- **DOI：** [10.1186/s13321-024-00832-1](https://doi.org/10.1186/s13321-024-00832-1)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

经典打分函数线性假设限制虚拟筛选命中率；如何为PARP1这类重要靶点构建靶点特异性机器学习打分函数，并设计足够难的测试集公正评估其富集能力。

## 作者主张的贡献

构建PARP1特异性ML打分函数体系：ChEMBL生化IC50数据+DeepCoy生成式图网络产生的性质匹配decoys+确认无活性物构成半合成训练数据；测试集额外做了去相似化（Tanimoto<0.70）；系统比较5种监督算法×(PLEC/GRID/配体Morgan)特征组合与3个现成通用SF。最优模型PLEC+SVM回归在最难测试集上NEF1%=0.588，超过所有通用与经典打分函数。

## 创新边界

靶点特异ML打分函数与PLEC指纹均为既有技术（作者团队前作）；创新在于严格评估设计（生成式decoy+去相似测试集+无活性富集）与'深度学习在该靶点上不如简单ML'的实证结论。PARP1 VS本身已有大量文献。

## 创新点证据卡

- **[p1]** 用生成式图网络(DeepCoy)构造性质匹配hard decoys并以确认无活性物富集训练数据
  - 原文："hard-to-discriminate decoys property-matched to them with generative graph neural networks and confirmed inactives"
- **[p1]** 去相似化测试集（Tanimoto<0.70）确保评估严格性，最优SVM+PLEC回归NEF1%=0.588
  - 原文："achieved a high Normalized Enrichment Factor at the top 1% on the hardest test set (NEF1% = 0.588)"
- **[p1]** 实证深度学习在该靶点VS上差于简单ML模型（SVM/RF）
  - 原文："Deep learning performed poorly on this target in comparison with the simpler ML models"
- **[p6]** 回归型打分函数利用定量生物活性数据普遍优于分类型
  - 原文："the majority of those trained with PLEC features gave better performance than their classification counterparts"
- **[p6]** 蛋白-配体指纹(PLEC)系统性优于GRID特征且最高效
  - 原文："Target-specific classification and regression models built on PLEC fingerprints were found to be more predictive than those based on GRID features"

## 方法

- Smina对接到PARP1晶体(PDB 7KK4)后提取PLEC与GRID蛋白-配体指纹
- DeepCoy生成式图网络生成性质匹配hard decoys（3350个对67个测试活性物）
- 五种算法：RF/SVM/XGB/ANN/DNN，贝叶斯超参优化
- 回归型（定量活性）与分类型SF对比；叠加配体Morgan指纹的增益实验
- 去相似测试集（与训练集Tanimoto<0.70）防止性能虚高
- NEF1%/EF1%/PR-AUC多指标评估

## 数据与基准

- ChEMBL v29：5097个PARP1生物活性数据点；训练集1565个生化IC50分子
- 测试集93个分子（细胞IC50+生化效价）+3350 DeepCoy decoys
- PDB 7KK4受体结构

## 结果证据

- 最优：PLEC+SVM回归，EF1%=38.8、NEF1%=0.764（测试集），最难去相似测试集NEF1%=0.588——超随机32倍以上富集
- PLEC特征普遍优于GRID特征（PR-AUC）
- 回归型SF多数优于分类型（定量活性数据有价值）
- 多数模型加Morgan配体指纹提升，但最优模型无进一步增益
- 深度学习(DNN)表现差于简单ML；ML型通用SF(CNN-Score/SCORCH)优于经典Smina

## 比较基线

- Smina（经典SF）
- CNN-Score（深度学习通用SF）
- SCORCH（集成通用SF）
- GRID vs PLEC特征互为对照

## 已知限制

- 单靶点（PARP1）回顾性研究，未湿实验验证命中
- 训练数据混合不同实验来源的IC50/Kd，效价可比性问题
- 作者指出训练集与CNN-Score训练集有0.52%微小重叠（已论证影响可忽略）

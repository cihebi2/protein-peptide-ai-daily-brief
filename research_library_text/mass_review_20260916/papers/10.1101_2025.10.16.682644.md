# peleke-1: A Suite of Protein Language Models Fine-Tuned for Targeted Antibody Sequence Generation

## 研究问题

传统抗体发现（动物免疫→杂交瘤→筛选）慢且贵。论文探索将通用指令微调 LLM（非蛋白专用）经 LoRA 微调用于抗原/表位条件化的治疗抗体 Fv 序列大规模生成。

## 作者主张的贡献

提出 peleke-1：三个通用 LLM（Phi-4 14.7B、Llama-3.1-8B-Instruct、Mistral-7B-Instruct）在 9523 条抗体-抗原复合物（PDB 策展，PandaProt 标注表位残基）上 LoRA 微调的套件；输入抗原序列（表位残基方括号标注）生成配对重/轻链 Fv；生成序列 100% 可 Chothia 编号、82%/80% 预测为人源、抗 PD-1 候选中 55.3% 预测 vdW 能量优于 pembrolizumab；开源权重/数据/微调与生成管线。

## 创新边界

用通用 NLP LLM 微调生成蛋白序列并非新范式（ProGen、多次抗体 LLM 工作在前）；本文的差异化是'通用指令 LLM + 表位 token 化 LoRA 微调'的轻量工程路线；评估全部为计算代理指标（编号/人源性/能量打分），无任何湿实验或结构验证，55.3% 优于 pembrolizumab 的声明基于 vdW 能量这一弱代理指标，证据力低；7 个基准抗原规模小。

## 创新点证据卡

- **[p5]** 通用指令 LLM（Phi-4/Llama/Mistral）LoRA 微调即可以做表位条件化抗体 Fv 生成
  - 原文："task-specific fine-tuning of PLMs will accelerate therapeutic discovery"
- **[p5]** 表位残基 token 化标注（<epi> token + 方括号）实现可控表位条件设计
  - 原文："peleke-1 can generate antibody sequences conditioned on desired epitopes, enabling controllable design"
- **[p5]** 完整开源权重+策展数据+微调与生成管线形成可复用抗体 LLM 调优框架
  - 原文："We release model weights, curated training data, tuning code, and generation pipelines"

## 方法

- 数据策展：PDB 抗体-抗原复合物过滤得 9523 条（重链 Fv+轻链 Fv+抗原）
- PandaProt 识别表位残基，方括号标注+特殊 token <epi></epi>
- LoRA PEFT 微调（可训练 0.19%-5.03% 参数），tokenizer 扩展氨基酸与'|'链分隔符
- 推理 <1 分钟/Fv（消费级 GPU）
- 评估：Chothia 编号（IgBLAST 类）、人源性预测、FoldX 风格能量分解、与已知抗体 vdW 能量比较

## 数据与基准

- 训练：9523 条 PDB 抗体-抗原三元组
- 基准：7 个抗原（EGFR 8HGO、PD-L1 4Z18、PD-1 5JXE、MBP、IL-7Ra、BBF-14、BHRF1）
- 每模型每抗原生成 50 个 Fv，共 1050 测试复合物

## 结果证据

- 100% 生成 Fv 可 Chothia 编号（仅 4 例编号警告）
- 重/轻链人源性预测 82%/80%
- 平均总能量 -215.59 kcal/mol（声称稳定）
- 序列多样性高于其先前 EvoDiff 工作，CDR 区外保守模式明显（EVQL/QVQL 起始）
- 靶点依赖：MBP/PD-1/PD-L1 亲和分数好，BBF-14/BHRF1/EGFR 差（如 BHRF1 vdW +218.86 到 +131.62）
- 150 个抗 PD-1 候选中 83 个（55.3%）vdW 能量优于 pembrolizumab (-62.22)

## 比较基线

- pembrolizumab 及其他已批抗 PD-1 抗体的文献 vdW 能量
- （无模型级 SOTA 对比，如无 IgBuddy/AbLang/binder DL 方法比较）

## 已知限制

- 纯计算评估，无湿实验/无结构验证（仅模板对比图）
- vdW 能量/打分作为亲和代理很弱
- 7 靶点小规模，且部分靶点结果差
- 通用 LLM token 化氨基酸的效率低于蛋白专用 tokenizer
- 训练数据仅 PDB 已解复合物，偏差大

## 待复核未知项

- 表位标注对抗体生成质量的消融
- 与蛋白专用生成模型（如 ProGen2/抗体特化模型）的定量对比
- 开发性（免疫原性/可溶性）评估缺失

# Chemprop: A Machine Learning Package for Chemical Property Prediction

- **DOI：** [10.1021/acs.jcim.3c01250](https://doi.org/10.1021/acs.jcim.3c01250)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）

## 研究问题

为非专家用户提供开源、易用、快速的分子性质预测深度学习软件。Chemprop 实现有向消息传递神经网络（D-MPNN）并持续扩展功能以覆盖多分子体系、反应、原子/键级性质与光谱预测。

## 作者主张的贡献

新版 Chemprop：支持多分子输入（溶质/溶剂）、反应（CGR 凝聚反应图）、原子/键级目标、光谱目标（谱信息散度损失）；集成不确定性量化与校准方法（集成、均值-方差、证据学习）、预训练与迁移学习工作流、改进超参优化；在 MoleculeNet/SAMPL 等基准上达到辛醇-水分配系数、反应能垒、原子部分电荷、吸收光谱预测的 SOTA。

## 创新边界

D-MPNN 架构源自 Gilmer 等与初版 Chemprop（2019），本文是软件功能更新论文而非架构创新；各功能（CGR 反应支持、证据不确定性等）均来自已发表方法（Heid 等）的工程集成；'SOTA' 声明限于其自选基准集。

## 创新点证据卡

- **[p4]** 将反应预测统一进 D-MPNN：反应物/产物图并集构建凝聚反应图（CGR）伪分子
  - 原文："The pair of reactants and products is transformed into a single pseudomolecule, namely, the condensed graph of reaction"
- **[p1]** 集成多种不确定性量化（集成/均值-方差/证据学习）与校准度量于统一命令行工具
  - 原文："we incorporate various uncertainty quantification and calibration methods along with related metrics"
- **[p4]** 光谱级目标预测采用谱信息散度损失并支持遮挡排除区域
  - 原文："Spectral Information Divergence... is adapted in Chemprop to be used as a loss function"
- **[p4]** 多分子体系（溶质/溶剂）分别编码后拼接的通用建模模式
  - 原文："Chemprop can also train on a data set containing more than one molecule as input"

## 方法

- D-MPNN：有向边消息传递（T=3 步默认），原子/键 one-hot 初始特征（RDKit 图构建）
- 原子嵌入聚合（求和/缩放求和/平均）为分子嵌入，可选 Morgan/RDKit 2D 指纹拼接
- FFN 输出层，端到端训练（Adam，warmup+指数衰减学习率）
- 多分子模式（各自 D-MPNN 或共享 --mpn_shared）
- 反应模式：反应物/产物 SMILES 并集构建 CGR 伪分子
- 光谱模式：谱信息散度（SID）损失+排除区域
- 不确定性：集成、均值-方差估计、证据学习及校准指标

## 已知限制

- 多分子模式不具备输入分子置换不变性（仅适合角色固定的输入）
- 作者提示小数据集需远超默认 30 epoch，需检查收敛
- 针对小分子；无原生肽/蛋白大分子支持

# Fingerprinting Interactions between Proteins and Ligands for Facilitating Machine Learning in Drug Discovery

## 研究问题

2D 分子指纹广泛用于 QSAR 但缺乏靶标特异性结构特征；3D 结构相互作用指纹（IFP）能编码蛋白-配体关键相互作用并驱动机器学习打分函数，需系统梳理其类型、能力与局限。

## 作者主张的贡献

综述结构 IFP 家族（自 Deng 2004 七位/氨基酸算法起的演进）并给两个案例研究：beta2 肾上腺素受体配体的激动剂/拮抗剂区分（SAR elucidation），以及逆合成预训练分子表示预测解离速率（结合动力学）；指出可解释性、结合位点可塑性/诱导契合等挑战。

## 创新边界

综述论文；所有 IFP 算法与案例均引自原始文献（Deng 2004、Mordalski 扩展等）；'3D IFP 优于 2D 指纹'为领域共识转述；FDA/NIH 作者视角的价值在于监管端应用归纳。

## 创新点证据卡

- **[p3]** 3D 相互作用指纹（IFP）作为靶标特异性特征优于通用 2D 指纹的论证
  - 原文："the focus of scoring function descriptors has shifted towards 3D interaction fingerprints (IFPs)"
- **[p1]** IFP 驱动的 ML 可区分激动剂与拮抗剂（beta2-AR 案例核心发现）
  - 原文："demonstrating the ability to differentiate agonists and antagonists"
- **[p1]** 逆合成预训练分子表示预测解离速率，连接 IFP 与结合动力学
  - 原文："a retrosynthesis-based pre-trained molecular representation to predict protein-ligand dissociation rates"
- **[p3]** IFP 的历史演进谱系（Deng 2004 七位编码->芳香/带电位扩展）
  - 原文："encompassed seven bits per interacting amino acid, representing predefined interaction types"

## 方法

- IFP 类型学综述（布尔/整数/浮点向量的相互作用模式编码）
- 2D vs 3D 指纹对比框架
- 两个案例研究（beta2-AR 配体分型；解离速率预测）

## 数据与基准

- 文献案例数据（激酶-抑制剂复合物聚类、beta2-AR 配体等）

## 结果证据

- IFP 以简洁表示+关键相互作用精细图谱成为 ML 打分函数的有力特征
- 结构 IFP 可区分激动剂与拮抗剂（beta2-AR 案例）
- 逆合成预训练表示可预测蛋白-配体解离速率
- 挑战：3D 指纹上复杂 ML 模型的可解释性、结合位点塑性/诱导契合

## 比较基线

- 经典打分函数（被 ML 打分超越）
- 2D 指纹（子结构键/拓扑/环形/药效团四类）

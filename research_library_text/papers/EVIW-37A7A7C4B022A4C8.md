# Shining light on drug discovery: optogenetic screening for TopBP1 biomolecular condensate inhibitors

- **论文 ID：** `EVIW-37A7A7C4B022A4C8`
- **期刊 / 来源：** NAR Cancer
- **发表时间：** 2025 Nov 3
- **DOI：** [10.1093/narcan/zcaf041](https://doi.org/10.1093/narcan/zcaf041)
- **范围标签：** `Pi 已解析` / `背景资料` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者建立并应用一个高通量 optogenetic screening 流程，从 FDA-approved compounds 中找出 TopBP1 condensate inhibitors，重点验证 quinacrine 和 thimerosal，并进一步证明 quinacrine 可削弱 ATR/Chk1 signaling、改变 TopBP1-chromatin 结合，且在细胞与小鼠模型中增强 FOLFIRI 疗效。

## 创新边界

`创新边界主要在于以 condensate-focused 的药物重定位与体内联用验证来干预 TopBP1/ATR 轴，而不是提出新的算法、模型架构或 de novo 分子设计。`。这不是全球首创性检索或独立复现结论。

## 研究问题

识别能够抑制 TopBP1 biomolecular condensate 形成、从而削弱 ATR/Chk1 DNA damage signaling 的可转用小分子，并评估其与标准化疗方案联用时是否能增强抗肿瘤效果。

## 方法

- 在细胞中光控TopBP1凝聚并筛选化合物，结合生化/成像、癌细胞和小鼠腹膜癌模型验证。

## 数据与基准

- HeLa/HCT116等细胞、凝聚与信号实验及结直肠癌小鼠模型。

## 比较基线

- 载体/未处理、标准化疗及候选化合物对照。

## 结果证据

- quinacrine阻断TopBP1凝聚并在小鼠模型提高5-FU与irinotecan疗效；这是实验药理学结果。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 与本知识库的计算蛋白/药物设计方法主线不一致；模型特异性和临床外推仍有限。

## 仍未知

- quinacrine 对 TopBP1 的直接结合位点或最初分子事件尚未解析。
- 该策略在其他癌种、其他 DNA-damage 负荷场景中的可迁移性未知。
- 缺少人体样本或临床试验层面的验证，真实安全窗与获益尚不清楚。

## Pi 结构化证据摘录

- **baseline：** 论文把传统 ATR inhibitors 视为重要但受 toxicity 和 resistance 限制的路线，因此转而寻找不直接抑制 kinase 的替代策略。
  - 证据：[doi:10.1093/narcan/zcaf041, p.2]
- **baseline：** 作者明确承接了自己先前关于 TopBP1 condensates 的 optogenetic framework，并将其扩展到 FDA-approved drug repurposing 的筛选场景。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.15]
- **baseline：** 相对 baseline treatment，FOLFIRI 单药已经能压低肿瘤负荷，而 quinacrine + FOLFIRI 在同一模型中进一步提升了疗效，形成明确的比较基线。
  - 证据：[doi:10.1093/narcan/zcaf041, p.13]；[doi:10.1093/narcan/zcaf041, p.14]
- **data：** Prestwick screen 共识别出 31 个潜在 TopBP1 condensation inhibitors，其中约一半是 DNA intercalators 或 DNA-binding molecules；quinacrine 和 thimerosal 被挑选为后续重点验证对象。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.7]
- **data：** 在 HCT116 中，quinacrine 和 thimerosal 都能显著降低 SN-38 诱导的 TopBP1 nuclear foci；quinacrine 还没有明显影响 PML bodies，也未引起显著 cell cycle 改变。
  - 证据：[doi:10.1093/narcan/zcaf041, p.8]；[doi:10.1093/narcan/zcaf041, p.7]
- **data：** quinacrine 使 TopBP1 更多出现在 soluble/nucleosolic fraction，并减少 chromatin fraction 中的 TopBP1，同时降低 H3K9Ac，但对 H3K4me3 和 H3K9me3 影响不明显。
  - 证据：[doi:10.1093/narcan/zcaf041, p.9]；[doi:10.1093/narcan/zcaf041, p.10]
- **data：** quinacrine 和 thimerosal 都抑制 SN-38 诱导的 pChk1、pRPA32 和 pATR；其中 quinacrine 对 γH2AX 的抑制更强，而 thimerosal 对 γH2AX 影响较小。
  - 证据：[doi:10.1093/narcan/zcaf041, p.9]；[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.11]
- **data：** quinacrine + FOLFIRI 在 2D 与 3D culture 中总体表现为 additivity 并伴有局部 synergy，在 HCT116 中主要是 cytostatic，在 CT26 中高剂量下呈现 cytotoxic；体内则降低肿瘤生长并改善 PCI。
  - 证据：[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.12]；[doi:10.1093/narcan/zcaf041, p.13]；[doi:10.1093/narcan/zcaf041, p.14]
- **declared_resources：** 可复用的实验资源包括可诱导表达 TopBP1-Cry2-mCherry 的 optoTopBP1-HEK293 细胞系，以及用于验证的 HCT116、LNCaP、CT26 和 SN-38-resistant HCT116-SN6/HCT116-SN50 细胞系。
  - 证据：[doi:10.1093/narcan/zcaf041, p.2]；[doi:10.1093/narcan/zcaf041, p.8]；[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.12]
- **declared_resources：** 化学与治疗资源包括 Prestwick Chemical Library、SN-38、5-FU、quinacrine、thimerosal 和 FOLFIRI 组合。
  - 证据：[doi:10.1093/narcan/zcaf041, p.2]；[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.10]
- **declared_resources：** 作者使用的主要平台资源包括 Opera Phenix high-content system、Celigo Imaging Cytometer、IVIS Lumina II、Gallios flow cytometer、CellProfiler、R、GraphPad、Fiji 和 MRI facility。
  - 证据：[doi:10.1093/narcan/zcaf041, p.3]；[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.15]
- **declared_resources：** 体内资源是 CT26-luc 腹膜播散小鼠模型，以及基于 bioluminescence 和 PCI 的病程评估流程。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.13]
- **declared_resources：** 作者还声明了用于核提取和细胞分馏的 HeLa S3/HCT116 nuclear extract workflow，这属于支持机制验证的关键实验资源。
  - 证据：[doi:10.1093/narcan/zcaf041, p.4]；[doi:10.1093/narcan/zcaf041, p.3]
- **limitations：** 作者在体外验证中需要较高浓度的 quinacrine 和 thimerosal、且仅做 2 h acute treatment，这限制了对长期给药可转化性的判断。
  - 证据：[doi:10.1093/narcan/zcaf041, p.7]；[doi:10.1093/narcan/zcaf041, p.8]
- **limitations：** quinacrine 和 thimerosal 本身都是多靶点或化学反应性较强的化合物，因此 TopBP1 condensate inhibition 不一定是其全部药理机制。
  - 证据：[doi:10.1093/narcan/zcaf041, p.7]；[doi:10.1093/narcan/zcaf041, p.14]
- **limitations：** 体内实验里 γH2AX 在 quinacrine + FOLFIRI 与 FOLFIRI 之间并未像细胞实验那样明显分离，说明机制读数并非完全一致。
  - 证据：[doi:10.1093/narcan/zcaf041, p.14]
- **limitations：** 筛选空间只覆盖 Prestwick 的 1520 个 FDA-approved compounds，化学空间和可发现的新骨架范围都比较有限。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]
- **method：** 作者使用可诱导表达 TopBP1-Cry2-mCherry 的 optoTopBP1-HEK293 细胞，在 384 孔板内通过 488 nm 蓝光脉冲诱导 TopBP1 condensates，并用 Prestwick Chemical Library 的 1520 个 FDA-approved compounds 做 10 μM、2 h 的高通量筛选。
  - 证据：[doi:10.1093/narcan/zcaf041, p.2]；[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.6]
- **method：** 筛选读数按板内中位数做 normalization，并以 triplicate 的 z-score、Z'-factor 和阈值判定 hit，以降低 plate effect 并量化凝聚体抑制强度。
  - 证据：[doi:10.1093/narcan/zcaf041, p.3]；[doi:10.1093/narcan/zcaf041, p.6]
- **method：** 作者在 HCT116、LNCaP、CT26、SN-38-resistant HCT116-SN6/HCT116-SN50，以及 HeLa S3/HCT116 nuclear extracts 上，结合 immunofluorescence、western blot、cell fractionation、Celigo Imaging Cytometer 和 flow cytometry 进行验证。
  - 证据：[doi:10.1093/narcan/zcaf041, p.2]；[doi:10.1093/narcan/zcaf041, p.3]；[doi:10.1093/narcan/zcaf041, p.4]；[doi:10.1093/narcan/zcaf041, p.9]；[doi:10.1093/narcan/zcaf041, p.10]
- **method：** 作者用 SRB assay、2D/3D spheroid assay 和 Bliss/Lehàr synergy matrix 评估 quinacrine、thimerosal 与 5-FU、SN-38、FOLFIRI 的联用效应，并区分 cytostatic 与 cytotoxic 结果。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.12]
- **method：** 作者在 CT26-luc 皮下/腹膜播散相关的小鼠模型中，采用 quinacrine 口服加 FOLFIRI 腹腔给药，并以 bioluminescence signal、PCI、tumor weight 和肿瘤免疫荧光作为体内终点评估。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.13]；[doi:10.1093/narcan/zcaf041, p.14]
- **results：** 作者的核心结果是：基于 optogenetic 的 condensate screen 能从已上市药物中找出真正能压制 TopBP1 聚集的化合物，并把这种表型和 ATR/Chk1 信号下降联系起来。
  - 证据：[doi:10.1093/narcan/zcaf041, p.5]；[doi:10.1093/narcan/zcaf041, p.8]；[doi:10.1093/narcan/zcaf041, p.9]
- **results：** quinacrine 被证明比 thimerosal 更像一个可转用的主候选，因为它不仅抑制 TopBP1 condensates，还影响 TopBP1-chromatin interface，并能在多种细胞背景中重复观察到。
  - 证据：[doi:10.1093/narcan/zcaf041, p.8]；[doi:10.1093/narcan/zcaf041, p.9]；[doi:10.1093/narcan/zcaf041, p.10]
- **results：** 数据支持 quinacrine 通过削弱 ATR signaling 和 checkpoint 输出来提高化疗敏感性，而不是单纯造成非特异性细胞毒性。
  - 证据：[doi:10.1093/narcan/zcaf041, p.9]；[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.14]
- **results：** 与 FOLFIRI 联用时，quinacrine 在体内比单用 FOLFIRI 更强地压低肿瘤负荷和 PCI，说明该 condensate-targeting 策略具有治疗放大效应。
  - 证据：[doi:10.1093/narcan/zcaf041, p.13]；[doi:10.1093/narcan/zcaf041, p.14]
- **results：** 作者把这些结果解释为：quinacrine 可能通过改变 chromatin accessibility 和 TopBP1 定位来阻断 replication-stress 下的 condensate assembly，从而降低 ATR/Chk1 放大回路。
  - 证据：[doi:10.1093/narcan/zcaf041, p.10]；[doi:10.1093/narcan/zcaf041, p.14]

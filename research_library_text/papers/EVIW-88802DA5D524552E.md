# Integration of molecular coarse-grained model into geometric representation learning framework for protein-protein complex property prediction

- **论文 ID：** `EVIW-88802DA5D524552E`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Nov 7

## 作者主张的创新点

提出 MCGLPPI，把 MARTINI coarse-grained 结构、力场参数、图神经网络编码与 DDI 自监督预训练结合起来，用于高效预测 PPI 复合物总体性质。

## 创新边界

`新意主要在表示与工程整合；是否构成更广义的原创算法突破，正文无法单独验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在保持化学可解释性的同时，用更少 GPU 资源，利用 coarse-grained MARTINI 图表示预测 protein-protein complex 的 overall properties（binding affinity 与 interface type）。

## 方法

- complex coarse-graining、equivariant/geometric message passing和property heads。

## 数据与基准

- PPI complex结构与affinity/quality等。

## 比较基线

- geometric GNN、物理CG和无融合消融。

## 结果证据

- 论文报告超过atom-only/CG baselines；为计算。

## 已知限制

- CG丢失原子细节，结构质量与数据规模限制。

## 仍未知

- 补充材料中的超参数、完整对照与更多消融未逐页核验。

- MARTINI2/MARTINI3、crop thresholds 与 pretraining gains 的最优性是否对更广泛 PPI 场景成立未知。

## Pi 结构化证据摘录

- **baseline：** 对比基线主要是 atom-scale GearNet-Edge、residue-scale GearNet-Edge、atom-scale GVP-GNN，以及既有的 DeepRank-GNN 和 EGGNet。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.5]；[doi:10.1038/s41467-024-53583-w, p.6]
- **baseline：** 作者指出 DeepRank-GNN 依赖时间较高的 sequence alignment 特征提取，因此其计算成本不适合与本文做严格一一对应的比较。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.6]
- **data：** 3DID 预训练集在去除与下游集合重叠模板后保留 41,663 个 DDI 结构样本；跨尺度比较时又统一为 33,144 个可识别样本。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.10]；[doi:10.1038/s41467-024-53583-w, p.7]
- **data：** 下游数据包括 PDBbind-strict-dimer 1270 个样本、ATLAS 531 个结构，以及 MANY 5739 和 DC 161 个 dimer。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.5]；[doi:10.1038/s41467-024-53583-w, p.6]
- **data：** 为做公平成本比较，作者还统计了可被 GearNet-Edge 处理的子集：PDBbind 为 915/1270，ATLAS 为 451/531。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.5]；[doi:10.1038/s41467-024-53583-w, p.6]
- **declared_resources：** 作者公开了 3DID、PDBbind、ATLAS、MANY/DC、AB-bind 等数据来源，并将数据重新打包到 GitHub；同时给出了 MCGLPPI v1.0 源码仓库地址。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.12]
- **declared_resources：** 实现环境采用 PyTorch、Torchdrug、Adam，在单块 NVIDIA A100 GPU 40GB 上运行，并使用 Baskerville Tier 2 HPC service。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.12]；[doi:10.1038/s41467-024-53583-w, p.13]
- **limitations：** 论文明确承认模型当前不能直接利用更容易获得的 PPI sequence 数据作为输入，仍主要依赖 3D 结构。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.10]
- **limitations：** 作者也指出 MCGLPPI 不能完全覆盖蛋白-蛋白系统复杂性，仍有其他 coarse-grained modeling system 值得探索。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.10]
- **limitations：** 预训练并非对所有任务都增益，MANY/DC 上出现指标下降，提示 DDI pretraining 的边界需要进一步验证。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.7]
- **method：** 作者先把蛋白复合物从 atomistic 结构转换为 MARTINI22/MARTINI3 coarse-grained beads，并把 bead types、bonds、angles、dihedrals 编入图特征。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.10]；[doi:10.1038/s41467-024-53583-w, p.11]
- **method：** CG 图将每个 bead 作为节点，边同时包含 5Å 接触、同/异 residue 的 intra/inter contact，以及五类 MARTINI bonded interactions。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.11]
- **method：** 图编码前使用 core region 与 adjacent region 的双阶段 cropping，以 8.5Å 和 10Å 的 residue backbone 距离阈值保留局部相互作用。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.11]
- **method：** 编码器基于 GearNet-Edge 的 line-graph 增强 message passing，输出再接三层 MLP；另外还引入基于 3DID 的 diffusion denoising pre-training。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.12]
- **results：** 在 PDBbind-strict-dimer 子集上，MCGLPPI-M2/M3 在 batch size 64 时分别达到 RP 0.597/0.603、RMSE 2.065/2.063、MAE 1.595/1.581，并比 atom/residue/GVP baseline 省显著 GPU 和时间。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.5]；[doi:10.1038/s41467-024-53583-w, p.6]
- **results：** 在 ATLAS 子集上，MCGLPPI-M3 在 batch size 64 时达到 RP 0.832、RMSE 1.013、MAE 0.783；完整 curated ATLAS 结果为 RP 0.809/0.823、RMSE 1.116/1.053、MAE 0.837/0.803。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.5]；[doi:10.1038/s41467-024-53583-w, p.7]
- **results：** 在 MANY/DC 子集上，MCGLPPI-M2/M3 在 batch size 64 时达到 AUROC 0.890/0.882、AUPR 0.871/0.881，并优于 GearNet-Atom、GearNet-Res 与 GVP-GNN；完整 MANY/DC 上也超过 DeepRank-GNN 和 EGGNet。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.6]；[doi:10.1038/s41467-024-53583-w, p.7]
- **results：** DDI pretraining 对 binding affinity regression 有帮助，但在 interface classification 上反而使 AUPR 从 0.880 降到 0.866，说明迁移效果具有任务依赖性。
  - 证据：[doi:10.1038/s41467-024-53583-w, p.7]；[doi:10.1038/s41467-024-53583-w, p.8]

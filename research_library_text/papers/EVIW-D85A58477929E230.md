# Comparative evaluation of methods for the prediction of protein-ligand binding sites

- **论文 ID：** `EVIW-D85A58477929E230`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2024 Nov 11
- **DOI：** [10.1186/s13321-024-00923-z](https://doi.org/10.1186/s13321-024-00923-z)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 LIGYSIS 作为新的人类蛋白配体结合位点基准，比较 13 个原始方法与 15 个变体，主张 top-N+2 recall 与去冗余/重评分能更真实反映性能。

## 创新边界

`新意主要在 benchmark、dataset 与评测规则，不是新预测器。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在不偏置于单一数据集或单一评分规则的前提下，公平评测 protein-ligand binding site predictors，并构建更可靠的 reference dataset。

## 方法

- 聚合同一蛋白多结构的生物学相关唯一界面，统一运行13个方法及15个变体，以残基级和口袋级10类指标比较并分析预测冗余。

## 数据与基准

- LIGYSIS总体约3万蛋白；本文人类子集基准含2775条链。

## 比较基线

- VN-EGNN、IF-SitePred、GrASP、PUResNet、DeepPocket、P2Rank/PRANK、fpocket、PocketFinder、Ligsite、Surfnet等。

## 结果证据

- 作者报告PRANK/DeepPocket重评分fpocket的recall最高约60%，去除重复预测可使IF-SitePred recall增14%、Surfnet precision增30%。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 基准聚焦人类子集且仍受已解析复合物偏差影响；这是一项评测/数据贡献，不是新预测器，排名取决于口袋定义和评分协议。

## 仍未知

- 补充材料与代码仓库未在本次评审中实际执行，复现性仅能依据论文声明判断。
- DCC=12Å、JI≥0.75、d≤5Å 等阈值是作者设定，跨数据集泛化性未在冻结页中独立验证。
- 作者未纳入部分较新的方法，完整排名可能随实现可用性变化。

## Pi 结构化证据摘录

- **baseline：** 文中把 top-N+2 recall 作为 success rate 基线，因为 reference data 不完整，N 取每个蛋白已观测 site 数；同时也给出 all-predictions 的 maximum recall 作为上界参考。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.21]；[doi:10.1186/s13321-024-00923-z, p.30]
- **baseline：** residue-level ROC 的随机基线为 0.5，PR 的基线为正类比例 0.1；作者同时指出 DCC=4Å 过严，而 DCC=10–12Å 更适合与 DCA 对齐。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.17]；[doi:10.1186/s13321-024-00923-z, p.21]；[doi:10.1186/s13321-024-00923-z, p.30]
- **baseline：** 作者将本工作定位为十余年来首个独立 ligand site benchmark，并把 13 个原始方法扩展为 13+15 个原始/变体比较对象。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.1]；[doi:10.1186/s13321-024-00923-z, p.20]
- **data：** LIGYSIS 全量覆盖约 30,000 个已知 ligand-bound proteins；人类子集在筛掉 UniProt 映射缺失的链后，形成最终 2775 条可评测 chains，并对应 6882 个 reference binding sites。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.4]；[doi:10.1186/s13321-024-00923-z, p.11]；[doi:10.1186/s13321-024-00923-z, p.28]
- **data：** LIGYSIS 通过聚合同一蛋白不同结构中的 23,321 个 biologically relevant ligand-binding structures，得到 65,116 个 ligands；作者还明确纳入约 40% 的 ion sites，并单列 LIGYSISNI 作为去离子对照。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.4]；[doi:10.1186/s13321-024-00923-z, p.6]；[doi:10.1186/s13321-024-00923-z, p.9]
- **data：** 与 sc-PDBFULL、bMOADSUB、CHEN11、PDBbindREF、SC6K、HOLO4K、COACH420、JOINED 相比，LIGYSIS 更强调 biological assembly、去冗余接口和多结构整合，因此在 site 数、ligand 类型和多位点分布上更接近真实生物学情境。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.6]；[doi:10.1186/s13321-024-00923-z, p.7]；[doi:10.1186/s13321-024-00923-z, p.22]
- **declared_resources：** Data availability：主结果表和复现实验文件放在 Zenodo 10.5281/zenodo.13121414。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.32]
- **declared_resources：** Code availability：分析软件发布在 GitHub repository `bartongroup/LBS-comparison`。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.33]
- **declared_resources：** 作者同时说明研究使用 University of Dundee 的 HPC infrastructure 完成。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.32]
- **limitations：** 最终评测仅剩 2775 human chains，且需要丢弃 UniProt 映射缺失的链；因此结论主要针对 human subset，而非所有蛋白。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.4]；[doi:10.1186/s13321-024-00923-z, p.28]
- **limitations：** reference data 本身不完整，作者估计仍有 33–50% 的真实 binding sites 未被观测到，因此部分“假阳性”可能只是尚未标注的真实位点。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.21]
- **limitations：** 部分方法不提供 pocket residues 或 score，作者不得不以 centroid/grid points 外推 residue labels，这会让 residue-level 指标与 pocket-level 指标不可直接同义。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.27]；[doi:10.1186/s13321-024-00923-z, p.29]；[doi:10.1186/s13321-024-00923-z, p.22]
- **limitations：** 论文还承认一些新方法因技术原因未纳入，且默认参数/公开实现差异会影响可比性。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.32]
- **method：** 作者先用 BioLiP 生物学相关配体、PISA biological assembly 与 PDBe-KB/SIFTS 映射构建 LIGYSIS，并用 ligand interaction fingerprint 的层次聚类把同一蛋白的配体归并为独立 binding sites。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.23]；[doi:10.1186/s13321-024-00923-z, p.24]
- **method：** 评测对象是 13 个原始 ligand binding site/cavity 方法；对 fpocket、P2Rank、PRANK、DeepPocket、IF-SitePred、GrASP 等按默认参数运行，并为缺少 pocket score 的方法补做 AA、PRANK、SS 三种重评分/重排序变体。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.27]；[doi:10.1186/s13321-024-00923-z, p.28]
- **method：** 评估分为 residue level 与 pocket level；pocket 命中用 DCC≤12Å 判定，采用 top-N、top-N+2、Precision1K、ROC100、RRO、RVO 和 redundancy 等指标。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.29]；[doi:10.1186/s13321-024-00923-z, p.30]
- **method：** 对 VN-EGNN、IF-SitePred 与 DeepPocketSEG 先做去冗余，冗余定义为 centroid 距离≤5Å 或 JI≥0.75，并保留高分 pocket。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.17]；[doi:10.1186/s13321-024-00923-z, p.19]
- **results：** 在 pocket 级 top-N+2 recall 上，fpocketPRANK 60.4% 与 DeepPocketRESC 58.1% 领先，P2RankCONS 53.9%、P2Rank 51.9% 紧随；IF-SitePred 最低，仅 25.7%。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.13]；[doi:10.1186/s13321-024-00923-z, p.15]
- **results：** 去冗余与重排序对 VN-EGNN、IF-SitePred、DeepPocketSEG 分别带来 +5.2%、+13.4%、+5.6% 的 recall 提升；IF-SitePred 采用新的 ligandability score 后又额外提升 +2.1%。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.19]；[doi:10.1186/s13321-024-00923-z, p.20]
- **results：** Newer ML methods 的 Precision1K 达 80–95%，明显高于 geometry/energy-based methods 的 40–50%；在 residue-level 上，P2RankCONS 的 AUC/AP 也最高，分别为 0.76 与 0.46。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.14]；[doi:10.1186/s13321-024-00923-z, p.17]
- **results：** 作者强调 pocket-level 的 RRO/RVO 和 recall 比 F1/MCC 更能反映可用性，因为后者更容易偏向高 precision 但低 recall 的方法。
  - 证据：[doi:10.1186/s13321-024-00923-z, p.15]；[doi:10.1186/s13321-024-00923-z, p.22]

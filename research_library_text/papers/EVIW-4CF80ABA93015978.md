# Generative design of compounds with desired potency from target protein sequences using a multimodal biochemical language model

- **论文 ID：** `EVIW-4CF80ABA93015978`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2024 May 22
- **DOI：** [10.1186/s13321-024-00852-x](https://doi.org/10.1186/s13321-024-00852-x)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `扩散/生成` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出了一个双组件的 multimodal biochemical language model：先用预训练 protein language model 生成蛋白序列 embedding，再把其与 potency token 结合输入 conditional transformer，以从目标序列条件化地生成期望 potency 的活性化合物；作者还宣称这是首次把这种条件化语言模型用于基于蛋白序列的化合物生成。

## 创新边界

`真正的新意主要在于条件化的序列到化合物生成框架与 potency conditioning，而不是某个已被独立证明普适优越的通用预测器；当前冻结证据只能支持在所选数据上的 proof-of-concept，不能支持全球新颖性结论。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在给定目标蛋白序列的前提下，能否把化合物生成转化为一种受 potency 约束的 sequence-to-SMILES 翻译问题，从而直接设计出对目标有效、并满足预设 pKi 条件的候选化合物。

## 方法

- protein/compound tokenization，conditional autoregressive generation。

## 数据与基准

- 公开protein-ligand potency pairs。

## 比较基线

- unconditional/target-aware generative models。

## 结果证据

- 论文报告target-conditioned potency/validity提升；为计算。

- potency label/sequence-only target representation和无实验。

## 仍未知

- 在未见 target 上的泛化能力仍未验证。
- 模型为何能复现特定 test compounds 的内部机制仍然不透明。
- 缺少 wet-lab prospective validation，实际可转化性未知。

## Pi 结构化证据摘录

- **baseline：** 作者以同架构但去掉 potency conditioning 的 unconditional transformer 作为主要 baseline，用来衡量 potency 条件本身的增益。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.6]
- **baseline：** 作者还设置了不做 fine-tuning 的 conditional control，结果没有复现任何 test compounds，用来证明任务需要 class-specific adaptation。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.7]
- **baseline：** 论文并未只看复现率，还把 fine-tuning compounds、test compounds、复现 compounds 和候选 compounds 的 potency、相似性与 SA 分布并列比较。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.8]；[doi:10.1186/s13321-024-00852-x, p.9]
- **data：** 数据来自 ChEMBL release 33 的 human direct interactions，限制为 assay confidence 9 且仅保留 Ki/pKi，最终形成 1575 个 activity classes 和 87,839 个 unique compounds。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.2]；[doi:10.1186/s13321-024-00852-x, p.3]
- **data：** 模型评估选取了 10 个 activity classes，覆盖 thrombin、CB1 receptor、D3 receptor、factor X、A2a receptor 等，单类规模大约在 397 到 1825 个 compounds 之间。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.3]
- **data：** 每个 activity class 先用 CCR 算法系统识别 analogue series，再按 50/50 分成 fine-tuning 与 test 子集，并保证 core structure 不重叠。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.6]
- **declared_resources：** 作者声明 Python scripts、models、all pre-training and fine-tuning data 以及 newly generated compounds 可通过文中给出的 sciebo 链接获取。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.12]
- **declared_resources：** 全文还声明计算基于 publicly available programs and compound data，且作者无 competing financial interest。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.12]
- **limitations：** 作者明确承认正确复现的内部原因仍然 non-transparent，后续需要解析模型学习特征并识别输入决定因素。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.11]
- **limitations：** 当前证据仍是 retrospective proof-of-concept，论文同时写明该方法还需要 prospective assessment 才能谈实际应用。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.11]
- **limitations：** 论文没有提供 wet-lab 验证或对未见 target 的系统外推实验，因此泛化能力仍属未知。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.11]；[doi:10.1186/s13321-024-00852-x, p.12]
- **method：** 模型把 ProtT5XLUniref50 产生的 protein embedding 与 potency embedding 拼接后输入 conditional transformer，再输出 SMILES 序列作为候选化合物。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.4]；[doi:10.1186/s13321-024-00852-x, p.5]
- **method：** 训练采用 Adam（lr=1e-5）、1024 维 hidden states、batch size 1 配合 gradient accumulation 到 effective batch 64，并执行 pre-training 加 fine-tuning。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.5]；[doi:10.1186/s13321-024-00852-x, p.6]
- **method：** 评估时每个 test instance 最多采样 100 个 valid compounds，并用 2048-bit Morgan fingerprints（radius 3）的 Tanimoto coefficient 做 1-NN 相似性分析。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.6]
- **results：** conditional model 在 10 个 activity classes 上分别复现了 10 到 115 个 test compounds，平均约 43 个/类；unconditional model 只复现 3 到 57 个，平均约 16 个/类。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.7]
- **results：** 在不做 fine-tuning 的对照中，针对 204、218、234 三个 class 的预测都没有复现任何 test compounds，说明 class-specific fine-tuning 很关键。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.7]
- **results：** 条件模型复现的 compounds 的 potency 分布通常更接近 test set，而无 potency 条件的 baseline 更倾向于复现较低 potency 的 compounds。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.8]
- **results：** 生成候选 compounds 的 1-NN 相似度范围很宽，约从 10% 到 100%；其 synthetic accessibility 分布又与 fine-tuning compounds 几乎不可区分。
  - 证据：[doi:10.1186/s13321-024-00852-x, p.9]

# Functional annotation of enzyme-encoding genes using deep learning with transformer layers

- **论文 ID：** `EVIW-CE317302C001A9DD`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2023 Nov 14
- **DOI：** [10.1038/s41467-023-43216-z](https://doi.org/10.1038/s41467-023-43216-z)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 DeepECtransformer：将 transformer/self-attention 与卷积层结合，从氨基酸序列预测 EC numbers，并用 attention 解释关键功能 motif，进一步用于 E. coli y-ome 注释与实验验证。

## 创新边界

`创新点在于 EC 号码预测与可解释性整合，不是蛋白/酶候选的生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

微生物基因组中大量 enzyme-encoding genes 仍缺少准确的 EC number 注释，限制了代谢功能理解、知识库完善和代谢工程分析。

## 方法

- 神经网络先预测四位EC号；若无预测则用Swiss-Prot同源酶补充；使用focal loss缓解类别不平衡，并解释模型归因。

## 数据与基准

- 训练含2200万条UniProtKB/TrEMBL酶序列，覆盖2802个四位EC号；应用于E. coli K-12的464个未注释基因。

## 比较基线

- DeepEC、DIAMOND同源搜索与CLEAN等EC预测器。

## 结果证据

- 作者报告相较DeepEC和DIAMOND改善四位EC预测，并对YgfF、YciO、YjdM三个预测做体外酶活验证。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 2802类分布高度不平衡，稀有EC仍困难；464个预测仅3个做实验验证，不能把其余预测写成已确认功能。

## 仍未知

- 补充材料与源码在本次冻结审阅中未实际运行验证。
- 模型在非酶序列上的误报规模没有在正文中完全量化。
- DeepECtransformer 对更长程序列依赖的覆盖能力仍不明确。

## Pi 结构化证据摘录

- **baseline：** 相较于 DIAMOND 和 DeepEC，DeepECtransformer 在宏平均与微平均指标上更强，尤其 recall 与 micro F1 的提升最明显。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.4]
- **baseline：** 作者也讨论了 CLEAN：其整体性能更高，但对 YgfF 和 YjdM 未能给出预测，且会对非酶序列也分配 EC numbers，因此需要更谨慎解读。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.7]
- **baseline：** 在 y-ome 注释任务上，DeepECtransformer 明显多于作者先前的 DeepEC（464 vs 82），说明新模型对低相似度蛋白更敏感。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.5]；[doi:10.1038/s41467-023-43216-z, p.6]
- **data：** 训练数据 uniprot dataset 来自 April 2018 的 UniProtKB/Swiss-Prot 与 TrEMBL，过滤掉非四位 EC、非标准氨基酸、长度超过 1000 aa、冗余序列以及每个 EC 少于 100 条序列的类别，最终得到 22,477,695 条 enzyme 序列，覆盖 2802 个 EC numbers。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.8]
- **data：** 用于 homology search 的 swissprot dataset 包含 226,325 条酶序列、5179 个 EC numbers；性能比较还使用了 NEW-392 和 Price-149 两个外部基准集。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.8]
- **data：** 下游分析包含 1122 个 E. coli strains 的 312,274 个 proteins 和 3967 个 genes，以及 E. coli K-12 MG1655 y-ome 中 1600 个 genes，其中 1569 个蛋白可从 UniProt 检索到。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.5]；[doi:10.1038/s41467-023-43216-z, p.9]
- **declared_resources：** 论文给出了源码仓库，地址为 GitHub 上的 DeepProZyme。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.10]
- **declared_resources：** Supplementary Data 1-7 通过 Zenodo 提供，source data 通过 figshare 提供；文中还使用了 PDB IDs 1IB6 和 1CIV 作为结构示例。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.10]
- **declared_resources：** 计算环境为 Python 3.6、Ubuntu 16.04 LTS 和 NVDIA Tesla V100，常用依赖包括 PyTorch 1.7.0、transformers 3.5.1 和 DIAMOND v2.0.11。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.8]；[doi:10.1038/s41467-023-43216-z, p.10]
- **limitations：** 模型性能受 class imbalance 影响明显，尤其 EC:1 的表现最低，而且 F1 与每个 EC 的序列数量呈正相关。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.2]
- **limitations：** 作者指出 EC classification 本身存在歧义：同一代谢反应可能对应多个 EC numbers，而 GO terms 对 EC 的覆盖也不完整。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.7]
- **limitations：** 文中多次强调预测结果仍需实验验证；in silico 解释只能提供线索，不能替代真实的功能鉴定。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.2]；[doi:10.1038/s41467-023-43216-z, p.7]
- **limitations：** 作者也提到前一层 self-attention 主要捕获近邻依赖，长程相互作用仍可能被低估。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.9]
- **method：** 核心模型采用改造后的 ProtBert/BERT 编码器，输入按单个氨基酸 token 化，经过两个 self-attention encoders、两个 convolutional layers、max-pooling、linear layer 和 sigmoid 层输出 EC numbers；训练使用 focal loss、Adam、30 epochs，并为每个 EC number 通过验证集搜索最优阈值。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.8]
- **method：** 当神经网络未给出预测时，系统再用 DIAMOND 在 Swiss-Prot 上做 homology search 来补足 EC numbers；对比实验还在 NEW-392 和 Price-149 数据集上与既有方法进行统一评估。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.2]；[doi:10.1038/s41467-023-43216-z, p.8]
- **method：** 作者通过 self-attention 分析识别 active site、cofactor binding site 和 Pfam 相关 motif，并用 MMseqs2 与 multiple sequence alignment 提取每个 EC number 的 16-residue common motifs 来解释模型关注区域。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.3]；[doi:10.1038/s41467-023-43216-z, p.4]；[doi:10.1038/s41467-023-43216-z, p.8]；[doi:10.1038/s41467-023-43216-z, p.9]
- **results：** 在 test dataset 上，DeepECtransformer 的 macro F1 为 0.8093、micro F1 为 0.9611，整体优于 DIAMOND 和 DeepEC；表中显示其召回率显著更高，只有 micro precision 略低于部分基线。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.4]
- **results：** 模型对 26,140 个 proteins 的 EC 预测与 Swiss-Prot 注释不同，并为 6454 个 proteins 补全了不完整的 EC numbers，显示其可用于发现潜在误注释或不完整注释。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.2]
- **results：** 在 E. coli y-ome 中，DeepECtransformer 为 464 个 proteins 预测出 EC numbers，其中 390 个带有完整四位 EC numbers；作者还对 YgfF、YciO、YjdM 的体外酶活进行了验证。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.5]；[doi:10.1038/s41467-023-43216-z, p.6]
- **results：** YgfF、YciO 和 YjdM 的实验结果分别支持其被预测为 glucose 1-dehydrogenase、L-threonylcarbamoyladenylate synthase 和 phosphonoacetate hydrolase，说明模型能把序列信号映射到具体酶功能。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.6]
- **results：** attention 分析表明模型聚焦于 active sites、ligand interaction sites 与功能域，并为 2547 个 EC numbers 提取了 common motifs，用于后续功能解释。
  - 证据：[doi:10.1038/s41467-023-43216-z, p.3]；[doi:10.1038/s41467-023-43216-z, p.4]；[doi:10.1038/s41467-023-43216-z, p.7]

## 作者主张的创新点

作者将 Morgan fingerprint 融入既有 FINDSITEcomb2.0、FRAGSITE、FRAGSITE2 及其 meta 组合，构建更新版 FINDSITEcomb2.0M、FRAGSITEM、FRAGSITE2M 与 FRAGSITEcombM，并在 DUD-E 与 DEKOIS2.0 上报告 EF1% 和 AUPR 的显著提升；消融结果表明 MF 是主要增益来源。

## 创新边界

`创新边界主要是 ligand fingerprint 表示与现有 VLS 流水线的增量增强；未见全新药物生成范式或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 structure-based virtual ligand screening 中，如何通过引入 Morgan fingerprint 提升已知候选分子的排序、早期富集与跨基准集泛化表现。

## 方法

- Morgan similarity、docking/structure scores与ranking。

## Pi 结构化证据摘录

- **baseline：** DenseFS 是用于对比的深度学习基线，在 DUD-E 上的 AUPR 为 0.443，低于 FRAGSITE 系列更新版本。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.1]；[doi:10.1021/acs.jpcb.4c01875, p.6]
- **baseline：** RF-score-VS 是 DEKOIS2.0 上的外部基线，其 EF1% 为 9.84，明显低于本工作的 FRAGSITE2M 和 FRAGSITEcombM。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.7]
- **baseline：** 原始 FINDSITEcomb2.0、FRAGSITE、FRAGSITE2 与 FRAGSITEcomb 作为内部基线，构成了 MF 增强前后的直接对照。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]；[doi:10.1021/acs.jpcb.4c01875, p.6]
- **data：** 主训练/测试基准是 DUD-E，共 102 个 targets，active/decoy ratio 约 0.016；训练时随机抽取约 10% decoys，形成约 160,000 个 protein-ligand pairs。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]
- **data：** 独立测试集是 DEKOIS2.0，共 81 个 structurally diverse targets，active/decoy ratio 约 0.033，并基于 BindDB bioactivity data。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]
- **data：** 模板 pocket 来自 PDB protein-ligand complex structures，并用 ChEMBL 与 DrugBank 扩充 template ligands。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.2]
- **declared_resources：** 计算与建模工具包括 RDKit、Open Babel、PaDEL-descriptor、XGBoost 和 Scikit-learn。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.3]
- **declared_resources：** 数据资源包括 DUD-E 与 DEKOIS2.0 两套虚拟筛选 benchmark。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]
- **declared_resources：** 模板与先验结构资源来自 PDB、ChEMBL 和 DrugBank。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.2]
- **limitations：** 研究仅在 DUD-E 与 DEKOIS2.0 两个 benchmark 上评估；作者明确未采用 MUV 和 LIT-PCBA，理由是 targets 数量太少。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]
- **limitations：** FRAGSITE2M 仍依赖 template pockets 与 similarity signal；在实验中，FINDSITEcomb2.0M 和 FRAGSITEM 仍优于结构-based 的 FRAGSITE2M。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.6]；[doi:10.1021/acs.jpcb.4c01875, p.7]
- **limitations：** 对于 similarity-based FINDSITEcomb2.0M，FP2、PubChem 与 MF 的组合并不优于单独 MF，说明部分 fingerprint 可能拖累加权相似度。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.4]；[doi:10.1021/acs.jpcb.4c01875, p.7]
- **method：** 将 target 的 template pockets 编码为 20 维 amino acid composition，并与 PubChem、FP2、Morgan fingerprint 拼接成输入特征。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.3]；[doi:10.1021/acs.jpcb.4c01875, p.4]
- **method：** 对高维特征改用 XGBoost/gradient boosting 回归，并设置 n_estimators、max_depth、learning_rate 等参数；FRAGSITE2M 仍保留 FINDSITEfilt 做 pocket 预测。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.3]；[doi:10.1021/acs.jpcb.4c01875, p.4]
- **method：** 训练与测试采用 DUD-E 的 modified LOOCV，并用 >80% sequence identity 过滤训练 target；结构建模仍使用 30% sequence cutoff 选模板。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.4]；[doi:10.1021/acs.jpcb.4c01875, p.5]
- **method：** FRAGSITEcombM 通过比较 FINDSITEcomb2.0M、FRAGSITEM 与 FRAGSITE2M 的 predicted precision，取最佳者作为 meta 排名结果。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]；[doi:10.1021/acs.jpcb.4c01875, p.4]
- **results：** 在 DUD-E 上，FRAGSITEcombM 达到 EF1% 47.6、AUPR 0.712，为全文最佳；相对原始 FRAGSITEcomb 的 41.7/0.606 有明显提升。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]；[doi:10.1021/acs.jpcb.4c01875, p.6]
- **results：** 在 DUD-E 上，FRAGSITE2M 由 FRAGSITE2 的 32.7/0.465 提升到 38.0/0.557，作者将主要增益归因于 Morgan fingerprint。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.1]；[doi:10.1021/acs.jpcb.4c01875, p.5]；[doi:10.1021/acs.jpcb.4c01875, p.6]
- **results：** 消融实验显示，去掉 MF 时性能降至 35.9/0.516，而仅用 MF 也有 35.4/0.514，说明 MF 比 FP2 或 PubChem 更关键。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.5]；[doi:10.1021/acs.jpcb.4c01875, p.6]；[doi:10.1021/acs.jpcb.4c01875, p.7]
- **results：** 在 DEKOIS2.0 上，FRAGSITEcombM 达到 EF1% 23.1、AUPR 0.683；FRAGSITE2M 为 18.5/0.551，仍优于 FRAGSITE2 的 15.9/0.437。
  - 证据：[doi:10.1021/acs.jpcb.4c01875, p.7]

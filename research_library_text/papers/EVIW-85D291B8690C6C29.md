## 作者主张的创新点

提出 molecular set representation learning 框架，包含 MSR1、MSR2、SR-GINE、SR-BIND 和 MSR2-RXN，并展示其可作为 GNN 的替代表示或增强模块。

## 创新边界

`主要创新在分子表示与预测架构层，不是分子生成、候选优化或实验筛选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在不依赖显式化学键拓扑的情况下，用集合/多重集表示分子、复合物和反应，并在多类化学与生物任务上保持或提升预测性能。

## 方法

- 对不同cardinality atom invariant集合应用RepSet，再用MLP预测；MSR2分别处理atom/bond set。

## 数据与基准

- 化学、生物和材料常用benchmark。

## 比较基线

- D-MPNN、GAT、DimeNet及传统fingerprint。

## 结果证据

- 简单set模型达到图模型水平，set layer加入GNN后可超过D-MPNN、GAT、DimeNet；旧benchmark可能不足以区分GNN优势。

## Pi 结构化证据摘录

- **baseline：** MoleculeNet 对照包括 MGCN、SchNet、GCN、GIN、D-MPNN、MolFormer 以及 GINE 控制组。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]
- **baseline：** OCELOT 对照包括 MPNN、MPNN+、ECFP2+ 与 finetuned MolFormer。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.4]
- **baseline：** Biogen ADME 对照包括 RF、LightGBM、D-MPNN、D-MPNN+、MolFormer 与 GINE。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.5]
- **baseline：** PDBbind 对照覆盖 GraphDTA 系列与 SGCN、GNN-DTI、MAT、DimeNet、CMPNN 等 GNN 方法。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]
- **baseline：** 反应收率对照包括 DFT、Yield-BERT、Yield-BERT(aug.)、DRFP 与 YieldGNN。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]
- **data：** 初始评测使用 MoleculeNet 的 11 个任务，采用 Murcko scaffold 划分，并以 BBBP 调参。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]；[doi:10.1038/s42256-024-00856-0, p.7]
- **data：** OCELOT 含 20,201 个训练样本的共轭分子数据，采用 5-fold 切分评估多性质回归。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.4]；[doi:10.1038/s42256-024-00856-0, p.7]
- **data：** Biogen ADME 数据集含 3,521 个商业化合物，覆盖 6 个 in vitro ADME 终点。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.5]；[doi:10.1038/s42256-024-00856-0, p.7]
- **data：** PDBbind 使用 refined/core 划分，核心集从 refined 集中剔除后作为测试集。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.5]；[doi:10.1038/s42256-024-00856-0, p.7]
- **data：** 反应收率部分使用 Buchwald–Hartwig 的 HTE 与 ELN 数据，并沿用既定分割。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]；[doi:10.1038/s42256-024-00856-0, p.7]
- **declared_resources：** 除 PDBbind 外，所有复现所需数据都放在 GitHub 仓库，PDBbind 需注册后下载。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.8]
- **declared_resources：** 代码与 pip package 以 MIT License 开放在同一 GitHub 仓库。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.8]
- **declared_resources：** 作者报告 GINE/SR-GINE 使用 Nvidia RTX 4090Ti 12GB；MolFormer 微调需要更高内存资源。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.8]
- **limitations：** 作者自己也指出，MoleculeNet 这类旧基准可能不适合评估 GNN 优势，而且 ToxCast、MUV、PCBA、QM9 因规模或任务数被排除。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]；[doi:10.1038/s42256-024-00856-0, p.7]
- **limitations：** MSR2 并未如预期普遍优于 MSR1，说明单纯加入 bond set 不一定带来收益。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]
- **limitations：** 在 OCELOT 上，纯 set 方法不如 MPNN+，表明额外分子描述符仍可能必要。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.4]
- **limitations：** SR-GINE 的训练开销在较大数据集上会上升，QM9 的训练时间增加 23.8%，MolFormer 微调也消耗更多硬件。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.8]
- **limitations：** 蛋白-配体任务不是基础模型的默认能力，作者明确说初始评测未包含 PDBbind，因为 base models 不支持复合物输入。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.7]
- **method：** MSR1 将每个非氢原子编码为一组 one-hot atom invariants，再交给 RepSet 与 MLP 读出。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.2]；[doi:10.1038/s42256-024-00856-0, p.7]
- **method：** MSR2 把 atom invariants 与 bond invariants 分成两套输入，分别经 RepSet 后拼接再预测。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]；[doi:10.1038/s42256-024-00856-0, p.7]
- **method：** SR-GINE 以 RepSet 替换 GINE 的 global mean pooling，从而把集合层嵌入现有 GNN。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]；[doi:10.1038/s42256-024-00856-0, p.7]
- **method：** SR-BIND 通过蛋白-配体原子近邻半径 r 组装双集合，再用双 RepSet 做亲和力预测。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.5]；[doi:10.1038/s42256-024-00856-0, p.6]
- **method：** MSR2-RXN 将反应物与产物分别做 ECFP 表示并送入双集合网络，用于收率预测。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]；[doi:10.1038/s42256-024-00856-0, p.7]
- **results：** 在 MoleculeNet 上，MSR1 对 D-MPNN 在 11 项中有 5 项更优，对 GIN 在 8 项中更优；SR-GINE 也在 8 项中优于 GINE。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.3]
- **results：** 在 OCELOT 上，MSR1 与 MPNN 总体相当，但 MSR1/MSR2 仍显著弱于带额外描述符的 MPNN+；SR-GINE 显著优于 GINE，且与 MPNN 总体不显著差异。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.4]
- **results：** 在 Biogen ADME 上，SR-GINE 明显优于 GINE，也优于 D-MPNN 与 D-MPNN+；MSR1/MSR2 与 GINE 差异不显著。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.5]
- **results：** 在 PDBbind 上，SR-BIND 在 RMSE、MAE 与 R 三项指标都优于所列 GraphDTA 与 GNN 基线。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]
- **results：** 在 Buchwald–Hartwig HTE 上，MSR2-RXN 接近 Yield-BERT、Yield-BERT(aug.) 与 DRFP，并优于 DFT；在 ELN 上，它仍低于实用阈值但优于 BERT/GNN 类基线。
  - 证据：[doi:10.1038/s42256-024-00856-0, p.6]

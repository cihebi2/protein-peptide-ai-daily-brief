# DDMut-PPI: predicting effects of mutations on protein-protein interactions using graph-based deep learning

- **论文 ID：** `EVIW-437CF46420154922`
- **期刊 / 来源：** Nucleic Acids Res
- **发表时间：** 2024 May 23
- **DOI：** [10.1093/nar/gkae412](https://doi.org/10.1093/nar/gkae412)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 DDMut-PPI：在既有 DDMut Siamese network 基础上加入面向 PPI interface graph 的 GCN、ProtT5 残基嵌入、Arpeggio 边特征与抗对称损失，用于预测单点和多点突变对 PPI 的影响，并提供 web server/API。

## 创新边界

`主要创新在界面图建模与抗对称训练方式，不是新湿实验或新结构测定；论文的验证仍建立在既有数据库与模式化结构生成之上。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在单点与多点突变场景下，如何快速且较准确地预测蛋白-蛋白相互作用（PPI）结合自由能变化（ΔΔG），并尽量兼顾不同界面类型、正负效应和泛化能力。

## 方法

- Siamese框架对野生型/突变型界面图编码，图节点含PLM嵌入、边含分子相互作用特征。[doi:10.1093/nar/gkae412, p.1]

## 数据与基准

- 以SKEMPI 2.0衍生S4169训练并加入反向突变形成S8338，盲测含AB-Bind S645和MDM2-p53测量。[doi:10.1093/nar/gkae412, p.2]

## 比较基线

- 与既有突变效应预测方法及不同特征/模型变体比较。[doi:10.1093/nar/gkae412, p.4][doi:10.1093/nar/gkae412, p.6]

## 结果证据

- 论文报告最高Pearson 0.75、RMSE 1.33 kcal/mol，并在若干盲测上有竞争力；为预测性能，不是新突变实验。[doi:10.1093/nar/gkae412, p.1]

## Pi 结构化证据摘录

- **baseline：** 作者将 DDMut-PPI 与 mCSM-PPI2、DGCddG 等方法在相近的 protein-level cross-validation 设置下比较，结论是整体表现具有竞争力。
  - 证据：[doi:10.1093/nar/gkae412, p.4]；[doi:10.1093/nar/gkae412, p.6]
- **baseline：** 在 S645、MDM2–p53、SPIKE–ACE2 以及 CAPRI round 26 盲测集上，论文与 iSEE、FoldX、BeAtMuSiC、mCSM-AB、BindProfX、SSIPe、deep geometric representations 等方法做了横向对比。
  - 证据：[doi:10.1093/nar/gkae412, p.6]；[doi:10.1093/nar/gkae412, p.7]
- **baseline：** 多突变评估中，DDMut-PPI 还与 mmCSM-PPI 和 FoldX 对比，强调其在加和式多突变预测上的竞争力。
  - 证据：[doi:10.1093/nar/gkae412, p.6]
- **data：** 单点突变训练集来自 SKEMPI 2.0 的 S4169：包含 3268 个降低亲和力和 901 个提高亲和力的突变，覆盖 319 个复合物和 138 类相互作用；加入 reverse mutation 后形成 S8338。
  - 证据：[doi:10.1093/nar/gkae412, p.2]
- **data：** 盲测集包括 S645（AB-Bind）、MDM2–p53 的 26 个界面突变、SPIKE–ACE2 的 418 个界面突变，以及 CAPRI round 26 的 T55 和 T56 深度突变扫描数据。
  - 证据：[doi:10.1093/nar/gkae412, p.2]；[doi:10.1093/nar/gkae412, p.5]
- **data：** 多突变数据集来自 SKEMPI 2.0 与 SKEMPI 1.0，包括 SM1124、SM595 和 SM_ZEMu，覆盖双/三突变到 4–27 突变不等的样本。
  - 证据：[doi:10.1093/nar/gkae412, p.2]
- **data：** wild-type 结构取自 Protein Data Bank，突变体结构则用 MODELLER 10.4 通过标准最小化流程生成。
  - 证据：[doi:10.1093/nar/gkae412, p.2]；[doi:10.1093/nar/gkae412, p.6]
- **declared_resources：** DDMut-PPI 以免费、无需登录的 web server 和 API 形式公开，地址为论文中给出的 biosig.lab.uq.edu.au/ddmut_ppi。
  - 证据：[doi:10.1093/nar/gkae412, p.4]；[doi:10.1093/nar/gkae412, p.6]
- **declared_resources：** 实现栈公开列出 TensorFlow 2.4.2、Flask 2.0.3、Python 3.6.13、Nginx、MaterializeCSS、NGL Viewer 和 python-igraph。
  - 证据：[doi:10.1093/nar/gkae412, p.4]
- **declared_resources：** 输出资源包括交互式 3D visualization、2D interaction graph、可下载表格以及接口扫描/饱和突变的热图或柱状图。
  - 证据：[doi:10.1093/nar/gkae412, p.4]
- **limitations：** 作者明确指出，SKEMPI 2.0 的相互作用类型多样性有限，导致模型对某些未见过的界面类型泛化受限。
  - 证据：[doi:10.1093/nar/gkae412, p.6]
- **limitations：** 多突变预测采用简单加和策略，突变数较多时性能下降，说明该假设难以完整捕捉突变之间的非线性交互。
  - 证据：[doi:10.1093/nar/gkae412, p.6]
- **limitations：** 突变体结构由 MODELLER 生成，作者也承认这可能引入结构误差，并且未显式建模邻近残基的构象重排。
  - 证据：[doi:10.1093/nar/gkae412, p.6]
- **method：** 单点突变部分先以 S4169 为基础，并通过虚拟 reverse mutation 扩展为 S8338，再用 leave-one-complex-out 和 leave-one-binding-site-out 两种交叉验证策略训练与调参。
  - 证据：[doi:10.1093/nar/gkae412, p.2]；[doi:10.1093/nar/gkae412, p.4]
- **method：** 特征工程同时覆盖序列与结构：包括 AAindex、BLOSUM、PAM、PSSM，以及 solvent accessibility、residue depth、secondary structure、FoldX 能量项、Arpeggio 原子相互作用和 mCSM graph signatures。
  - 证据：[doi:10.1093/nar/gkae412, p.2]；[doi:10.1093/nar/gkae412, p.3]
- **method：** PPI interface 被构造成图：距离对侧链原子 5.0 Å 内的残基作为节点，节点使用 ProtT5 1024 维嵌入，边由 Arpeggio 生成并编码 10 类相互作用。
  - 证据：[doi:10.1093/nar/gkae412, p.2]；[doi:10.1093/nar/gkae412, p.3]
- **method：** 模型架构是在 DDMut 的 Siamese network 中加入 GCN、convolutional layer、transformer encoder 和 dense layers，并用带 forward/reverse 约束的 modified contrastive loss 强化 anti-symmetry。
  - 证据：[doi:10.1093/nar/gkae412, p.3]
- **method：** 评估使用 R2、Pearson、Spearman、Kendall、RMSE、MAE 和 MSE 等指标，以同时衡量线性相关性、秩相关和误差大小。
  - 证据：[doi:10.1093/nar/gkae412, p.3]
- **results：** 在单点突变训练集上，CV1 达到 Pearson 0.75、RMSE 1.33 kcal/mol；CV2 达到 Pearson 0.67、RMSE 1.51 kcal/mol。
  - 证据：[doi:10.1093/nar/gkae412, p.5]
- **results：** 在 S645 与 MDM2–p53 等盲测集中，模型保持竞争力；例如 S645 的 Pearson 为 0.60、RMSE 为 1.60 kcal/mol，MDM2–p53 的 Pearson 为 0.37。
  - 证据：[doi:10.1093/nar/gkae412, p.5]
- **results：** 多突变场景下，SM1124 的 Pearson 为 0.83、RMSE 为 1.51 kcal/mol；SM595 的 Pearson 为 0.71、RMSE 为 2.56 kcal/mol；SM_ZEMu 的 Pearson 为 0.72、RMSE 为 2.04 kcal/mol。
  - 证据：[doi:10.1093/nar/gkae412, p.6]
- **results：** 消融和特征打乱实验表明各模块都贡献了性能，其中 FoldX ΔΔG 和 Δauthority score 对结果影响尤其明显。
  - 证据：[doi:10.1093/nar/gkae412, p.6]

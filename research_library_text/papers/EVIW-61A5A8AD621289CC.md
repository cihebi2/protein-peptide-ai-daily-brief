# PepLM-GNN: A graph neural network framework leveraging pre-trained language models for peptide-protein binding prediction

- **论文 ID：** `EVIW-61A5A8AD621289CC`
- **期刊 / 来源：** PLoS Comput Biol
- **发表时间：** 2026 Mar 24
- **DOI：** [10.1371/journal.pcbi.1014084](https://doi.org/10.1371/journal.pcbi.1014084)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `语言模型` / `图与几何学习` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称 PepLM-GNN 将 ProtT5、GCN、GIN 与可解释子图分析结合起来，在 PepPI 二分类、冷启动场景和虚拟肽药筛选中优于基线，并提供在线服务。[doi:10.1371/journal.pcbi.1014084, p.1][doi:10.1371/journal.pcbi.1014084, p.2][doi:10.1371/journal.pcbi.1014084, p.3][doi:10.1371/journal.pcbi.1014084, p.10][doi:10.1371/journal.pcbi.1014084, p.11]

## 创新边界

`边界在于这是预测、表征与可解释分析框架，不是直接生成、优化或对接新的肽候选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

论文聚焦于在冷启动条件下准确预测 peptide-protein binding，并缓解非欧几里得交互表示困难与泛化不足的问题。[doi:10.1371/journal.pcbi.1014084, p.1][doi:10.1371/journal.pcbi.1014084, p.2][doi:10.1371/journal.pcbi.1014084, p.3]

## 方法

- 分别编码peptide/protein，构图/交互attention，分类结合。

## 数据与基准

- PepPI benchmark、independent/cold-start splits。

## 比较基线

- 传统ML/深度PepPI模型及冷启动方法。

## 结果证据

- 论文报告显著超过baselines；为计算结合分类。

## Pi 结构化证据摘录

- **baseline：** 外部比较基线包括 LR、RF、SVM、CAMP、DrugBAN、IIDL-PepPI、HIGH-PPI、DeepRank-GNN-esm 和 DeepGNHV。[doi:10.1371/journal.pcbi.1014084, p.4][doi:10.1371/journal.pcbi.1014084, p.6]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.4]；[doi:10.1371/journal.pcbi.1014084, p.6]
- **baseline：** 预训练编码器对照包括 ProtBert、TAPE、ESM-2 和 ESM-3，用于检验不同 sequence embedding 的影响。[doi:10.1371/journal.pcbi.1014084, p.8]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.8]
- **baseline：** 内部消融 A-D 分别对应 ProtT5-only、+GAT、+GCN、+GIN，再与完整 hybrid model 对比。[doi:10.1371/journal.pcbi.1014084, p.9]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.9]
- **baseline：** 作者说明在 independent test 上已将各基线超参数调到最优，以尽量保证公平比较。[doi:10.1371/journal.pcbi.1014084, p.5]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.5]
- **data：** benchmark dataset 来自 2022 年 10 月前的 RCSB PDB peptide-protein complexes，按 Cα 距离 <5 Å 或最近原子距离定义相互作用，并过滤掉未知或非标准氨基酸占比超过 20% 的样本，最终得到 8622 个正样本及同数负样本。[doi:10.1371/journal.pcbi.1014084, p.5][doi:10.1371/journal.pcbi.1014084, p.12]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.5]；[doi:10.1371/journal.pcbi.1014084, p.12]
- **data：** 四个 independent test sets 分别是 Test1440、LEADS-PEP、Test251 和 Test167；文中给出了各自的正负样本规模与来源时间段。[doi:10.1371/journal.pcbi.1014084, p.6][doi:10.1371/journal.pcbi.1014084, p.12]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.6]；[doi:10.1371/journal.pcbi.1014084, p.12]
- **data：** cold-start test dataset 通过 CD-HIT 对 peptide 和 protein 分别聚类，并在 0.6、0.7、0.8、0.9 四个阈值下确保训练集与测试集不共享同簇实体，从而构造 novel peptide、novel protein 和 novel pair 子集。[doi:10.1371/journal.pcbi.1014084, p.7][doi:10.1371/journal.pcbi.1014084, p.12]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.7]；[doi:10.1371/journal.pcbi.1014084, p.12]
- **data：** 可解释性案例使用了 SALL4(1–12) 的 alanine-scanning 以及 FFW peptide 的子图与富集分析来验证模型输出的生物学含义。[doi:10.1371/journal.pcbi.1014084, p.10]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.10]
- **declared_resources：** 论文声明数据和在线服务可通过 http://bliulab.net/PepLM-GNN 访问。[doi:10.1371/journal.pcbi.1014084, p.1]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.1]
- **declared_resources：** 论文声明 PepLM-GNN 的源码和相关数据已公开在 GitHub：https://github.com/cokeyk/PepLM-GNN。[doi:10.1371/journal.pcbi.1014084, p.1]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.1]
- **limitations：** 作者明确指出数据集构建仍可能存在偏倚，因为 benchmark 不能完全覆盖不同物种和功能类型的 protein-peptide pairs，这会影响稀有或专门样本的预测表现。[doi:10.1371/journal.pcbi.1014084, p.11]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.11]
- **limitations：** 作者还指出，基于序列特征构图会带来一定计算开销，在低配置环境中部署会比较困难。[doi:10.1371/journal.pcbi.1014084, p.11]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.11]
- **method：** PepLM-GNN 先用 ProtT5 为肽和蛋白序列提取残基级表示，再经平均池化得到 1024 维定长向量，并做 Z-score 标准化后作为节点特征。[doi:10.1371/journal.pcbi.1014084, p.13][doi:10.1371/journal.pcbi.1014084, p.14]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.13]；[doi:10.1371/journal.pcbi.1014084, p.14]
- **method：** 模型把 peptide 和 protein 组成全局 PepPI 图，节点对应序列实体，边用双向 edge index [[0,1],[1,0]] 显式表示交互关系。[doi:10.1371/journal.pcbi.1014084, p.13][doi:10.1371/journal.pcbi.1014084, p.14]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.13]；[doi:10.1371/journal.pcbi.1014084, p.14]
- **method：** 局部模块用两层 GCNConv 配合 InstanceNorm、ReLU 和 dropout 聚合一阶邻域信息，以刻画 PepPI 的非欧几里得局部结构。[doi:10.1371/journal.pcbi.1014084, p.14]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.14]
- **method：** 全局模块用两层 GINConv，并在后续使用 Global Add Pooling 压缩为 32 维图表示，用于捕获全局拓扑并缓解过平滑。[doi:10.1371/journal.pcbi.1014084, p.14][doi:10.1371/journal.pcbi.1014084, p.15]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.14]；[doi:10.1371/journal.pcbi.1014084, p.15]
- **method：** 分类头对 32 维图表示做 dropout、线性映射和 sigmoid；训练采用 Adam、学习率 1e-3、weight decay 5e-4、early stopping patience 10、BCEWithLogitsLoss，并固定随机种子 1234。[doi:10.1371/journal.pcbi.1014084, p.15][doi:10.1371/journal.pcbi.1014084, p.16]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.15]；[doi:10.1371/journal.pcbi.1014084, p.16]
- **method：** 评估时采用动态阈值优化，并选取使 F1 最大的阈值作为决策边界。[doi:10.1371/journal.pcbi.1014084, p.15]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.15]
- **results：** 在 benchmark 上，PepLM-GNN 的 ACC 为 0.7636、F1 为 0.7880、AUC 为 0.8434、AUPR 为 0.8165，整体优于传统机器学习与深度学习基线。[doi:10.1371/journal.pcbi.1014084, p.4][doi:10.1371/journal.pcbi.1014084, p.8]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.4]；[doi:10.1371/journal.pcbi.1014084, p.8]
- **results：** 作者在 benchmark 与合并独立测试集上对 ACC 做 t-test，报告与各基线相比的 p 值均小于 0.05，用来支持统计显著性。[doi:10.1371/journal.pcbi.1014084, p.4][doi:10.1371/journal.pcbi.1014084, p.5][doi:10.1371/journal.pcbi.1014084, p.7]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.4]；[doi:10.1371/journal.pcbi.1014084, p.5]；[doi:10.1371/journal.pcbi.1014084, p.7]
- **results：** 在四个 independent test sets 和 cold-start splits 上，PepLM-GNN 都保持领先；文中还指出当序列相似度下降时，性能下降相对较小。[doi:10.1371/journal.pcbi.1014084, p.5][doi:10.1371/journal.pcbi.1014084, p.6][doi:10.1371/journal.pcbi.1014084, p.7]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.5]；[doi:10.1371/journal.pcbi.1014084, p.6]；[doi:10.1371/journal.pcbi.1014084, p.7]
- **results：** 与 ProtBert、TAPE、ESM-2、ESM-3 相比，采用 ProtT5 的完整模型最好，ACC 从 0.6620–0.7013 提升到 0.7636。[doi:10.1371/journal.pcbi.1014084, p.8]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.8]
- **results：** Ablation 显示完整模型优于仅 ProtT5、加 GAT、加 GCN 或加 GIN 的变体，且删除任一核心模块都会显著降低 ACC。[doi:10.1371/journal.pcbi.1014084, p.9]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.9]
- **results：** SALL4 alanine-scan、FFW 子图与富集结果和已知 SALL4-RBBp4 生物学关系一致，文中给出的富集 p 值为 3.63 × 10^-2。[doi:10.1371/journal.pcbi.1014084, p.10]
  - 证据：[doi:10.1371/journal.pcbi.1014084, p.10]

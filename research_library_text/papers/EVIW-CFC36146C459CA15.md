## 作者主张的创新点

作者声称提出 LANTERN：一个把蛋白与分子 large language model 预训练表示结合起来的两阶段深度学习框架，并用 Multi-Head Cross-Attention 做 TCR-peptide 跨模态融合，以提升 binding prediction 的零样本和 few-shot 泛化。[doi:10.7717/peerj.20980, p.1] [doi:10.7717/peerj.20980, p.3]

## 创新边界

`新意主要落在 ESM + MolFormer + MHCA 的组合式框架与 SMILES 化 peptide 表示；它是一个转移学习式的相互作用预测模型，不是候选生成、优化或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

预测 T-cell receptor (TCR) 与 peptide/pMHC 的结合关系，重点解决标注稀缺、未见 epitope 和随机负采样条件下的泛化困难。[doi:10.7717/peerj.20980, p.1]

## 方法

- 双sequence encoders、MHCA alignment与分类。

## 数据与基准

- TCHard、random control、unseen epitope。

## Pi 结构化证据摘录

- **baseline：** 比较基线包括 Smiles-Bert、TEINet、ChemBERTa、TITAN、ERGO II、NetTCR、DlpTcr 和 Imrex。
  - 证据：[doi:10.7717/peerj.20980, p.11]；[doi:10.7717/peerj.20980, p.13]；[doi:10.7717/peerj.20980, p.14]
- **baseline：** 结果并非全表最优：例如 TEINet 在 Gen NA 与 Original NA 的 AUC-ROC 高于 LANTERN，说明该方法的优势更集中在某些难例与随机控制设定。
  - 证据：[doi:10.7717/peerj.20980, p.13]；[doi:10.7717/peerj.20980, p.14]
- **baseline：** 作者把 LLM-based models 与 end-to-end deep learning models 对照，总结前者平均 AUC-ROC 为 0.8165、后者为 0.5846，认为预训练表示在零样本和随机控制上更稳健。
  - 证据：[doi:10.7717/peerj.20980, p.12]；[doi:10.7717/peerj.20980, p.13]；[doi:10.7717/peerj.20980, p.14]
- **data：** 主要数据来自 TCHard，输入只使用 TCR β-chain CDR3 与 antigen peptide，刻意不纳入 TCR α-chain、MHC alleles 和 V/J genes。
  - 证据：[doi:10.7717/peerj.20980, p.10]；[doi:10.7717/peerj.20980, p.19]
- **data：** 全文报告数据规模约为 160,000 个 unique TCR β chains 和 1,341 个 unique peptides；不同负采样设置会产生不同大小的 pair 集。
  - 证据：[doi:10.7717/peerj.20980, p.11]；[doi:10.7717/peerj.20980, p.7]
- **data：** 作者在 Data Availability 中声明数据还提供于 supplemental file 和 figshare 数据集。
  - 证据：[doi:10.7717/peerj.20980, p.23]
- **declared_resources：** 作者声明代码可在 anonymous.4open.science/r/LANTERN-87D9/README.md 获取。
  - 证据：[doi:10.7717/peerj.20980, p.23]
- **declared_resources：** 作者声明数据见 supplemental file 与 figshare 数据集 10.6084/m9.figshare.30389626.v1。
  - 证据：[doi:10.7717/peerj.20980, p.23]
- **limitations：** 模型只看 TCR β-chain CDR3 和 peptide，忽略 TCR α-chain、MHC alleles 与 V/J genes，作者明确承认这会限制生物学完整性。
  - 证据：[doi:10.7717/peerj.20980, p.19]；[doi:10.7717/peerj.20980, p.20]
- **limitations：** 论文明确写明这是 purely computational study，没有实验或结构验证，因此机制解释仍主要停留在推断层面。
  - 证据：[doi:10.7717/peerj.20980, p.19]；[doi:10.7717/peerj.20980, p.20]
- **limitations：** hard negatives 在 random control 下仍是主要瓶颈，作者建议未来采用更生物学化或结构感知的负采样策略。
  - 证据：[doi:10.7717/peerj.20980, p.14]；[doi:10.7717/peerj.20980, p.19]；[doi:10.7717/peerj.20980, p.20]
- **method：** LANTERN 采用双编码器：TCR β-chain CDR3 由 ESM 编码，peptide 先转成 SMILES 再由 MolFormer 编码，以同时保留进化/结构与化学信息。
  - 证据：[doi:10.7717/peerj.20980, p.1]；[doi:10.7717/peerj.20980, p.3]；[doi:10.7717/peerj.20980, p.6]；[doi:10.7717/peerj.20980, p.8]
- **method：** 模型用 Multi-Head Cross-Attention 让 TCR 作为 query、peptide 作为 key/value 做跨模态对齐，再把 Eprotein 与 Ealign 拼接后进入 MLP 输出二分类概率。
  - 证据：[doi:10.7717/peerj.20980, p.8]；[doi:10.7717/peerj.20980, p.9]
- **method：** 训练目标是 Binary Cross-Entropy 加 alignment regularization；文中说明 MHCA 和预测头通过反向传播联合优化，ESM/MolFormer 可按实验设置冻结或微调。
  - 证据：[doi:10.7717/peerj.20980, p.9]；[doi:10.7717/peerj.20980, p.10]；[doi:10.7717/peerj.20980, p.11]
- **method：** 评估采用 5-fold cross-validation，并用 peptide-level grouped split 构造验证集，避免同一 peptide 在 train 与 val 间泄漏；test peptides 也与 train/val 严格分离。
  - 证据：[doi:10.7717/peerj.20980, p.10]；[doi:10.7717/peerj.20980, p.22]；[doi:10.7717/peerj.20980, p.23]
- **method：** 负样本构造同时使用 reference control 与 random control，并进一步生成 Gen NA/Gen RN 以比较不同负采样难度下的鲁棒性。
  - 证据：[doi:10.7717/peerj.20980, p.6]；[doi:10.7717/peerj.20980, p.7]；[doi:10.7717/peerj.20980, p.10]；[doi:10.7717/peerj.20980, p.11]
- **results：** 在 Gen NA、Gen RN、Original NA、Original RN 四个设置中，LANTERN 的 AUC-ROC 分别为 0.883、0.663、0.903 和 0.571。
  - 证据：[doi:10.7717/peerj.20980, p.13]；[doi:10.7717/peerj.20980, p.14]
- **results：** Ablation 显示去掉 SMILES 后 AUC-ROC 降到 0.865/0.628/0.894/0.541，随机化 SMILES 后进一步降到 0.791/0.542/0.775/0.463，说明收益主要来自化学结构信息。
  - 证据：[doi:10.7717/peerj.20980, p.17]
- **results：** 预训练 embedding 的聚类指标也更好：CTS、HS、SI、CHI 都优于无预训练版本，作者据此认为表示空间更可分。
  - 证据：[doi:10.7717/peerj.20980, p.16]；[doi:10.7717/peerj.20980, p.17]
- **results：** 作者还总结 few-shot 场景下性能会随着见到的 peptide/pair 数增加而提升，但在 random control 下仍然明显更难。
  - 证据：[doi:10.7717/peerj.20980, p.18]；[doi:10.7717/peerj.20980, p.19]

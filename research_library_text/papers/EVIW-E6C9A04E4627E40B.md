# Multi-modal features-based human-herpesvirus protein-protein interaction prediction by using LightGBM

## 作者主张的创新点

作者声称提出了一个将 Doc2vec、Node2vec/GO2vec 与 LightGBM 结合的多模态 human-herpesvirus PPI 预测框架，并通过非严格、严格及跨亚型基准显示其优于多种传统编码、深度学习和迁移学习方法，同时还能迁移到 CMV 场景。

## 创新边界

`创新边界主要在多模态嵌入融合与评测设计，不是新湿实验，也不是候选分子生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知 human-herpesvirus PPI 数据稀缺、且训练/测试划分容易产生偏倚的情况下，如何把序列、网络和功能信息联合起来，建立一个在严格条件下仍能较好泛化的 PPI 预测模型。

## 方法

- 蛋白序列嵌入、PPI网络图嵌入和GO/功能文本嵌入拼接，LightGBM学习交互概率；留出巨细胞病毒做迁移。

## 数据与基准

- 作者汇编的人-疱疹病毒PPI正负集，含rigorous与non-rigorous benchmark及HCMV留出。

## 比较基线

- DPC/CT/AC等序列编码ML、DeepViral和单模态/双模态消融。

## 结果证据

- 论文报告融合模型超过传统编码和DeepViral等，并可预测HCMV交互；均为计算分类。

## 已知限制

- 网络/GO模态对已知蛋白注释依赖强，可能产生信息泄漏；病毒留出不等同真正新物种泛化，未做实验验证。

- GitHub 仓库是否与论文结果完全一致，冻结文本未核验。
- 负样本中是否混入未发现的真实互作，无法从文本完全排除。
- 作者自建的非严格/严格划分是否仍残留隐性泄漏，无法独立确认。
- 新湿实验未做，生物学结论仍需后续实验复核。

## Pi 结构化证据摘录

- **baseline：** 相较 Doc2vec+RF，作者方法在严格集上把 AUROC/AUPRC 从 0.924/0.497 提升到 0.975/0.810。
  - 证据：[doi:10.1093/bib/bbae005, p.5]
- **baseline：** 作者还将其与 DPC+RF、CT+RF、AC+RF、SVM 和 MLP 比较，整体 AUROC/AUPRC 更高。
  - 证据：[doi:10.1093/bib/bbae005, p.4]；[doi:10.1093/bib/bbae005, p.5]
- **baseline：** 作者也报告优于 TransPPI 与 DeepViral，显示跨数据集对比优势。
  - 证据：[doi:10.1093/bib/bbae005, p.7]
- **data：** 正样本覆盖 HHV-1 至 HHV-6 与 HHV-8，作者明确排除 HHV-7。
  - 证据：[doi:10.1093/bib/bbae005, p.2]
- **data：** 用于网络特征的图数据包含 329,611 条人类 PPI（26,691 个蛋白）和 2104 条疱疹病毒 PPI（706 个蛋白）。
  - 证据：[doi:10.1093/bib/bbae005, p.3]
- **data：** 比较与外部测试数据包括 9301 条 2022 年前实验确定 PPI、138 条 2022 年新验证互作，以及 TransPPI 和 DeepViral 对应基准。
  - 证据：[doi:10.1093/bib/bbae005, p.6]；[doi:10.1093/bib/bbae005, p.7]
- **declared_resources：** 代码仓库公开在 GitHub: https://github.com/XiaodiYangpku/MultimodalPPI/。
  - 证据：[doi:10.1093/bib/bbae005, p.11]
- **declared_resources：** 数据与特征构建依赖 UniProt、IntAct、BioGRID、HPIDB、VirHostNet、VirusMentha、GO 与 KEGG 等公开资源。
  - 证据：[doi:10.1093/bib/bbae005, p.2]；[doi:10.1093/bib/bbae005, p.3]；[doi:10.1093/bib/bbae005, p.4]
- **limitations：** 作者明确承认，对未见蛋白的泛化仍不足，遇到训练中未出现的蛋白时性能会明显下滑。
  - 证据：[doi:10.1093/bib/bbae005, p.11]
- **limitations：** 负样本选择仍然是核心难点，可能同时影响精度和泛化能力。
  - 证据：[doi:10.1093/bib/bbae005, p.2]；[doi:10.1093/bib/bbae005, p.11]
- **limitations：** 论文的生物学可信度主要来自文献回溯、网络拓扑和富集分析，并没有新的湿实验验证。
  - 证据：[doi:10.1093/bib/bbae005, p.10]；[doi:10.1093/bib/bbae005, p.11]
- **method：** 作者先从 IntAct、BioGRID、HPIDB、VirHostNet 和 VirusMentha 收集 human-herpesvirus PPI，并过滤非物理、冗余、超长/过短及非标准氨基酸样本，得到 9439 个正样本，同时构造严格与非严格两类划分。
  - 证据：[doi:10.1093/bib/bbae005, p.2]
- **method：** 序列表征采用 Doc2vec：将蛋白序列切成 k-mer，用 Gensim 训练 DM 模型；作者把 k=1 作为最佳切分，并通过窗口、向量维度和 epoch 搜索优化参数。
  - 证据：[doi:10.1093/bib/bbae005, p.3]；[doi:10.1093/bib/bbae005, p.5]
- **method：** 网络与功能表征分别基于人类/疱疹病毒 PPI 网络和 GO-蛋白综合网络训练 Node2vec，形成 Net2vec 与 GO2vec，再与序列特征拼接后输入 LightGBM 二分类器。
  - 证据：[doi:10.1093/bib/bbae005, p.3]；[doi:10.1093/bib/bbae005, p.4]
- **method：** 评估采用 5-fold cross-validation，主要看 AUROC/AUPRC，并补充 Precision、Recall、Accuracy、F1 与 GO/KEGG 富集分析。
  - 证据：[doi:10.1093/bib/bbae005, p.4]
- **results：** Doc2vec 的 1-mers 明显优于 k>1；最佳 Doc2vec+LightGBM 在非严格/严格集上的 AUROC/AUPRC 分别为 0.968/0.774 与 0.975/0.810。
  - 证据：[doi:10.1093/bib/bbae005, p.5]
- **results：** 多模态融合 LightGBM 在两类基准上都优于单模态，AUPRC 比次优单模态 Doc2vec 高 3.5 和 2.2 个百分点。
  - 证据：[doi:10.1093/bib/bbae005, p.5]
- **results：** 在 2022 独立测试集上，作者方法达到 AUROC 0.919、AUPRC 0.408、Recall 0.688、Accuracy 0.881，优于 LSTM-PHV。
  - 证据：[doi:10.1093/bib/bbae005, p.6]
- **results：** 在 DeepViral 的跨亚型测试中，作者方法 AUROC/AUPRC 为 0.986/0.896，显著高于 DeepViral 的 0.922/0.513。
  - 证据：[doi:10.1093/bib/bbae005, p.7]
- **results：** 作者最终为 9 个 herpesvirus 亚型给出 560、387、346、662、545、415、356、353 和 625 对候选互作，并覆盖 762 个 human proteins 与 470 个 herpesviral proteins。
  - 证据：[doi:10.1093/bib/bbae005, p.8]
- **results：** 文献回溯支持了 6 个预测互作，其中 4 个在 1% false positive control rate 下仍被命中。
  - 证据：[doi:10.1093/bib/bbae005, p.10]

# Protein Set Transformer: A protein-based genome language model to power high diversity viromics

## 作者主张的创新点

作者提出 Protein Set Transformer (PST) / viral PST (vPST)，把每个病毒基因组表示为蛋白集合，通过上下文化蛋白表征和基因组级表征，形成可用于多种 viromics 下游任务的 foundation model。

## 创新边界

`创新边界在于病毒基因组级的 protein-set contextualization 与自监督表示学习，不是直接生成或优化新的病毒/蛋白候选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

病毒基因组与蛋白序列高度多样，单纯依赖序列同源的注释、比较和下游推断方法在远缘病毒上容易失效，因此需要一种能利用蛋白集合与基因组组织信息的可泛化表示学习框架来支持高多样性 viromics。

## 方法

- protein LM embeddings输入set transformer，无需基因顺序/功能标签，训练病毒genome-level objectives。

## 数据与基准

- >10万训练病毒/600万蛋白，>15万测试病毒/700万蛋白。

## 比较基线

- 序列同源、蛋白LM聚合和病毒分类方法。

## 结果证据

- 论文报告超过homology/LM genome关系方法并聚类capsid/late proteins；为计算viromics。

## Pi 结构化证据摘录

- **baseline：** 基因组级对照基线包括 4-mer kmer、GenSLM ORF/genome embeddings、HyenaDNA，以及基于 AAI 的 genus/family clustering。
  - 证据：[doi:10.1101/2024.07.26.605391, p.9]；[doi:10.1101/2024.07.26.605391, p.10]；[doi:10.1101/2024.07.26.605391, p.29]；[doi:10.1101/2024.07.26.605391, p.31]；[doi:10.1101/2024.07.26.605391, p.32]
- **baseline：** 蛋白级对照主要是 raw ESM2 protein embeddings、GenSLM ORF embeddings，以及基于 VOG/PHROG 的注释分组。
  - 证据：[doi:10.1101/2024.07.26.605391, p.11]；[doi:10.1101/2024.07.26.605391, p.13]；[doi:10.1101/2024.07.26.605391, p.32]；[doi:10.1101/2024.07.26.605391, p.35]
- **baseline：** host prediction 的比较基线是 CHERRY 和 iPHoP，作者还用同一框架替换为 ESM2、vPST 或 kmer embedding 进行对照。
  - 证据：[doi:10.1101/2024.07.26.605391, p.18]；[doi:10.1101/2024.07.26.605391, p.19]；[doi:10.1101/2024.07.26.605391, p.37]；[doi:10.1101/2024.07.26.605391, p.39]；[doi:10.1101/2024.07.26.605391, p.41]
- **data：** 训练集来自 12 个公开来源的 103,589 个病毒基因组，经过 CheckV 质控、skani/MCL 去冗余，并共预测出 6,391,562 个蛋白。
  - 证据：[doi:10.1101/2024.07.26.605391, p.8]；[doi:10.1101/2024.07.26.605391, p.23]
- **data：** 测试集来自 IMG/VR v4 的 151,255 个病毒基因组，与训练集按 nucleotide-level ANI 去重后保留独立样本，共预测出 7,182,220 个蛋白。
  - 证据：[doi:10.1101/2024.07.26.605391, p.8]；[doi:10.1101/2024.07.26.605391, p.23]
- **data：** host prediction proof-of-concept 使用 iPHoP 的训练/测试设置：训练集 3,628 个病毒，测试集 1,636 个病毒，并构建了 805 个 host genomes、594 个 host species。
  - 证据：[doi:10.1101/2024.07.26.605391, p.37]；[doi:10.1101/2024.07.26.605391, p.38]
- **data：** 功能注释与结构分析主要依赖 VOG r219、PHROG v4 以及 Protein Data Bank 的结构检索。
  - 证据：[doi:10.1101/2024.07.26.605391, p.32]；[doi:10.1101/2024.07.26.605391, p.36]
- **declared_resources：** Supplementary data（protein FASTA、protein/genome embeddings、训练好的 vPST weights、virus-host interaction graphs）已存放于 Dryad，DOI 为 10.5061/dryad.d7wm37q8w。
  - 证据：[doi:10.1101/2024.07.26.605391, p.22]
- **declared_resources：** 作者给出的代码仓库地址是 https://github.com/AnantharamanLab/protein_set_transformer，并说明相关 notebook 与辅助 embedding 生成仓库会在 biosecurity review 后发布。
  - 证据：[doi:10.1101/2024.07.26.605391, p.22]
- **declared_resources：** 模型训练与推理依赖 University of Wisconsin-Madison Center for High Throughput Computing 的算力支持。
  - 证据：[doi:10.1101/2024.07.26.605391, p.22]
- **limitations：** 作者明确指出 vPST 并未针对 host prediction 训练，因此更高阶 host 分类上的表现会下降；他们也承认进一步 fine-tuning 可能带来更好效果。
  - 证据：[doi:10.1101/2024.07.26.605391, p.19]；[doi:10.1101/2024.07.26.605391, p.20]
- **limitations：** 蛋白功能结果受到现有注释覆盖率限制，许多测试蛋白仍是 hypothetical proteins，且 VOG/PHROG 的标签体系本身并不完备。
  - 证据：[doi:10.1101/2024.07.26.605391, p.14]；[doi:10.1101/2024.07.26.605391, p.32]；[doi:10.1101/2024.07.26.605391, p.35]
- **limitations：** 代码和模型权重在文中仍受 biosecurity review 约束而未公开，作者也专门讨论了这类 viral foundation model 的潜在 biosecurity 风险。
  - 证据：[doi:10.1101/2024.07.26.605391, p.21]；[doi:10.1101/2024.07.26.605391, p.22]
- **method：** PST 先用冻结的 ESM2 生成每个蛋白的 embedding，再拼接基因组内相对位置与编码链信息，经过多头注意力 encoder 上下文化蛋白，最后用 attention pooling decoder 汇聚成 genome embedding。
  - 证据：[doi:10.1101/2024.07.26.605391, p.7]；[doi:10.1101/2024.07.26.605391, p.24]；[doi:10.1101/2024.07.26.605391, p.26]
- **method：** vPST 的预训练使用 self-supervised triplet loss；正样本通过输入 ESM2 空间的 Chamfer distance 选取，负样本在 PST embedding space 中做半硬采样，并用 PointSwap 交换相近蛋白向量做增强。
  - 证据：[doi:10.1101/2024.07.26.605391, p.6]；[doi:10.1101/2024.07.26.605391, p.7]；[doi:10.1101/2024.07.26.605391, p.8]；[doi:10.1101/2024.07.26.605391, p.26]；[doi:10.1101/2024.07.26.605391, p.27]；[doi:10.1101/2024.07.26.605391, p.28]
- **method：** 超参数搜索采用修改版 Leave-One-Group-Out cross validation，以 viral realm 为 group，并固定把 Duplodnaviria 纳入每个训练折，以避免模型只偏向最常见类群。
  - 证据：[doi:10.1101/2024.07.26.605391, p.8]；[doi:10.1101/2024.07.26.605391, p.28]；[doi:10.1101/2024.07.26.605391, p.29]
- **method：** 下游评估包括 similarity-weighted kNN + Leiden 的 genome/protein clustering、AAI 质量评估，以及基于 GNN 的 host prediction proof-of-concept。
  - 证据：[doi:10.1101/2024.07.26.605391, p.10]；[doi:10.1101/2024.07.26.605391, p.30]；[doi:10.1101/2024.07.26.605391, p.31]；[doi:10.1101/2024.07.26.605391, p.37]；[doi:10.1101/2024.07.26.605391, p.39]；[doi:10.1101/2024.07.26.605391, p.41]
- **results：** 与 kmer、GenSLM、HyenaDNA、ESM2 ctx-avg 等比较时，vPST 的 genome embedding 更能把不同 viral realm 分开，并在 AAI 聚类质量上整体更优；pst-small 的簇内 AAI 最高，而 pst-large 在覆盖更多基因组时更稳健。
  - 证据：[doi:10.1101/2024.07.26.605391, p.9]；[doi:10.1101/2024.07.26.605391, p.10]
- **results：** vPST protein embeddings 能把 structural proteins、replication proteins 和 late genes 等功能模块更一致地聚到一起，而 ESM2/GenSLM 的功能簇解释性较弱。
  - 证据：[doi:10.1101/2024.07.26.605391, p.11]；[doi:10.1101/2024.07.26.605391, p.13]；[doi:10.1101/2024.07.26.605391, p.14]
- **results：** 对于 hypothetical proteins，vPST 更常把未注释蛋白与已注释 capsid proteins 聚类，并且更多未注释蛋白能通过 foldseek/PDB 找到 capsid-fold 同源；annotation transfer 也更敏感。
  - 证据：[doi:10.1101/2024.07.26.605391, p.15]；[doi:10.1101/2024.07.26.605391, p.16]；[doi:10.1101/2024.07.26.605391, p.17]
- **results：** 在 host prediction proof-of-concept 中，使用 vPST genome embeddings 的 GNN 在 species-level 上优于 CHERRY、iPHoP、ESM2 与 kmer 的比较组合，但在更高 host taxon 上 kmer 往往更强。
  - 证据：[doi:10.1101/2024.07.26.605391, p.18]；[doi:10.1101/2024.07.26.605391, p.19]；[doi:10.1101/2024.07.26.605391, p.41]；[doi:10.1101/2024.07.26.605391, p.62]；[doi:10.1101/2024.07.26.605391, p.63]

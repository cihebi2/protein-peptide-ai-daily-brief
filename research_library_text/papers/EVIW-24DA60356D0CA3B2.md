# Accurate de novo design of high-affinity protein-binding macrocycles using deep learning

- **论文 ID：** `EVIW-24DA60356D0CA3B2`
- **期刊 / 来源：** Nat Chem Biol
- **发表时间：** 2025 Jun 20
- **DOI：** [10.1038/s41589-025-01929-w](https://doi.org/10.1038/s41589-025-01929-w)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 RFpeptides：把 cyclic relative positional encoding 引入 RF2 与 RFdiffusion，再结合 ProteinMPNN、Rosetta 和 AfCycDesign，实现对 MCL1、MDM2、GABARAP 以及预测结构 RbtA 的 de novo 宏环肽 binder 设计，并以 SPR、AlphaScreen 与 X-ray 证明其有效。

## 创新边界

`本稿可确认的新意主要是将 cyclic 编码扩展到蛋白结合宏环肽的生成式设计管线；但仅凭冻结证据，无法独立验证其相对全部外部先前工作的全球新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在不依赖已知结合伙伴起始 motif、且尽量少量实验筛选的前提下，从头设计对蛋白靶标具有高亲和力、并能被结构实验验证的宏环肽结合体。

## 方法

- 去噪扩散生成环肽骨架，再进行序列设计、结构预测筛选和结合实验/晶体结构验证。[doi:10.1038/s41589-025-01929-w, p.1][doi:10.1038/s41589-025-01929-w, p.2]

## 数据与基准

- 覆盖多个蛋白靶标；晶体结构与设计模型C-alpha RMSD小于1.5 Å，设计模型和序列随补充材料提供。[doi:10.1038/s41589-025-01929-w, p.1][doi:10.1038/s41589-025-01929-w, p.13]

## 比较基线

- 正文把传统展示筛选、自然产物发现和AfCycDesign类方案作为比较背景，后者计算昂贵且未完成同类实验验证。[doi:10.1038/s41589-025-01929-w, p.1][doi:10.1038/s41589-025-01929-w, p.2]

## 结果证据

- 论文报告获得多个高亲和力结合宏环并以X射线结构支持设计构象；这是论文实验结果，不应外推到任意靶标。[doi:10.1038/s41589-025-01929-w, p.1]

## Pi 结构化证据摘录

- **baseline：** 相较传统大规模随机库筛选，作者强调其方法不需要 trillions 级别的实验筛库，也能定制到特定表位或表面 patch。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.1]；[doi:10.1038/s41589-025-01929-w, p.8]
- **baseline：** 相较以已知 ligand 或 binding partner 为起点的结构引导设计，RFpeptides 不依赖预先存在的结合 motif。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.2]；[doi:10.1038/s41589-025-01929-w, p.8]
- **baseline：** 作者也把本工作放在其先前的 AF2/AfCycDesign 宏环肽结构预测工作之后，表示这次是将 cyclic 编码进一步扩展到 binder 生成。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.2]；[doi:10.1038/s41589-025-01929-w, p.8]
- **data：** 研究覆盖四个设计战役：MCL1、MDM2、GABARAP，以及没有实验结构的 RbtA；后者先用 AF2 和 RF2 预测目标结构，再进入设计流程。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.5]；[doi:10.1038/s41589-025-01929-w, p.6]；[doi:10.1038/s41589-025-01929-w, p.7]
- **data：** MCL1 和 MDM2 各生成约 10,000 个宏环肽骨架，每个骨架设计 4 条序列；GABARAP 与 RbtA 也各生成 20,000 个骨架并做同样的序列设计。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.5]；[doi:10.1038/s41589-025-01929-w, p.6]；[doi:10.1038/s41589-025-01929-w, p.7]
- **data：** 最终进入实验的候选集分别为 14 个 MCL1、8 个 MDM2、6 个 GABARAP 和 11 个 RbtA peptide；部分设计因环化产率不足而无法继续表征。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.5]；[doi:10.1038/s41589-025-01929-w, p.6]；[doi:10.1038/s41589-025-01929-w, p.7]
- **data：** 数据可得性声明给出 5 个 PDB 条目 9CDT、9HGC、9HGD、9CDU 和 9CDV，并说明 Source Data 随文提供。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.13]
- **declared_resources：** 论文公开了设计模型与序列、5 个 PDB 结构条目以及随文提供的 Source Data。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.13]
- **declared_resources：** 代码与脚本可从 Zenodo 和 RFdiffusion GitHub repository 获取。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.13]
- **declared_resources：** 结构生物学实验使用了 ESRF BM07 与 NSLS-II AMX/FMX 等束线资源。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.12]；[doi:10.1038/s41589-025-01929-w, p.13]
- **limitations：** 作者明确指出，in silico 指标能富集 binder，但不同靶标上这些指标的分布差异很大，且对实验亲和力的排序并不完美。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.8]
- **limitations：** 若干候选在化学环化步骤中产率过低，导致 MCL1 与 MDM2 的部分设计无法进一步做实验表征。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.5]
- **limitations：** 研究未预先用统计方法确定样本量，实验也未随机化、未盲法，这限制了统计推断强度。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.12]
- **limitations：** GAB_D8 没有获得足够高质量的同靶晶体，作者改用 GABARAPL1 作为同源替代进行结构验证。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.6]
- **method：** 作者先在 RF2 中实现 cyclic relative position encoding，再把同一编码移植到 RFdiffusion，用于生成闭环宏环肽骨架。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.2]；[doi:10.1038/s41589-025-01929-w, p.10]
- **method：** 生成骨架后，他们用 ProteinMPNN 设计序列，并结合 Rosetta Relax、AfCycDesign，部分靶标还加上 RF2 复预测，再按 iPAE、ddG、SAP、CMS 等指标筛选。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.2]；[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.5]；[doi:10.1038/s41589-025-01929-w, p.7]
- **method：** 实验验证包括 Fmoc-based solid-phase synthesis、SPR 单循环动力学、AlphaScreen 竞争实验，以及蛋白-肽复合物的 X-ray crystallography。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.10]；[doi:10.1038/s41589-025-01929-w, p.12]
- **method：** 针对不同靶标，作者还使用 hotspot 约束、结构聚类和分层下选，以提高位点定向性与结构多样性。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.6]；[doi:10.1038/s41589-025-01929-w, p.7]
- **results：** MCL1 上最佳设计 MCB_D2 的 SPR Kd 为 2.0 µM，且其 X-ray 结构与设计模型高度一致，macrocycle Cα RMSD 为 0.7 Å。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.3]；[doi:10.1038/s41589-025-01929-w, p.4]
- **results：** MDM2 上最佳设计 MDB_D8 的 SPR Kd 为 1.9 µM，设计模型与 MDM2 的已知结合界面相符。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.4]；[doi:10.1038/s41589-025-01929-w, p.5]
- **results：** GABARAP 上的 GAB_D8 和 GAB_D23 分别达到 6 nM 与 36 nM 的 Kd，并在 AlphaScreen 中给出约 0.7 nM 与 2.5 nM 的 IC50。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.5]；[doi:10.1038/s41589-025-01929-w, p.6]
- **results：** RbtA 上的 RBB_D10 达到 9.4 nM 的 Kd；其 apo RbtA 结构也与 AF2/RF2 预测一致，复合物 X-ray 与设计模型的 macrocycle RMSD 为 1.4 Å，单独对齐时为 0.4 Å。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.7]；[doi:10.1038/s41589-025-01929-w, p.8]
- **results：** 作者据此主张，RFpeptides 能在不同口袋形状和表面类型上给出高亲和力、且结构接近原子级匹配的 macrocycle binder。
  - 证据：[doi:10.1038/s41589-025-01929-w, p.1]；[doi:10.1038/s41589-025-01929-w, p.8]

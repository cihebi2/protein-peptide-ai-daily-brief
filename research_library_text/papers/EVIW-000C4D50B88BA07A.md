# Atomic context-conditioned protein sequence design using LigandMPNN

- **论文 ID：** `EVIW-000C4D50B88BA07A`
- **期刊 / 来源：** Nat Methods
- **发表时间：** 2025 Mar 28
- **DOI：** [10.1038/s41592-025-02626-1](https://doi.org/10.1038/s41592-025-02626-1)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 LigandMPNN，将 ProteinMPNN 扩展为显式建模 atomic context 的深度学习序列设计器，并进一步加入 sidechain packing 预测与实验重设计示例，声称能显著优于 Rosetta 与 ProteinMPNN。

## 创新边界

`核心边界是把 inverse folding 从 protein-only 扩展到 atomic-context-conditioned design。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 protein sequence design 中，把 small molecules、nucleotides 和 metals 等非蛋白原子纳入上下文，以便更准确地为酶、结合蛋白和传感器设计氨基酸序列与侧链构象。

## 方法

- 以蛋白主链图和邻近非蛋白原子图联合编码，每个残基接收局部配体/核酸/金属环境后自回归生成序列与侧链。

## 数据与基准

- 测试集含317个小分子复合物、74个核酸复合物和83个过渡金属结构，并在相同PDB biounit训练数据上重训ProteinMPNN公平比较。

## 比较基线

- Rosetta、相同数据重训的ProteinMPNN及相关逆折叠模型。

## 结果证据

- 论文报告相互作用残基序列恢复率：小分子63.3%（Rosetta 50.4%、ProteinMPNN 50.5%）、核酸50.5%（35.2%、34.0%）、金属77.5%（36.0%、40.6%）；仍主要是回顾性结构指标。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 序列恢复不等同于催化或结合功能；依赖固定主链和给定原子上下文，对柔性/溶剂和质子化建模有限。

## 仍未知

## Pi 结构化证据摘录

- **baseline：** 序列设计对比基线主要是 Rosetta 与重新训练但不提供 context atoms 的 ProteinMPNN。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.3]
- **baseline：** sidechain packing 还加入了 LigandMPNN-wo 作为消融基线，用来分离 ligand context 的贡献。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.4]
- **baseline：** 实验重设计部分以原始 Rosetta 设计作为起点，再与 LigandMPNN redesign 对照评估结合恢复效果。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.5]
- **data：** 训练数据来自截至 2022-12-16 的 PDB biological assemblies，限定为 X-ray crystallography 或 cryo-EM、分辨率优于 3.5 Å、总长度小于 6000 residues，并按 30% sequence identity 聚类划分。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.8]
- **data：** 测试集包含 317 个 small-molecule、74 个 nucleotide 和 83 个 metal 复合物；sequence recovery 统计的是距离任一 context atom 5.0 Å 内的残基。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.3]；[doi:10.1038/s41592-025-02626-1, p.4]
- **data：** 方法部分还明确列出若干分析用 PDB IDs，包括 8VEI、8BEJ、8VEZ、8VFQ、8TAC、6JY3、2P7G、1BC8 和 1E4M。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.10]
- **declared_resources：** 代码在论文中声明可通过 GitHub 的 LigandMPNN 仓库获取，运行环境列为 PyTorch 1.11.0、CUDA 11.1、NumPy 1.21.5、Matplotlib v3.5.1 和 Python 3.9.12。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.10]
- **declared_resources：** 训练使用单张 NVIDIA A100 GPU，batch size 为 6,000 tokens，优化 300,000 steps；mmseqs2、mmcif 和 rdkit 分别用于聚类与 PDB 解析。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.8]；[doi:10.1038/s41592-025-02626-1, p.10]
- **declared_resources：** 论文还披露了 source data，并列出若干分析用 PDB IDs 供复现参考。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.10]
- **limitations：** 作者明确提醒，对 PDB 中稀有或几乎不存在的元素要谨慎使用，必要时需映射到最接近的元素。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.6]
- **limitations：** 模型对 chi3 与 chi4 的恢复仍然较弱，说明远端 sidechain torsion 的可预测性有限。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.4]
- **limitations：** 加入 sidechain context 并未显著提升 sequence recovery，提示很多位点的关键信息仍主要来自 protein context。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.3]；[doi:10.1038/s41592-025-02626-1, p.4]
- **method：** 模型把 protein backbone、ligand graph 和 protein–ligand graph 结合起来，通过消息传递把非蛋白原子的局部化学环境注入序列解码。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.1]；[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.8]
- **method：** 训练与推理都采用 autoregressive decoding；同时作者在输入坐标上加入 0.1 Å Gaussian noise，以降低对晶体结构细节的记忆。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.8]；[doi:10.1038/s41592-025-02626-1, p.9]
- **method：** 除序列设计外，论文还训练了 sidechain packing model，按 chi1→chi4 顺序预测四个 torsion angles 的 mixture distribution。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.2]；[doi:10.1038/s41592-025-02626-1, p.10]
- **results：** 在 native sequence recovery 上，LigandMPNN 在 small-molecule、nucleotide 和 metal 三类上下文中都优于 Rosetta 与 ProteinMPNN。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.1]；[doi:10.1038/s41592-025-02626-1, p.3]
- **results：** sidechain packing 的 chi1 恢复率也高于 Rosetta，并在 small-molecule、nucleotide 和 metal 数据集上分别达到 86.1%、71.4% 和 79.3%。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.4]
- **results：** 论文展示了对 rocuronium 和 cholic acid 的重设计可恢复或增强结合，并在 discussion 中总结已有超过 100 个经实验验证的设计案例以及 5 个接近计算模型的 co-crystal structures。
  - 证据：[doi:10.1038/s41592-025-02626-1, p.5]；[doi:10.1038/s41592-025-02626-1, p.6]

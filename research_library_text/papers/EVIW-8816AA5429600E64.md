# A Suite of Designed Protein Cages Using Machine Learning Algorithms and Protein Fragment-Based Protocols

- **论文 ID：** `EVIW-8816AA5429600E64`
- **期刊 / 来源：** bioRxiv
- **发表时间：** 2023 Oct 9
- **DOI：** [10.1101/2023.10.09.561468](https://doi.org/10.1101/2023.10.09.561468)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出了一套将 Nanohedra fragment docking、FragmentHBNet、AlphaFold 预处理与 ProteinMPNN 结合的设计流程，成功构建并结构验证了一组新的 two-component tetrahedral protein cages，并据此说明 fragment/sequence agreement 与实验成功相关。

## 创新边界

`新意主要在 workflow integration、筛选启发式和实验验证；不是在单独首次发明 Nanohedra、AlphaFold 或 ProteinMPNN。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在可预测性仍然有限的前提下，如何设计并实验验证新的 two-component tetrahedral protein cages，并判断 fragment-based docking 与机器学习序列设计是否能提升自组装成功率。

## 方法

- fragment assembly、ML scoring/design、表达/structural characterization。

## 数据与基准

- cage designs与实验。

## 比较基线

## Pi 结构化证据摘录

- **baseline：** 与 King 2014、Bale 2016 和 Cannon 2020 的 prior two-component SCM 设计相比，作者的新设计在若干界面指标上总体达到相当甚至更 favorable 的水平。
  - 证据：[doi:10.1101/2023.10.09.561468, p.7]；[doi:10.1101/2023.10.09.561468, p.12]
- **baseline：** 论文把自身工作定位为在既有 knowledge-based cage design 基础上加入 AlphaFold 与 ProteinMPNN 的机器学习流程改进，而不是重建整个 symmetry-based design framework。
  - 证据：[doi:10.1101/2023.10.09.561468, p.2]；[doi:10.1101/2023.10.09.561468, p.8]；[doi:10.1101/2023.10.09.561468, p.14]
- **baseline：** 作者也明确承认，knowledge-based 与 machine-learning protocol 的优劣比较受到多项 heuristic 选择影响，因此不能把成功率差异简单归因于单一算法。
  - 证据：[doi:10.1101/2023.10.09.561468, p.14]；[doi:10.1101/2023.10.09.561468, p.15]
- **data：** Round 1 的输入来自 2020 年 7 月从 PDB 过滤得到的 84 个 C3 trimeric building blocks；Round 2 的输入来自 2023 年 3 月整理出的 334 个 AlphaFold-curated trimers。
  - 证据：[doi:10.1101/2023.10.09.561468, p.23]；[doi:10.1101/2023.10.09.561468, p.24]
- **data：** 作者实际合成并测试了 41 个 T33-fn constructs 和 38 个 T33-ml gene constructs，其中 T33-ml 有 1 个构建在 gene synthesis 阶段失败。
  - 证据：[doi:10.1101/2023.10.09.561468, p.5]；[doi:10.1101/2023.10.09.561468, p.10]
- **data：** 结构数据包括 1 个 X-ray crystal structure、4 个完整 cage 的 cryo-EM 结构，以及 2 个 partial assembly 的 cryo-EM 重构，表 1 与表 2 给出了对应的 resolution、RMSD 和 LDDT。
  - 证据：[doi:10.1101/2023.10.09.561468, p.6]；[doi:10.1101/2023.10.09.561468, p.11]；[doi:10.1101/2023.10.09.561468, p.22]；[doi:10.1101/2023.10.09.561468, p.36]；[doi:10.1101/2023.10.09.561468, p.37]
- **declared_resources：** 经费来源包括 NIH R01GM129854、T32GM008496、DOE DE-FC02-02ER63421，以及与 cryo-EM/数据收集相关的 NIH Common Fund U24 GM129541 与 U24GM129547。
  - 证据：[doi:10.1101/2023.10.09.561468, p.15]
- **declared_resources：** 实验与数据采集资源包括 UCLA structural facilities、S2C2、PNCC、SSRL、Titan Krios、cryoSPARC、Phenix、Coot 和 ChimeraX 等平台与软件。
  - 证据：[doi:10.1101/2023.10.09.561468, p.15]；[doi:10.1101/2023.10.09.561468, p.36]；[doi:10.1101/2023.10.09.561468, p.37]
- **declared_resources：** 作者在论文中声明所有 code 都公开在 GitHub 的 https://github.com/kylemeador/symdesign，并提供了 Google Colab 入口 https://bit.ly/symdesign-colab。
  - 证据：[doi:10.1101/2023.10.09.561468, p.16]
- **limitations：** T33-fn 的总体成功率偏低，作者回顾性分析认为这些设计往往过于 polar，可能缺少维持接口组装所需的关键 hydrophobicity。
  - 证据：[doi:10.1101/2023.10.09.561468, p.5]；[doi:10.1101/2023.10.09.561468, p.7]
- **limitations：** 作者指出，计算得到的 interface energy 常为正值，而这类指标并未充分捕捉 protein concentration 对多组分组装平衡的影响。
  - 证据：[doi:10.1101/2023.10.09.561468, p.11]
- **limitations：** 对 partial assemblies 的成因，作者没有给出单一机制，只能提出几种可能：轻微几何偏差、kinetic traps，或不同组分在组装过程中的 depletion。
  - 证据：[doi:10.1101/2023.10.09.561468, p.14]；[doi:10.1101/2023.10.09.561468, p.15]
- **limitations：** 作者也承认，用当前数据比较 knowledge-based 与 machine-learning 方案时，多个筛选与启发式步骤混杂在一起，限制了因果解释。
  - 证据：[doi:10.1101/2023.10.09.561468, p.14]；[doi:10.1101/2023.10.09.561468, p.15]
- **method：** 作者先将目标定义为 T:{C3}{C3} tetrahedral cage，并用 Nanohedra 对 84 个 C3 trimer building blocks 做全对全 docking，按 fragment overlap、BSA、能量和形状指标筛到 590 个候选 pose。
  - 证据：[doi:10.1101/2023.10.09.561468, p.3]；[doi:10.1101/2023.10.09.561468, p.23]；[doi:10.1101/2023.10.09.561468, p.25]
- **method：** T33-fn 采用 fragment profile、evolutionary profile 与 tertiary profile 约束设计，并以 FragmentHBNet 结合 HBNet、FastDesign、reversion 和 iAlign 聚类进行筛选，最终得到 41 个待测设计。
  - 证据：[doi:10.1101/2023.10.09.561468, p.4]；[doi:10.1101/2023.10.09.561468, p.5]；[doi:10.1101/2023.10.09.561468, p.31]；[doi:10.1101/2023.10.09.561468, p.32]；[doi:10.1101/2023.10.09.561468, p.33]
- **method：** T33-ml 引入 AlphaFold-curated 的 334 个 trimers，使用改进的 Nanohedra 搜索与 ProteinMPNN 生成约 3.7 million sequences，再按 CE、profile loss、shape complementarity 和 folding prediction 过滤到 39 个设计。
  - 证据：[doi:10.1101/2023.10.09.561468, p.8]；[doi:10.1101/2023.10.09.561468, p.9]；[doi:10.1101/2023.10.09.561468, p.31]；[doi:10.1101/2023.10.09.561468, p.33]；[doi:10.1101/2023.10.09.561468, p.34]
- **method：** 实验验证采用 bicistronic E. coli 表达、单侧 His-tag、IMAC、SEC、SEC-SAXS、X-ray crystallography 和 cryo-EM，并用 Rosetta、Phenix、Coot 等进行结构精修。
  - 证据：[doi:10.1101/2023.10.09.561468, p.5]；[doi:10.1101/2023.10.09.561468, p.10]；[doi:10.1101/2023.10.09.561468, p.34]；[doi:10.1101/2023.10.09.561468, p.35]；[doi:10.1101/2023.10.09.561468, p.36]；[doi:10.1101/2023.10.09.561468, p.37]
- **results：** T33-fn10 的 SEC-SAXS Rg 为 5.55 nm，与设计值 5.53 nm 非常接近；晶体结构在 6 Å 分辨率下解出，整体 assembly RMSD 为 0.75 Å、LDDT 为 0.99。
  - 证据：[doi:10.1101/2023.10.09.561468, p.5]；[doi:10.1101/2023.10.09.561468, p.6]；[doi:10.1101/2023.10.09.561468, p.22]
- **results：** T33-ml 最终获得 6/38 的实验成功率（约 16%）；其中 4 个设计给出清晰的 cryo-EM 重构，T33-ml23 达到最好分辨率 2.0 Å。
  - 证据：[doi:10.1101/2023.10.09.561468, p.10]；[doi:10.1101/2023.10.09.561468, p.11]；[doi:10.1101/2023.10.09.561468, p.22]
- **results：** 在可溶设计中，fragment profile loss 是最强的 outcome predictor（r²=-0.59），而 ProteinMPNN score 本身并不是强预测因子。
  - 证据：[doi:10.1101/2023.10.09.561468, p.12]
- **results：** 更高的 polar BSA、更多 loop/coil interface 以及更大的 Cβ 距离与 polar interactions 相关；T33-ml23 与 T33-ml28 在结构上相近但序列差异明显，体现出 sequence/structure degeneracy。
  - 证据：[doi:10.1101/2023.10.09.561468, p.13]
- **results：** 作者还从 cryo-EM 数据中观察到约 20% 的 particles 对应 partial assemblies（A12B9 与 A9B12），提示 cage 组装可能经过可分辨的中间态。
  - 证据：[doi:10.1101/2023.10.09.561468, p.13]；[doi:10.1101/2023.10.09.561468, p.14]；[doi:10.1101/2023.10.09.561468, p.22]

# Accurate Identification of Protein Binding Sites for All Drug Modalities Using ALLSites

- **论文 ID：** `EVIW-77CFA975A5E481C9`
- **期刊 / 来源：** Adv Sci (Weinh)
- **发表时间：** 2025 Dec 27
- **DOI：** [10.1002/advs.202516530](https://doi.org/10.1002/advs.202516530)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `数据集/基准`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 ALLSites：一种基于 ESM-2、GatedCNN 与 cross-attention decoder 的序列驱动框架，可统一预测多种药物模态的蛋白结合位点，并在多套基准上取得 SOTA 或接近 SOTA 表现。

## 创新边界

`创新主要在多模态结合位点的序列级统一预测与模型组合；不涉及新候选分子的生成、优化、对接或湿实验发现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在缺乏高质量结构和统一工具的情况下，如何仅凭蛋白序列准确识别覆盖蛋白、肽、小分子、糖类、DNA 和 RNA 的结合位点。

## 方法

- ESM-2残基表示经gated conv和self-attention，多任务/多数据集训练。

## 数据与基准

- PPI/PepPI/DPI等多modal benchmark。

## 比较基线

- 13种PPI/PepPI/小分子结构/序列模型。

## 结果证据

- 论文报告序列方法SOTA并接近最佳结构工具；为计算位点。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 训练modal标签异质；结构工具受预测结构误差，ALLSites也不提供实验结合。

## 仍未知

- 是否存在可复用的单一跨模态 checkpoint 仍不清楚。
- 对真正前瞻样本和全新 proteome 的泛化能力仍未知。
- SMPI 评测中不同训练数据来源的可比性仍未完全澄清。

## Pi 结构化证据摘录

- **baseline：** PPI 任务的对照方法覆盖结构与序列两类，包括 IntPred、SPPIDER、DeepPPISP、EGRET、ISIS、RF_PPI、PSIVER、SPRINGS、ProNA2020、SCRIBER、DELPHI、DLPred、EnsemPPIS，以及后续评估中的 GraphPPIS、RGN 和 MaSIF-site。
  - 证据：[doi:10.1002/advs.202516530, p.3]；[doi:10.1002/advs.202516530, p.5]
- **baseline：** PepPI 任务比较了 SPRINT-seq、Visual、PepBind、PepNN-Seq、PepBCL、PepSite、PeptiMap、SPRINT-Str 和 PepNN-Struct。
  - 证据：[doi:10.1002/advs.202516530, p.6]
- **baseline：** SMPI 与 CarbPI 任务的主要 baselines 包括 P2Rank、FTMap、CAPSIF: V 和 CAPSIF: G。
  - 证据：[doi:10.1002/advs.202516530, p.6]；[doi:10.1002/advs.202516530, p.7]
- **baseline：** DPI 与 RPI 任务的 baselines 包括 SVMnuc、NCBRPred、DNAPred、COACH-D、NucBind、DNABind、GraphBind、RNABindRPlus、aaRNA 和 NucleicNet。
  - 证据：[doi:10.1002/advs.202516530, p.7]；[doi:10.1002/advs.202516530, p.8]
- **data：** PPI 与 PepPI 基准来自 DeepPPISP、DELPHI、GraphPPIS 等既有研究，训练/测试集之间通常将序列同一性控制在 25% 到 30% 以下。
  - 证据：[doi:10.1002/advs.202516530, p.9]；[doi:10.1002/advs.202516530, p.10]
- **data：** SMPI 基准从 sc-PDB 构建，先得到 17,594 个复合物、4,993 条 UniProt 序列，再经 30% 去冗余得到 2,324 个蛋白，并划分为 1,628/348/348。
  - 证据：[doi:10.1002/advs.202516530, p.6]；[doi:10.1002/advs.202516530, p.9]
- **data：** CarbPI 基准来自 CAPSIF 研究，包含 517/129/162 的训练、验证与测试划分，结构分辨率低于 3.0 Å，且序列同一性低于 30%。
  - 证据：[doi:10.1002/advs.202516530, p.6]；[doi:10.1002/advs.202516530, p.9]
- **data：** DPI 与 RPI 基准来自 BioLip、GraphBind 和后续研究，包括 DPI-Train573/Test129、DPI-Test181 以及 RPI-Train495/Test117，且训练与测试间序列同一性均低于 30%。
  - 证据：[doi:10.1002/advs.202516530, p.7]；[doi:10.1002/advs.202516530, p.10]
- **declared_resources：** 作者在数据可用性声明中给出 GitHub 仓库，且补充材料提供了 benchmark evaluation 的 source data。
  - 证据：[doi:10.1002/advs.202516530, p.12]
- **declared_resources：** 实现环境为 Python 3.10、PyTorch 1.12.0、CentOS Linux 7.9，硬件为 Intel Xeon Gold 6132、NVIDIA Tesla V100 32GB 和 263GB RAM。
  - 证据：[doi:10.1002/advs.202516530, p.12]
- **declared_resources：** 资金来源包括浙江省和国家级基金，作者同时声明无 conflicts of interest。
  - 证据：[doi:10.1002/advs.202516530, p.12]
- **limitations：** 该方法在 DNA/RNA 任务上仍略逊于 GraphBind，说明在高质量结构可用时，结构方法依然可能占优。
  - 证据：[doi:10.1002/advs.202516530, p.7]；[doi:10.1002/advs.202516530, p.8]；[doi:10.1002/advs.202516530, p.9]
- **limitations：** SMPI 评测中 P2Rank 直接加载预训练参数推断，作者也承认训练数据可能不完全一致，因此横向比较存在公平性限制。
  - 证据：[doi:10.1002/advs.202516530, p.6]
- **limitations：** 论文为不同模态或任务分别训练模型，并未展示单一 checkpoint 覆盖全部模态，因此统一框架在部署层面仍是任务级方案。
  - 证据：[doi:10.1002/advs.202516530, p.11]
- **limitations：** 各 benchmark 存在明显 class imbalance，作者依赖 weighted cross-entropy 才稳定训练，说明正负样本失衡仍是核心难点。
  - 证据：[doi:10.1002/advs.202516530, p.10]；[doi:10.1002/advs.202516530, p.11]
- **method：** ALLSites 使用 ESM-2 为每个残基生成 2560 维序列嵌入，作为统一输入表示。
  - 证据：[doi:10.1002/advs.202516530, p.10]
- **method：** 编码器由多层 1D convolution、GLU、残差连接和 layer normalization 组成，用于提取局部与全局上下文。
  - 证据：[doi:10.1002/advs.202516530, p.3]；[doi:10.1002/advs.202516530, p.10]；[doi:10.1002/advs.202516530, p.11]
- **method：** 解码器采用 multi-head cross-attention 将局部表示与全局蛋白特征耦合，并通过 significance-weighted aggregation 与全连接分类器输出残基级 binding probability。
  - 证据：[doi:10.1002/advs.202516530, p.3]；[doi:10.1002/advs.202516530, p.11]
- **method：** 训练时使用 weighted cross-entropy、RAdam+Lookahead、dropout、weight decay 和 early stopping，并按模态或任务分别训练模型。
  - 证据：[doi:10.1002/advs.202516530, p.11]；[doi:10.1002/advs.202516530, p.12]
- **results：** 在 PPI-Test70 与 PPI-Test355 上，ALLSites 在 AUROC、AUPRC、F1 和 MCC 上均最好；在 PPI-Test60 与 PPI-Test315 上，它与最强结构方法 RGN 和 MaSIF-site 相当或更好，且 Brier score 低于 0.25。
  - 证据：[doi:10.1002/advs.202516530, p.4]；[doi:10.1002/advs.202516530, p.5]
- **results：** 在 PepPI-Test125 上，ALLSites 在 AUROC 与 MCC 上都优于序列和结构 baselines；在 PepPI-Test639 上整体排名第二，显示出较强稳健性。
  - 证据：[doi:10.1002/advs.202516530, p.6]
- **results：** 在 SMPI-Test348 上，ALLSites 相比 P2Rank 在 F1、MCC 和 recall 上都有明显提升；在 CarbPI-Test162 上，它的平均 DICE、precision、recall 和 MCC 也优于 FTMap 与 CAPSIF: V/G。
  - 证据：[doi:10.1002/advs.202516530, p.6]；[doi:10.1002/advs.202516530, p.7]
- **results：** 在 DPI-Test129/Test181 与 RPI-Test117 上，ALLSites 优于大多数序列方法并接近最佳结构方法 GraphBind；当使用 AlphaFold2 预测结构时，GraphBind 性能下降，说明结构误差敏感。
  - 证据：[doi:10.1002/advs.202516530, p.7]；[doi:10.1002/advs.202516530, p.8]；[doi:10.1002/advs.202516530, p.9]
- **results：** 推理效率较高：单张 NVIDIA V100 可在约 16 小时内扫描全人类 proteome，平均 2.81 秒/蛋白、0.0075 秒/残基。
  - 证据：[doi:10.1002/advs.202516530, p.9]

# Integrated convolution and self-attention for improving peptide toxicity prediction

- **期刊 / 来源：** Bioinformatics

## 作者主张的创新点

论文声称提出 CAPTP，一个将 convolutional modulation、multi-head self-attention 与 supervised contrastive learning 结合的端到端肽毒性预测模型；同时还整理了新的毒/非毒肽数据集，并用 ISM 与裁剪实验解释 head/central regions 对毒性的影响。

## 创新边界

`这是序列级毒性属性预测，不是候选肽生成、优化或对接。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：仅凭 amino acid sequence，如何快速、准确地预测 peptide toxicity，并在类别不平衡与历史标注冲突存在的情况下仍保持可用的筛选能力。

## 方法

- 局部卷积与全局self-attention编码序列，对比损失增强少数类，再二分类。

## 数据与基准

- 作者整理的peptide toxicity训练/独立集，并比较CSM-Toxin等benchmark。

## 比较基线

- ATSE、ToxIBTL、CSM-Toxin及蛋白/肽毒性模型。

## 结果证据

- 交叉验证与独立集MCC约0.82；为计算毒性预测。

- 毒性定义/assay异质，类别不平衡和数据规模有限；模型不能替代细胞/动物毒理。

## Pi 结构化证据摘录

- **baseline：** 作者将 CSM-Toxin、ToxinPred2 和 ToxIBTL 作为主要 state-of-the-art 对照，并在 Test1/Test2 上逐项比较。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.5]
- **baseline：** 还与基于 hand-crafted features 的 classical ML 管线对照，包括 AAC、GAAC、QSOrder、PAAC、NMBroto，以及 logistic regression、SVM、random forest 和 LGBM。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.5]
- **baseline：** 内部 ablation 还比较了去掉 contrastive learning、不同 pooling 方式和不同 kernel size，用于确认 CAPTP 的关键设计。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.4]
- **data：** 数据集由 CSM-Toxin、ToxinPred2、ATSE 的样本与 UniProt reviewed non-toxic peptides 组合而成，仅保留长度小于 50 aa 的序列，并剔除了非标准氨基酸样本。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.2]；[doi:10.1093/bioinformatics/btae297, p.3]
- **data：** 作者删除了 97 条冲突标注样本，去重后得到 2138 条 toxic peptides 和 5375 条 non-toxic peptides，再以 85%/15% 划分训练集与独立测试集。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.3]
- **data：** 为了做更公平的外部比较，作者还构造了 Test2，并移除了与 ToxIBTL 训练集重叠的样本。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.5]
- **declared_resources：** 论文摘要给出 CAPTP 的源代码地址 https://github.com/jiaoshihu/CAPTP，表示代码公开可得。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.1]
- **declared_resources：** 作者同时声明 Supplementary data 在线提供，并在致谢中列出 JSPS KAKENHI、JST、NSFC 与 Quzhou 市项目资助。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.8]
- **limitations：** 作者明确指出当前版本不包含结构信息，因此难以支撑更完整的功能分析和下游应用。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.8]
- **limitations：** 论文也说明模型只区分 toxin 与 non-toxin，没有考虑 peptide 的来源。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.8]
- **method：** CAPTP 由 embedding、encoder、prediction 和 contrastive learning 四个模块组成，输入仅为 amino acid sequence 与 position embedding，不依赖额外手工特征。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.3]
- **method：** encoder 将 depthwise convolution 的局部上下文建模与 Transformer self-attention 的长程依赖建模结合；卷积调制通过 Hadamard product 作用于 value 向量。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.3]
- **method：** 训练目标把 supervised contrastive loss 与 binary cross-entropy 组合起来，用距离拉近同类表示、推远异类表示，并用更强调异类对的形式缓解不平衡。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.3]；[doi:10.1093/bioinformatics/btae297, p.4]
- **method：** 作者采用 BACC、SN、SP、MCC 和 AUC 评价模型，并明确在不平衡数据场景下重点关注 BACC 与 MCC。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.4]
- **results：** 消融结果显示，加入 contrastive learning 后，BACC、AUC、MCC 从 68.64、0.854、0.467 提升到 91.62、0.960、0.820，SN 也从 41.63% 升至 89.56%。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.4]
- **results：** 在结构选择上，max pooling 优于 [CLS]、mean、min 和 attention pooling；卷积核大小 K=3 取得最佳综合性能。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.4]
- **results：** 独立测试集 Test1 上，CAPTP 达到 BACC 91.59%、AUC 0.959、SN 90.63%、SP 92.56%、MCC 0.811；在更严格的 Test2 上仍有 BACC 82.95%、AUC 0.901、SN 73.91%、SP 91.98%、MCC 0.525。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.5]
- **results：** ISM 和 sequence truncation 分析共同提示，head region 与 central region 对毒性判别更关键，且 Q 在模型中的贡献高于传统 AAC 直觉。
  - 证据：[doi:10.1093/bioinformatics/btae297, p.6]；[doi:10.1093/bioinformatics/btae297, p.7]

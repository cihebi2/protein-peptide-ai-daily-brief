# HybridGCN for protein solubility prediction with adaptive weighting of multiple features

- **论文 ID：** `EVIW-7EB0644884548F6C`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2023 Dec 8
- **DOI：** [10.1186/s13321-023-00788-8](https://doi.org/10.1186/s13321-023-00788-8)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 HybridGCN，把 ESM-1v 零样本特征、五类传统蛋白特征、接触图、GCN 与 AFR 组合起来，以自适应方式融合多源特征来提升蛋白溶解度预测。

## 创新边界

`新意主要在特征融合、特征重加权和图式预测框架，不在新湿实验，也不在蛋白候选生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在公开数据集上预测蛋白溶解度的连续值，并评估序列、进化、结构与深度表示能否提升回归与分类表现。

## 方法

- 构建多类序列特征和ESM-1v零样本表示，以GCN融合并用AFR动态加权。

## 数据与基准

- 公共eSOL和S. cerevisiae数据集。

## 比较基线

- 手工特征、PLM和既有solubility预测模型。

## 结果证据

- 论文报告在eSOL和酵母集达到SOTA，并以消融支持ESM-1v与AFR贡献；为计算分类/回归。

## Pi 结构化证据摘录

- **baseline：** eSOL 上对比了 GraphSoLSingle、GraphSoLEnsemble、NetSolP、DeepSol、SeqVec、TAPE、ProGAN，以及 LSTM、SVM、KNN、LR、RF、XGBoost 等方法。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.10]
- **baseline：** 作者报告 OursEnsemble 在 eSOL 上的 Accuracy、Precision、Recall、F1 分别比 GraphSoLEnsemble 高 1.9%、2.6%、2.7%、2.1%。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.11]
- **data：** eSOL 数据集共 2,737 条蛋白序列，作者沿用 75% 训练、25% 独立测试的划分，溶解度定义来自 PURE 实验。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.7]
- **data：** S. cerevisiae 外部测试集包含 108 个蛋白及其对应 3D 结构，溶解度同样由 PURE 测定。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.7]
- **data：** 训练阶段使用 5-fold cross-validation，并用 5 个随机种子平均结果，之后再用完整训练集训练并做独立测试。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.7]
- **declared_resources：** 作者给出公开数据来源，说明 eSOL 数据可从 GitHub 地址获取。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.12]
- **declared_resources：** 作者声明源码会在接受后发布到 GitHub，但冻结证据中没有可直接核验的仓库链接。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.12]
- **limitations：** 作者明确指出该方法不是 end-to-end，需要依赖外部特征提取器来生成节点与边特征，因此会增加时间开销。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.12]
- **limitations：** 他们也承认当前流程依赖预训练蛋白语言模型和手工特征工程，后续希望探索更高效的特征提取与融合方法。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.12]
- **method：** 模型把蛋白序列建成图，节点特征由 ESM-1v、BLOSUM62、AAPHY7、PSSM、HMM 和 SPIDER3 六类特征组成，边特征使用 SPOT-Contact 预测的 contact map。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.5]；[doi:10.1186/s13321-023-00788-8, p.6]
- **method：** AFR 先对各通道做 global average pooling，再通过卷积、ReLU 和 sigmoid 估计通道权重，对 hybrid feature 做逐通道重加权。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.6]
- **method：** 预测器包含 GCN 与 self-attention，后接两层 FC，并用 tanh、softmax 和 sigmoid 将输出映射到 0 到 1 的溶解度值。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.4]；[doi:10.1186/s13321-023-00788-8, p.7]
- **results：** 在 eSOL 的 5-fold cross-validation 上，HybridGCN 取得 RMSE 0.227、R2 0.497、AUC 0.876，为四种设置中最好。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.8]
- **results：** 消融结果显示，去掉 ESM 特征带来最大性能下降，而 HMM 是与 ESM 最互补的特征，说明进化信息对该任务很重要。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.8]；[doi:10.1186/s13321-023-00788-8, p.9]
- **results：** 在 S. cerevisiae 外部测试上，OursEnsemble 的 R2 达到 0.390，优于 GraphSOLEnsemble 的 0.372。
  - 证据：[doi:10.1186/s13321-023-00788-8, p.11]

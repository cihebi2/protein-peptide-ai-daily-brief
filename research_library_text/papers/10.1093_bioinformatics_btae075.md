# GeneGPT: augmenting large language models with domain tools for improved access to biomedical information

- **DOI：** [10.1093/bioinformatics/btae075](https://doi.org/10.1093/bioinformatics/btae075)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

自回归LLM缺乏与真实知识源 consult 的内在机制，在基因组学事实型问答上幻觉严重；如何教会LLM调用NCBI Web API（E-utils、BLAST）以获得精准的生物医学信息访问能力。

## 作者主张的贡献

提出GeneGPT：通过带API文档与演示的上下文学习提示+解码时检测并执行API调用的增强推断算法，教会Codex使用NCBI Web API；在GeneTuring基准8个任务上取得SOTA（平均0.83），大幅超过New Bing(0.44)、BioMedLM(0.08)、BioGPT(0.04)、GPT-3(0.16)、ChatGPT(0.12)；并引入多跳问答新数据集GeneHop。

## 创新边界

工具增强LLM与API调用解码并非首创（已有Toolformer、program-aided LMs等）；本文的新颖性主要在于生物医学领域工具（NCBI API）的具体实例化、发现演示比文档更有效、以及跨任务泛化证据。'LLM+外部工具减幻觉'的大框架不能当首创。

## 创新点证据卡

- **[p1]** 将LLM API调用集成进解码过程：生成中检测并执行NCBI Web API调用再续写
  - 原文："an augmented decoding algorithm that can detect and execute API calls"
- **[p1]** 实证发现API演示(demonstrations)比文档(documentations)对上下文学习更有效且跨任务泛化
  - 原文："API demonstrations have good cross-task generalizability and are more useful than documentations for in-context learning"
- **[p1]** 引入GeneHop多跳问答数据集验证模型可泛化到更长的API调用链
  - 原文："GeneGPT can generalize to longer chains of API calls and answer multi-hop questions in GeneHop, a novel dataset"
- **[p5]** 在GeneTuring 8任务上平均0.83大幅超过检索增强与生物医学LLM基线
  - 原文："GeneGPT achieves state-of-the-art performance on eight tasks in the GeneTuring benchmark with an average score of 0.83"
- **[p6]** 仅两条演示（基因别名+BLAST比对）即可恢复接近完整提示的全部能力
  - 原文："GeneGPT with only two demonstrations (Dm.1 and Dm.4) in the prompt can general-"

## 方法

- 上下文学习提示：指令+API文档(Dc.1/2)+API演示(Dm.1-4)+测试问题四模块
- 增强解码算法：在Codex生成中检测'->'标记的API调用、实际执行NCBI请求并将结果回填继续解码
- 基于Codex(code-davinci-002)、temperature=0
- 消融/探针实验量化各提示组件贡献

## 数据与基准

- GeneTuring基准（基因组学QA，8任务）
- GeneHop（本文新引入的多跳QA数据集）
- NCBI Web API：E-utils(esearch/efetch/esummary, gene/snp/omim库)与BLAST URL API

## 结果证据

- GeneTuring总体平均0.83 vs New Bing 0.44、GPT-3 0.16、ChatGPT 0.12
- 序列比对任务平均0.66，New Bing为0.00（BLAST工具不可被检索替代）
- 基因名转换1.00、SNP定位0.98-1.00
- 仅2条演示(Dm.1+Dm.4)即可达到接近完整提示的性能，演示跨任务泛化性强
- 仅用文档不用演示则在所有任务失败；文档单独无能力

## 比较基线

- GPT-2
- BioGPT
- BioMedLM
- GPT-3(text-davinci-003)
- ChatGPT
- New Bing(检索增强)

## 已知限制

- 依赖Codex闭源模型，无法复现权重级实验
- 仅覆盖NCBI数据库，未扩展到其他生物医学API
- 作者承认gene disease association任务上被New Bing超过(0.66 vs 0.84)
- 错误类型在不同任务富集，长链API调用仍会出错

## 待复核未知项

- GeneHop数据集的规模与构造细节未在所读页面给出

# Comparative Assessment of Protein Large Language Models for Enzyme Commission Number Prediction

- **DOI：** [10.1186/s12859-025-06081-9](https://doi.org/10.1186/s12859-025-06081-9)
- **批次：** mass-review-20260916 / strict-v2 高分通过（OA 补下全文）
- **质量分：** 74.17
- **检索通道：** C03-protein-language-generation
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

蛋白语言模型（ESM2/ESM1b/ProtBERT）被广泛用于酶 EC 编号功能注释，但 (1) 各 LLM 作为特征提取器的相对性能缺乏系统对比；(2) LLM 与序列比对方法（BLASTp）作为独立预测器从未在大测试集上正面对比，LLM 能否取代 BLASTp 的问题悬而未决。

## 作者主张的贡献

构建稳健评估框架：7 种 LLM 嵌入（ProtBERT/ESM1b/五种 ESM2 变体）+ DNN 分类器，与 BLASTp、DeepEC、D-SPACE 及 one-hot 基线在五个评估数据集、六档序列同一性阈值（40-90%）×5 折上系统对比；发现 BLASTp 总体仍略优，但 ESM2 3B 在难注释/低同源（<25% 一致性）酶上更准，两者互补、组合最优；DL 模型能学好 EC 层级结构。

## 创新边界

LLM vs BLASTp 互补的结论与 ProteInfer、CLEAN 等先前研究的观察一致，本文是更大规模的确认性研究而非新范式；DNN+嵌入的架构本身无创新；评估设计（同一性阈值分层、证据级别数据集）是可复用的方法论贡献。

## 创新点证据卡

- **[p1]** 首次在大测试集上将 LLM 与 BLASTp 作为独立 EC 注释器系统对比
  - 原文："LLMs and sequence alignment methods have not been extensively compared as individual predictors"
- **[p5]** 六档同一性阈值×5 折的分层评估协议量化同源性对性能的影响
  - 原文："six distinct identity thresholds (90%, 80%, 70%, 60%, 50% and 40%) using CD-HIT"
- **[p1]** 发现 BLASTp 与 LLM 预测互补、组合最优，LLM 在 <25% 一致性时更优
  - 原文："BLASTp and LLM models complement each other and can be more effective when used together"
- **[p14]** 用 S-min 与 HCE 层级指标证明 DNN-LLM 能学好 EC 层级结构
  - 原文："DNN ESM2 3B stands out as the most optimal model with an S-min of 0.240"

## 方法

- LLM 最后一层 token 平均池化为蛋白级嵌入（7 种：ProtBERT、ESM1b、ESM2 150M/650M/3B 等五变体）
- 浅层 DNN（输入-隐层-输出 sigmoid 多标签头，BCE 损失，架构搜索 4 试）
- 自研分层切分算法保证低频 EC 类在测试集中有代表（<15% 类按比例从训练集转移）
- CD-HIT 六档同一性阈值（90-40%）× 5 折 train-test 切分
- 五个评估数据集：全测试集/文献证据级/混杂多功能酶/低同源集等
- WSR 统计显著性检验；S-min 语义距离与 HCE 层级一致性误差评估层级学习

## 数据与基准

- UniProtKB 衍生酶-EC 数据集（SwissProt 文献证据级子集）
- 30 个 train-test 组合（6 阈值×5 折）
- 复现实现 DeepEC 与 D-SPACE

## 结果证据

- BLASTp 在几乎全部同一性阈值上 mF1 显著高于单独 DL 模型（p<0.001）
- DNN ESM2 3B 是 LLM 中最佳，各阈值均显著超其他 DNN-LLM
- Models+BLASTp 组合在所有阈值上总体最优（除 40% 阈值与 BLASTp 持平）
- 同源一致性<25% 时 LLM 预测优于 BLASTp（无同源场景）
- DNN-LLM 的 S-min 最低（ESM2 3B 0.240），层级一致性显著优于 CNN 基线
- LLM 与 BLASTp 各自擅长不同 EC 类，互补性明确

## 比较基线

- BLASTp（金标准）
- one-hot 编码 DL 模型
- DeepEC（CNN+DIAMOND）、D-SPACE（CNN）

## 已知限制

- 结论受限于 EC 注释本身的质量与偏差（部分自动注释）
- 未测更新一代模型（如 ESM3/ProtT5/结构基础方法）
- DNN 头简单（最多 2 隐层），嵌入未微调
- BLASTp 数据库与 LLM 预训练数据的泄漏区分不够彻底

## 待复核未知项

- 各数据集上的绝对 mF1 数值表（图表形式为主，未逐一读出）
- 组合策略（Models+BLASTp）的具体融合规则
- 嵌入维度与训练成本细节

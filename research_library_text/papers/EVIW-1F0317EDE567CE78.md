# Optimizing enzyme thermostability by combining multiple mutations using protein language model

## 作者主张的创新点

作者声称用温度引导的 protein language model Pro-PRIME 结合少量实验数据，对 creatinase 的 18 个有利单点突变做两轮细调与排序，在 2^18 组合空间中只用两轮实验就筛出 50 个全部优于 WT 的组合突变体，并得到最优变体 13M4。

## 创新边界

`创新主要在于将既有 Pro-PRIME 细调到具体酶的组合突变设计场景，并用实验反馈与 DCCM 解释长程 epistasis；并非从头提出新的基础 PLM 架构。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在酶热稳定性优化中，把已知有利的单点突变高效重组为高阶组合突变，同时尽量避免 epistasis 导致的失活或局部最优陷阱。

## 方法

- 以Tm和相对活性分别微调回归/判别模型；枚举18个位点的262,144种组合并按稳定性和活性筛选；实验反馈再微调；用动力学交叉相关矩阵分析上位性。

## 数据与基准

- 18个单突变、22个双突变、21个三突变、12个四突变作为初始标签；Pro-PRIME预训练来源为约9,600万条宿主最适生长温度相关序列；两轮各测试25个组合。

## 比较基线

- 传统逐步贪心组合流程；Pro-PRIME原基准在论文引用的数据集上与其他PLM比较，但本文肌酸酶组合实验缺少同预算端到端基线。

## 结果证据

- 论文报告50个设计均高于野生型稳定性；13M4含13个位点、Tm提高最高10.19°C、58°C半衰期约提高655倍并基本保持催化活性。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 只在一个酶和预先筛得的18个位点上验证；100%成功率的分母是强筛选后的50个候选；跨酶和未筛位点泛化未证明。

## 仍未知

- 文中未见独立外部 prior-art 检索或与其他 PLM 的同台量化 benchmark。
- 本文专用代码仓库在冻结页内未被明确验证。
- 13M4 是否为更大组合空间中的全局最优，冻结证据未能证明。

## Pi 结构化证据摘录

- **baseline：** 与前作的 stepwise combinatorial strategy 相比，本文用一次性枚举 2^18 组合并通过模型排序，减少了逐轮试错。
  - 证据：[doi:10.1002/mlf2.12151, p.2]；[doi:10.1002/mlf2.12151, p.3]；[doi:10.1002/mlf2.12151, p.9]
- **baseline：** 本文仍以 WT 和作者先前获得的低阶组合变体作为性能参照，13M4 在热稳定性与活性上均优于这些基线。
  - 证据：[doi:10.1002/mlf2.12151, p.3]；[doi:10.1002/mlf2.12151, p.5]
- **data：** 初始实验数据集来自 creatinase 的 18 个单突变、22 个双突变、21 个三突变和 12 个四突变；正文还写到共 99 个实验数据点用于二次细调。
  - 证据：[doi:10.1002/mlf2.12151, p.2]；[doi:10.1002/mlf2.12151, p.3]；[doi:10.1002/mlf2.12151, p.9]
- **data：** 热稳定性用 DSF、CD 和 nanoDSC 测量，分别得到 Tm 与 ΔH；动力学稳定性用 T50^15 与 58°C 下的 t1/2 评估。
  - 证据：[doi:10.1002/mlf2.12151, p.4]；[doi:10.1002/mlf2.12151, p.5]；[doi:10.1002/mlf2.12151, p.10]；[doi:10.1002/mlf2.12151, p.11]
- **data：** 作者枚举了 18 个有利单突变对应的全部 2^18 = 262,144 个组合序列作为计算筛选库。
  - 证据：[doi:10.1002/mlf2.12151, p.3]
- **declared_resources：** 底物/表达资源包括 creatinase 基因 BAA88830.1、parent template I304L/F395V (afCR-M0)、pET-28a(+)、E. coli DH5α 和 BL21(DE3)。
  - 证据：[doi:10.1002/mlf2.12151, p.10]
- **declared_resources：** 实验设备与试剂包括 SYPRO Orange、Analytik Jena qTower3、TA Instruments nanoDSC、Jasco J-1500、GROMACS-2021、Bio3D、VMD 和 PyMOL。
  - 证据：[doi:10.1002/mlf2.12151, p.10]；[doi:10.1002/mlf2.12151, p.11]
- **declared_resources：** 作者还在 Data availability 中给出 Pro-PRIME 的基准数据来源与 GitHub 链接 https://github.com/ai4protein/Prime，并说明 creatinase 数据见正文和补充材料。
  - 证据：[doi:10.1002/mlf2.12151, p.12]
- **limitations：** 论文的全部湿实验都围绕 creatinase 展开，因此推广到其他酶仍属于推断，而非已验证结论。
  - 证据：[doi:10.1002/mlf2.12151, p.2]；[doi:10.1002/mlf2.12151, p.10]
- **limitations：** 组合空间随单点突变数量指数增长，作者也承认单点库的选择和算力会显著限制可搜索规模。
  - 证据：[doi:10.1002/mlf2.12151, p.9]
- **limitations：** 长程 epistasis 的机理主要来自 MD/DCCM 解释，而非直接的实验级结构动力学测量。
  - 证据：[doi:10.1002/mlf2.12151, p.5]；[doi:10.1002/mlf2.12151, p.6]；[doi:10.1002/mlf2.12151, p.7]；[doi:10.1002/mlf2.12151, p.8]；[doi:10.1002/mlf2.12151, p.11]
- **method：** 作者先把 Pro-PRIME 细调成热稳定性回归模型和相对活性判别模型，再用初始标注数据驱动组合突变筛选。
  - 证据：[doi:10.1002/mlf2.12151, p.3]；[doi:10.1002/mlf2.12151, p.11]
- **method：** 序列被编码为 L×1280 的潜在表示，再平均成 1280 维向量，经 MLP、dropout 和 Tanh 输出单一预测分数。
  - 证据：[doi:10.1002/mlf2.12151, p.11]
- **method：** 训练使用 Adam、MSE、最多 200 个 epoch，并在 10 个 epoch 无改进时 early stop；实现运行于单张 80GB NVIDIA A100。
  - 证据：[doi:10.1002/mlf2.12151, p.11]
- **method：** 作者对 WT 与 13M4 做了 100 ns MD 模拟，并用 RMSF、随机卷曲数、SASA、Rg 和 DCCM 解释稳定性与长程 epistasis。
  - 证据：[doi:10.1002/mlf2.12151, p.5]；[doi:10.1002/mlf2.12151, p.6]；[doi:10.1002/mlf2.12151, p.7]；[doi:10.1002/mlf2.12151, p.8]；[doi:10.1002/mlf2.12151, p.11]
- **results：** 第一轮筛选得到 25 个 5–9 位点组合突变体，全部比 WT 更稳定，Tm 提升约 7°C 到 9.33°C，且多数活性仍高于 80%。
  - 证据：[doi:10.1002/mlf2.12151, p.3]
- **results：** 第二轮又筛出 25 个 12–15 位点突变体，Tm 再提升到 8.17°C 到 10.19°C；最佳变体 13M4 保持接近 WT 的活性。
  - 证据：[doi:10.1002/mlf2.12151, p.3]；[doi:10.1002/mlf2.12151, p.5]
- **results：** 13M4 的 DSF Tm 为 69.72±0.15°C，CD 为 69.84±0.23°C，DSC 为 69.53°C；WT 分别约为 59.53、60.18 和 60.29°C。
  - 证据：[doi:10.1002/mlf2.12151, p.5]
- **results：** 13M4 的 58°C 半衰期为 1049.45 min，较 WT 的 1.60 min 提升约 655.91 倍；T50^15 也提升约 10°C。
  - 证据：[doi:10.1002/mlf2.12151, p.5]
- **results：** DCCM 和局部结构分析表明，K351E 呈 sign epistasis，D17V/I149V 呈 synergistic epistasis，且这些远程效应与局部 RMSF 改变相关。
  - 证据：[doi:10.1002/mlf2.12151, p.7]；[doi:10.1002/mlf2.12151, p.8]

# Multi-Property De Novo Drug Design Using Deep Learning-Based Knowledge Distillation and Reinforcement Learning

- **论文 ID：** `EVIW-FCBA3B306071F343`
- **期刊 / 来源：** Int J Mol Sci
- **发表时间：** 2026 Jul 8
- **DOI：** [10.3390/ijms27146125](https://doi.org/10.3390/ijms27146125)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 TSItransRL：用 conditional transformer 教师和 vanilla transformer 学生进行双向 interactive knowledge distillation，再用带 KL regularization 的 PPO 微调学生模型，以在 DRD2 与 JNK3/GSK3β 任务上生成满足多属性约束的候选分子。

## 创新边界

`创新主要在 teacher-student 交互蒸馏与 RL 的阶段化组合，不是实验发现或已验证 lead。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在 de novo drug design 中同时优化目标活性、drug-likeness 与 synthetic accessibility，并在不依赖显式条件输入的情况下维持多样性与化学空间探索。

## 方法

- teacher学习目标性质条件，student通过交互蒸馏吸收条件知识，再用RL奖励微调生成。

## 数据与基准

- PubChem-10M预训练及DRD2、JNK3/GSK3β生物活性数据；用MOSES、条件指标、对接、SEA和scaffold novelty评价。

## 比较基线

- REINVENT/REINVENT2.0及多种条件/RL分子生成模型。

## 结果证据

- 论文报告DRD2和JNK3/GSK3β任务成功率98.36%和98.90%、内部多样性0.795；作者明确生成物只是计算候选。

## Pi 结构化证据摘录

- **baseline：** 相较于 c-Transformer、DL、DM，init-TS 在 success 和 validity 上都更优，而这些 baseline 的 success 仅为 4.9%–25.4%。
  - 证据：[doi:10.3390/ijms27146125, p.5]
- **baseline：** 相较于 REINVENT、REINVENT2.0、MCMGL、MCMGM、Semi-MCMGM，TSItransRL 在 success、real success、novelty 和 IntDiv 上均保持领先或接近领先。
  - 证据：[doi:10.3390/ijms27146125, p.9]
- **baseline：** scaffold similarity 的基线对比显示，TSItransRL 的 0.131 低于 REINVENT、REINVENT2.0、MCMGL、MCMGM、Semi-MCMGM 报告值 0.550、0.600、0.574、0.542、0.446。
  - 证据：[doi:10.3390/ijms27146125, p.14]
- **data：** 教师预训练数据来自既有 benchmark：DRD2 包含 7219 个 positive 和 100000 个 negative；JNK3/GSK3β 合并后为 3405 个 positive 和 100000 个 negative。
  - 证据：[doi:10.3390/ijms27146125, p.4]；[doi:10.3390/ijms27146125, p.22]
- **data：** 学生预训练使用 PubChem-10M 的 1000 万条 SMILES 作为无标签知识库。
  - 证据：[doi:10.3390/ijms27146125, p.20]；[doi:10.3390/ijms27146125, p.23]
- **data：** 交互阶段每轮从 teacher 采样 500000 个候选分子，RL 阶段也使用 500000 个生成样本进行微调。
  - 证据：[doi:10.3390/ijms27146125, p.23]
- **declared_resources：** 实验使用两张 NVIDIA Quadro GV100 32 GB GPU，软件环境包括 PyTorch 1.10、RDKit 2024.3.1、AutoDock Vina 1.2.2、PyMOL 3.1.4、matplotlib 3.11、ADMET-AI 和 Chemprop-RDKit。
  - 证据：[doi:10.3390/ijms27146125, p.9]；[doi:10.3390/ijms27146125, p.15]；[doi:10.3390/ijms27146125, p.16]；[doi:10.3390/ijms27146125, p.21]；[doi:10.3390/ijms27146125, p.23]；[doi:10.3390/ijms27146125, p.24]
- **declared_resources：** 预训练用 Adam 进行 100 epochs、batch size 128；交互蒸馏用 SGD、lr 5e-4、10 epochs、batch size 32；PPO 微调用 30000 iterations、batch size 256、lr 1e-6。
  - 证据：[doi:10.3390/ijms27146125, p.23]
- **declared_resources：** 作者在 Data Availability 中声明 code 已公开于 GitHub，且提供了 TSItransRL-web 在线应用。
  - 证据：[doi:10.3390/ijms27146125, p.24]
- **limitations：** 作者多次强调，生成分子只是 computational candidates，docking/SEA/ADMET 仅用于 exploratory prioritization，不能当作实验活性或结合证据。
  - 证据：[doi:10.3390/ijms27146125, p.1]；[doi:10.3390/ijms27146125, p.9]；[doi:10.3390/ijms27146125, p.10]；[doi:10.3390/ijms27146125, p.11]；[doi:10.3390/ijms27146125, p.16]；[doi:10.3390/ijms27146125, p.17]；[doi:10.3390/ijms27146125, p.18]；[doi:10.3390/ijms27146125, p.19]；[doi:10.3390/ijms27146125, p.20]
- **limitations：** 论文未提供生物活性、选择性、化学稳定性、毒性和可合成性的实验验证，也未进行生化或细胞实验。
  - 证据：[doi:10.3390/ijms27146125, p.19]；[doi:10.3390/ijms27146125, p.20]
- **limitations：** QED 和 SA 仍是简化启发式指标，可能漏掉 reactive、unstable 或 assay-interfering 结构，因此仍需 PAINS/toxicophore 和人工审查。
  - 证据：[doi:10.3390/ijms27146125, p.7]；[doi:10.3390/ijms27146125, p.19]；[doi:10.3390/ijms27146125, p.20]
- **limitations：** RL 相对 Round-7 student 的增益较小，提示交互蒸馏已带来主要提升，而缺少严格的 RL-only 对照使贡献分离不够充分。
  - 证据：[doi:10.3390/ijms27146125, p.17]；[doi:10.3390/ijms27146125, p.18]；[doi:10.3390/ijms27146125, p.19]
- **method：** 教师模型采用 conditional transformer，在目标特异数据上以 (SMILES, c) 形式预训练；学生模型采用 vanilla transformer，在 PubChem-10M 的无标签 SMILES 上预训练，分别学习条件约束与通用化学分布。
  - 证据：[doi:10.3390/ijms27146125, p.20]；[doi:10.3390/ijms27146125, p.21]；[doi:10.3390/ijms27146125, p.23]
- **method：** 交互蒸馏是双向的：teacher 在 c=1 下生成候选并筛出满足条件的正样本更新 student；student 仅用 <s> 或片段输入生成分子，再将带二元标签的结果回流更新 teacher，共 7 轮。
  - 证据：[doi:10.3390/ijms27146125, p.21]；[doi:10.3390/ijms27146125, p.23]
- **method：** RL 微调阶段使用 PPO，并以目标活性、QED 和二值化 SA 之和作为 reward，同时加入 KL regularization 约束与参考学生分布的偏移。
  - 证据：[doi:10.3390/ijms27146125, p.9]；[doi:10.3390/ijms27146125, p.21]；[doi:10.3390/ijms27146125, p.22]；[doi:10.3390/ijms27146125, p.23]
- **method：** DRD2 任务要求预测活性≥0.5、QED≥0.6、SA≤4；JNK3/GSK3β 任务使用对应双靶点阈值，均沿用 Wang et al. 的 benchmark 设定。
  - 证据：[doi:10.3390/ijms27146125, p.21]；[doi:10.3390/ijms27146125, p.22]
- **results：** 在 DRD2 的初始交互实验中，init-TS 的 success 提升到 89.5%，明显高于 c-Transformer、DL、DM、init-T 和 init-S；同时 validity 也达到 0.997。
  - 证据：[doi:10.3390/ijms27146125, p.5]
- **results：** 七轮交互后，student success 达到 0.953±0.001，teacher success 达到 0.906±0.005，表明交互蒸馏能持续改善多属性生成。
  - 证据：[doi:10.3390/ijms27146125, p.6]
- **results：** 最终 TSItransRL 在 DRD2 / JNK3/GSK3β 上分别达到 98.36% 和 98.90% 的 success，IntDiv 为 0.795、novelty 为 0.998、unique 为 0.998。
  - 证据：[doi:10.3390/ijms27146125, p.9]
- **results：** 探索性 docking 显示部分生成分子的 Vina 分数优于 perphenazine，平均内部相似度约 0.35，但作者明确将其定义为预筛选可视化而非亲和力验证。
  - 证据：[doi:10.3390/ijms27146125, p.10]；[doi:10.3390/ijms27146125, p.11]
- **results：** SEA 与 MaxTC 结果显示生成分子与 DRD2 及相关神经系统靶点保持化学相似性，且超过 92% 的样本对 DRD2 的 MaxTC 大于 0.5。
  - 证据：[doi:10.3390/ijms27146125, p.12]；[doi:10.3390/ijms27146125, p.13]
- **results：** scaffold 分析中，TSItransRL 的平均 pairwise scaffold similarity 为 0.131，且分析了 9621 个有效 Murcko scaffold、3575 个 unique scaffold，显示出较强 scaffold novelty。
  - 证据：[doi:10.3390/ijms27146125, p.13]；[doi:10.3390/ijms27146125, p.14]

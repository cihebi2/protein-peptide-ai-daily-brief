# A variational expectation-maximization framework for balanced multi-scale learning of protein and drug interactions

- **论文 ID：** `EVIW-D858D0437C6CD98B`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 May 25
- **DOI：** [10.1038/s41467-024-48801-4](https://doi.org/10.1038/s41467-024-48801-4)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 MUSE：用 variational EM 把结构尺度与网络尺度交替优化，并通过 mutual supervision 和伪标签传播提升 protein/drug 交互与界面预测性能。

## 创新边界

`创新主要在多尺度交替优化、伪标签互监督和失衡缓解；它是预测/表征方法，不是湿实验研究，也不以生成新候选分子为主。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在 protein/drug 交互预测中，把 atomic structure scale 与 molecular network scale 统一建模，并缓解多尺度学习中的优化失衡与单尺度偏置。

## 方法

- E步学习生物分子的原子/结构表示，M步使用分子网络GNN和伪标签扩展未观测边，再迭代更新。

## 数据与基准

- 覆盖PPI、DDI和DPI数据；PPI/蛋白数据来自HIGH-PPI，结构来自PDB，另有Zenodo数据。

## 比较基线

- DrugVQA、TAG-PPI、GNN-PPI、HIGH-PPI及单尺度/多视图模型。

## 结果证据

- 论文报告DDI与DPI上的AUPRC分别为0.998和0.922、AUROC为0.993和0.915，并在PPI基准优于比较方法；均为链接预测。

## Pi 结构化证据摘录

- **baseline：** PPI/DPI/DDI 部分比较了 DrugVQA、TAG-PPI、GNN-PPI、HIGH-PPI、MUSE-Joint、CGIB、ConPlex 和 MIRACLE 等基线，论文指出 MIRACLE 在多数指标上甚至不如结构基线 CGIB。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]
- **baseline：** 结构界面任务中，论文与 BIPSPI、DeepInteract、GLINTER、CDPred、PeSTo 和 MUSE-Joint 对比，并强调 MUSE 在接触预测与 binding-site 预测上整体更强。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]；[doi:10.1038/s41467-024-48801-4, p.3]
- **baseline：** MUSE-Joint 被作为 ablation，用来说明仅联合优化但缺少 EM 迭代时，模型仍会受多尺度失衡影响。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]；[doi:10.1038/s41467-024-48801-4, p.4]；[doi:10.1038/s41467-024-48801-4, p.5]
- **data：** SHS27K PPI、BioSNAP DPI 和 DeepDDI DDI 被用作多尺度交互预测基准；SHS27K 含 6660 个 protein-protein pairs 和 1533 个 human proteins，BioSNAP 的负样本由随机采样得到，DeepDDI 使用 192,284 个 drug-drug pairs 与 DrugBank 的 side-effect 信息。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.6]；[doi:10.1038/s41467-024-48801-4, p.7]
- **data：** DIPS-Plus 被用于 inter-chain contact prediction，PPBS 数据集来自 Dockground，包含 41,466 个 PDB files 和 240,506 个 protein-protein interfaces；论文还说明蛋白结构来自 PDB 或 ESMFold。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.7]
- **data：** 作者在数据与代码可得性中列出多个公开来源，包括 HIGH-PPI 的 Zenodo 数据、PDB、ConPlex、MIRACLE、DeepInteract、ScanNet，以及 MUSE 的 GitHub 仓库和 Zenodo 归档。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.11]
- **declared_resources：** 论文公开了 MUSE 的源码仓库与 Zenodo 版本，便于后续静态检查或复现。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.11]
- **declared_resources：** 论文复用了多个外部公开数据源，数据边界主要来自 HIGH-PPI、PDB、ConPlex、MIRACLE、DeepInteract 和 ScanNet。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.11]
- **limitations：** 作者明确指出，MUSE 对 noisy and incomplete multi-scale downstream tasks 仍有提升空间，可能需要结合 knowledge graph 与 explainable AI。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.6]
- **limitations：** 在伪标签实验中，随着阈值 t 增大，pseudo interactions 会越来越 noisy，尤其当 t > 0.4 时性能开始下降。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.5]
- **method：** MUSE 用 variational EM 把 atomic structure scale 与 molecular network scale 交替优化，E-step 学结构表征，M-step 学网络拓扑，并通过 mutual supervision 让两种尺度互相提供伪标签。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]；[doi:10.1038/s41467-024-48801-4, p.8]；[doi:10.1038/s41467-024-48801-4, p.9]；[doi:10.1038/s41467-024-48801-4, p.10]
- **method：** 在实现上，论文把蛋白和药物分别编码成图表示，再用 GIN/NCN 在 interaction network 上做 link prediction，并用阈值 1-t 把结构模型产生的 pseudo interactions 软加入网络。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.8]；[doi:10.1038/s41467-024-48801-4, p.9]；[doi:10.1038/s41467-024-48801-4, p.10]
- **method：** 论文还分析了多尺度学习失衡，利用 iterative optimization 观察两尺度利用率变化，并说明 EM 训练能逐步缓解 greedy learning。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.3]；[doi:10.1038/s41467-024-48801-4, p.4]；[doi:10.1038/s41467-024-48801-4, p.5]
- **results：** 在 SHS27K 上，MUSE 相比 HIGH-PPI 在 BFS、DFS、Random splits 上分别提升 13.81%、13.06% 和 7.69%；在 DDI 和 DPI 上分别达到 AUPRC 0.998/0.922、AUROC 0.993/0.915。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]
- **results：** 在 DIPS-Plus 上，MUSE 的 AUROC 为 0.92，P@10/P@L/10/P@L/5 为 0.26/0.25/0.23，优于 DeepInteract 的 0.90 和 0.20/0.19/0.17；基于其接触图的 Kabsch docking RMSD 为 4.33。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.2]
- **results：** 在 ScanNet 上，MUSE 的 median AUPRC/AUROC 为 0.811/0.938，优于 PeSTo；在 MaSIF-site 上也分别比 PeSTo 和 MUSE-Joint 高 2.23% 和 1.40%。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.3]
- **results：** 利用率分析显示，HIGH-PPI 的 atomic structure scale 与 molecular network scale 利用率比值为 21.22，而 MUSE 降到 3.08，支持其能更均衡地利用多尺度信息。
  - 证据：[doi:10.1038/s41467-024-48801-4, p.4]

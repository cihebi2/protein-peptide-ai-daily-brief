# GeoPep: A Geometry-Aware Masked Language Model for Protein-Peptide Binding Site Prediction

## 作者主张的创新点

作者提出 GeoPep，把 ESM3_sm_open_v0 的多模态表示、KAN 下游头和 distance-based geometric loss 结合，用于 residue-level protein-peptide binding site prediction，并报告其在外部 PPIRef 测试集上优于现有方法。

## 创新边界

`新意主要在预测与几何正则化层面，不是 de novo peptide design、docking 或生成式优化；核心边界是把 ESM3 迁移到 peptide interface localization。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在蛋白-肽相互作用中，如何在结构数据稀缺、肽构象高度柔性且界面信号稀疏的前提下，准确定位受体蛋白上的 peptide binding site，并保持三维空间一致性。

## 方法

- residue geometry tokens/graph与masked modeling，site classifier。

## 数据与基准

- protein-peptide complexes。

## 比较基线

- sequence/structure PepPI site methods。

## Pi 结构化证据摘录

- **baseline：** 作者把 PepNN 作为最相关的 peptide-specific baseline，同时加入 ScanNet 和 PeSTo 作为 protein-protein interface 方法来检验可迁移性。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]
- **baseline：** 在 threshold 0.8 下，PepNN 的 precision/recall/F1/accuracy 分别为 0.5056/0.3479/0.4122/0.8552，明显低于 GeoPep。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]
- **baseline：** ScanNet 与 PeSTo 的 AUC 分别为 0.694 和 0.592，说明直接把 protein-protein interface 模型迁移到 peptide 场景效果有限。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]
- **baseline：** 作者声明所有方法都使用相同阈值以便公平比较，并补充报告了更宽松的 threshold 0.5 结果。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]
- **data：** ESM3 预训练数据覆盖 UniRef、MGnify90、JGI、OAS，以及 PDB、AlphaFoldDB v4、ESMAtlas 等大规模序列和结构资源。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]
- **data：** Fine-tuning 数据来自 Propedia v2.3，过滤后得到 32,290 个 protein-peptide chain combinations、12,540 个 unique complexes，并按 90%/10% 划分训练/验证。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]
- **data：** 外部测试集来自 PPIRef，经过长度过滤与 MMseqs2 去冗余后保留 4,436 个 complexes；作者还分析了 receptor-only、peptide-only 和 joint identity 的更严格子集。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]；[doi:10.1021/acs.jcim.6c00187, p.9]
- **data：** 案例展示数据包括 6WLW、7Z31、7WZ6、6ATH、6MGN、8UCS 与 2P58 等 PDB 条目，用于可视化与结构一致性检查。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]；[doi:10.1021/acs.jcim.6c00187, p.7]；[doi:10.1021/acs.jcim.6c00187, p.8]
- **declared_resources：** GeoPep 的实现和训练流水线已公开在 https://github.com/Dian0212/GeoPep；但正文同时说明 pretrained weights 将在 publication 时提供。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.11]
- **declared_resources：** 训练使用 8 张 NVIDIA RTX A5000 GPUs，并通过 PyTorch Lightning、FSDP 和 automatic mixed precision 优化 14 亿参数模型。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.11]
- **declared_resources：** Supporting Information 额外给出 amino acid enrichment、random negative sampling、physicochemical complementarity 和 redundancy analyses，表明作者将辅助分析作为正式资源的一部分。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.11]
- **limitations：** 作者明确指出可用的 protein-peptide structural data 仍显著小于 protein-protein 数据，这会限制对罕见 binding mode、receptor family 和 interface topology 的泛化。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.9]
- **limitations：** 当前训练数据主要是 natural linear peptides，因此模型未显式覆盖 cyclic peptides、disulfide-bonded peptides、stapled peptides 或化学修饰残基。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.9]
- **limitations：** 随机 negative pairing 的探索性实验没有带来收益，说明更 realistic hard negatives 仍然是开放问题。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.9]；[doi:10.1021/acs.jcim.6c00187, p.10]
- **limitations：** 作者还指出，若要进一步稳健，最好引入 experimentally validated nonbinding pairs，但本文尚未提供这类数据。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.9]
- **method：** GeoPep 将 ESM3_sm_open_v0 产生的 residue embeddings 输入 KAN 预测模块，输出受体残基级 binding probability，用于 interface localization，而不是判定整对分子是否结合。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.2]；[doi:10.1021/acs.jcim.6c00187, p.10]
- **method：** 训练目标由 binary cross-entropy 与 distance-based structural regularization 组成，后者对高置信但远离真实 interface 的 false positives 施加惩罚，且正文默认 λ=10.0。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]
- **method：** 输入在 PDB 结构上提取序列和原子坐标，peptide 与 protein 分别 pad 到 50 和 500 residues，并用 chain-break token "|" 拼接后送入 tokenizer。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]
- **method：** 为离散预测，作者固定使用 probability threshold 0.8，将 pi≥0.8 视为 binding residue，且不再做额外 spatial clustering 或 postprocessing。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.10]；[doi:10.1021/acs.jcim.6c00187, p.6]
- **results：** 在 ESM2 vs ESM3 对比中，ESM3-GeoPep 的 ROC AUC 为 0.945，对比 ESM2-GeoPep 的 0.889；PR AUC 为 0.748 对 0.639；distance loss 为 0.039 对 0.361。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.4]
- **results：** KAN head 相比 MLP 在 PR AUC 上从 0.725 提升到 0.748，并把 mean distance loss 从 0.875 降到 0.039，说明下游非线性建模更有效。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.5]
- **results：** 使用 distance-based loss 与标准 loss 相比，PR AUC 仅小幅变化（0.748 vs 0.745），但 mean distance loss 明显改善（0.039 vs 0.570），说明几何约束主要提升空间一致性。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.5]
- **results：** 与 PepNN、ScanNet、PeSTo 相比，GeoPep 在外部测试集上达到 AUC 0.945，并在 threshold 0.8 下取得 precision 0.8379、recall 0.6272、F1 0.7174、accuracy 0.9279。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.6]
- **results：** 在 6ATH case study 中，GeoPep 报告 precision 1.000、recall 0.969、63 true positives 和 0 false positives，并且 Positive predictions 的 ΔRSA 更负，符合 interface burial 特征。
  - 证据：[doi:10.1021/acs.jcim.6c00187, p.8]

# PyAMPA: a high-throughput prediction and optimization tool for antimicrobial peptides

## 作者主张的创新点

作者提出 PyAMPA，一个整合 AMPScreen、AMPValidate、AMPSolve、AMPMutate 和 AMPOptimize 的平台，用于蛋白组高通量筛选、AMP 真假判别、性质预测、单点突变分析以及基于遗传算法的序列优化，并报告了 5 条候选肽的实验验证。

## 创新边界

`新意主要在于把既有的滑窗扫描、随机森林预测、回归估计和遗传算法优化组合成一个可执行的 AMP 发现工作流，并把原版 AMPA 扩展到更大规模筛选与多性质联合评估；它更像是系统集成与应用升级，而不是全新 AMP 理论框架。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在大规模蛋白序列中快速定位潜在抗菌肽片段，并进一步同时兼顾抗菌活性、低毒性、低溶血性与更长血清半衰期地进行候选优化。

## 方法

- 机器学习预测活性、CPP、溶血、毒性和半衰期，扫描蛋白序列定位motif，再用点突变/遗传算法优化多目标评分。

## 数据与基准

- AMPlify实验AMP、CPP 924条、AMPDeep 7,180条、ToxinPred 3,613条及GRAMPA IC50。

## 比较基线

- 原AMPA及现有AMP/溶血/毒性预测器。

## Pi 结构化证据摘录

- **baseline：** AMPValidate 的性能与 AI4AMP、AMPScanner、iAMPPred 在相同测试集上的结果做了直接比较。
  - 证据：[doi:10.1128/msystems.01358-23, p.7]
- **baseline：** cell-penetrating capacity 模型与 CellPPD、C2Pred、BChemRF-CPPred 对照；toxicity 模型与 ToxinPred、ToxinPred3、PreTP-EL 对照。
  - 证据：[doi:10.1128/msystems.01358-23, p.7]
- **baseline：** hemolysis 模型与 HemoPI-2、HemoPI-3 和 HemoPred 对照，表 1 也同时列出这些基线的 accuracy 与 MCC。
  - 证据：[doi:10.1128/msystems.01358-23, p.7]
- **baseline：** 作者还把 PyAMPA 的高通量筛选结果与此前类似的高通量 AMP 研究作了定性对比，说明其筛出的候选数量处于可比范围。
  - 证据：[doi:10.1128/msystems.01358-23, p.8]
- **data：** 训练数据主要来自 AMPlify 数据集，共 6,676 条肽序列，AMP 与 non-AMP 各 3,338 条。
  - 证据：[doi:10.1128/msystems.01358-23, p.2]
- **data：** 作者还使用了 Liu et al. 的 CPP 数据库（924 条）、AMPDeep 的 hemolysis 数据库（7,180 条）和 ToxinPred 数据库（3,613 条）；长度短于 7 个残基或含修饰残基的序列被排除。
  - 证据：[doi:10.1128/msystems.01358-23, p.2]
- **data：** 用于抗菌谱建模的活动数据来自 GRAMPA，覆盖 Escherichia coli、Staphylococcus aureus、Pseudomonas aeruginosa、Candida albicans 等 11 个物种的 IC50 信息。
  - 证据：[doi:10.1128/msystems.01358-23, p.2]
- **data：** 作者按 60%/20%/20% 划分训练、验证与测试集，并用 accuracy、MCC、ROC/AUPR 作为主要评估指标。
  - 证据：[doi:10.1128/msystems.01358-23, p.5]
- **data：** 湿实验验证从人类 proteome 中筛选出 5 条肽，筛选条件包括 AMPValidate 概率 >0.5、hemolysis 概率 <0.5、无 Cys、长度 10–25 个残基。
  - 证据：[doi:10.1128/msystems.01358-23, p.8]
- **data：** 实验部分还包括 Fmoc 固相合成、RP-HPLC/LC-MS 纯化鉴定，以及 MIC、hemolysis、HepG2 cytotoxicity 和 circular dichroism 测定。
  - 证据：[doi:10.1128/msystems.01358-23, p.5]；[doi:10.1128/msystems.01358-23, p.6]；[doi:10.1128/msystems.01358-23, p.7]
- **declared_resources：** 作者在摘要与数据可用性部分都给出了 GitHub 仓库：https://github.com/SysBioUAB/PyAMPA。
  - 证据：[doi:10.1128/msystems.01358-23, p.1]；[doi:10.1128/msystems.01358-23, p.14]
- **declared_resources：** 实现环境为 Python 3.11，并使用 NumPy 1.24.3、Pandas 2.0.2、SciKit-Learn 1.2.2、BioPython 1.81、Matplotlib 3.7.1 和 Seaborn 0.12.2。
  - 证据：[doi:10.1128/msystems.01358-23, p.5]
- **declared_resources：** 实验资源包括 H-Rink amide ChemMatrix resin、Prelude 合成仪、Shimadzu HPLC/MS、Jasco CD spectropolarimeter、Tecan microplate reader 和 HepG2 cells。
  - 证据：[doi:10.1128/msystems.01358-23, p.5]；[doi:10.1128/msystems.01358-23, p.6]；[doi:10.1128/msystems.01358-23, p.7]
- **declared_resources：** 资金来源列明 MCIN/AEI、European Union Next GenerationEU/PRTR、La Caixa Health Foundation 和 ESCMID 等支持。
  - 证据：[doi:10.1128/msystems.01358-23, p.13]
- **limitations：** 作者明确提示，初筛命中仍需要进一步分析与实验验证，单靠 AMPScreen 并不能保证得到理想 AMP。
  - 证据：[doi:10.1128/msystems.01358-23, p.2]；[doi:10.1128/msystems.01358-23, p.8]
- **limitations：** 抗菌谱回归器并非对所有物种都同样强，表 3 中 E. faecium 的 R2 只有 0.26，显示部分物种上的可预测性较弱。
  - 证据：[doi:10.1128/msystems.01358-23, p.9]
- **limitations：** 湿实验只验证了 5 条候选肽，因此对更大化学空间、其它蛋白组或不同病原体场景的外推仍有限。
  - 证据：[doi:10.1128/msystems.01358-23, p.8]；[doi:10.1128/msystems.01358-23, p.9]
- **limitations：** AMPOptimize 的输出依赖用户设定的权重、交叉率和突变率，优化目标本身带有明显的任务偏好。
  - 证据：[doi:10.1128/msystems.01358-23, p.5]；[doi:10.1128/msystems.01358-23, p.9]
- **method：** PyAMPA 由五个模块组成：AMPScreen、AMPValidate、AMPSolve、AMPMutate 和 AMPOptimize，分别覆盖蛋白组扫描、候选验证、性质预测、点突变分析与序列优化。
  - 证据：[doi:10.1128/msystems.01358-23, p.2]；[doi:10.1128/msystems.01358-23, p.3]；[doi:10.1128/msystems.01358-23, p.4]；[doi:10.1128/msystems.01358-23, p.5]
- **method：** AMPScreen 采用默认窗口 7 的滑窗平均打分，并以 0.225 作为默认阈值；连续至少 12 个阳性位置、且允许 2 个 gap 时，序列片段被视为潜在 AMP motif。
  - 证据：[doi:10.1128/msystems.01358-23, p.3]
- **method：** AMPValidate 使用 dipeptide（2-mer）向量化特征和 random forest 分类器，文中给出的随机森林配置为 250 棵树、每棵树最少 1 个 leaf。
  - 证据：[doi:10.1128/msystems.01358-23, p.4]
- **method：** AMPSolve 对 hemolysis、toxicity 和 cell-penetrating capacity 采用随机森林模型，对不同菌种的 antimicrobial spectrum 采用按菌种分别训练的随机森林回归器，而 peptide half-life 则按文中多变量回归公式估计。
  - 证据：[doi:10.1128/msystems.01358-23, p.4]
- **method：** AMPMutate 会穷举每个位点的全部单点突变并输出预测的 antimicrobial/hemolytic probability 与 half-life；AMPOptimize 则用含精英保留、交叉和突变的 genetic algorithm 按 fitness function 迭代生成新序列。
  - 证据：[doi:10.1128/msystems.01358-23, p.4]；[doi:10.1128/msystems.01358-23, p.5]
- **results：** AMPValidate 在文中测试集上的 accuracy 为 0.87、MCC 为 0.74，AUC 为 0.94，并优于 AI4AMP、AMPScanner 和 iAMPPred。
  - 证据：[doi:10.1128/msystems.01358-23, p.7]；[doi:10.1128/msystems.01358-23, p.8]
- **results：** AMPSolve 的 hemolysis、toxicity 与 CPP 模型分别达到 0.88/0.76、0.94/0.88 和 0.89/0.77 的 accuracy/MCC 组合。
  - 证据：[doi:10.1128/msystems.01358-23, p.7]；[doi:10.1128/msystems.01358-23, p.8]
- **results：** 作者用 AMPScreen 扫描了 20,398 条 UniProt human proteome 序列，得到 41,964 个肽片段，经 AMPValidate 进一步保留 19,393 个潜在 AMP。
  - 证据：[doi:10.1128/msystems.01358-23, p.8]
- **results：** 5 条实验肽在多菌种面板上都显示了较广谱的抗菌活性，并且总体上具有可接受的 hemolysis 与 cytotoxicity/antimicrobial 比值。
  - 证据：[doi:10.1128/msystems.01358-23, p.8]；[doi:10.1128/msystems.01358-23, p.9]
- **results：** AMPOptimize 的示例优化展示了 antimicrobial propensity 提高、hemolytic probability 降低以及 serum half-life 延长的联合改进。
  - 证据：[doi:10.1128/msystems.01358-23, p.12]

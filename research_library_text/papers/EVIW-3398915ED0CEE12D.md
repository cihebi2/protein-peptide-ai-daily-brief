## 作者主张的创新点

这是一篇 mini review，汇总并比较近期 sequence-based protein-ligand binding site prediction 研究，按 feature extraction 与 machine learning architecture 进行归纳，分析方法优缺点、研究空白与未来方向。

## 创新边界

`论文的新意主要在综述式整合与归纳，不是新的预测模型、数据集或独立 benchmark。`。这不是全球首创性检索或独立复现结论。

## 研究问题

仅基于蛋白序列，如何利用机器学习更准确地预测 protein-ligand binding sites，并比较不同特征表示与网络架构在这一任务中的适用性。

## Pi 结构化证据摘录

- **baseline：** 作者把 SCRIBER、DeepCSeqSite、DELIA、HoTS、Birds、T5 GAT Ensemble、LaMPSite、Pseq2Sites、Seq-InSite 作为主要对照对象进行综述。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.3]；[doi:10.3389/fbinf.2025.1520382, p.4]；[doi:10.3389/fbinf.2025.1520382, p.5]
- **baseline：** 文中提醒，Table 1 的数值来自各自原始论文，不同预处理和测试集下的结果不宜直接比较。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.3]
- **baseline：** 在效率讨论里，作者将 Pseq2Sites、Birds、DeepCSeqSite、HoTS 与 DeepPocket、DeepSurf、P2Rank 等 structure-based 方法并列比较。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]
- **data：** 文中汇总的公开数据资源包括 scPDB、COACH420、HOLO4k、PDBBind、CSAR NRC-HiQ、UniProt、Pfam、BioLip 与 PiSite。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.2]；[doi:10.3389/fbinf.2025.1520382, p.3]
- **data：** 作者还点名 COACH420 含 420 个 protein-ligand complexes，而 HOLO4k 含 4,009 个 complexes。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.2]
- **data：** Table 1 中列出的研究覆盖 BioLip、scPDB、COACH420、HOLO4k、CSAR、RCSB 等不同测试集合。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.3]；[doi:10.3389/fbinf.2025.1520382, p.5]
- **declared_resources：** 作者声明未获得任何 financial support，并明确写明不存在 conflict of interest。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.7]
- **declared_resources：** 作者还声明未使用 Generative AI 撰写本文，并在致谢中感谢 Dr. Lurong Pan 与 Recep Tayyip Erdogan University。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.7]
- **declared_resources：** 本稿未报告作者自建代码库、湿实验资源或独立模型资源，资源声明主要是综述性整理。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.1]；[doi:10.3389/fbinf.2025.1520382, p.7]
- **limitations：** sequence-only 方法缺乏 3D spatial context，因此在跨链相互作用和复杂 binding 关系上容易漏判。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]；[doi:10.3389/fbinf.2025.1520382, p.6]
- **limitations：** 作者指出，sequence-based 方法对 allosteric binding sites 的识别能力有限，尤其当位点远离 active site 时更明显。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.6]
- **limitations：** pLM 对 rare 或 underrepresented proteins 的效果较弱，且数据泄漏与训练/测试相似性会影响评估可信度。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]；[doi:10.3389/fbinf.2025.1520382, p.6]
- **method：** 本文采用 mini review 形式，先区分 structure-based 与 sequence-based 两类方法，再聚焦于 sequence-based 研究进行整理。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.1]；[doi:10.3389/fbinf.2025.1520382, p.2]
- **method：** 作者以 Table 1 为核心，按 feature extraction 方法与 machine learning model 对既有工作做横向归纳。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.3]；[doi:10.3389/fbinf.2025.1520382, p.4]
- **method：** 讨论部分围绕特征工程、sequence-only 局限、hybrid 方法、数据集与 AlphaFold 相关问题展开。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]；[doi:10.3389/fbinf.2025.1520382, p.6]；[doi:10.3389/fbinf.2025.1520382, p.7]
- **results：** 本文没有给出作者自己的新实验 benchmark；其主要产出是对既有研究结果的综合解读。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.3]；[doi:10.3389/fbinf.2025.1520382, p.7]
- **results：** 作者的总体判断是：sequence-based 方法计算更快，而 hybrid 方法在复杂 binding site 场景下更有潜力。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]；[doi:10.3389/fbinf.2025.1520382, p.6]；[doi:10.3389/fbinf.2025.1520382, p.7]
- **results：** 文中明确指出，pLM-based 方法（如 T5 GAT Ensemble、LaMPSite、Pseq2Sites、Seq-InSite）被认为表现更有前景。
  - 证据：[doi:10.3389/fbinf.2025.1520382, p.5]；[doi:10.3389/fbinf.2025.1520382, p.6]

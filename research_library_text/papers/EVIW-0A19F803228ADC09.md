# Structure-aware machine learning strategies for antimicrobial peptide discovery

- **论文 ID：** `EVIW-0A19F803228ADC09`
- **期刊 / 来源：** Sci Rep
- **发表时间：** 2024 May 25
- **DOI：** [10.1038/s41598-024-62419-y](https://doi.org/10.1038/s41598-024-62419-y)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `结构预测`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者构建了基于二肽、全局理化性质和 Random Forest 的机制分类器，并引入 AF2+STRIDE 结构景观分析，提出结构特异与结构无关两类策略来缓解 α-螺旋偏置。

## 创新边界

`创新主要在结构偏倚审计与分层建模，不是生成新肽或做湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知抗菌肽/宿主防御肽中，如何用序列与预测结构特征区分膜破坏、膜穿透和蛋白结合三种作用机制，并识别结构偏倚对预测性能的影响。

## 方法

- 以二肽和全局理化描述符为特征，对二分类和三分类任务比较12种/9种算法及过采样方案；用PEP2D/AlphaFold2预测结构景观，再训练结构特异和结构无关模型。

## 数据与基准

- 模型数据集1046条肽序列，外部验证集262条（72 MDP、57 MPP、133 PBP）；训练数据中alpha/松散螺旋占比高且无beta折叠类。

## 比较基线

- 以Lee等的序列SVC和Brand等的膜活性肽无监督分析为直接先例，并比较RFC、GBC、KNN等多类分类器和多种过采样方法。

## 结果证据

- RFC+ROSE在二分类和三分类上给出约86.7%-88.0%训练准确率与83.3%-83.5%测试准确率；外部验证显示原始模型偏向alpha螺旋，结构特异模型仅在训练/测试结构匹配且样本充足时更好。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 结构类别极不平衡且缺少beta折叠肽；结构特异模型需要预知或可靠预测测试序列结构，随机削减优势类会损失信息。

## 仍未知

- 未见新的湿实验验证。
- AF2 预测结构的误差对分类边界的影响未被单独量化。
- GitHub 仓库虽已声明，但本次未核验其实现细节与可复现性。

## Pi 结构化证据摘录

- **baseline：** 与 RFC 相比，GBC、ABC、KNN、SVC 和 DT 均表现更弱，其中 ROSE 一致优于 SMOTE 和 ADASYN。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.6]；[doi:10.1038/s41598-024-62419-y, p.7]
- **baseline：** 未做结构分层的 model 1.0 和 2.0 是作者的主基线，后续结构特异模型以其为对照。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.6]；[doi:10.1038/s41598-024-62419-y, p.10]；[doi:10.1038/s41598-024-62419-y, p.11]
- **data：** 模型集最终含 1046 条可用序列：412 条 MDP、326 条 MPP 和 307 条 PBP；原始收集量为 1057 条。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.2]；[doi:10.1038/s41598-024-62419-y, p.8]
- **data：** 外部验证集含 262 条序列（72 MDP、57 MPP、133 PBP），并按结构区 I/III/IV 做分层分析。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.3]；[doi:10.1038/s41598-024-62419-y, p.9]
- **declared_resources：** 数据与序列标签来自 DBAASP v3、APD3、PDBe 和 CPPsite 2.0，结构预测/注释使用 ColabFold、AlphaFold2 和 STRIDE。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.2]；[doi:10.1038/s41598-024-62419-y, p.3]；[doi:10.1038/s41598-024-62419-y, p.4]；[doi:10.1038/s41598-024-62419-y, p.8]
- **declared_resources：** 作者声明 Supporting Information 及公开 GitHub 仓库可下载数据和 scripts。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.14]；[doi:10.1038/s41598-024-62419-y, p.16]
- **limitations：** 训练集明显偏向 α-螺旋，且 β-折叠几乎缺失，导致初始模型对 α-helical peptides 有结构偏置。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.8]；[doi:10.1038/s41598-024-62419-y, p.9]；[doi:10.1038/s41598-024-62419-y, p.13]
- **limitations：** 作者指出，随机删减 α-螺旋序列会造成信息损失并使结构无关模型变弱，因此简单平衡并不总是收益。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.12]；[doi:10.1038/s41598-024-62419-y, p.13]
- **limitations：** 结构信息来自 AF2+STRIDE 预测而非新湿实验，因此结论依赖预测结构质量与已有标签的准确性。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.4]；[doi:10.1038/s41598-024-62419-y, p.8]；[doi:10.1038/s41598-024-62419-y, p.13]
- **limitations：** 外部验证仍是已知肽序列而非真正 de novo 候选，泛化到更远分布序列的能力未被充分证明。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.3]；[doi:10.1038/s41598-024-62419-y, p.9]
- **method：** 从 DBAASP v3、APD3、PDBe 和 CPPsite 2.0 整理 1057 条肽序列，并按膜破坏、膜穿透、蛋白结合三类标注；外部验证集另取 262 条未见序列。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.2]；[doi:10.1038/s41598-024-62419-y, p.3]
- **method：** 为每条序列计算 AAC、400 个二肽、8000 个三肽和 117 个理化性质，并用 Pearson 相关和多重共线性筛掉冗余特征。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.3]；[doi:10.1038/s41598-024-62419-y, p.5]
- **method：** 比较 12 个二分类与 9 个三分类算法，结合 ROSE、SMOTE 和 ADASYN 处理类别不平衡，并用 80/20 划分、十折交叉验证和超参数调优训练模型。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.4]；[doi:10.1038/s41598-024-62419-y, p.6]
- **method：** 用 ColabFold/AlphaFold2 预测所有肽结构，再以 STRIDE 注释二级结构并在三元图中划分四个结构区，以检查结构偏倚。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.4]；[doi:10.1038/s41598-024-62419-y, p.8]
- **results：** 在初始基线中，RFC+ROSE 给出最优性能：二分类训练/测试准确率 88.0%/83.3%，三分类 86.7%/83.5%，优于其他分类器与过采样方案。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.6]；[doi:10.1038/s41598-024-62419-y, p.7]
- **results：** 结构特异模型通常优于父模型：例如 α-螺旋二分类 1.1 测试准确率 89.5%，coiled 1.3 为 83.3%，三分类 2.4 测试准确率 89.3%，高于未分层模型 2.0 的 83.5%。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.10]；[doi:10.1038/s41598-024-62419-y, p.11]
- **results：** 特征重要性随结构子集变化，α-螺旋模型偏重 hydrophobicity、size 和 charge，coiled 模型偏重 flexibility，mixed 模型偏重 molecular weight，说明模型对结构类别敏感。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.11]；[doi:10.1038/s41598-024-62419-y, p.12]
- **results：** 在外部验证上，完整集的二分类误判率为 0.318，三分类约 0.305；与训练/测试结构分布不一致时，性能会明显下降。
  - 证据：[doi:10.1038/s41598-024-62419-y, p.10]；[doi:10.1038/s41598-024-62419-y, p.12]

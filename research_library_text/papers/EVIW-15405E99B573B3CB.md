# DeepRank-GNN-esm: a graph neural network for scoring protein-protein models using protein language model

- **论文 ID：** `EVIW-15405E99B573B3CB`
- **期刊 / 来源：** Bioinform Adv
- **发表时间：** 2024 Jan 5
- **DOI：** [10.1093/bioadv/vbad191](https://doi.org/10.1093/bioadv/vbad191)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型` / `图与几何学习`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 DeepRank-GNN-esm，在 DeepRank-GNN 图神经网络中引入 ESM-2 embeddings，用它们替代或补充 PSSM 特征；作者声称该方法在多个 PPI 评测上保持或提升性能，并显著加速特征生成。

## 创新边界

`属于对既有 DeepRank-GNN 的特征替换与重训扩展；论文未提供独立 prior-art 证据来验证全球首创。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 PPI 结构建模中，对 docking models 进行打分与排序，并区分 physiological 与 crystallographic interfaces，同时尽量降低传统 PSSM 生成的计算开销。

## 方法

- 复合物界面转残基图，结构/序列/ESM-2节点边特征输入GNN，分类/回归pose质量。

## 数据与基准

- BM5与CAPRI decoy数据，沿用DeepRank/DeepRank-GNN拆分。

## 比较基线

- DeepRank、DeepRank-GNN及传统PPI scoring函数。

## 结果证据

- 论文报告ESM版本提高评分且减少PSSM计算依赖；属于decoy ranking。

## Pi 结构化证据摘录

- **baseline：** 作者将方法与 DeepRank、DeepRank-GNN、GNN-Dove、HADDOCK、iScore、GOAP、PISA 和 PRODIGY-Crystal 做了对比。
  - 证据：[doi:10.1093/bioadv/vbad191, p.3]；[doi:10.1093/bioadv/vbad191, p.4]；[doi:10.1093/bioadv/vbad191, p.5]
- **baseline：** DeepRank-GNN-no-pssm 去掉 PSSM 和 ESM 后表现最差，说明 sequence conservation 类特征仍然关键。
  - 证据：[doi:10.1093/bioadv/vbad191, p.3]；[doi:10.1093/bioadv/vbad191, p.4]
- **data：** BM5 数据集包含 143 个 docking complexes，排除 antibody-antigen complexes 和多于两条链的 complexes；128 个 complexes 按 complex 划分为训练/评估集，另留 15 个 complexes 作为独立测试集。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **data：** 作者另外使用 13 个 CAPRI score set complexes 来做独立测试，以验证 scoring 表现。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **data：** MANY/DC benchmark 被用于 biological interfaces 与 crystallographic interfaces 的二分类评估。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **declared_resources：** DeepRank-GNN-esm 源码公开在 GitHub 的 https://github.com/DeepRank/DeepRank-GNN-esm。
  - 证据：[doi:10.1093/bioadv/vbad191, p.1]；[doi:10.1093/bioadv/vbad191, p.5]
- **declared_resources：** BM5 docking models、CAPRI score set、MANY 和 DC datasets 可从 SBGRID dataset 843 下载。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]；[doi:10.1093/bioadv/vbad191, p.5]
- **declared_resources：** 作者报告 PSSM 生成依赖 176 GB 的 NR database 且约需 2 小时单核计算，而 ESM-2 仅需 2.5 GB 预训练模型并约 5 秒即可得到 embedding。
  - 证据：[doi:10.1093/bioadv/vbad191, p.5]
- **limitations：** 作者指出同时使用 PSSM 与 ESM embeddings 可能带来冗余和 noise，并增加可训练参数，使收敛更困难。
  - 证据：[doi:10.1093/bioadv/vbad191, p.4]
- **limitations：** 论文的评估主要集中在 BM5、CAPRI、MANY 和 DC 这些冻结基准上，未见更广泛的独立外部队列验证。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]；[doi:10.1093/bioadv/vbad191, p.3]；[doi:10.1093/bioadv/vbad191, p.4]；[doi:10.1093/bioadv/vbad191, p.5]
- **limitations：** 作者也将方法定位为更适合 antibody-antigen complexes 或 protein-peptide complexes 等 PSSM 不易获得的场景，说明其适用边界主要在现有 PPI scoring 任务。
  - 证据：[doi:10.1093/bioadv/vbad191, p.1]；[doi:10.1093/bioadv/vbad191, p.5]
- **method：** 以界面周围 8.5 Å 内的残基构建 residue-level graph，并将 ESM-2 embedding 逐残基映射到对应图节点。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **method：** 在 DeepRank-GNN 架构上训练 DeepRank-GNN-esm-pssm、DeepRank-GNN-esm 和 DeepRank-GNN-no-pssm，使用 MSE、Adam、batch size 128、learning rate 0.001、20 epochs。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **method：** 对 scoring 任务采用 BM5/CAPRI 评测；对界面分类任务采用 MANY 训练并在 DC 上独立测试。
  - 证据：[doi:10.1093/bioadv/vbad191, p.2]
- **results：** 在 BM5 evaluation set 上，DeepRank-GNN-esm-pssm 的 F1 为 0.793、MCC 为 0.776、AUC 为 0.872，均高于原始 DeepRank-GNN。
  - 证据：[doi:10.1093/bioadv/vbad191, p.3]
- **results：** 在 BM5 test set 上，final foldall 模型的 ROC AUC 达到 0.938，且多数子折模型优于原始 DeepRank-GNN。
  - 证据：[doi:10.1093/bioadv/vbad191, p.3]
- **results：** 在 CAPRI score set 上，DeepRank-GNN-esm 的 Top50 success rate 为 69.2%，与 iScore 和 GNN-Dove 持平或更优，且优于原始 DeepRank-GNN 的 61.5%。
  - 证据：[doi:10.1093/bioadv/vbad191, p.4]
- **results：** 在 DC test set 上，DeepRank-GNN-esm-pssm 和 DeepRank-GNN-esm 的 accuracy 都是 0.83，略高于 DeepRank-GNN 的 0.82。
  - 证据：[doi:10.1093/bioadv/vbad191, p.5]

# A deep learning method for drug-target affinity prediction based on sequence interaction information mining

- **论文 ID：** `EVIW-643B1E1D6A4DC185`
- **期刊 / 来源：** PeerJ
- **发表时间：** 2023 Dec 11

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `数据集/基准`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出 KC-DTA：把蛋白序列分别编码成基于 k-mers 的 3D matrix 与基于 Cartesian product 的 2D matrix，再与分子图的 GNN 表征一起融合，最终用于 affinity 回归预测。[doi:10.7717/peerj.16625, p.4][doi:10.7717/peerj.16625, p.7]

## 创新边界

`其主要新意在序列特征编码与多分支网络组合；论文没有做候选分子的生成、优化或 docking，而是做 DTA 的属性预测，因此更符合 accepted_transfer 的范围。[doi:10.7717/peerj.16625, p.1][doi:10.7717/peerj.16625, p.7]`。这不是全球首创性检索或独立复现结论。

## 研究问题

该文要解决的是：在不依赖蛋白三维结构、又尽量避免湿实验成本的前提下，用蛋白序列与分子表示来更准确地预测 drug-target affinity (DTA)，以支持虚拟筛选与药物发现流程。[doi:10.7717/peerj.16625, p.1]

## 方法

- 蛋白k-mer共现矩阵与进化矩阵输入双CNN，分子图经GNN，融合回归affinity。

## 数据与基准

- Davis、KIBA、Metz、PDBBind refined。

## 比较基线

- DeepDTA、WideDTA、GraphDTA、MDeePred等。

## 结果证据

- 论文报告多数据集和指标上高性能/超过所选SOTA；均为回顾性affinity预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- k-mer Cartesian矩阵随序列/词表增大；随机拆分可能共享蛋白/化学空间，无实验验证。

## 仍未知

- 未见独立外部数据集上的复现实验。
- 未看到完整训练超参数与早停细节的全部展开。
- Metz 和 PDBBind 的部分对比结果存在跨论文可比性限制。

## Pi 结构化证据摘录

- **baseline：** Davis/KIBA 对比基线包括 KronRLS、SimBoost、DeepCPI、DeepDTA、GANsDTA、MPS2IT-DTI 和 WideDTA。[doi:10.7717/peerj.16625, p.13]
  - 证据：[doi:10.7717/peerj.16625, p.13]
- **baseline：** Metz 对比基线包括 GraphDTA 的多种变体、RF、SVM、FNN、MGraphDTA 和 DeepDTA。[doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.15]
- **baseline：** PDBBind refined 对比基线包括 MoleculeNet、Affinity2Vec 和 MDeePred。[doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.15]
- **data：** Davis 数据集包含 68 个 inhibitors、442 个 protein kinases 和 30,056 个 binding entities；论文还将其 affinity 转成 pKd 形式评估。[doi:10.7717/peerj.16625, p.9][doi:10.7717/peerj.16625, p.10]
  - 证据：[doi:10.7717/peerj.16625, p.9]；[doi:10.7717/peerj.16625, p.10]
- **data：** KIBA 数据集由 229 个 proteins、2,111 个 small molecules 和 118,254 个 binding entities 组成。[doi:10.7717/peerj.16625, p.9]
  - 证据：[doi:10.7717/peerj.16625, p.9]
- **data：** Metz 数据集在文中被整理为 1,423 个 small molecules、170 个 proteins 和 35,259 个 binding entries。[doi:10.7717/peerj.16625, p.10]
  - 证据：[doi:10.7717/peerj.16625, p.10]
- **data：** PDBBind refined (v.2015) 数据集用于额外评估，共 3,047 对 protein-molecule pairs；作者还说明其按年份划分为训练、验证和测试集。[doi:10.7717/peerj.16625, p.10][doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.10]；[doi:10.7717/peerj.16625, p.15]
- **declared_resources：** 作者声明代码与数据可在 GitHub 的 KCDTA 仓库获取；摘要页也直接给出了仓库地址。[doi:10.7717/peerj.16625, p.1][doi:10.7717/peerj.16625, p.17]
  - 证据：[doi:10.7717/peerj.16625, p.1]；[doi:10.7717/peerj.16625, p.17]
- **declared_resources：** 实验环境使用 PyTorch 2.0.0、Ubuntu、128 GB 内存、两张 NVIDIA GeForce RTX 4090 和 CUDA 11.8。[doi:10.7717/peerj.16625, p.10]
  - 证据：[doi:10.7717/peerj.16625, p.10]
- **declared_resources：** 数据来源还明确指向 DeepDTA、PADME 和 MDeePred 的 GitHub 仓库，说明部分 benchmark 数据来自既有公开资源。[doi:10.7717/peerj.16625, p.17]
  - 证据：[doi:10.7717/peerj.16625, p.17]
- **limitations：** 作者明确承认该方法尚未应用到实际案例，因此对更大数据集或更复杂场景的有效性仍未被验证。[doi:10.7717/peerj.16625, p.16]
  - 证据：[doi:10.7717/peerj.16625, p.16]
- **limitations：** 在 PDBBind refined 上，训练集只有 2,188 个样本，作者认为数据量有限可能限制模型充分拟合。[doi:10.7717/peerj.16625, p.16]
  - 证据：[doi:10.7717/peerj.16625, p.16]
- **limitations：** Metz 与 PDBBind 的部分对比数值来自相关论文而非同一代码重跑，跨论文可比性仍有不确定性。[doi:10.7717/peerj.16625, p.14][doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.14]；[doi:10.7717/peerj.16625, p.15]
- **method：** 蛋白序列先做 k=3 的 k-mers 分割，再把等价三肽的出现次数映射为 3D matrix，以保留局部片段与部分进化信息。[doi:10.7717/peerj.16625, p.4][doi:10.7717/peerj.16625, p.5]
  - 证据：[doi:10.7717/peerj.16625, p.4]；[doi:10.7717/peerj.16625, p.5]
- **method：** 同一蛋白还会做 Cartesian product 计数，并映射成有序二肽的 2D matrix，用来补充更远距离残基关系。[doi:10.7717/peerj.16625, p.5][doi:10.7717/peerj.16625, p.6]
  - 证据：[doi:10.7717/peerj.16625, p.5]；[doi:10.7717/peerj.16625, p.6]
- **method：** 分子由 SMILES 经 RDKit 转成 atom-node / bond-edge graph，随后分别尝试 GCN、GAT、GIN 作为图特征提取器，并在其后接 batch normalization 与 pooling。[doi:10.7717/peerj.16625, p.6][doi:10.7717/peerj.16625, p.7][doi:10.7717/peerj.16625, p.8][doi:10.7717/peerj.16625, p.9]
  - 证据：[doi:10.7717/peerj.16625, p.6]；[doi:10.7717/peerj.16625, p.7]；[doi:10.7717/peerj.16625, p.8]；[doi:10.7717/peerj.16625, p.9]
- **method：** 3D CNN、2D CNN 和 GNN 提取出的隐藏特征最后被拼接，再送入 fully connected network 输出 binding affinity。[doi:10.7717/peerj.16625, p.7]
  - 证据：[doi:10.7717/peerj.16625, p.7]
- **results：** 在 Davis 与 KIBA 的 5-fold cross-validation 中，KC-DTA 在 CI、MSE、r2m 上整体优于对比方法；在 KIBA 上相对 WideDTA 的 CI 提升 1.71%，MSE 提升 20.1%，r2m 相对 GANsDTA 提升 12.4%。[doi:10.7717/peerj.16625, p.13]
  - 证据：[doi:10.7717/peerj.16625, p.13]
- **results：** 消融实验表明，protein 的 2D+3D 表征通常优于单独 2D 或 3D，作者因此选择 2D+3D+GCN 作为后续主模型。[doi:10.7717/peerj.16625, p.12]
  - 证据：[doi:10.7717/peerj.16625, p.12]
- **results：** 在 Metz 数据集上，KC-DTA 的 MSE 最好，为 0.258，但 CI 与 r2m 略低于最优方法。[doi:10.7717/peerj.16625, p.14][doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.14]；[doi:10.7717/peerj.16625, p.15]
- **results：** 在 PDBBind refined 上，KC-DTA 的 RMSE 约比 MDeePred 低 3.8%，但整体仍略逊于 Affinity2Vec。[doi:10.7717/peerj.16625, p.15]
  - 证据：[doi:10.7717/peerj.16625, p.15]

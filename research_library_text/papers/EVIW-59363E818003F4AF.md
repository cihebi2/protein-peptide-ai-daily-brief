# Mutual annotation-based prediction of protein domain functions with Domain2GO

- **论文 ID：** `EVIW-59363E818003F4AF`
- **期刊 / 来源：** Protein Sci
- **发表时间：** 2024 May 16
- **DOI：** [10.1002/pro.4988](https://doi.org/10.1002/pro.4988)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 Domain2GO：先从结构域与GO术语的共注释模式中学习域-功能映射，再用这些映射为未注释蛋白生成功能预测，同时强调其可解释性和较低的计算开销。

## 创新边界

`新意主要在于把已有的 InterPro/GO 注释组合成统计化、可筛选的域-功能映射流程；它不是湿实验发现，也没有在冻结材料内被独立证明为全局最优。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在实验注释稀缺的背景下，作者试图利用蛋白结构域与GO注释的共现关系，建立一种可解释、低计算成本的 domain-function 预测框架，并进一步把域级关系传播到蛋白级功能预测。

## 方法

- 从已注释蛋白统计domain-GO共现，交替更新domain功能与蛋白功能概率，并输出可解释映射。

## 数据与基准

- InterPro、UniProt/GO与CAFA3目标；最终26,696个domain-GO关联，覆盖4,742 domains和11,742 GO。

## 比较基线

- CAFA3顶级方法、同源/domain转移和深度混合模型。

## 结果证据

- 论文报告MF/BP有竞争力且计算成本极低，但cellular component和CAFA full-mode低于SOTA。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 无法覆盖没有已知domain的蛋白，domain注释错误会传播；CC与full-mode表现弱，GO标签不完整。

## 仍未知

- GitHub 仓库中的实现细节与论文描述是否完全一致，冻结材料内无法独立复核。
- HuggingFace 在线工具的实时可用性、延迟和输入边界未在冻结材料内验证。
- E score 在全量映射上的实际收益与可扩展性仍受计算成本限制，完整外部复验缺失。

## Pi 结构化证据摘录

- **baseline：** 作者将 Naive 和 BLAST 作为 baseline；Naive 为每个输入蛋白分配所有 GO terms，并用术语频率打分，BLAST 按 CAFA3 方案构建。
  - 证据：[doi:10.1002/pro.4988, p.17]
- **baseline：** 对照模型还包括 2016/09 版 InterPro2GO 和 DomFun；前者是手工 curated、分值固定为 1，后者基于 CATH-Gene3D 与 tripartite network analysis。
  - 证据：[doi:10.1002/pro.4988, p.18]
- **baseline：** 作者另外把 CAFA3 的 top-performing methods 以及多种 hybrid 组合（例如 S_E_IPR2GO、S_E_BLAST、S_E_IPR2GO_BLAST）纳入比较。
  - 证据：[doi:10.1002/pro.4988, p.8]；[doi:10.1002/pro.4988, p.11]
- **data：** 结构域数据来自 InterPro v85.0；筛掉非 domain 条目后，作者保留了 11,233 个 InterPro domain entries 和 222,753,705 条域-蛋白注释。
  - 证据：[doi:10.1002/pro.4988, p.15]
- **data：** 功能注释来自 UniProt-GOA v193，仅保留 manual 和 experimental evidence codes，并向父项传播后得到 6,998,018 条注释、125,309 个蛋白和 30,959 个 GO terms。
  - 证据：[doi:10.1002/pro.4988, p.15]
- **data：** 蛋白级评测使用 CAFA3 benchmark，并对齐到挑战时间线；作者还使用 no-knowledge benchmark 来避免数据泄漏。
  - 证据：[doi:10.1002/pro.4988, p.8]；[doi:10.1002/pro.4988, p.18]
- **declared_resources：** 作者声明源码、datasets、results 和 user instructions 已公开在 GitHub repo `HUBioDataLab/Domain2GO`，并提供 HuggingFace Space 在线工具。
  - 证据：[doi:10.1002/pro.4988, p.1]；[doi:10.1002/pro.4988, p.13]；[doi:10.1002/pro.4988, p.19]
- **declared_resources：** 作者还发布了最终 protein function prediction set：对 UniProtKB/Swiss-Prot 2022_01 的 291,519 个 proteins 生成了 5,046,060 条 GO predictions。
  - 证据：[doi:10.1002/pro.4988, p.14]
- **limitations：** 作者明确指出 CCO 类别表现较弱，因为结构域与蛋白定位/localization 的关系更难建模。
  - 证据：[doi:10.1002/pro.4988, p.9]；[doi:10.1002/pro.4988, p.14]
- **limitations：** 方法 coverage 很低，原因包括部分蛋白没有 domain annotations，以及阈值筛选导致可预测蛋白集合缩小。
  - 证据：[doi:10.1002/pro.4988, p.8]；[doi:10.1002/pro.4988, p.14]
- **limitations：** E score 的计算代价极高；作者估计若在完整初始集合上逐对重跑 EM，单核普通电脑需要约 2272 天，因此只能在子集上比较。
  - 证据：[doi:10.1002/pro.4988, p.5]
- **method：** 作者用 UniProtKB-InterPro 域注释和 UniProt-GOA 功能注释按 UniProt ID 配对，生成初始 domain-GO 映射，并以 co-occurrence similarity S = 2N_di,GOj/(N_di+N_GOj) 衡量共注释强度。
  - 证据：[doi:10.1002/pro.4988, p.15]
- **method：** 随后作者用随机打乱后的映射分布配合 Kolmogorov-Smirnov test 选阈值，最终采用 n≥2 且 S>0.2 过滤不可靠映射。
  - 证据：[doi:10.1002/pro.4988, p.5]；[doi:10.1002/pro.4988, p.16]
- **method：** 第二步再用 EM 估计 θ，并通过 likelihood ratio test 计算 E score；作者还用 ablation study 比较 S、θi、θ 和 E 的排序效果。
  - 证据：[doi:10.1002/pro.4988, p.5]；[doi:10.1002/pro.4988, p.16]；[doi:10.1002/pro.4988, p.17]
- **results：** 初始/raw mappings 共 2,069,796 个；经筛选后得到 26,696 个 finalized associations，覆盖 4,742 个 domains 和 11,742 个 GO terms。
  - 证据：[doi:10.1002/pro.4988, p.4]；[doi:10.1002/pro.4988, p.5]
- **results：** 与 InterPro2GO 对照时，Domain2GO 追回了 737/5881 条人工注释，并且能给部分 domain 提供更具体、甚至新增的 CCO 关联。
  - 证据：[doi:10.1002/pro.4988, p.6]；[doi:10.1002/pro.4988, p.7]
- **results：** 在方法消融中，S 在 top 100 的 manual-association enrichment 达到 19-fold，而 θi 基本没有显著富集，说明简单共现筛选在这份数据上很强。
  - 证据：[doi:10.1002/pro.4988, p.5]
- **results：** 在 CAFA3 partial-mode 下，Domain2GO-E 与 Domain2GO-S 在 MF/BP 上分别达到 0.68/0.63 和 0.49/0.46 的 Fmax，优于 baseline 和 DomFun。
  - 证据：[doi:10.1002/pro.4988, p.9]
- **results：** 在 full-mode 下，Domain2GO 受到 coverage 限制，整体不及顶级 CAFA3 模型，但仍在 MF/BP 上优于 baseline 方法。
  - 证据：[doi:10.1002/pro.4988, p.9]；[doi:10.1002/pro.4988, p.11]

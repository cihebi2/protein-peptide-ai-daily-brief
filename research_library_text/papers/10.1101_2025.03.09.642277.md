# Benchmarking AlphaFold3-like Methods for Protein-Peptide Complex Prediction

## 研究问题

AF3 及其复现模型（Chai-1、Boltz-1、Protenix）在蛋白-蛋白相互作用上已证明显著优于 AF2-multimer，但其在蛋白-短肽复合物预测上的系统性表现未评估。论文在蛋白-短肽基准上对比新旧两代方法并探索多模型组合与选择策略。

## 作者主张的贡献

在文献基准集上系统对比 AF3、Chai-1（±MSA）、Boltz-1、Protenix 与 AF2-multimer 的蛋白-短肽预测：严格标准（Fnat≥0.8）成功率从 AF2m 的 53% 提升至 70-80%（Protenix 最高 80.8% 超 AF3 76.8%）；AF3+Protenix 等多模型组合将高质量预测成功率推至 89%，中等标准（Fnat≥0.5）覆盖 97%；发现模型间一致性（inter-model consistency）是选择最佳预测的有效指标；识别失败模式（环肽被当线性肽、多结合位点、无口袋棒状受体）。

## 创新边界

纯基准评测论文，无新方法；基准集取自文献[22]而非自建；AF3-like 模型评测已有 PoseBusters/FoldBench 等更系统的框架，本文差异化仅在'短肽'这一子域；多模型集成提升与一致性选优的思想在蛋白-蛋白领域已有先例。

## 创新点证据卡

- **[p3]** AF3-like 模型在蛋白-短肽复合物上把严格成功率从 53% 提到 70-80%，Protenix 80.8% 超 AF3
  - 原文："Protenix showed the best performance with an accuracy of 80.8%, even surpassing AF3 which achieved 76.8%"
- **[p1]** 多模型组合（如 AF3+Protenix）将高质量预测成功率推至 89%、中等标准覆盖 97%
  - 原文："A multi-method combination strategy ... enabled a high-quality prediction success rate of 89%"
- **[p1]** 模型间一致性可作为选择最佳预测的有效指标，优于常规 pLDDT/ipTM 等
  - 原文："inter-model consistency analysis provided an efficient metric for selecting optimal predictions"
- **[p6]** 识别关键失败模式：环肽按线性处理、多结合位点受体、无口袋棒状蛋白
  - 原文："MaL6 is actually a cyclic peptide linked via a disulfide bond ... yet we treated it as a linear peptide"

## 方法

- 对基准蛋白-短肽复合物分别跑 AF3、Chai-1（含/不含 MSA）、Boltz-1、Protenix、AF2m
- Fnat 评估（5Å 重原子接触），分级：High≥0.8 / Medium≥0.5 / Acceptable≥0.3（CAPRI 体系）
- 多模型组合策略：聚合所有方法的预测取最优
- 模型间一致性分析作为预测选择指标（对比 pLDDT/ipTM/RMSD/#PPI）
- 代表案例与失败案例结构分析

## 数据与基准

- 蛋白-短肽复合物基准测试集（来自文献[22]）
- 案例：Munc13-1(6A30)、MMP-2(3AYU)、rhomboid(6PJ8)、核糖体失活蛋白(3N2D)、MATE 转运体(3WBN)、PL2(5A29)

## 结果证据

- Fnat≥0.8 成功率：Protenix 80.8% > AF3 76.8% > Chai-1 w/MSA 78.8% > Chai-1 w/o MSA 70.7% ≈ Boltz-1 71.7% >> AF2m 53%
- Fnat≥0.5：85-90%（AF3 最高 89.9%）
- Fnat≥0.3+MSA：~90%
- 多模型组合：High 89%、Medium 97%、Acceptable 98%（理论上限）
- 失败模式：环肽线性化处理导致全错（3WBN）、多结合位点（MATE）、无口袋伸长受体（3N2D 全失败）
- Chai-1 无 MSA 时效率优势明显且性能可比

## 比较基线

- AF2-multimer（前代）
- AF3/Chai-1/Boltz-1/Protenix（同代互比）

## 已知限制

- 基准规模未明确披露（沿用文献集）
- 未含 AutoDock-CrankPep/HADDOCK 等肽专用传统方法对比
- 环肽未按环化处理是评估缺陷
- MSA 影响只在 Chai-1 上系统测试

- 一致性指标的定义与量化细节

# Predicting protein–carbohydrate binding sites: a deep learning approach integrating protein language model embeddings and structural features

- **论文 ID：** `EVIW-2B57DB63EFE65586`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2026 Jan 29
- **DOI：** [10.1093/bib/bbag008](https://doi.org/10.1093/bib/bbag008)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出 DeepCPBSite：一个结合 ProtT5-XL-U50/ESM-2/结构特征与 ResNet+FNN 集成的位点预测模型，并通过多源数据集、特征选择、不平衡学习和 SHAP 可解释性分析，在多个 benchmark 上优于现有方法。

## 创新边界

`创新主要在于多源特征融合与不平衡集成分类器；它是 prediction/annotation 任务，不是候选分子的生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

面向非共价 protein–carbohydrate binding site 的残基级预测，目标是在无需昂贵实验测定的情况下识别结合位点，为后续功能注释和设计提供计算支持。

## 方法

- 结合PLM嵌入、结构特征和多种不平衡处理，比较RCSB/UniProt/CASP域。

## 数据与基准

- RCSB、UniProt、CASP三来源数据，TS53等独立测试。

## 比较基线

- DeepGlycanSite等SOTA及不同不平衡/特征方案。

## 结果证据

- TS53 balanced accuracy 78.7%、sensitivity 59.6%，F1/MCC/AUPR较基线提高；仍有多个binding sites漏检。

- domain adaptation仍困难，预测结构误差会传播；作者建议hybrid/UQ。

## Pi 结构化证据摘录

- **baseline：** 与 DeepGlycanSite 相比，DeepCPBSite 在 TS53 上的 BACC/F1/MCC/AUPR 均更高，作者报告的增益在 experimental 与 ESMFold 两种输入下分别达到 BACC +1.16/+1.84、F1 +3.77/+4.64、MCC +3.84/+5.20、AUPR +8.43/+15.84 个百分点。
  - 证据：[doi:10.1093/bib/bbag008, p.13]；[doi:10.1093/bib/bbag008, p.17]
- **baseline：** 与 CAPSIF:V/G 和 PS-G/S 相比，DeepCPBSite 在 TS53 与 TS14 上总体更均衡；PS-G 虽然 SN 较高，但 precision 太低，导致 F1/MCC 受限。
  - 证据：[doi:10.1093/bib/bbag008, p.17]
- **baseline：** 与 10 个传统分类器相比，FNN/ResNet+FNN 在 AUPR 和 AUC 上优于 XGB、ET、RF、SVM、MLP 等传统基线。
  - 证据：[doi:10.1093/bib/bbag008, p.9]；[doi:10.1093/bib/bbag008, p.10]
- **data：** RCSB 数据集最终形成 622 条训练链和 152 条独立测试链，并在总计 332341 个残基中标注了 8498 个阳性位点与 305519 个阴性位点。
  - 证据：[doi:10.1093/bib/bbag008, p.3]；[doi:10.1093/bib/bbag008, p.4]
- **data：** TS53、TS37、TS14 分别由 53、37、14 条独立链构成，分别对应 649/24276、409/15458、74/5349 的正负位点划分。
  - 证据：[doi:10.1093/bib/bbag008, p.3]；[doi:10.1093/bib/bbag008, p.4]；[doi:10.1093/bib/bbag008, p.12]；[doi:10.1093/bib/bbag008, p.14]
- **data：** 训练与验证实验还对平衡后的 independent set 与 TS37 做了 20 次重复抽样评估，以检查结果稳定性。
  - 证据：[doi:10.1093/bib/bbag008, p.14]
- **data：** 结构特征既来自实验结构，也来自 AlphaFold 与 ESMFold 预测结构，用于比较推断时结构输入的差异。
  - 证据：[doi:10.1093/bib/bbag008, p.1]；[doi:10.1093/bib/bbag008, p.12]
- **declared_resources：** 作者公开了复现脚本和数据集于 GitHub 仓库 https://github.com/nafcoder/DeepCPBSite。
  - 证据：[doi:10.1093/bib/bbag008, p.21]；[doi:10.1093/bib/bbag008, p.23]
- **declared_resources：** 数据资源主要来自 RCSB、UniProt、CASP；结构/embedding 资源来自 AlphaFold、ESMFold、ProtTrans、ESM-2、ProteinBERT 和 TAPE。
  - 证据：[doi:10.1093/bib/bbag008, p.3]；[doi:10.1093/bib/bbag008, p.4]；[doi:10.1093/bib/bbag008, p.5]；[doi:10.1093/bib/bbag008, p.12]
- **declared_resources：** 物种分类分析还借助 NCBI taxonomy 和 GBIF 完成。
  - 证据：[doi:10.1093/bib/bbag008, p.14]；[doi:10.1093/bib/bbag008, p.24]
- **limitations：** 作者明确指出，测试蛋白可能已进入 AlphaFold/ESMFold 的预训练或相关数据库，可能抬高评估结果。
  - 证据：[doi:10.1093/bib/bbag008, p.21]
- **limitations：** 模型在 orphan proteins、稀缺同源序列和 unusual folds 上的泛化仍不确定，尤其是 Archaea/Fungi 这类域偏移场景。
  - 证据：[doi:10.1093/bib/bbag008, p.14]；[doi:10.1093/bib/bbag008, p.20]；[doi:10.1093/bib/bbag008, p.21]
- **limitations：** 由于训练集排除了 glycosylation 相关复合物，模型可能不适用于这类场景。
  - 证据：[doi:10.1093/bib/bbag008, p.21]
- **method：** 作者从 RCSB、UniProt 和 CASP 构建训练集与独立测试集，并通过 30% 序列相似性阈值、fold-level homology 过滤以及对非标准氨基酸和 glycosylation 相关条目的排除来去冗余。
  - 证据：[doi:10.1093/bib/bbag008, p.3]；[doi:10.1093/bib/bbag008, p.4]
- **method：** 特征端同时使用 PSSM、DPC、Monogram、PHYSICO、ProtTrans/ESM-2/ProteinBERT/TAPE 的 per-residue embeddings、DSSP 结构特征以及 31-residue word embedding 窗口。
  - 证据：[doi:10.1093/bib/bbag008, p.4]；[doi:10.1093/bib/bbag008, p.5]
- **method：** 特征选择先做 Yeo-Johnson 变换，再用 IFS、RFE(XGB) 和 Elastic Net 比较 top feature groups，三种方法都收敛到同一组核心特征。
  - 证据：[doi:10.1093/bib/bbag008, p.5]；[doi:10.1093/bib/bbag008, p.9]
- **method：** 最终模型采用双分支 ResNet+FNN：ResNet 分支处理 word embedding 的局部邻域模式，FNN 分支处理最优特征集；输出再融合为二分类概率。
  - 证据：[doi:10.1093/bib/bbag008, p.6]；[doi:10.1093/bib/bbag008, p.7]；[doi:10.1093/bib/bbag008, p.10]
- **method：** 作者比较了 random undersampling、weighted oversampling、class-weighted loss、SMOTE 和 ADASYN，最后用 MRU、MWO、MCWL 三个子模型做加权平均集成。
  - 证据：[doi:10.1093/bib/bbag008, p.6]；[doi:10.1093/bib/bbag008, p.10]；[doi:10.1093/bib/bbag008, p.11]
- **method：** 为解释模型，作者对结构特征、ResNet 邻域窗口和样本分离效果分别做了 SHAP 与 t-SNE 分析。
  - 证据：[doi:10.1093/bib/bbag008, p.11]；[doi:10.1093/bib/bbag008, p.14]；[doi:10.1093/bib/bbag008, p.18]
- **results：** 在 embedding 选择上，ProtT5-XL-U50 表现最好，ESM-2 次优；窗口平均会削弱两者的性能。
  - 证据：[doi:10.1093/bib/bbag008, p.8]
- **results：** 在 top five feature groups 中，最终保留的是 ProtT5-XL-U50、Structural、ESM-2；PSSM 和 DPC 也位列靠前。
  - 证据：[doi:10.1093/bib/bbag008, p.8]；[doi:10.1093/bib/bbag008, p.9]
- **results：** 在传统 ML 对比中，SVM 在 top feature groups 上最好，而 FNN 在 AUPR 和 AUC 上超过 10 个传统分类器。
  - 证据：[doi:10.1093/bib/bbag008, p.9]；[doi:10.1093/bib/bbag008, p.10]
- **results：** ResNet+FNN 在验证集上优于纯 FNN 和 Transformer+FNN，因此被选为最终 DL 架构。
  - 证据：[doi:10.1093/bib/bbag008, p.10]
- **results：** DeepCPBSite 在 TS53（实验结构）上达到 BACC 0.787、F1 0.496、MCC 0.487、AUPR 0.463；使用 ESMFold 时分别为 0.775、0.474、0.465、0.446。
  - 证据：[doi:10.1093/bib/bbag008, p.13]；[doi:10.1093/bib/bbag008, p.17]
- **results：** 在独立集上，DeepCPBSite 达到 BACC 0.768、F1 0.467、MCC 0.456、AUPR 0.427，说明其在内部留出集上仍保持较稳健表现。
  - 证据：[doi:10.1093/bib/bbag008, p.12]
- **results：** 在 TS14 上，模型仍取得 AUC 0.843、AUPR 0.176、F1 0.209、MCC 0.200，显示 domain-shift 下仍有一定可用性。
  - 证据：[doi:10.1093/bib/bbag008, p.17]
- **results：** 案例研究显示 DeepCPBSite 在 7EE4 和 6WWX 上正确识别了其它方法漏掉的多个位点。
  - 证据：[doi:10.1093/bib/bbag008, p.19]；[doi:10.1093/bib/bbag008, p.22]

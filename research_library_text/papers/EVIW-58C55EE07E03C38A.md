# A Point Cloud Graph Neural Network for Protein–Ligand Binding Site Prediction

- **论文 ID：** `EVIW-58C55EE07E03C38A`
- **期刊 / 来源：** Int J Mol Sci
- **发表时间：** 2024 Aug 27
- **DOI：** [10.3390/ijms25179280](https://doi.org/10.3390/ijms25179280)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `图与几何学习`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 PGpocket，一个面向 protein–ligand binding site prediction 的 geometric deep learning 框架：将蛋白表面转为 point cloud，提取几何与化学特征，构建 point cloud graph，并用 PointGNN 风格的 GNN、downsampling 与 auto-alignment 来预测 binding sites。[doi:10.3390/ijms25179280, p.3]

## 创新边界

`其主要新意在于把蛋白表面点云与图神经网络组合用于 binding site 预测；但文中也明确借鉴了 MaSIF、PointGNN 等已有思路，且未涉及候选分子生成、对接优化或湿实验验证。[doi:10.3390/ijms25179280, p.11][doi:10.3390/ijms25179280, p.12][doi:10.3390/ijms25179280, p.13][doi:10.3390/ijms25179280, p.15]`。这不是全球首创性检索或独立复现结论。

## 研究问题

论文聚焦于蛋白质–配体 binding site 预测：在已知蛋白三维结构中，准确定位可结合小分子或配体的口袋/凹槽，以服务于药物发现、机制解析与结构生物学研究。[doi:10.3390/ijms25179280, p.1]

## 方法

- 提取表面点/几何化学特征，按距离建图，point-cloud GNN输出pocket。

## 数据与基准

- scPDB训练，Coach420/HOLO4K独立测试。

## 比较基线

- Kalasanty等pocket方法。

## 结果证据

- success rate 58%/56%；为计算pocket预测。

## Pi 结构化证据摘录

- **baseline：** 主要对比对象是 COACH、Kalasanty、PUResNet 和 P2Rank；其中 COACH 先输出 binding residues，再被转换为 surface-level 口袋评估，因此比较并不完全同口径。
  - 证据：[doi:10.3390/ijms25179280, p.6]；[doi:10.3390/ijms25179280, p.7]；[doi:10.3390/ijms25179280, p.14]
- **baseline：** COACH、Kalasanty、PUResNet 与 P2Rank 的方法定位分别来自序列/模板比较、U-Net 3D mesh、3D image ResNet，以及基于表面点与随机森林的 ligandicity 预测。
  - 证据：[doi:10.3390/ijms25179280, p.14]
- **baseline：** 作者还明确指出，本工作中的 F1 定义来自 PUResNet 的 pocket-level 口径，与 COACH 的 amino-acid-level F1 不可直接比较。
  - 证据：[doi:10.3390/ijms25179280, p.4]；[doi:10.3390/ijms25179280, p.5]
- **data：** 训练与验证使用 PUResNet 采用的 scPDB 子集：原始 5020 个 protein–ligand complex，剔除无法 point-cloud 化的样本后得到 4895 个复合物。
  - 证据：[doi:10.3390/ijms25179280, p.11]
- **data：** 作者按 protein family 将数据以 8:1:1 划分为训练集、验证集和测试集，以减少 data leakage。
  - 证据：[doi:10.3390/ijms25179280, p.11]
- **data：** 独立测试集包括去冗余后的 Coach420（保留 298 个复合物）和 HOLO4K（保留 4055 个复合物）。
  - 证据：[doi:10.3390/ijms25179280, p.11]
- **data：** 文中采用 surface-level binding-site 定义，并用 DCC 与 DVO 作为主要评价指标；DCC 小于等于 4 Å 视为成功。
  - 证据：[doi:10.3390/ijms25179280, p.4]；[doi:10.3390/ijms25179280, p.5]
- **declared_resources：** 论文给出了 GitHub 源码地址 https://github.com/zhaoyanpeng208/PGpocket，并在 Data Availability 中再次声明 datasets 和 code 可用。
  - 证据：[doi:10.3390/ijms25179280, p.3]；[doi:10.3390/ijms25179280, p.15]
- **limitations：** 论文当前只给出 binding site 位置，不提供具体参与结合的 amino acids；作者把可解释性与残基级预测列为未来工作。
  - 证据：[doi:10.3390/ijms25179280, p.15]
- **limitations：** downsampling 虽然降低了计算时间，但也带来一定性能损失；全点云模型更准但更慢。
  - 证据：[doi:10.3390/ijms25179280, p.10]
- **limitations：** 在 HOLO4K 上，PGpocket 的 DVO 低于 P2Rank，说明其优势更集中在 success rate 而非所有指标上。
  - 证据：[doi:10.3390/ijms25179280, p.8]
- **limitations：** 与 COACH 的对比受 residue-level 到 surface-level 转换影响，文中也承认这可能引入额外误差。
  - 证据：[doi:10.3390/ijms25179280, p.6]；[doi:10.3390/ijms25179280, p.7]
- **method：** 先用 MaSIF 风格的表面表示把蛋白质结构离散为点云，并为每个点拼接化学特征与几何特征，最终形成 16 维点表示。
  - 证据：[doi:10.3390/ijms25179280, p.11]；[doi:10.3390/ijms25179280, p.12]
- **method：** 图构建采用固定半径邻接，文中设定 graph radius r=4 Å；同时用 voxel-downsampling 降低点云密度，并用 r0=2 Å 的局部聚合保留原始点云信息。
  - 证据：[doi:10.3390/ijms25179280, p.12]；[doi:10.3390/ijms25179280, p.13]
- **method：** GNN 部分迭代三层，利用相对坐标与 MLP 更新节点表示，并通过 auto-alignment 缓解平移敏感性，随后对每个点输出 binding-site 概率。
  - 证据：[doi:10.3390/ijms25179280, p.12]；[doi:10.3390/ijms25179280, p.13]
- **method：** 预测阶段使用 OPTICS 将高概率点聚成 pocket，再按簇内概率和排序，并按真实 binding site 数量取 top-n 进行 DCC/DVO 评估。
  - 证据：[doi:10.3390/ijms25179280, p.13]；[doi:10.3390/ijms25179280, p.4]；[doi:10.3390/ijms25179280, p.5]
- **method：** 训练实现基于 Python 3.8、PyTorch 2.1.0，批大小为 4，Adam 学习率 5e-4，weight decay 1e-5，最多训练 50 epochs。
  - 证据：[doi:10.3390/ijms25179280, p.13]
- **results：** 在 scPDB 测试集上，PGpocket 识别 350 个 binding sites、漏检 13 个，success rate 为 66.2%，平均 DVO 为 0.65，优于 COACH、Kalasanty、PUResNet 和 P2Rank。
  - 证据：[doi:10.3390/ijms25179280, p.6]
- **results：** 在 Coach420 上，PGpocket 的 success rate 为 57.8%，平均 DVO 为 0.35，F1-score 为 0.733，是该页报告中的最佳结果。
  - 证据：[doi:10.3390/ijms25179280, p.8]
- **results：** 在 HOLO4K 上，PGpocket 的 success rate 为 56.3%，平均 DVO 为 0.24，F1-score 为 0.721；其成功率最高，但 DVO 不是最高。
  - 证据：[doi:10.3390/ijms25179280, p.8]
- **results：** 消融实验显示，全点云模型 F1-score 最高为 0.805，但平均预测时间 25.36 s；downsampling 加 feature aggregation 在速度与精度之间折中，F1-score 为 0.796、平均时间 14.65 s。
  - 证据：[doi:10.3390/ijms25179280, p.10]
- **results：** ATP case study 中，PGpocket 对 2ZHZ、3GPL 和 3H39 都定位到了 ATP binding site，而 Kalasanty 在这三个例子上均未成功预测。
  - 证据：[doi:10.3390/ijms25179280, p.10]

# DTI-LM: language model powered drug-target interaction prediction

- **论文 ID：** `EVIW-1DB0B140C115A6B4`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Sep 2
- **DOI：** [10.1093/bioinformatics/btae533](https://doi.org/10.1093/bioinformatics/btae533)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 DTI-LM：先用 ESM-2 与 ChemBERTa 生成序列编码，再用基于相似度的 GAT 融合邻域信息，最后用 MLP 预测二分类 DTI；同时系统分析了语言模型在蛋白与药物冷启动中的差异与瓶颈。

## 创新边界

`其主要新意是把 pretrained LM 表示与邻域图注意力结合到 DTI prediction；论文主要提供 benchmark 分类与相似性分析，没有把任务扩展为候选分子/蛋白生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在只依赖药物 SMILES 与蛋白 amino acid sequences 的前提下，提升 drug–target interaction prediction 的准确率，尤其缓解 warm start 之外的 cold start for drug/protein 问题。

## 方法

- 药物/蛋白序列预训练LM嵌入，已知DTI图GAT聚合邻域，融合分类。

## 数据与基准

- 四个公开DTI benchmark，warm/drug-cold/protein-cold拆分。

## 比较基线

- 序列DTI、知识图谱与图神经模型。

## 结果证据

- 论文报告总体及protein cold-start优势；cold drug仍受化学LM/架构限制。

## Pi 结构化证据摘录

- **baseline：** sequence-based baselines 包括 DeepDTA、DeepDTI、TransDTI、MolTrans，另有 MPNN_CNN 参与部分比较。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]；[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]
- **baseline：** structure-based baseline 是 FragXsiteDTI，并分别在 Predicted 与 Mixed 两种结构来源下评估。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]
- **baseline：** heterogeneous baselines 包括 DTiGEMS+、DTINet、KGE_NFM 和 TriModel；作者还说明部分结果直接复现自 Ye et al. 2021。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]；[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]
- **data：** 实验共使用四个 benchmark datasets：DrugBank、BindingDB、Yamanishi_08 和 Luo’s dataset。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]
- **data：** DrugBank 和 BindingDB 主要用于 sequence-based 比较，而 Yamanishi_08 与 Luo’s dataset 还包含 heterogeneous KG，适合比较 sequence-based 与 heterogeneous methods。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]
- **data：** DrugBank/BindingDB 按 0.79/0.01/0.20 划分训练、验证与测试，并分别评估 warm start、cold start for drug、cold start for protein。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]；[doi:10.1093/bioinformatics/btae533, p.6]
- **data：** BindingDB 的 Kd 数据被阈值化为二分类标签；作者同时报告 balanced 1:1 与 unbalanced 1:10 两种采样设置。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]；[doi:10.1093/bioinformatics/btae533, p.6]
- **declared_resources：** 论文给出 source code 地址：https://github.com/compbiolabucf/DTI-LM。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.1]；[doi:10.1093/bioinformatics/btae533, p.10]
- **declared_resources：** 作者同时声明 Supplementary data 可在线获取，Funding 来自 NSF-III2246796 和 NSF-III2152030。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.9]；[doi:10.1093/bioinformatics/btae533, p.10]
- **limitations：** 模型的主要短板仍是 cold start for drug；在多个 benchmark 上，它在这一设置下仍不如 heterogeneous methods。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]；[doi:10.1093/bioinformatics/btae533, p.9]
- **limitations：** 作者明确承认 Section 3.5 的证据并不 conclusive，因为 Pearson correlation 不能捕捉非线性关系，而 top-5 neighbor support 也只是局部证据。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.9]
- **limitations：** 用 raw sequence-based similarity 去构建 drug GAT 反而更差，说明 SMILES 邻域与 LM encoding 邻域并不等价。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.9]
- **limitations：** 作者把 chemical language model 的表达能力视为瓶颈，并提到更大的 ChemGPT 也观察到类似现象。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.9]
- **method：** 蛋白序列用 ESM-2 编码，作者说明它是 33-layer、650M parameters、输出维度 1280 的 protein language model。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.3]；[doi:10.1093/bioinformatics/btae533, p.4]
- **method：** 药物 SMILES 用 ChemBERTa 编码，作者给出的配置是 6-attention-layer、84M parameters、输出维度 768。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.4]
- **method：** 作者先用 Pearson correlation 构建蛋白与药物的相似度矩阵，再按阈值二值化成 adjacency matrix 供 GAT 做 mask attention。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.4]
- **method：** 最终表示由 GAT embeddings 与 LM encodings 残差相加后拼接，再输入 MLP；训练目标是 binary cross-entropy。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.4]
- **results：** 在 DrugBank 与 BindingDB 上，DTI-LM 在大多数情形都优于 baselines，且 warm start 表现最稳；作者报告的平均提升为 AUROC/AUPRC 3.57%/8.33%、3.84%/6.13%、5.57%/8.93%。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.5]
- **results：** 在 Yamanishi_08 与 Luo’s dataset 上，DTI-LM 不仅超过其他 sequence-based baselines，也在 warm start 与 cold start for protein 上超过多数 heterogeneous baselines。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]
- **results：** 对于 cold start for drug，DTI-LM 仍会落后于部分 heterogeneous data-driven models，但通常优于其他 sequence-based 与 structure-based baselines。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.6]；[doi:10.1093/bioinformatics/btae533, p.7]
- **results：** 作者的相似性与 neighbor-support 分析显示，ESM-2 更能把 protein similarity 映射到有意义的邻域，而 ChemBERTa 对 drug 的 support 更弱，这与蛋白侧冷启动更强、药物侧更弱相一致。
  - 证据：[doi:10.1093/bioinformatics/btae533, p.8]；[doi:10.1093/bioinformatics/btae533, p.9]

# ProteinReDiff: Complex-based ligand-binding proteins redesign by equivariant diffusion-based generative models

- **论文 ID：** `EVIW-A0ED9A9776557B02`
- **期刊 / 来源：** Struct Dyn

## 作者主张的创新点

ProteinReDiff 提出一个基于 equivariant diffusion 的 ligand-binding protein redesign 框架，把 AF2 风格的 SRA、OPU 与 triangle multiplicative updates 融入残差特征更新，并在 sequence 与结构两个域联合去噪，以生成新的蛋白序列及对应复合物构象。

## 创新边界

`创新边界主要是对既有 DPL 框架的模块级增强与训练/特征改造，而不是全新定义 protein-ligand 扩散范式。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在缺少明确 binding pocket 和高分辨率复合物结构时，如何仅凭蛋白序列与 ligand SMILES 重设计 ligand-binding proteins，并同时兼顾亲和力、序列多样性与结构保真。

## 方法

- 蛋白/配体表示分别加噪去噪，残基-原子pair特征经等变更新和AF2启发模块融合，联合输出序列/结构和结合评分。

## 数据与基准

- PDBBind等蛋白-配体复合物与扩展蛋白/配体数据，论文未提供公开完整数据，仅可申请。

## 比较基线

- DPL、ProteinMPNN、CARP及相关蛋白-配体扩散/重设计模型。

## 结果证据

- 论文报告生成质量、结合评分和序列多样性优于所选模型；全部是计算生成/预测，没有合成、表达或结合实验。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 蛋白-配体配对数据有限且多样性不足；未定义/错误binding site与评分器会限制可靠性，缺少实验和公开数据。

## 仍未知

- 未见湿实验或独立功能验证，因而亲和力提升仍是计算代理证据。
- CATH 4.2 没有进入测试集，外部泛化结论主要来自 PDBBind v2020。
- 不同 masking ratio 的表现差异较大，跨数据集稳定性尚不清楚。

## Pi 结构化证据摘录

- **baseline：** 对比对象包括 CARP、MIF、MIF-ST、ESMIF、ProteinMPNN、LigandMPNN、Protein generator 与 DPL；其中 LigandMPNN 需要 binding pocket 信息，而 ProteinReDiff 不需要。
  - 证据：[doi:10.1063/4.0000271, p.9]；[doi:10.1063/4.0000271, p.11]
- **baseline：** 作者把 DPL 作为最接近的先前框架，并说明 ProteinReDiff 通过增加 sequence prediction、SRA/OPU 和改造 loss 来区别于 DPL。
  - 证据：[doi:10.1063/4.0000271, p.2]；[doi:10.1063/4.0000271, p.11]
- **baseline：** 在 affinity 预测表中，ProteinReDiff 的 Pearson 最好，但 TankBind/PSICHIC 在 RMSE、MAE 或 Spearman 上更强，说明其表征更偏向相关性而非全面最优。
  - 证据：[doi:10.1063/4.0000271, p.15]
- **data：** 训练数据来自 PDBBind v2020 与 CATH 4.2；PDBBind 划分为 9430/552/207，CATH 划分为 15261/939，且 CATH 不进入测试集。
  - 证据：[doi:10.1063/4.0000271, p.7]
- **data：** 作者对蛋白按 MMseqs2 聚类并控制相似度，配体按 Morgan fingerprint 的 Tanimoto 相似度聚类；CATH 仅保留少于 400 aa、序列相似度低于 90% 的蛋白。
  - 证据：[doi:10.1063/4.0000271, p.7]
- **data：** 评测阶段用 Omegafold 预测 redesign 后的结构，再用 AutoDock Vina 做 docking，并将结果与原始蛋白和其他设计模型比较。
  - 证据：[doi:10.1063/4.0000271, p.9]
- **declared_resources：** ESM-2 作为预训练 protein language model 用于序列特征；文中称其为 650M 参数、预训练于约 65M UniRef 序列。
  - 证据：[doi:10.1063/4.0000271, p.4]
- **declared_resources：** 评估工具包括 Omegafold、AutoDock Vina、MMseqs2 与 Morgan fingerprints；数据集包括 PDBBind v2020 和 CATH 4.2。
  - 证据：[doi:10.1063/4.0000271, p.7]；[doi:10.1063/4.0000271, p.9]；[doi:10.1063/4.0000271, p.17]；[doi:10.1063/4.0000271, p.18]；[doi:10.1063/4.0000271, p.19]
- **declared_resources：** 作者在 Data Availability 中直接给出 GitHub 仓库 https://github.com/HySonLab/Protein_Redesign。
  - 证据：[doi:10.1063/4.0000271, p.15]；[doi:10.1063/4.0000271, p.19]
- **limitations：** 冻结文本中的评估主要依赖 predicted structure 和 docking score，没有出现湿实验或独立功能验证。
  - 证据：[doi:10.1063/4.0000271, p.9]；[doi:10.1063/4.0000271, p.15]
- **limitations：** CATH 4.2 因缺少对应 ligand 被排除在测试集之外，因此对 apo 结构的 ligand-conditioned 泛化支持有限。
  - 证据：[doi:10.1063/4.0000271, p.7]
- **limitations：** 性能对 masking ratio 很敏感，超过 30% 后结构保真与 LBA 波动明显，方法稳定性还需要更系统验证。
  - 证据：[doi:10.1063/4.0000271, p.10]；[doi:10.1063/4.0000271, p.13]；[doi:10.1063/4.0000271, p.16]
- **method：** 输入端把蛋白序列经 ESM-2 编码，并与 stochastic masking、残基位置编码结合；配体则由原子/键特征、RBF 距离嵌入与时间嵌入组成联合表示。
  - 证据：[doi:10.1063/4.0000271, p.4]；[doi:10.1063/4.0000271, p.5]
- **method：** 残差特征更新由 SRA、OPU 和 triangle multiplicative updates 组成，用来在单表示与双表示之间交换信息并建模蛋白–配体接触。
  - 证据：[doi:10.1063/4.0000271, p.5]；[doi:10.1063/4.0000271, p.6]
- **method：** 扩散解码采用 SE(3) equivariant 的噪声预测器，以距离加权的坐标差向量形成噪声估计，并显式保持旋转/平移等变。
  - 证据：[doi:10.1063/4.0000271, p.6]；[doi:10.1063/4.0000271, p.7]
- **method：** 训练目标是 L = L_WS + L_KL + L_CE，其中分别约束结构去噪、分布匹配和序列分类；数据按 MMseqs2 与 ligand Tanimoto 聚类后划分。
  - 证据：[doi:10.1063/4.0000271, p.7]；[doi:10.1063/4.0000271, p.8]
- **results：** 在主结果表中，ProteinReDiff 的 15% masking 在 LBA 上最好，达到 6.803±0.329 kcal/mol，优于 reference cases 的 5.847±0.263，也高于多数基线。
  - 证据：[doi:10.1063/4.0000271, p.10]
- **results：** 结构保真方面，5% masking 更强：TM score 0.864±0.022、RMSD 3.197±0.470 Å、CO 0.942±0.007；更高 masking 会明显恶化结构指标。
  - 证据：[doi:10.1063/4.0000271, p.10]；[doi:10.1063/4.0000271, p.16]
- **results：** 作者把 15% masking 视为亲和力与保真之间的平衡点，但 sequence diversity 并非该设置下最高，说明多样性、保真和亲和力存在权衡。
  - 证据：[doi:10.1063/4.0000271, p.10]；[doi:10.1063/4.0000271, p.12]；[doi:10.1063/4.0000271, p.16]
- **results：** 在 PDBBind v2020 的辅助 affinity 预测任务上，Input Featurizer embeddings 的 GP 模型取得最高 Pearson 0.721，但不是所有指标都最好。
  - 证据：[doi:10.1063/4.0000271, p.15]

# 3DSMILES-GPT: 3D molecular pocket-based generation with token-only large language model

- **DOI：** [10.1039/d4sc06864e](https://doi.org/10.1039/d4sc06864e)
- **批次：** mass-review-20260916（wave3 多源 OA 补下）/ strict-v2 高分通过（OA 补下全文）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

基于口袋的 3D 分子生成现有方法（GNN 自回归/扩散）常产生无效构型、非物理构象、类药物性差、可合成性低且生成慢；语言模型虽擅长 2D 化学语言但对连续 3D 坐标的表征能力存疑。

## 作者主张的贡献

提出 3DSMILES-GPT：纯 token 的 GPT（transformer decoder）框架，把 2D/3D 分子表示统一为语言表达（原子 3D 坐标编码为 token），先在数千万类药物分子上预训练，再在口袋-配体对数据上微调，引入可拆卸蛋白编码器，并用强化学习优化理化性质；10 个基准指标中 8 个最优：Vina -7.72 保持 SOTA 同时 QED 比最优基线提升 33%（0.76），生成速度 0.45s/分子（最快基线的 3 倍）。

## 创新边界

核心思想（坐标 token 化 + GPT）与 Regression Transformer/Lingo3DMol/xyz-token 等前作同路线，贡献是全维度表示整合与'预训练-微调-RL'三段式工程化；分子量与参考接近避免了大小偏差。多样性(0.89)低于基线（训练约束所致），Vina 领先幅度小(-7.72 vs Lingo3DMol -7.68)；评估仍依赖 Vina/QED/SAS 等代理指标，无湿实验。

## 方法

- 全 token 表示：2D SMILES 与 3D 坐标均作为语言 token 输入 GPT（transformer decoder），统一 2D/3D 信息
- 三段式训练：数千万类药物分子预训练 → 蛋白口袋-配体对微调（口袋表面原子坐标+配体联合输入） → 强化学习优化生物物理/化学性质
- 可拆卸蛋白编码器模块增强口袋信息提取
- 生成时施加 QED 与 logP 约束
- 评估：键长分布 JSD、PoseBusters 物理/化学合理性套件、QuickVina2 结合能、QED/SAS/分子量/多样性、BR（优于参考）比例、真实靶点案例（AKT1、SARS-CoV-2 3CL 等训练集外 4-5 靶）

## 数据与基准

- 预训练：数千万级类药物分子数据集（含 2D+3D）
- 微调：蛋白口袋-配体结构对（PDB 来源，具体规模在未读部分）
- 案例研究：4 个训练/测试集外蛋白靶（AKT1 4gv1、SARS-CoV-2 3CL 等）

## 结果证据

- Table 1：Vina -7.72（超参考分子 -7.45 与全部基线）、QED 0.76（比 Pocket2Mol 0.57 提升约 33%）、SAS 3.07 最优、类药物分子比例 100%、分子量 329.10 最接近参考 332.35
- PoseBusters 多数指标通过率>85-90%，整体优于 Lingo3DMol/TargetDiff（后者个别指标仅 50-70%）；键长 JSD 均衡无短板（0.4-0.6），稀有键（硝基/磺酸基）表现最佳
- BR 比例 53%（Vina 优于参考），高于 Pocket2Mol/TargetDiff 的 48%；BR-QED 0.76、BR-SAS 3.10 保持优势
- 速度 0.45s/分子（V100），为最快基线 Lingo3DMol(1.32s) 的约 3 倍、Pocket2Mol(13.63s) 的 30 倍
- 多样性 0.89 略低于基线（性质约束的代价）
- 可直接生成物理合理构象而无需 redocking 流程

## 比较基线

- Pocket2Mol（等变自回归）、TargetDiff（扩散 SOTA）、Lingo3DMol（片段式语言模型）
- 参考分子（真实活性配体）作上界对照
- PoseBusters 物理合理性套件作为客观第三方评估

## 已知限制

- 无实验合成/活性验证，全部依赖计算代理指标
- Vina 优势幅度小且 Vina 与分子大小相关的偏差问题需谨慎（文中以分子量对齐缓解）
- 多样性降低（0.89），性质约束可能限制化学空间探索
- 键长分布整体仍落后 TargetDiff（迁移遗忘现象）
- token 化坐标的分辨率对构象精度有内在限制

## 待复核未知项

- 更大骨架 LLM（数十 B 参数）的 scaling 收益
- 案例靶点生成分子的实验验证结果
- 与 DrugHIVE 类潜空间方法在同一 Vina-n 归一化协议下的公平对比
- 蛋白编码器替换为 ESM 类 PLM 的增益

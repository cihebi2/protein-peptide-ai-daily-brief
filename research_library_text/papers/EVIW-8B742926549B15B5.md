# DCGAT-DTI: dynamic cross-graph attention network for drug-target interaction prediction

- **论文 ID：** `EVIW-8B742926549B15B5`
- **期刊 / 来源：** Bioinform Adv
- **发表时间：** 2025 Dec 15
- **DOI：** [10.1093/bioadv/vbaf306](https://doi.org/10.1093/bioadv/vbaf306)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 DCGAT-DTI：先用 ESM-2 和 ChemBERTa 生成初始表示，再通过动态跨图注意力与跨模态邻域选择联合更新药物/蛋白表示，并结合 BCE 与监督对比损失完成预测。

## 创新边界

`仅限于其声明的动态跨图注意力、CNS 邻域选择和双损失组合；未做独立全局新颖性验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在DTI预测中同时建模药物与蛋白的各自图结构及其跨模态依赖，以提升冷启动和类别不平衡场景下的交互预测能力。

## 方法

- ChemBERTa/ESM-2类嵌入建立药物与蛋白图；GCN cross-neighborhood selector动态采样跨图邻居，跨图注意和对比损失联合训练。

## 数据与基准

- DrugBank、BindingDB等四个DTI benchmark，平衡/不平衡及warm、drug-cold、protein-cold拆分；DUD-E/LIT-PCBA补充早期富集评价。

## 比较基线

- DTI-LM、CCL-DTI、TransDTI、CAT-DTI、ColdstartCPI，以及去DCGAT/动态邻居/对比损失消融。

## 结果证据

- 相对最佳基线，drug-cold AUPRC平均改善11.12%（平衡）/11.81%（不平衡），protein-cold改善4.03%/10.17%；但蛋白同源和药物scaffold跨拆分可能抬高性能。

## Pi 结构化证据摘录

- **baseline：** 主要对比基线为 DTI-LM、CCL-DTI、TransDTI 和 CAT-DTI，用于覆盖语言模型、对比学习、Transformer 与 cross-attention 等不同路线。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.5]
- **baseline：** 虚拟筛选部分额外加入 ColdstartCPI，并说明其原始训练来自 PDBbind，因此作者将其改用 DrugBank 重新训练以便公平比较。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.8]；[doi:10.1093/bioadv/vbaf306, p.9]
- **data：** 实验使用四个基准数据集：DrugBank（2203 proteins、1603 drugs、6041 interactions）、BindingDB（879、9144、4040）、Yamanishi_08（722、791、3448）和 Luo's dataset（1129、708、1526）。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.5]
- **data：** DrugBank 与 BindingDB 采用 0.79/0.01/0.20 的 train/validation/test 划分，并评估 warm start、cold start for drug、cold start for protein 三种设置。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.5]
- **data：** Yamanishi_08 与 Luo's dataset 采用 Ye et al. 2021 的划分；实验同时在 balanced 1:1 与 unbalanced 1:10（或可达到的最大比例）条件下重复 10 次，报告 AUROC 和 AUPRC 均值。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.5]
- **declared_resources：** 论文明确给出源码与预处理数据仓库：https://github.com/compbiolabucf/DCGAT-DTI。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.1]；[doi:10.1093/bioadv/vbaf306, p.11]
- **declared_resources：** 作者声称该模型在单张 NVIDIA RTX A4500 GPU（24 GB）上训练约需 10 分钟。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.10]
- **declared_resources：** Funding 声明包括 NSF-III2246796、NSF-III2152030 等项目支持。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.11]
- **limitations：** 作者指出模型性能会受预训练嵌入质量和相似性阈值选择影响，因此图构建策略本身可能改变结果。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.10]
- **limitations：** 作者也承认冷启动评估可能仍存在 similarity-based leakage，因为训练/测试蛋白可能有较强序列同源性、药物可能共享 scaffold。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.10]
- **limitations：** 论文提出的后续方向包括自适应图构建、引入 3D 结构或 binding affinity，以及扩展到 temporal 或 multi-context biological data。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.10]
- **method：** 使用 ESM-2 编码蛋白序列、ChemBERTa 编码 SMILES，得到药物与蛋白的初始嵌入表示。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.2]；[doi:10.1093/bioadv/vbaf306, p.3]
- **method：** 基于嵌入向量的欧氏距离和阈值 τP/τD 构建蛋白相似图与药物相似图，以保留同模态邻域结构。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.3]
- **method：** DCGAT 通过 GCN 实现的 CNS 网络与 straight-through Gumbel-softmax 动态选择跨图邻居，再结合 intra-graph 与 cross-graph 多头注意力更新节点表示。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.4]
- **method：** 模型将残差连接后的药物与蛋白表示拼接后输入 MLP，训练目标由 BCE loss 与监督对比损失加权组成。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.5]
- **results：** 在 BindingDB 上，DCGAT-DTI 的 balanced warm start AUROC/AUPRC 为 0.943/0.938，cold start for drug 为 0.875/0.889，cold start for protein 为 0.838/0.809。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.6]
- **results：** 作者报告该方法在四个数据集的 warm/cold 与 balanced/unbalanced 场景中总体优于 DTI-LM、CCL-DTI、TransDTI 和 CAT-DTI，并在 BindingDB 上相对 DTI-LM 的平均提升为 2.785% AUROC 和 2.65% AUPRC。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.6]；[doi:10.1093/bioadv/vbaf306, p.7]
- **results：** 消融实验显示，去掉 DCGAT module、contrastive loss 或 dynamic neighborhood 后，BindingDB balanced warm start 下降到 0.881/0.886、0.912/0.903 和 0.893/0.889。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.8]
- **results：** 在虚拟筛选基准中，ColdstartCPI 在 DUD-E 上略优于 DCGAT-DTI，而 DTI-LM 在 LIT-PCBA 上略优，DCGAT-DTI 仍保持第二或接近最优。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.8]；[doi:10.1093/bioadv/vbaf306, p.9]
- **results：** 鲁棒性分析显示，模型对邻域噪声和 batch 组成较稳定；positive anchor 的预测概率约 0.85，negative anchor 约 0.20。
  - 证据：[doi:10.1093/bioadv/vbaf306, p.7]；[doi:10.1093/bioadv/vbaf306, p.8]

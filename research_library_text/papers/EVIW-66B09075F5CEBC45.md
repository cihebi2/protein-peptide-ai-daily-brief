# Dual modality feature fused neural network integrating binding site information for drug target affinity prediction

## 作者主张的创新点

作者提出 DMFF-DTA：一个结合序列模态与图模态的双模态 DTA 预测框架，利用 AF2/UniProt/GeneCards 驱动的 binding-site contact map、virtual node 融合、以及 warm-up 和 source feature 机制来提升性能、效率与可解释性。

## 创新边界

`主要新意在 binding-site-aware 图构造与双模态特征融合的组合设计；它没有提供新湿实验，也未在冻结材料中独立验证全球新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在药物-靶标亲和力（DTA）预测中同时融合序列与结构信息，并通过 binding-site-aware 图建模缓解药物/蛋白图规模失衡，从而提升准确性、泛化能力与可解释性。

## 方法

- BiLSTM/注意力提取SMILES和蛋白序列；基于AF2及数据库检索构建结合范围接触图；药物图与靶点图经虚拟节点交互后融合回归。

## 数据与基准

- Davis和KIBA基准；常规随机拆分以及未见药物、未见靶点、两者均未见三种场景；另做胰腺癌药物重定位案例。

## 比较基线

- DeepDTA、FusionDTA、GraphDTA、MgraphDTA、MSGNN-DTA、AttentionMGT-DTA等序列/图/结合位点方法。

## 结果证据

- Davis上MSE从次优0.226降至0.218、CI从0.891升至0.894；论文报告双冷启动场景平均指标相对次优提升约9%至10%。

- 结合位点依赖AF2和外部数据库；基准DTA标签和拆分仍可能含结构近邻；重定位案例是计算预测而非临床或实验验证。

## 仍未知

- 公开代码与网页是否能在当前环境稳定复现，冻结材料未独立验证。
- 胰腺癌候选药物是否经过实验或临床层面的验证，冻结文本未给出。

- attention 权重能否提供可因果解释的结论仍然未知。

## Pi 结构化证据摘录

- **baseline：** 对比基线包括 DeepDTA、GraphDTA、AttentionSiteDTI、AttentionMGT、FusionDTA、MgraphDTA 和 MSGNN-DTA。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.4]
- **baseline：** 作者把既有方法分成 pure sequence、semi-graph、fully graph 和 binding-site-based 四类，并批评很多方法要么缺少结构，要么缺少跨模态交互。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.2]
- **data：** 主 benchmark 为 Davis 与 KIBA，均包含 drug SMILES、protein amino-acid sequences 和实验测得的 binding affinity。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.12]
- **data：** 结构与 binding-site 信息来自 AF2 Database、UniProt 和 GeneCards 的检索结果，用于构建 target graph。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.11]；[doi:10.1038/s41746-025-01464-x, p.12]
- **data：** 胰腺癌 case study 使用 KEGG map05212、ChEMBL 的 2889 条 DTA 样本和 2509 个 FDA-approved drugs 进行重排序分析。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.7]；[doi:10.1038/s41746-025-01464-x, p.8]
- **declared_resources：** 主数据与代码公开在 GitHub，论文还给出 Hugging Face Spaces web server。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.12]
- **declared_resources：** 结构/注释资源包括 GeneCards、UniProt、AF2 Database 和 RDKit。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.11]；[doi:10.1038/s41746-025-01464-x, p.12]
- **declared_resources：** 案例资源来自 KEGG、ChEMBL、ADMETlab 2.0 与 CB-Dock2。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.7]；[doi:10.1038/s41746-025-01464-x, p.8]
- **limitations：** 模型依赖 UniProt 注释的 binding site，作者明确承认对新或未注释 binding site 的 inhibitor 可能受限。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.10]
- **limitations：** 作者也提醒 attention 不能被当作严格的解释性证据，需要谨慎解读。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.10]
- **limitations：** 作者把 drug repurposing 视为多因素问题，DTA 只是初筛，仍需结合生物学相关性、PK/PD、off-target 与后续验证。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.10]
- **limitations：** 作者还提出未来应在更多 protein families 上验证泛化，并进一步探索直接预测 binding site。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.10]
- **method：** 模型对目标序列和药物 SMILES 分别做 residue/atom 级 tokenization，再通过 Embedding、GEM、BiLSTM 和 LinkAttention 提取序列模态表征。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.11]
- **method：** 图模态部分用 RDKit 构建药物分子图，并经 GeneCards→UniProt→AF2 Database 取回蛋白结构和 binding range，再以 8 Å contact map 截取 binding-site target graph。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.11]；[doi:10.1038/s41746-025-01464-x, p.12]
- **method：** 融合阶段引入 virtual node、source type feature，并先做 sequence-only warm-up，以便把序列特征映射到可用于联合训练的节点表示。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.12]
- **method：** 最终将 sequence/graph 表征拼接后经 fusion FFN 输出 DTA；训练采用 MSELoss、Adam 和 5-fold cross-validation（7:1:2 划分）。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.12]
- **results：** 在 Davis 和 KIBA 上，DMFF-DTA 的 MSE/CI/r2m 都是最佳；Davis 达到 0.218/0.894/0.702，KIBA 达到 0.144/0.889/0.773，且多项提升具有统计显著性。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.4]
- **results：** 在 unseen drug、unseen target 和 all unseen 场景下，作者报告 DMFF-DTA 仍优于对照方法，最难的 all unseen 场景可获得约 10% 的平均提升。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.5]；[doi:10.1038/s41746-025-01464-x, p.6]
- **results：** AF2-based contact map 在性能与代价之间取得更好折中：单 epoch 约 36.80 s、17,681 MB，优于部分 fully graph baselines；替换为 Pconsc4/ESM 时性能更差。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.4]
- **results：** 消融显示 MEFseq 退化最大，MEFstr、LinkAttention、virtual node、Warm Up 和 Source feature 也都有正贡献。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.6]
- **results：** 注意力分布更集中于 binding site/range，胰腺癌 case study 中优先筛出 Noscapine 等候选，但这仍是 in silico 结果。
  - 证据：[doi:10.1038/s41746-025-01464-x, p.7]；[doi:10.1038/s41746-025-01464-x, p.8]

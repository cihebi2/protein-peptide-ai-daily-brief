# Evaluating ligand docking methods for drugging protein-protein interfaces: insights from AlphaFold2 and molecular dynamics refinement

- **论文 ID：** `EVIW-B0F5998042EF0F16`
- **期刊 / 来源：** Journal of Cheminformatics（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1186/s13321-025-01067-4](https://doi.org/10.1186/s13321-025-01067-4)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `结构预测` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称构建了一个包含 16 个具备已验证活性化合物的 PPI/蛋白-肽基准，并系统比较 8 种对接策略；结论是 AF2 模型可作为 PPI 对接起点，MD/AlphaFlow 在部分案例可改进结果，但整体仍受评分函数与位点预测限制。

## 创新边界

`新意主要在 PPI 专题基准与结构来源对比，不是新对接算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

评估面向蛋白-蛋白相互作用（PPI）靶点的小分子对接流程在真实已知调节剂上的筛选能力，并比较 native PDB、AlphaFold2 及 MD/AlphaFlow 构象集合是否能提升虚拟筛选与早期富集。

## 方法

- 多docking engines、AF2 structures、MD/minimization。

## 数据与基准

- PPI interface ligand benchmark。

## 比较基线

- 各docking methods。

## 结果证据

- 论文报告方法可靠性/差异；为计算。

## 已知限制

- interface flexibility/structure/score与无prospective assay。

## 仍未知

- 是否能推广到更大规模、更多样化的 PPI/蛋白-肽集合，冻结证据未给出独立外部验证。
- AlphaFold3 与其他更新的结构预测/对接组合未被纳入，因此其相对优势仍未知。
- 对于 cryptic pocket 或更强诱导契合体系，当前结论是否仍成立尚未直接验证。

## Pi 结构化证据摘录

- **baseline：** native PDB 是主要结构基线；作者显示 AF2 模型与其在 PPI 对接上的表现近似，而 Glide-IFD 相比 Glide 没有带来显著提升。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]；[doi:10.1186/s13321-025-01067-4, p.10]
- **baseline：** AutoDock Vina 是较弱的比较基线之一，平均 AUPRC 约为 0.299；相对地，Gnina 在全局排序上最好。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.9]
- **baseline：** EquiBind 与 DiffDock 等 blind docking 方法被用来对照传统 local docking，但作者观察到其更容易出现不合理构象，因此不适合作为单独的高置信基线。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.8]；[doi:10.1186/s13321-025-01067-4, p.9]
- **data：** 基准数据集覆盖 16 个复合物，既有 protein-protein 也有 protein-peptide 体系，表 1 列出 RUNX1/CBFB、KRAS/SOS1、MDM2/P53 等案例及其活性配体数量。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.3]；[doi:10.1186/s13321-025-01067-4, p.11]
- **data：** 结构输入包括 native PDB、AFnat、AFfull、MD-PDB、MD-AF 和 AlphaFlow 多构象集合，作者明确将这些结构类型作为对接输入来源。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.2]；[doi:10.1186/s13321-025-01067-4, p.5]；[doi:10.1186/s13321-025-01067-4, p.6]
- **data：** 作者使用各复合物对应的 active 及与之理化性质相近的 decoy 来构建筛选任务，以模拟真实虚拟筛选场景。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]；[doi:10.1186/s13321-025-01067-4, p.11]
- **declared_resources：** 结构预测资源包括 AlphaFold v2.3.1 及其数据库版本 UniRef90 v2022_01、MGnify v2022_05、Uniclust30 v2021_03、BFD、PDB 和 PDB70。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.11]
- **declared_resources：** 分子动力学使用 Gromacs 2022.3、CHARMM36、TIP3P、水盒与 500 ns 时间尺度，轨迹用 gmx cluster 和 gromos 聚类。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.12]
- **declared_resources：** 对接与前处理依赖 Schrödinger Maestro 的 LigPrep / Protein Preparation，以及 Glide 2021-2、AutoDock Vina 1.2.5、Gnina 1.0、Open Babel 3.1.0、EquiBind、DiffDock、TankBind、P2Rank 2.3、SiteMap 和 FoldX 5.0。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.12]；[doi:10.1186/s13321-025-01067-4, p.13]
- **declared_resources：** 作者声明复现数据与代码已发布在 GitHub 仓库 https://github.com/SysBioUAB/docking_benchmark。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.13]
- **limitations：** 样本只有 16 个复合物，而且不同 assay 条件和技术可能影响 active/decoy 标注，限制了统计稳健性。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.11]
- **limitations：** 蛋白-肽体系高度柔性，作者明确指出 top-ranked pose 未必代表真实结合构象。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.11]
- **limitations：** AlphaFold3 在分析时尚未公开，无法纳入同一基准比较，因此结论不覆盖更新一代结构预测器。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.11]
- **limitations：** blind docking 仍受 pocket 预测失败、clash 和物理不合理 pose 的限制，说明其误差来源不仅是结构输入。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.8]；[doi:10.1186/s13321-025-01067-4, p.9]
- **method：** 作者从 ChEMBL 与 2P2Idb 汇总 16 个具有实验验证小分子的 PPI/蛋白-肽复合物，要求存在 PDB 结构，并按 pChEMBL > 5 定义 active、以 ChemBridge 1:10 比例抽取 decoy。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.3]；[doi:10.1186/s13321-025-01067-4, p.11]
- **method：** 作者用 AlphaFold v2.3.1 分别对 PDB 截断链（AFnat）和 full-length 序列（AFfull）建模，采用默认 MSA 与 recycling 设置，并以 ipTM+pTM 最优模型为代表；ipTM+pTM > 0.7 被视为高质量。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.3]；[doi:10.1186/s13321-025-01067-4, p.11]
- **method：** 作者对 PDB 与 AFnat 结构各做 500 ns 全原子 MD，排除前 20 ns 后聚类成约 30 类并取最常见 10 个代表构象；同时用 AlphaFlow 生成 250 个构象，并通过 glycine linker 处理多聚体输入后再聚类取代表结构。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.5]；[doi:10.1186/s13321-025-01067-4, p.11]；[doi:10.1186/s13321-025-01067-4, p.12]
- **method：** 作者比较了 Glide、Glide-IFD、AutoDock Vina、Gnina、TankBind_local、TankBind_blind、EquiBind 和 DiffDock；local docking 以界面中心建网格，blind docking 依赖 P2Rank 或模型自带口袋预测，EquiBind 因 clash/正能量被后续分析排除。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]；[doi:10.1186/s13321-025-01067-4, p.8]；[doi:10.1186/s13321-025-01067-4, p.12]；[doi:10.1186/s13321-025-01067-4, p.13]
- **method：** 性能评估同时使用 AUROC、AUPRC、EF1% 和 SiteMap 的 SiteScore/Dscore；对每个 PPI-协议组合，作者先选 AUROC 最优的结构类型，再在该结构上统计其余指标。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]；[doi:10.1186/s13321-025-01067-4, p.9]；[doi:10.1186/s13321-025-01067-4, p.10]；[doi:10.1186/s13321-025-01067-4, p.12]
- **results：** AFnat 与 native PDB 总体接近：所有模型 TM-score 都高于 0.6，中位数为 0.972；除 1G73 外 DockQ 均高于 0.23，且 16 个复合物中有 9 个达到 DockQ > 0.8。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.3]
- **results：** AFfull 通常更差，主要因为全长无序区和额外残基改变了界面；作者指出 16 个复杂体中有 15 个受到负面影响。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.4]
- **results：** MD 与 AlphaFlow 能在部分案例改善构象描述，AlphaFlow 还呈现更宽的能量分布，但不同构象之间差异很大，说明“选对构象”本身就是难点。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.5]；[doi:10.1186/s13321-025-01067-4, p.6]
- **results：** local docking 中 PDB 与 AFnat 的 AUROC 没有显著差异；TankBind_local 与 Glide 在早期富集上最好，而 Gnina 的平均 AUPRC 最高。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]；[doi:10.1186/s13321-025-01067-4, p.9]；[doi:10.1186/s13321-025-01067-4, p.10]
- **results：** blind docking 的主要瓶颈是口袋识别失败、配体错位和立体冲突；DiffDock 与 TankBind_blind 在部分体系上可被 MD/AlphaFlow 结构轻度改善。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.8]；[doi:10.1186/s13321-025-01067-4, p.9]
- **results：** AUROC 与 DockQ 或 ipTM+pTM 没有相关性，作者据此判断当前对接性能更受评分函数与方法学限制影响，而非单纯结构质量。
  - 证据：[doi:10.1186/s13321-025-01067-4, p.7]

## 作者主张的创新点

本文作为综述，系统梳理近年基于结构的 PPI 预测路线，按数据资源、特征表示和算法家族总结 SVM、RF、Bayesian network、ANN、CNN、GNN 与 clustering，并讨论 XAI、AlphaFold/AlphaFold Multimer 相关趋势和未来方向。

## 创新边界

## 研究问题

在结构信息逐步可得的前提下，如何借助 ML/DL 从蛋白三维结构、界面几何和生化特征中更可靠地预测 PPI，并同时处理负样本构造、数据稀缺与可扩展性问题。

## Pi 结构化证据摘录

- **baseline：** 文中主要以 sequence-based 预测器和 docking/template-based 方法作为对照背景，强调结构信息可补足仅靠序列难以区分的构象差异。
  - 证据：[doi:10.3390/biom15010141, p.2]；[doi:10.3390/biom15010141, p.3]；[doi:10.3390/biom15010141, p.15]
- **baseline：** 在具体案例中，SpatialPPI 与 DeepTrio 以及 docking-based 方法进行比较；Li 等方法则与 Šikić 等随机森林位点方法比较。
  - 证据：[doi:10.3390/biom15010141, p.11]；[doi:10.3390/biom15010141, p.12]
- **data：** 本文不含原创实验数据，作者明确说明内容完全基于已发表文献。
  - 证据：[doi:10.3390/biom15010141, p.18]
- **data：** Table 1 汇总了主流 PPI 数据库、负相互作用数据库和蛋白特征资源，作为综述的数据底座。
  - 证据：[doi:10.3390/biom15010141, p.4]；[doi:10.3390/biom15010141, p.5]
- **data：** 文中强调结构输入主要来自 PDB 与 AlphaFold Database，补充特征来自 UniProt 等资源。
  - 证据：[doi:10.3390/biom15010141, p.4]
- **declared_resources：** PDB、AlphaFold Database 与 UniProt 是文中明确依赖的蛋白结构/注释资源。
  - 证据：[doi:10.3390/biom15010141, p.4]
- **declared_resources：** Table 1 列出 DIP、MINT、BioGRID、IntAct、STRING、Mentha、IMEx、iRefIndex、HINT、OmniPath、PICKLE、Negatome 2.0 等资源。
  - 证据：[doi:10.3390/biom15010141, p.4]；[doi:10.3390/biom15010141, p.5]
- **declared_resources：** 作者还提到 PrePPI webserver、AlphaFold Multimer 和 AlphaBridge 作为后续工具/资源。
  - 证据：[doi:10.3390/biom15010141, p.11]；[doi:10.3390/biom15010141, p.12]；[doi:10.3390/biom15010141, p.15]
- **limitations：** 高分辨率结构并不总是可得，而且 3D 建模的计算开销限制了规模化应用。
  - 证据：[doi:10.3390/biom15010141, p.1]；[doi:10.3390/biom15010141, p.15]；[doi:10.3390/biom15010141, p.17]
- **limitations：** 负样本几乎无法被实验直接确认，随机采样、亚细胞定位筛选和 Negatome 式集合都可能引入偏差或夸大准确率。
  - 证据：[doi:10.3390/biom15010141, p.3]；[doi:10.3390/biom15010141, p.15]；[doi:10.3390/biom15010141, p.16]
- **limitations：** 图模型和深度模型对图构建、超参数和数据平衡较敏感，且在大规模网络上仍有资源压力。
  - 证据：[doi:10.3390/biom15010141, p.13]；[doi:10.3390/biom15010141, p.14]；[doi:10.3390/biom15010141, p.16]
- **method：** 文章采用叙述性综述方式，先回顾 PPI 数据库、负样本与蛋白结构/注释资源，再归纳结构基预测的主要技术路线。
  - 证据：[doi:10.3390/biom15010141, p.4]；[doi:10.3390/biom15010141, p.6]；[doi:10.3390/biom15010141, p.18]
- **method：** 作者按代表性方法逐类介绍经典 ML、DL、图学习与聚类分析，并在 Table 2 中列出对应论文、DOI、作者和年份。
  - 证据：[doi:10.3390/biom15010141, p.6]；[doi:10.3390/biom15010141, p.7]；[doi:10.3390/biom15010141, p.21]；[doi:10.3390/biom15010141, p.22]
- **results：** 作者的核心判断是：结构基方法通常比 sequence-based 方法更准确，但要付出更高的结构获取与计算代价。
  - 证据：[doi:10.3390/biom15010141, p.1]；[doi:10.3390/biom15010141, p.15]；[doi:10.3390/biom15010141, p.16]；[doi:10.3390/biom15010141, p.17]
- **results：** SpatialPPI 的最优设置在五折交叉验证下达到 mean accuracy 0.81、AUC 0.89；在 DeepTrio 测试子集上达到 0.83 accuracy 和 0.92 AUC。
  - 证据：[doi:10.3390/biom15010141, p.12]
- **results：** Struct2Graph 在平衡数据上达到 98.96% accuracy、99.4% precision、98.57% recall、98.98% F1；HIGH-PPI 报告约 90% micro-F1，并在扰动和 OOD 场景下保持较强稳健性。
  - 证据：[doi:10.3390/biom15010141, p.13]；[doi:10.3390/biom15010141, p.14]；[doi:10.3390/biom15010141, p.15]
- **results：** NOXclass、RF 与 ANN 等早期方法已能在绑定类型、界面位点和相互作用类别上取得中等到较好的效果，但论文也指出其受限于特征工程和数据规模。
  - 证据：[doi:10.3390/biom15010141, p.8]；[doi:10.3390/biom15010141, p.9]；[doi:10.3390/biom15010141, p.10]；[doi:10.3390/biom15010141, p.11]；[doi:10.3390/biom15010141, p.16]

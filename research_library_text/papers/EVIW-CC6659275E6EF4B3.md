# EquiPNAS: improved protein–nucleic acid binding site prediction using protein-language-model-informed equivariant deep graph neural networks

- **论文 ID：** `EVIW-CC6659275E6EF4B3`

## 作者主张的创新点

提出 EquiPNAS，将 ESM-2 的 protein-language-model embeddings 与 E(3)-equivariant deep graph neural network 结合，用于蛋白-DNA/蛋白-RNA binding site prediction，并声称在多个公开基准上优于现有方法且对 AlphaFold2 结构更鲁棒。

## 创新边界

`作者声称 pLM embeddings 在该任务中此前未被充分利用，但冻结材料没有提供独立 prior-art 证据来验证这一新颖性边界。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在仅有蛋白序列、实验结构或 AlphaFold2 预测结构时，准确预测蛋白对 DNA/RNA 的残基级结合位点，并尽量降低对进化信息的依赖。

## 方法

- 残基结构图+PLM embedding输入等变消息传递，位点二分类。

## 数据与基准

- 多个protein-DNA/RNA benchmark及AlphaFold2输入场景。

## 比较基线

- NABind/GraphBind类方法及去PLM/非等变消融。

## 结果证据

- 论文报告超过序列/结构SOTA并对AF2结构稳健；为计算预测。

## Pi 结构化证据摘录

- **baseline：** Protein-DNA 对照方法包括 SVMnuc、NCBRPred、DNAPred、COACH-D、NucBind、DNABind、GraphBind 和 GraphSite。
  - 证据：[doi:10.1093/nar/gkae039, p.7]；[doi:10.1093/nar/gkae039, p.8]
- **baseline：** Protein-RNA 对照方法包括 RNABindRPlus、SVMnuc、COACH-D、NucBind、aaRNA、NucleicNet 和 GraphBind。
  - 证据：[doi:10.1093/nar/gkae039, p.7]；[doi:10.1093/nar/gkae039, p.8]
- **baseline：** Invariant network 是作者专门构造的消融基线，用来测量 coordinate updates 与 equivariance 的实际收益。
  - 证据：[doi:10.1093/nar/gkae039, p.13]；[doi:10.1093/nar/gkae039, p.14]
- **data：** Protein-DNA 基准来自 GraphBind/GraphSite 的 Train_573、Test_129、Test_181，均源自 BioLiP 并经 CD-Hit 去冗余。
  - 证据：[doi:10.1093/nar/gkae039, p.6]；[doi:10.1093/nar/gkae039, p.7]
- **data：** Protein-RNA 基准使用 Train_495 与 Test_117，同样来自 BioLiP 并经 CD-Hit 去冗余。
  - 证据：[doi:10.1093/nar/gkae039, p.7]
- **data：** 评估主要采用 ROC-AUC 与 PR-AUC，并分别比较实验结构与 AlphaFold2 预测结构作为输入。
  - 证据：[doi:10.1093/nar/gkae039, p.7]；[doi:10.1093/nar/gkae039, p.8]；[doi:10.1093/nar/gkae039, p.10]
- **declared_resources：** 训练/测试数据来自公开的 GraphBind 和 GraphSite 资源，原始数据可公开获取。
  - 证据：[doi:10.1093/nar/gkae039, p.15]
- **declared_resources：** EquiPNAS 提供开源实现，论文给出 GitHub 地址，并声明采用 GPLv3 许可。
  - 证据：[doi:10.1093/nar/gkae039, p.1]；[doi:10.1093/nar/gkae039, p.15]
- **limitations：** 作者明确把任务界定为 partner-independent：只根据孤立蛋白表面预测 binding site，没有利用 DNA/RNA 伙伴信息。
  - 证据：[doi:10.1093/nar/gkae039, p.15]
- **limitations：** 作者指出，引入相互作用核酸伙伴信息可能进一步提升准确率，说明当前框架仍有提升空间。
  - 证据：[doi:10.1093/nar/gkae039, p.15]
- **limitations：** 论文把更进一步的 protein-DNA 或 protein-RNA complex structure modeling 作为后续方向，而非当前工作的一部分。
  - 证据：[doi:10.1093/nar/gkae039, p.15]
- **method：** 将蛋白单体表示为 residue-level graph，按 Cα 距离阈值（DNA 14Å、RNA 15Å）连边，并要求最小序列间隔为 6。
  - 证据：[doi:10.1093/nar/gkae039, p.3]
- **method：** 节点特征融合 aa one-hot、PSSM、ColabFold 蒸馏 MSA、ESM-2 pLM embeddings，以及 SS/RSA、局部几何、取向、相对位置、虚表面积和 contact count。
  - 证据：[doi:10.1093/nar/gkae039, p.3]；[doi:10.1093/nar/gkae039, p.4]；[doi:10.1093/nar/gkae039, p.5]
- **method：** 边特征定义为序列索引差的对数与三维欧氏距离之比；坐标特征直接使用 Cα 的 x/y/z 坐标。
  - 证据：[doi:10.1093/nar/gkae039, p.5]
- **method：** 模型主体是 12 层、hidden dim 768 的 E(3)-equivariant graph neural network，训练使用 BCE、Adam、cosine annealing、dropout 0.1，最多 40 epochs。
  - 证据：[doi:10.1093/nar/gkae039, p.6]
- **method：** 作者还训练了关闭 coordinate updates 的 invariant baseline，以单独验证 equivariance 的贡献。
  - 证据：[doi:10.1093/nar/gkae039, p.6]；[doi:10.1093/nar/gkae039, p.13]；[doi:10.1093/nar/gkae039, p.14]
- **results：** 在 Test_129 上，EquiPNAS 的 ROC-AUC/PR-AUC 为 0.940/0.569，优于 GraphSite 的 0.934/0.544 和 GraphBind 的 0.916/0.497。
  - 证据：[doi:10.1093/nar/gkae039, p.8]
- **results：** 在 Test_181 上，EquiPNAS 达到 0.918/0.384，略高于 GraphSite 的 0.917/0.369，也高于 GraphBind 的 0.893/0.317。
  - 证据：[doi:10.1093/nar/gkae039, p.8]
- **results：** 在 Test_117 上，EquiPNAS 达到 0.886/0.320，显著高于 GraphBind 的 0.793/0.204。
  - 证据：[doi:10.1093/nar/gkae039, p.8]
- **results：** 代表性案例显示，EquiPNAS 通常能减少 false positives 与 false negatives，并在多例上取得更高的 F1 和 MCC。
  - 证据：[doi:10.1093/nar/gkae039, p.9]
- **results：** 从实验结构切换到 AF2 预测结构时，EquiPNAS 的性能下降很小，DNA 的 PR-AUC 仅约下降 2.3%，RNA 的 ROC-AUC 几乎不变。
  - 证据：[doi:10.1093/nar/gkae039, p.10]；[doi:10.1093/nar/gkae039, p.11]

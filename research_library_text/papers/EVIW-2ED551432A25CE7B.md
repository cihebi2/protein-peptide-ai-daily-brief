# Pair-EGRET: enhancing the prediction of protein-protein interaction sites through graph attention networks and protein language models

- **论文 ID：** `EVIW-2ED551432A25CE7B`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Oct 3
- **DOI：** [10.1093/bioinformatics/btae588](https://doi.org/10.1093/bioinformatics/btae588)
- **范围标签：** `Pi 已解析` / `核心相关` / `有静态审计仓库` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出 Pair-EGRET：把 EGRET 的 edge-aggregated graph attention network 扩展为 Siamese 结构，结合 ProtBERT、physicochemical features、positional encoding 和 multiheaded cross-attention，用于 pairwise PPIS 与 interface region 预测，并给出一定可解释性分析。[doi:10.1093/bioinformatics/btae588, p.1][doi:10.1093/bioinformatics/btae588, p.3][doi:10.1093/bioinformatics/btae588, p.4][doi:10.1093/bioinformatics/btae588, p.7]

## 创新边界

`创新主要在于把 protein language model 特征、EGRET 风格图注意力和 cross-attention 组合到 partner-specific PPI site 预测框架中；它属于可支持设计判断的 transfer 型预测工作，而不是直接生成或优化蛋白候选。[doi:10.1093/bioinformatics/btae588, p.1][doi:10.1093/bioinformatics/btae588, p.9]`。这不是全球首创性检索或独立复现结论。

## 研究问题

面向 partner-specific 的 protein-protein interaction sites (PPIS) 预测，作者同时处理 residue-residue pairwise PPIS 与 interface region prediction，目标是在公开结构基准上更准确地识别两条蛋白之间的结合残基。[doi:10.1093/bioinformatics/btae588, p.1][doi:10.1093/bioinformatics/btae588, p.2]

## 方法

- 由PDB结构构建残基图和边特征，注入预训练Transformer嵌入，经边聚合GAT编码，再用跨注意融合两条蛋白并做残基级分类。

## 数据与基准

- DBD5、Dockground和MaSIF三个伙伴特异基准，并构建去除结构相似测试复合物的子集。

## 比较基线

- BIPSPI+、PInet、NEA、AFM及传统ML/CNN/GNN伙伴特异方法。

## 结果证据

- Dockground中位AUROC 0.8747；MaSIF上AUROC 0.9583、AUPRC 0.5938，分别比次优PInet高8.89%和约15%；AUPRC总体仍显示任务不平衡困难。

## Pi 结构化证据摘录

- **baseline：** pairwise PPIS 的对比方法覆盖了 BIPSPI、SASNet、DCNN、DTNN、NEA、NGF、EGNN、GVP-GNN 和 BIPSPI+ 等不同类型的深度学习/图模型。[doi:10.1093/bioinformatics/btae588, p.5][doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]；[doi:10.1093/bioinformatics/btae588, p.6]
- **baseline：** interface region prediction 的对比方法包括 BIPSPI、BIPSPI+、PInet、MaSIF、SPPIDER，以及 case study 中的 NEA。[doi:10.1093/bioinformatics/btae588, p.6][doi:10.1093/bioinformatics/btae588, p.8]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.6]；[doi:10.1093/bioinformatics/btae588, p.8]
- **baseline：** 文中还报告了 geometry-only 变体，如 MaSIF geom 和 PInet geom，以便区分几何特征单独使用时的效果。[doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.6]
- **data：** DBD5 与 Dockground 都提供 bound 和 unbound 结构；作者用 unbound 结构生成输入特征，用 bound 结构标注相互作用残基，并按非氢原子距离小于 6 Å 定义相互作用。[doi:10.1093/bioinformatics/btae588, p.4][doi:10.1093/bioinformatics/btae588, p.5]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.4]；[doi:10.1093/bioinformatics/btae588, p.5]
- **data：** MaSIF 数据集缺少 unbound 结构，因此作者改用 bound 结构生成输入特征；该数据集主要用于 interface region prediction 的评测。[doi:10.1093/bioinformatics/btae588, p.5][doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]；[doi:10.1093/bioinformatics/btae588, p.6]
- **data：** 作者还从 DBD5 测试集中抽取了 17 个 antibody-antigen complexes 做额外评测，并指出与 AlphaFold-Multimer 的比较存在训练数据重叠偏置。[doi:10.1093/bioinformatics/btae588, p.7]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.7]
- **declared_resources：** 源码以 open source 形式公开在 GitHub，预处理后的数据集也可在 Zenodo 获取。[doi:10.1093/bioinformatics/btae588, p.1][doi:10.1093/bioinformatics/btae588, p.9]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.1]；[doi:10.1093/bioinformatics/btae588, p.9]
- **declared_resources：** 资助来源包括 BUET Basic Research Grant 以及 RISE-BUET Internal Research Grant (ID: 2021-01-016)。[doi:10.1093/bioinformatics/btae588, p.9]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.9]
- **limitations：** 数据极度不平衡，正负样本比例接近 1:1000，这直接导致 pairwise PPIS 的 AUPRC 普遍很低，即使最优模型也不例外。[doi:10.1093/bioinformatics/btae588, p.5]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]
- **limitations：** 在 DBD5 的 interface region 任务上，Pair-EGRET 虽然 AUROC 很高，但 precision 和 AUPRC 仍不占优，说明阈值选择与校准仍是问题。[doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.6]
- **limitations：** AlphaFold-Multimer 的对比并不完全公平，因为那 17 个 antibody-antigen complexes 早于 AFM 的训练截止时间，存在明显训练数据重叠偏置。[doi:10.1093/bioinformatics/btae588, p.7]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.7]
- **limitations：** 作者在结论中把 ESM-2 和更大规模数据集作为下一步方向，暗示当前版本仍受限于所用蛋白语言模型与训练数据规模。[doi:10.1093/bioinformatics/btae588, p.9]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.9]
- **method：** 将 receptor/ligand 的三维结构表示为 directed k-nearest neighbor graph，节点是残基，节点特征由 ProtBERT 1024 维 embedding 与 16 维 physicochemical descriptors 拼接而成，边特征包含 residue distance 和 relative orientation。[doi:10.1093/bioinformatics/btae588, p.2]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.2]
- **method：** Pair-EGRET 先用共享权重的 Siamese EGRET 编码两条蛋白，再加入 positional encoding，并通过 multiheaded cross-attention 让两侧残基交换信息。[doi:10.1093/bioinformatics/btae588, p.3][doi:10.1093/bioinformatics/btae588, p.4]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.3]；[doi:10.1093/bioinformatics/btae588, p.4]
- **method：** 输出端分成 pairwise classifier 与 interface region classifier；前者对 ligand-receptor 的两种拼接顺序分别预测并取平均，以保证顺序不变性。[doi:10.1093/bioinformatics/btae588, p.4]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.4]
- **method：** 训练与评估基于高度不平衡样本：作者把负样本下采样到 1:10 进行训练，而测试集保留原始比例，并主要报告 AUROC 和 AUPRC。[doi:10.1093/bioinformatics/btae588, p.5]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]
- **results：** 在 DBD5 的 pairwise PPIS 任务上，Pair-EGRET 的 median AUROC 达到 0.88828，AUPRC 为 0.0173，文中称其 AUROC 优于所有对比方法。[doi:10.1093/bioinformatics/btae588, p.5]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]
- **results：** 在 Dockground 的 pairwise PPIS 任务上，Pair-EGRET 的 median AUROC 为 0.8747，明显高于 BIPSPI+ 的 0.831。[doi:10.1093/bioinformatics/btae588, p.5][doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.5]；[doi:10.1093/bioinformatics/btae588, p.6]
- **results：** 在 DBD5 的 interface region 任务上，Pair-EGRET 的 AUROC 为 0.924、recall 为 0.746，但 precision 0.255 和 AUPRC 0.275 低于部分 baseline。[doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.6]
- **results：** 在 MaSIF 的 interface region 任务上，Pair-EGRET 达到 AUROC 0.9583 和 AUPRC 0.5938，优于 PInet 的 0.88 和 0.45。[doi:10.1093/bioinformatics/btae588, p.6]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.6]
- **results：** 可解释性与 case study 显示，高 attention score 往往对应已标注的 interacting residue pairs 或空间上更接近的残基对；与 NEA 相比，Pair-EGRET 的预测更集中于真实界面且 false negative 更少。[doi:10.1093/bioinformatics/btae588, p.7][doi:10.1093/bioinformatics/btae588, p.8]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.7]；[doi:10.1093/bioinformatics/btae588, p.8]
- **results：** 在 17 个 antibody-antigen complexes 上，Pair-EGRET 在 16 个案例的 AUROC 更高，且在部分案例的 AUPRC、F1、precision、recall 也优于 AFM。[doi:10.1093/bioinformatics/btae588, p.7]
  - 证据：[doi:10.1093/bioinformatics/btae588, p.7]

# A generative explainable model for antimicrobial peptide prediction using bidirectional temporal convolutional neural network

- **论文 ID：** `EVIW-FD12D61BC580B2CB`
- **期刊 / 来源：** Scientific Reports（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1038/s41598-026-43370-6](https://doi.org/10.1038/s41598-026-43370-6)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 GAC-BiTCNN-AMP，把 ProtTrans-T5、UniRep、ESM-2 与 PsePSSM-DCT 融合，并结合 feature-level GAN、CapsNet、BiTCNN、XGB-FFS 和 SHAP，构成一个可解释的 AMP 二分类框架。

## 创新边界

`本工作的新意主要在于特征融合与架构堆叠；冻证只支持其在自建 AMP/non-AMP 基准上的性能提升，不能证明其在 AMP 预测领域的全球首创性，也不等于端到端的 AMP 生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在不依赖湿实验的情况下，如何更准确地区分 antimicrobial peptide 与 non-AMP，并用序列、进化与预训练表示提升其对治疗候选肽筛选的可用性。

## 方法

- 从序列特征构建双向TCN，attention/贡献分析定位重要片段。

## 数据与基准

- CAMPR4、DBAASPv3、dbAMP2、DRAMP3、LAMP2、YADAMP实验AMP/MIC记录。

## 比较基线

- 现有AMP predictor和CNN/RNN模型。

## 结果证据

- 论文报告CV accuracy 97.42%、MCC 0.923，独立集accuracy 95.32%、MCC 0.914；属于分类。

## Pi 结构化证据摘录

- **baseline：** 内部基线包括 BiLSTM、CNN、TCN，以及 SVM、RF、XGBoost；作者还分别对这些模型做了网格搜索。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.24]；[doi:10.1038/s41598-026-43370-6, p.29]；[doi:10.1038/s41598-026-43370-6, p.30]；[doi:10.1038/s41598-026-43370-6, p.31]
- **baseline：** Transformer 基线包含 ESM-2 fine-tuned、ProtTrans-T5 fine-tuned 和一个轻量 Transformer encoder，均在相同数据切分下比较。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.42]；[doi:10.1038/s41598-026-43370-6, p.43]；[doi:10.1038/s41598-026-43370-6, p.44]
- **baseline：** 外部对照还包括 AmPEP、AMPfun、CAMPR4-ANN、AmpGram、amPEPpy、sAMPpred-GAT、AMPScannerV2、RF-AmPEP30、CAMPR4-SVM、CAMPR4-RF 和 UniAMP；文中说明仅在数据集可比时采用原文结果。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.48]；[doi:10.1038/s41598-026-43370-6, p.49]；[doi:10.1038/s41598-026-43370-6, p.50]
- **baseline：** 在独立测试集上，最强外部基线 UniAMP 报告 90.13% Acc、91.65% F1 和 0.865 MCC。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.50]；[doi:10.1038/s41598-026-43370-6, p.51]
- **data：** 正类来自六个公开 AMP 数据库，最终得到 8,141 条 AMP；负类来自 UniProtKB 的 9,190 条短肽候选，过滤后形成 8,290 条 non-AMP。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.11]；[doi:10.1038/s41598-026-43370-6, p.12]
- **data：** 数据筛选保留 6–50 aa、标准 20 种氨基酸，并用 CD-HIT 40% 去冗余；作者再以 2022 年前后做时间切分，测试集来自 2023–2024 或新整理条目。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.12]
- **data：** 训练/验证与独立测试之间又做了 BLASTp 检查，文中称在 E-value < 1e-5 下未见显著命中。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.12]
- **declared_resources：** 作者在文末给出公开 GitHub 链接，声明 datasets 和 code 可自由获取：https://github.com/Farman335/GAC-BiTCNN-AMP。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.55]
- **declared_resources：** 训练数据资源来自 CAMPR4、DBAASPv3、dbAMP2.0、DRAMP3.0、LAMP2 和 YADAMP 六个公开数据库。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.11]；[doi:10.1038/s41598-026-43370-6, p.12]
- **limitations：** 作者承认数据主要来自较常研究的物种，负类也可能混入尚未标注的弱 AMP，因此存在选择偏差。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.52]；[doi:10.1038/s41598-026-43370-6, p.53]
- **limitations：** 即便做了 CD-HIT 40%、时间切分和 BLASTp 检查，短肽中的远缘同源或趋同演化仍可能抬高交叉验证结果。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.52]；[doi:10.1038/s41598-026-43370-6, p.53]
- **limitations：** 二元 MIC 阈值把连续活性压缩成 AMP/non-AMP，可能掩盖治疗相关的 potency 差异。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.53]
- **limitations：** SHAP 只解释抽象 latent dimensions，而非残基或 motif 级别的生物学机制，因此解释性仍是 representation-level。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.36]；[doi:10.1038/s41598-026-43370-6, p.37]；[doi:10.1038/s41598-026-43370-6, p.54]
- **method：** 作者先从 CAMPR4、DBAASPv3、dbAMP2、DRAMP3、LAMP2 和 YADAMP 汇总 AMP，再从 UniProtKB 构造 non-AMP，并以 MIC≤100 μg/ml、长度 6–50 aa、去冗余与时间切分控制数据质量与泄漏。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.11]；[doi:10.1038/s41598-026-43370-6, p.12]
- **method：** 特征层面同时使用 ProtTrans-T5、ESM-2、UniRep 与新定义的 PsePSSM-DCT，以覆盖上下文、长程依赖和进化信息。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.13]；[doi:10.1038/s41598-026-43370-6, p.16]；[doi:10.1038/s41598-026-43370-6, p.18]；[doi:10.1038/s41598-026-43370-6, p.20]；[doi:10.1038/s41598-026-43370-6, p.21]
- **method：** 作者用 XGB-Forward Feature Selection 为四类特征分别筛选子集，并报告保留了 59、112、74 和 41 个特征。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.22]；[doi:10.1038/s41598-026-43370-6, p.23]
- **method：** 分类器主体是 feature-level GAN 先做增强，再接 CNN、BiTCNN、CapsNet 与 sigmoid 输出层；同时还比较了 BiLSTM、CNN、TCN、SVM、RF 与 XGBoost。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.24]；[doi:10.1038/s41598-026-43370-6, p.25]；[doi:10.1038/s41598-026-43370-6, p.27]；[doi:10.1038/s41598-026-43370-6, p.28]；[doi:10.1038/s41598-026-43370-6, p.29]；[doi:10.1038/s41598-026-43370-6, p.30]
- **method：** 评估采用 5-fold cross-validation 和独立测试集，并报告 Acc、Sn、Sp、Pre、F1、AUC 与 MCC；作者声称所有选择与调参均只在训练数据内完成。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.30]；[doi:10.1038/s41598-026-43370-6, p.31]
- **results：** 5-fold CV 中，融合四种特征时 GAC-BiTCNN 达到 97.42% Acc、97.83% F1、99.54% AUC 和 0.923 MCC。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.38]；[doi:10.1038/s41598-026-43370-6, p.39]
- **results：** 在经过特征选择后，单特征里 GAC-BiTCNN+ESM-2 达到 91.87% Acc、91.83% F1、96.89% AUC 和 0.813 MCC。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.34]；[doi:10.1038/s41598-026-43370-6, p.35]
- **results：** 独立测试集上，GAC-BiTCNN 得到 95.32% Acc、94.94% Sn、96.02% Sp、95.86% F1、98.32% AUC 和 0.914 MCC。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.41]
- **results：** 消融显示从 TCN 到 Bi-TCN、再到 capsule 与 CapsGAN 逐步提升，完整模型优于各简化版本。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.46]；[doi:10.1038/s41598-026-43370-6, p.47]
- **results：** 与 UniAMP 的独立测试对比，作者报告 Acc 从 90.13% 提升到 95.32%，MCC 从 0.865 提升到 0.914。
  - 证据：[doi:10.1038/s41598-026-43370-6, p.50]；[doi:10.1038/s41598-026-43370-6, p.51]

# Hybrid Dual-Context Prompted Cross-Attention Framework with Language Model Guidance for Multi-Label Prediction of Human Off-Target Ligand-Protein Interactions

- **论文 ID：** `EVIW-B72BFE30F8217623`
- **期刊 / 来源：** Int J Mol Sci
- **发表时间：** 2026 Jan 22
- **DOI：** [10.3390/ijms27021126](https://doi.org/10.3390/ijms27021126)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出 HDPC-LGT，把 graph-prompt ligand encoder、层级蛋白编码、interaction-masked 双向 cross-attention、domain generalisation 和多任务对比学习整合进一个 16 标签多标签框架，用于 off-target 预测与机制解释。

## 创新边界

`创新主要体现在多模态集成、双向 cross-attention 与多标签脱靶预测设定；冻结证据中没有独立 prior-art 证据，因此全球新颖性不能被验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

面向抗生素相关人类脱靶毒性，论文要解决的是：如何对 16 个翻译相关 human protein 同时做多标签 ligand–protein interaction 预测，并在 unseen scaffold / unseen protein 条件下保持泛化与可解释性。

## 方法

- drug/protein LM embeddings、prompted cross-attention、多标签头。

## 数据与基准

- 人ligand-off-target数据库。

## 比较基线

- 传统DTI/多标签模型。

## 结果证据

- 论文报告超过多标签baselines；为计算安全性候选。

## Pi 结构化证据摘录

- **baseline：** 对照组包括 Ligand-only MLP、Protein-Ligand MLP、Docking-only、DeepDTA、GraphDTA、MolTrans、HGT-DTA、CAT-DTI 与 GraphormerDTI，且都按相同 leak-proof split 训练和评估。
  - 证据：[doi:10.3390/ijms27021126, p.7]；[doi:10.3390/ijms27021126, p.16]；[doi:10.3390/ijms27021126, p.28]；[doi:10.3390/ijms27021126, p.29]
- **baseline：** 表中最强基线之一 CAT-DTI 的 macro ROC-AUC 为 0.952，而 HDPC-LGT 为 0.996；作者把提升归因于 hierarchical protein embeddings、graph-prompt ligand encoding 和 cross-attention。
  - 证据：[doi:10.3390/ijms27021126, p.7]；[doi:10.3390/ijms27021126, p.16]；[doi:10.3390/ijms27021126, p.30]
- **baseline：** 论文还把 Yamanishi 作为经典外部参考基准，而不是训练来源，用于说明模型在传统 DTI setting 下的迁移表现。
  - 证据：[doi:10.3390/ijms27021126, p.14]；[doi:10.3390/ijms27021126, p.19]；[doi:10.3390/ijms27021126, p.31]
- **data：** 最终 curated training set 为 216,482 对 ligand–protein pairs，来自 1,796,653 条原始记录；作者通过去重、单位标准化、IQR 去异常和 InChIKey canonicalization 得到高置信度训练集。
  - 证据：[doi:10.3390/ijms27021126, p.21]；[doi:10.3390/ijms27021126, p.22]
- **data：** 原始活性/失活比约为 1:4.3，随后用 scaffold-based decoys、Tanimoto < 0.4 和理化属性匹配把类别平衡到 1:1 ± 0.05。
  - 证据：[doi:10.3390/ijms27021126, p.21]；[doi:10.3390/ijms27021126, p.18]
- **data：** 外部验证数据集包括 Papyrus v05.7、PDBbind v2023 和 Yamanishi benchmark，作者明确将它们排除在训练之外，只用于泛化评估。
  - 证据：[doi:10.3390/ijms27021126, p.12]；[doi:10.3390/ijms27021126, p.13]；[doi:10.3390/ijms27021126, p.14]；[doi:10.3390/ijms27021126, p.18]；[doi:10.3390/ijms27021126, p.19]；[doi:10.3390/ijms27021126, p.31]
- **data：** 16 个目标覆盖 cytosolic aaRS、mitochondrial aaRS、ribosomal tunnel proteins、eEF1A1、AIMP1、PSMB1、MRPL12 和 MRPL4 等翻译相关 human proteins。
  - 证据：[doi:10.3390/ijms27021126, p.18]；[doi:10.3390/ijms27021126, p.19]；[doi:10.3390/ijms27021126, p.20]；[doi:10.3390/ijms27021126, p.11]
- **declared_resources：** 训练与验证所用资源来自 BindingDB、ChEMBL、Papyrus、PDBbind 与 Yamanishi 等公开数据库，作者在 Data Availability Statement 中给出访问位置。
  - 证据：[doi:10.3390/ijms27021126, p.31]
- **declared_resources：** 论文声明 datasets、scripts 和 model checkpoints 都是 version-controlled，但冻结证据没有提供可核验的直接代码仓库 URL。
  - 证据：[doi:10.3390/ijms27021126, p.29]
- **declared_resources：** 计算与资金资源来自 CONACYT、IPN grants、Microsoft Latin America PhD Award，以及 CONACYT/INAOE 深度学习平台。
  - 证据：[doi:10.3390/ijms27021126, p.31]
- **limitations：** 作者承认标签来自异质 biochemical sources，assay variability 和 experimental noise 仍会影响 ground truth 质量。
  - 证据：[doi:10.3390/ijms27021126, p.15]
- **limitations：** 当前系统只覆盖 16 个 human targets，蛋白构象变化仅被隐式建模，且作者明确指出仍需要 prospective wet-lab validation；heavy transformer 计算成本也较高。
  - 证据：[doi:10.3390/ijms27021126, p.15]
- **method：** 训练数据来自 ChEMBL v33 与 BindingDB，限定 single protein、IC50/Ki/Kd、≤10 µM，并把 16 个 human translation-associated targets 作为 16 个二元输出来建模。
  - 证据：[doi:10.3390/ijms27021126, p.17]；[doi:10.3390/ijms27021126, p.18]；[doi:10.3390/ijms27021126, p.19]；[doi:10.3390/ijms27021126, p.20]；[doi:10.3390/ijms27021126, p.21]；[doi:10.3390/ijms27021126, p.22]
- **method：** 蛋白端采用 ESM2/ProtBert 序列嵌入叠加 residue-level graph transformer，并用 pocket-residue attention 做层级融合，以同时保留全局序列和局部结构信息。
  - 证据：[doi:10.3390/ijms27021126, p.23]；[doi:10.3390/ijms27021126, p.25]；[doi:10.3390/ijms27021126, p.26]
- **method：** 配体端同时使用 molecular graph MPNN、SMILES Transformer、3D conformers 以及 physicochemical descriptors，并通过 graph-prompt 注入功能团和 scaffold motif 信息。
  - 证据：[doi:10.3390/ijms27021126, p.23]；[doi:10.3390/ijms27021126, p.24]；[doi:10.3390/ijms27021126, p.25]；[doi:10.3390/ijms27021126, p.27]
- **method：** 模型主体是 bidirectional cross-attention with interaction masking，再接 adversarial domain adaptation 和 16 维 sigmoid multi-task head；优化器为 Adam，学习率 5×10^-5，batch size 32，label smoothing 0.05，early stopping 12 epochs。
  - 证据：[doi:10.3390/ijms27021126, p.24]；[doi:10.3390/ijms27021126, p.25]；[doi:10.3390/ijms27021126, p.26]；[doi:10.3390/ijms27021126, p.27]
- **method：** 评估采用 scaffold-level split、protein-level holdout、5-fold stratified cross-validation，并在 Papyrus、PDBbind 与 Yamanishi 上做外部泛化测试。
  - 证据：[doi:10.3390/ijms27021126, p.12]；[doi:10.3390/ijms27021126, p.13]；[doi:10.3390/ijms27021126, p.14]；[doi:10.3390/ijms27021126, p.22]；[doi:10.3390/ijms27021126, p.29]；[doi:10.3390/ijms27021126, p.30]
- **results：** 在 10-fold CV 后，HDPC-LGT 报告 macro ROC-AUC 0.996、micro ROC-AUC 0.998、macro F1 0.986、micro F1 0.989、accuracy 0.989，且 fold 间 Std 多数低于 0.003。
  - 证据：[doi:10.3390/ijms27021126, p.5]；[doi:10.3390/ijms27021126, p.30]
- **results：** 16 个目标的单类 ROC-AUC 处于 0.993–0.998，F1 处于 0.975–0.984，说明各类性能较均衡。
  - 证据：[doi:10.3390/ijms27021126, p.6]；[doi:10.3390/ijms27021126, p.11]；[doi:10.3390/ijms27021126, p.30]
- **results：** 外部验证中，Papyrus ROC-AUC 为 0.971、PDBbind ROC-AUC 为 0.958；Yamanishi 上 mean ROC-AUC 为 97.3%，mean AUPR 为 94.0%。
  - 证据：[doi:10.3390/ijms27021126, p.12]；[doi:10.3390/ijms27021126, p.13]；[doi:10.3390/ijms27021126, p.14]；[doi:10.3390/ijms27021126, p.30]
- **results：** 消融结果显示，去掉 cross-attention 会把 macro-AUC 从 0.996 拉低到 0.944，去掉 graph-prompt ligand encoding 会把 macro-F1 降到 0.922，说明各模块都在贡献性能。
  - 证据：[doi:10.3390/ijms27021126, p.8]；[doi:10.3390/ijms27021126, p.27]；[doi:10.3390/ijms27021126, p.30]
- **results：** 可解释性分析把注意力和梯度归因定位到 LeuRS K599/D528/Y330、RPL23 U2609/A2610、mt-LeuRS R414/H382 等已知位点，与论文叙述的 biochemical mechanism 一致。
  - 证据：[doi:10.3390/ijms27021126, p.8]；[doi:10.3390/ijms27021126, p.9]；[doi:10.3390/ijms27021126, p.10]；[doi:10.3390/ijms27021126, p.11]；[doi:10.3390/ijms27021126, p.15]

## 作者主张的创新点

作者声称构建了一个基于多源生物活性数据和 deep learning 的通用 CPI 预测模型，并进一步把该模型用于 TCM 化合物靶点扩展、协同抗肿瘤组合筛选和细胞实验验证。

## 创新边界

`主要创新在大规模数据整合、负样本筛选、适用域评估和应用验证；核心网络仍是较常规的 PCA + Word2vec + 全连接 DNN 组合。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在大规模高质量正负样本稀缺、hidden ligand bias 明显且新蛋白/新化合物泛化不足的情况下，如何构建一个可用于 compound-protein interaction（CPI）预测并支持 traditional Chinese medicine（TCM）靶点解析的通用模型。

## 方法

- SMILES/protein encoders与interaction fusion。

## Pi 结构化证据摘录

- **baseline：** 作者把 KNN、RF 和 XGBoost 作为主要基线，并通过五折交叉验证与 grid search 调参，最终 DNN 在全部指标上领先。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.7]
- **baseline：** 基线比较使用同一训练/测试数据与相近特征管线，因此主要反映模型能力差异，而不是数据处理差异。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.5]；[doi:10.3389/fphar.2024.1465890, p.7]
- **data：** 主建模集共 1,014,627 对 CPI，包含 346,943 个化合物、1,957 个蛋白、485,954 个正样本和 528,673 个负样本，并按 80/20 划分训练集与测试集。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.6]
- **data：** 外部验证集包括 BindingDB&ChEMBL 的 648,477 对新 CPI、KIBA 的 240,986 对数据，以及 DrugBank 的 2,408 对 novel CPI。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.8]
- **data：** TCM 验证数据来自 Astragalus membranaceus 与 Hedyotis diffusaas 的 46 个化合物，初始 558 个靶点扩展到 698 个靶点，并结合 MDA-MB-231 的 GEO 表达谱。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.5]；[doi:10.3389/fphar.2024.1465890, p.11]
- **declared_resources：** 数据与资源来自 BindingDB、ChEMBL、DrugBank、PubChem、KIBA 和 GEO，覆盖生物活性、激酶抑制和细胞系表达谱。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.3]；[doi:10.3389/fphar.2024.1465890, p.5]；[doi:10.3389/fphar.2024.1465890, p.8]
- **declared_resources：** 实现与分析工具包括 Python 3.6、Keras/TensorFlow、RDKit、scikit-learn、MOE、PROFEAT、DeepMDS 和 CompuSyn。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.3]；[doi:10.3389/fphar.2024.1465890, p.4]；[doi:10.3389/fphar.2024.1465890, p.5]；[doi:10.3389/fphar.2024.1465890, p.11]
- **declared_resources：** 论文在 Data availability 中声明代码和样本可通过 Zenodo DOI 10.5281/zenodo.8245354 获取。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.12]
- **limitations：** 模型适用域明显依赖训练蛋白相似性，Euclidean distance 超过 0.4 后性能下滑，因此对远离训练分布的新靶点仍有风险。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.9]；[doi:10.3389/fphar.2024.1465890, p.12]
- **limitations：** 作者明确承认可解释性不足，SHAP、saliency maps 等分析未做，原因是额外算力与时间成本。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.12]
- **limitations：** 湿实验验证只覆盖 MDA-MB-231 和两组候选组合，作者也把扩展到肺癌、结直肠癌等场景放到未来工作。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.11]；[doi:10.3389/fphar.2024.1465890, p.12]
- **limitations：** 文中对 Comb II 的 IC50 存在 23.83 μM 与 23.89 μM 两种写法不一致，说明结果呈现仍需复核。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.1]；[doi:10.3389/fphar.2024.1465890, p.11]
- **method：** 作者从 BindingDB、ChEMBL、DrugBank 和 PubChem 汇总 CPI，并按 IC50/Ki 阈值与 PubChem BioAssays 负样本规则构建正负样本，同时去重、去除极端分子量化合物并用 Tanimoto 与 CTCS-IPM 降低偏倚。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.3]
- **method：** 化合物用 2048-bit Morgan fingerprints 表示后再经 PCA 压缩到 200 维；蛋白序列按三肽切分并通过 Word2vec CBOW 学得 100 维表示。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.3]；[doi:10.3389/fphar.2024.1465890, p.4]
- **method：** 模型将化合物与蛋白表示拼接后输入 Keras/TensorFlow 的两层全连接 DNN，使用 ReLU、BatchNormalization、Dropout、Sigmoid、Adam 和 binary cross-entropy，并用 grid search 搜索超参数。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.4]；[doi:10.3389/fphar.2024.1465890, p.7]
- **method：** 性能评估采用 AUROC、AUPR、ACC、SEN 和 SPE，并把 DNN 与 KNN、RF、XGBoost 在同一数据管线上比较，还用外部数据集检验泛化能力。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.4]；[doi:10.3389/fphar.2024.1465890, p.5]
- **method：** 在 TCM 场景中，作者先收集两味药的 46 个化合物及已知靶点，再用 CPI 模型补全靶点并输入 DeepMDS 预测多化合物组合，最后用 CCK-8 和 CompuSyn 做实验验证。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.5]；[doi:10.3389/fphar.2024.1465890, p.11]
- **results：** 最优 DNN 在测试集上达到 AUROC 0.98、AUPR 0.98、ACC 93.31%、SEN 93.95% 和 SPE 92.72%，优于 KNN、RF 与 XGBoost。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.7]
- **results：** 蛋白相似性分析显示 Euclidean distance 与共享活性化合物数的相关性最好，因此被选作适用域指标；模型在距离不超过 0.4 时表现最好，距离增大后性能下降。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.8]；[doi:10.3389/fphar.2024.1465890, p.9]
- **results：** 外部集上，BindingDB&ChEMBL 在 Euclidean [0,0.4] 时 ACC 为 85.29%、AUROC 为 0.91；DrugBank 在同区间 ACC 为 92.64%；KIBA 在 [0,0.4] 时 ACC 为 64.02%、AUC 为 0.75。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.9]
- **results：** 在 TCM 应用中，模型对已知靶点的 recall 为 87.2%；排名最高的两组组合在 MDA-MB-231 上均显示协同抑制，CI 分别为 0.682 和 0.805。
  - 证据：[doi:10.3389/fphar.2024.1465890, p.1]；[doi:10.3389/fphar.2024.1465890, p.11]

# Generation of 3D molecules in pockets via a language model

- **论文 ID：** `EVIW-61D2CB039D461481`
- **期刊 / 来源：** Nature Machine Intelligence（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1038/s42256-023-00775-6](https://doi.org/10.1038/s42256-023-00775-6)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 Lingo3DMol：以 FSMILES 表示分子，结合局部/全局坐标解码、NCI/anchor 辅助预测和预训练-微调流程，实现口袋条件下的 3D 分子生成。

## 创新边界

`主要新意集中在表示法、条件建模与训练流程，不足以单凭冻结稿件验证其全球首创性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在蛋白口袋条件下生成兼顾3D构象、拓扑合理性与可结合性的候选小分子，避免线性/图表示忽略空间相互作用并产生不药样结构。

## 方法

- pocket/atom tokens逐步生成3D coordinates/types。

## 数据与基准

- CrossDocked/PDBBind。

## 比较基线

- Pocket2Mol/3D generators。

## Pi 结构化证据摘录

- **baseline：** 对比基线是 Pocket2Mol 和 TargetDiff，分别代表 autoregressive GNN 与 diffusion-based 3D 生成路线。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]
- **baseline：** 两者按原作者方案都训练于 CrossDocked2020，因此该文额外做了同源泄漏控制。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]；[doi:10.1038/s42256-023-00775-6, p.4]
- **baseline：** 作者指出 Pocket2Mol 在 DUD-E 上可能因同源泄漏而被高估。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.4]；[doi:10.1038/s42256-023-00775-6, p.19]
- **data：** 预训练集来自 2000 万+ in-house 商用可得化合物，筛到约 1200 万分子。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]
- **data：** 微调集来自 PDBbind general set v2020，按与 DUD-E 的同源过滤后得到 11,800 个样本。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]
- **data：** NCI 监督标注由 ODDT 生成，平均每个 pocket 约有 4.1 个 NCI 原子和 32.1 个 anchor 原子。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]
- **data：** 评测主要在 DUD-E 上进行，并辅以 CrossDocked2020 相关对照与泄漏分组分析。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]；[doi:10.1038/s42256-023-00775-6, p.4]；[doi:10.1038/s42256-023-00775-6, p.19]
- **declared_resources：** 论文声明源码、推理代码和模型结构已公开在 GitHub，且预训练、微调与 NCI checkpoints 也已发布。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.10]；[doi:10.1038/s42256-023-00775-6, p.11]
- **declared_resources：** 评测数据 CrossDocked2020、DUD-E、PDBbind，以及部分训练/评测分子都给出了可访问链接。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.10]；[doi:10.1038/s42256-023-00775-6, p.11]
- **declared_resources：** 完整预训练集为私有 in-house 数据，仅公开了 140 万条来自公共数据库的部分样本。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.10]
- **limitations：** 作者承认 autoregressive 过程难以一次覆盖所有 NCI，仍需后续研究。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.7]
- **limitations：** 模型无法强制所有预测 NCI 位点都被覆盖，也不能保证生成分子与 pocket 的精确相对位置。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.9]
- **limitations：** 作者仅用 rotation/translation augmentation 和 SE(3) invariant features 缓解等变性问题，系统化评估仍是下一步。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.7]
- **limitations：** 完整预训练数据受商业合同限制无法公开，外部复现仍受数据可得性约束。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.10]
- **method：** FSMILES 将分子切成 fragment，并把环尺寸写入 token，以增强 2D 拓扑与环闭合建模。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.1]；[doi:10.1038/s42256-023-00775-6, p.8]
- **method：** 预训练阶段对 3D 分子施加结构、坐标和元素扰动，再通过自回归重建原分子。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.3]；[doi:10.1038/s42256-023-00775-6, p.8]
- **method：** 微调阶段使用 PDBbind pocket 输入，并冻结 encoder 前 3 层以减轻过拟合。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.2]；[doi:10.1038/s42256-023-00775-6, p.8]
- **method：** NCI/anchor 模型基于同一 Transformer 架构与预训练参数，输出 pocket 原子是否形成 NCI 或 anchor。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.8]；[doi:10.1038/s42256-023-00775-6, p.9]
- **method：** 解码器联合预测 FSMILES token、局部坐标与全局坐标，并用局部/全局坐标融合搜索最终位置。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.9]；[doi:10.1038/s42256-023-00775-6, p.10]
- **results：** 在 DUD-E 上，Lingo3DMol 生成 100,428 个分子，其中 82% 被判为 drug-like；该比例高于 TargetDiff，但低于 Pocket2Mol。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.5]
- **results：** 在 drug-like 子集上，Lingo3DMol 的 ECFP_TS>0.5 为 33%，min-in-place GlideSP 为 -6.8，redocking 为 -7.8，r.m.s.d. 为 0.9 Å。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.5]
- **results：** Extended Data Table 2 显示，Lingo3DMol 更少生成 7 元及以上的大环分子。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.14]
- **results：** 在 10 个 DUD-E target 的推理测试里，Lingo3DMol 平均生成 100 个有效分子的时间为 874±401 秒，快于两个基线。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.16]
- **results：** 在信息泄漏分组分析中，随着泄漏减弱，Lingo3DMol 相对 Pocket2Mol 的优势更明显。
  - 证据：[doi:10.1038/s42256-023-00775-6, p.19]

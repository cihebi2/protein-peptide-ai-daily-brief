# A Transformer for Reaction-Aware Compound Explorations with GFlowNet in QSAR-Guided Molecular Design

- **论文 ID：** `EVIW-B44A523D00052AB4`
- **期刊 / 来源：** J Chem Inf Model
- **发表时间：** 2026 Apr 25
- **DOI：** [10.1021/acs.jcim.6c00181](https://doi.org/10.1021/acs.jcim.6c00181)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 TRACE-GFN，把 TRACER 的反应学习模块与 GFlowNet 的轨迹采样结合：用 GCN 选择 reaction template、用 conditional transformer 生成产物，再以 trajectory balance 训练，使生成分子按奖励比例采样并保持多样性；并在 DRD2、AKT1、CXCR4 上证明其优于 TRACER、Molecule Chef 和 DoG-Gen。

## 创新边界

`创新主要在方法整合与训练目标，不是新湿实验或新数据集。它依赖 USPTO 反应数据和 QSAR 代理 reward，且保护基、反应选择性与真实可合成性并未被完全建模。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在QSAR 目标驱动的分子设计中，同时兼顾高预测活性、真实化学反应路径、合成可行性与生成多样性。作者指出，现有模板式或强化学习式生成方法往往要么忽略合成路线，要么过度偏向高奖励模式而牺牲多样性，且反应模板难以充分表达选择性。

## 方法

- Transformer学习USPTO类反应条件生成，GFlowNet以QSAR作为终点奖励；温度控制奖励-多样性，生成后按DRD2/AKT1/CXCR4评分。

## 数据与基准

- 公开反应数据与三个靶标的活性/QSAR数据，按论文流程生成和评估候选。

## 比较基线

- TRACER、DoG-Gen、Molecule Chef及其他反应模板/生成模型，另比较不同温度。

## 结果证据

- 论文报告三个靶标上高QSAR候选生成效率超过所选模型，且多样性高于TRACER；DoG-Gen在部分靶标更具多样性。均为QSAR预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 奖励模型会产生模式集中和偏差；反应Transformer只证明路径似然，不保证产率/选择性；未合成验证候选。

## 仍未知

- 真实合成成功率和生物活性是否能在实验中保持一致。
- 与更强或更新的生成基线在同一设置下的公平比较仍不清楚。
- QSAR 作为 reward 的外推可靠性在化学空间边界处未被量化。
- 反应选择性、保护基与副反应对实际可执行性的影响仍未解决。

## Pi 结构化证据摘录

- **baseline：** 比较基线包括 TRACER、Molecule Chef 和 DoG-Gen；其中 TRACER 与 TRACE-GFN 都支持 starting material 指定和 multistep reactions，而 Molecule Chef 不支持这两点，DoG-Gen 也不支持 starting material 指定。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.6]
- **baseline：** 相对 TRACER，TRACE-GFN 通过 GFlowNet 提升了 diversity；相对 DoG-Gen，它不依赖无起点的自由搜索，因此在高 reward 生成上更稳定，但 DoG-Gen 在 AKT1 和 CXCR4 上的 diversity 更高。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.6]；[doi:10.1021/acs.jcim.6c00181, p.7]
- **baseline：** Molecule Chef 和 DoG-Gen 更偏向训练分布，作者用较低 FCD 和较低 SA score 来描述这一点；TRACE-GFN 则更强地进入新颖化学空间，但代价是 SA score 偏高。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.7]；[doi:10.1021/acs.jcim.6c00181, p.8]
- **data：** 核心反应数据集是 USPTO 1k TPL；作者说明其由约 445,000 条 USPTO 反应构成，并保留最常见的 1,000 个 reaction templates。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.3]
- **data：** 靶点评估数据覆盖 DRD2、AKT1、CXCR4 三个任务，分别使用 9,006/306,457、3,623/14,814、853/3,051 的 active/inactive 组合来训练 QSAR 模型。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.4]；[doi:10.1021/acs.jcim.6c00181, p.5]
- **data：** 起始分子来自过滤后的 USPTO 化合物：先去除大环、分子量超过 300 或缺少反应性官能团的分子，再按 QSAR 区间 0-0.1 到 0.4-0.5 选取代表性 starting compounds。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.5]
- **declared_resources：** 论文声明 source code 已公开，并以 MIT license 发布在 GitHub 仓库 `https://github.com/sekijima-lab/TRACE-GFN`。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.1]；[doi:10.1021/acs.jcim.6c00181, p.9]
- **declared_resources：** 计算资源包括 Ubuntu 22.04、Xeon Gold 5318Y、128GB RAM、RTX 4090 用于预训练，以及 V100 32GB 用于实验训练。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.3]；[doi:10.1021/acs.jcim.6c00181, p.4]
- **declared_resources：** Supporting Information 还声明提供了 retrosynthetic analysis、SA 转 reward 的线性映射，以及 QSAR 与 SA 的散点图。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.9]
- **limitations：** QSAR 模型存在 applicability domain 限制，生成到训练空间之外的分子时其 activity 估计带有 intrinsic uncertainty，因此 QSAR 值不能视为真实活性的保证。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.5]
- **limitations：** 模型不显式控制 protecting group 策略，也可能提出在真实条件下不会发生的反应；文中明确要求对 chemoselectivity、regioselectivity 和 stereoselectivity 做专家复核。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.8]
- **limitations：** 计算代价较高：作者报告在当前设置下平均训练约 70 小时，且代价会随 maximum reaction length 和 beam width 增长而上升。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.4]
- **method：** 将分子生成形式化为 MDP：state 是当前 reactant SMILES，action 是 reaction template，GCN 学习 π(a|s)，conditional transformer 学习 T(s'|s,a)，并用 GFlowNet 的 trajectory balance 目标训练。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.3]；[doi:10.1021/acs.jcim.6c00181, p.4]
- **method：** GFlowNet 使用 uniform backward policy 近似父状态分布，并引入温度参数 β 让 reward 按 R(x)^β 加权，以调节高奖励与多样性的权衡。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.3]；[doi:10.1021/acs.jcim.6c00181, p.4]
- **method：** GCN 和 conditional transformer 的预训练基于 USPTO 1k TPL：从 Lowe 的 USPTO 反应库抽取约 445,000 条反应，筛成 1,000 个高频 templates，并按 RxnMapper 与相似度规则做预处理。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.3]
- **method：** 训练时采用 maximum reaction length 5、100 rounds、batch size 64、beam width 50；在 Ubuntu 22.04 与 V100 32GB 上，TRACE-GFN 平均约需 70 小时完成训练。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.4]
- **method：** QSAR reward 由随机森林分类器基于 ECFP 训练，目标包括 DRD2、AKT1、CXCR4，标签分别来自 DUD-E、ExCAPE-DB 和 ChEMBL。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.4]；[doi:10.1021/acs.jcim.6c00181, p.5]
- **results：** 温度实验显示，β 从 8 增至 16 再到 32 时，DRD2 reward mean 从 0.177 升至 0.571 和 0.635，而 diversity mean 从 0.710 降至 0.641 和 0.571，说明 reward 与 diversity 存在可调节的权衡。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.5]
- **results：** 在三靶点 benchmark 中，TRACE-GFN 的 QSAR > 0.5 比例分别为 DRD2 48.6%、AKT1 71.5%、CXCR4 62.6%，作者将其报告为优于 TRACER、Molecule Chef 和 DoG-Gen。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.7]
- **results：** TRACE-GFN 的 uniqueness 分别为 71.4%、74.6%、80.5%，FCD 分别为 30.5、24.3、21.3，显示它比 TRACER 探索到更远离训练分布的化学空间，同时保持较高唯一性。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.7]
- **results：** 作者给出的代表性合成路径中，DRD2、AKT1、CXCR4 的最高预测 QSAR 产物分别达到 0.980、0.854 和 0.893，说明模型能够产生高分值反应路径。
  - 证据：[doi:10.1021/acs.jcim.6c00181, p.8]

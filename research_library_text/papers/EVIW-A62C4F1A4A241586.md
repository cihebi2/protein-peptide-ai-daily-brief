# ALDELE: All-Purpose Deep Learning Toolkits for Predicting the Biocatalytic Activities of Enzymes

## 作者主张的创新点

作者提出 ALDELE，一个多工具箱 deep-learning workflow，把 RDKit、GNN-subgraph、protein n-gram CNN、PSSM CNN 和 Rosetta energy features 组合起来，再用 two-phase attention 与 pairwise interaction module 预测 biocatalytic activities，并输出 hotspot/heat map 解释。

## 创新边界

`创新主要在多表示融合、任务化工具箱选择与解释性热图，不是新 wet-lab 实验，也不是直接生成或优化 enzyme candidates。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在数据规模偏小、酶/底物组合多样且结构信息常缺失的 biocatalysis 场景中，构建一个能同时预测 enzyme-substrate 活性并给出可解释 hotspot 的统一深度学习框架。

## Pi 结构化证据摘录

- **baseline：** 回归基线包括 RF、SVM、KNN、Goldman's、Tsubaki's、DLKcat、DeepAffinity、DeepDTA、BACPI 与 TransformerCPI。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.8]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **baseline：** 作者强调这些 baseline 多依赖大规模 drug-target 或 protein-ligand 数据，而 ALDELE 面向更小、更专一的 biocatalyst 数据集。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.2]；[doi:10.1021/acs.jcim.4c00058, p.8]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **data：** 基准集覆盖 CALB、collective kcat、thiolase、halogenase、glycosyltransferase、phosphatase 和 BVMO，规模从约百级到 23,000 级 pair 不等。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.3]
- **data：** collective kcat 数据来自 BRENDA 和 SABIO-RK，经去除缺少 UniProtID、substrate name、protein sequence 或 SMILES 的条目后得到 16,808 对。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.3]
- **data：** 除 kcat 数据集外，其余 benchmark 的蛋白 3D 结构通过 RosettaCM 构建；PSSM 则通过 PSI-BLAST 在 UniProt90 上计算。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.3]；[doi:10.1021/acs.jcim.4c00058, p.6]
- **declared_resources：** 作者声明源代码、原始数据和使用说明发布在 GitHub: https://github.com/Xiangwen-Wang/ALDELE。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.15]
- **declared_resources：** Supporting Information 提供 downstream task 细节、不同 toolkit 组合架构、训练超参数、对照方法、fixed one-dimension 任务模型和 phosphatase 测试。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.15]
- **declared_resources：** 计算资源来自 Queen's University Belfast 的 HPC Tier2，项目获得 EPSRC 与 Invest Northern Ireland / ERDF 支持。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.15]
- **limitations：** 作者明确指出多数 biocatalyst 数据集偏小，CALB 等数据分布稀疏时误差会明显变大。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.2]；[doi:10.1021/acs.jcim.4c00058, p.8]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **limitations：** 结构特征在 sequence-divergent 数据集上未带来稳定增益，model6 只在 CALB 上略有提升，说明 predicted structure 需要谨慎检查。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.9]
- **limitations：** 作者也承认当前没有一个全面、成功的实验验证案例来证明 attention 预测的 hotspot。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.11]
- **limitations：** 在分类任务中，加入过多特征可能引入噪声并导致 overfit。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.9]
- **method：** 作者为多种 biocatalyst 任务整理了回归与多分类 benchmark，并按原始实验值或阈值把数据转换成回归目标或离散活性类别。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.3]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **method：** ALDELE 的 substrate 侧同时使用 RDKit descriptors 与 molecular graph，protein 侧同时使用 n-gram 序列、PSSM 和 Rosetta 结构能量特征。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.3]；[doi:10.1021/acs.jcim.4c00058, p.5]；[doi:10.1021/acs.jcim.4c00058, p.6]
- **method：** 模型先分别对 protein 与 ligand 做 two-phase attention，再经过 pairwise interaction module 和 MLP 输出预测值。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.6]；[doi:10.1021/acs.jcim.4c00058, p.7]
- **method：** 训练与选择模型时使用 5-fold cross-validation，并以 r.m.s.e.、R²、precision、recall 与 F1 评估不同任务。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.7]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **method：** fixed one-dimension 任务只保留 protein-only 或 substrate-only 工具箱，以比较 CPI 设定与单侧预测设定的适用性。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.10]；[doi:10.1021/acs.jcim.4c00058, p.14]
- **results：** 最优超参数为 r-radius=2、n-gram=3、PSSM sliding window=21、vector dimensionality=10，GNN/NN/CNN 深度均为 3 层。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.8]
- **results：** 在回归任务上，最优模型的 test RMSE 分别为 thiolase 0.22、halogenase 0.09、collective kcat 3.39、CALB 9.99，对应 Pearson r 为 0.87、0.82、0.86、0.68。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.8]
- **results：** 与 RF、SVM、KNN、Goldman's、Tsubaki's、DLKcat、DeepAffinity、DeepDTA、BACPI 和 TransformerCPI 相比，ALDELE 在四个回归数据集上整体取得更低 RMSE。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.8]；[doi:10.1021/acs.jcim.4c00058, p.9]
- **results：** 在 glycosyltransferase 多分类任务上，ALDELE M1 的 precision/recall/F1 为 0.861/0.886/0.872。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.9]
- **results：** 在 fixed one-dimension 任务上，CPI 模型的 RMSE 多数高于对应单侧模型，作者据此认为专门的 enzyme-only 或 substrate-only 预测更合适。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.10]
- **results：** attention map 在 thiolase、BVMO thermostability 与 phosphatase 例子中能对齐已知突变位点或关键功能基团。
  - 证据：[doi:10.1021/acs.jcim.4c00058, p.11]；[doi:10.1021/acs.jcim.4c00058, p.12]；[doi:10.1021/acs.jcim.4c00058, p.13]；[doi:10.1021/acs.jcim.4c00058, p.14]

# DisoFLAG: accurate prediction of protein intrinsic disorder and its functions using graph-based interaction protein language model

- **论文 ID：** `EVIW-50EC4D98F422F622`
- **期刊 / 来源：** BMC Biol
- **发表时间：** 2024 Jan 2
- **DOI：** [10.1186/s12915-023-01803-y](https://doi.org/10.1186/s12915-023-01803-y)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 DisoFLAG 与 GiPLM：以预训练 protein language model 的序列表征为输入，联合预测 intrinsic disorder、protein/DNA/RNA/ion/lipid-binding 以及 flexible linker，并宣称在多项基准上优于既有工具，同时提供 standalone package 和 web server。

## 创新边界

`创新边界主要是序列级预测框架与功能相关图建模；它不涉及新蛋白/肽/药物候选的生成或优化，也没有湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何仅基于氨基酸序列，同时更准确地预测蛋白 intrinsic disorder 及其多类 disordered functions，并缓解现有方法在功能覆盖不足、功能相关性未建模、以及多功能残基识别较弱等问题。

## 方法

- 将预训练蛋白语言模型语义表示送入图式交互单元，对无序、蛋白/RNA/DNA 结合、linker 等多个残基层任务联合建模。[doi:10.1186/s12915-023-01803-y, p.1][doi:10.1186/s12915-023-01803-y, p.7]

## 数据与基准

- 按照 CAID/CAID2 和 DP93/DP94 等独立测试集评估，并对多功能残基单独分析。[doi:10.1186/s12915-023-01803-y, p.3][doi:10.1186/s12915-023-01803-y, p.8]

## 比较基线

- 与 CAID 参评无序/功能预测器、不同特征表示及模型消融比较。[doi:10.1186/s12915-023-01803-y, p.6][doi:10.1186/s12915-023-01803-y, p.9]

## 结果证据

- 作者报告 GiPLM 表示持续优于单纯序列特征；linker 任务 AUC 约 0.8，部分总体无序任务 AUC 达 0.879，并扩大了可预测功能类别。[doi:10.1186/s12915-023-01803-y, p.7][doi:10.1186/s12915-023-01803-y, p.9][doi:10.1186/s12915-023-01803-y, p.10]

## Pi 结构化证据摘录

- **baseline：** 作者将 DisoFLAG 与 fIDPnn、DeepDISOBind、DisoRDPbind、ANCHOR-2、MoRFchibi、SPOT-MoRF、DisoLipPred、TransDFL 和 DFLpred 等专用方法逐项比较。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.8]；[doi:10.1186/s12915-023-01803-y, p.9]
- **baseline：** 在功能消融中，去掉 GiU 和 GCN 的 Seq 基线在所有功能类别上都弱于完整 GiU，支持图式功能相关建模的必要性。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.7]
- **baseline：** 在 disorder 预测部分，作者还把 DisoFLAG 与 CAID2 报告的 top 10 方法对齐比较，包括 Disorder-NOX 和 Disorder-PDB 两个测试集。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.10]
- **data：** 训练与评测数据来自 DisProt 9.3；作者收集 protein-, DNA-, RNA-, ion-, lipid-binding 以及 flexible linker 的功能注释，并在过滤后保留 925 条序列。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.4]
- **data：** 这些序列先用 CD-HIT 按 25% 相似度聚类，再划分为 589 条训练、148 条验证和 188 条独立测试序列（DP93）；另构建了 98 条新序列的 DP94。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.4]
- **data：** CAID2 相关测试还使用 disorder-binding（78 proteins）、disorder-linker（40 proteins）、DisProt-NOX（210 proteins）和 DisProt-PDB（348 proteins）数据集。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.9]；[doi:10.1186/s12915-023-01803-y, p.10]
- **declared_resources：** 作者声明提供 standalone package、web server，以及包含 benchmark datasets 和 prediction results 的 Zenodo 资源。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.13]
- **declared_resources：** 作者还声明 source code 与说明已发布在 GitHub，并被 Zenodo 归档。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.13]
- **limitations：** 作者明确指出：PLM 的优势依赖足够的同源序列；当 MSA depth 较低时，PSSM 反而更适合，说明该框架对序列同源信息存在条件依赖。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.7]
- **limitations：** 在更新后的 DP94 上，DisoFLAG 对 RNA-binding 和 lipid-binding 的表现有所下降，提示其跨数据版本的稳定性并不完全一致。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.9]
- **limitations：** 从冻结稿件页面本身看，评估主要停留在 benchmark 与 case study 层面，没有独立湿实验来验证预测的生物学结论。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.11]；[doi:10.1186/s12915-023-01803-y, p.13]
- **method：** DisoFLAG 先用 ProtT5 提取残基 embedding，再通过 Bi-GRU 和带 attention 的 GRU 捕获上下文与全局语义，随后映射成六类功能的残基表征。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.4]
- **method：** GiPLM 用训练集上预计算的 information gain 作为功能图邻接矩阵初始化，并通过 GCN 在六类 disordered functions 之间传播和聚合相关性特征。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.4]；[doi:10.1186/s12915-023-01803-y, p.5]
- **method：** 模型训练采用 disorder 与六类功能输出的 binary cross-entropy 组合损失，评估则使用 AUC、AUPR、APS、Fmax、MCC 和 BACC。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.5]
- **results：** 在 DP93 上，ProtT5 等 PLM 特征总体优于 PSSM 和 One-hot；作者还指出当 MSA depth 较高时，PLM 的收益更明显。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.6]；[doi:10.1186/s12915-023-01803-y, p.7]
- **results：** GiU 相比简单序列层在六类功能上都更优，并且 DisoFLAG 是 DP93 中唯一能覆盖所有类型 multifunctional residues 的方法。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.7]
- **results：** 在 DP93 上，DisoFLAG 对 protein/DNA/RNA/lipid-binding 和 flexible linker 普遍优于既有工具；在 CAID2 disorder-binding 上达到 AUC 0.879、APS 0.563，在 disorder-linker 上达到 AUC 0.800、APS 0.197。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.9]；[doi:10.1186/s12915-023-01803-y, p.10]
- **results：** 在 disorder 预测上，DisoFLAG 在 Disorder-NOX 上取得 AUC 0.836、APS 0.560，并在 Disorder-PDB 上表现接近 CAID2 顶级方法。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.10]
- **results：** Vif case study 中，DisoFLAG 同时识别出 protein-binding 与 lipid-binding 的完整区域，且 false-positive 更少。
  - 证据：[doi:10.1186/s12915-023-01803-y, p.11]

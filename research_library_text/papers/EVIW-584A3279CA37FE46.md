# A dual diffusion model-based representation learning framework for antimicrobial peptides classification

- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2026 Feb 15

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `扩散/生成`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出一个 dual diffusion model-based representation learning framework，通过多视图特征构建、序列/结构双扩散去噪、单模态与双模态对比学习，以及 cross-attention 与 gating 融合，提升 AMP 分类性能并优于现有基线。

## 创新边界

`主要新意在 representation learning 与分类框架，不涉及 AMP 候选生成、序列优化或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在 antimicrobial peptides (AMPs) 与 non-AMPs 的二分类任务中，更充分地融合序列与结构的多视角信息，并缓解现有方法在特征表示深度不足、单一模态建模受限和跨模态语义未充分对齐的问题。

## 方法

- 序列和图结构经独立前向加噪/反向去噪网络学习，多尺度特征和跨模态对比损失融合后分类。

## 数据与基准

- AMP正样本与UniProt非AMP负样本；序列截断/填充至100，结构可用时构建原子/残基图。

## 比较基线

- 传统ML、序列深度模型、图模型和单扩散/无对比损失消融。

## 结果证据

- 论文报告在所选AMP数据集上超过序列或结构单模态及既有分类器；所有结果是回顾性计算分类，没有新肽实验。

## Pi 结构化证据摘录

- **baseline：** 作者对比的九个基线包括 iAMP-Attenpred、AI4AMP、AMP-BERT、sAMPpred-GAT、amPEPpy、Ampir、iAMP-DL、deepAMPNet 和 TP-LMMSG。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.7]
- **baseline：** 所有模型使用相同数据划分，且基线按原论文调参，以尽量保证比较公平。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.7]
- **data：** 正样本来自 CAMP、DBAASP、DRAMP、APD3 和 SATPDB，经过去重、去除非标准氨基酸并截断到 100 residues 后，得到 10,057 条 AMPs。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.6]
- **data：** 负样本从 UniProt 取与 AMP 集合等量的 non-AMPs，并按 8:1:1 划分训练、验证和测试集。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.6]
- **data：** 约 67.4% 的 AMPs 没有已验证结构时，作者用 ESMfold 预测结构以补全结构模态。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.6]
- **declared_resources：** 正文明确给出 GitHub 地址，声明 data 和 source codes 可用。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.1]
- **declared_resources：** 实现基于 PyTorch，使用 AdamW、100 epochs、batch size 32 和 early stopping。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.6]
- **limitations：** 作者承认 dual diffusion 的特征生成仍偏黑箱，限制了对表示演化过程的解释。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.9]
- **limitations：** 双扩散与对比学习增加了模型复杂度，对训练时间与算力提出更高要求。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.9]
- **limitations：** UniProt 负样本可能混入未注释的 antimicrobial activity，且训练数据规模与多样性仍有限。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.9]
- **method：** 序列分支先用 BLOSUM62、PAM120、hydrophobicity、helical tendency、AAindex 和 ESM2 生成多视图特征，并融合为 100×768 的序列表示。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.2]；[doi:10.1093/bioinformatics/btag077, p.3]
- **method：** 结构分支把 PDB 转成 residue graph，节点包含残基类型、四个主原子坐标、helical propensity 和 45 个 AAindex，边由 5 Å 距离与相邻序列距离阈值定义，并加入几何、相互作用和序列特征。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.4]
- **method：** 序列扩散模块采用 Transformer 去噪，线性噪声表从 0.0001 到 0.02，T=1000，并使用 6 层、8 头注意力学习去噪表示。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.4]
- **method：** 结构扩散模块结合 multi-scale encoder、GAT、多头注意力、残差连接和 global attention，对残基图特征进行去噪优化。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.5]
- **method：** 训练目标把 sequence/structure 的 denoising loss 与 SMCL、DMCL 按权重组合，再通过 cross-attention、gating 和三层 MLP 完成二分类。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.5]；[doi:10.1093/bioinformatics/btag077, p.6]
- **results：** 正文报告该方法在 ACC、F1、Sn、Sp 和 AUC 上整体优于九个基线方法，但具体数值主要放在补充表中。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.7]
- **results：** 消融结果表明，single-modal contrastive learning、dual-modal contrastive learning、multi-scale encoder、sequence diffusion、structure diffusion 等组件都对性能有贡献，其中两类 diffusion 贡献更大。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.7]
- **results：** 序列扩散后，特征均值差约为 1.1，且 P-value < .001、Cohen’s d > 1.5；F341、F229、F34 等特征呈现更强区分度。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.7]
- **results：** 结构扩散后的平均特征差约为 1.63，同样满足 P-value < .001 且 Cohen’s d > 1.5，t-SNE 也显示融合后与分类后分离度继续提升。
  - 证据：[doi:10.1093/bioinformatics/btag077, p.8]

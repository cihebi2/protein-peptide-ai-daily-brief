## 作者主张的创新点

作者提出 MoleculeFormer：一个结合 atom graph、bond graph、GCN、Transformer、EGNN 与分子指纹的多尺度分子性质预测框架，并在 28 个数据集上报告了较强的性能、可解释性和抗噪声能力。

## 创新边界

`主要新意在于预测模型结构与多源特征融合，不涉及候选分子的生成或优化，也未在冻存证据中给出独立 prior-art 验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在分子性质预测中同时利用原子图、键图、3D 几何信息和先验分子指纹，并提升泛化、可解释性与噪声鲁棒性。

## 方法

- 原子/键图GCN、Transformer全局聚合与fingerprint分支融合。

## 数据与基准

- 28个MoleculeNet、ADME、breast cancer任务。

## 比较基线

- 传统fingerprint、GCN、graph transformer及融合消融。

## 结果证据

- 论文报告分类/回归多任务稳健；为计算性质预测。

## Pi 结构化证据摘录

- **baseline：** MoleculeNet 表中的基线包括 MoleculeNet (Graph)、Chemprop、Attentive FP、HRGCN+ 和 FP-GNN。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.5]
- **baseline：** breast cell line 对比基线包括 Attentive FP、MPNN、XGBoost、FP-GNN，以及从 MoleculeFormer 中单独抽取的 FP 模块。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.6]
- **baseline：** 噪声鲁棒性实验还对比了 Attentive FP、FP-GNN 与 XGBoost。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.6]
- **data：** 实验覆盖 MoleculeNet 的 10 个核心基准任务，包含分类与回归，并采用 random 与 scaffold 两种切分方式。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.3]；[doi:10.1038/s42003-025-09064-x, p.4]
- **data：** 细胞表型筛选数据来自 14 个 breast cancer cell lines，共保留 33,757 个 active 与 21,152 个 inactive compounds。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.5]；[doi:10.1038/s42003-025-09064-x, p.6]
- **data：** ADME 部分使用 Biogen 相关数据，包含 HLM、MDR1-MDCK ER、RLM 和 SOLUBILITY 四个任务。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.5]；[doi:10.1038/s42003-025-09064-x, p.7]
- **declared_resources：** 代码公开在 GitHub 与 Zenodo。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.10]
- **declared_resources：** 数据来源明确列出 MoleculeNet、ChemBC 和 Computational-ADME。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.10]
- **declared_resources：** 实验环境声明为 Python 3.9 与 Torch 2.7.1。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.10]
- **limitations：** 作者明确指出，三项回归任务中的训练分子数量较少，限制了 attention 机制的充分发挥。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.4]
- **limitations：** 在 HIV、Tox21、MUV 等更困难且可能类别不平衡的数据集上，PR-AUC 仍然较低，说明模型并未完全解决难样本问题。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.4]
- **limitations：** 大规模 100k 分子场景下训练/推理时间较长，因此作者另做 MoleculeFormer-Mini，并承认其会牺牲少量准确率。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.5]
- **method：** 将 SMILES 先经一般力场优化，再分别转换为 atom graph 与 bond graph，并用原子/键特征矩阵表示输入。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.9]；[doi:10.1038/s42003-025-09064-x, p.10]
- **method：** 模型主体由独立训练的 GCN 局部特征提取和带 EGNN 的 equivariant Transformer 编码器组成，以 CLS 作为全局分子表示。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.3]；[doi:10.1038/s42003-025-09064-x, p.9]；[doi:10.1038/s42003-025-09064-x, p.10]
- **method：** 作者把 molecular fingerprints 作为先验知识注入，并在图卷积与注意力之外加入 3D 坐标的旋转/平移等变更新。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.1]；[doi:10.1038/s42003-025-09064-x, p.2]；[doi:10.1038/s42003-025-09064-x, p.10]
- **results：** 在 MoleculeNet 评测中，作者称该模型在 13 个任务上的平均表现最好，并给出 BACE PR-AUC 0.87±0.04、BBBP PR-AUC 0.97±0.01、ClinTox PR-AUC 0.98±0.01 等结果。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.4]；[doi:10.1038/s42003-025-09064-x, p.5]
- **results：** 在 14 个 breast cancer cell line 数据集上，MoleculeFormer 的平均 ROC-AUC 为 0.862，高于所列对比模型。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.6]
- **results：** 在 HIV 标签噪声实验中，MoleculeFormer 被报告为比 Attentive FP、FP-GNN 和 XGBoost 更稳健。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.6]
- **results：** 消融结果显示完整模型平均 RMSE 为 0.495，优于 GCN、Atom、Atom+Bond、FP 以及 Atom+Bond+FP。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.7]
- **results：** 可解释性案例显示，模型关注高 cLogP 区域与 polar bonds / HBD 特征，且与 BBB permeability 的已知化学规律一致。
  - 证据：[doi:10.1038/s42003-025-09064-x, p.7]；[doi:10.1038/s42003-025-09064-x, p.8]

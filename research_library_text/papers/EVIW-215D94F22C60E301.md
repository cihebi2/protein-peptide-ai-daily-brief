# MMPred: a tool to predict peptide mimicry events in MHC class II recognition

- **论文 ID：** `EVIW-215D94F22C60E301`
- **期刊 / 来源：** Front Genet
- **发表时间：** 2024 Dec 10
- **DOI：** [10.3389/fgene.2024.1500684](https://doi.org/10.3389/fgene.2024.1500684)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出了 MMPred，一个面向非专家的整合式工具：它以 fasta 序列和 HLA allele 列表为输入，可选用 BLASTp 或 PSI-BLAST 做 alignment，再结合 CNN-PepPred 与 NetMHCIIpan 4.1（BA/EL）进行 MHC class II 预测，并输出候选 mimicry 事件、预测 binding core、以及基于人蛋白网络的功能关联结果。

## 创新边界

`其创新边界主要是流程集成与分析包装，不是新训练的预测模型；核心仍复用现成的 alignment、epitope prediction 和 network-analysis 组件。`。这不是全球首创性检索或独立复现结论。

## 研究问题

本文要解决的是：如何把序列相似性搜索、MHC class II 表位预测和后续系统生物学解释串成一个可用流程，用于从 query/target 两组蛋白或肽序列中筛查可能的 molecular mimicry 事件，并据此提出潜在的 human autoantigen / autoepitope 候选。

## 方法

- 在微生物表位与人自身表位/蛋白组间比对，随后对HLA-II结合进行双预测器筛选，按置换/百分位和功能网络排序候选。

## 数据与基准

- IEDB下载的微生物HLA-II阳性配体集MEDS、人自身免疫表位集HADS、SARS-CoV-2肽集和人类蛋白组。

## 比较基线

- BLASTp与PSI-BLAST两种检索，NetMHCIIpan 4.1和CNN-PepPred双表位预测；不构成独立端到端基线胜负。

## 结果证据

- 论文提供监督案例与SARS-CoV-2候选分析，但明确说明由于已知阳性/阴性分子模拟事件极少，不宜给出工具总体统计性能；MOV10等属于预测候选而非实验自免因果。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 缺乏足够的真阳性/真阴性分子模拟标签，无法可靠估计敏感性特异性；结论依赖上游MHC预测器和序列比对，案例需免疫实验验证。

## 仍未知

- GitHub 仓库内容与可复现脚本未在本次冻结纸本文本中逐项核验。
- SARS-CoV-2 与 autoimmunity 的因果链条仍主要依赖相关性、网络评分和结构相似性，缺少直接实验闭环。
- 论文中未提供独立于所用预测器之外的全新 MHC II 基础模型训练证据。

## Pi 结构化证据摘录

- **baseline：** 作者将 CRESSP 作为最接近的整合式先前工具，但指出它主要面向 B-cell epitopes，且公开工具版本实际只整合了 MHC class I 的 MHCflurry 预测。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.2]
- **baseline：** 功能分析用 HPDS 的随机 1000 蛋白子样本作为背景分布，来判断 predicted autoantigens 的 network score S 是否偏高。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.9]；[doi:10.3389/fgene.2024.1500684, p.10]
- **baseline：** alignment 侧的内部对照是 BLASTp 与 PSI-BLAST 的直接比较，作者借此判断引入 PSSM 后是否更能捕捉生物学相关的 mimicry 信号。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.3]；[doi:10.3389/fgene.2024.1500684, p.10]
- **data：** MEDS 数据集来自 IEDB 的手工筛选，保留了与自身免疫病相关微生物的 HLA class II epitopes；最终包含 3,676 个 epitopes、88 个蛋白、13 个微生物、50 个 HLA class II alleles，共 9,229 个 epitope-allele pairs。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.6]
- **data：** HADS 数据集同样来自 IEDB，筛选 human source、autoimmune disease 相关的 class II epitopes；合并重叠 nested sets 后得到 807 个 epitopes、608 个 human proteins、5 个 HLA class II alleles。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.7]
- **data：** HPDS 是从 UniProt 下载的 20,426 个 reviewed human proteins，作为全人蛋白组背景集合。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.7]
- **data：** SC2DS 由 SARS-CoV-2 reference proteome 和 Pangolin variants 构成，并被手工切成所有重叠的 15-mers；最终共有 9,608 个 15-mers，其中 243 个来自变异株。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.8]
- **data：** MHCII-EDS 包含 IEDB 中下载的全部 class II epitopes，去冗余后按 95% identity 聚类，最终保留 155,923 个 cluster centroid，用于 PSI-BLAST 的 PSSM 构建。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.8]
- **declared_resources：** 论文明确给出 MMPred 的 GitHub 仓库和 user guide，表示代码对外公开。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.1]
- **declared_resources：** 实现环境写明为 Python 3.6.8，并列出 Pandas、NumPy、Matplotlib、sklearn 和 TensorFlow 等依赖。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.2]
- **declared_resources：** 论文使用的外部资源包括 IEDB、UniProt、CD-HIT、BLASTp、PSI-BLAST、NetMHCIIpan 4.1、CNN-PepPred、Expression Atlas、g:Profiler、FAMSA 以及 NCBI Virus。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.6]；[doi:10.3389/fgene.2024.1500684, p.8]；[doi:10.3389/fgene.2024.1500684, p.10]；[doi:10.3389/fgene.2024.1500684, p.12]
- **declared_resources：** 结构分析部分明确使用了 NSP13 的晶体结构 6ZSL 和 MOV10 的 AlphaFold model（Q9HCE1）。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.13]
- **limitations：** 作者明确表示，已知的人类 mimicry 相关 autoepitopes 太少，因此无法做真正有意义的统计性能评测；若硬做，主要也只是在重复验证 CNN-PepPred 和 NetMHCIIpan。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.2]
- **limitations：** 更严格的 alignment 阈值，尤其是 PSI-BLAST 配合 E-value 0.001，会把 hits 大幅压缩，甚至在某些设置下直接没有候选。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.5]；[doi:10.3389/fgene.2024.1500684, p.10]
- **limitations：** SARS-CoV-2 相关的功能与结构推断仍然是 hypothesis-generating；作者也承认 predicted autoepitopes 与 autoimmune diseases 之间缺少直接实验验证。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.11]；[doi:10.3389/fgene.2024.1500684, p.13]
- **limitations：** 工具当前原生只支持 MHC class II；若要扩展到 class I，需要额外接入预训练模型。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.2]
- **method：** MMPred 的最小输入是 query fasta 文件和 MHC allele 列表；若提供 target fasta，则可进入 mimicry 搜索流程。protein mode 会对每条蛋白按窗口大小 W 做 1-residue 滑窗切片，peptide mode 则直接对短肽整体预测。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.2]；[doi:10.3389/fgene.2024.1500684, p.3]
- **method：** alignment 这一步可选 BLASTp 或 PSI-BLAST；若相似性达到用户设定阈值（默认 E-value < 0.05），对应 target 序列会被保留到 TARGET*，再继续做 epitope prediction。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.3]；[doi:10.3389/fgene.2024.1500684, p.4]
- **method：** 表位预测同时调用 NetMHCIIpan 4.1 的 BA 与 EL 模型，以及 CNN-PepPred；作者不做 consensus，而是保留三路结果，并输出 9-mer binding core、score、%Rank、alignment 位置和 allele 信息。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.4]；[doi:10.3389/fgene.2024.1500684, p.5]；[doi:10.3389/fgene.2024.1500684, p.6]
- **method：** 功能评估把被预测为 autoantigen 的人蛋白映射到 BED / human protein network 中的 autoimmune motifs，并用 ANN 得到 score S；随后与 HPDS 随机抽样 1000 蛋白的背景分布做 Mann-Whitney U 检验比较。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.9]；[doi:10.3389/fgene.2024.1500684, p.10]
- **method：** 在 SARS-CoV-2 案例里，作者进一步用 Perc(S) 阈值（>95、>99、>99.9）解释 autoantigen 与疾病 motif 的关联，并结合 Expression Atlas、g:Profiler、PDB 和 AlphaFold 做补充验证式解读。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.10]；[doi:10.3389/fgene.2024.1500684, p.11]；[doi:10.3389/fgene.2024.1500684, p.12]；[doi:10.3389/fgene.2024.1500684, p.13]
- **results：** 在监督评估中，807 个已知 human autoepitopes 里有 21 个至少与 MEDS 的 microbial epitope 显著对齐，并且被 CNN-PepPred 和/或 NetMHCIIpan 预测为 autoepitope。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.10]
- **results：** 其中 4 个案例还能在 epitope-allele level 上匹配到已知同一 HLA allele；代表性 autoantigens 包括 H1-2、H1-4 和 MPO。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.10]
- **results：** 在功能评估中，PSI-BLAST 虽然显著减少命中数，但平均 score ratio 和统计显著性更强；作者据此认为 E-value 0.01 与 %Rank 2 是更平衡的筛选阈值。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.5]；[doi:10.3389/fgene.2024.1500684, p.10]
- **results：** SARS-CoV-2 分析里，BLASTp 在 E-value 0.01 下识别出 14 个潜在 autoantigens，而 PSI-BLAST 在同阈值下没有检出候选、在 0.05 下仅检出 HELZ2；8 个蛋白在 19 个 motif 上达到 Perc(S) ≥95，且 MOV10 在 Lupus Erythematosus Systemic motif 上超过 99.9。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.11]
- **results：** 作者还报告 NSP13 与 MOV10 之间存在 214-residue 的 structural similarity，Cα RMSD 为 1.98 Å，而且两者对应 epitope 在结构上重叠。
  - 证据：[doi:10.3389/fgene.2024.1500684, p.13]

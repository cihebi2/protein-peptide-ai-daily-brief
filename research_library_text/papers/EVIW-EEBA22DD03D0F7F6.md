# High-throughput prediction of protein conformational distributions with subsampled AlphaFold2

- **论文 ID：** `EVIW-EEBA22DD03D0F7F6`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Mar 27
- **DOI：** [10.1038/s41467-024-46715-9](https://doi.org/10.1038/s41467-024-46715-9)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `结构预测`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称通过缩减 MSA 深度、调整 AF2 采样并增加独立预测，可高通量地产生构象集合并推断相对状态人口；在 Abl1、Src、Anc-AS 和 GMCSF 上与 NMR/MD 结果总体一致。

## 创新边界

`更偏向对现有 AF2 的采样参数化与用法改造，而不是新的端到端结构生成模型。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在只给定序列和 MSA 的情况下，是否能利用 subsampled AlphaFold2 估计蛋白不同构象状态的相对占比，并跟踪突变或进化导致的构象分布变化。

## 方法

- 对同一序列反复随机子采样 MSA、运行 AlphaFold2，将输出聚类到已知/新构象态，以预测频率近似相对群体和突变引起的群体变化。[doi:10.1038/s41467-024-46715-9, p.1][doi:10.1038/s41467-024-46715-9, p.2]

## 数据与基准

- 以 Abl1 激酶和粒细胞-巨噬细胞集落刺激因子的 NMR 群体为主要测试，并分析 Src、突变体及 MD 对照。[doi:10.1038/s41467-024-46715-9, p.1][doi:10.1038/s41467-024-46715-9, p.4]

## 比较基线

- NMR 实验群体、MD 模拟和默认/不同 MSA 深度的 AlphaFold2 输出。[doi:10.1038/s41467-024-46715-9, p.1][doi:10.1038/s41467-024-46715-9, p.2]

## 结果证据

- 两个主要 NMR 体系上作者报告相对状态变化预测准确率超过 80%，最适合定性预测高占比态和突变/演化趋势。[doi:10.1038/s41467-024-46715-9, p.1]

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 低占比状态可能完全漏检，例如 Src 的稀有 I2 态；结果受 AF2 训练结构分布和 MSA 深度影响，预测频率也不是严格玻尔兹曼概率。[doi:10.1038/s41467-024-46715-9, p.4]

## 仍未知

- Supplementary Appendix 的具体实验细节与统计检验未逐页核对。

## Pi 结构化证据摘录

- **baseline：** 作者把默认 AF2 主要面向 ground state、且先前 ensemble 方法常需 sequence clustering 加后续 MD 的做法作为背景对照。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.1]；[doi:10.1038/s41467-024-46715-9, p.2]
- **baseline：** 实验/模拟基准主要来自 Abl1 的 NMR 参考状态、GMCSF 的 NMR 化学位移结果，以及 Abl1 的 enhanced-sampling MD 轨迹。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.3]；[doi:10.1038/s41467-024-46715-9, p.6]；[doi:10.1038/s41467-024-46715-9, p.7]
- **baseline：** 正文把这种做法描述为相对既有 AF2 ensemble 路线的推进，因为它试图直接从 subsampled AF2 给出相对状态人口，而不把主要信息外包给后续 MD。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.2]；[doi:10.1038/s41467-024-46715-9, p.9]
- **data：** Abl1 kinase core 的 MSA 超过 600,000 条序列，而 GMCSF 的 MSA 只有 112 条左右，构成深浅序列信息的强对照。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.2]；[doi:10.1038/s41467-024-46715-9, p.5]；[doi:10.1038/s41467-024-46715-9, p.7]
- **data：** 主要对照对象包括 Src kinase、Anc-AS、Abl1 的 8 个单/双突变体，以及补充材料中的额外 8 个蛋白系统。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.3]；[doi:10.1038/s41467-024-46715-9, p.5]；[doi:10.1038/s41467-024-46715-9, p.8]；[doi:10.1038/s41467-024-46715-9, p.10]
- **data：** GMCSF 数据侧聚焦于野生型和 H15/H83/H87 位点突变体，并以化学位移扰动和 broadened peaks 描述动态差异。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.7]；[doi:10.1038/s41467-024-46715-9, p.8]；[doi:10.1038/s41467-024-46715-9, p.11]
- **declared_resources：** 论文明确使用 AlphaFold2 及 localcolabfold 1.5.0，并依赖 JackHMMR、UniRef90、smallBFD 和 MGnify 生成输入 MSA。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.11]
- **declared_resources：** Abl1 的对照分析使用 WESTPA2 和 OpenMM 做增强采样 MD，结构可视化与几何测量用 PyMOL。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.11]
- **declared_resources：** GMCSF 的实验流程用到 Bruker Avance NEO 600 MHz、NMRPipe、Sparky，以及 Brown University 的计算资源。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.11]；[doi:10.1038/s41467-024-46715-9, p.13]
- **declared_resources：** 作者公开了 GitHub 仓库和 Zenodo 归档，用于 MSA、AF2 脚本和部分分析数据。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.11]；[doi:10.1038/s41467-024-46715-9, p.12]
- **limitations：** Src 的低占据 I2 态没有被捕捉到，作者将其解释为当前实现的分辨率限制，并与训练集偏向 ground state 有关。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.4]
- **limitations：** M290L、H83N、H83Y 和 H87Y 等案例存在方向或幅度误差，因此结果仍不能视为严格定量的 Boltzmann ratio 预测。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.5]；[doi:10.1038/s41467-024-46715-9, p.8]；[doi:10.1038/s41467-024-46715-9, p.10]
- **limitations：** GMCSF 在浅 MSA 条件下偶发 partial unfolding，Aggressive subsampling 也会让部分额外测试蛋白出现非功能性构象。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.7]；[doi:10.1038/s41467-024-46715-9, p.10]
- **limitations：** 作者对 A1 只给出假说式解释，并建议用 CEST 或 residual dipolar coupling 进一步验证其是否为真实亚稳态。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.8]
- **method：** 作者用 JackHMMR 从 UniRef90、smallBFD 和 MGnify 构建 MSA，并在 AF2 推理时通过调小 max_seq/extra_seq、开启 dropout 和多种 seeds 来采样构象集合。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.2]；[doi:10.1038/s41467-024-46715-9, p.11]
- **method：** Abl1 相关分析还把 subsampled AF2 结果与 enhanced-sampling MD 轨迹逐帧比较，MD 由 WESTPA2 与 OpenMM 实现。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.3]；[doi:10.1038/s41467-024-46715-9, p.6]；[doi:10.1038/s41467-024-46715-9, p.11]
- **method：** GMCSF 部分包含蛋白表达纯化与 600 MHz NMR 采集，并用 HSQC、CSP 和 peak broadening 评估突变效应。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.7]；[doi:10.1038/s41467-024-46715-9, p.11]
- **results：** Abl1、Src 和 Anc-AS 的预测 ground-state 占比分别约为 89%、97% 和 93%，与实验上已知的相对排序一致。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.4]
- **results：** 对 Abl1 allelic series，方法在定性方向上正确预测了超过 80% 的突变效应，但 M290L 出现反向误判，双突变幅度也被低估。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.1]；[doi:10.1038/s41467-024-46715-9, p.5]；[doi:10.1038/s41467-024-46715-9, p.10]
- **results：** GMCSF 中，方法能区分 H15/H83 与 H87 的敏感性差异，并在 H83/H87 突变体中发现富集的替代构象 A1。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.7]；[doi:10.1038/s41467-024-46715-9, p.8]；[doi:10.1038/s41467-024-46715-9, p.9]
- **results：** 附加的 8 个蛋白系统显示该方法更适合大型、慢速构象变化；对更快或低占据态变化，预测分辨率会下降。
  - 证据：[doi:10.1038/s41467-024-46715-9, p.10]

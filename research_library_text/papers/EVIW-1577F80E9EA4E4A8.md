# Evaluating GPT and BERT models for protein-protein interaction identification in biomedical text

- **论文 ID：** `EVIW-1577F80E9EA4E4A8`
- **期刊 / 来源：** Bioinform Adv
- **发表时间：** 2024 Sep 11
- **DOI：** [10.1093/bioadv/vbae133](https://doi.org/10.1093/bioadv/vbae133)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称系统评估 GPT-3.5 与 GPT-4 在 PPI 文本识别中的表现，并与 BioBERT、SciBERT、PubMedBERT 在三个金标准语料上比较，同时分析 prompt engineering、蛋白词典、PROTEIN masking 和温度参数对结果的影响。

## 创新边界

`创新边界主要是现有大模型在 PPI 关系抽取上的评测与提示工程优化，而不是提出新的候选生成或新的湿实验方法；冻结证据不足以证明全球首创。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在生物医学文本中自动识别蛋白-蛋白相互作用（PPI），以缓解人工抽取成本并支持文献挖掘与下游生物医学研究。

## 方法

- 将句子与候选蛋白对输入prompt或fine-tuned encoder，做关系二分类并按三语料precision/recall/F1评价。

## 数据与基准

- LLL 77句/164交互、HPRD50 145句/163交互、IEPA 486句/335交互。

## 比较基线

- GPT-3.5、GPT-4、BERT、BioBERT及其他encoder模型。

## 结果证据

- LLL上BioBERT recall 91.95%、F1 86.84%；GPT-4 precision 88.37%、recall 85.14%、F1 86.49%。结果不代表抽取到的PPI已实验复核。

## Pi 结构化证据摘录

- **baseline：** 论文将 Miwa 2009、Bui 2011、Yu 2018 等传统机器学习式 PPI 抽取方法作为对照，并把其结果汇总在补充表中。
  - 证据：[doi:10.1093/bioadv/vbae133, p.8]
- **baseline：** BioBERT、SciBERT 与 PubMedBERT 作为主要 BERT 对照模型，与 GPT 系列在相同数据划分下比较。
  - 证据：[doi:10.1093/bioadv/vbae133, p.2]；[doi:10.1093/bioadv/vbae133, p.3]
- **data：** LLL 数据集包含 77 句、164 个正对与 166 个负对；IEPA 包含 486 句、335 个正对与 482 个负对；HPRD50 包含 145 句、163 个正对与 270 个负对。
  - 证据：[doi:10.1093/bioadv/vbae133, p.3]
- **data：** GPT 侧为每个数据集编制蛋白词典，并做去标点、去纯数字、去空白和小写化归一化；BERT 侧将目标实体对替换为 PROTEIN1/PROTEIN2，其他蛋白替换为 PROTEIN。
  - 证据：[doi:10.1093/bioadv/vbae133, p.3]
- **data：** GPT 的 masked 设置还区分原始字典与归一化字典，并对较大的 folds 做拆分后再合并输出，以适配上下文窗口限制。
  - 证据：[doi:10.1093/bioadv/vbae133, p.3]；[doi:10.1093/bioadv/vbae133, p.4]
- **declared_resources：** 论文声明源代码与数据集可在 https://github.com/hurlab/PPI-GPT-BERT/ 获取。
  - 证据：[doi:10.1093/bioadv/vbae133, p.1]；[doi:10.1093/bioadv/vbae133, p.9]
- **declared_resources：** GPT 通过 OpenAI API 调用，BioBERT/SciBERT/PubMedBERT 从 Hugging Face 获取，BERT 微调在 Tesla A100 上完成。
  - 证据：[doi:10.1093/bioadv/vbae133, p.2]；[doi:10.1093/bioadv/vbae133, p.3]；[doi:10.1093/bioadv/vbae133, p.4]
- **limitations：** 作者明确指出模型范围有限，仅覆盖 GPT-3.5/4 与三种 BERT 模型，未纳入更广泛的 LLM 或其他架构。
  - 证据：[doi:10.1093/bioadv/vbae133, p.8]
- **limitations：** 三个语料规模并不大，因此结果对更大、更异质数据集的泛化能力可能受限。
  - 证据：[doi:10.1093/bioadv/vbae133, p.8]
- **limitations：** GPT 的实际部署伴随较高的计算与金钱成本，限制其在真实场景中的可用性。
  - 证据：[doi:10.1093/bioadv/vbae133, p.8]
- **method：** 使用 OpenAI API 调用 GPT-3.5–0613 与 GPT-4–0613 进行零样本文本抽取，并将其与 BioBERT、SciBERT、PubMedBERT 的微调结果对比。
  - 证据：[doi:10.1093/bioadv/vbae133, p.2]；[doi:10.1093/bioadv/vbae133, p.4]；[doi:10.1093/bioadv/vbae133, p.5]
- **method：** 在 LLL、IEPA、HPRD50 三个金标准数据集上采用 document-level 10-fold 划分，GPT 与 BERT 共享相同 folds，并额外使用 PROTEIN masking 以降低原始蛋白名带来的泄漏风险。
  - 证据：[doi:10.1093/bioadv/vbae133, p.3]；[doi:10.1093/bioadv/vbae133, p.4]
- **method：** GPT prompt 被拆成 7 个 section 逐节搜索候选模板，以 F1 选择最优 prompt；Section 1 至 7 的候选数分别为 128、54、96、72、72、24 和 12。
  - 证据：[doi:10.1093/bioadv/vbae133, p.4]；[doi:10.1093/bioadv/vbae133, p.5]
- **method：** BERT 模型采用 AdamW 微调，搜索 learning rate、weight decay、batch size 与最大句长，并在 Tesla A100 上进行 10-fold cross-validation。
  - 证据：[doi:10.1093/bioadv/vbae133, p.4]
- **results：** 在 LLL 上，GPT-4 加 protein dictionary 的 precision 为 88.37%，recall 为 85.14%，F1 为 86.49%；BioBERT 在该集上获得最高 recall 91.95% 和 F1 86.84%。
  - 证据：[doi:10.1093/bioadv/vbae133, p.1]；[doi:10.1093/bioadv/vbae133, p.5]
- **results：** 在 IEPA 上，GPT-3.5 的 PROTEIN masking（one sentence at a time）取得最高 precision 78.95%，GPT-4 同设定取得最高 recall 79.41% 与 F1 71.54%；BioBERT 的 recall 83.21% 和 F1 78.81% 最优，PubMedBERT 的 precision 77.70% 最优。
  - 证据：[doi:10.1093/bioadv/vbae133, p.6]
- **results：** 在 HPRD50 上，GPT-4 的 PROTEIN masking（one sentence at a time）取得最高 recall 95.22%；PubMedBERT 在该集上达到 precision 78.81%、recall 82.71% 和 F1 79.65%，为整体最佳。
  - 证据：[doi:10.1093/bioadv/vbae133, p.6]

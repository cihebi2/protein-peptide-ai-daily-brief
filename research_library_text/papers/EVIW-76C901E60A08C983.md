# KGDiff: towards explainable target-aware molecule generation with knowledge guidance

- **论文 ID：** `EVIW-76C901E60A08C983`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2023 Dec 1
- **DOI：** [10.1093/bib/bbad435](https://doi.org/10.1093/bib/bbad435)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 KGDiff：把 AutoDock Vina 的 binding affinity 知识蒸馏进 diffusion model，使用共享表示的 SE(3)-invariant expert network 进行 affinity fitting，并在 denoising 过程中同时指导 atom coordinates 与 atom types 的生成，还给出 atom-level explanation。

## 创新边界

`新意主要在“知识引导的 target-aware 分子生成”这一方法边界内：把现有 Vina 亲和力知识注入扩散采样与解释；它没有宣称新的 wet-lab 数据、也没有独立的 prior-art 验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在给定 protein target / pocket 的 3D 结构条件下，生成能够高 affinity binding 的候选 molecule，并同时提升可解释性与对生成过程的可控性。

## 方法

- CrossDocked pocket-conditioned diffusion与joint expert network。

## 数据与基准

- CrossDocked2020。

## 比较基线

- Pocket2Mol/TargetDiff等。

## 结果证据

- 论文报告生成与Vina指标超过SOTA；所谓experimental results是计算实验。

## Pi 结构化证据摘录

- **baseline：** 对比基线包括 liGAN、GraphBP、AR、Pocket2Mol、TargetDiff，以及来自数据集的 reference ligand / protein-ligand pair。
  - 证据：[doi:10.1093/bib/bbad435, p.5]
- **baseline：** TargetDiff 是最接近的 diffusion baseline；作者还说明去掉 affinity branch 并令 λ=0 时，KGDiff 会退化回 TargetDiff。
  - 证据：[doi:10.1093/bib/bbad435, p.3]
- **baseline：** 文中强调 KGDiff 相对 reference 在 Vina Score 上也有提升，用来说明其生成结果不仅优于学习到的生成基线，也优于原始配体参考。
  - 证据：[doi:10.1093/bib/bbad435, p.4]；[doi:10.1093/bib/bbad435, p.5]
- **data：** 主要实验在 CrossDocked2020 benchmark 上进行，并以其 protein-ligand 结构对作为评估基础。
  - 证据：[doi:10.1093/bib/bbad435, p.1]；[doi:10.1093/bib/bbad435, p.5]
- **data：** 作者说明每个方法评估时生成 10,000 molecules，并报告 Vina Score、Vina Minimize、Vina Dock、High Affinity、QED 与 SA。
  - 证据：[doi:10.1093/bib/bbad435, p.5]
- **data：** 文中还做了 GPCR、ion channel、kinase、phosphatase 等 protein category 的案例分析，以及 TNKS1 / TNKS2 subtype selectivity 分析。
  - 证据：[doi:10.1093/bib/bbad435, p.6]；[doi:10.1093/bib/bbad435, p.7]；[doi:10.1093/bib/bbad435, p.8]
- **declared_resources：** Funding 来自 National Natural Science Foundation of China (62172273) 与 Shanghai Municipal Science and Technology Major Project (2021SHZDZX0102)。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **declared_resources：** 作者声明相关 data 可在 Zenodo 记录 8419944 获取。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **declared_resources：** 作者声明相关 code 已公开在 GitHub：https://github.com/CMACH508/KGDiff。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **limitations：** 作者承认当前做法独立地对 atom types 和 atom coordinates 加噪，忽略了二者在 3D space 中的内在依赖。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **limitations：** 化学 bond 的构建没有被显式建模，而是依赖后处理把生成的 3D points 组装成 molecule，可能导致不理想构型和大环。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **limitations：** 模型尚未显式纳入 salt bridges 与 π-π stacking 等更细粒度的 chemical knowledge。
  - 证据：[doi:10.1093/bib/bbad435, p.8]
- **limitations：** 在 flat surface 的 pocket 上性能有限，作者指出分子可能被生成到 pocket 两侧，从而得到很差的 Vina Score。
  - 证据：[doi:10.1093/bib/bbad435, p.7]；[doi:10.1093/bib/bbad435, p.8]
- **method：** 将 molecule 表示为 3D coordinates 与 atom features，在固定 protein pocket 条件下做 forward diffusion，再通过 reverse denoising 重建并逐步生成目标分子。
  - 证据：[doi:10.1093/bib/bbad435, p.2]；[doi:10.1093/bib/bbad435, p.3]
- **method：** 使用 two-branch 模型 φθ：共享的 SE(3)-equivariant GNN φω 负责 atom representation 与 coordinate update，另一分支用 MLP 拟合基于 Vina 的 affinity ˆv，并保持对 SE(3) 变换不变。
  - 证据：[doi:10.1093/bib/bbad435, p.2]；[doi:10.1093/bib/bbad435, p.3]
- **method：** 训练目标由 coordinate reconstruction、categorical KL 和 affinity fitting 三项组成；作者还明确指出，当 λ=0 且去掉 affinity branch 时，方法会退化为 TargetDiff。
  - 证据：[doi:10.1093/bib/bbad435, p.3]
- **method：** 采样阶段利用 expert network 的梯度同时指导连续的 atom coordinates 和离散的 atom types；前者通过 conditional Gaussian shift 实现，后者通过对 one-hot type vector 加 δ 后再施加梯度式更新实现。
  - 证据：[doi:10.1093/bib/bbad435, p.3]；[doi:10.1093/bib/bbad435, p.4]
- **results：** expert network 对 noisy molecules 的 binding affinity 预测与 normalized Vina Score 的相关性很高，Pearson correlation coefficient 达到 94.0%。
  - 证据：[doi:10.1093/bib/bbad435, p.4]
- **results：** 在 Table 1 中，KGDiff 的 binding-related metrics 优于所有对比方法：Vina Score average/median 为 -8.04 / -8.61，Vina Dock average/median 为 -9.43 / -9.43，High Affinity 为 79.2% / 87.0%。
  - 证据：[doi:10.1093/bib/bbad435, p.5]
- **results：** 作者报告 KGDiff 相比 TargetDiff 在 Vina Score 上 average 提升 46.2%、median 提升 36.2%；同时其 binding affinity 也被声称首次超过 reference。
  - 证据：[doi:10.1093/bib/bbad435, p.4]；[doi:10.1093/bib/bbad435, p.5]
- **results：** KGDiff 在 86% 的 protein targets 上取得最佳 binding affinity；此外，作者还观察到 pocket volume 越大通常得分越好，并用 TNKS1/TNKS2 实验支持 subtype selectivity。
  - 证据：[doi:10.1093/bib/bbad435, p.5]；[doi:10.1093/bib/bbad435, p.7]；[doi:10.1093/bib/bbad435, p.8]

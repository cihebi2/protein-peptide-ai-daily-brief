# The Goldilocks paradigm: comparing classical machine learning, large language models, and few-shot learning for drug discovery applications

- **DOI：** [10.1038/s42004-024-01220-4](https://doi.org/10.1038/s42004-024-01220-4)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

药物发现数据集规模差异巨大（几十到几千分子），'没有免费午餐'定理下应如何在小样本（FSLC）、transformer（MolBART）与经典ML（SVR/SVC）之间选择建模策略？

## 作者主张的贡献

提出'Goldilocks学习范式'：<50分子时FSLC占优；50-240分子且多样性高时transformer（MolBART）占优；>240分子时经典SVR+ECFP最优；并开发基于数据集大小与多样性（Murcko骨架数）的模型选择预测器；在5个AD相关激酶（18-2969数据点）上验证并发现MARK1新抑制剂。

## 创新边界

比较性研究；FSLC、MolBART、SVR均为现成方法；'小数据用小模型'的直觉结论并非全新，贡献在于给出可操作的分段阈值与多样性量化；单团队数据集上得出，阈值（50/240）的普适性存疑。

## 创新点证据卡

- **[p1]** 提出按数据集规模+多样性分段的Goldilocks模型选择范式
  - 原文："dataset size and feature distribution (i.e. dataset diversity) determines the optimal algorithm strategy"
- **[p5]** 量化分段阈值：<50用FSLC、50-240高多样性用transformer、>240用经典ML
  - 原文："For datasets <50 molecules, FSLCs dominate. From 50-240 molecules... LLMs such as MolBART outperform"
- **[p5]** 在5个AD相关激酶上验证范式并发现MARK1新抑制剂
  - 原文："we built and applied ML models to discover new kinase inhibitors for AD"

## 方法

- 三类模型（SVR/SVC+ECFP6、MolBART transformer、FSLC）跨多规模数据集系统对比
- 以Murcko骨架数量化数据集多样性
- 构建模型选择启发式与预测器
- 5个AD激酶靶点（GSK3β/ABL1/FYN/CDK5/MARK1）应用验证

## 数据与基准

- ChEMBL激酶IC50数据（18-2969数据点跨度）
- 多种规模与多样性的基准数据集

## 结果证据

- <50分子：FSLC优于经典ML与transformer
- 50-240分子且高多样性：MolBART占优
- >240分子：SVR+ECFP最优
- 发现MARK1新抑制剂（虚拟筛选+实验验证）

## 比较基线

- SVR/SVC经典ML
- MolBART
- FSLC互为基线

## 已知限制

- 阈值边界（50/240）依赖所用数据集分布，外推性未证
- 仅小分子QSAR场景，未涉及蛋白/肽序列任务
- MolBART已非最先进分子LLM

## 作者主张的创新点

作者提出 NeXtMD，一个把机器学习与 ResNeXt 深度学习模块进行堆叠融合的双模块框架；它结合四类序列描述符与两阶段预测流程，用于提高 AIP 识别精度并增强可解释性与泛化能力。

## 创新边界

`创新点主要在分类框架集成与特征融合，不是湿实验筛选，也不是候选肽生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

短抗炎肽（AIP）序列通常较短、信息量有限，传统实验筛选成本高，现有计算方法在特征表达、模型融合与泛化方面仍存在不足，因此需要更准确的 AIP 识别方法。

## Pi 结构化证据摘录

- **baseline：** 内部对照包括单独的 RF、XGBoost、LightGBM、GBDT，以及四者集成后的 stacking 结果，用于衡量 ResNeXt 融合的增益。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.3]；[doi:10.1186/s12915-025-02314-8, p.4]
- **baseline：** 外部基准模型包括 TriStack、AIPStack、TriNet 和 PPTPP 的 cls/prb/fus 变体，作者声明这些模型使用同一数据集和官方实现重训。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.5]
- **baseline：** Ablation 基线分别移除单个分类器或单个描述符，以检验 RF、XGBoost、LightGBM、GBDT 以及 DDE、CKSAAP、PP16、ACH 的边际贡献。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.8]；[doi:10.1186/s12915-025-02314-8, p.10]
- **baseline：** 迁移到 AMP 任务时，比较基线为 TriStack 与 TriNet。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.13]
- **data：** 内部数据集包含训练集 3,495 条（1,398 AIP / 2,097 non-AIP）和测试集 699 条（280 / 419），并采用五折交叉验证降低过拟合风险。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.14]
- **data：** 外部验证使用 DeepAIP、BertAIP 和 AIP-DeepEnC 的互补子集，作者强调这些测试样本与训练数据不重叠。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.8]；[doi:10.1186/s12915-025-02314-8, p.11]
- **data：** 作者还把 DeepAIP 衍生 AIP 与原始 AIP 测试集合并，构建增强数据集，并重新划分训练/测试以评估增量效果。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.8]；[doi:10.1186/s12915-025-02314-8, p.11]
- **data：** 迁移任务中，NeXtMD 还在 AMP 数据集上按与 AIP 相同的预处理流程进行评估。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.8]；[doi:10.1186/s12915-025-02314-8, p.13]
- **declared_resources：** 作者声明训练/测试所用数据与代码已发布到 Zenodo 和 Figshare 仓库。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.17]
- **declared_resources：** 论文所用 AIP 数据来自 IEDB，外部验证与迁移评估又涉及 DeepAIP、BertAIP、AIP-DeepEnC、TriStack 和 AMPs 等公开资源。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.14]；[doi:10.1186/s12915-025-02314-8, p.17]
- **limitations：** 作者明确指出当前数据集仅包含长度小于 40 aa 的肽，因此未必覆盖 AIP 的全部多样性。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.13]
- **limitations：** 作者也承认高维特征空间和堆叠结构会带来较高计算复杂度与潜在冗余，并建议未来使用 mRMR 或 ANOVA 降维。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.13]
- **limitations：** 跨域外部测试中存在指标权衡，例如 BertAIP 上 precision 较低而 recall 较高，说明泛化仍受数据分布影响。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.11]
- **method：** NeXtMD 以 IEDB 中经人工验证的线性肽/表位构建 AIP 数据集，将可诱导抗炎细胞因子的样本定义为正类、未诱导者定义为负类，并对 4,194 个非冗余样本按 5:1 划分训练集和测试集。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.14]
- **method：** 模型抽取四类序列描述符：DDE、CKSAAP、PP16 和 ACH，分别覆盖局部二肽偏离、k 间隔氨基酸对、理化属性以及疏水性自相关信息。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.14]；[doi:10.1186/s12915-025-02314-8, p.15]
- **method：** 第一层采用 RF、XGBoost、LightGBM 和 GBDT，在五折交叉验证下输出四个预测分数，并把它们作为 meta-features 供后续融合。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.16]
- **method：** 第二层把 4 维 meta-feature 映射到 64 维后送入 5 个 ResNeXt blocks；每个 block 使用 4 个分组分支、BatchNormalization、Dropout=0.3、残差跳连和 sigmoid 二分类输出。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.16]
- **method：** 论文用 AUC、ACC、precision、recall、F1-score、MCC 作为核心评估指标，并据此比较内部测试、外部测试与迁移任务。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.16]
- **results：** 内部测试中，NeXtMD 的五折结果为 AUC 0.8607、ACC 0.7996、Precision 0.8062、Recall 0.7134、F1-score 0.7513、MCC 0.5884；表 1 还显示五折优于十折。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.4]；[doi:10.1186/s12915-025-02314-8, p.5]
- **results：** 与 TriStack、AIPStack、PPTPP 和 TriNet 等方法相比，NeXtMD 在 6 项指标中的 5 项领先，且 AUC 最高；TriStack 仅在 ACC 上略高。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.5]；[doi:10.1186/s12915-025-02314-8, p.6]
- **results：** 外部验证中，DeepAIP、BertAIP 和 AIPs-DeepEnC 的 AUC 分别为 0.9374、0.7128 和 0.7938，说明模型在相关但不同的数据分布上仍具一定稳健性。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.11]
- **results：** 增强数据后，NeXtMD 的 AUC 提升到 0.9783，ACC 提升到 0.9317，F1-score 提升到 0.9200，MCC 提升到 0.8618。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.11]
- **results：** 在 AMP 迁移任务上，NeXtMD 达到 AUC 0.9706、ACC 0.9294、F1-score 0.9160、MCC 0.8189。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.13]
- **results：** UMAP/t-SNE 和 silhouette 分析表明，NeXtMD 学到的表示比原始特征更易分离，且改进具有统计显著性（p < 0.001）。
  - 证据：[doi:10.1186/s12915-025-02314-8, p.7]

# TransFactor—prediction of pro-viral SARS-CoV-2 host factors using a protein language model

- **论文 ID：** `EVIW-204A215535DA2931`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2025 Sep 10
- **DOI：** [10.1093/bioinformatics/btaf491](https://doi.org/10.1093/bioinformatics/btaf491)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 TransFactor：一个基于预训练 ESM-2、结合 LoRA 微调的序列模型，用于从人类蛋白序列中预测并排序 pro-viral SARS-CoV-2 host factors；同时还用 computational alanine scan 提供域/基序层面的可解释性。

## 创新边界

`其创新边界是 sequence-based 的 host-factor prediction、ranking 与解释，不涉及新蛋白或药物的生成/优化，也没有在冻结材料中给出独立湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 SARS-CoV-2 相关宿主因子证据高度噪声化、跨研究一致性差的情况下，能否仅凭蛋白序列对人类蛋白进行可靠的 host factor 识别与优先排序，从而辅助后续实验验证与抗病毒靶点筛选。

## 方法

- ESM-2残基嵌入经注意池化与分类头输出宿主因子概率，LoRA只适配注意权重；六折分组、五模型集成，并用滑窗丙氨酸替换解释COMM、PX、RRM等结构域。

## 数据与基准

- 20,415条人类Swiss-Prot蛋白；正标签由33项SARS-CoV-2筛选/互作组学研究汇总；按MMseqs2相似性聚类后五折交叉验证加一折留出测试。

## 比较基线

- SVM、序列CNN/LSTM类深度学习模型、冻结ESM-2和随机初始化骨干消融。

## 结果证据

- 集成模型在留出测试上AUROC约0.89、APS约0.30、F1约0.38，Precision@50/100/200为0.44/0.37/0.28；候选与GO富集和计算丙氨酸扫描一致，但未完成新候选的功能实验验证。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 输入截断到1024 aa；标签噪声和极端类别不平衡明显；对远缘HIV宿主因子召回仅18%；只用序列且最终需要功能筛选验证。

## 仍未知

- 候选短名单是否被独立湿实验验证，冻结材料未给出。
- GitHub 仓库与 Zenodo 包是否可一键复现全部图表与数值，冻结材料未执行。
- 对更远缘病毒的真实前瞻性泛化能力仍不明确，只有 proxy 级证据。

## Pi 结构化证据摘录

- **baseline：** 传统基线包括基于 3-mer 计数的 TriPepSVM（linear 与 RBF kernel）和 CNN-LSTM；随机初始化 backbone 的 TransFactor 变体也只与这些序列模型大致相当。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.4]；[doi:10.1093/bioinformatics/btaf491, p.5]
- **baseline：** 作者还将单个实验 screen 作为外部参照，其平均 F1 仅 0.13±0.11，precision 0.60±0.25，recall 0.11±0.13，说明计算排序在召回候选方面更有优势。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.5]
- **data：** 输入数据是来自 UniProtKB/Swiss-Prot 的 20,415 条人类 canonical reviewed 蛋白序列，域注释则来自 2024 年 12 月的 UniProtKB 特征集合。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.2]
- **data：** 标签由 33 项独立 SARS-CoV-2 assays 聚合而成：正例 1,045 个、负例 15,434 个、候选 3,936 个；正例标准是至少三项高通量研究或至少一项低通量 functional study 支持。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.2]
- **data：** 候选蛋白不参与训练和性能评估，只用于最终排序与假设生成；作者还把 Baggen review 中整理的实验 screen 作为方法参照。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.2]；[doi:10.1093/bioinformatics/btaf491, p.5]
- **declared_resources：** Paper 明确提供了 source code 的 GitHub 仓库，以及包含 code、trained models 和 data 的 Zenodo reproducibility package。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.1]；[doi:10.1093/bioinformatics/btaf491, p.8]
- **declared_resources：** 超参数搜索与训练评估在配备 Nvidia A100 的机器上进行，单轮 hyperparameter optimization 持续 48h。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.3]
- **declared_resources：** 训练与标注资源来自 UniProtKB/Swiss-Prot 以及 Baggen 等整理的 33 项 SARS-CoV-2 studies，属于本文的数据基础设施。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.2]
- **limitations：** 模型输入被截断到 1024 aa，可能遗漏重要 C-terminal 区域；作者虽在 2048 aa 上复评并看到少量指标提升，但仍因计算成本保留较短长度。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.6]
- **limitations：** 方法只依赖 primary sequence，因此对低同源蛋白和远缘病毒的泛化受限；作者明确建议加入 structure、proteomics 和 PPI network 等正交信息。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.6]；[doi:10.1093/bioinformatics/btaf491, p.7]
- **limitations：** 宿主因子标签本身噪声高且类别极不平衡，文中也强调最终预测仍需后续 functional screen 验证。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.2]；[doi:10.1093/bioinformatics/btaf491, p.7]
- **method：** 使用 ESM-2 encoder-only protein language model 提取蛋白前 1024 个残基的上下文表示，mean pooling 后接线性层与 sigmoid 输出 host-factor score，并仅对 attention 模块应用 LoRA 微调。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.3]；[doi:10.1093/bioinformatics/btaf491, p.4]
- **method：** 训练被定义为带正类加权 λ 的二分类任务；作者先用 mmseqs2 聚类去泄漏，再按簇划分六折，其中五折用于交叉验证、一折保留为最终测试集。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.3]
- **method：** 超参数通过 Optuna 以 AUROC 为目标搜索，单次搜索持续 48h，并用 25 个 epoch 无提升作为早停条件；最终对五个折模型做平均集成以稳定输出。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.3]
- **method：** 作者将 TransFactor 与 TriPepSVM、CNN-LSTM 以及 frozen BB / init BB 消融版本比较，并进一步用 DAVID 做 GO enrichment、用窗口大小 1–40 的 computational alanine scan 做解释。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.4]；[doi:10.1093/bioinformatics/btaf491, p.5]
- **results：** fine-tuned backbone 的 ensemble 在测试集上达到 AUROC 0.89、APS 0.30、F1 0.38，整体优于 SVM、CNN-LSTM 以及随机初始化骨干等对照。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.5]
- **results：** 在实验容量 50、100、200 时，Precision@K 分别为 0.44、0.37、0.28；候选集中共有 883/3936 个蛋白被判为潜在 host factors。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.5]
- **results：** GO enrichment 显示被预测为正的候选与已知正例在 BP/MF/CC 上更接近，Fisher OR 约为 15.0、9.23、4.67，而负向候选的重叠显著更弱。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.5]
- **results：** alanine scan 显示窗口越大，预测分数下降越明显；作者特别指出 COMM、PX 和 RRM 域最敏感，并将 COMMD4 等蛋白的 C-terminal COMM 区段解释为关键位点。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.5]；[doi:10.1093/bioinformatics/btaf491, p.6]
- **results：** 跨病毒 proxy 测试中，模型对 SARS-CoV host factors 的 recall 为 42%，对 HIV host factors 的 recall 为 18%，提示远缘迁移能力有限。
  - 证据：[doi:10.1093/bioinformatics/btaf491, p.6]；[doi:10.1093/bioinformatics/btaf491, p.7]

## 作者主张的创新点

作者提出 FRoGS，将 human gene 的 GO 与 ARCHS4 信息编码为功能向量，并据此训练 Siamese network / logistic regression 的 Model L 来做 compound-target 预测；文中还把该框架与结构和 activity 证据整合，构建更高质量的 compound-target network，并通过 kinase 与 AhR wet-lab assays 做验证。

## 创新边界

`新颖性边界主要在于把 word2vec 式功能嵌入迁移到 gene signature 表征与 target deconvolution，而不是提出新的分子生成、优化或 docking 体系；论文展示的是 representation learning + ranking 框架的迁移与组合。`。这不是全球首创性检索或独立复现结论。

## 研究问题

现有基于基因身份匹配的 gene signature 比较方法在稀疏、弱信号场景下往往难以识别共同通路，从而限制了 L1000 等转录组数据用于 drug target prediction 和 mechanism-of-action 解析的能力。

## Pi 结构化证据摘录

- **baseline：** 作者把 FRoGS 与 CMap score、Fisher's exact test、OPA2Vec GO、OPA2Vec gene、Gene2Vec 和 clusDCA 做了直接比较，其中 FRoGS 在 recall 上表现最佳，而 CMap 和 OPA2Vec GO 接近 random。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.3]；[doi:10.1038/s41467-024-46089-y, p.4]
- **baseline：** 在 activity-based baseline 中，FRoGS/Model L 的表现优于 NCI60 与 PSP models；文中也报告把 Model L 与 pQSAR 合并后能把 pQSAR 的性能进一步推高。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.5]
- **baseline：** 作者还用 structural similarity / SAR probability 作为辅助基线来标注 'structure sure' 与 'structure likely'，以区分仅由转录组推断与可被化学结构支持的预测。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.4]
- **data：** 训练与评估主要依赖 L1000 Connectivity Map、Broad compound-target annotations、Reactome、GO、ARCHS4，以及 NCI60、PSP 和 pQSAR 等数据源。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.12]；[doi:10.1038/s41467-024-46089-y, p.13]
- **data：** 作者报告 pQSAR 内部 activity matrix 覆盖约 5.5 million compounds 与约 12,000 assays；可用于建模的样本中，1601 个化合物有 pQSAR profiles，93 个有 PSP profiles，321 个有 NCI60 profiles。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.12]
- **data：** 实验验证部分包含 19 个 kinase 的 HTRF assays，以及 AhR agonist / antagonist / toxicity reporter assays；相关实验结果被放在 Supplementary Table 2–3 和 Supplementary Data 2–3。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.12]
- **declared_resources：** 作者声明 custom Python code 和 trained gene embedding vectors 已公开在 GitHub: https://github.com/chenhcs/FRoGS。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.13]
- **declared_resources：** 文中将去除 1163 个仅由 in-house activity database 支持的 pairs 后剩余的 5133 个高证据预测，作为 community resource 放在 Supplementary Data 1。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.12]
- **declared_resources：** kinase binders 与 AhR binders 的实验数据分别公开在 Supplementary Table 2–3 和 Supplementary Data 2–3。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.12]
- **limitations：** 论文自己也指出，转录组与 activity profile 主要反映 target downstream effects，因而很难把真正的 target 与 pathway 下游邻居区分开，容易带来 polypharmacology。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.9]
- **limitations：** 作者承认某些 target class 仍然困难，例如 AhR 只有 6 个 reference compounds、且 45% 的预测除 combined model 外没有额外支持证据。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.8]
- **limitations：** 训练与验证在很大程度上依赖内部 proprietary activity datasets 和作者设定的加权/重采样策略，因此外部可复核性和跨数据域泛化仍有不确定性。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.11]；[doi:10.1038/s41467-024-46089-y, p.12]
- **method：** FRoGS 为每个 gene 学习两类 256 维 embedding，分别来自 GO hypergraph 和 ARCHS4 RNA-seq hypergraph，并用 random walk with restart 与 contrastive learning 让功能相近的基因靠近。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.9]；[doi:10.1038/s41467-024-46089-y, p.10]
- **method：** 对 gene signature 的表示不是简单 one-hot，而是先按基因间 cosine similarity 计算权重，再对 signature 内基因做加权聚合，以削弱 noise genes 和 outliers 的影响。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.10]
- **method：** Model L 采用 Siamese neural network 处理 compound signature 与 shRNA/cDNA signature，再用 logistic regression 聚合多 cell line / 多 perturbagen 的排序结果来输出 compound-target 概率。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.10]；[doi:10.1038/s41467-024-46089-y, p.11]
- **results：** 在模拟的 weak pathway signal 场景中，FRoGS 对 foreground-foreground 与 foreground-background 的区分能力整体优于 Fisher's exact test、OPA2Vec、Gene2Vec 和 clusDCA。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.3]
- **results：** 在 L1000 compound-target recall 评估中，FRoGS 达到 36.3% 的 top-5% recall，明显高于 clusDCA 24.9%、Gene2Vec 20.7%、OPA2Vec gene 15.9%、Fisher's exact test 12.3%、OPA2Vec GO 9.5% 和 CMap 9.6%。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.3]；[doi:10.1038/s41467-024-46089-y, p.4]
- **results：** Model L 对全部 L1000 compound-gene pairs 生成了 780,438 个概率高于 0.8 的预测；结合 pQSAR、NCI60、PSP 和结构证据后，作者汇总出 6296 个更高质量的 predictions，覆盖 1406 compounds 与 448 targets。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.4]；[doi:10.1038/s41467-024-46089-y, p.5]；[doi:10.1038/s41467-024-46089-y, p.6]
- **results：** 实验上，1,116 个被预测可结合 19 个 kinases 的 compounds 中，18/19 assays 的 predicted binders 显示更高 confirmation rate；AhR 部分则在 333 个可测 compounds 中确认了 76 个 active binders，约 23% confirmation rate。
  - 证据：[doi:10.1038/s41467-024-46089-y, p.6]；[doi:10.1038/s41467-024-46089-y, p.7]；[doi:10.1038/s41467-024-46089-y, p.8]

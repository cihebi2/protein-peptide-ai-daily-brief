# ChemSpaceAL: An Efficient Active Learning Methodology Applied to Protein-Specific Molecular Generation

## 作者主张的创新点

提出 ChemSpaceAL：用基于分子描述符的化学空间代理、簇级采样、对接打分和主动学习微调，把 GPT 分子生成器朝目标蛋白分布重定向，并展示其可用于 c-Abl kinase 与 HNH Cas9 这类不同难度靶点。

## 创新边界

`新意主要在于“只评估子集 + 簇级分数传播”来驱动生成器重定向；论文不主张新的实验结合机制或新的湿实验筛选体系。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何以较低计算成本，把生成式分子模型定向到特定蛋白靶点，同时尽量只对生成结果中的一小部分分子做对接与打分。

## 方法

- generator采样、uncertainty/diversity acquisition、docking label、迭代训练。

## 数据与基准

- 蛋白靶标、生成库与docking trajectories。

## 比较基线

- random sampling/one-shot fine-tune。

## 结果证据

- 论文报告更少oracle获得高score molecules；为计算。

## Pi 结构化证据摘录

- **baseline：** naive AL 只随机选取 1,000 个分子对接，再用命中阈值的分子及其复制品微调；其高分比例只从 26.2% 增至 44.2%。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.12]；[doi:10.1021/acs.jcim.3c01456, p.67]
- **baseline：** uniform sampling control 把化学空间分成 100 个簇并对每簇等量抽样，虽然优于 naive AL，但最终仍只到 51.1%，低于完整方法的 76.0%。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.15]；[doi:10.1021/acs.jcim.3c01456, p.16]；[doi:10.1021/acs.jcim.3c01456, p.68]
- **baseline：** 作者还将 Filella-Merce 等人的 two-tier active learning 作为相关背景，指出其 outer loop 需要对每个分子做 docking，计算代价较高。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.2]
- **data：** 预训练数据整合自 ChEMBL 33、GuacaMol v1、MOSES 和 BindingDB，去重并剔除无效 SMILES 后得到 5,622,772 条唯一有效分子；再按长度与稀有 token 过滤后保留 5,539,765 条。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.17]；[doi:10.1021/acs.jcim.3c01456, p.18]；[doi:10.1021/acs.jcim.3c01456, p.47]；[doi:10.1021/acs.jcim.3c01456, p.49]
- **data：** c-Abl kinase 采用 PDB ID 1IEP，并以 7 个 FDA 批准的小分子抑制剂设定 score threshold = 37；作者还对 c-Abl 生成阶段施加 ADMET 与 functional group 过滤。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.6]；[doi:10.1021/acs.jcim.3c01456, p.32]
- **data：** HNH domain of Cas9 采用 PDB ID 6O56；由于缺少已知小分子 binder，作者改用 PDBbind v2020 refined set 设定 score threshold = 11。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.11]；[doi:10.1021/acs.jcim.3c01456, p.20]；[doi:10.1021/acs.jcim.3c01456, p.63]
- **data：** 作者在每轮生成 100,000 个分子、抽取 1,000 个进行对接评分，并重复 5 轮主动学习；预训练后模型还在 MOSES benchmark 上被系统评估。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.3]；[doi:10.1021/acs.jcim.3c01456, p.18]；[doi:10.1021/acs.jcim.3c01456, p.54]；[doi:10.1021/acs.jcim.3c01456, p.55]
- **declared_resources：** 作者在数据可用性部分声明，ChemSpaceAL 软件以开源形式发布在 GitHub，并且还提供了 PyPI 包。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.21]
- **limitations：** 打分函数本质上只是粗略启发式：不同相互作用类型的权重是手工设定的，且这些权重会随靶点变化；与 PDBbind refined set 的 Pearson 相关仅为 0.32。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.20]；[doi:10.1021/acs.jcim.3c01456, p.63]
- **limitations：** 该方法依赖于所选 descriptors 与打分函数之间的相关性，论文也明确说 descriptor 选择并未做穷尽研究，因此化学空间代理的有效性并非自动成立。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.19]；[doi:10.1021/acs.jcim.3c01456, p.20]
- **limitations：** 对 HNH 的评估缺少已知小分子 binder，只能借助 PDBbind 阈值做间接代理，因此结论主要是计算层面的，而不是实验结合活性层面的直接验证。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.11]；[doi:10.1021/acs.jcim.3c01456, p.20]
- **method：** 先在约 560 万条去重且有效的 SMILES 上预训练 GPT 式 decoder，然后每轮生成 10 万个唯一分子作为后续主动学习候选池。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.17]；[doi:10.1021/acs.jcim.3c01456, p.18]；[doi:10.1021/acs.jcim.3c01456, p.3]
- **method：** 对生成分子计算 196 个 RDKit descriptors，做 PCA 后保留前 120 个主成分作为 chemical space proxy，再用 k-means（k=100）把分子按相似性质分簇。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.19]；[doi:10.1021/acs.jcim.3c01456, p.3]；[doi:10.1021/acs.jcim.3c01456, p.58]
- **method：** 每轮从各簇中抽样约 1% 分子、共 1,000 个候选，使用 DiffDock 做对接，并用 ProLIF 统计加权的蛋白-配体有利相互作用分数。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.3]；[doi:10.1021/acs.jcim.3c01456, p.15]；[doi:10.1021/acs.jcim.3c01456, p.20]；[doi:10.1021/acs.jcim.3c01456, p.45]
- **method：** 把高于阈值的已评估分子复制进训练集，再按簇均分数经 softmax/softsub 转成采样比例，补入未评估分子，构成约 10,000 个样本的 AL 训练集并继续微调。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.3]；[doi:10.1021/acs.jcim.3c01456, p.20]；[doi:10.1021/acs.jcim.3c01456, p.64]
- **results：** 对 c-Abl 来说，生成分子分布在 5 轮后明显向 FDA 批准抑制剂区域移动，并且后期生成物中甚至精确复现了 imatinib 与 bosutinib。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.7]；[doi:10.1021/acs.jcim.3c01456, p.8]
- **results：** c-Abl 的高分分子占比在 C model 中从 38.8% 升至 91.6%，在 M model 中从 21.7% 升至 80.3%，说明该方法能把生成分布推向更有利的打分区域。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.9]；[doi:10.1021/acs.jcim.3c01456, p.10]
- **results：** 对 HNH domain of Cas9，5 轮后高于阈值的比例在 C model 中从 21.3% 升至 52.1%，在 M model 中从 14.3% 升至 28.2%，表现出与 c-Abl 相似的提升趋势。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.11]
- **results：** 在不加过滤的 HNH 设置下，完整方法把高分比例从 28.1% 推到 76.0%，明显优于 naive AL 和 uniform sampling control。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.15]；[doi:10.1021/acs.jcim.3c01456, p.16]；[doi:10.1021/acs.jcim.3c01456, p.67]；[doi:10.1021/acs.jcim.3c01456, p.68]
- **results：** 预训练模型在 MOSES benchmark 上保持较强生成质量，例如 Validity=0.996、Unique@1K=1.000、Unique@10K=0.999，说明它是一个可靠的主动学习起点。
  - 证据：[doi:10.1021/acs.jcim.3c01456, p.54]；[doi:10.1021/acs.jcim.3c01456, p.55]

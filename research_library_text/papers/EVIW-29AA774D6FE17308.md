# Systematic Exploration of Small-Molecule Binding via a Large Language Model Trained on Textualized Protein-Ligand Interactions

- **论文 ID：** `EVIW-29AA774D6FE17308`
- **期刊 / 来源：** Molecules
- **发表时间：** 2025 Nov 22

- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出基于DSSP/供受体规则的 synthetic language 与 3bmGPT，把 binding mode 编码成 words/sentences 后训练 GPT/BERT，用于 next-word 预测、靶标聚类、功能分群、相似药物检索和目标识别。

## 创新边界

`创新点主要在表示学习与分析流程，不是湿实验，也不是直接生成或优化候选分子。`。这不是全球首创性检索或独立复现结论。

## 研究问题

把3D蛋白-配体结合模式转成可被LLM处理的1D文本表示，并判断这种表示能否稳定提取结合残基、靶标功能、相似配体与相关药物。

## 方法

- complex转token/text、causal/masked LM与binding tasks。

## 数据与基准

- protein-ligand complexes/interactions。

## 比较基线

- graph/3D models。

## 结果证据

- 论文报告预测/解释性能；为计算。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- tokenization损失3D细节、数据泄漏/无实验。

## 仍未知

- 2907 个训练蛋白是否足以泛化到更大蛋白空间仍不清楚。
- logits 与真实 binding affinity / 实验活性的定量对应关系未被验证。
- 文中检出的相关药物与 multifunctionality 结论缺少独立实验确认。

## Pi 结构化证据摘录

- **baseline：** 相对于 BERT，GPT 在相关 word 预测上更优；若只算 adjacent word，两者 AUC 接近，而 BERT 生成了更多 unrelated new words。
  - 证据：[doi:10.3390/molecules30234516, p.9]
- **baseline：** 相对于 ProBiS 和 Foldseek，3bmGPT 在粗粒度 target assignment 上并未显著拉开距离，但在相似性判别 AUC 上更敏感。
  - 证据：[doi:10.3390/molecules30234516, p.14]
- **data：** 方法验证首先使用 463 个 tight-binding simulated datasets，覆盖 16 个 target proteins，包括 BACE、CDK2、EG5、HIF2A、JNK1、MCL1、P38、SYK、THROMBIN、TNKS2 与 TYK2 等。
  - 证据：[doi:10.3390/molecules30234516, p.4]；[doi:10.3390/molecules30234516, p.8]
- **data：** 具体案例包括 Rebastinib–ABL1：从 PDB 生成 30 个 binding words，并取前 10 个 word 作为输入；另一个案例是 EGFR–AEE788：共生成 23 个 word，取前 7 个作为提示。
  - 证据：[doi:10.3390/molecules30234516, p.6]；[doi:10.3390/molecules30234516, p.9]
- **data：** 聚类分析随机抽取 10,000 sentences，形成 10,000 × 50,257 的 logits matrix，并进一步压缩到 737 个高标准差 token vector。
  - 证据：[doi:10.3390/molecules30234516, p.7]
- **data：** 新输入示例使用 PDB 5EDQ（EGFR kinase）及其 ligand 5N3，并在 10,000 条参考数据上进行对照分析。
  - 证据：[doi:10.3390/molecules30234516, p.13]；[doi:10.3390/molecules30234516, p.14]
- **data：** 基准测试使用 23 个随机 PDB 和 9 个 KLIFS kinases，以比较 3bmGPT、ProBiS 和 Foldseek 的判别能力。
  - 证据：[doi:10.3390/molecules30234516, p.14]
- **declared_resources：** 论文声明原始数据来自 CrossDocked2020 / gnina models 仓库，预训练 model 与 analysis data 放在 Zenodo，训练与分析 code 公开在 GitHub。
  - 证据：[doi:10.3390/molecules30234516, p.16]
- **declared_resources：** 训练使用 Cerebras Wafer Scale Cluster / WSE，文中说明其有 850,000 cores 和 40 GB on-chip memory。
  - 证据：[doi:10.3390/molecules30234516, p.5]
- **limitations：** 作者明确承认训练目标蛋白数量有限，训练集只有 2907 个 proteins，与真实蛋白空间相比覆盖不足。
  - 证据：[doi:10.3390/molecules30234516, p.15]
- **limitations：** tokenized binding units 仍较碎片化，一些 vector 不含足够 binding 信息，作者认为需要 attention maps 才更便于重建 binding mode。
  - 证据：[doi:10.3390/molecules30234516, p.15]；[doi:10.3390/molecules30234516, p.16]
- **limitations：** 论文只比较了 GPT 与 BERT，其他模型、epoch 和 tuning 可能改变结果，因此 benchmark 还不充分。
  - 证据：[doi:10.3390/molecules30234516, p.16]
- **limitations：** 训练数据主要是结构性 binding data，没有实验亲和力或 wet-lab 结果，输出与真实 in vitro binding strength 的相关性尚未证实。
  - 证据：[doi:10.3390/molecules30234516, p.16]
- **method：** 作者用 DSSP 思路和 donor/acceptor 规则把单个 residue–ligand 作用编码成 binding interaction word，再把多个 word 组成 sentence，用来表示同一配体在不同空间姿态下的结合状态。
  - 证据：[doi:10.3390/molecules30234516, p.2]；[doi:10.3390/molecules30234516, p.3]；[doi:10.3390/molecules30234516, p.4]
- **method：** 训练数据来自 CrossDocked2020 / Pocketome：18,450 个 protein–ligand complex、22.6 million interaction poses，并用 CNN affinity algorithm 为每个 complex 额外模拟 120 个 poses 以覆盖柔性。
  - 证据：[doi:10.3390/molecules30234516, p.4]
- **method：** 数据预处理时剔除不超过 5 个 word 的 sentence，按 7:2:1 切分训练/验证/测试集，并比较 word-based 与 BPE 两种 tokenizer；词表规模分别为 143,018 和 50,257，最长序列长度 1071。
  - 证据：[doi:10.3390/molecules30234516, p.5]
- **method：** 模型层面训练了 GPT-2 small / medium 和 BERT；GPT 使用 PyTorch 与 Cerebras Wafer Scale Cluster，BERT 则在 3 张 NVIDIA Tesla V100 上训练。
  - 证据：[doi:10.3390/molecules30234516, p.5]
- **method：** 推理时将 query PDB 转成 binding text 与 logits，再用 UMAP、Louvain clustering、GO enrichment、Tanimoto similarity 和邻近图网络分析，最后与 ProBiS、Foldseek 做基准比较。
  - 证据：[doi:10.3390/molecules30234516, p.6]；[doi:10.3390/molecules30234516, p.7]；[doi:10.3390/molecules30234516, p.14]
- **results：** 在 Rebastinib–ABL1 例子中，模型准确抓到 4 个关键 binding interactions；GPT 与 BERT 的 adjacent word 生成比例接近，但把相关 word 也算入正类时，GPT 的 AUC 为 0.8486，高于 BERT 的 0.7073。
  - 证据：[doi:10.3390/molecules30234516, p.9]
- **results：** EGFR–AEE788 生成的 12 个 word 中，有 4 个可在其他 target 的 interaction words 里找到，对应 ABL1、VGFR2、EPHA2 与 CDK2，提示模型学到了 kinase family 共享特征。
  - 证据：[doi:10.3390/molecules30234516, p.9]
- **results：** 10,000 条表示被分成 23 个 cluster，且同一 target 的 sentence 往往聚在一起；例如 DNA polymerase 相关 sentence 在 cluster 7 中高度集中，TK 与 STK 也主要混在 cluster 0 和 3。
  - 证据：[doi:10.3390/molecules30234516, p.9]；[doi:10.3390/molecules30234516, p.10]；[doi:10.3390/molecules30234516, p.11]
- **results：** 基于 GO 的分析把 cluster 归并为 6 类功能：nuclear receptor、protein kinase、protease、phospholipase、catalysis 与 transferase，并能分出 VDR、AR/ESR/PGR、PPAR/RXRA 等子群。
  - 证据：[doi:10.3390/molecules30234516, p.11]；[doi:10.3390/molecules30234516, p.12]
- **results：** 对新输入 5EDQ/5N3，模型把目标蛋白判定为 protein kinase，UMAP 位置与配体结构相似度呈正相关，并在邻近样本中找到 merestinib 和 brigatinib 等已知药物。
  - 证据：[doi:10.3390/molecules30234516, p.13]；[doi:10.3390/molecules30234516, p.14]
- **results：** 与只看结构的 ligand clustering 相比，3bmGPT 的 interaction space 把 kinase 与 protease、nuclear receptor 放得更近，说明其表示不只依赖配体结构。
  - 证据：[doi:10.3390/molecules30234516, p.14]
- **results：** 基准上，三种方法对 23 个 unlabeled binding data 的 target detection 都超过 90% accuracy，但 3bmGPT 在区分相似 target 的 AUC 上更强。
  - 证据：[doi:10.3390/molecules30234516, p.14]
- **results：** UMAP clustering 重复 3 次后结果一致，作者据此主张其分群分析具有可重复性。
  - 证据：[doi:10.3390/molecules30234516, p.7]

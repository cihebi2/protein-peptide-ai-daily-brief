## 作者主张的创新点

作者声称提出两条新路线：其一是 fine-tuned ESM-2 token classification，用于线性、天然 amino acid peptide 的 cleavage 预测；其二是 hierarchical GNN，用 atom/amino-acid 双层图表示 cyclic peptides 与 non-natural residues，并用四个 cyclic peptide case study 展示适用性。[doi:10.1038/s41598-025-21801-0, p.1][doi:10.1038/s41598-025-21801-0, p.2][doi:10.1038/s41598-025-21801-0, p.11][doi:10.1038/s41598-025-21801-0, p.12]

## 创新边界

`就冻结证据看，创新边界主要是 cleavage-site prediction 的模型实现与适用范围扩展，而不是新蛋白/肽候选的生成或优化；global novelty 不能在本次审查中独立验证。[doi:10.1038/s41598-025-21801-0, p.1][doi:10.1038/s41598-025-21801-0, p.12]`。这不是全球首创性检索或独立复现结论。

## 研究问题

该文要解决的是 peptide 底物的 proteolytic cleavage site prediction，服务于 peptide drug development；重点难点在于现有方法多依赖手工特征，且对 non-natural amino acids 与 cyclic peptides 的表示不足。[doi:10.1038/s41598-025-21801-0, p.1][doi:10.1038/s41598-025-21801-0, p.2]

## Pi 结构化证据摘录

- **baseline：** 作者设置了两个极简基线：50% 概率随机判定 cleavage 的 random model，以及把所有 bond 都判为 cleavage 的 Constant 1；两种新模型在所有蛋白酶上都明显优于这两个基线。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.6]；[doi:10.1038/s41598-025-21801-0, p.8]
- **baseline：** 用于比较的 ProsperousPlus 采用 8-amino-acid window、17 个 feature scores、9 种 base learners 和 stacking/blending/bagging；作者还指出其 windowing 会遗漏短 peptide 的端点 cleavage 候选。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.9]
- **baseline：** 由于 ProsperousPlus 的公开代码与已发表数据切分不可直接复用，作者重新用其代码在本地训练，并仅对 training set 做 1:1 undersampling 以便做公平比较。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.9]；[doi:10.1038/s41598-025-21801-0, p.10]
- **data：** 训练/测试数据来自 MEROPS cleavage annotations，负样本与正样本比例极不均衡，范围约为 36 到 592，中位数 188；这也是作者强调 F1 和 PR AUC 的原因之一。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.5]；[doi:10.1038/s41598-025-21801-0, p.6]
- **data：** case study 额外使用了先前文献中对四个 cyclic peptides 的 LC-HRMS metabolite identification 结果，涉及 elastase-2、cathepsin G 和 chymotrypsin A 的 incubation experiments。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.11]；[doi:10.1038/s41598-025-21801-0, p.12]
- **data：** 论文明确公开了 ESM-2 代码、GNN 代码和全部 datasets 的 anonymous.4open.science repositories；本次冻结审查仅能读取声明，未实际拉取仓库内容。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.12]
- **declared_resources：** 生物序列与酶底物资源来自 MEROPS Release 12.5、UniProt 和 CD-HIT；这些资源支撑了 29 个 protease-specific datasets 的构建。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.2]
- **declared_resources：** 预训练 backbone 是 ESM-2 的 esm2_t6_8M_UR50D；GNN 的原子/键特征与分子图表示则依赖 RDKit，并在文中列出 atom-type、degree、formal charge、chirality 等特征。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.2]；[doi:10.1038/s41598-025-21801-0, p.4]
- **declared_resources：** 计算环境写明为 Intel Core i7-4790、32 GB RAM、SSD、Python 3.7.16 和 Arch Linux kernel 6.12.3；这有助于理解训练耗时与复现实验的硬件门槛。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.10]
- **declared_resources：** 论文还披露了代码与数据的 anonymous.4open.science 仓库，以及补充材料链接；但这些外部资源未在本次冻结审查中被实际访问。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.12]
- **limitations：** ESM-2 路线本身受 tokenizer/vocabulary 限制，不能处理 non-natural amino acids 或 cyclic structures，因此只适用于线性、天然 amino acid peptide。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.2]
- **limitations：** 作者承认当前评估只基于单次 stratified train/test split，k-fold cross-validation 或 repeated subsampling 可能给出更稳健的性能估计。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.8]
- **limitations：** cyclic-peptide case study 只覆盖四个分子，作者也明确说需要更大、更外部的数据集来验证 GNN 的泛化能力，而这类公开数据目前仍然有限。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.12]
- **limitations：** 作者在方法部分明确说明未做 grid search 或 early stopping，且把一致性优先于绝对最优性能作为训练设计取向，这限制了对单个数据集的极致调参空间。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.3]
- **method：** 作者从 MEROPS Release 12.5 收集已验证 cleavage sites，并用 UniProt 补齐缺失 FASTA，再用 CD-HIT 以 70% identity 去冗余；少于 100 个 substrates 的数据集被排除，最终保留 29 个 protease-specific datasets。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.2]
- **method：** ESM-2 路线采用 esm2_t6_8M_UR50D，输入为标准 20-letter FASTA，输出 320 维 embeddings，再用 dropout + linear layer 对每个 peptide bond 做二分类；训练设为 20 epochs、lr 0.0003、batch size 4、weight decay 0.00001，且未做 grid search 或 early stopping。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.2]；[doi:10.1038/s41598-025-21801-0, p.3]
- **method：** GNN 路线把 peptide 构造成 atom-level 与 amino-acid-level 的 hierarchical graph，atom/bond features 用 RDKit 提取；模型包含 transformer convolution、4 层 gated graph convolution、mean pooling 与 4 层 amino-acid-level gated graph convolution，训练 30 epochs、lr 0.0003、batch size 4。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.3]；[doi:10.1038/s41598-025-21801-0, p.4]；[doi:10.1038/s41598-025-21801-0, p.5]
- **method：** 评估指标包括 accuracy、precision、specificity、recall 与 F1；作者采用 substrate-level 的 stratified split，并尽量让测试集保留约 30% 的 cleavage sites，以缓解强类别不平衡。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.5]
- **results：** 在 8 个 selected proteases 上，ESM-2 的最高 F1 为 C14.005 的 0.8655，GNN 的最高 F1 为同一蛋白酶的 0.7370；作者同时报告两种模型都显著优于 random model 与 Constant 1 baseline。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.6]
- **results：** 把 substrate length 限制到 200 aa 后，ESM-2 的 mean relative improvement 为 25.22%，GNN 为 125.30%，paired permutation test 的 p 值为 0.0017。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.7]；[doi:10.1038/s41598-025-21801-0, p.8]
- **results：** 与 ProsperousPlus 对比时，作者报告两种新模型在 8 个 protease 上的 F1 和 PR AUC 整体更优；例如 C14.005 上 ESM-2 为 0.8655、GNN 为 0.7370，而 ProsperousPlus 在同一任务上的 F1 为 0.4547（1:1 undersampling training set）。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.10]；[doi:10.1038/s41598-025-21801-0, p.11]
- **results：** GNN 在四个 cyclic-peptide case studies 中给出的 top predictions 与已知实验 cleavage/metabolite 结果相符，例如 somatostatin、iseganan、octreotide 与 oxytocin 的关键切割位点都被命中。
  - 证据：[doi:10.1038/s41598-025-21801-0, p.11]；[doi:10.1038/s41598-025-21801-0, p.12]

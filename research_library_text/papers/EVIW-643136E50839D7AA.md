# Accurate structure prediction of biomolecular interactions with AlphaFold 3

- **论文 ID：** `EVIW-643136E50839D7AA`
- **期刊 / 来源：** Nature
- **发表时间：** 2024 May 8
- **DOI：** [10.1038/s41586-024-07487-w](https://doi.org/10.1038/s41586-024-07487-w)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `结构预测`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 AlphaFold 3：一种更新为扩散式原子坐标生成的深度学习模型，可在单一框架内处理多类生物分子复合物，并在多项基准上优于专门方法。

## 创新边界

`主要新意是通用结构预测框架与训练/推理机制的重构，不是候选分子的生成、筛选或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在统一框架中准确预测蛋白、核酸、小分子、离子与修饰残基等生物分子复合物的三维联合结构，并提升界面与配体等任务的结构预测精度。

## 方法

- 输入序列、配体和共价关系，经模板/MSA模块、Pairformer与扩散模块联合生成复合物结构并输出置信度。

## 数据与基准

- 训练使用截至2023-01-12的PDB和公开化学组件等数据，评估含PoseBusters、近期PDB、CASP15 RNA及蛋白/抗体等集合。

## 比较基线

- AutoDock Vina、RoseTTAFold All-Atom/2NA、AlphaFold-Multimer及其他专用预测器。

## 结果证据

- 作者报告蛋白-配体、蛋白-核酸及抗体-抗原等类别相对专用基线显著提升，并展示统一模型的广覆盖。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 作者明确列出手性/立体化学错误、无序区幻觉、静态结构无法代表动力学以及特定靶点准确度不足。

## Pi 结构化证据摘录

- **baseline：** 蛋白-配体对比主要包括 AutoDock Vina、Gold 和 RoseTTAFold All-Atom；部分方法使用 pocket 或 holo 结构等特权信息，而 AF3 仍在盲预测设定下占优。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.4]；[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.15]
- **baseline：** 蛋白-核酸与 RNA 任务的主要对比对象是 RoseTTAFold2NA、RF2NA、AIchemy_RNA 和 AIchemy_RNA2。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.10]；[doi:10.1038/s41586-024-07487-w, p.16]
- **baseline：** 蛋白-蛋白与抗体任务主要对比 AlphaFold-Multimer v2.3，文中也把大规模 seed 采样作为抗体性能提升的重要背景。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.7]；[doi:10.1038/s41586-024-07487-w, p.18]
- **baseline：** PoseBusters V2 中还比较了 AF3 2019 与 Vina，并分析了是否提供 pocket residue 信息的设置。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.15]
- **data：** 主要评估使用 recent PDB set，共 8,856 个复合物，覆盖 2022-05-01 到 2023-01-12 发布的结构，且大多数样本少于 5,120 tokens。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.9]
- **data：** PoseBusters 评估使用 2021 年后发布的 428 个 protein-ligand 结构，并配合 2019-09-30 早截断模型避免训练集泄漏。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.4]；[doi:10.1038/s41586-024-07487-w, p.9]
- **data：** 核酸相关比较使用与 RF2NA 约束一致的低同源 recent PDB 子集，以及 CASP15 RNA targets。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.10]
- **data：** 训练与模板来源均来自公共资源，包括 PDB、UniRef、Uniclust、MGnify、BFD、RFam、RNAcentral、Nucleotide Database、JASPAR 与 SELEX 序列。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.10]
- **declared_resources：** 训练与评估所用科学数据均来自公共来源，包括 PDB、UniRef90、Uniclust30、MGnify、BFD、RFam、RNAcentral、Nucleotide Database、JASPAR 与 SELEX 资料。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.10]
- **declared_resources：** 结构模板与训练版本分别使用 2023-01-12 下载的 PDB、2022-09-28 下载的模板库，以及 2023-10-19 下载的 Chemical Components Dictionary。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.10]
- **declared_resources：** 论文明确写明 AF3 仅以 non-commercial usage only server 形式提供，且 code is not provided。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.10]
- **limitations：** 立体化学问题仍未完全解决：正文指出 chirality 违规率在 PoseBusters 上仍有 4.4%，且偶发 atom clash，极端时同源链会重叠。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.7]
- **limitations：** 扩散式生成会在无序区产生 hallucination，虽然 cross-distillation 和 ranking 规则能缓解，但不能彻底消除。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.4]；[doi:10.1038/s41586-024-07487-w, p.6]
- **limitations：** AF3 预测的是静态 PDB 式构象，不是溶液中的动力学 ensemble；多状态体系的覆盖也有限，例如 cereblon 只预测到 closed state。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.6]；[doi:10.1038/s41586-024-07487-w, p.7]
- **limitations：** 为了获得最高精度，部分任务需要大量 seeds，尤其 antibody-antigen 复杂体，因此计算成本会上升。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.7]；[doi:10.1038/s41586-024-07487-w, p.18]
- **method：** AF3 延续 trunk+structure 的总体思路，但用 pairformer 替代 AF2 的 evoformer，并用 diffusion module 直接生成原子坐标。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.2]；[doi:10.1038/s41586-024-07487-w, p.3]
- **method：** 扩散模块直接处理 raw atom coordinates，刻意不使用全局旋转/平移等变处理、torsion 参数化或结构 violation loss。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.3]；[doi:10.1038/s41586-024-07487-w, p.4]
- **method：** 训练中加入 cross-distillation 来缓解 hallucination，并用 mini-rollout 训练 confidence head，以输出 pLDDT、PAE 和 PDE。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.4]
- **method：** 训练分为初始训练和两轮 fine-tuning，crop size 依次为 384、640、768 token；推理默认从 5 个 seeds × 5 个 diffusion samples 中选最高置信结果。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.9]
- **results：** AF3 在 protein-ligand、protein-nucleic acid、protein-antibody 和 protein monomer 等任务上整体优于对应强基线，正文将其概括为跨大多数类别都显著更强。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.1]；[doi:10.1038/s41586-024-07487-w, p.5]
- **results：** 在 PoseBusters 上，AF3 在 blind docking 设定下显著优于 Vina，并优于 RoseTTAFold All-Atom；文中给出 Fisher 检验 P=2.27×10^-13。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.4]；[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.15]
- **results：** AF3 对 protein-nucleic complexes 和 RNA 的准确率高于 RoseTTAFold2NA；在 CASP15 RNA 上平均优于 RF2NA 和 AIchemy_RNA，但未超过人工辅助的 AIchemy_RNA2。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.5]；[doi:10.1038/s41586-024-07487-w, p.16]
- **results：** 置信度指标与真实误差匹配良好，ipTM、pLDDT、PAE 与 DockQ、iLDDT 和 LDDT_to_polymer 呈一致关系。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.6]；[doi:10.1038/s41586-024-07487-w, p.20]
- **results：** 抗体-抗原预测的 top-ranked 结果随 seeds 增加持续改善，直到 1,000 seeds 仍可看到增益。
  - 证据：[doi:10.1038/s41586-024-07487-w, p.7]；[doi:10.1038/s41586-024-07487-w, p.18]

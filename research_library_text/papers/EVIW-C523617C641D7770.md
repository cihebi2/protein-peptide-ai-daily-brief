# Molecular embedding-based algorithm selection in protein-ligand docking

- **论文 ID：** `EVIW-C523617C641D7770`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2026 Mar 14

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

MolAS 用预训练蛋白/配体 embedding、轻量 attentional pooling 和浅层 residual decoder 构造一个算法选择器，并通过跨 benchmark 与跨 protocol 分析说明 docking AS 的成败主要受 oracle entropy 和 solver hierarchy shift 约束，而不只是模型容量 [doi:10.1186/s13321-026-01168-8, p.1] [doi:10.1186/s13321-026-01168-8, p.3]

## 创新边界

`新意主要在轻量 embedding-based selector 与 protocol dependence 分析；它不直接生成或优化分子候选，而是在固定 solver portfolio 中做选择 [doi:10.1186/s13321-026-01168-8, p.1] [doi:10.1186/s13321-026-01168-8, p.15]`。这不是全球首创性检索或独立复现结论。

## 研究问题

在固定 docking portfolio 下为每个蛋白-配体复合物选择更合适的求解器，并判断这种选择在不同 benchmark、post-processing 与 protocol 变化下是否还能稳定迁移 [doi:10.1186/s13321-026-01168-8, p.2] [doi:10.1186/s13321-026-01168-8, p.4]

## 方法

- 用分子embedding预测solver排名/选择，并分析winner entropy、top-solver margin和跨protocol ranking shift。

## 数据与基准

- 多docking benchmark、solver portfolio和不同预处理/protocol。

## 比较基线

- 单一solver、oracle、随机/多数solver及既有algorithm-selection方法。

## 结果证据

- MolAS在固定pipeline、低oracle entropy时有效，但protocol mismatch会显著退化；论文强调稳健性瓶颈来自workflow而非表示容量。

## Pi 结构化证据摘录

- **baseline：** 论文把 SBS 作为单一求解器基线，把 VBS 作为 oracle 上界，并以 VBS-SBS gap 及其闭合比例作为核心比较指标。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]
- **baseline：** 对比基线还包括更重的 MC-GNNAS-Dock，以及若干 ablation 变体，如 GCN-GAT-GINE、EGNN-GAT-GINE、pairwise logistic、NDCG@3 和 modality-dropout 版本。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.13]；[doi:10.1186/s13321-026-01168-8, p.14]
- **data：** MOAD-curated 数据集由约 6700 个 BindingMOAD 复合物经去除 PDBBind v2020 与 DockGen 重叠、仅保留 20 种标准氨基酸蛋白和满足 Lipinski-like 约束的配体后得到，共 3179 个复合物。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.4]；[doi:10.1186/s13321-026-01168-8, p.5]
- **data：** 主 docking portfolio 包含 8 个算法：Smina、Qvina-W、DiffDock、DiffDockL、SurfDock、Gnina、Uni-Mol Docking V2 和 KarmaDock。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.5]
- **data：** 外部 benchmark 包括 PoseX（718 个 self-docking、1312 个 cross-docking；另有 Astex Diverse Set 85 个复合物）以及 PoseBusters v2（428 个复合物和 7 个模型输出的 MM-min 结果）。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.5]；[doi:10.1186/s13321-026-01168-8, p.6]
- **declared_resources：** 实现使用 PyTorch、Adam、cosine learning-rate schedule 和 early stopping，并在双路 AMD EPYC 7763 + 8×NVIDIA RTX 3090 的服务器上运行。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]
- **declared_resources：** 预训练资源包括 ESM-C 600M 与 ChemBERTa-77M-MLM；MolAS 的代码与 pretrained weights 在 GitHub，数据与 in-domain checkpoints 在 Zenodo。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.6]；[doi:10.1186/s13321-026-01168-8, p.25]
- **declared_resources：** PoseX 与 PoseBusters 的 docking 输出来自各自的官方 benchmark release，属于论文所依赖的外部资源。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]
- **limitations：** 论文明确的主要边界是 protocol dependence：数据清洗、dock engine 和 post-processing 的变化会重排 solver ranking，导致跨协议转移显著退化，甚至劣于 SBS。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.11]；[doi:10.1186/s13321-026-01168-8, p.12]；[doi:10.1186/s13321-026-01168-8, p.15]
- **limitations：** 在高 oracle entropy、near-ties 与 selection collapse 的 regime 中，embedding 分离度不足，且 margin 也不是稳定的优于 SBS 的单调置信度信号。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.9]；[doi:10.1186/s13321-026-01168-8, p.10]；[doi:10.1186/s13321-026-01168-8, p.14]
- **limitations：** 模型不显式编码 protein-ligand contact geometry，作者把更强的 cross-protocol robustness 留给 protocol descriptors、domain adaptation 或交互图特征。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.16]
- **method：** MolAS 采用 ESM-C 600M 的蛋白残基级 embedding 与 ChemBERTa-77M-MLM 的配体 embedding，先做 attentional pooling，再与配体向量融合后送入 shallow residual MLP 预测各算法表现。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.6]；[doi:10.1186/s13321-026-01168-8, p.7]
- **method：** 监督目标是 gated score s=sRMSD·sPB：sRMSD 是以 2 Å 为中心的 sigmoid 评分，sPB 要求通过 18 项 PoseBusters 检查；训练主损失使用 BCE-with-logits，并把 MSE、pairwise logistic 与 NDCG@3 作为对照目标。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.6]；[doi:10.1186/s13321-026-01168-8, p.7]；[doi:10.1186/s13321-026-01168-8, p.14]
- **method：** 主实验把 MolAS 形式化为 algorithm selection 映射，在 8 个 docking 算法组成的 portfolio 上学习每个 protein-ligand pair 的 solver 选择。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.4]；[doi:10.1186/s13321-026-01168-8, p.5]
- **method：** 评估采用 5-fold、8:2 的 in-domain 划分以及 source-to-target 的 cross-benchmark 迁移，并用 strict / relaxed success rate 与 VBS-SBS gap closure 报告性能。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]
- **results：** 在 MOAD-curated 上，MolAS 的 strict / relaxed success 为 50.01% / 74.68%，高于 SBS 的 43.41% / 68.17%，并关闭 17.42% / 22.40% 的 VBS-SBS gap。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]；[doi:10.1186/s13321-026-01168-8, p.9]
- **results：** 在 PoseX-CD 的 in-domain 设置下，MolAS 达到 66.39% / 87.50%，相对 SBS 的 49.08% / 73.02% 关闭 45.50% / 61.28% 的 gap；在 PoseX + Astex 上也取得 58.61% / 79.80% 并显著优于 SBS。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.8]；[doi:10.1186/s13321-026-01168-8, p.9]
- **results：** 跨 benchmark 迁移总体失败，许多设置出现 gap widening，最差可到 108.29%，说明训练到目标协议的 solver hierarchy 不稳定。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.11]；[doi:10.1186/s13321-026-01168-8, p.12]
- **results：** 与 MC-GNNAS-Dock 相比，MolAS 在 2 Å & PB-valid metric 上普遍高出约 3.5–8 个百分点，同时参数量约 638k 对 3.2M。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.13]
- **results：** 在 PoseX-SD(relax) 和 PoseBusters(MM-min) 等困难 regime 中，MolAS 出现 selection collapse；score margin 与 oracle agreement 正相关，但并不能稳定充当优于 SBS 的单调信号。
  - 证据：[doi:10.1186/s13321-026-01168-8, p.9]；[doi:10.1186/s13321-026-01168-8, p.10]

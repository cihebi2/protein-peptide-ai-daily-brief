# DualPG-DTA: A Large Language Model-Powered Graph Neural Network Framework for Enhanced Drug-Target Affinity Prediction and Discovery of Novel CDK9 Inhibitors Exhibiting In Vivo Anti-Leukemia Activity

## 作者主张的创新点

作者声称提出 DualPG-DTA：用 Uni-Mol、ESM-2/ESMFold 生成分子与蛋白表示，再经 GATv2 和 multi-head attention 融合做 DTA 预测；同时通过 scaffold hopping 发现新 CDK9 inhibitor C1，并给出体内 anti-leukemia activity 证据。

## 创新边界

`按冻结证据只能确认论文自称提出了一个组合式新框架和新 CDK9 先导化合物；未见独立外部 prior-art 复核，因此 global novelty 不能被此 job 证明。`。这不是全球首创性检索或独立复现结论。

## 研究问题

构建一种能同时利用 pre-trained large language models 与 GNN 的 drug-target binding affinity prediction 框架，并把它直接用于 CDK9 inhibitor discovery，最终服务于 Venetoclax-resistant AML 的候选先导物筛选与验证。

## 方法

- drug/protein LLM embeddings、图消息传递与affinity regression，虚拟筛选CDK9后实验验证。

## 数据与基准

- Davis/KIBA类DTA及CDK9候选筛选/细胞与动物实验。

## 比较基线

- DeepDTA/WideDTA/AttentionDTA及图模型。

## 结果证据

- 论文标题/正文明确报告novel CDK9 inhibitors具in vivo anti-leukemia activity；仅该候选实验写作实验。

## Pi 结构化证据摘录

- **baseline：** DTA 评测 baselines 包括 KronRLS、SimBoost、DeepDTA、AttentionDTA、MATT-DTI、GraphDTA、FusionDTA、BiComp-DTA、G-KBertDTA、TEFDTA、AttentionMGT-DTA、InceptionDTA，以及较新的 StructureNet、PLAIG、GNNSeq。
  - 证据：[doi:10.1002/advs.202513099, p.2]；[doi:10.1002/advs.202513099, p.3]；[doi:10.1002/advs.202513099, p.4]
- **baseline：** 化合物发现阶段以 BAY1251152 作为起始 scaffold/对照，并以 Venetoclax 作为 AML 细胞与体内实验的阳性对照，因此该工作更偏向 scaffold hopping 与抗药性场景下的 lead optimization，而不是纯粹的通用 de novo generation。
  - 证据：[doi:10.1002/advs.202513099, p.6]；[doi:10.1002/advs.202513099, p.8]；[doi:10.1002/advs.202513099, p.9]
- **data：** 方法评测使用 Davis 和 KIBA 两个 benchmark；Davis 的 Kd 被转换为 pKd，KIBA 则经过滤保留 229 proteins 和 2,111 small molecules，并保证每个 target 至少有 10 条 activity measurements。
  - 证据：[doi:10.1002/advs.202513099, p.10]；[doi:10.1002/advs.202513099, p.11]
- **data：** CDK9 任务使用约 1,330 个来自作者近期工作的 CDK9 inhibitors 作为回归/分类数据集，并以 BAY1251152 作为母体 scaffold 构建 C1–C4；文中还使用 CDK9 X-ray structure 4BCI 以及 MV4-11、HL-60、MV4-11-VR、MRC-5 细胞和 Balb/c nude mice/SCID mice。
  - 证据：[doi:10.1002/advs.202513099, p.6]；[doi:10.1002/advs.202513099, p.12]
- **data：** 药代与体内数据包括 human liver microsome 稳定性、Sprague Dawley rat PK，以及 MV4-11-VR xenograft 模型中的肿瘤体积和体重监测。
  - 证据：[doi:10.1002/advs.202513099, p.9]；[doi:10.1002/advs.202513099, p.12]
- **declared_resources：** 作者声明 DualPG-DTA 的 source code 和 data 已公开在 GitHub: https://github.com/idruglab/DualPG-DTA；正文同时指向 Supporting Information 作为补充结果来源。
  - 证据：[doi:10.1002/advs.202513099, p.13]；[doi:10.1002/advs.202513099, p.10]
- **declared_resources：** 实现与实验依赖的已声明资源包括 Uni-Mol、ESM-2、ESMFold、RDKit、Optuna、PyMOL、Amber 22、Schrödinger/Maestro、GraphPad Prism，以及 South China University of Technology 的 HPC platform。
  - 证据：[doi:10.1002/advs.202513099, p.11]；[doi:10.1002/advs.202513099, p.12]；[doi:10.1002/advs.202513099, p.13]
- **limitations：** 作者明确承认模型依赖预先计算的 3D conformations，可能限制动态 conformational sampling；同时训练开销高于 DeepDTA 这类单模态方法。
  - 证据：[doi:10.1002/advs.202513099, p.10]
- **limitations：** 文中也指出 DualPG-DTA 对不同 target class 的实际效果会受训练数据量和质量影响，GPCR 或 ion channels 等场景仍需 case-by-case 验证。
  - 证据：[doi:10.1002/advs.202513099, p.10]
- **method：** DualPG-DTA 对 drug 使用 Uni-Mol 预训练嵌入并结合 RDKit 构建 molecular graph；对 protein 使用 ESM-2/ESMFold 生成 residue-level 表示，并以 8 Å cutoff 建立 protein graph，再用三层 GATv2 提取图级特征。
  - 证据：[doi:10.1002/advs.202513099, p.11]
- **method：** 融合模块将 drug 与 protein embedding 拼接后，经过 8-head multi-head self-attention 和两层 BN+ReLU 全连接层压缩，输出连续 binding affinity prediction；训练采用 fivefold cross-validation，并用 Optuna 做超参数优化。
  - 证据：[doi:10.1002/advs.202513099, p.11]；[doi:10.1002/advs.202513099, p.12]
- **method：** 在 CDK9 发现流程中，作者基于 BAY1251152 的 docking pose 进行 scaffold hopping，设计 C1–C4；随后用 CDK9 kinase assay、Glide docking、100 ns MD、MMPBSA、selectivity assay、qPCR/WB/apoptosis/cell-cycle 与 xenograft 逐级验证。
  - 证据：[doi:10.1002/advs.202513099, p.6]；[doi:10.1002/advs.202513099, p.7]；[doi:10.1002/advs.202513099, p.12]
- **results：** 在 Davis/KIBA 上，DualPG-DTA 获得最佳综合性能：Davis 的 MSE/CI/r2m 为 0.169/0.908/0.778，KIBA 为 0.138/0.894/0.791；相较 BiComp-DTA，MSE 分别下降 21.8% 和 8.0%，r2m 分别提升 11.8% 和 4.5%。
  - 证据：[doi:10.1002/advs.202513099, p.2]；[doi:10.1002/advs.202513099, p.4]
- **results：** 在 PDBBind v2020 refined set 上，模型也取得最佳 MSE=1.384、MAE=0.951 和 PCC=0.776；预测值与实测值的散点分布和 KDE 分布都显示出较高一致性。
  - 证据：[doi:10.1002/advs.202513099, p.3]
- **results：** Ablation 和 Y-scrambling 支持模型有效性：移除 molecular graph/protein graph、去掉 attention 或将 GATv2 换成 GAT/GCN 都会降性能，而随机打乱标签后的结果明显劣于原模型。
  - 证据：[doi:10.1002/advs.202513099, p.4]；[doi:10.1002/advs.202513099, p.5]
- **results：** 在 CDK9 发现中，C1 与 C2 被实验证实具有强抑制活性，IC50 分别为 1.2 nM 和 3.9 nM；C1 对 CDK9 在 200 nM 下的抑制率为 91.5%，并表现出对 CDK6/CDK9/CDK16 的相对选择性。
  - 证据：[doi:10.1002/advs.202513099, p.6]；[doi:10.1002/advs.202513099, p.7]
- **results：** C1 还能抑制 MV4-11 与 Venetoclax-resistant MV4-11-VR 的增殖，诱导 apoptosis 和 G0/G1 arrest，降低 p-RNAP II CTD(Ser2)、c-MYC、Mcl-1 等信号；其 oral PK 具有约 24.3% bioavailability，并在 xenograft 中实现 47.2% 和 62.7% 的 TGI，且未见明显体重下降。
  - 证据：[doi:10.1002/advs.202513099, p.8]；[doi:10.1002/advs.202513099, p.9]；[doi:10.1002/advs.202513099, p.10]

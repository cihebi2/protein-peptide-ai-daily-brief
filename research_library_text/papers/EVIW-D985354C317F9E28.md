## 作者主张的创新点

作者提出 PepNet：将 amino acid type one-hot、physicochemical properties 与 ProtT5-XL-U50 预训练 embedding 融合，经 residual dilated convolution block 和 residual Transformer block 进行表示学习，用于 AMP/AIP 二分类，并提供在线 web server。

## 创新边界

`创新主要在序列表征、分类结构与可解释分析；不涉及新肽生成、优化或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在标注样本有限且肽序列模式复杂的情况下，如何仅凭 peptide sequence 更准确地区分 AIPs 与 AMPs，并兼顾一定的可解释性与部署可用性。

## Pi 结构化证据摘录

- **baseline：** AMP 对比方法包括 AMPlify、AMP Scanner Vr.1/2、TriNet、AMP-BERT，以及作者重训的 AMP Scanner/TriNet 版本和 PepNet Fast。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.3]
- **baseline：** AIP 对比方法包括 AIPStack、PPTPP 的 class/probability/fusion 三种特征、AIP_MDL、TriNet，以及 PepNet Fast。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.4]
- **data：** AIP 正样本来自 IEDB 中可诱导 anti-inflammatory cytokines 的人/鼠 T-cell assays，负样本为未诱导者；AMP 正样本来自 APD3 和 DADP，负样本为已知无抗菌活性的肽。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **data：** 主数据按既有工作划分为训练/验证/测试集：AIP 为 2516/629/1049，AMP 为 5340/1336/1670。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **data：** 作者还加入了 5 个 AMP 子任务数据集、3 个 AIP 数据集以及一个 toxic peptide 数据集，用于泛化与毒性评估；样本长度主要集中在 50 AA 以内，因此设定 L=40。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.4]；[doi:10.1038/s42003-024-06911-1, p.10]
- **declared_resources：** 作者提供了面向 AMP/AIP 预测的在线 web server，并区分 Fast 与 Standard 两种运行模式；同时还提供 toxicity prediction 接口。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.8]
- **declared_resources：** 论文给出可复现数据与代码的 Zenodo 入口，分别对应数据集与源码归档。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.11]；[doi:10.1038/s42003-024-06911-1, p.12]
- **declared_resources：** 实现语言为 Python，深度学习框架为 PyTorch。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.12]
- **limitations：** 作者明确指出 AIP 数据量偏小，可能限制模型对未见样本的泛化能力。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **limitations：** 固定长度输入会带来 zero-padding 噪声和 truncation 信息丢失，因此长度超参仍是关键限制。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **limitations：** Transformer attention 需要额外计算资源，并可能使模型过度依赖少数显著特征而增加 overfitting 风险。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **limitations：** Standard 模式需要用户自行提交 ProtT5-XL-U50 生成的 H5PY 特征文件，受限于作者设备条件。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.8]
- **method：** PepNet 同时提取 one-hot 氨基酸类型、14 个 physicochemical properties，以及来自 ProtT5-XL-U50 的 1024 维每残基 embedding；序列统一到固定长度 L=40，短序列 padding、长序列 truncation。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]
- **method：** 原始特征先经 residual dilated convolution block 处理，包含 dilation rate 为 1、2、4 的三层卷积并带 residual connection；再与预训练特征融合后输入 residual Transformer block，采用 4 个 attention heads、1 层 encoder/decoder 和 sinusoidal positional encoding。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.10]；[doi:10.1038/s42003-024-06911-1, p.11]
- **method：** 最终对残基表示做 average pooling，并用 MLP/softmax 输出 peptide 级别二分类得分。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.11]
- **method：** 作者用 ACC、Recall、Precision、F1-score 和 MCC 作为主要评价指标，并在 AMP/AIP 测试集上比较模型。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.3]；[doi:10.1038/s42003-024-06911-1, p.4]
- **results：** AMP test set 上 PepNet Standard 达到 ACC 0.950、Recall 0.954、Precision 0.947、F1-score 0.951、MCC 0.901，且五项指标均高于对比方法。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.3]；[doi:10.1038/s42003-024-06911-1, p.4]
- **results：** AIP test set 上 PepNet Standard 达到 ACC 0.819、Recall 0.940、Precision 0.705、F1-score 0.806、MCC 0.666；尽管 Precision 略低于部分基线，但总体最佳。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.4]
- **results：** 相对第二名，PepNet 在 AMP 上的 Recall/F1/MCC 分别提升 4.4%/3.5%/7.3%，在 AIP 上分别提升 28.6%/14.0%/33.2%。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.4]
- **results：** 消融实验表明 pre-trained features 贡献最大，移除后 AMP/AIP 的 F1-score 与 MCC 明显下降；移除 residual dilated convolution block 或 residual Transformer block 也会进一步损伤性能。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.5]；[doi:10.1038/s42003-024-06911-1, p.6]
- **results：** t-SNE 可视化显示 residual Transformer block 后正负样本分离更清晰，且 PepNet 能感知 AMP 的 cationic 和部分 amphiphilic 特征。
  - 证据：[doi:10.1038/s42003-024-06911-1, p.6]；[doi:10.1038/s42003-024-06911-1, p.7]；[doi:10.1038/s42003-024-06911-1, p.8]

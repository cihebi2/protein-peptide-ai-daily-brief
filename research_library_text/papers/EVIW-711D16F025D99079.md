# Linker-GPT: design of Antibody-drug conjugates linkers with molecular generators and reinforcement learning

- **论文 ID：** `EVIW-711D16F025D99079`
- **期刊 / 来源：** Scientific Reports（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1038/s41598-025-05555-3](https://doi.org/10.1038/s41598-025-05555-3)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 Linker-GPT：把 Transformer 分子生成、预训练迁移、linker 微调、scaffold 条件生成与 RL 结合，用于 ADC linker 的生成与属性优化。

## 创新边界

`新意主要在任务化改造与组合式训练，而不是全新生成范式；它是计算设计框架，不是湿实验发现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

为 ADC 设计结构多样、可合成且具药物样性的 linker，同时尽量用可控的生成模型替代人工枚举与局部经验设计。

## 方法

- 先在大规模分子数据预训练，再在整理的linker集微调；以QED、LogP和SAS奖励进行RL性质优化。

## 数据与基准

- 使用大规模分子预训练集和ADC linker专用数据，以validity、novelty、uniqueness及性质阈值评价。

## 比较基线

- LSTM、VAE及无RL/不同预训练的分子生成模型。

## 结果证据

- 微调生成validity 0.894、novelty 0.997、1k uniqueness 0.814；RL后98.7%满足QED>0.6、LogP<5、SAS<4。作者明确这些均为计算结果。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 生成规模增加时唯一性下降；性质奖励不能覆盖ADC偶联化学、血浆稳定性、释放和毒性。

## 仍未知

- GitHub 仓库与代码实现未在本次冻结证据中核验。
- 具体超参数与训练细节主要放在 Supporting Information，正文未完整展开。
- 实际合成难度、稳定性、药效与毒理尚未被实验确认。
- 临床相关属性如 plasma stability、release kinetics、immunogenicity 仍未纳入模型。

## Pi 结构化证据摘录

- **baseline：** 对照模型包括 CharRNN、LSTM、VAE 和 AAE，且都使用相同的预训练与微调数据。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.6]
- **baseline：** Table 2 显示 CharRNN 的 validity 接近 Linker-GPT，但在 KL、FCD 和 uniqueness 上更弱；LSTM、VAE、AAE 则整体落后。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.7]
- **baseline：** 无 RL 版本在部分约束任务上的表现明显弱于 RL 版本，说明奖励约束是性能差异的重要来源。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.7]；[doi:10.1038/s41598-025-05555-3, p.11]
- **data：** 专用数据来自 Creative Biolabs 的 3707 个 ADC linker，SMILES 由 PubChemPy 标注，结构预处理用 RDKit 完成。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.2]
- **data：** 预训练数据分别来自 ChEMBL 的 1.05 million 过滤子集、ZINC 子集和 QM9 CSV 数据集。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.2]
- **data：** 生成结果还经过 RDKit 的 PAINS 过滤，以排除潜在 assay interference 风险。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.9]
- **declared_resources：** 论文第13页声明 datasets 和 code 可在 GitHub 获取。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.13]
- **declared_resources：** Supporting Information 记录了 pre-training 和 RL 的具体参数设置。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.3]；[doi:10.1038/s41598-025-05555-3, p.5]
- **declared_resources：** 资金支持来自浙江省科技计划、NSFC、澳门理工内部资助和浙江省自然科学基金联合项目。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.14]
- **limitations：** 论文明确说明结果完全是计算性的，实际稳定性、生物活性和合成可行性都未实验验证。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.12]
- **limitations：** 作者也指出 plasma stability、release kinetics、immunogenicity 等临床属性尚未纳入建模。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.12]
- **limitations：** 当生成规模继续扩大时，多样性下降，显示模型存在采样或模式坍塌式限制。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.11]
- **limitations：** 性能对训练数据质量和多样性高度敏感，数据不足可能削弱创新性与实用性。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.12]；[doi:10.1038/s41598-025-05555-3, p.13]
- **method：** 作者先用 3707 个 ADC linker 构建专用数据集，再用 ChEMBL、ZINC、QM9 做预训练，均经 RDKit 清洗与特征处理。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.2]
- **method：** Linker-GPT 基于 Mol-GPT/Transformer decoder，用 SMILES token 序列和 masked self-attention 建模 linker 生成。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.3]；[doi:10.1038/s41598-025-05555-3, p.4]
- **method：** RL 目标把合法性、QED、SAS 和 ring number 纳入 reward，并通过监督损失与 RL 损失联合优化。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.4]；[doi:10.1038/s41598-025-05555-3, p.5]
- **method：** 评估采用 MOSES 风格指标，包括 validity、uniqueness、novelty、KL、FCD 和 IntDiv。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.5]；[doi:10.1038/s41598-025-05555-3, p.6]
- **results：** 在 linker 生成任务上，Linker-GPT 的 validity 0.888、novelty 0.986、KL 0.850、FCD 6.63、IntDiv 0.737，整体优于对照模型。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.7]
- **results：** RL 使 SAS<3 的占比从 55.7% 升至 98.7%，并同步改善 QED 和 ring 约束下的生成比例。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.7]
- **results：** scaffold-based generation 的 mean validity 为 0.968、mean novelty 为 0.998，说明可在保留端基的同时改写 linker 中段。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.7]
- **results：** ChEMBL 预训练在迁移任务上整体最好，而 ZINC 在 validity 和 FCD 上略优，表明预训练域会影响生成质量。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.9]；[doi:10.1038/s41598-025-05555-3, p.10]
- **results：** 当生成规模扩展到 100k 时，validity、novelty、KL 与 FCD 基本稳定，但 uniqueness 降到 0.212，提示规模化时多样性受限。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.11]
- **results：** 示例生成的 cleavable/non-cleavable linker 的 QED 约 0.41–0.61，SAS 约 2.65–3.10 / 2.67–2.95。
  - 证据：[doi:10.1038/s41598-025-05555-3, p.12]

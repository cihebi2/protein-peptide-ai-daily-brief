## 研究问题

药物-药物相互作用（DDI，占药物不良反应 30%）预测在零样本场景与少数据约束下表现差——如何用 LLM 的上下文学习（ICL）与多模型评判（judging）机制在无需微调的前提下提升 DDI 预测。

## 作者主张的贡献

提出 DDI-JUDGE：(1) 新 ICL 提示范式——按五种相似度（Tanimoto/Cosine/Dice/Weisfeiler-Lehman 图核/MolBERT 嵌入）检索高相似药物对作为正负示例；(2) 结构化 ICL 提示模板（输入/任务/相关因素/示例）；(3) GPT-4 作为 discriminator 按评分标准为多个 LLM 的预测+解释打分（1-5 分），加权融合得最终预测。零样本/少样本 AUC 0.642/0.788，AUPR 0.629/0.801，为测试模型中最优。代码开源。

## 创新边界

ICL 检索示例、LLM 评判（LLM-as-judge）与加权集成均为已确立技术（文中引用 MolecularGPT、TxT-LLM、Y-Mol 等前作）；DDI 的 LLM 方法亦有先例；其增量在于 DDI 场景的多相似度示例检索与 judge 融合的特定组合。绝对性能不高（零样本 AUC 0.642），与专用微调 GNN 方法不可直接比较（其定位是免微调场景）。与 C03 蛋白语言生成 lane 实质关联弱。

## 方法

- ICL 示例检索：2048-bit Morgan（半径2）指纹 Tanimoto/Cosine/Dice + WL 图核 + MolBERT SMILES 嵌入余弦；药物对相似度=两药相似度乘积，从已知正/负 DDI 中选取
- 结构化提示模板：输入描述、预测任务、相关因素、示例（zero-shot 无示例）
- 多 LLM 预测：多个开源 LLM 各自生成预测+解释
- GPT-4 评判：按明确评分标准对每个预测的解释打 1-5 分（few-shot 评判含高质量评分示例）
- 加权融合：各模型得分×预定权重求和为最终 DDI 预测

## 结果证据

- 零样本：AUC 0.642、AUPR 0.629（所有测试模型中最优）
- 少样本：AUC 0.788、AUPR 0.801
- 优于其他 LLM 基线方法（具体对照表在未读部分）
- 评判+融合对鲁棒性有贡献

## 比较基线

- 其他 LLM 提示方法（zero/few-shot 直接提示）
- 文献中的 GNN/DNN DDI 模型（讨论性对比）

## 已知限制

- 绝对性能中等（零样本 AUC 0.642），未与 SOTA 监督 GNN 公平对比
- 依赖 GPT-4 作为评判器，成本与可复现性受 API 影响
- 相似度检索的示例可能引入数据泄漏（未讨论去重/泄漏控制）
- 与蛋白语言生成 lane 不匹配，属小分子/文本 LLM 应用

## 待复核未知项

- 数据集划分协议与负样本构造（关键，未读部分）
- 各 LLM 候选清单与权重确定方式
- 评判标准的稳定性（多次运行方差）

# Accurate prediction of protein-ligand interactions by combining physical energy functions and graph-neural networks

- **论文 ID：** `EVIW-450A2DC6B2948F9C`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2024 Nov 4
- **DOI：** [10.1186/s13321-024-00912-2](https://doi.org/10.1186/s13321-024-00912-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 AK-Score2，把三个独立的 GNN 子模型与物理打分函数融合：一个做二分类相互作用判定，一个联合预测 binding affinity 与 RMSD，另一个输出带 RMSD 惩罚的能量；目标是在 forward/reverse screening 和 ATX hit discovery 中提高筛选效果。

## 创新边界

`新意主要在训练策略、decoy 设计与多模型融合，不是新的分子生成器或新的 wet-lab 机制；它仍属于 structure-based scoring / virtual screening 方法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知蛋白结构前提下，如何更稳健地预测 protein–ligand 相互作用、结合亲和力与近天然结合姿势，以提升虚拟筛选和 hit discovery 的命中率。

## 方法

- 三个图神经网络子模型分别处理结合/非结合、亲和力和姿势偏差，再与物理能量函数组合重评分。

## 数据与基准

- 使用CASF-2016、DUD-E、LIT-PCBA及专家构造decoy；另对63个候选做autotaxin实验筛选。

## 比较基线

- 既有ML/物理评分函数及在三个独立decoy集合上的筛选方法。

## 结果证据

- 作者报告CASF-2016与DUD-E的top-1%富集因子分别32.7和23.1，并在63个实验候选中识别23个活性化合物。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 训练仍受原生复合物数量和decoy构造影响，输入姿势错误会传递；单个autotaxin案例不能证明广泛前瞻性命中率。

## 仍未知

- 完整训练代码、权重与再训练细节是否都可从冻结文本直接复核。
- 各 benchmark 上的提升有多少来自数据重叠、多少来自模型结构，仍需独立复现。
- ATX 个案的实验成功率能否外推到其他靶点与其他化学空间，尚不清楚。

## Pi 结构化证据摘录

- **baseline：** 作者在 CASF-2016 上对比 AutoDock-GPU、AutoDock Vina、OnionNet-SFCT、PIGNet、RTMScore、GenScore、IGModel、PIGNet2 等方法。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.8]
- **baseline：** 在 DUD-E 与 LIT-PCBA 上，主要比较对象是 AutoDock-GPU、RTMScore，以及 Glide-SP / Glide-XP 和 OnionNet-SFCT+Vina。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.10]；[doi:10.1186/s13321-024-00912-2, p.11]；[doi:10.1186/s13321-024-00912-2, p.12]
- **baseline：** 作者还把 physics-based AutoDock-GPU scoring function 当作融合基线，并验证与 Glide-SP 结合后也能提升 EF。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.7]；[doi:10.1186/s13321-024-00912-2, p.10]
- **data：** 训练数据包含 17,225 个晶体复合物，另外生成 900,910 个 Dconf、1,720,958 个 Dcross 和 1,721,583 个 Drandom 复合结构。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.3]；[doi:10.1186/s13321-024-00912-2, p.4]
- **data：** 基准集使用 CASF-2016、DUD-E（102 个 targets）和 LIT-PCBA（15 个 targets）；LIT-PCBA 还扩展到 489,000 个 active 和 20,391,950 个 inactive docked conformations。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.4]；[doi:10.1186/s13321-024-00912-2, p.10]；[doi:10.1186/s13321-024-00912-2, p.11]
- **data：** 实验验证部分先用 MolFinder 生成超过 100,000 个 ATX 候选，再筛选并合成 63 个分子做 kinetic assay。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.7]；[doi:10.1186/s13321-024-00912-2, p.12]
- **declared_resources：** 训练和测试用的 protein–ligand conformations 已上传至 Zenodo。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.14]
- **declared_resources：** 推理代码已提供于 GitHub 仓库。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.14]
- **limitations：** 作者把 Dcross/Drandom 的真实结合能近似为低于 -5 kcal/mol，这是一种标签假设，而非实测真值。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.6]
- **limitations：** DUD-E 与训练集存在 25 个 target 的高序列相似，CASF-2016 有 10 个 target 与 DUD-E 相似，LIT-PCBA 也有 2 个 target 与训练集重叠。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.10]；[doi:10.1186/s13321-024-00912-2, p.11]
- **limitations：** cutoff 从 5 Å 改到 6 Å 会带来约 5–10% 的准确率下降，说明模型对几何设定仍有依赖。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.9]
- **limitations：** 实验验证只覆盖 ATX 单一靶点，因此更像强力 case study，而不是跨靶点普适性证明。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.12]；[doi:10.1186/s13321-024-00912-2, p.13]
- **method：** 训练集以 PDBbind v2020 general set 为核心，并剔除 CASF-2016 core 及对接失败样本；同时构造 native、conformational decoy、cross-docked decoy 和 random decoy 四类结构数据。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.3]；[doi:10.1186/s13321-024-00912-2, p.4]
- **method：** 图表示以 heavy atom 为节点，区分 covalent 与 non-covalent 边；非共价边在 8 Å 内连接，节点/边特征维度分别为 73/24，NonDock 为 73/12。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.4]
- **method：** AK-Score-NonDock、AK-Score-DockS、AK-Score-DockC 都基于 GATv2 与 MLP；前者做二分类，后两者分别做 affinity+RMSD 回归和惩罚后能量预测。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.5]；[doi:10.1186/s13321-024-00912-2, p.6]；[doi:10.1186/s13321-024-00912-2, p.7]
- **method：** 训练时对 native、decoy 和 RMSD 采用分段监督：Dcross/Drandom 被压到低于 -5 kcal/mol，Dconf 用 RMSD 约束，最终再把三个模型与 AutoDock-GPU 分数做乘积或加权融合。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.6]；[doi:10.1186/s13321-024-00912-2, p.7]
- **results：** 在 CASF-2016 上，AK-Score-C 的 top 1% EF 为 32.7，AK-Score-S 为 32.0；reverse screening top 1% success rate 分别为 71.9% 和 61.4%。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.8]；[doi:10.1186/s13321-024-00912-2, p.9]
- **results：** 在 DUD-E 上，AK-Score-C 的平均 EF 分别为 30.0/23.1/8.4（top 0.5/1/5%），去除高相似 targets 后仍为 29.4/22.8/8.4，并优于 AutoDock-GPU。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.10]
- **results：** 在 LIT-PCBA 上，AK-Score-C 的平均 EF 在 top 0.5% 和 1.0% 阈值为 6.5 和 4.4，剔除重叠 targets 后为 5.6 和 4.1，均高于 RTMScore。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.11]；[doi:10.1186/s13321-024-00912-2, p.12]
- **results：** ATX 实验中，63 个合成候选里有 23 个活性（IC50 < 1 µM），模型的 AUC 为 0.76，高于 AutoDock-GPU 的 0.70 和 Glide-XP 的 0.56。
  - 证据：[doi:10.1186/s13321-024-00912-2, p.12]

# POOE: predicting oomycete effectors based on a pre-trained large protein language model

- **论文 ID：** `EVIW-426A1A532D5D26FF`
- **期刊 / 来源：** mSystems
- **发表时间：** 2023 Dec 11
- **DOI：** [10.1128/msystems.01004-23](https://doi.org/10.1128/msystems.01004-23)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 POOE：用 ProtTrans/ProtT5 生成蛋白嵌入，结合 SVM 构建 oomycete effector 预测器，并提供 web server、源码与数据。

## 创新边界

`这是一个序列级分类与优先级筛选工具，能辅助候选发现，但不直接生成或优化新序列。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 oomycete 蛋白组中，仅基于序列更准确地区分 effector 与 non-effector，以缩小候选集合并支持后续功能研究。

## 方法

- ProtT5-XL-UniRef50生成蛋白嵌入，SVM五折训练并集成输出；比较其他PLM/传统编码。

## 数据与基准

- 文献中1,143个实验确定卵菌效应子及构造负样本，另有独立测试集。

## 比较基线

- EffectorP3.0、EffectorO及传统序列编码+ML、不同PLM。

## 结果证据

- 五折AUPR 0.804、AUROC 0.893、accuracy 0.874、precision 0.777、recall 0.684；独立集超过既有工具。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 正样本物种/发表偏差和负样本不确定；PLM分类不能证明候选实际分泌或致病功能。

## 仍未知

- 冻结证据未独立验证 GitHub 仓库代码是否可直接复现。
- 未见针对更远缘 oomycete 物种的单独泛化验证。
- 未见对新预测候选的实验级功能确认。

## Pi 结构化证据摘录

- **baseline：** 在所有编码/算法组合里，SVM_ProtTrans 的整体表现最好，且 SVM 通常优于 RF、CNN 和 AdaBoost。
  - 证据：[doi:10.1128/msystems.01004-23, p.7]；[doi:10.1128/msystems.01004-23, p.10]；[doi:10.1128/msystems.01004-23, p.11]
- **baseline：** 与 EffectorO、EffectorP 3.0、deepredeff 相比，POOE 的 AUPRC 与其他指标明显更高，论文声称提升约 0.4 个 AUPRC。
  - 证据：[doi:10.1128/msystems.01004-23, p.11]；[doi:10.1128/msystems.01004-23, p.12]
- **baseline：** 与 BLAST 和 motif scanning 相比，POOE 也更强；作者还指出 motif scanning 的效果会受负样本 motif 过滤策略影响。
  - 证据：[doi:10.1128/msystems.01004-23, p.12]
- **data：** 原始数据集包含 549 条正样本和 3337 条负样本；正样本平均长度 194±165，负样本平均长度 283±288。
  - 证据：[doi:10.1128/msystems.01004-23, p.4]
- **data：** 作者按 1:3 正负比构建训练/独立测试集，分别为 437/1338 与 112/332。
  - 证据：[doi:10.1128/msystems.01004-23, p.5]
- **data：** 额外构建了 Additional test-38 与 Additional test-29，前者来自已知效应蛋白少于 10 条的物种，后者来自 2022-01-01 之后新收集的 29 条效应蛋白。
  - 证据：[doi:10.1128/msystems.01004-23, p.8]
- **data：** 论文还给出 Phytophthora parasitica 的蛋白组级示例：22,979 条蛋白先筛得 1,515 条分泌且无跨膜区域的候选。
  - 证据：[doi:10.1128/msystems.01004-23, p.11]
- **declared_resources：** POOE 的 web server、源码与数据集都被作者明确公开，并给出 GitHub 地址。
  - 证据：[doi:10.1128/msystems.01004-23, p.1]；[doi:10.1128/msystems.01004-23, p.13]
- **declared_resources：** 实现与训练依赖 ProtTrans/ProtT5、ESM、scikit-learn、Keras，以及 NCBI、Ensembl、UniRef50、SwissProt、NR 等公开资源。
  - 证据：[doi:10.1128/msystems.01004-23, p.4]；[doi:10.1128/msystems.01004-23, p.5]；[doi:10.1128/msystems.01004-23, p.6]
- **limitations：** 作者明确承认已知 oomycete effectors 数量仍然不足，而且负样本并没有公认的 gold standard。
  - 证据：[doi:10.1128/msystems.01004-23, p.3]；[doi:10.1128/msystems.01004-23, p.9]
- **limitations：** 负样本是否做 motif 过滤会改变并降低性能，说明评估结果可能受采样启发式影响。
  - 证据：[doi:10.1128/msystems.01004-23, p.9]；[doi:10.1128/msystems.01004-23, p.12]
- **limitations：** 作者指出 CNN 在该数据规模下不如 SVM/RF，暗示深度学习在小样本场景下未必占优。
  - 证据：[doi:10.1128/msystems.01004-23, p.11]
- **limitations：** 在线服务对输入也有限制：建议序列长度大于 20 aa，且每个任务最多 200 条序列。
  - 证据：[doi:10.1128/msystems.01004-23, p.12]；[doi:10.1128/msystems.01004-23, p.13]
- **method：** 作者以文献中已实验确认的 oomycete effectors 为正样本来源，并在去冗余与物种阈值筛选后保留 549 条、覆盖 8 个物种。
  - 证据：[doi:10.1128/msystems.01004-23, p.3]；[doi:10.1128/msystems.01004-23, p.4]
- **method：** 负样本由 8 个 oomycete proteome 经过去除 effector 注释、motif 过滤、40% 去冗余、与正样本 95% identity 剔除，以及 SignalP/TMHMM 过滤后得到 3337 条。
  - 证据：[doi:10.1128/msystems.01004-23, p.4]
- **method：** 序列表征同时比较了 ProtT5、ESM-1b、Doc2Vec、PSSM、DPC 和 CT，其中 ProtT5/ProtTrans 通过 mean pooling 形成 1024 维向量。
  - 证据：[doi:10.1128/msystems.01004-23, p.5]；[doi:10.1128/msystems.01004-23, p.6]
- **method：** 模型层面比较了 SVM、RF、AdaBoost 与 CNN，并用 GridSearchCV 或手工调参优化；SVM 使用 rbf kernel，最优 C=10、gamma=0.25。
  - 证据：[doi:10.1128/msystems.01004-23, p.6]
- **method：** 评估采用五折交叉验证和独立测试，指标包括 AUPRC、AUROC、accuracy、precision、recall 与 specificity。
  - 证据：[doi:10.1128/msystems.01004-23, p.6]；[doi:10.1128/msystems.01004-23, p.7]
- **results：** 在五折交叉验证中，SVM_ProtTrans 达到 AUPRC 0.804、AUROC 0.893、accuracy 0.874；在独立测试中达到 AUPRC 0.786、AUROC 0.878、accuracy 0.861。
  - 证据：[doi:10.1128/msystems.01004-23, p.7]；[doi:10.1128/msystems.01004-23, p.9]
- **results：** Additional test-38 和 Additional test-29 的 AUPRC 分别为 0.815 和 0.920，说明该方法在额外测试集上仍然稳健。
  - 证据：[doi:10.1128/msystems.01004-23, p.8]
- **results：** 误分类分析显示，真阳性中 57.3% 含已知 motif，而假阴性仅 35.1%；21 个假阳性里有 16 个与训练效应蛋白存在 BLAST 相似性。
  - 证据：[doi:10.1128/msystems.01004-23, p.8]；[doi:10.1128/msystems.01004-23, p.9]
- **results：** 在 Phytophthora parasitica 的蛋白组示例中，按 FPR 10.2% 控制时 POOE 预测出 324 个 effector，并成功找回 1 个已知 effector。
  - 证据：[doi:10.1128/msystems.01004-23, p.11]

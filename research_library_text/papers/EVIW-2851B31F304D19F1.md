# Attention network for predicting T-cell receptor-peptide binding can associate attention with interpretable protein structural properties

- **论文 ID：** `EVIW-2851B31F304D19F1`
- **期刊 / 来源：** Front Bioinform
- **发表时间：** 2023 Dec 18
- **DOI：** [10.3389/fbinf.2023.1274599](https://doi.org/10.3389/fbinf.2023.1274599)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 cross-TCR-interpreter：将 CDR3α:CDR3β 与 peptide 分别编码后，经 cross-attention 和 MLP 输出结合概率；同时在 benchmark、recent data test set、COVID-19 dataset 与 PDB 结构上做性能和解释性分析。

## 创新边界

`该文的主要新意在于同时处理 CDR3α、CDR3β 与 peptide，并将 cross-attention 与 3D 结构 / H-bond 解释关联；但冻结证据未独立验证其相对于全部外部文献的全球新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在只使用 TCR CDR3α、CDR3β 与 peptide 序列的条件下，预测 TCR–pMHC / TCR–peptide 结合，并尝试把 attention 权重与可解释的蛋白结构特征联系起来。

## 方法

- 修改Transformer的source-target/cross-attention；二分类；内部基准、近期外部集和COVID-19集评估；注意力与结构属性关联。

## 数据与基准

- 公开TCR-pMHC记录及构造负样本；外部近期数据在加假负样本前完成切分。

## 比较基线

- 既有TCR-pMHC序列预测器及内部回顾验证方法。

## 结果证据

- 论文报告在基准和真正较新的外部数据上具有竞争性能，并观察到注意力权重与部分结构性质相关。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 只输入CDR3和肽而不含完整TCR/MHC；假负样本会简化任务；未见数据泛化仍受限。

## 仍未知

- 冻结证据未显示独立代码仓库、许可证或完整可复现运行入口。
- recent data 与 COVID-19 的负样本生成方式可能影响指标解读。
- PDB 结构样本量偏小，attention-structure 结论更适合作为假说而非定论。
- benchmark 中存在训练/测试层面的共享 CDR3 或 peptide，外推难度与已见模式混杂。

## Pi 结构化证据摘录

- **baseline：** 作者比较了 NetTCR-2.0、PanPep、AttnTAP、DLpTCR 和 ERGO-II，认为其方法在序列-only 设定下具有竞争力。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.7]；[doi:10.3389/fbinf.2023.1274599, p.8]
- **baseline：** 在 benchmark 上，ERGO-II 的文献分数被直接引用而非重新完整复现；作者也提到 AttnTAP 与 DLpTCR 在其复现实验里表现较差。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.7]；[doi:10.3389/fbinf.2023.1274599, p.8]
- **baseline：** 在 recent data test set 上，NetTCR-2.0 和 PanPep 也只能达到接近随机的水平，表明跨数据集泛化困难并非本模型独有。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.9]
- **data：** 基准数据来自 ERGO-II 仓库中的 McPAS 与 VDJdb-without10x；作者删除了缺失 CDR3 或 peptide 的记录，并移除训练/测试中重复 pair。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]；[doi:10.3389/fbinf.2023.1274599, p.4]；[doi:10.3389/fbinf.2023.1274599, p.6]
- **data：** combined data dataset 合并 McPAS、VDJdb-without10x 与 VDJdb-with10x；recent data test set 则来自 2023 年 6 月的 VDJdb 下载，并额外加入 5 倍随机负样本。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.4]；[doi:10.3389/fbinf.2023.1274599, p.6]
- **data：** COVID-19 dataset 基于 Lu et al. 2021b 的 spike peptide 窗口重建，作者用 9-mer sliding window 生成 2,120,140 条记录，其中只有 40 条为正例。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.5]；[doi:10.3389/fbinf.2023.1274599, p.9]
- **data：** 结构解释数据来自 PDB 与 SCEptRe；最初识别 65 个结构，筛到 55 个，再去掉重复后用于统计分析的为 47 个结构。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.5]
- **declared_resources：** 训练阶段使用 Osaka University SQUID cluster 的一台 A100 GPU 节点，约 3 小时完成；推理阶段在 2.6 GHz 6-Core Intel Core i7 CPU 上约 2 小时。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]；[doi:10.3389/fbinf.2023.1274599, p.16]
- **declared_resources：** 作者明确使用了 Optuna、ANARCI、Biopython、LIGPLOT、Clustal Omega 和 PyMOL 等工具完成超参搜索、编号、结构分析与可视化。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]；[doi:10.3389/fbinf.2023.1274599, p.5]；[doi:10.3389/fbinf.2023.1274599, p.10]；[doi:10.3389/fbinf.2023.1274599, p.16]
- **declared_resources：** 论文的数据可获取性声明只给出了 GitHub 的 data 路径与 supplementary material 链接，没有在冻结文本中明确给出独立代码仓库或许可。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.15]；[doi:10.3389/fbinf.2023.1274599, p.16]
- **limitations：** 作者明确指出，只用 CDR3 和 peptide 会忽略完整 TCR 与 MHC 信息，因此可能漏掉关键结合机制。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.13]
- **limitations：** recent data test set 与 COVID-19 dataset 的性能较差，作者把原因部分归结为 unseen peptides、数据分布差异以及负样本构造偏差。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.8]；[doi:10.3389/fbinf.2023.1274599, p.14]；[doi:10.3389/fbinf.2023.1274599, p.15]
- **limitations：** 结构解释样本只有 47 个 PDB 复合物，且其中 39 个被模型判为 positive，样本量有限，统计解释的外推性受限。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.9]；[doi:10.3389/fbinf.2023.1274599, p.10]
- **limitations：** benchmark 中训练集与测试集在单条 CDR3 或 peptide 层面仍存在重叠，这使任务在某些划分下更接近已见模式匹配而非真正的外推。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.6]；[doi:10.3389/fbinf.2023.1274599, p.14]
- **method：** 模型将 CDR3α:CDR3β 与 peptide 分别嵌入后，经 Transformer 与 cross-attention，再用 MLP 输出 0–1 结合分数。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]
- **method：** cross-attention 以 peptide 为 Q、TCR 侧为 K/V，并对多头 attention 矩阵做残基级可视化与解释。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]；[doi:10.3389/fbinf.2023.1274599, p.10]
- **method：** 训练目标是 binary cross entropy，使用 ROC AUC 与 average precision 评估；若 10 次更新内 BCE 不再改善则 early stopping，超参由 Optuna 搜索。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.3]；[doi:10.3389/fbinf.2023.1274599, p.4]
- **method：** 结构解释阶段把 attention 按 mean+γ·STD 划分为 large / small 两组，对 47 个 PDB 复合物做 paired t-test，并用 Benjamini-Hochberg 校正。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.5]；[doi:10.3389/fbinf.2023.1274599, p.10]；[doi:10.3389/fbinf.2023.1274599, p.11]
- **results：** 在 McPAS 上，模型 ROC AUC 为 0.9154、APS 为 0.6211；在 VDJdb-without10x 上，ROC AUC 为 0.9445、APS 为 0.7600，整体与 NetTCR-2.0 接近。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.7]；[doi:10.3389/fbinf.2023.1274599, p.8]
- **results：** recent data test set 上 ROC AUC 只有 0.5362、APS 为 0.1855；known peptide 子集明显好于 new peptide 子集，说明 unseen peptides 仍是主要难点。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.9]；[doi:10.3389/fbinf.2023.1274599, p.15]
- **results：** COVID-19 dataset 上 ROC AUC 为 0.5461、APS 为 2.032e-5；当正例比例调到 20% 时，ROC AUC 提升到 0.5881，但整体仍不足以替代实验。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.9]；[doi:10.3389/fbinf.2023.1274599, p.14]
- **results：** 结构统计表明，large-attention residues 更常与自身 CDR3 形成 H-bond，而更少与非 CDR3 TCR 区域形成 H-bond；peptide 侧的 large-attention residues 也更接近 TCR。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.11]；[doi:10.3389/fbinf.2023.1274599, p.12]
- **results：** 输入扰动在 5TEZ、1AO7 和 4FTV 上显示，模型会集中到少数关键 CDR3 残基，尤其是那些参与内部 H-bond 或突变增强结合的位点。
  - 证据：[doi:10.3389/fbinf.2023.1274599, p.12]；[doi:10.3389/fbinf.2023.1274599, p.13]

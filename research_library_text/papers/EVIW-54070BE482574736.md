# Nucleotide context models outperform protein language models for predicting antibody affinity maturation

- **论文 ID：** `EVIW-54070BE482574736`
- **期刊 / 来源：** PLoS Comput Biol
- **发表时间：** 2025 Dec 1
- **DOI：** [10.1371/journal.pcbi.1013758](https://doi.org/10.1371/journal.pcbi.1013758)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 EPAM 作为统一评估框架，把 SHM-only、SHM+selection 和 protein language models 放到同一流程中比较，并声称 nucleotide-based SHM 模型在 human repertoires 与 Replay mouse data 上整体优于 AbLang2、ESM-1v 等蛋白语言模型。

## 创新边界

`新颖性主要在统一评估框架 EPAM、分框架比较和经验结论，不在新抗体候选生成或湿实验发现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

比较 nucleotide-context 的 SHM/selection 模型与 protein language models 在 antibody affinity maturation 轨迹预测上的相对能力，尤其是对 BCR phylogenetic parent-child pairs 的位点替换、氨基酸结果和校准性能。

## 方法

- 比较多种molecular evolution和protein LM评分，在人/鼠BCR克隆家系上预测亲子突变，并分析mutation与selection贡献。

## 数据与基准

- 多个人BCR repertoire和重复免疫小鼠数据；部分数据已在AbLang2或Thrifty训练集中出现并被作者披露。

## 比较基线

- AbLang2、Thrifty等PLM及多种somatic hypermutation nucleotide-context模型。

## 结果证据

- 论文总体发现核苷酸上下文模型优于PLM；该结果用于理解突变偏好，不直接证明抗体亲和力。

## 可用资源与代码关系

## 已知限制

- 部分评价数据与模型训练数据重叠；亲子推断不处理同一位点多次突变，且只保留完整无歧义序列家系。

## Pi 结构化证据摘录

- **baseline：** 论文显式对比的基线包括 S5F、Thrifty-SHM、Thrifty-prod、ReplaySHM、ReplaySHM+BLOSUM62、ReplaySHM+ESM-1v、ReplaySHM+DMS、AbLang1/2、ESM-1v 和 BLOSUM62-derived selection。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.6]；[doi:10.1371/journal.pcbi.1013758, p.7]；[doi:10.1371/journal.pcbi.1013758, p.19]；[doi:10.1371/journal.pcbi.1013758, p.20]；[doi:10.1371/journal.pcbi.1013758, p.21]
- **baseline：** 作者指出 Tang 的一部分序列与 AbLang2 训练集重叠，Jaffe 数据集是 Thrifty-prod 的训练数据，而 Rodriguez 和 Ford 更接近真正的 out-of-sample human evaluation。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.3]；[doi:10.1371/journal.pcbi.1013758, p.6]；[doi:10.1371/journal.pcbi.1013758, p.17]；[doi:10.1371/journal.pcbi.1013758, p.21]
- **baseline：** BLOSUM62 作为 selection proxy 基本没有带来稳定收益，而 ESM-1v 作为 selection proxy 往往削弱性能，因此它们更像对照基线而非强竞争方案。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.7]；[doi:10.1371/journal.pcbi.1013758, p.14]；[doi:10.1371/journal.pcbi.1013758, p.19]
- **data：** 主分析覆盖四个 human IgH repertoire 数据集（Tang, Jaffe, Rodriguez, Ford）以及 Replay mouse affinity maturation experiment；Replay 数据约有 heavy/light chain 各 5000 个 PCP，且每个 PCP 的中位替换数约为 1。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.3]；[doi:10.1371/journal.pcbi.1013758, p.11]；[doi:10.1371/journal.pcbi.1013758, p.15]；[doi:10.1371/journal.pcbi.1013758, p.17]
- **data：** 数据预处理先用 partis 做 germline inference 和 clonal family clustering，再用 IQ-TREE 重建系统发育树与 ancestral sequences，并过滤掉非 productive、含 indel、stop codon、ambiguous nucleotides 或异常高突变密度的序列。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.15]；[doi:10.1371/journal.pcbi.1013758, p.16]；[doi:10.1371/journal.pcbi.1013758, p.17]
- **data：** 人类数据用 ANARCI 和 IMGT 编号对齐，并采用 IMGT 定义的 FWR/CDR 边界；成对 heavy/light 数据还使用 edge-linked-proportional partition 处理链特异速率。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.16]；[doi:10.1371/journal.pcbi.1013758, p.17]
- **declared_resources：** 作者在正文中声明 models、inference code 和 analysis scripts 已公开在 GitHub，processed data 公开在 Zenodo。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.2]
- **declared_resources：** 分析流程依赖 partis、IQ-TREE、Biopython、ANARCI 以及 OGRDB human germline sets 等公共工具和资源。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.15]；[doi:10.1371/journal.pcbi.1013758, p.16]；[doi:10.1371/journal.pcbi.1013758, p.17]
- **declared_resources：** 研究还使用了外部预训练模型和实验资源，包括 AbLang1/2、ESM-1v，以及 Replay 实验中的 DMS binding measurements。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.6]；[doi:10.1371/journal.pcbi.1013758, p.11]；[doi:10.1371/journal.pcbi.1013758, p.19]；[doi:10.1371/journal.pcbi.1013758, p.20]；[doi:10.1371/journal.pcbi.1013758, p.21]
- **limitations：** 作者承认使用的是 classification-style 指标而不是 CTMC likelihood，因为并非所有模型都能放进 CTMC 框架，因此结果更像统一评测而非严格的进化模型拟合。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.14]
- **limitations：** NT 侧的 amino acid 概率是由 codon 级别概率近似得到，不能自然处理同一位点的多次突变；作者依赖 PCP 分支较短来说明这一近似可接受。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.18]
- **limitations：** AA 模型对 MLM 概率做了启发式的 (1-e^-τ) 缩放，仍无法直接表达 evolutionary time 或 SHM 机制，因此校准和可比性有限。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.20]
- **limitations：** 论文也指出没有显式结构信息，并且 ESM-1v selection factors 与 DMS 的相关性偏弱；另外部分人类数据与训练集重叠会带来潜在偏差。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.14]；[doi:10.1371/journal.pcbi.1013758, p.15]；[doi:10.1371/journal.pcbi.1013758, p.3]；[doi:10.1371/journal.pcbi.1013758, p.6]
- **method：** EPAM 以 phylogenetic parent-child pairs 为评估单元，并通过对每个模型优化 branch length τ，把不同输入/输出形式的模型统一成可比较的 amino acid 概率。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.4]；[doi:10.1371/journal.pcbi.1013758, p.17]；[doi:10.1371/journal.pcbi.1013758, p.18]；[doi:10.1371/journal.pcbi.1013758, p.19]；[doi:10.1371/journal.pcbi.1013758, p.20]
- **method：** 论文把模型分成 NT、NT-AA 和 AA 三类：NT 主要是 S5F、Thrifty-SHM、ReplaySHM、Thrifty-prod，NT-AA 叠加 ESM-1v、BLOSUM62 或 DMS 形成 selection factor，AA 则使用 AbLang1/2 与 ESM-1v 的 masked-marginals 或 wt-marginals。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.6]；[doi:10.1371/journal.pcbi.1013758, p.7]；[doi:10.1371/journal.pcbi.1013758, p.19]；[doi:10.1371/journal.pcbi.1013758, p.20]；[doi:10.1371/journal.pcbi.1013758, p.21]
- **method：** 性能指标包括 site substitution probability 的 overlap、R-precision，以及氨基酸结果预测的 substitution accuracy 和 CSP perplexity，并且在全序列与 FWR/CDR 区域分别汇总。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.4]；[doi:10.1371/journal.pcbi.1013758, p.5]；[doi:10.1371/journal.pcbi.1013758, p.10]；[doi:10.1371/journal.pcbi.1013758, p.11]
- **results：** 在 Tang 数据上，Thrifty-SHM 比 S5F 更好（overlap 0.834 vs 0.784；R-precision 0.127 vs 0.0963），而 Thrifty-prod 在 overlap 0.923 和 R-precision 0.139 上达到最佳。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.7]
- **results：** protein LMs 的 site-level 预测更不稳定：ESM-1v 和 AbLang2 常在 FWR/CDR 分布上高估或低估替换，且用 ESM-1v 生成 selection factors 往往会让 overlap 和 R-precision 变差。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.7]；[doi:10.1371/journal.pcbi.1013758, p.8]；[doi:10.1371/journal.pcbi.1013758, p.10]
- **results：** 在七个已知高度保守位点上，SHM-only 模型通常过度预测替换；Thrifty-SHM + ESM-1v 虽把这些位点排得更靠前，但整体仍明显低估大多数位点的替换数。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.9]
- **results：** Replay 数据上，ReplaySHM + DMS 在位点定位、substitution accuracy 和 CSP perplexity 上总体最好或并列最好，但相对 ReplaySHM 的提升并不大；ReplaySHM 本身仍整体优于 AbLang2。
  - 证据：[doi:10.1371/journal.pcbi.1013758, p.11]；[doi:10.1371/journal.pcbi.1013758, p.12]；[doi:10.1371/journal.pcbi.1013758, p.13]

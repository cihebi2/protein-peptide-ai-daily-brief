# MOLECULE: Molecular-dynamics and Optimized deep Learning for Entropy-regularized Classification and Uncertainty-aware Ligand Evaluation

## 作者主张的创新点

作者声称提出了一个双模态 deep learning 分类器，分别处理动力学时间序列矩阵与 Morgan fingerprint，并加入 dynamic focal loss、entropy regularization、confidence threshold 和 imputer 分支，以支持不确定性意识的 ligand 功能评估。[doi:10.1021/acs.jctc.5c01140, p.3][doi:10.1021/acs.jctc.5c01140, p.4][doi:10.1021/acs.jctc.5c01140, p.10]

## 创新边界

`相对可核验的新意主要是数据集扩展、双分支架构与插补式工程化整合；论文自身未提供独立外部证据来验证全球首创性。[doi:10.1021/acs.jctc.5c01140, p.2][doi:10.1021/acs.jctc.5c01140, p.10][doi:10.1021/acs.jctc.5c01140, p.12]`。这不是全球首创性检索或独立复现结论。

## 研究问题

该文要解决的是：如何把 protein-ligand 复合物的 MD 动力学信息与 ligand 的静态化学指纹结合起来，稳健地区分 kinase ligand 的 orthosteric 与 allosteric 作用模式，并在缺少 MD 数据时仍能给出可控不确定性的预测。[doi:10.1021/acs.jctc.5c01140, p.1][doi:10.1021/acs.jctc.5c01140, p.5]

## 方法

- MD descriptors与结构features双分支网络，entropy regularization/uncertainty输出。

## 数据与基准

- 约280 resolved kinase structures，经筛选构建allosteric/orthosteric集。

## 比较基线

- 仅MD/仅结构与传统ML。

## 结果证据

- 论文报告结构+动态提高分类；为计算mode-of-action预测。

## Pi 结构化证据摘录

- **baseline：** 作者给出的 binary-only 对照模型明显更弱，尤其在更严格阈值下鲁棒性下降，说明单独依赖 fingerprint 不够。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.8]；[doi:10.1021/acs.jctc.5c01140, p.12]
- **baseline：** 论文也把此前仅含 38 个 CDKs 的工作作为历史参照，本工作将范围扩展到 73 个 kinases 和约 280 个结构。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.2]；[doi:10.1021/acs.jctc.5c01140, p.10]
- **data：** 最终数据集约含 280 个 experimentally resolved ligand-protein complexes，覆盖 73 个 protein kinases，并按 80:10:10 在 complex 级别划分训练、验证和测试集。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.5]
- **data：** 作者在 UMAP 上观察到两类样本没有清晰分离，说明该二分类任务本身具有较强重叠和非线性。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.5]
- **data：** 每个复合物的输入同时包含完整动力学矩阵和 2048-bit fingerprint，因此同一 complex 会派生出多个 replica/atom-selection 样本。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.3]；[doi:10.1021/acs.jctc.5c01140, p.5]
- **declared_resources：** 作者在 Notes 中声明代码公开于 GitHub: https://github.com/colombolab/molecule.git。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.12]
- **declared_resources：** 论文还明确列出可复现环境，包括 Python 3.12.10、PyTorch 2.6.0+cu126、CUDA 12.8 和 RTX 3050 Laptop GPU。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.12]
- **limitations：** MD 轨迹获取成本高，作者也明确指出在早期筛选、计算资源受限或 binding site 未知时，直接做 MD 往往不现实。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.2]；[doi:10.1021/acs.jctc.5c01140, p.8]；[doi:10.1021/acs.jctc.5c01140, p.11]
- **limitations：** 阈值越高，模型越保守，coverage 会下降且 test accuracy 明显变差，例如 0.95 时原始模型 test accuracy 降到 69.64%。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.7]；[doi:10.1021/acs.jctc.5c01140, p.9]；[doi:10.1021/acs.jctc.5c01140, p.11]
- **limitations：** 论文没有提供独立外部测试集或前瞻性实验验证，因此泛化能力主要仍来自冻结划分内的评估。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.5]；[doi:10.1021/acs.jctc.5c01140, p.12]
- **method：** 数据先按实验解析的 kinase 复合物进行整理，并排除重复、鼠源、缺失残基或已知绑定冲突的结构，再形成 orthosteric/allosteric 两类样本。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.2]
- **method：** 每个复合物做 4 个独立 100 ns MD replicas，提取 6 个残基的 RMSD 与 pairwise distances，形成 16×2000 的时间序列矩阵，并对每条序列做 z-score 标准化。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.3]；[doi:10.1021/acs.jctc.5c01140, p.5]
- **method：** ligand 侧用 RDKit 计算 2048-bit Morgan fingerprint，作为静态化学输入。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.3]；[doi:10.1021/acs.jctc.5c01140, p.5]
- **method：** 模型采用 temporal CNN 分支、binary fully connected 分支与 shared classification head；训练中使用 dynamic focal loss、entropy regularization、AdaBelief、max-norm 和高 dropout。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.3]；[doi:10.1021/acs.jctc.5c01140, p.4]；[doi:10.1021/acs.jctc.5c01140, p.6]
- **method：** 作者还训练了一个 imputer，把 2048 维 fingerprint 映射到 8 维动态 latent embedding，以便在缺少 MD 时仍可做推断。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.4]；[doi:10.1021/acs.jctc.5c01140, p.8]；[doi:10.1021/acs.jctc.5c01140, p.10]
- **results：** 原始双模态模型在阈值 0.5 下的 test accuracy 与 F1 都达到 92.86%，Cohen’s kappa 为 0.86。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.6]；[doi:10.1021/acs.jctc.5c01140, p.7]
- **results：** Integrated Gradients 显示动力学输入贡献了超过 90% 的 total attribution，而 fingerprint 在平均单特征贡献上约占 62%。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.8]；[doi:10.1021/acs.jctc.5c01140, p.11]
- **results：** imputation-augmented 模型在阈值 0.5 下 test accuracy 为 89.29%，F1 为 89.16%，kappa 为 0.79，说明重建的动态表征仍能支持较强分类。
  - 证据：[doi:10.1021/acs.jctc.5c01140, p.8]；[doi:10.1021/acs.jctc.5c01140, p.9]

# GTE-PPIS: a protein-protein interaction site predictor based on graph transformer and equivariant graph neural network

## 作者主张的创新点

作者声称提出 GTE-PPIS：一个双分支结构化预测器，把 graph transformer 与 equivariant graph neural network 结合起来，并融合四类节点特征与两类边特征，在多个 benchmark 上优于既有方法。

## 创新边界

`新意主要在残基级预测架构与特征融合，不是生成式候选设计或实验筛选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知蛋白结构上对残基是否属于 protein–protein interaction site 进行高精度预测，以支持界面识别、功能分析和后续分子设计。

## 方法

- residue graph transformer+equivariant message passing。

## 数据与基准

- PPI site benchmarks。

## 比较基线

- AGAT/GeoNet等。

## Pi 结构化证据摘录

- **baseline：** Test_60 的对比基线包括 ScanNet、DELPHI、HN-PPISP、DeepPPISP、MaSIF-site、EDLMPPI、GraphPPIS、RGCNPPIS 与 AGAT-PPIS。
  - 证据：[doi:10.1093/bib/bbaf290, p.5]
- **baseline：** Test_315-28 与 UBtest_25 的对比对象主要是 GraphPPIS、RGCNPPIS 和 AGAT-PPIS。
  - 证据：[doi:10.1093/bib/bbaf290, p.5]
- **data：** 实验使用 Train_334、Test_60、Test_315-28 与 UBtest_25 等 benchmark，数据源自 PDB 蛋白复合物；作者还说明对少数序列与 PDB 条目不一致的样本做了剔除，形成最终 curated 数据集。
  - 证据：[doi:10.1093/bib/bbaf290, p.2]；[doi:10.1093/bib/bbaf290, p.3]
- **data：** 这些数据集具有明显 class imbalance，正样本比例大约在 12.02% 到 15.79% 之间，作者明确指出 interacting residues 少于 20%。
  - 证据：[doi:10.1093/bib/bbaf290, p.3]
- **declared_resources：** Data availability 声明给出 datasets and code 的 GitHub 地址：https://github.com/Reverie-12/GTE-PPIS。
  - 证据：[doi:10.1093/bib/bbaf290, p.8]
- **declared_resources：** Funding 来自 National Natural Science Foundation of China、Natural Science Foundation of Shandong Province，以及 National Key R&D Program of China。
  - 证据：[doi:10.1093/bib/bbaf290, p.8]
- **declared_resources：** 论文声明 no conflict of interest。
  - 证据：[doi:10.1093/bib/bbaf290, p.7]
- **limitations：** 作者明确承认，基于 GNN 与 attention 的模型会受到 sequence size 和 GPU memory 的限制，因此采用 binary adjacency matrix，并使用 NVIDIA RTX 4090 进行缓解。
  - 证据：[doi:10.1093/bib/bbaf290, p.7]
- **limitations：** 作者把可扩展性列为后续改进方向，建议采用 linear attention approximation 和 model parallelism 进一步降低复杂度。
  - 证据：[doi:10.1093/bib/bbaf290, p.7]
- **method：** 将蛋白表示为无向图，把 PPI site 预测转成 node classification；节点融合 PSSM、HMM、DSSP、AF 四类特征，形成 61 维 residue 表征，边则由 14 Å 邻接与距离/余弦关系构成。
  - 证据：[doi:10.1093/bib/bbaf290, p.2]；[doi:10.1093/bib/bbaf290, p.3]
- **method：** 采用 dual-branch 架构：EGNN 通过 equivariant message passing 更新坐标与节点特征，GT 通过 multi-head self-attention 捕获 global dependencies，最后融合表示并用 MLP 输出残基级概率。
  - 证据：[doi:10.1093/bib/bbaf290, p.3]；[doi:10.1093/bib/bbaf290, p.4]
- **method：** 训练采用 5-fold cross-validation，每折再划出 20% 作为 validation；使用 Adam 训练 50 epochs，初始学习率 0.001 并衰减到 10^-6，评价指标为 ACC、Precision、Recall、F1、AUROC、MCC 和 AUPRC。
  - 证据：[doi:10.1093/bib/bbaf290, p.4]
- **results：** 在 Test_60 上，GTE-PPIS 取得 ACC 0.861、F1 0.582、AUROC 0.873、MCC 0.500、AUPRC 0.611，并相对次优方法在 Recall、F1、MCC、AUPRC 上分别提升约 1.3%、2.2%、3.3% 和 6.4%。
  - 证据：[doi:10.1093/bib/bbaf290, p.5]
- **results：** 在 Test_315-28、Btest_25 与 UBtest_25 上，GTE-PPIS 分别取得 MCC/AUPRC 为 0.511/0.598、0.471/0.545、0.320/0.343；其中 UBtest_25 的 AUPRC 略低于 RGCNPPIS，但 MCC 最好。
  - 证据：[doi:10.1093/bib/bbaf290, p.5]
- **results：** 消融实验表明，去掉 EGNN、GT、Residual connections 或 previous layer representations 都会降低性能；其中 NoResidual 在 Test_60 上下降最明显，说明 residual connections 对稳定性很关键。
  - 证据：[doi:10.1093/bib/bbaf290, p.6]
- **results：** 特征消融显示去掉 AF 时性能降幅最大，而 HMM 影响最小；作者还指出 DSSP 对 AUROC/AUPRC 波动和预测稳定性有重要作用。
  - 证据：[doi:10.1093/bib/bbaf290, p.6]；[doi:10.1093/bib/bbaf290, p.7]
- **results：** 案例研究以 PDB 6LKI Chain A 为例，GTE-PPIS 相比 GraphPPIS、RGCNPPIS、AGAT-PPIS 产生更少 false positive，并且正确预测的 positive sites 数量最多。
  - 证据：[doi:10.1093/bib/bbaf290, p.7]

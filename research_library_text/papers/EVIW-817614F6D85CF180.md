# VeGA-RX and VeGA-SCX: Controllable SMARTS-Guided Generative Transformers for Precision-Driven De Novo Drug Design

- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 VeGA-RX 与 VeGA-SCX 两种基于 decoder-only Transformer 的条件生成器：前者用 SMARTS-RX 语义约束，后者再叠加 Bemis-Murcko scaffold；并用温度采样、漏泄安全 fine-tuning、与 LDMol 对比，以及 DCAF1/WRN 的 docking/MD 案例展示其适用性。

## 创新边界

`相对既有 VeGA 的条件化扩展与任务化应用，核心增量在 SMARTS-RX 与 scaffold 的组合控制；冻结证据不足以独立验证其全局原创性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

解决 de novo drug design 中的可控生成问题：如何在保持化学有效性、drug-likeness 与多样性的同时，按 SMARTS/Scaffold 约束定向生成候选分子，并在低数据靶点上做可解释的候选优先级排序。

## 方法

- SMILES transformer按SMARTS constraints/reaction contexts conditional generation。

## 数据与基准

- 大规模molecules/reactions及constrained benchmarks。

## 比较基线

- unconstrained/fragment/scaffold generators。

## Pi 结构化证据摘录

- **baseline：** 对照基线包括原始 VeGA、R4、S4，以及条件生成对比中的 LDMol；作者还以目标训练集对 ChEMBL 的同规模随机样本定义 Baseline FCD。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.2]；[doi:10.1021/acs.jcim.6c00535, p.4]；[doi:10.1021/acs.jcim.6c00535, p.6]；[doi:10.1021/acs.jcim.6c00535, p.11]
- **baseline：** 作者把前作 VeGA 作为直接方法基线，并强调其先前在 MOSES 和 FXR 场景中的竞争性表现，以此作为本工作的改进起点。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.2]；[doi:10.1021/acs.jcim.6c00535, p.6]
- **data：** 五个下游靶点的数据规模分别为 FXR 882、PKM2 436、MAPK1 246、GBA 132、mTORC1 77；DCAF1 只有 28 个 Kd 数据点，而 WRN 以 PDB 8F8E 和 8PFO 的共晶复合物为模板。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]；[doi:10.1021/acs.jcim.6c00535, p.13]
- **data：** 作者声明 ChEMBL 是 public domain 资源，SMARTS-RX 代码以 Apache 2.0 许可公开，VeGA-for-de-novo-design 的 code/data/fine-tuned models 以 MIT license 公开，并给出对应 GitHub 仓库。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.14]
- **data：** 论文还声明使用的基础软件与平台包括 RDKit、TensorFlow、Schrödinger Suite、PyMOL、ChEMBL 和 SMARTS-RX；其中部分为开源或带许可的第三方资源。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **declared_resources：** 训练与预处理使用 ChEMBL28、RDKit 2022.03 和 TensorFlow 2.9.0；ChEMBL 被声明为 public domain 数据资源。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **declared_resources：** 对接与分子动力学使用 Schrödinger Suite 2025-2（Protein Preparation Workflow、LigPrep、Glide、Desmond），并采用 OPLS_2005 与 OPLS4；PyMOL 用于结构展示与图形制作。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.4]；[doi:10.1021/acs.jcim.6c00535, p.5]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **declared_resources：** 作者声明 SMARTS-RX 代码在 GitHub 以 Apache 2.0 公开，VeGA-for-de-novo-design 的 code/data/fine-tuned models 以 MIT license 公开，并提供 supporting information。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.14]
- **limitations：** 方法依赖用户定义的 SMARTS-RX 和可选 scaffold，不直接编码 protein structure，因此需要先验化学或结构知识来构造 prompt。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.13]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **limitations：** VeGA-SCX 的 scaffold 约束会偏向 scaffold retention，降低相对 VeGA-RX 的探索性；同时模型也不是 free-text-to-molecule 系统。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.13]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **limitations：** docking 和 MD 只提供结构与能量上的 plausibility，作者明确指出仍需 biochemical 和 cellular assays 才能确认 binding affinity 与 biological activity。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.13]；[doi:10.1021/acs.jcim.6c00535, p.14]
- **method：** 模型是 decoder-only autoregressive Transformer，使用 causal masking、sinusoidal positional encodings，6 层/6 heads、d_model 512、FFN 2048、dropout 0.1，并基于 Python 3.9、RDKit 2022.03 和 TensorFlow 2.9.0 实现。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]
- **method：** 预训练集来自 ChEMBL28，经去盐、去混合物、去无机物、去重和去立体化后得到 1,092,285 个分子；每个分子提取 SMILES、Bemis-Murcko scaffold 和 SMARTS-RX 三种表示。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]
- **method：** 作者构造 SMARTS-only 与 Hybrid 两种序列格式，并将 composite sequence length 限制在 5 到 140 tokens；过滤后保留 891,004 个 SMILES。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.3]
- **method：** 下游 fine-tuning 使用 FXR、PKM2、MAPK1、GBA、mTORC1 五个低数据集合，并采用 scaffold split 加 ECFP4 Tanimoto ≥ 0.6 的 sphere exclusion 构建 leakage-safe holdout；训练最多 100 epochs，学习率 5×10^-5，batch size 32，并使用 early stopping。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.4]
- **method：** 评估指标包括 validity、uniqueness、novelty、QED、SA、Ro5/PAINS、KS、KL、FCD，以及 RR_T、RS_T/RS_H、SNN 和 IntDiv；同时用 UMAP 做 chemical space 可视化。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.4]
- **method：** 结构验证使用 Glide 在 OPLS_2005 下做 rigid-receptor docking，随后以 OPLS4 在 Desmond 中做四个独立 100 ns MD；DCAF1 和 WRN 的 top candidates 还进行了 MM-GBSA rescoring。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.4]；[doi:10.1021/acs.jcim.6c00535, p.5]
- **results：** 在无条件生成中，VeGA-RX validity 为 94.40%、VeGA-SCX 为 90.10%，两者 uniqueness/novelty 都超过 99%；FCD 分别为 0.90±0.02 与 0.93±0.02，优于原始 VeGA 的 0.97±0.02。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.6]；[doi:10.1021/acs.jcim.6c00535, p.7]
- **results：** 当 sampling temperature 从 1.0 降到 0.6 时，VeGA-RX 的 QED 从 0.56 升到 0.65、SA 从 2.90 降到 2.32；VeGA-SCX 的 QED 从 0.60 升到 0.68、SA 从 2.86 降到 2.38，并伴随 structural alerts 大幅减少。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.7]；[doi:10.1021/acs.jcim.6c00535, p.8]
- **results：** 在五靶点 retrospective rediscovery 中，VeGA-SCX 在 mTORC1 上 RR_T 达 91.94%，在 GBA 上达 96.15%；VeGA-RX 在 PKM2 上 RR_T 为 76.44%、FCD 为 8.93，体现出更强的 scaffold hopping 与较高 validity。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.8]；[doi:10.1021/acs.jcim.6c00535, p.9]；[doi:10.1021/acs.jcim.6c00535, p.10]
- **results：** 相较 LDMol，VeGA 在两个 case studies 中给出更高 validity、更低 structural alerts/PSA，且批量生成 100 个分子所需时间少于 30 s，而 LDMol 约需 3 min。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.11]；[doi:10.1021/acs.jcim.6c00535, p.12]
- **results：** 在 DCAF1 与 WRN 案例中，Top-1/3/4/5/6 候选在 docking、MM-GBSA 和四重复 100 ns MD 下保持相对稳定的结合姿态；作者将其定位为结构可行性和候选优先级证据，而非直接亲和力证明。
  - 证据：[doi:10.1021/acs.jcim.6c00535, p.13]；[doi:10.1021/acs.jcim.6c00535, p.14]

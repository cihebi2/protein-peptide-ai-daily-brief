# xCAPT5: protein-protein interaction prediction using deep and wide multi-kernel pooling convolutional neural networks with protein language model

- **论文 ID：** `EVIW-548BA32503295D77`
- **期刊 / 来源：** BMC Bioinformatics

## 作者主张的创新点

提出 xCAPT5：把 ProtT5-XL-UniRef50 序列嵌入、深而宽的 multi-kernel Siamese CNN、pair-level MLP 和 XGBoost 结合起来，用于 sequence-only PPI 预测，并在多个基准与泛化设置上取得更高指标。

## 创新边界

`其创新边界在于序列表征与分类架构改进，不是生成、优化、对接或筛选新的蛋白/肽/药物候选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

用蛋白序列直接预测二分类 protein-protein interactions (PPI)，以替代昂贵、缓慢且覆盖不全的实验筛选，并提升跨物种与低同源场景下的泛化能力。

## 方法

- 双蛋白ProtT5 embedding、不同kernel convolution/pooling与classifier。

## 数据与基准

- 多个PPI benchmark。

## 比较基线

- PIPR/D-SCRIPT等。

## Pi 结构化证据摘录

- **baseline：** 对比基线覆盖 PIPR、FSNN-LGBM、GcForestPPI、MARPPI、HNSPPI、EresCNN、TAGPPI、Graph-BERT、D-SCRIPT、Topsy-Turvy 和 DeepTrio。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.10]；[doi:10.1186/s12859-024-05725-6, p.11]；[doi:10.1186/s12859-024-05725-6, p.12]；[doi:10.1186/s12859-024-05725-6, p.15]
- **baseline：** 作者将增益主要归因于 protein language model embedding、多 kernel CNN、深层结构，以及 neural network + XGBoost 的 hybrid 设计。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.3]；[doi:10.1186/s12859-024-05725-6, p.16]；[doi:10.1186/s12859-024-05725-6, p.17]
- **data：** 五折交叉验证主要在 Martin H. pylori、Guo yeast 和 Pan human 三个 gold-standard 数据集上完成。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.10]；[doi:10.1186/s12859-024-05725-6, p.11]
- **data：** 泛化评估使用 human 训练集后测试 intra-species、cross-species 和 inter-species 场景，覆盖 HPRD、DIP、HIPPIE HQ/LQ、mouse、fly、worm、yeast、E. coli 以及多种 human-virus 数据集。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.10]；[doi:10.1186/s12859-024-05725-6, p.11]；[doi:10.1186/s12859-024-05725-6, p.14]；[doi:10.1186/s12859-024-05725-6, p.15]
- **data：** 严格同源评估使用 Chen multispecies 数据集，并按 sequence similarity 从 Any、≤40%、≤25%、≤10% 到 ≤1% 分层。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.15]；[doi:10.1186/s12859-024-05725-6, p.16]
- **declared_resources：** 作者声明 xCAPT5 代码可在 GitHub 仓库 https://github.com/aidantee/xCAPT5 获取，但本次未核验仓库内容。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.19]
- **declared_resources：** 论文声明由 Vietnam National Foundation for Science and Technology Development (NAFOSTED) 资助，grant number 102.05-2016.14。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.19]
- **limitations：** 作者明确指出，在不平衡数据集上，xCAPT5 的 precision 并不总是最优，部分情况下 Topsy-Turvy 或 D-SCRIPT 反而更高。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.18]
- **limitations：** 作者也承认模型较复杂，解释性不足，且需要较多 hyperparameter tuning。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.18]
- **limitations：** 论文未展开对内部表示的 PCA/聚类分析，作者把这视为当前工作的一个空缺。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.18]
- **method：** 先用 ProtT5-XL-UniRef50 将氨基酸序列编码为 embedding，试图保留上下文、理化、进化与功能信息。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.4]；[doi:10.1186/s12859-024-05725-6, p.5]
- **method：** 主体网络采用 Siamese 的 deep multi-kernel CNN，kernel size 为 2、3、4，且每个分支有 5 个 block，并结合 Swish、AP/MP、GAP/GMP 和 depth-wise pooling accumulation。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.4]；[doi:10.1186/s12859-024-05725-6, p.5]；[doi:10.1186/s12859-024-05725-6, p.6]；[doi:10.1186/s12859-024-05725-6, p.7]
- **method：** 两个蛋白的表征先在 pair-level MLP 中融合，再把倒数层表示送入 XGBoost 做最终二分类与概率输出。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.8]；[doi:10.1186/s12859-024-05725-6, p.9]
- **method：** 训练超参数包括 Adam、学习率 1e-3、batch size 64，以及 XGBoost 的 gbtree、1000 estimators、max depth 5 和若干正则与采样设置。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.10]
- **results：** 五折交叉验证中，xCAPT5 在 Martin、Guo、Pan 上分别达到 97.27%、99.76%、99.77% accuracy，并在多数指标上居首。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.11]；[doi:10.1186/s12859-024-05725-6, p.12]
- **results：** 在 generalized inference 中，xCAPT5 在多个 intra-species、cross-species 和 inter-species 测试集上通常取得最高 recall，且在部分病毒数据集上也拿到最好 precision 或 F1。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.14]；[doi:10.1186/s12859-024-05725-6, p.15]
- **results：** 在严格相似度测试中，xCAPT5 在不同阈值下保持约 99.70% 以上 accuracy 和约 99.5% 以上 F1，最低同源阈值下仍报告 99.73% accuracy、99.60% F1。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.15]；[doi:10.1186/s12859-024-05725-6, p.16]
- **results：** 作者还报告了统计检验，认为 xCAPT5 相对若干基线的 accuracy 差异在多组比较中具有显著性。
  - 证据：[doi:10.1186/s12859-024-05725-6, p.13]

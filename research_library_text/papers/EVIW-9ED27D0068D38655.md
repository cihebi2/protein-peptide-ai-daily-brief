# Prompt-to-Pill: Multi-Agent Drug Discovery and Clinical Simulation Pipeline

- **论文 ID：** `EVIW-9ED27D0068D38655`
- **期刊 / 来源：** Bioinform Adv
- **发表时间：** 2025 Dec 23
- **DOI：** [10.1093/bioadv/vbaf323](https://doi.org/10.1093/bioadv/vbaf323)
- **范围标签：** `Pi 已解析` / `背景资料` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 Prompt-to-Pill，一个由 Orchestrator 编排的多智能体框架，串联药物发现、preclinical 和 clinical 三阶段，并给出以 DPP4 为例的 proof-of-concept 代码实现。

## 创新边界

`创新点主要在多智能体流程编排、跨阶段连接和临床模拟扩展；它更像系统集成与工作流设计，而不是全新分子生成模型。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何把 LLM 驱动的药物发现从候选分子生成、对接、性质/ADMET 评估与优化，扩展到虚拟临床试验设计、患者匹配和结局预测，并把这些环节整合成一个可操作的端到端系统。

## 方法

- 多Agent阶段化编排，复用已有生成/DTI/ADMET/临床文本模块；以DrugBank、KIBA、BindingDB和DPP4示例展示流程。

## 数据与基准

- 对51个系统的分析与若干公开药物/相互作用数据；部分报告指标属于被集成组件而非同一端到端实验。

## 比较基线

- 单LLM组件、综述中的51个系统及DPP4示例。

## 结果证据

- 论文报告原型与单LLM基线的部分计算比较，但明确仍缺少agents、统一评价和多疾病/多靶验证；不应把组件指标归因为端到端临床效果。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 仅供受训专业人员做假设生成；透明性、评价一致性、复现性和适用域不足，临床模拟不是临床证据。

## 仍未知

- 完整 GitHub 仓库的可运行性与依赖项未在冻结页内核验。
- 端到端流程没有独立外部 benchmark；多数数值来自被引原文。
- 临床模块只是虚拟模拟，真实 EHR/临床试验环境未验证。
- DPP4 仅为单目标示例，跨靶点泛化尚未知。

## Pi 结构化证据摘录

- **baseline：** 作者回顾的先前 MAS，如 Gao et al., CLADD, PharmaSwarm, DrugMCTS 与 DrugAgent，主要集中在分子或 DTI 级推理，缺少临床试验模拟与 EHR/RWE 整合。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.1]；[doi:10.1093/bioadv/vbaf323, p.2]
- **baseline：** 论文把 Prompt-to-Pill 定位为对既有 preclinical baselines 的扩展，而不是替代单任务模型；其目标是把生成、对接、筛选、优化和临床模块串成一条链。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.2]；[doi:10.1093/bioadv/vbaf323, p.3]
- **baseline：** Table 2 列出的 component baselines 采用原文报告的指标值，例如 DrugGen、ChemFM、Panacea、MediTab 和 DrugAssist 的性能，不是本工作新得分。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.4]
- **data：** 综述抽取的元数据包含 bibliographic、technical、reproducibility 和 contextual 字段，并据此按阶段汇总研究。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.2]
- **data：** Table 2 中的 DrugGen、ChemFM、Panacea、MediTab、DrugAssist 指标来自原始论文，被用作组件选型依据，而不是本工作重新训练得到的结果。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.4]
- **data：** DPP4 演示使用 UniProt ID P27487；对接结构示例采用 PDB 2QT9，并在缺乏实验结构时回退到 AlphaFold 模型。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.4]；[doi:10.1093/bioadv/vbaf323, p.5]
- **data：** 临床阶段把 patient EHR descriptions 作为输入，输出 matched patient IDs、trial report fields，以及用于汇总的结构化试验信息。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.6]；[doi:10.1093/bioadv/vbaf323, p.7]
- **declared_resources：** 完整实现代码公开在 GitHub: https://github.com/ChatMED/Prompt-to-Pill。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.1]；[doi:10.1093/bioadv/vbaf323, p.8]
- **declared_resources：** 补充材料 Supplementary Table 1 提供本综述纳入论文清单和提取结果。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.8]
- **limitations：** 仍有多项灰色概念占位 agent 未完成集成，包括 Target Identification、Formulation and Dosage Development、FDA/EMA approval and documentation、Pharmacovigilance and Safety Monitoring。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.6]
- **limitations：** Orchestrator 目前使用 OpenAI o4-mini，且 trial-generation 结果不能替代专家驱动的临床试验设计。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.6]；[doi:10.1093/bioadv/vbaf323, p.7]
- **limitations：** 各组件受训练数据 applicability domain 约束，偏离分布的分子、试验结构或患者群体只能作 exploratory 解释。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.6]
- **limitations：** 作者只展示单目标 DPP4 案例，明确承认可行性已证实但 generalizability 尚未证实。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.6]；[doi:10.1093/bioadv/vbaf323, p.7]
- **method：** 研究遵循 PRISMA 流程做系统综述，经过检索、筛选、全文评估和数据抽取，整合了 2022–2025 年的 51 篇 LLM-based drug discovery 与 clinical 相关研究。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.2]
- **method：** 检索源覆盖 PubMed、ScienceDirect、Google Scholar 和 Springer Nature Link，检索式围绕 target identification、molecule generation、clinical trial design、RAG 与 patient recruitment 等主题展开。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.2]
- **method：** 实现层面使用 AutoGen 组织多智能体，并由 Orchestrator 与 Planning Agent 协调 DD、preclinical、clinical 三阶段工作流。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.3]
- **method：** DPP4 案例中，Drug-Generation、Docking、Chemical Properties、ADMET、Molecule Optimization、Trial Generation、Patient-Matching 与 Trial Outcome Prediction 分别由专门 agent 处理。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.4]；[doi:10.1093/bioadv/vbaf323, p.5]；[doi:10.1093/bioadv/vbaf323, p.6]
- **results：** 综述统计显示 2024 年最活跃，51 篇研究中 preclinical/DD 为 14 篇、clinical 为 8 篇，2025 年又上升到 17 篇。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.3]
- **results：** Table 1 显示 RAG 采用率仍低，preclinical/DD 仅 3 篇、clinical 为 6 篇，同时输出示例和代码链接并不普遍。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.3]
- **results：** 作者报告其 docking setup 在 Astex dataset 上 RMSD < 2 Å 的比例为 86.59%，平均 RMSD 为 1.16 Å。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.5]
- **results：** 图 4 展示了 DPP4 端到端输入输出示例，并明确 trial success probability 只是 MediTab 的预测值，不等于药效。
  - 证据：[doi:10.1093/bioadv/vbaf323, p.7]

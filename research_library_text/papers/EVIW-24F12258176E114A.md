# AbFlex: designing antibody complementarity determining regions with flexible CDR definition

- **论文 ID：** `EVIW-24F12258176E114A`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Mar 6
- **DOI：** [10.1093/bioinformatics/btae122](https://doi.org/10.1093/bioinformatics/btae122)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 AbFlex：一个基于 EGNN 的抗体 CDR 设计模型，结合 flexible CDR definition augmentation，同步预测 CDR 结构与氨基酸序列，并声称在结构准确率、AAR 和若干基准上达到 state-of-the-art。

## 创新边界

`主要新意在 flexible CDR augmentation 与 EGNN 共设计框架；论文没有提供独立 prior-art 证据来证明其全局首创，只能确认其在所给基准上的方法组合与效果。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在抗体-抗原复合物结构数据稀缺、且不同 antibody numbering scheme 会改变 CDR 边界的情况下，如何同时预测并设计 CDR 的结构与序列。

## 方法

- SAbDab复合物构图，随机扩张/收缩CDR边界产生增强样本，16层EGNN联合恢复序列和结构。

## 数据与基准

- SAbDab训练/测试及RAbD 60个complex评估。

## 比较基线

- MEAN、RefineGNN、Rosetta类CDR设计方法及固定CDR消融。

## 结果证据

- 论文报告SOTA结构/恢复率；>38%或文内后续设置>80%设计被计算估计结合能优于WT，未做实验。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 深EGNN有梯度消失；能量为计算估计，CDR数据少且编号增强可能引入偏差。

## 仍未知

- 是否能在更大、更多样的外部 antibody-antigen 数据集上保持同样的泛化性能。
- FoldX 与 Rosetta InterfaceAnalyzer 的排序结果与真实实验亲和力提升的一致性未知。
- GitHub 仓库中的实现细节、训练脚本和参数是否与论文完全一致，冻结证据无法独立核验。

## Pi 结构化证据摘录

- **baseline：** 文中比较对象包括 RosettaAD、LSTM、C-LSTM、RefineGNN、C-RefineGNN 和 MEAN，其中 MEAN 是最近的直接方法对照。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.6]
- **baseline：** 作者指出，先前工作通常只采用单一 CDR 定义（IMGT 或 Chothia），这会让模型对特定编号体系产生偏置。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.7]
- **data：** 最终训练集由 32,596 个 CDR-antigen pairs 组成，来源于 4,312 个 PDB 文件，并按 95:5 划分为 training/validation。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]
- **data：** 测试集使用 RAbD 的 60 个 PDB，并分别按 Chothia、IMGT 和 North et al. 三种 CDR 定义评估。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.5]
- **data：** 在严格对比设置中，作者重训时使用与测试集 CDR 序列相似度 <50% 的数据，得到 10,349 个 CDR-antigen pairs，其中 HCDR3 为 2,274 对。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.6]
- **declared_resources：** 作者在摘要页明确声明 source code and implementation 可在 GitHub 获取，且 job 元数据给出直接仓库地址。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.1]
- **declared_resources：** 数据来源包括 SAbDab 与 RAbD，评测中还用到 PyIgClassify server 来定义 North et al. CDR。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.5]
- **declared_resources：** 结构重建与松弛链路使用了 PyMOL、PDBFixer、OpenMM、FoldX 和 Rosetta InterfaceAnalyzer。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.7]
- **limitations：** AbFlex 只预测一个最优 CDR 结构，不能像部分生成模型那样输出多样化的结构集合。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.8]
- **limitations：** 训练时没有充分纳入 binding affinity，而且把不同抗体-抗原复合物按同等权重处理。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.8]
- **limitations：** 模型默认 CDR 的结构和序列变化不会显著改变其他 non-CDR 区域，这一假设可能过强。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.8]
- **limitations：** 作者也承认预测精度仍有提升空间，而 binding energy 结论本身来自计算打分函数的近似。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.7]；[doi:10.1093/bioinformatics/btae122, p.8]
- **method：** 从 SAbDab 收集抗体-抗原复合物，只保留 CDR 完整且 antigen 为 protein-type 的样本，并用 Chothia numbering 定义 CDR。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]
- **method：** 通过将 CDR 两端 anchor residue 在原位置 ±k 范围内移动来做数据增强，文中取 k=5，因此单个 CDR 可生成大量边界变体。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]
- **method：** AbFlex 以残基级图表示复合物，仅使用 Cα 坐标与 258 维 node feature，堆叠 16 层 EGNN，并在每层后用 masking 保持非 CDR 坐标不变。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.3]
- **method：** 训练目标同时包含 CDR 结构的 RMSD、repulsion、neighbor loss，以及 CDR/非 CDR 的 cross-entropy，并借助 local loss 缓解 16 层 EGNN 的梯度消失。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.4]；[doi:10.1093/bioinformatics/btae122, p.5]
- **method：** 完整抗体-抗原模型通过 PyMOL、PDBFixer 和 OpenMM 重建与松弛，再用 FoldX AnalyzeComplex 与 Rosetta InterfaceAnalyzer 估计 binding energy。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.2]；[doi:10.1093/bioinformatics/btae122, p.7]
- **results：** 在 RAbD 上，除 HCDR3 外多数 CDR 都达到亚埃级 RMSD 和约 54%–80% 的 Top1 AAR；IMGT 设定下 HCDR3 的 RMSD 为 1.568 Å、Top1 AAR 为 37.54%。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.5]；[doi:10.1093/bioinformatics/btae122, p.6]
- **results：** HCDR3 对比基线时，AbFlex 的 Top1 AAR 为 40.64%、RMSD 为 1.88 Å；作者报告其序列准确率优于 MEAN，而结构误差与 MEAN 接近。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.6]
- **results：** 消融结果表明，仅用 Chothia 数据训练时，模型在 IMGT 和 North 评测上的性能明显退化，说明 flexible CDR augmentation 提升了跨编号体系鲁棒性。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.7]
- **results：** 在 binding energy 分析中，设计序列相对 reconstructed native 的改进率最高可达 FoldX 38.5% 与 InterfaceAnalyzer 44.5%，成功率分别为 51/60 和 52/60。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.7]
- **results：** SARS-CoV-2 spike 的案例里，sample 6 的 InterfaceAnalyzer 分数为 -48.482，优于 native 的 -35.454 和 reconstructed native 的 -34.293。
  - 证据：[doi:10.1093/bioinformatics/btae122, p.8]

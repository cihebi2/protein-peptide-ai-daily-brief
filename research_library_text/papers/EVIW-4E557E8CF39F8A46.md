# Structure-based prediction of nucleic acid binding residues by merging deep learning- and template-based approaches

- **论文 ID：** `EVIW-4E557E8CF39F8A46`
- **期刊 / 来源：** PLoS Comput Biol
- **发表时间：** 2023 Sep 6
- **DOI：** [10.1371/journal.pcbi.1011428](https://doi.org/10.1371/journal.pcbi.1011428)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 NABind，把基于 EGAT 的深度学习模块、基于多模板的监督学习模块、stacking 融合器和 random walk 后处理串联起来，用于同时预测 DBR 和 RBR，并称其在 native 与 predicted structures 上优于既有混合方法和若干深度学习方法。

## 创新边界

`创新主要在模块化集成与特征/模板设计的组合，不在于提出全新的生物学任务或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在仅有蛋白结构或预测结构的前提下，准确识别 DNA 与 RNA 结合残基，以支持对转录、翻译相关蛋白功能位点的理解与后续分析。

## 方法

- 深度模块编码序列/结构描述和残基图，模板模块把多模板比对转为监督特征，最后随机游走平滑预测。

## 数据与基准

- DNA/RNA binding residue数据，按有/无高质量模板分组，并测试native与predicted structures。

## 比较基线

- GraphBind、DNABind、RBRDetector及模板/深度单模块。

## 结果证据

- 论文报告同时超过传统hybrid与近期DL方法，良好模板组收益更明显；为残基级计算预测。

## Pi 结构化证据摘录

- **baseline：** 作者将 DNABind 和 RBRDetector 作为自家历史混合基线，并与 NucBind、GraphBind、GraphSite、COACH-D、NCBRPred、SVMnuc、aaRNA、NucleicNet、PSTPRNA 等方法比较。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.2]；[doi:10.1371/journal.pcbi.1011428, p.8]；[doi:10.1371/journal.pcbi.1011428, p.11]
- **baseline：** 与 GraphBind/GraphSite 等近期深度学习方法相比，NABind 在测试集上仍取得更高 MCC 与 AUPR，尤其在 native structures 上优势更明显。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.8]；[doi:10.1371/journal.pcbi.1011428, p.11]
- **baseline：** 表 2 还显示在 predicted structures 上，部分 template-based 方法退化更明显，作者据此把 GraphSite、GraphBind 及传统 hybrid methods 作为关键比较对象。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.6]；[doi:10.1371/journal.pcbi.1011428, p.8]；[doi:10.1371/journal.pcbi.1011428, p.11]
- **data：** 训练集使用 DBR_573 和 RBR_495，测试集使用 DBR_129、DBR_181、RBR_117 和 RBR_106；所有条目来自 BioLiP，训练/测试间序列同一性均低于 30%。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.13]；[doi:10.1371/journal.pcbi.1011428, p.14]
- **data：** 论文还在 native structures 之外评估了 trRosetta 生成的预测结构；DBP 的 AlphaFold2 预测结构由 GraphSite 提供，RBP 的 AlphaFold2 预测结构来自 AlphaFold database。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.6]；[doi:10.1371/journal.pcbi.1011428, p.14]
- **data：** 作者按原子距离定义 binding residue：任一原子与核酸任一原子距离小于 0.5 Å 加上两原子 van der Waals 半径即判为结合残基，并用相似链注释转移做了训练集数据增强。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.14]
- **declared_resources：** Data Availability Statement 声明数据集、源代码和模型可从 GitHub 下载，并提供 NABind server。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.1]
- **declared_resources：** 训练依赖的外部资源包括 BioLiP、UniRef90、UniClust30、AlphaFold database、trRosetta、ESM-MSA-1b、ESMIF、PyTorch 和 DGL 等公开工具/数据库。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.14]；[doi:10.1371/journal.pcbi.1011428, p.17]；[doi:10.1371/journal.pcbi.1011428, p.18]
- **limitations：** 作者明确指出 template-based module 对 predicted structures 非常敏感，结构相似性下降会显著拉低性能，因此该分支的鲁棒性仍需加强。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.7]；[doi:10.1371/journal.pcbi.1011428, p.12]
- **limitations：** 论文也承认 DBR 与 RBR 的区分仍然困难，现有方法容易跨预测，NABind 虽然在 cross-prediction 中表现接近常规测试，但作者仍建议设计更具判别性的特征。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.12]
- **method：** 深度学习分支将蛋白表示为以残基为节点、接触为边的图，并用 EGAT 结合节点与边特征学习残基表征与结合概率。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.16]；[doi:10.1371/journal.pcbi.1011428, p.17]
- **method：** 节点特征同时包含 ESM-MSA-1b、PSSM、HHblits HMM、ESMIF 结构嵌入，以及 ORC/FRC/MFD、几何和距离类描述符。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.14]；[doi:10.1371/journal.pcbi.1011428, p.15]
- **method：** 模板分支从 BioLiP 的 ligand ID 为 NUC 的条目构建 DBP/RBP 模板库，筛选 TMscore >0.3、sequence identity <0.3 的模板，并以 RF/XGBoost/LightGBM 预测残基结合概率。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.17]
- **method：** 融合分支把 5 个深度学习模型和 3 个模板模型的输出作为输入，使用 LightGBM 做 stacked generalization；后处理分支在蛋白表面残基网络上执行 random walk with restart 修正概率。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.17]；[doi:10.1371/journal.pcbi.1011428, p.18]
- **results：** 在训练集 5-fold CV 中，融合模块通常优于单独 DL 或 TL；例如 DBR_573 的 MCC/AUC/AUPR 由 0.575/0.931/0.695 提升到 0.595/0.939/0.728，RBR_495 由 0.441/0.880/0.581 提升到 0.473/0.893/0.621。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.5]；[doi:10.1371/journal.pcbi.1011428, p.6]
- **results：** 在测试集上，NABind 在 DBR_129、DBR_181、RBR_117、RBR_106 的 protein-based 和 residue-based 评估里都取得最佳或并列最佳表现；例如 DBR_129 的 protein-based AUC/AUPR 达到 0.946/0.637，RBR_106 达到 0.884/0.542。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.8]；[doi:10.1371/journal.pcbi.1011428, p.11]；[doi:10.1371/journal.pcbi.1011428, p.12]
- **results：** 相较于 DNABind、RBRDetector，NABind 通过更强的特征、独立模板库、stacking 和 post-processing 获得系统性提升，作者称其在 native 与 predicted structures 上均更优。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.8]；[doi:10.1371/journal.pcbi.1011428, p.9]；[doi:10.1371/journal.pcbi.1011428, p.10]
- **results：** 案例分析中，NABind 在 7D7C_F 和 5Y58_B 上都以更少 false positives 取得更优 MCC/AUC/AUPR，说明后处理更偏向提高精度而非单纯增加召回。
  - 证据：[doi:10.1371/journal.pcbi.1011428, p.10]

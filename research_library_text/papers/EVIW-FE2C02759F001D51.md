## 作者主张的创新点

作者提出两级预测框架 ToxPre-2L，将 MLSI、AdaptMVTL 与带 low-rank 约束的 BR 融合起来，在同一套多视图表征下同时完成 TXP 二分类与多标签功能类型预测，并声明公开 webserver 及数据/代码访问入口。

## 创新边界

`作者声称其创新点在于首次将 MVTL 用于 TXP 及其多功能类型预测；论文边界主要是监督式计算预测与表征学习，不涉及候选肽生成、湿实验验证或蛋白设计优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在仅依赖序列/多视图特征的条件下，准确区分毒性肽（TXP）与非毒性肽，并进一步识别 TXP 的多功能亚型（如 ABP、ACP、AMP、AFP、CPP、APP、DDV、AVP）.

## 方法

- 多类序列/PLM/理化视图构成tensor，第一级二分类toxicity，第二级多标签功能预测。

## 数据与基准

- 作者更新的toxicity peptide benchmark。

## 比较基线

- 现有toxicity peptide预测器和不同单视图/特征模型。

## 结果证据

- 论文报告比既有模型更准确；全部为计算标签预测。

## Pi 结构化证据摘录

- **baseline：** 第一层基线方法包括 ToxinPred2、ToxDL 和 ToxIBTL，用于比较 TXP 与 Non-TXP 的单标签分类性能。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.6]
- **baseline：** 第二层多标签基线包括 MIML-KNN、MIML-RBF、ML-KNN、RankSVM、LIFT、ETFC、IMFP、TPpred-LE 和 TPpred-SC。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.7]
- **baseline：** 特征/降维对照方法包括 PCA、MDDM 和 MDS，用于检验 MLSI 的稳定性与有效性。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.7]；[doi:10.1093/bioinformatics/btaf489, p.8]
- **data：** 训练与测试均基于作者自建 benchmark dataset；第一层使用平衡的 TXP/Non-TXP 数据，第二层只在 TXP 子集上做九类多标签学习。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]
- **data：** 论文明确声明 source code 和 data 可通过 http://bliulab.net/ToxPre-2L 访问，同时给出基金资助信息。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.1]；[doi:10.1093/bioinformatics/btaf489, p.10]
- **declared_resources：** 作者声明提供公开 webserver、source code 和 data 入口，资源地址为 http://bliulab.net/ToxPre-2L 。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.1]；[doi:10.1093/bioinformatics/btaf489, p.10]
- **declared_resources：** 论文声明获得 Beijing Natural Science Foundation、National Natural Science Foundation of China 与 Zhongguancun Academy 的资助。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.10]
- **limitations：** 论文的验证主要停留在作者自建 benchmark dataset 与 10-fold cross-validation，冻结证据中未见独立外部队列或湿实验验证。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]；[doi:10.1093/bioinformatics/btaf489, p.6]；[doi:10.1093/bioinformatics/btaf489, p.7]；[doi:10.1093/bioinformatics/btaf489, p.8]；[doi:10.1093/bioinformatics/btaf489, p.9]
- **limitations：** 方法仍依赖四种预设特征编码与 λ1/λ2/λ3 的网格搜索调参，说明其性能对人工特征设计与超参数选择仍有依赖。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]；[doi:10.1093/bioinformatics/btaf489, p.8]；[doi:10.1093/bioinformatics/btaf489, p.9]
- **method：** 构建第一层与第二层基准数据集：第一层包含 2345 条实验验证 TXP 和 2345 条 Non-TXP；Non-TXP 来自 Swiss-Prot，经毒性关键词、非标准残基、重复序列和 >90% 同源过滤后得到，并将 TXP 进一步划分为 9 个功能类别。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]
- **method：** 使用四种特征编码方法 k-mer、DR、DP 和 Pse-AAC 表示肽序列，并通过 Bioseq-Analysis 2.0 提取特征；随后用 MLSI 与 RBF kernel 选择各视图的潜在语义子空间。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]；[doi:10.1093/bioinformatics/btaf489, p.4]
- **method：** 第一层 AdaptMVTL 通过多视图投影、tensor nuclear norm 与自适应视图权重学习共享潜空间，并输出 TXP/Non-TXP 二分类结果。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.4]；[doi:10.1093/bioinformatics/btaf489, p.5]
- **method：** 第二层 MLMVTLowRankBin 将 BR、least-squared hinge surrogate 和 low-rank 约束结合，用于在 TXP 内部预测多标签功能类型并建模标签相关性。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.5]
- **method：** 评估采用 10-fold cross-validation；第一层报告 ACC、SN、SP、MCC、AUC，第二层报告 HL、AP、CV、ACC 等指标。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.3]；[doi:10.1093/bioinformatics/btaf489, p.6]
- **results：** 在第一层 TXP/Non-TXP 任务上，ToxPre-2L 相比 ToxinPred2、ToxDL、ToxIBTL 表现更好，作者报告 AUC 和 ACC 提升 11.33%–22.65%，MCC 和 F1 提升 0.11–0.58。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.6]
- **results：** 在第二层多标签任务上，ToxPre-2L 于 Table 1 中取得最佳结果：ACC 0.86、HL 0.06、AP 0.94、CV 1.65。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.7]
- **results：** 作者比较不同降维/特征选择方法后认为 MLSI 在维度设为 10 时最优，并且比 PCA、MDDM、MDS 更稳定。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.7]；[doi:10.1093/bioinformatics/btaf489, p.8]
- **results：** t-SNE 可视化显示 latent features 能较清楚地区分 TXP 与 Non-TXP；运行时间上，ToxPre-2L 在 dataset S 上为 1.15 s，在 S_TXP 上为 0.02 s。
  - 证据：[doi:10.1093/bioinformatics/btaf489, p.8]；[doi:10.1093/bioinformatics/btaf489, p.9]

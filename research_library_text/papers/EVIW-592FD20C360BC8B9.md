# An artificial intelligence accelerated virtual screening platform for drug discovery

- **论文 ID：** `EVIW-592FD20C360BC8B9`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Sep 5
- **DOI：** [10.1038/s41467-024-52061-7](https://doi.org/10.1038/s41467-024-52061-7)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出 RosettaGenFF-VS、RosettaVS 与 OpenVS：一套结合物理力场、熵校正、受体柔性和 active learning 的开放式超大库虚拟筛选平台，并在 KLHDC2 与 NaV1.7 上获得单数 μM 命中。[doi:10.1038/s41467-024-52061-7, p.1]

## 创新边界

`新意主要在方法集成、力场修正与大规模实证筛选，不是通用 AI 生成模型本身。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在超大规模化学库中同时保证 docking 速度、pose 准确性和排序能力，并把筛选结果推进到可实验验证的 hit discovery。

## 方法

- 以 Rosetta 物理建模生成/优化复合物姿势，用深度学习筛选和亲和力评分构成分层虚拟筛选流程，再以少量候选实验测试。[doi:10.1038/s41467-024-52061-7, p.1][doi:10.1038/s41467-024-52061-7, p.2]

## 数据与基准

- 在多组姿势、亲和力和早期富集基准上评估，并用于 Enamine REAL/ZINC22 等超大库及 KLHDC2 靶点案例。[doi:10.1038/s41467-024-52061-7, p.2][doi:10.1038/s41467-024-52061-7, p.12]

## 比较基线

- 与 Glide 等对接/评分方法及不同受体柔性处理策略比较，重点看 ROC-AUC 和早期富集。[doi:10.1038/s41467-024-52061-7, p.2][doi:10.1038/s41467-024-52061-7, p.3]

## 结果证据

- 论文报告在多项基准优于所比较方法，并以高分辨率 X 射线结构验证一个 KLHDC2 配体的预测结合姿势；其余大规模筛选分数仍是计算预测。[doi:10.1038/s41467-024-52061-7, p.1]

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 可实验测试的候选仅为几十到数百个，早期富集对实际收益至关重要；Rosetta 许可为非商业科研，平台泛化仍受靶点构象覆盖约束。[doi:10.1038/s41467-024-52061-7, p.3][doi:10.1038/s41467-024-52061-7, p.12]

## 仍未知

- OpenVS 与 Rosetta 的仓库实现细节未在本次审查中逐行核验
- 论文中列出的命中与结构公开情况未做外部可复现性检查
- 与全部近期 docking/AI screening 方法的优先权关系未做独立 prior-art 复核

## Pi 结构化证据摘录

- **baseline：** 作者把 RosettaGenFF-VS 与其他 physics-based scoring functions 对比，也补充了部分 deep-learning scoring functions 的结果。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.8]；[doi:10.1038/s41467-024-52061-7, p.9]
- **baseline：** 在 DUD 评估中，RosettaVS 与常见 docking/virtual screening baselines 一并比较，论文强调其优于对照方法。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.2]；[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.13]
- **baseline：** 正文明确提到 Glide、GOLD 和 AutoDock Vina 等主流工具，作为该工作所要超越的基线参照。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.2]；[doi:10.1038/s41467-024-52061-7, p.13]
- **data：** 基准数据集使用 CASF2016 的 285 个蛋白-配体复合物，以及 DUD 的 40 个靶点和超过 100,000 个小分子。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.8]；[doi:10.1038/s41467-024-52061-7, p.13]
- **data：** 超大库筛选分别使用 Enamine REAL 2022-q1 约 5.5 billion SMILES 和 ZINC22 约 4.1 billion ready-to-dock molecules。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.4]；[doi:10.1038/s41467-024-52061-7, p.9]
- **data：** KLHDC2 受体来自 PDB 6DO3，NaV1.7 受体来自 PDB 5EK0，后者保留了 VSD4 区域作为筛选口袋。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.9]；[doi:10.1038/s41467-024-52061-7, p.10]
- **data：** 实验化合物由 Enamine 合成并做 LC-MS 纯度确认，结构与原始源数据也在论文附录或 PDB 中公开。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.11]；[doi:10.1038/s41467-024-52061-7, p.12]；[doi:10.1038/s41467-024-52061-7, p.14]
- **declared_resources：** 筛选在本地 HPC cluster 上完成，配置约 3000 CPUs 与每个靶点 1 块 RTX2080 GPU，单个靶点全流程少于 7 天。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.2]；[doi:10.1038/s41467-024-52061-7, p.4]
- **declared_resources：** 作者声明 RosettaVS 随 Rosetta 软件公开，OpenVS code 和 scripts 可在 Zenodo 与 GitHub 获取。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.12]；[doi:10.1038/s41467-024-52061-7, p.14]
- **declared_resources：** 论文还公开了 druglike-centroid library、KLHDC2-C29 结构条目 8UXS，以及部分源数据和补充数据。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.9]；[doi:10.1038/s41467-024-52061-7, p.12]；[doi:10.1038/s41467-024-52061-7, p.14]
- **limitations：** 作者承认后续仍可通过 GPU 加速、生成式 AI pose generation、改进 surrogate active learning 模型和更通用的深度学习打分函数继续提升。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.6]
- **limitations：** KLHDC2 与 NaV1.7 的命中目前仍以微摩尔级为主，作者明确写到后续需要继续优化到 nanomolar 范围。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.4]
- **limitations：** 筛选中大量化合物因 buried unsatisfied H-bonds 或 torsion outliers 被剔除，作者认为这说明当前能量模型可能仍有 under-penalized 构象。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.10]
- **method：** 作者在 Rosetta GALigandDock 基础上扩展出 RosettaGenFF-VS，并加入熵项来对同一靶点的不同配体进行排序。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.6]；[doi:10.1038/s41467-024-52061-7, p.8]
- **method：** RosettaVS 提供 VSX 与 VSH 两种模式：VSX 用于快速初筛，VSH 允许口袋侧链柔性并做更精细的重打分。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.8]
- **method：** OpenVS 采用 active learning 与 fingerprint-based FFN 迭代挑选分子，再把高分和随机分子送回对接流程继续训练。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.9]；[doi:10.1038/s41467-024-52061-7, p.10]
- **method：** KLHDC2 与 NaV1.7 两条筛选线都先做受体预处理与 FastRelax，再分别用 Enamine REAL 或 ZINC22 进入超大库筛选。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.9]；[doi:10.1038/s41467-024-52061-7, p.10]
- **method：** 实验验证包括 AlphaLISA、BioLayer Interferometry、X-ray crystallography，以及 NaV1.7/NaV1.5/hERG 的 whole-cell patch clamp。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.11]；[doi:10.1038/s41467-024-52061-7, p.12]
- **results：** RosettaGenFF-VS 在 CASF2016 上取得领先 docking power，screening power 的 EF1% 达到 16.72。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.8]；[doi:10.1038/s41467-024-52061-7, p.9]
- **results：** RosettaVS 在 DUD 上的 AUC 与 ROC enrichment 处于领先，且 VSH 通常略优于 VSX。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.3]；[doi:10.1038/s41467-024-52061-7, p.8]；[doi:10.1038/s41467-024-52061-7, p.9]
- **results：** KLHDC2 首轮得到 C29，AlphaLISA IC50 约 3 μM，BLI 进一步确认；后续 focused library 又得到 6 个额外命中。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.4]；[doi:10.1038/s41467-024-52061-7, p.5]；[doi:10.1038/s41467-024-52061-7, p.11]
- **results：** KLHDC2-C29 的 2.0 Å X-ray 结构与对接姿势高度一致，支持该平台给出的结合模式。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.4]；[doi:10.1038/s41467-024-52061-7, p.5]；[doi:10.1038/s41467-024-52061-7, p.11]
- **results：** NaV1.7 方向获得 4 个单数 μM 命中，最佳化合物 Z8739902234 的 IC50 为 1.33 μM，并表现出状态依赖性。
  - 证据：[doi:10.1038/s41467-024-52061-7, p.4]；[doi:10.1038/s41467-024-52061-7, p.7]；[doi:10.1038/s41467-024-52061-7, p.12]

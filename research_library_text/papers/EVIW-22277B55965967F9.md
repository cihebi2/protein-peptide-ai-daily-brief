# Integrating Pharmacogenomics and Network Topology for Machine Learning Prediction of HLA-Associated Severe Cutaneous Adverse Drug Reactions

- **论文 ID：** `EVIW-22277B55965967F9`
- **期刊 / 来源：** Int J Mol Sci

## 作者主张的创新点

作者声称提出了一个把 HLA 序列特征、drug chemical descriptors、DDI/DSI 网络拓扑和 cohort ethnicity 融合到 XGBoost 中的整合框架，用于预测 HLA-associated SCAR 风险，并用分子对接对若干预测阳性对做结构层面的支持。

## 创新边界

`新意主要在多模态特征整合、网络拓扑引入和任务设置，不在全新预测算法本身。`。这不是全球首创性检索或独立复现结论。

## 研究问题

针对 HLA 相关 severe cutaneous adverse drug reactions（SCARs，尤其是 SJS/TEN）建立可前瞻预测的 drug–allele 风险模型，弥补现有工作多为回顾性、局部已知关联标注、难以发现未见风险对的不足。

## Pi 结构化证据摘录

- **baseline：** 仅用 HLA + drug structure + ethnicity 的 baseline 已达到 AUROC 0.88853 ± 0.03828、AUPRC 0.68953 ± 0.08753，说明大部分信号来自遗传与化学特征。
  - 证据：[doi:10.3390/ijms27104187, p.6]
- **baseline：** 作者将结果与既有 ADR 预测工作做任务层面对照，并声称本框架在 HLA-SCAR 场景下具有竞争性，但该比较并非同任务同数据集的严格 head-to-head。
  - 证据：[doi:10.3390/ijms27104187, p.15]
- **baseline：** 在特征消融中，DSI 比 DDI 略更有信息量，但两者都只带来很小的提升，未改变 baseline 已较强这一总体格局。
  - 证据：[doi:10.3390/ijms27104187, p.6]；[doi:10.3390/ijms27104187, p.14]
- **data：** 最终数据集包含 825 个实例、116 个 HLA 等位基因、15 种药物、4 个 ethnicity 类别和 361 列特征；类别分布为 653 个 non-SCAR-associated 与 172 个 SCAR-associated。
  - 证据：[doi:10.3390/ijms27104187, p.5]；[doi:10.3390/ijms27104187, p.6]
- **data：** 标签由 AFND 中 hypersensitive cases 与 drug-exposed controls 的 Fisher 精确检验构建，p≤0.05 记为正例，p>0.05 或对照更高记为负例；作者也明确承认负类可能混入未标注正例。
  - 证据：[doi:10.3390/ijms27104187, p.17]；[doi:10.3390/ijms27104187, p.18]
- **data：** HLA 特征聚焦 class I 的 α1–α2 peptide-binding domains，并采用参考结构 1A1N 辅助；ethnicity 直接沿用 AFND 分类并做 one-hot 编码。
  - 证据：[doi:10.3390/ijms27104187, p.18]；[doi:10.3390/ijms27104187, p.17]
- **declared_resources：** Funding 来自 National Science, Research and Innovation Fund（NSRF）与 King Mongkut’s University of Technology North Bangkok，项目号 KMUTNB-FF-68-B-21。
  - 证据：[doi:10.3390/ijms27104187, p.22]
- **declared_resources：** 数据源声明为 AFND 与 IPD-IMGT/HLA；处理后的数据和特征集可向通讯作者按合理请求获取。
  - 证据：[doi:10.3390/ijms27104187, p.22]
- **declared_resources：** 作者声明写作过程中使用了 ChatGPT GPT-4o 进行语言编辑与润色，且已人工审核。
  - 证据：[doi:10.3390/ijms27104187, p.22]
- **declared_resources：** 实现中引用了 XGBoost、Optuna、NetworkX、Scikit-learn、MAFFT 与 SwissDock/AutoDock Vina 等现成工具链。
  - 证据：[doi:10.3390/ijms27104187, p.9]；[doi:10.3390/ijms27104187, p.17]；[doi:10.3390/ijms27104187, p.19]；[doi:10.3390/ijms27104187, p.20]；[doi:10.3390/ijms27104187, p.11]
- **limitations：** 样本量受限且族群分布偏向特定人群，作者自己也指出这会限制外部泛化能力。
  - 证据：[doi:10.3390/ijms27104187, p.16]；[doi:10.3390/ijms27104187, p.21]
- **limitations：** 以 degree/eigenvector centrality 表示网络拓扑较粗糙，作者认为 graph embeddings 之类更表达式的表示可能更合适。
  - 证据：[doi:10.3390/ijms27104187, p.16]；[doi:10.3390/ijms27104187, p.21]
- **limitations：** SMOTE 可能生成生物学上不合理样本，Fisher 标签也可能复现已有统计关联而非真正发现新机制。
  - 证据：[doi:10.3390/ijms27104187, p.16]；[doi:10.3390/ijms27104187, p.20]
- **limitations：** 分子对接只能提供静态、间接的结构支持，无法覆盖 peptide processing、TCR 识别和微环境等免疫关键环节。
  - 证据：[doi:10.3390/ijms27104187, p.13]；[doi:10.3390/ijms27104187, p.16]；[doi:10.3390/ijms27104187, p.21]
- **method：** 研究从 AFND、IPD-IMGT/HLA、PubChem/DrugBank、DDInter 和 T-ARDIS 汇集数据，并用 MAFFT 对 HLA class I 的 α1/α2 区域对齐后，结合 Morgan fingerprints、one-hot 编码与网络中心性特征构建统一输入。
  - 证据：[doi:10.3390/ijms27104187, p.17]；[doi:10.3390/ijms27104187, p.18]；[doi:10.3390/ijms27104187, p.19]
- **method：** 分类器采用 XGBoost v3.2.0，使用 Optuna 进行 25 次超参数搜索，并在分层 nested 5-fold cross-validation 中评估；SMOTE 仅作用于训练折以避免数据泄漏。
  - 证据：[doi:10.3390/ijms27104187, p.9]；[doi:10.3390/ijms27104187, p.10]；[doi:10.3390/ijms27104187, p.20]
- **method：** 为给预测结果提供结构支持，作者用 SwissDock（Attracting Cavities + AutoDock Vina）对 carbamazepine 与 HLA-B*15:02、HLA-B*15:11、HLA-C*44:03 进行了分子对接比较。
  - 证据：[doi:10.3390/ijms27104187, p.11]；[doi:10.3390/ijms27104187, p.12]；[doi:10.3390/ijms27104187, p.13]
- **results：** 最终模型在重复 nested CV 中达到 accuracy 0.860 ± 0.005、F1 0.689 ± 0.010、AUROC 0.922 ± 0.003 和 AUPRC 0.768 ± 0.007；Youden 阈值 0.1505 时 F1 升至 0.735。
  - 证据：[doi:10.3390/ijms27104187, p.10]
- **results：** 加入 DSI/DDI 只带来很小的性能变化：baseline AUROC 0.88853 → 0.88989，AUPRC 0.68953 → 0.69185，说明网络特征提供的是有限但互补的增益。
  - 证据：[doi:10.3390/ijms27104187, p.6]；[doi:10.3390/ijms27104187, p.7]；[doi:10.3390/ijms27104187, p.14]
- **results：** 作者强调 carbamazepine–HLA-B*15:11 是训练外预测阳性且有独立临床报告支持；对接结果显示其与 HLA-B*15:02 呈相近的免疫相关结合模式，而 HLA-C*44:03 更不符合该模式。
  - 证据：[doi:10.3390/ijms27104187, p.11]；[doi:10.3390/ijms27104187, p.12]；[doi:10.3390/ijms27104187, p.13]；[doi:10.3390/ijms27104187, p.15]

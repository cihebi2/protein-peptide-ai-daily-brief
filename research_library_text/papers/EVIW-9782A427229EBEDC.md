# DLM-DTI: a dual language model for the prediction of drug-target interaction with hint-based learning

- **论文 ID：** `EVIW-9782A427229EBEDC`
- **期刊 / 来源：** J Cheminform
- **发表时间：** 2024 Feb 1
- **DOI：** [10.1186/s13321-024-00808-1](https://doi.org/10.1186/s13321-024-00808-1)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文提出 DLM-DTI：用 ChemBERTa 编码药物、用 ProtBERT 的 teacher-student 结构为蛋白序列做 hint-based knowledge adaptation，并在 BIOSNAP、DAVIS、Binding DB 上声称同时提升准确性与训练效率。

## 创新边界

`新意主要在轻量化 target encoder 与 hint-based adaptation 的组合；它不是新数据集、不是 wet-lab 发现，也没有证明全局最优，只是对现有预训练语言模型方案做了任务化裁剪与融合。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在给定药物 SMILES 与蛋白质氨基酸序列时，预测二元 drug-target interaction (DTI) 是否发生，并尽量降低蛋白编码器的计算与显存开销。

## 方法

- 分子和蛋白分别由语言模型编码；适配参数融合通用与目标知识，hint损失指导轻量学生表示，再进行DTI分类。

## 数据与基准

- 在BIOSNAP、DAVIS和BindingDB三个基准上训练与评价。

## 比较基线

- DeepDTA、MolTrans及更大结构/语言编码DTI模型。

## 结果证据

- 论文报告性能和学习效率提升，训练显存7.7GB，为先前SOTA的16.24%；属于计算相互作用分类。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- Transformer计算随输入长度二次增长；相互作用标签与负样本构造可能造成数据偏差。

## 仍未知

- GitHub 源码与论文描述是否完全一致尚未外部核验。
- integrated training 的收益是否可推广到其他 DTI 数据集仍不确定。
- cold-split 退化的主要原因是 student 压缩还是 interaction head 设计，论文未彻底排除。

## Pi 结构化证据摘录

- **baseline：** 论文把 MolTrans 作为基础 baseline，并把 Kang et al. 视为前一代强基线/近似 state-of-the-art，对比其单数据集与 integrated 数据集两种训练设置。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.6]；[doi:10.1186/s13321-024-00808-1, p.7]
- **baseline：** 作者明确说明 MolTrans 只在单个数据集上训练与评测，而 Kang et al. 和 DLM-DTI 都使用了单数据集与 integrated dataset 两种设定。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.6]；[doi:10.1186/s13321-024-00808-1, p.7]
- **data：** 论文评测三个公开基准：DAVIS（68 drugs、379 proteins、11,103 interactions）、Binding DB（10,665 drugs、1,413 proteins、32,601 interactions）和 BIOSNAP（4,510 drugs、2,181 proteins、27,482 interactions）。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.3]
- **data：** 作者沿用 7:1:2 的 train/validation/test 划分，并额外采用 integrated training，把多个数据集的训练与验证部分合并后再测试单个测试集。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.3]
- **data：** cold-splitting 评测只在 Binding DB 上做，包含 2,127 个 cold drugs、136 个 cold targets 和 114 个 cold binding pairs。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.8]
- **declared_resources：** 实验声明使用单张 NVIDIA A100 GPU，软件环境为 Python 3.8 和 PyTorch 1.13。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.6]
- **declared_resources：** 论文末尾声明 datasets 可从 MolTrans 的 GitHub 路径获取，source code 也提供了 GitHub 仓库链接。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.11]
- **limitations：** 作者承认 DLM-DTI 在 DAVIS 和 cold-splitting，特别是 cold binding 场景下泛化不足。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.8]；[doi:10.1186/s13321-024-00808-1, p.9]
- **limitations：** 论文认为 student model 可能被压缩得过度，限制了 generalization performance。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.9]
- **limitations：** 作者提出未来可尝试 LoRA 和更强的 interaction head，例如 squeeze-and-excitation、capsule network 或 cross-attention。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.9]；[doi:10.1186/s13321-024-00808-1, p.10]
- **method：** 药物侧使用 ChemBERTa 编码 Canonical SMILES，并取最后一层 hidden state 的 CLS 向量经投影后作为 drug 表征。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.4]；[doi:10.1186/s13321-024-00808-1, p.10]
- **method：** 蛋白侧采用 ProtBERT teacher 和 2-layer student 共同编码序列，利用可学习的 adaptation parameter 混合 teacher 的 general knowledge 与 student 的 task-specific knowledge。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.5]；[doi:10.1186/s13321-024-00808-1, p.11]
- **method：** teacher 模型冻结并可缓存输出，student 参数在训练中更新；作者将 teacher CLS 视为 hint，再与 student CLS 通过 class token mixing 融合。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.5]
- **method：** 交互预测头将 drug 与 target 表征拼接后，经过 3 个 FC block（2048、1024、512）、GeLU 和 dropout，再输出 binding probability。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.5]；[doi:10.1186/s13321-024-00808-1, p.6]
- **method：** 训练使用 AdamW、学习率 0.0001、cosine annealing、binary cross-entropy、50 epochs，并以验证集 AUPRC 选取最佳参数。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.6]
- **results：** 在 BIOSNAP 上，DLM-DTI 的 AUPRC 为 0.914 左右，优于 MolTrans 的 0.901，也优于 Kang et al. 的 0.897～0.900；在 Binding DB 上，DLM-DTI 的 AUPRC 为 0.643/0.636，高于 MolTrans 的 0.622 和 Kang et al. 的 0.623/0.639。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.7]
- **results：** 在 DAVIS 上，DLM-DTI 的表现反而下降，AUPRC 只有 0.373/0.406，明显低于 Kang et al. 的 integrated setting 0.517。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.7]
- **results：** 消融实验显示 adaptation 版本最好：Binding DB 上 AUROC/AUPRC 为 0.912/0.643，优于 teacher-only 的 0.911/0.635 和 student-only 的 0.900/0.612。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.7]
- **results：** 资源开销方面，DLM-DTI 只有 86.7M 参数、7.7 GB VRAM、63.00 s/epoch，而 Kang et al. 为 353.0M 参数、47.4 GB VRAM、631.00 s/epoch。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.8]
- **results：** cold-split 下 DLM-DTI 明显变弱，尤其是 cold binding（AUROC/AUPRC 0.622/0.261），作者也指出其泛化弱于常规测试。
  - 证据：[doi:10.1186/s13321-024-00808-1, p.8]；[doi:10.1186/s13321-024-00808-1, p.9]

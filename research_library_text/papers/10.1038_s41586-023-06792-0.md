# Autonomous chemical research with large language models

- **DOI：** [10.1038/s41586-023-06792-0](https://doi.org/10.1038/s41586-023-06792-0)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

能否构建由GPT-4驱动的AI系统，自主设计、规划并实际执行复杂化学实验（包括云端实验室与液体处理器），同时保持决策可解释。

## 作者主张的贡献

开发Coscientist：基于GPT-4的多模块智能体（Planner + GOOGLE/PYTHON/DOCUMENTATION/EXPERIMENT四个命令的动作空间 + Web searcher/Docs searcher/代码执行/机器人API工具），在六类任务上展示自主实验能力，包括成功完成钯催化交叉偶联（Suzuki/Sonogashira）的反应优化闭环。

## 创新边界

LLM+工具的agent范式与同期ChemCrow等并行工作重叠；自动化学优化（贝叶斯/流程系统）早已存在，本文新意在于用LLM Planner统一规划与低层硬件控制并给出可解释决策记录；'自主科学发现'的宣称限定在反应条件优化级别，非新化学知识发现。

## 创新点证据卡

- **[p1]** 构建GPT-4驱动的多模块agent，首次端到端自主设计并物理执行钯催化偶联反应优化
  - 原文："an artificial intelligence system driven by GPT-4 that autonomously designs, plans and performs complex experiments"
- **[p1]** 用四命令动作空间（GOOGLE/PYTHON/DOCUMENTATION/EXPERIMENT）模块化定义Planner的行动空间
  - 原文："engineered in a modular fashion, described as four commands that define the action space: 'GOOGLE', 'PYTHON', 'DOCUMENTATION' and 'EXPERIMENT'"
- **[p3]** 通过ada嵌入+向量检索让GPT-4自学未见过的机器人API文档（OT-2与ECL SLL）
  - 原文："all sections of the OT-2 API documentation were embedded using OpenAI's ada model... documentation sections are selected through a distance-based vector search"
- **[p3]** 实证web搜索grounding显著降低合成规划幻觉，GPT-4无搜索时会给出化学上不合理的路线
  - 原文："The GPT-4-powered Web Searcher significantly improves on synthesis planning... importance of grounding LLMs to avoid 'hallucinations'"
- **[p6]** Coscientist的试剂选择与大规模历史数据统计一致，且能给出可解释的选择理由
  - 原文："Coscientist's abilities to tackle real-world experimental campaigns involving thousands of examples"

## 方法

- Planner为GPT-4 chat实例，动作空间为GOOGLE/PYTHON/DOCUMENTATION/EXPERIMENT四命令
- Docs searcher用OpenAI ada嵌入+向量检索定位OT-2/ECL SLL文档片段
- 支持Opentrons OT-2液体处理器低层控制与Emerald Cloud Lab(ECL)符号实验语言SLL
- Web搜索 grounding 避免幻觉；用RDKit+代码执行做化学计算

## 数据与基准

- 七个化合物合成规划基准（acetaminophen/aspirin/ibuprofen等，与多个LLM对比打分）
- Historic Reactions数据集子集（D-A/Michael/酯化/Buchwald-Hartwig/Heck反应）用于试剂选择评估
- ECL样本目录1110个样品

## 结果证据

- GPT-4+Web Search在4/7个化合物合成规划上满分，GPT-4无搜索时会产生不化学合理的路线
- prompt-to-SLL：生成的HPLC实验SLL代码在云端实验室成功执行
- Suzuki反应试剂选择与大数据集统计一致（如芳基碘化物优先），两轮内完成优化，产物经GC-MS验证
- 多硬件模块（heater-shaker+UV-Vis读板）联合任务成功

# S 2 ALM: Sequence-Structure Pre-trained Large Language Model for Comprehensive Antibody Representation Learning

- **论文 ID：** `EVIW-81BCF02102E54A0C`
- **期刊 / 来源：** Research (Wash D C)
- **发表时间：** 2025 Aug 19
- **DOI：** [10.34133/research.0721](https://doi.org/10.34133/research.0721)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 S2ALM，一个基于 ESM-2 的 650M 参数抗体语言模型，采用两阶段层级预训练，并引入 sequence-structure matching 与 cross-level reconstruction 两个自定义目标，声称首次以混合方式把抗体序列与结构联合建模，且在多项抗体任务上达到新 SOTA。[doi:10.34133/research.0721, p.1][doi:10.34133/research.0721, p.3][doi:10.34133/research.0721, p.10]

## 创新边界

`作者的创新边界是“首个”在大规模抗体预训练中联合 1D 序列与 3D 结构；冻结证据仅支持这一作者自述，未独立验证其全球首创性。[doi:10.34133/research.0721, p.3][doi:10.34133/research.0721, p.10]`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在抗体基础模型预训练中同时吸收1D序列与3D结构信息，从而形成可迁移到抗体功能理解、位点识别、亲和力预测与CDR生成的综合表征。[doi:10.34133/research.0721, p.1][doi:10.34133/research.0721, p.3]

## 方法

- 第一阶段学习一般蛋白序列/结构，第二阶段面向抗体多层级目标继续预训练，再用于理解和生成任务。

## 数据与基准

- 7500万条1D序列和1170万条3D结构，来自蛋白和抗体域。

## 比较基线

- 抗体PLM、通用蛋白PLM及序列-only/结构-aware模型。

## 结果证据

- 论文报告在多项抗体理解与生成任务达到SOTA；均为计算基准，未证明生成抗体实验功能。

## Pi 结构化证据摘录

- **baseline：** 对照模型覆盖通用蛋白模型与抗体专用模型，包括 ESM-1b、MSA-1b、ESM-2、AbLang-H/L、AntiBERTa、EATLM、SaProt、AntiBERTa2、A2binder、ProtBERT、AntiBERTy、BALM、Vanilla BERT、Ens-Grad、AbMAP、ReprogBERT 与 Sapiens-H 等。[doi:10.34133/research.0721, p.6][doi:10.34133/research.0721, p.7][doi:10.34133/research.0721, p.8][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.6]；[doi:10.34133/research.0721, p.7]；[doi:10.34133/research.0721, p.8]；[doi:10.34133/research.0721, p.9]
- **baseline：** 作者用 ESM-2 作为通用蛋白表示参照，以对照抗体专用模型，强调仅有序列预训练不足以覆盖抗体结构信息。[doi:10.34133/research.0721, p.3][doi:10.34133/research.0721, p.6][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.3]；[doi:10.34133/research.0721, p.6]；[doi:10.34133/research.0721, p.9]
- **baseline：** 生成任务还把 ProtBERT、AbLang-H、ReprogBERT 与 ProGen2 纳入比较，并用 AlphaFold3 对生成结果做结构层面的再评估。[doi:10.34133/research.0721, p.8][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.8]；[doi:10.34133/research.0721, p.9]
- **data：** 预训练总规模为 75 million 1D sequences 与 11.7 million 3D structures，覆盖 protein 与 antibody 两个域。[doi:10.34133/research.0721, p.10]
  - 证据：[doi:10.34133/research.0721, p.10]
- **data：** 抗体序列来自 OAS，作者先去重、过滤异常残基与过短 framework，再用 MMseq2 在 70% identity 下聚类，最终抽取 10 million 条用于训练。[doi:10.34133/research.0721, p.10]
  - 证据：[doi:10.34133/research.0721, p.10]
- **data：** 抗体结构包括约 10k 实验结构、150k ABodyBuilder2 预测结构和 1.4M IgFold 预测结构；蛋白结构部分则含 0.2M PDB 结构与 10M AFDB 结构。[doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **declared_resources：** 训练与评估依赖 ESM-2、Foldseek、MMseq2、AlphaFold3，以及 OAS、UniRef50、PDB、AFDB、ABodyBuilder2、IgFold、SAbDab 和 CoV-AbDab 等资源。[doi:10.34133/research.0721, p.3][doi:10.34133/research.0721, p.8][doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.3]；[doi:10.34133/research.0721, p.8]；[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **declared_resources：** 作者在 Data Availability 中声明源码与数据公开于 https://github.com/KDurant-123/S2ALM ，但冻结证据未核验仓库实际内容。[doi:10.34133/research.0721, p.12]
  - 证据：[doi:10.34133/research.0721, p.12]
- **declared_resources：** Funding 来自 NSFC 82202984、浙江省重点研发项目 2023C03053，以及浙江省医学影像人工智能重点实验室。[doi:10.34133/research.0721, p.12]
  - 证据：[doi:10.34133/research.0721, p.12]
- **limitations：** 作者明确承认受计算资源限制，S2ALM 的模型规模可能尚未达到最大容量。[doi:10.34133/research.0721, p.10]
  - 证据：[doi:10.34133/research.0721, p.10]
- **limitations：** 作者也指出抗体实验结构数据仍然稀缺，因此只能用预测结构和蛋白结构进行补偿。[doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **limitations：** 结构预训练高度依赖 Foldseek，作者承认这类方法在编码精度与检索效率之间仍有提升空间。[doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **method：** Stage I 先在蛋白域做一般序列-结构学习，把 UniRef50、PDB 和 AFDB 的序列/结构转成 1D 与 3Di token，再用 MLM 同时训练两种表示。[doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **method：** Stage II 转入抗体域，分别用 sequence-structure matching 判别配对关系，用 cross-level reconstruction 在一层被遮蔽时借助另一层信息恢复 token。[doi:10.34133/research.0721, p.11][doi:10.34133/research.0721, p.12]
  - 证据：[doi:10.34133/research.0721, p.11]；[doi:10.34133/research.0721, p.12]
- **method：** 结构编码依赖 Foldseek，将 3D 结构离散为 20 类 3Di tokens，以统一处理序列与结构输入。[doi:10.34133/research.0721, p.10][doi:10.34133/research.0721, p.11]
  - 证据：[doi:10.34133/research.0721, p.10]；[doi:10.34133/research.0721, p.11]
- **method：** 下游评估覆盖 binding prediction、B cell maturation、paratope prediction、binding affinity prediction 与 CDR infilling design，并通过线性层或 MLP 接入预训练表示。[doi:10.34133/research.0721, p.6][doi:10.34133/research.0721, p.7][doi:10.34133/research.0721, p.8][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.6]；[doi:10.34133/research.0721, p.7]；[doi:10.34133/research.0721, p.8]；[doi:10.34133/research.0721, p.9]
- **results：** t-SNE 可视化显示，预训练表示能更清楚地区分 pathogen specificity、species 与 isotype，作者据此认为模型学到了多尺度生物组织规律。[doi:10.34133/research.0721, p.3][doi:10.34133/research.0721, p.4]
  - 证据：[doi:10.34133/research.0721, p.3]；[doi:10.34133/research.0721, p.4]
- **results：** 在 STE90-C11 示例中，高 self-attention 分数对应 TRP157 与 SER183，作者将其解释为模型捕捉到长程结构接触与潜在氢键。[doi:10.34133/research.0721, p.5][doi:10.34133/research.0721, p.6]
  - 证据：[doi:10.34133/research.0721, p.5]；[doi:10.34133/research.0721, p.6]
- **results：** 在 antigen binding、B cell maturation 和 paratope prediction 三项任务上，S2ALM 都优于所列基线，并给出新的最佳指标或更强的整体表现。[doi:10.34133/research.0721, p.6][doi:10.34133/research.0721, p.7]
  - 证据：[doi:10.34133/research.0721, p.6]；[doi:10.34133/research.0721, p.7]
- **results：** 在 14H、14L 与 BioMap 的 binding affinity prediction 上，S2ALM 的 Pearson/Spearman 结果达到最优或并列最优。[doi:10.34133/research.0721, p.7][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.7]；[doi:10.34133/research.0721, p.9]
- **results：** 在 CDR-H3 生成任务中，S2ALM 在 PPL、AAR 与 DIV 之间取得更均衡的结果，并进一步用 AlphaFold3 评估生成复合物的结构质量。[doi:10.34133/research.0721, p.8][doi:10.34133/research.0721, p.9]
  - 证据：[doi:10.34133/research.0721, p.8]；[doi:10.34133/research.0721, p.9]

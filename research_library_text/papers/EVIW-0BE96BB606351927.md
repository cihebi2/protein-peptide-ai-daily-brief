# Preferential CDR masking in paired antibody language models improves binding affinity prediction

- **论文 ID：** `EVIW-0BE96BB606351927`
- **期刊 / 来源：** Communications AI & Computing（Crossref 书目信息）
- **发表时间：** 2026-08-13
- **DOI：** [10.1038/s44488-026-00010-2](https://doi.org/10.1038/s44488-026-00010-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `语言模型` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 preferential CDR masking 的配对抗体 MLM 训练方案，并在 ESM2-3B 与 ESM C 上证明它能同时提升 CDR 表征、masked recovery 和下游 binding affinity prediction。

## 创新边界

`创新边界在于 antibody representation learning 与 affinity prediction 的训练策略改进，不涉及新湿实验或候选分子生成。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在配对抗体语言模型中，通过更符合生物功能分布的 masking 方式，学习更能迁移到 binding affinity prediction 的表征，同时减少对大规模 unpaired 预训练的依赖。

## 方法

- paired sequence transformer、CDR-biased MLM与affinity fine-tuning。

## 数据与基准

- paired antibody sequences与affinity datasets。

## 比较基线

- antibody LMs与masking消融。

## 结果证据

- 论文报告优于uniform masking/单链baselines；为计算。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

- affinity数据小、antigen context不足。

## Pi 结构化证据摘录

- **baseline：** 在 WC-15% 与 CDR-50% masked recovery 上，本文模型总体与 IgBERT、IgT5 持平或更好，尤其是 HCDR3 和 LCDR3；但作者也明确说明 cross-paper split 不完全一致，因此这类比较只能视为指示性。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.5]
- **baseline：** 在 binding regression 上，AbCDR-ESM2/ESMC 普遍优于 AntiBERTy、AbLang、ProtBert、ProtT5、IgBERT、IgT5 等基线；唯一明显例外是 Trast 上 AbLang2 仍然更强。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.6]；[doi:10.1038/s44488-026-00010-2, p.7]
- **baseline：** 结果还显示，较大的参数规模并不自动带来更好的 antibody-specific performance，收益主要来自 CDR-aware fine-tuning 而不是单纯扩尺。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.6]；[doi:10.1038/s44488-026-00010-2, p.7]
- **data：** MLM 语料来自 OAS，作者去除了非 human 序列和 autoimmune repertoires；聚类后保留了 1,220,072,064 个 unpaired 代表序列和 1,617,948 个 paired 代表序列。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]
- **data：** paired 集合被划分为 20,225 条 validation 和 20,225 条 test 序列，并用 IMGT 标注来定义 CDR 位置用于 masking。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]；[doi:10.1038/s44488-026-00010-2, p.10]
- **data：** 下游数据包含 D44、G6、Trastuzumab 单突变集，以及 anti-HR2 SARS-CoV-2、anti-Fluorescein、anti-H1 Hemagglutinin 组合突变集，且 affinity 统一转换为 log(KD)。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]；[doi:10.1038/s44488-026-00010-2, p.10]
- **declared_resources：** 作者公开了处理后的 paired antibody MLM 数据集与 binding affinity 数据集，分别以 Zenodo DOI 形式发布，并声明采用 CC-BY 4.0。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.10]；[doi:10.1038/s44488-026-00010-2, p.11]
- **declared_resources：** 代码以 GitHub 仓库 `noc-lab/AbCDR-ESM` 形式公开，并提供 Zenodo 归档版本；论文还给出了 AbCDR-ESM2 和 AbCDR-ESMC 的 HuggingFace checkpoints。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.10]；[doi:10.1038/s44488-026-00010-2, p.12]
- **limitations：** 作者只评估了 ESM-family 架构，因此对 ProtT5、IgBERT 等其他架构和 positional encoding 的可迁移性仍未知。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]
- **limitations：** 论文只验证 binding prediction，尚未证明该表征能提升 stability、expression 或 immunogenicity 等其它治疗属性。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]
- **limitations：** cross-paper masked-recovery 比较存在 split 不完全一致的问题，且 CDR-50% 下的部分基线可能因测试集与其训练数据重叠而偏乐观；较小数据集也限制了结论置信度。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.5]；[doi:10.1038/s44488-026-00010-2, p.7]
- **method：** 研究在 ESM2-3B 与 ESM C 600M 两个 transformer PLM 上进行配对 VH-VL 的自监督微调，并系统比较 whole-chain、CDR-focused 与 hybrid 三种 masking 策略。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]；[doi:10.1038/s44488-026-00010-2, p.10]
- **method：** CDR masking 只在注释到的 CDR 区域内进行，按 50% 比例随机 mask，目的是让每个样本的 masked token 数量与 15% whole-chain masking 大致可比。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]
- **method：** Hybrid 策略在每个 batch 内以 80% CDR masking 加 20% whole-chain masking 混合训练；Stage II 还用 Pareto-knee 规则挑选最早的验证集 checkpoint，并结合 ridge regression 与 nested cross-validation 做下游评估。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.9]；[doi:10.1038/s44488-026-00010-2, p.10]
- **results：** 在 masked recovery 上，ESM2 的 Stage II Hybrid/CDR 模型显著改善了 HCDR3 与 LCDR3 的恢复率，ESM C 600M 也整体优于 ESM2，说明 CDR-focused training 确实强化了功能相关区域的表征。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.5]
- **results：** 在单突变 binding regression 上，AbCDR-ESM2 将 D44、G6、Trast 的 R2 从 0.302、0.264、0.335 提升到 0.359、0.298、0.350；AbCDR-ESMC 在 D44 和 G6 上分别达到 0.345 和 0.313。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.6]
- **results：** 在组合突变集上，AbCDR-ESM2 的 R2 在 anti-Fluorescein、anti-HR2 SARS-CoV-2、anti-H1 HA 上分别达到 0.693、0.396、0.411，体现出对不同抗原系统的泛化。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.7]
- **results：** 作者报告 unpaired pretraining 对 paired downstream binding 没有 measurable benefit，paired-only adaptation 已足以达到相当或更好的表现。
  - 证据：[doi:10.1038/s44488-026-00010-2, p.3]；[doi:10.1038/s44488-026-00010-2, p.6]；[doi:10.1038/s44488-026-00010-2, p.8]

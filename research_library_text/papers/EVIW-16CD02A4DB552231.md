## 作者主张的创新点

提出 PepCNN，将 ProtT5 序列嵌入、PSSM 与 HSE 特征结合 1D CNN，用于残基级蛋白-肽结合预测，并在两个基准集上优于既有方法。

## 创新边界

`这是残基属性/位点预测，不是直接生成、优化或对接候选蛋白/肽。`。这不是全球首创性检索或独立复现结论。

## 研究问题

预测蛋白序列中的 peptide-binding residues，以支持蛋白-肽相互作用解析和后续设计任务。

## 方法

- 1279 proteins残基特征拼接，1D CNN分类。

## 数据与基准

- 1279蛋白及binding residue labels。

## 比较基线

- 现有PepPI residue predictors和特征消融。

## 结果证据

- 论文报告specificity/precision/AUC超过SOTA；为计算预测。

## Pi 结构化证据摘录

- **baseline：** 比较对象包括 Pepsite、Peptimap、SPRINT-Seq、SPRINT-Str、PepBind、Visual、PepNN-Seq 和 PepBCL。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **baseline：** 与此前最佳方法 PepBCL 相比，PepCNN 的 AUC 在 TE125 上从 0.815 提升到 0.843，在 TE639 上从 0.804 提升到 0.826。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **baseline：** 但 sensitivity 并非始终最优；例如 TE125 上 Visual 更高，TE639 上 PepBCL 更高。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **data：** 全体数据包含 1,279 个 proteins、290,943 个 non-binding residues 和 16,749 个 binding residues。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]
- **data：** binding residue 的实验定义是：其任一 heavy atom 与 peptide 的 heavy atom 距离小于等于 3.5 Å。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]
- **data：** Dataset 1 的 TE125 包含 125 个 proteins 和 30,870 个 residues；对应训练集 TR1115 包含 1,115 个 proteins 和 266,712 个 residues。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]
- **data：** Dataset 2 的 TE639 包含 639 个 proteins 和 150,330 个 residues；对应训练集 TR640 包含 640 个 proteins 和 157,362 个 residues。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **data：** 作者在 Data Availability 中声明，数据集可从 PepCNN 的 GitHub 仓库下载。
  - 证据：[doi:10.1101/2023.09.02.556055, p.11]
- **declared_resources：** 作者在论文中声明代码和数据均发布在 PepCNN 的 GitHub 仓库中。
  - 证据：[doi:10.1101/2023.09.02.556055, p.11]
- **declared_resources：** Acknowledgements 提到 Australian Research Council Grant DP180102727，以及 Griffith University eResearch Service & Specialised Platforms 的 HPC Cluster 支持。
  - 证据：[doi:10.1101/2023.09.02.556055, p.12]
- **limitations：** 评估范围仅覆盖 TE125 和 TE639 两个公开 benchmark，没有看到独立外部测试集结果。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]；[doi:10.1101/2023.09.02.556055, p.5]
- **limitations：** 作者把整合 DeepInsight 并改用 2D CNN 作为 future work，说明当前方案仍局限于 1D CNN 与现有特征组合。
  - 证据：[doi:10.1101/2023.09.02.556055, p.8]
- **method：** 作者以 BioLiP 为来源构建两个 benchmark 数据集，并沿用既有工作划分 TE125/TR1115 与 TE639/TR640，同时用 blastclust 去除超过 30% 序列同一性的冗余。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]；[doi:10.1101/2023.09.02.556055, p.5]
- **method：** 每个残基被表示为 ProtT5 1,024 维 embedding、PSSM 20 维和 HSE 3 维特征的拼接向量，总维度为 1×1047。
  - 证据：[doi:10.1101/2023.09.02.556055, p.8]；[doi:10.1101/2023.09.02.556055, p.9]；[doi:10.1101/2023.09.02.556055, p.10]
- **method：** PepCNN 的主体是三层 1D CNN 加两层 dense，配合 ReLU、sigmoid、Adam(1e-6)、binary crossentropy、early stopping，并用 Bayesian Optimization 调参。
  - 证据：[doi:10.1101/2023.09.02.556055, p.10]；[doi:10.1101/2023.09.02.556055, p.11]
- **method：** 训练前作者对非绑定残基做随机下采样以缓解类别不平衡，并在训练集中再按 80:20 划分训练与验证。
  - 证据：[doi:10.1101/2023.09.02.556055, p.4]；[doi:10.1101/2023.09.02.556055, p.5]
- **results：** 在 TE125 上，PepCNN 的 sensitivity/specificity/precision/AUC 分别为 0.254/0.988/0.55/0.843。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **results：** 在 TE639 上，PepCNN 的 sensitivity/specificity/precision/AUC 分别为 0.217/0.986/0.479/0.826。
  - 证据：[doi:10.1101/2023.09.02.556055, p.5]
- **results：** 三个 case study（1dpuA、2bugA、1uj0A）中，模型预测的 binding residues 与实验标注总体相似。
  - 证据：[doi:10.1101/2023.09.02.556055, p.6]
- **results：** 作者在特征分析中观察到，ProtT5 embedding 单独表现最佳，而 embedding+PSSM+HSE 的组合取得更好的 AUC。
  - 证据：[doi:10.1101/2023.09.02.556055, p.6]

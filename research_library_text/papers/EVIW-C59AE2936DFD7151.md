# iProtDNA-SMOTE: Enhancing protein-DNA binding sites prediction through imbalanced graph neural networks

## 作者主张的创新点

作者声称提出 iProtDNA-SMOTE，把 ESM2、GraphSMOTE、GraphSAGE-MLP 和 focal loss 组合起来，用于蛋白-DNA 结合位点预测，并在多个 benchmark 上优于既有方法。

## 创新边界

`边界在于这是一个判别式预测框架，不是候选蛋白或药物的生成/优化方法；其新意主要来自现有模块的组合与不平衡学习策略。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在蛋白-DNA 结合位点预测中，如何在严重类别不平衡条件下融合序列与结构信息，提高少数类残基识别能力和独立测试泛化。

## 方法

- 蛋白结构/序列构图，PLM节点特征经GNN编码，GraphSMOTE在潜空间生成正类节点并分类。

## 数据与基准

- TR646/TR573训练与TE46/TE129/TE181独立测试。

## 比较基线

- 现有DNA-binding residue方法及无SMOTE/不同采样消融。

## 结果证据

- 独立集AUC 0.850/0.896/0.858；为计算位点预测。

## Pi 结构化证据摘录

- **baseline：** TE46 的对照包括 DRNAPred、DNAPred、SVMnuc、NCBRPred、DBPred 和 CLAPE-DB；TE129 也与同类序列/结构方法比较。
  - 证据：[doi:10.1371/journal.pone.0320817, p.9]
- **baseline：** TE181 的对照包括 DNAPred、SVMnuc、NCBRPred 和 CLAPE-DB，论文把 CLAPE-DB 视为最强深度学习对手之一。
  - 证据：[doi:10.1371/journal.pone.0320817, p.10]
- **data：** 模型在五个 benchmark 数据集上评估：TR646/TR573 为训练集，TE46/TE129/TE181 为独立测试集。
  - 证据：[doi:10.1371/journal.pone.0320817, p.3]；[doi:10.1371/journal.pone.0320817, p.4]
- **data：** TE129 和 TE181 相对 TR573 的序列相似性被限制在 30% 以下，TE46 也作为与 TR646 独立的测试集使用。
  - 证据：[doi:10.1371/journal.pone.0320817, p.3]；[doi:10.1371/journal.pone.0320817, p.4]
- **data：** Table 1 给出各集的残基统计，binding 比例约为 4.26%–9.06%，显示明显类别不平衡。
  - 证据：[doi:10.1371/journal.pone.0320817, p.4]
- **declared_resources：** 摘要直接给出 GitHub 仓库，且声明 benchmark datasets 和 code 对外公开。
  - 证据：[doi:10.1371/journal.pone.0320817, p.1]
- **declared_resources：** Supporting Information 包含 S1 Dataset、S1 Code、S1 Weight 和 S1 Model；数据可得性声明称相关内容都在正文和补充材料中。
  - 证据：[doi:10.1371/journal.pone.0320817, p.1]；[doi:10.1371/journal.pone.0320817, p.11]
- **limitations：** 作者承认当前图模型对极长蛋白序列可能不够友好。
  - 证据：[doi:10.1371/journal.pone.0320817, p.10]
- **limitations：** 作者建议后续加入更强的图卷积或 attention，并结合 AlphaFold3 与 ESM2 的进一步预测结果。
  - 证据：[doi:10.1371/journal.pone.0320817, p.10]
- **method：** 作者将 iProtDNA-SMOTE 设计为四步流程：ESM2 提取残基表示，AlphaFold3 结构构图，GraphSMOTE 处理少数类，再由 GraphSAGE-MLP 完成分类。
  - 证据：[doi:10.1371/journal.pone.0320817, p.4]；[doi:10.1371/journal.pone.0320817, p.5]；[doi:10.1371/journal.pone.0320817, p.6]；[doi:10.1371/journal.pone.0320817, p.7]
- **method：** ESM2_t36_3B_UR50D 产生 L×2560 的嵌入，并被直接作为图节点特征输入后续 GNN。
  - 证据：[doi:10.1371/journal.pone.0320817, p.5]；[doi:10.1371/journal.pone.0320817, p.7]
- **method：** 图边由 Cα 距离小于 8 Å 的残基连接，训练时再用 focal loss 缓解二分类不平衡。
  - 证据：[doi:10.1371/journal.pone.0320817, p.5]；[doi:10.1371/journal.pone.0320817, p.8]
- **results：** 在 TE46 上，iProtDNA-SMOTE 的 Spe/Pre/Rec/F1/MCC/AUC 为 0.973/0.583/0.363/0.447/0.418/0.850；作者强调其 MCC 最佳，但 AUC 不是最高。
  - 证据：[doi:10.1371/journal.pone.0320817, p.9]
- **results：** 在 TE129 上，模型取得 0.972/0.497/0.442/0.468/0.437/0.896，并在 MCC 与 AUC 上领先 CLAPE-DB。
  - 证据：[doi:10.1371/journal.pone.0320817, p.9]
- **results：** 在 TE181 上，模型取得 0.963/0.303/0.362/0.330/0.299/0.858，仍优于 CLAPE-DB 与其他对照。
  - 证据：[doi:10.1371/journal.pone.0320817, p.10]

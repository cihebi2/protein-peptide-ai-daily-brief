# Rigid Protein-Protein Docking via Equivariant Elliptic-Paraboloid Interface Prediction

## 研究问题

刚性蛋白-蛋白对接的学习方法中：点云配准范式（EquiDock）在退化点云下变换不唯一且口袋对齐错误；MaSIF缺蛋白间信息交互；DiffDock-PP推理慢且超参敏感；此前模型普遍存在空间冲突

## 作者主张的贡献

提出ElliDock：为两输入蛋白各预测一个椭圆抛物面表示对接界面，通过让两界面重合的闭式变换完成对接；EPIT网络（PAINN骨干+图transformer层+跨蛋白密集边）实现独立SE(3)等变性；推理最快（比EquiDock快2-3倍）且与DiffDock-PP/Multimer竞争，尤其抗体-抗原

## 创新边界

学习式刚性对接（EquiDock/DiffDock-PP）、等变GNN（PAINN）已有；本文新颖点在椭圆抛物面界面参数化（二次曲面闭式SE(3)变换，避免平面/球面歧义）与'界面重合'对接范式及界面两侧分离的重叠损失

## 创新点证据卡

- **[p1]** 以椭圆抛物面表示对接界面并以界面重合闭式求解变换
  - 原文："our model estimates elliptic paraboloid interfaces for the two input proteins respectively, and obtains the roto-translation transformation for docking by making two interfaces coincide"
- **[p4]** 独立SE(3)等变的EPIT（PAINN+图transformer+跨蛋白密集边）
  - 原文："we propose dense edge connections between every node pair of the receptor and the ligand, and only allow the invariant node features to be passed"
- **[p7]** 界面两侧分离约束硬性避免空间冲突
  - 原文："we address this issue by restricting receptor and ligand to either side of the interface in the standard form"
- **[p8]** 全部对比方法中推理最快（36.7s/DB5.5）
  - 原文："ElliDock is 2~3 times faster than EquiDock"

## 方法

- EPIT：PAINN骨干（不变标量H+等变向量V）+每消息传递块内图transformer层（多头注意力聚合k近邻边消息）
- 跨蛋白交互：不基于坐标建边，而对两蛋白节点对间密集连接，仅传递不变特征，sigmoid门控更新（保证独立SE(3)等变，命题1）
- 界面预测：图级不变输出回归标准形系数Λ*（softplus正定），等变输出构造R_p经U=(RR^T)^{1/2}极分解得旋转Q_p（命题3），坐标中心补偿得平移
- 对接：Q_{1→2}=Q2 Qr Q1^T，其中Qr为绕界面轴的旋转精修（Kabsch对齐xy维口袋）
- 四损失：Lfit（真值口袋对位于界面上且近切平面）、Loverlap（ReLU约束受体/配体分居界面两侧避免冲突）、Lref（精修角对齐）、Ldock（直接回归变换误差）

## 数据与基准

- DB5.5基准（253复合物，EquiDock拆分203/25/25）
- SAbDab训练（MMseqs2序列相似度拆分1781/300/0）+RAbD 54复合物测试（0.8序列相关聚类防泄漏）

## 结果证据

- DB5.5：CRMSD中位12.995/IRMSD中位11.134，优于EquiDock（14.136/11.971）与DiffDock-PP（14.109/15.060）全部指标；推理36.7秒为最快（EquiDock 60.1、DiffDock-PP 2103.1、HDock 11478、Multimer 56762）
- SAbDab抗体-抗原：IRMSD中位11.319最优，CRMSD略逊DiffDock-PP；DockQ 0.054与DiffDock-PP 0.045可比
- 比Multimer在SAbDab多数样本更好，但Multimer在特定样本精度极高
- HDock预训练性能极强但作者质疑其数据泄漏
- 消融：去Loverlap CRMSD 13.00→13.95（冲突约束重要）；去Lfit/ref主要伤IRMSD；去精修Qr IRMSD 11.13→13.22

## 比较基线

- AlphaFold-Multimer（预训练）、HDock（模板）
- EquiDock、DiffDock-PP（同数据从头训练）

## 已知限制

- 仅刚性对接，不考虑构象变化（作者自述，柔性对接为future work）
- 软约束而非硬约束，界面性质不保证完全满足
- 绝对精度（IRMSD~11Å）仍远低于HDock/Multimer模板类方法
- 单一界面假设对多界面/弱结合场景不适配

## 待复核未知项

- 椭圆抛物面假设在凹界面/大面积平面界面的失效模式
- 加入表面化学性质（作者提议）的增益
- 与柔性对接（DiffBindFR类）组合的路径

# VirusHound-I: prediction of viral proteins involved in the evasion of host adaptive immune response using the random forest algorithm and generative adversarial network

- **论文 ID：** `EVIW-DC23DC882167B02D`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2023 Nov 29
- **DOI：** [10.1093/bib/bbad434](https://doi.org/10.1093/bib/bbad434)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 VirusHound-I：结合 GAN 数据增强与 RF 分类器、基于 DPC 描述符的网页工具，用于预测病毒蛋白是否参与宿主适应性免疫逃逸。

## 创新边界

`边界在于对已知病毒蛋白序列做功能分类与候选筛选，不涉及新蛋白发现、机理解析或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

识别并预测那些参与逃避宿主适应性免疫应答的病毒蛋白，以便在大规模序列层面快速筛选候选靶标。

## 方法

- sequence features、GAN augmentation和RF分类。

## 数据与基准

- viral immune-evasion proteins/negatives。

## 比较基线

- 传统ML/无GAN。

## Pi 结构化证据摘录

- **baseline：** 论文的内部基线是 AAC、APAAC、DPC、PAAC 四种 descriptor 在同一 RF 框架下的对比，而不是已有 VPE 专用预测器的外部 benchmark。
  - 证据：[doi:10.1093/bib/bbad434, p.2]；[doi:10.1093/bib/bbad434, p.5]
- **baseline：** 引言明确指出，现有病毒研究工具主要面向抗原、表位或亚细胞定位预测，并不直接覆盖 VPE 预测。
  - 证据：[doi:10.1093/bib/bbad434, p.2]
- **baseline：** 在四种描述符中，APAAC 在训练阶段略强，但 DPC 在独立测试集上更优，因此作者选择 DPC 作为最终方案。
  - 证据：[doi:10.1093/bib/bbad434, p.5]；[doi:10.1093/bib/bbad434, p.6]
- **data：** 原始数据集包含 98 个参与免疫逃逸的病毒蛋白和 285 个不具备该功能的病毒蛋白，且都以 UniProt 和文献进行核对。
  - 证据：[doi:10.1093/bib/bbad434, p.2]
- **data：** GAN 生成的 synthetic data 被用于扩增正类，再与负类共同构建训练与测试流程。
  - 证据：[doi:10.1093/bib/bbad434, p.3]；[doi:10.1093/bib/bbad434, p.4]
- **data：** GAN 与整体流程的实现使用 TensorFlow 2.0，分类工作流使用 scikit-learn，网页应用使用 Python 3.11。
  - 证据：[doi:10.1093/bib/bbad434, p.3]
- **declared_resources：** 数据来源为 UniProt，正样本与负样本都由文献与数据库联合整理。
  - 证据：[doi:10.1093/bib/bbad434, p.2]
- **declared_resources：** 实现所用资源包括 TensorFlow 2.0、scikit-learn、propy3 和 Python 3.11。
  - 证据：[doi:10.1093/bib/bbad434, p.2]；[doi:10.1093/bib/bbad434, p.3]
- **declared_resources：** 作者公开了 GitHub 仓库 https://github.com/jfbldevs/virushound-I，并提供 VirusHound-I 网页应用 https://www.biochemintelli.com/VirusHound-I。
  - 证据：[doi:10.1093/bib/bbad434, p.3]
- **limitations：** 作者明确说明受计算资源限制，当前版本每次查询最多处理 100 条病毒序列，后续才计划逐步增加。
  - 证据：[doi:10.1093/bib/bbad434, p.3]
- **limitations：** 原始样本规模较小且类别不平衡（98 vs 285），因此需要 GAN 扩增正类，这也限制了数据规模。
  - 证据：[doi:10.1093/bib/bbad434, p.2]；[doi:10.1093/bib/bbad434, p.3]
- **limitations：** 论文将该工具定位为实验前的候选筛选步骤，没有提供湿实验验证。
  - 证据：[doi:10.1093/bib/bbad434, p.7]
- **method：** 作者从文献中整理出 98 条 VPE，并从 UniProt 随机选取 285 条 non-VPE 作为负集。
  - 证据：[doi:10.1093/bib/bbad434, p.2]
- **method：** 对两类序列计算 AAC、APAAC、DPC 和 PAAC 四种分子描述符，特征提取使用 propy3 完成。
  - 证据：[doi:10.1093/bib/bbad434, p.2]
- **method：** 为缓解正负样本不平衡，作者用 GAN 对正类做数据增强，GAN 由 generator 与 discriminator 组成，并训练 1000 epochs、batch size 30、Adam lr=0.0002、beta=0.5。
  - 证据：[doi:10.1093/bib/bbad434, p.2]；[doi:10.1093/bib/bbad434, p.3]
- **method：** 分类阶段采用 RF，在 80% 训练集上做超参数搜索与 10-fold CV，再用剩余 20% 作为独立测试集。
  - 证据：[doi:10.1093/bib/bbad434, p.3]
- **results：** 摘要与表 1 报告的最佳模型均为 DPC：训练阶段 10-fold CV 的 ACC 为 0.947、F1 为 0.943、AUC 为 0.989；测试阶段 ACC 为 0.964、F1 为 0.967、AUC 为 1.0。
  - 证据：[doi:10.1093/bib/bbad434, p.1]；[doi:10.1093/bib/bbad434, p.5]
- **results：** 作者认为 DPC 模型在独立测试集上泛化最好，因此将其整合进 VirusHound-I 网页工具。
  - 证据：[doi:10.1093/bib/bbad434, p.3]；[doi:10.1093/bib/bbad434, p.6]
- **results：** 网页应用可输出 0 到 1 的概率分数，并可用于对病毒蛋白进行批量预测。
  - 证据：[doi:10.1093/bib/bbad434, p.3]

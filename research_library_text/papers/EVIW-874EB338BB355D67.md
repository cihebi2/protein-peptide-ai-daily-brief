# SurfFold: a unified model for protein inverse folding by integrating surface and structural information

- **论文 ID：** `EVIW-874EB338BB355D67`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2025 Dec 19
- **DOI：** [10.1093/bioinformatics/btaf666](https://doi.org/10.1093/bioinformatics/btaf666)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白质设计` / `结构预测`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 SurfFold，把结构编码、surface 编码、representation alignment 和 one-shot decoding 统一到一个框架中，声称在 CATH4.2 与同源结构逆折叠任务上优于现有方法。

## 创新边界

`主要新意在于将 surface 与 side-chain 显式纳入逆折叠并做对齐融合；其全局原创性与外部优先权，冻结证据不足以验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在 protein inverse folding 中同时利用 backbone、side-chain 与 surface 的生化/几何信息，以提高序列预测与设计的准确率。

## 方法

- 从PDB提取主链/侧链图与表面点/化学属性，分别编码后跨模态融合，残基级softmax输出序列。

## 数据与基准

- CATH4.2训练/验证/测试和同源结构inverse-folding设置。

## 比较基线

- ProteinMPNN、GraphTrans、GVP-Transformer、PiFold及结构/表面单模态消融。

## 结果证据

- 论文报告CATH4.2测试序列恢复率62.47%，在所选基线和消融上最佳；属于计算恢复，不证明设计序列可折叠或有功能。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 依赖高质量结构和表面计算；仅测蛋白，未覆盖核酸/复合物；序列恢复指标偏向天然序列，不等于设计成功。

## 仍未知

- 冻结页未提供独立 prior-art 检索，无法验证全局新颖性。
- 摘要与表1的 full-test recovery 数值略有不一致，原因未说明。

## Pi 结构化证据摘录

- **baseline：** 作者对比了 GVP、GCA、StructGNN、ProteinMPNN、LM-design、PiFold、Knowledge-Design、ScFold、SurfPro 与 ESM-IF 等方法。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.4]；[doi:10.1093/bioinformatics/btaf666, p.5]；[doi:10.1093/bioinformatics/btaf666, p.6]
- **baseline：** 作者明确说明采用与 PiFold 相同的数据集和 evaluation metrics，以保证比较公平。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.4]
- **data：** 主要评测数据包含 CATH4.2，以及 TS50 和 TS500 两个 benchmark；作者还说明实验结果对不同 random seeds 取平均。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.4]；[doi:10.1093/bioinformatics/btaf666, p.5]；[doi:10.1093/bioinformatics/btaf666, p.6]
- **data：** 同源结构逆折叠实验从测试集蛋白对中筛选 TM-score 介于 0.3 到 0.6 的 pair，并按 0.02 区间分箱后随机采样 1000 对。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.7]
- **declared_resources：** 论文声明 source code 和 data 公开在 GitHub 仓库 https://github.com/jiudizhengf/SurfFold 。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.1]；[doi:10.1093/bioinformatics/btaf666, p.8]
- **declared_resources：** 作者同时声明获得多项中国国家与省部级 funding，并表示无 conflict of interest。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.8]
- **limitations：** 作者明确指出该框架目前仅面向 proteins，尚未测试 nucleic acids 或 protein–nucleic acid complexes。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.8]
- **limitations：** 论文给出的未来方向是把 SurfFold 扩展到更复杂的生物分子场景，说明当前工作边界仍限于蛋白序列设计。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.8]
- **method：** 结构分支同时提取 backbone 的球坐标、Euler 角与 side-chain 的四个 torsion angles，并以残基图上的 EdgeGraphConv/EGNN 式编码得到结构表示。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.2]；[doi:10.1093/bioinformatics/btaf666, p.3]
- **method：** surface 分支基于 dMaSIF 从原子坐标生成表面点云，再从最近原子、曲率与 quasi-geodesic neighborhood 中学习化学和几何特征。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.3]；[doi:10.1093/bioinformatics/btaf666, p.4]
- **method：** representation alignment 模块用 KDTree 为每个 Cα 匹配 8 个最近 surface points，做平均池化后再通过双向 cross-attention 和 MLP 融合。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.4]
- **method：** 解码端采用 inspired by PiFold 的 one-shot decoder，用 MLP 一次性输出每个位点的 amino acid 概率分布。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.4]
- **results：** 在 CATH4.2 上，SurfFold 在 short、single 与 all 三个划分里都取得最低 perplexity，并在 full-test 上达到 62.05±0.54% recovery。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.5]
- **results：** 在 TS50/TS500 上，SurfFold 的 recovery 分别为 64.16±0.27% 与 69.32±0.40%，略优于 Knowledge-Design。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.6]
- **results：** 消融实验表明，去掉 side-chain、surface、8-nearest alignment 或 cross-attention 都会明显降绩效；同源结构逆折叠中，当 TM-score 高于 0.45 时 SurfFold 明显优于 PiFold。
  - 证据：[doi:10.1093/bioinformatics/btaf666, p.6]；[doi:10.1093/bioinformatics/btaf666, p.7]

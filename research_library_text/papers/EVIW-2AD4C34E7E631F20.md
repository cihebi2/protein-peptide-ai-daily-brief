# ULDNA: integrating unsupervised multi-source language models with LSTM-attention network for high-accuracy protein-DNA binding site prediction

- **论文 ID：** `EVIW-2AD4C34E7E631F20`
- **期刊 / 来源：** Brief Bioinform

## 作者主张的创新点

作者提出 ULDNA，将来自多种数据库来源的三个无监督 protein language models 与 BiLSTM+self-attention 结合，输出残基级 DNA-binding 置信分数，并在多个基准集上优于既有方法。

## 创新边界

`这是序列级性质预测方法，不是候选蛋白/配体的生成、优化或排序；其新意主要在于多源 language model 嵌入与 LSTM-attention 的组合。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在实验注释极其稀缺的情况下，仅基于蛋白序列对残基级 DNA-binding sites 进行高精度预测，以便支持蛋白-DNA 相互作用解析与后续生物医学应用。

## 方法

- 多源PLM残基embedding拼接后由LSTM-attention解码位点。

## 数据与基准

- 多个protein-DNA residue benchmark。

## 比较基线

- 17种SOTA及单PLM消融。

## 结果证据

- 论文报告超过17种方法；为计算预测。

## Pi 结构化证据摘录

- **baseline：** PDNA-41 的对照方法包括 BindN、ProteDNA、BindN+、MetaDBSite、DP-Bind、DNABind、TargetDNA、iProDNA-CapsNet、DNAPred、Guan’s method、COACH 和 PredDBR。
  - 证据：[doi:10.1093/bib/bbae040, p.5]
- **baseline：** PDNA-52 的对照方法包括 DNABR、MetaDBSite、TargetS、DNAPred、COACH 和 PredDBR。
  - 证据：[doi:10.1093/bib/bbae040, p.5]
- **baseline：** PDNA-136 的对照方法包括 DP-Bind、TargetS、TargetDNA、DNAPred、GraphBind、NCBRPred、GraphSite、PredDBR 和 iDRNA-ITF。
  - 证据：[doi:10.1093/bib/bbae040, p.7]
- **baseline：** 作者还把 M0（one-hot + BiLSTM）和 M1（language-model embedding + BiLSTM）作为内部基线，再加入 self-attention 得到 M2/ULDNA。
  - 证据：[doi:10.1093/bib/bbae040, p.6]
- **data：** 五个基准集分别为 PDNA-543、PDNA-41、PDNA-335、PDNA-52 和 PDNA-316；作者给出了各自的序列长度范围与 DNA-binding / non-binding 位点统计。
  - 证据：[doi:10.1093/bib/bbae040, p.2]
- **data：** 为保证 DNA-binding site 定义一致，作者用 PDNA-543 训练并在 PDNA-41 上独立验证，用 PDNA-335 训练并在 PDNA-52 上独立验证；PDNA-316 用于 10-fold cross-validation。
  - 证据：[doi:10.1093/bib/bbae040, p.4]
- **data：** 三个 language model 的预训练资源分别是 UniRef50 上的 ESM2、BFD+UniRef50 上的 ProtTrans、以及 UniClust30+UniRef50 上的 ESM-MSA。
  - 证据：[doi:10.1093/bib/bbae040, p.3]
- **data：** 作者还构建了 PDNA-960 训练集与 PDNA-136 测试集，二者来自 PDB 中按 30% 序列一致性过滤的 1096 条 DNA-binding protein chains。
  - 证据：[doi:10.1093/bib/bbae040, p.6]
- **declared_resources：** 作者声明 datasets 和 source codes 可从 GitHub 仓库 https://github.com/yiheng-zhu/ULDNA 下载。
  - 证据：[doi:10.1093/bib/bbae040, p.9]
- **declared_resources：** 作者还提供了可供学术使用的在线服务器 http://csbio.njust.edu.cn/bioinf/uldna/ 。
  - 证据：[doi:10.1093/bib/bbae040, p.1]；[doi:10.1093/bib/bbae040, p.9]
- **limitations：** 作者指出当前的串联式特征融合难以完全消化不同 transformer 之间的冗余信息，因此仍需更高级的融合策略。
  - 证据：[doi:10.1093/bib/bbae040, p.8]
- **limitations：** 作者认为引入 AlphaFold2 或 ESMFold 的预测结构有望继续提升性能，说明当前模型仍主要依赖序列信息。
  - 证据：[doi:10.1093/bib/bbae040, p.8]
- **limitations：** 作者对部分对照方法采用了文献摘录结果或默认程序阈值，而本模型阈值则在训练集上按最大 MCC 选取，跨方法公平性有一定边界。
  - 证据：[doi:10.1093/bib/bbae040, p.4]；[doi:10.1093/bib/bbae040, p.5]
- **method：** ULDNA 先分别用 ESM2、ProtTrans 和 ESM-MSA 提取 L×2560、L×1024 和 L×768 的特征嵌入，并拼接成 L×4352 的混合表示。
  - 证据：[doi:10.1093/bib/bbae040, p.2]；[doi:10.1093/bib/bbae040, p.3]
- **method：** 混合嵌入输入 BiLSTM，再接 10-head self-attention、1024-neuron 全连接层和输出层，以产生每个残基的 DNA-binding score。
  - 证据：[doi:10.1093/bib/bbae040, p.3]；[doi:10.1093/bib/bbae040, p.4]
- **method：** 训练时使用 cross-entropy loss 和 Adam；learning rate、dropout rate、batch size 分别设为 0.001、0.2、1。
  - 证据：[doi:10.1093/bib/bbae040, p.4]
- **method：** 作者在 10-fold cross-validation 中用 grid search 选超参数，并以训练集上最大 MCC 的阈值作为报告指标的判定标准。
  - 证据：[doi:10.1093/bib/bbae040, p.4]
- **results：** 在 PDNA-41 上，ULDNA 在 Sen≈Spe 条件下取得 MCC 0.458、AUROC 0.935，明显高于 PredDBR 的 MCC 0.351。
  - 证据：[doi:10.1093/bib/bbae040, p.5]
- **results：** 在 PDNA-52 上，ULDNA 取得 MCC 0.517、AUROC 0.945，是表中所有方法的最佳结果。
  - 证据：[doi:10.1093/bib/bbae040, p.5]
- **results：** 在 PDNA-136 外部测试集上，ULDNA 取得 MCC 0.451、AP 0.360、AUROC 0.923，优于 9 个对照方法。
  - 证据：[doi:10.1093/bib/bbae040, p.7]
- **results：** 消融实验显示，加入三种 protein language models 后，MCC 平均提升 31.4%、AUROC 平均提升 17.7%；再加入 self-attention 后，MCC 还可平均提升约 0.7%。
  - 证据：[doi:10.1093/bib/bbae040, p.6]
- **results：** 案例 2MXF_A 和 3ZQL_A 里，ULDNA 分别达到 MCC 0.861 和 0.783，均优于 PredDBR。
  - 证据：[doi:10.1093/bib/bbae040, p.7]；[doi:10.1093/bib/bbae040, p.8]

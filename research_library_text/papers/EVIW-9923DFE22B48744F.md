# SOFB is a comprehensive ensemble deep learning approach for elucidating and characterizing protein-nucleic-acid-binding residues

## 作者主张的创新点

作者提出 SOFB，一个仅依赖序列信息的 ensemble deep learning 框架，结合 NABert 动态 residue language embedding、ProtT5 与多种生物学特征，并用 CNN/BiLSTM 与 bagging 提升 DNA/RNA binding residue 识别性能。

## 创新边界

`新意主要在序列表示与 ensemble 架构组合；不包含新 wet-lab 结果，也不主张生成候选分子。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在仅有蛋白序列信息时，逐残基预测 DNA/RNA binding residues，以弥补结构信息缺失带来的识别困难。

## 方法

- 蛋白序列经NABert/语言特征和多尺度CNN-BiLSTM多个模型，ensemble投票/平均。

## 数据与基准

- DNA/RNA binding residue benchmark，CD-HIT低同一性修剪。

## 比较基线

- 现有DNA/RNA位点预测器与单网络/特征消融。

## 结果证据

- 论文报告多个数据集优于SOTA；均为计算位点预测。

## Pi 结构化证据摘录

- **baseline：** 蛋白 embedding 对比包括 ProtVec、ESM、ESM2、ProGen 及其 finetune 版本。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.3]；[doi:10.1038/s42003-024-06332-0, p.4]
- **baseline：** 机器学习基线包括 XGBoost、KNN、GaussianNB、Decision Tree、Random Forest 和 SVM。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.5]；[doi:10.1038/s42003-024-06332-0, p.6]
- **baseline：** 深度学习与既有方法对比包括 TextCNN、RNN、ResNet、DeepForest、MLP，以及 TargetDNA、DNABind、GraphBind、aaRNA、RNABindRPlus、iDRNA-ITF、NCBRPred 等。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.5]；[doi:10.1038/s42003-024-06332-0, p.7]
- **data：** 训练/测试基准来自 BioLip，包含 DNA-573_train/129_test 与 RNA-495_train/117_test；初始共选出 9574 条 DNA-protein chains 和 7693 条 RNA-protein chains。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.2]
- **data：** 作者通过 bl2seq、TM-align、聚类和 CD-HIT 扩增并筛选正样本，使 DNA 与 RNA binding residues 分别增加 30.7% 和 24.3%。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.2]
- **data：** 除主基准外，作者还在 YFK16、YK17 和 MW15 等数据集上做了补充验证。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.7]
- **declared_resources：** 实现使用 Python、TensorFlow 2.7.0 和 Keras 2.7.0，训练配置包括 Adam、batch size 64、learning rate 0.0005，以及 NVIDIA GeForce RTX 3090 GPU。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.14]
- **declared_resources：** 作者声明源码可从 GitHub 获取，NABert 模型与训练好的 SOFB 模型可从 figshare 获取。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.14]；[doi:10.1038/s42003-024-06332-0, p.15]
- **declared_resources：** 数据也通过 figshare 与 GitHub 提供，且主文图表的数值源数据收录于 Supplementary Datafile。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.14]；[doi:10.1038/s42003-024-06332-0, p.15]
- **limitations：** 作者明确指出，HDOCK 的 docking score 不能被当作实验测得的真实 binding affinity。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.11]
- **limitations：** 作者也承认，NABert 的部分 attention results 并不一定 meaningful，因此可解释性并非完全确定。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.9]
- **limitations：** 在 RNA case 6htu_A 中，SOFB 仍漏掉 3 个 binding sites，说明它并非对所有位点都能完整命中。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.8]
- **method：** 问题被建模为逐残基二分类：输入蛋白序列，输出每个氨基酸是否为 nucleic-acid-binding residue 的概率。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.12]
- **method：** NABert 由双向 Transformer encoder 微调而来，保留 30 层和 16 个 attention heads，并抽取最后一层 hidden states 作为 1024 维 residue embedding。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.12]
- **method：** 作者同时使用 ProtT5 embeddings，以及 PSSM、HMM、physicochemical features、RAA、PKx 和 one-hot，构成 75 维生物特征。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.12]
- **method：** 网络由 stacked convolutional module、不同 kernel size 的卷积层、以及基于三层 64-unit LSTM 的 integrated multi-feature prediction module 组成，并用 ensemble learning 处理负样本子集。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.13]；[doi:10.1038/s42003-024-06332-0, p.14]
- **results：** 在 DNA test set 上，动态语言 embedding 的平均 Rec/Pre/F1/MCC 为 73.0%/40.4%/43.5%/40.9%，SOFB 的 AUC 达到 93.4%。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.3]；[doi:10.1038/s42003-024-06332-0, p.4]
- **results：** 在 RNA test set 上，SOFB 的 AUC 为 86.5%，相对第二好的 embedding method，F1 与 MCC 分别提升 6.2% 和 7.0%。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.4]
- **results：** 与 iDRNA-ITF 等 SOTA 方法相比，SOFB 在 DNA/RNA test sets 上取得 F1 0.520/0.358、MCC 0.505/0.337、AUROC 0.934/0.865，并分别将 AUROC 提高 5.1% 和 10.5%。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.5]
- **results：** 个例中，5h3r_A 的 20 个 DNA binding residues 被全部识别，F1 为 0.909、MCC 为 0.898；6htu_A 则漏掉 3 个 RNA binding sites，但 false positive 很少。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.7]；[doi:10.1038/s42003-024-06332-0, p.8]
- **results：** Docking 示例中，5h3r_A 的 docking score 为 -196.21；对 6htu_A，SOFB 的预测位置更贴近 true labels，但作者强调 HDOCK score 不能直接视为真实 binding affinity。
  - 证据：[doi:10.1038/s42003-024-06332-0, p.11]

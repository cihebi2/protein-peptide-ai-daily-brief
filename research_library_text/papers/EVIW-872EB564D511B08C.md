# Protein structure generation via folding diffusion

- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Feb 5
- **DOI：** [10.1038/s41467-024-45051-2](https://doi.org/10.1038/s41467-024-45051-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成` / `结构预测`
- **基础层：** Codex 辅助专家全文审阅

## 作者主张的创新点

作者提出 FoldingDiff：把 protein backbone 表示为每个 residue 的 6 个 internal angles，并在 wrapped angular space 上训练 diffusion model；结合 vanilla bidirectional transformer，声称可直接生成更符合天然分布、具 chirality、且具有一定 designability 与 diversity 的新 backbone 结构。

## 创新边界

`该工作在冻结证据中最明确的新意是“角度表示 + diffusion 生成”的组合，以及在无需复杂 equivariance 的情况下生成 backbone；但未独立验证其相对更广 prior art 的全球新颖性，也没有 wet-lab 级别功能验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在不依赖复杂 equivariant 3D 坐标网络的前提下，如何直接生成新颖、物理上可折叠、且在二级结构与设计性上接近天然蛋白的 protein backbone 结构。

## 方法

- CATH短域训练；对内角序列做1,000步去噪扩散；用逆折叠+结构预测的scTM评价可设计性，并检查新颖性/多样性。

## 数据与基准

- 30,395个40–128 aa CATH域，80/10/10拆分；生成50–127 aa共780个骨架。

## 比较基线

- 同角度表示自回归模型、随机角度打乱、ProtDiff、ProteinSGM和天然结构上界。

## 结果证据

- 780个生成物中177个scTM≥0.5；角度和二级结构分布接近测试集；短骨架更可设计，β-sheet生成物明显更难达到高scTM。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 只生成骨架，不生成序列/侧链；长度上限128 aa；没有湿实验；scTM流程本身对天然结构也会失败且偏向短α结构。

## 仍未知

- 是否能稳定扩展到远长于 128 residues 的 backbone 仍未知。
- 对更复杂拓扑（如 β barrels）与更高阶功能约束的效果未知。
- 真实实验层面的可折叠性、表达性与功能性未在冻结证据中验证。
- 相对更广 prior art 的全球新颖性未被独立核验。

## Pi 结构化证据摘录

- **baseline：** autoregressive baseline 虽然使用同样的角度表示，但几乎退化为只生成单一 α helix，显示出严重 mode collapse。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.5]；[doi:10.1038/s41467-024-45051-2, p.7]
- **baseline：** randomized angle shuffling baseline 保留边际分布与 pairwise correlations，但几乎不产生可识别的 secondary structure，且无 designable 结构。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.5]；[doi:10.1038/s41467-024-45051-2, p.7]
- **baseline：** 作者将 ProteinSGM 作为参照，但指出其 scTM 结果因 Rosetta 后处理而不可直接与 FoldingDiff 比较。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.7]
- **data：** 训练数据来自 CATH 的去冗余结构域集合，作者强调任意两条链的序列一致性不超过 40%（在 60% overlap 上），用于覆盖较宽的 fold 空间。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.3]；[doi:10.1038/s41467-024-45051-2, p.9]
- **data：** 主实验生成了 780 个 backbone（长度 50–128，每个长度 10 个样本），并与同长度的 test set 天然结构做分布对比。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.3]；[doi:10.1038/s41467-024-45051-2, p.4]；[doi:10.1038/s41467-024-45051-2, p.5]
- **data：** 作者还公开了生成结构、元数据、designability 分数、训练集相似度、二级结构内容和 Gauss integral embeddings。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.10]
- **declared_resources：** 作者声明训练与采样代码、trained model weights、绘图代码和全部结果脚本已发布在 GitHub，并可在 Zenodo 引用。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.10]
- **declared_resources：** 论文方法依赖的主要 open-source 组件包括 PyTorch、PyTorch Lightning、biotite、scikit-learn、numpy、pandas、matplotlib、seaborn 与 PyMOL。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.10]
- **declared_resources：** 模型训练与评估使用了 Microsoft 和 Stanford University 提供的计算资源。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.12]
- **limitations：** 作者明确承认方法当前仅在 128 residues 以内展示稳定结果，尚不能保证对更长蛋白或如 β barrels 这类更复杂折叠的可扩展性。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.8]
- **limitations：** 单个角度误差可能通过 lever arm effect 放大为整体结构偏差，且部分生成结构存在 self-crossing / collisions。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.8]
- **limitations：** 当前方法只生成 backbone，仍依赖外部 inverse folding 推断序列；sequence 与 side-chain 生成尚未纳入。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.3]；[doi:10.1038/s41467-024-45051-2, p.8]
- **limitations：** 设计性评估依赖 scTM 管线，而作者自己也指出该管线对真实结构并不完美，因而结果存在脆弱性。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.7]
- **method：** 蛋白 backbone 被编码为每个 residue 的 6 个 internal angles（3 个 bond angles + 3 个 dihedral angles），并以 residue 自身作为独立 reference frame，从表示层面获得平移/旋转不变性。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.2]；[doi:10.1038/s41467-024-45051-2, p.3]
- **method：** FoldingDiff 在这些周期性角度上执行 DDPM：forward 过程使用 wrapped normal 噪声，reverse 过程由 vanilla bidirectional transformer 参数化，并用 wrapped smooth L1 loss 训练。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.8]；[doi:10.1038/s41467-024-45051-2, p.9]
- **method：** 模型训练使用 CATH 4.3.0，保留 40–128 residues 的链，长链随机裁剪，最终划分为 24,316/3,039/3,040 的 train/validation/test 集。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.3]；[doi:10.1038/s41467-024-45051-2, p.9]
- **method：** 设计性评估采用 ProteinMPNN 生成候选序列，再用 OmegaFold（并与 AlphaFold2 对照）回折结构，计算 self-consistency TM score（scTM），以 scTM ≥ 0.5 作为 designable 阈值。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.6]；[doi:10.1038/s41467-024-45051-2, p.7]；[doi:10.1038/s41467-024-45051-2, p.9]
- **results：** 生成角度分布几乎复现测试集的单变量分布与 φ/ψ Ramachandran 联合分布，包括 ω 的周期边界效应与右手/左手 α 螺旋及 β sheet 区域。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.3]；[doi:10.1038/s41467-024-45051-2, p.4]
- **results：** 生成 backbone 的二级结构频率与共现模式接近天然蛋白，并在 Gauss integral + UMAP 可视化中覆盖较宽的设计空间。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.5]
- **results：** 在 780 个生成结构中，177 个（22.7%）达到 scTM ≥ 0.5；作者还报告相较 ProtDiff 有更高设计性，并指出短链通常优于长链。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.6]；[doi:10.1038/s41467-024-45051-2, p.7]
- **results：** 与随机角度打乱相比，FoldingDiff 生成的结构具有显著更高的 designability；作者同时观察到生成结构的训练 TM score 分布并不表现为简单 memorization。
  - 证据：[doi:10.1038/s41467-024-45051-2, p.7]

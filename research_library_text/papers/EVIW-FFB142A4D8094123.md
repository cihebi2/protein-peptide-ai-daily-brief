# Enhanced Sequence-Activity Mapping and Evolution of Artificial Metalloenzymes by Active Learning

- **论文 ID：** `EVIW-FFB142A4D8094123`
- **期刊 / 来源：** ACS Cent Sci
- **发表时间：** 2024 May 22
- **DOI：** [10.1021/acscentsci.4c00258](https://doi.org/10.1021/acscentsci.4c00258)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文声称提出了一个把信息密集型库设计、自动化高通量筛选、NGS 条形码测序、带实验噪声建模的 Gaussian process active learning，以及 DPP 多样化采样串联起来的整合管线，并将其用于 Sav-based ArM 的 gold-catalyzed hydroamination 优化，最终把命中率从初始库约 3% 提升到 38%。

## 创新边界

`可确认的是作者自述的管线集成与该 ArM 场景中的实验结果；但冻结证据本身不能独立验证其相对全部既有文献的全局新颖性，因此这里只能把 novelty 视为论文主张而非外部已证实事实。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：在巨大蛋白序列空间中，以可承受的实验预算，建立并利用可靠的序列-活性映射，从而高效改造人工金属酶（ArM），避免传统随机/贪婪筛选在低命中率和局部最优上的瓶颈。

## 方法

- 初始实验筛选记录sequence/activity，GP建模landscape，加入explorative round并迭代选择实验变体。

## 数据与基准

- artificial metalloenzyme组合突变库和colorimetric activity assay。

## 比较基线

- exhaustive/random screening和无exploration AL。

## 结果证据

- 论文实验展示信息丰富数据、探索轮和噪声建模可增强sequence-activity map并导向改进变体。

## Pi 结构化证据摘录

- **baseline：** 与作者先前仅覆盖 400 个双突变体的工作相比，本研究把搜索空间扩展到 5 个关键位点、理论上达到 3,200,000 个组合，明显提高了工程难度与搜索规模。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.5]；[doi:10.1021/acscentsci.4c00258, p.7]
- **baseline：** 作者还比较了随机采样与 model-guided exploration，指出约 40% 的初始数据量已经接近全量训练效果，而仅增加不到 20% 的数据量就能把识别 hits 的 precision 从约 20% 提升到 48%。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.10]
- **data：** 初始筛选覆盖 32 个 96-well plates，共 2880 个变体；排除未生长样本后得到 2790 个活性读数，NGS 读到 2663 个 well 的序列，最终形成 2164 个克隆、2035 个 distinct variants 的序列-活性数据。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.6]
- **data：** 作者又把先前已获得的 400 个 Sav double mutants 追加到训练集，使初始 machine-learning 数据达到 2992 个数据点、覆盖 2435 个 distinct ArM variants。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.7]
- **data：** 后续 exploration 库按设计包含 720 个 variant，实际再获得 465 个额外变体；exploitation 库同样设计 720 个 variant，实际测得 349 个 distinct variants。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.8]；[doi:10.1021/acscentsci.4c00258, p.10]
- **declared_resources：** 作者在 Data Availability Statement 中给出 data and code 的 GitHub 仓库链接，并说明 Supporting Information 含 materials and methods、Figures S1-S10 与 Tables S1-S15。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.12]
- **limitations：** 若只靠单次筛选，或者把不同表达/反应环境中的排名直接等同于同一序列的真实内在活性，结果可能会受环境依赖和测量噪声影响；作者也承认 in vivo 排名与 in vitro 排名会变化。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.10]
- **limitations：** 作者明确指出，当同时工程化超过大约 7 个位点时，穷举式计算不再可行，必须引入 Hamming distance 之类的限制；此外，Sav 中暴露的 cofactor 位置也可能限制最终提升幅度。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.11]
- **limitations：** 论文也承认，只用 chemical descriptors 已足够，说明更昂贵的结构特征没有带来清晰增益；而 fully automated workflow 仍不是完全落地的最终形态。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.7]；[doi:10.1021/acscentsci.4c00258, p.11]
- **method：** 先对靠近 biotinylated gold cofactor 的 20 个 Sav 位点做单点饱和突变，用 NDT codon 识别出 111、118、119 等更有提升潜力的位置，再选择 111、112、118、119、121 进行后续组合随机化。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.5]
- **method：** 构建的组合库刻意限制为最多 4 个氨基酸替换，以在 sequence diversity 与残余活性之间取得折中，避免 5 位点全随机化导致的大量失活变体。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.5]
- **method：** 筛选流程把 colony picking、ArM assembly、reaction setup 和产物定量自动化到 Tecan EVO 200 平台，并用两步 PCR barcode + Illumina paired-end NGS 把每个 well 的序列与活性重新关联起来。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.5]；[doi:10.1021/acscentsci.4c00258, p.6]
- **method：** 模型部分使用 Gaussian process regression，比较 chemical、geometric、energy descriptors，并通过 LASSO 与 Bayesian evidence maximization 做特征压缩；同时用重复测量估计实验噪声并把它纳入 likelihood。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.7]
- **method：** active learning 阶段先按 uncertainty 选出 informative variants 做 exploration，再用 DPP 在高预测活性候选中做 diversification 以进入 exploitation。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.8]；[doi:10.1021/acscentsci.4c00258, p.10]
- **results：** 初始 GP 模型的中位数交叉验证表现为 R2=0.54，Spearman 相关中位数为 0.68，说明它能较好复现相对排序但仍留有改进空间。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.7]
- **results：** 探索轮后，模型对高不确定区域的预测标准差明显下降，说明新增数据确实更充分地覆盖了先前欠采样的 sequence space。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.8]；[doi:10.1021/acscentsci.4c00258, p.9]
- **results：** 命中率从初始库的约 3% 提升到 exploitation 阶段的 38%，作者据此报告约 12-fold increase。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.6]；[doi:10.1021/acscentsci.4c00258, p.10]
- **results：** 最优变体 Sav CTNLV 的 cell-specific hydroamination activity 达到 wild type 的 18 倍、参考变体的 3 倍；此外，7 个被纯化验证的高活性变体里有 5 个在 in vitro total turnover number 上也更好。
  - 证据：[doi:10.1021/acscentsci.4c00258, p.10]

# PMIpred: a physics-informed web server for quantitative protein–membrane interaction prediction

- **论文 ID：** `EVIW-B7344ADA79740409`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Feb 5
- **DOI：** [10.1093/bioinformatics/btae069](https://doi.org/10.1093/bioinformatics/btae069)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称训练了一个以 MD 产生的 DDF 为监督信号的 transformer，并将其封装进 PMIpred web server；该系统可预测肽的膜结合自由能、区分 non-binder/sensor/binder，并可把蛋白结构中的膜相互作用区域映射到残基级别。

## 创新边界

`新意主要在 physics-informed transformer 与 web server 集成，而不是 wet-lab 生成新分子；冻结证据未能证明全球首创，只能支持其在给定 MD 体系与基准上的方法性增量。`。这不是全球首创性检索或独立复现结论。

## 研究问题

建立一种能从蛋白或肽序列与结构出发，定量预测 protein–membrane interaction、curvature sensing 与 membrane binding 的方法，以弥补现有工具缺乏自由能级别输出、且难以区分曲率感知与一般膜结合的问题。

## 方法

- 在不同膜曲率上模拟7–24 aa肽，获得relative binding free energy，再训练序列Transformer并部署web server。

## 数据与基准

- 超过5万条肽的MD数据，覆盖inactive至理论最优约0到−30 kJ/mol。

## 比较基线

- 物理规则/ALPS motif和先前模型。

## 结果证据

- 论文报告可准确预测相对膜结合自由能并分类non-binding、curvature sensing、membrane binding；为MD代理模型。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 训练标签来自特定膜模型与力场，不能替代实验膜结合；短肽长度限制适用域。

## 仍未知

- 缺少独立、盲测式的外部实验验证范围说明。
- 对非 α-helical、特定脂质环境和带 lipid anchor 蛋白的泛化边界仍不清楚。
- 训练数据中的 force-field 误差与熵项低估可能迁移到最终预测。

## Pi 结构化证据摘录

- **baseline：** 论文明确把同任务上的先前 CNN 作为内部基线，并说明当前工作改用 transformer。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.2]
- **baseline：** 外部基线是 DREAMM、PPM3 和 MODA；作者强调这些工具多偏向单残基、二元分类或 likelihood 输出，而 PMIpred 给出自由能式的定量分数。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.5]；[doi:10.1093/bioinformatics/btae069, p.7]
- **data：** 训练集包含 53,940 条唯一的 24 aa peptide，它们的 DDF 来自作者先前优化曲率感知时生成的 MD 数据。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.2]
- **data：** 作者还用 96 条未参与训练的 24 aa 序列展示全范围相关性，并以 3 个独立 replica 的 MD 结果作对照。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.3]
- **data：** 结构示例数据包括 ArfGAP1、epsin1 的 ENTH domain，以及 Bin1 的 N-BAR domain。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.5]
- **data：** 外部比较集由 27 个 PMP 组成，其中 19 个来自 Chatzigoulas and Cournia 的集合，另外 8 个是已知 lipid packing defect sensing proteins，且 PDB 与 AF 结构分开处理。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.6]
- **declared_resources：** 作者提供了 PMIpred web server，地址为 https://pmipred.fkt.physik.tu-dortmund.de。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.1]；[doi:10.1093/bioinformatics/btae069, p.4]
- **declared_resources：** 数据可用性声明指向 GitHub 仓库 https://github.com/nvanhilten/PMIpred。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.5]；[doi:10.1093/bioinformatics/btae069, p.9]
- **declared_resources：** 计算资源来自 NWO、HLRN、DFG EXC 2033、NWO Vidi 以及 JUWELS / Gauss Centre 等。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.9]
- **limitations：** 模型默认所有输入 peptide 都是 α-helical fold，因此对已知 non-helical 序列或结构需要谨慎解释。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.4]；[doi:10.1093/bioinformatics/btae069, p.8]
- **limitations：** 短肽，尤其约 12 aa 以下，更容易被判成 binder，作者认为这与长度外推步骤有关。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.7]
- **limitations：** charge correction 只在 z=-1 到 +4 的实验 benchmark 上验证，超出该范围时不确定性更高。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.8]
- **limitations：** 训练膜体系主要是 pure POPC 与 POPC/POPE；若相互作用依赖特定 lipid species、lipid anchor、链断点或低置信度结构，模型可能低估或误判。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.8]
- **limitations：** N/C terminus、gap、低 pLDDT 的预测结构，以及 transmembrane proteins 的多跨膜区域，都可能带来 false positives 或漏检。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.8]
- **method：** 作者用 coarse-grained MD 计算得到的 DDF 监督训练 transformer，以回归 24 aa peptide 的膜相关自由能。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.2]
- **method：** 模型通过长度外推、charge correction 和与膜曲率相关的公式，把 DDF 连接到 DDF_L24、DDF_adj、DF_sm 与膜结合概率 Pm。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.2]
- **method：** 蛋白结构筛选模块采用 15-residue sliding window 生成片段分数，再结合 9-residue 邻域平均 SASA，只把暴露残基纳入膜相互作用判定。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.3]
- **method：** Web server 允许输入 peptide 或 PDB/AF 结构，并把预测结果写入 PDB 的 B-factor 以便可视化。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.4]；[doi:10.1093/bioinformatics/btae069, p.7]
- **results：** Transformer 对 DDF 的预测 RMSE 为 1.79 kJ mol−1，且覆盖整个自由能范围。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.2]
- **results：** PMIpred 能识别 ArfGAP1 的 ALPS1/ALPS2、epsin1 的 helix-0，并把 Bin1 的 helix-0 标成 sensor，但与已知 liposome 结果存在不一致。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.5]
- **results：** 在 27 个 protein test set 上，PMIpred 与 DREAMM、PPM3、MODA 的总体 MCC 大致都在 0.45 左右；它对 lipid packing defect sensors 更强，但在 Chatzigoulas/Cournia 集合上较弱。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.6]
- **results：** 作者报告 PMIpred 的错误主要是 false positives，FDR 为 60%，FOR 为 4.4%。
  - 证据：[doi:10.1093/bioinformatics/btae069, p.6]

# Protein design using structure-based residue preferences

- **论文 ID：** `EVIW-73A3EA2A0A3BFC91`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Feb 22
- **DOI：** [10.1038/s41467-024-45621-4](https://doi.org/10.1038/s41467-024-45621-4)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白质设计`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

本文提出 CoVES（Combinatorial Variant Effects from Structure）：先用等变图神经网络从结构微环境中推断每个残基的氨基酸偏好，再把这些偏好用于组合效应预测与 Boltzmann 采样生成序列；作者声称它能在无监督条件下设计出功能且多样的 protein variants，并在若干任务上接近或优于更复杂的生成模型。[doi:10.1038/s41467-024-45621-4, p.2] [doi:10.1038/s41467-024-45621-4, p.5] [doi:10.1038/s41467-024-45621-4, p.6]

## 创新边界

`新意主要在把已有的 global epistasis / residue preference 思路推进到“结构驱动的无监督设计”上；它不是首次提出非线性残基偏好模型，但把该模型用于从结构直接生成蛋白序列是本文的边界内贡献。[doi:10.1038/s41467-024-45621-4, p.4] [doi:10.1038/s41467-024-45621-4, p.8]`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要回答的是：仅凭残基周围的局部三维结构环境，是否足以解释并预测组合突变的功能效应，从而在不显式建模残基间具体互作的情况下完成蛋白设计；同时还要判断这种简单的 residue preference 视角是否足够普适。[doi:10.1038/s41467-024-45621-4, p.1] [doi:10.1038/s41467-024-45621-4, p.2]

## 方法

- 先用非线性逐位点偏好/全局上位性模型分析组合适应度，再训练基于局部原子邻域的等变图网络CoVES进行无监督序列采样；以监督surrogate fitness评估生成序列。

## 数据与基准

- 覆盖6种蛋白的8个组合突变数据集，其中含本研究ParD3十位点文库；使用GFP、AAV、PABP等公开DMS数据、多个PDB结构和新生成的SRA数据PRJNA988522。

## 比较基线

- 比较模型无关随机采样、监督逐位点surrogate、ProteinMPNN、ESM-IF和其他无监督序列变体预测器。

## 结果证据

- 逐位点偏好可解释约78%-98%的组合效应；对7组数据，约为参数数目5倍的随机观察量可使留出预测Pearson r>0.8；CoVES优于模型无关采样，并与部分自回归方法相当。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 接触残基的真实上位性仍可能解释剩余变异；surrogate fitness不建模特定上位性并可能使生成评估偏置；全序列设计、更多突变数和预测结构输入的泛化尚未证明。

## 仍未知

- 外部先前工作是否已完全覆盖 CoVES 的具体边界，冻结证据未独立验证。
- 生成序列的湿实验验证样本量仍较小，推广到更广蛋白空间的稳健性未知。
- 作者的 surrogate fitness 与真实高阶互作之间的偏差，在部分数据集上仍未被完全量化。

## Pi 结构化证据摘录

- **baseline：** 单纯把观测到的单点效应相加，预测较差；ParD3 两个库分别只有 Pearson r=0.48 和 0.57，说明仅用单突变观察不足以重建组合效应。[doi:10.1038/s41467-024-45621-4, p.4]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.4]
- **baseline：** 线性回归在 ParD3 上能拟合但 residual 明显偏差；加入 sigmoid 的 logistic model 后显著改善，这是作者与更简单基线的直接对照。[doi:10.1038/s41467-024-45621-4, p.4]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.4]
- **baseline：** CoVES 与 proteinMPNN、ESM-IF、EvCouplings、BLOSUM 和随机库比较；作者报告 CoVES 通常优于这些 unsupervised baselines，但由监督 surrogate fitness 做 Boltzmann 采样时表现最好。[doi:10.1038/s41467-024-45621-4, p.6] [doi:10.1038/s41467-024-45621-4, p.7]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.6]；[doi:10.1038/s41467-024-45621-4, p.7]
- **data：** ParD3 十位点库采用两步 overlap-extension PCR 构建，先分别引入五个随机位点，再拼接成完整随机化 antitoxin；随后克隆入 pEXT20，并在 E. coli TOP10 / M9L / IPTG / arabinose 选择体系中测量。[doi:10.1038/s41467-024-45621-4, p.8] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.8]；[doi:10.1038/s41467-024-45621-4, p.9]
- **data：** 对 ParD3 变体，作者记录了两个时间点的高通量测序读数，用 FLASH 和 vsearch 处理后，在前后各至少 3 条 reads 的变体上计算 normalized log read ratio。[doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.9]
- **data：** GFP 数据来自随机突变实验，只覆盖 1810/4427 个可观测单点突变，因此后续 surrogate fitness 只能在这些已见单点变体组成的组合上使用。[doi:10.1038/s41467-024-45621-4, p.7] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.7]；[doi:10.1038/s41467-024-45621-4, p.9]
- **data：** 数据可用性声明给出原始变体测序数据 PRJNA988522，以及处理后的 variant-effect data 与 Source Data；代码可通过 Zenodo DOI 获取。[doi:10.1038/s41467-024-45621-4, p.11]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.11]
- **declared_resources：** 原始变体测序数据沉积在 PRJNA988522，processed data 与 Source Data 通过 github 和补充文件提供。[doi:10.1038/s41467-024-45621-4, p.11]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.11]
- **declared_resources：** 软件以 CoVES 名义发布在 Zenodo DOI 10.5281/zenodo.10461017；正文还列出使用的结构资源 PDB IDs: 5CEG, 1LP3, 1PGA, 1FCC, 2WUR, 2VWF, 1CVJ。[doi:10.1038/s41467-024-45621-4, p.11]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.11]
- **limitations：** 作者明确指出，生长选择对低于约 0.2 的非功能 antitoxin 变体分辨率不足，因此这部分表型存在不可解析的截断与噪声。[doi:10.1038/s41467-024-45621-4, p.3] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.3]；[doi:10.1038/s41467-024-45621-4, p.9]
- **limitations：** 该 surrogate fitness 只对训练分布内的组合有效；若出现未见过的单点替换，模型无法泛化，这是作者在方法部分直接承认的限制。[doi:10.1038/s41467-024-45621-4, p.7] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.7]；[doi:10.1038/s41467-024-45621-4, p.9]
- **limitations：** 作者承认模型不显式捕捉高阶 epistasis，剩余误差可能来自真实残基互作；另外，gain-of-function antitoxin 变体在当前测定条件下也难以观察。[doi:10.1038/s41467-024-45621-4, p.8]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.8]
- **limitations：** GFP 评估被限制在 surrogate 已训练和测试过的单点变体组合内，并且生成序列还被限制为少于 15 个突变，因此 full sequence design 仍是开放问题。[doi:10.1038/s41467-024-45621-4, p.7] [doi:10.1038/s41467-024-45621-4, p.8]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.7]；[doi:10.1038/s41467-024-45621-4, p.8]
- **method：** 作者对 ParD3 的 10 个结合位点构建随机化库，并用生长选择结合高通量测序测量组合变体效应；共测得 7923 个组合氨基酸变体和 2615 个截断抗毒素变体，且设置了两个生物重复。[doi:10.1038/s41467-024-45621-4, p.2] [doi:10.1038/s41467-024-45621-4, p.3] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.2]；[doi:10.1038/s41467-024-45621-4, p.3]；[doi:10.1038/s41467-024-45621-4, p.9]
- **method：** 用于解释组合效应的监督模型是带 sigmoid 的非线性 site-wise logistic regression：先对每个位点的 20 种氨基酸偏好做线性求和，再经非线性映射预测归一化表型。[doi:10.1038/s41467-024-45621-4, p.4] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.4]；[doi:10.1038/s41467-024-45621-4, p.9]
- **method：** CoVES 用等变图神经网络在 PDB 的原子级三维环境上做 masked-residue 预测，再把各位点的 log probability 作为偏好分数，用于组合评分和序列采样。[doi:10.1038/s41467-024-45621-4, p.5] [doi:10.1038/s41467-024-45621-4, p.10]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.5]；[doi:10.1038/s41467-024-45621-4, p.10]
- **method：** 序列生成阶段，作者对 CoVES、proteinMPNN、ESM-IF、EvCouplings 和监督 surrogate fitness model 统一做温度采样，并用“预测功能比例 + 多样性”比较不同方法。[doi:10.1038/s41467-024-45621-4, p.6] [doi:10.1038/s41467-024-45621-4, p.7] [doi:10.1038/s41467-024-45621-4, p.10]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.6]；[doi:10.1038/s41467-024-45621-4, p.7]；[doi:10.1038/s41467-024-45621-4, p.10]
- **method：** GFP 部分使用随机突变数据训练 surrogate fitness function，并明确只在训练分布内、已观察到的单点变体组合上评估；生成序列随后再由该 surrogate 过滤。[doi:10.1038/s41467-024-45621-4, p.6] [doi:10.1038/s41467-024-45621-4, p.7] [doi:10.1038/s41467-024-45621-4, p.9]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.6]；[doi:10.1038/s41467-024-45621-4, p.7]；[doi:10.1038/s41467-024-45621-4, p.9]
- **results：** ParD3 10 位点随机库的生物重复一致性很高（Pearson r=0.93），并估计约有 3×10^10 个组合序列能达到半最大 neutralization。[doi:10.1038/s41467-024-45621-4, p.3] [doi:10.1038/s41467-024-45621-4, p.10]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.3]；[doi:10.1038/s41467-024-45621-4, p.10]
- **results：** 仅用位点偏好而不加显式互作，线性模型已能给出较好拟合，但非线性 logistic model 更好：3 位点库 Pearson r=0.98、10 位点库 Pearson r=0.91，对应解释度约 98% 和 83%。[doi:10.1038/s41467-024-45621-4, p.4]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.4]
- **results：** 跨 8 个数据集，非线性 residue preference model 可解释 78–95% 的变异；在 7 个数据集上，训练样本约为参数数目的 5 倍即可让 held-out 相关性超过 0.8。[doi:10.1038/s41467-024-45621-4, p.4] [doi:10.1038/s41467-024-45621-4, p.5]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.4]；[doi:10.1038/s41467-024-45621-4, p.5]
- **results：** CoVES 在结构驱动的无监督评估中，能恢复偏好并在 5 个有结构的数据集上与其他 unsupervised predictors 相当；在 ParD3 上生成 6/11 个功能变体，在固定 Hamming 距离采样时 4/5 个仍保持功能。[doi:10.1038/s41467-024-45621-4, p.5]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.5]
- **results：** 在 antitoxin 任务里，CoVES 生成的序列比 proteinMPNN、ESM-IF、EvCouplings 和随机库更可能被 surrogate 判为功能性，同时保留更高多样性；在 GFP 上也观察到类似优势。[doi:10.1038/s41467-024-45621-4, p.6] [doi:10.1038/s41467-024-45621-4, p.7]
  - 证据：[doi:10.1038/s41467-024-45621-4, p.6]；[doi:10.1038/s41467-024-45621-4, p.7]

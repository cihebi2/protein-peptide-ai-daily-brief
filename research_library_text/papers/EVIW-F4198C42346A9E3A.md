## 作者主张的创新点

作者声称基于 17,312 条不超过 40% 序列相似度的蛋白构建 Tm 回归器，系统比较多种序列组成特征与 protein language model embeddings，最终以 ProtBert + ANN + MLP 获得最佳验证表现，并发布 PPTstab 网页、独立软件与设计模块。

## 创新边界

`主要创新在非冗余数据集、特征/嵌入对比、ProtBert 回归和单点突变扫描式设计；它不是新的湿实验流程，也未证明全局生成式蛋白设计。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在去冗余蛋白序列上回归预测 melting temperature (Tm)，并进一步为用户提供可朝目标 Tm 设计热稳定蛋白的工具。

## 方法

- Shannon entropy/序列features与ProtBert/ProtGPT2/ProtT5 embeddings进入回归，目标Tm用于候选筛选。

## 数据与基准

- 17,312非冗余蛋白，80/20训练测试与验证。

## 比较基线

- 传统序列features和多PLM/ML回归器。

## 结果证据

- ProtBert PCC 0.89、R² 0.80；为Tm回归，设计候选未证明实验耐热。

## Pi 结构化证据摘录

- **baseline：** 作者只把该方法与 regression-based 旧方法比较，并指出很多既有方法训练于 redundant datasets，且部分在线服务已不可用。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.6]
- **baseline：** 按 Table 7，PPTstab 的 test PCC 0.89、R2 0.80，与 DeepSTABp 的 test PCC 0.90、R2 0.80 接近，但优于 ProTstab2 和 ProTstab。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.7]
- **baseline：** 作者还强调 DeepSTABp 需要 query protein 的 organism growth temperature，而 PPTstab 不需要这一输入。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.6]
- **data：** 主数据来自 DeepSTABp，原始规模 35,114 条蛋白，来源于 Meltome Atlas，并涉及多种细菌、酵母、植物和哺乳动物样本。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.8]
- **data：** 去冗余后保留 17,312 条序列，其中 13,849 条用于训练，3,463 条用于 validation。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.8]
- **data：** 作者还按 Tm < 50 与 Tm > 50 分组做 composition analysis，并在应用部分用 reviewed proteomes 检查不同微生物在多个 Tm 区间的分布。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.2]；[doi:10.1038/s41598-025-98667-9, p.7]
- **declared_resources：** 作者提供了 web server `https://webs.iiitd.edu.in/raghava/pptstab/` 和 standalone 版本，用于预测与设计 thermostable proteins。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.1]；[doi:10.1038/s41598-025-98667-9, p.7]
- **declared_resources：** 数据下载页为 `https://webs.iiitd.edu.in/raghava/pptstab/data.html`，文中也给出 GitHub `https://github.com/raghavagps/pptstab`。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.1]；[doi:10.1038/s41598-025-98667-9, p.12]
- **declared_resources：** 论文声明有 Python package，可配合 web server 进行本地预测与设计。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.1]
- **limitations：** 作者明确指出该方法主要优化用于 thermophilic proteins；若要更泛化，需要把 thermophilic、psychrophilic 和 mesophilic proteins 一并纳入训练。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.8]
- **limitations：** 文中仅提供 in silico 设计与预测，Design 模块是 single-residue mutagenesis 扫描，没有报告新候选的实验测定。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.7]
- **limitations：** 作者承认 fine-tuning LLMs 需要大量内存和计算资源，因此选择 ProtBert 作为较低计算成本方案。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.8]
- **method：** 作者先从 DeepSTABp / Meltome Atlas 收集 35,114 条蛋白记录，过滤掉长度大于 2500 aa 和非天然氨基酸序列，再用 CD-HIT 40% 去冗余，得到 17,312 条 unique protein sequences，并按 80:20 划分训练/验证集。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.8]；[doi:10.1038/s41598-025-98667-9, p.11]
- **method：** 特征工程同时覆盖 Pfeature 生成的 15 类 composition-based descriptors，以及 ProtBert、ProtGPT2、ProtT5-XL-UniRef50、Ankh、ProsT5 等 embeddings；ProtBert 使用 1024 维序列表示。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.9]
- **method：** 建模时作者用 H2O AutoML 筛选候选 regressor，再用 scikit-learn / LightGBM / TensorFlow 实现 SVR、ET、NuSVR、LGBM、CatBoost、MLP 和自定义 4 层 ANN，并以 10-fold CV 和 Min-Max normalization 评估。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.10]；[doi:10.1038/s41598-025-98667-9, p.11]
- **results：** 在 composition-based 模型里，SER 的 validation 表现最好，达到 PCC 0.80、R2 0.63。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.4]
- **results：** 使用 ProtBert embeddings 的 ANN + MLP 在 validation 上达到 PCC 0.89、R2 0.80，MAE 3.00、RMSE 4.11，是全文最佳结果。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.6]
- **results：** 把 SER 与 ProtBert embeddings 合并后并未继续提升，validation 仅到 R2 0.79，说明传统特征没有补充到新的有效信息。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.6]
- **results：** 作者报告 PPTstab 的 test 性能与 DeepSTABp 接近，并在 web server 中提供 Predict 与 Design 两个模块。
  - 证据：[doi:10.1038/s41598-025-98667-9, p.6]；[doi:10.1038/s41598-025-98667-9, p.7]

# Unraveling druggable cancer-driving proteins and targeted drugs using artificial intelligence and multi-omics analyses

## 作者主张的创新点

作者声称构建了一个基于 AC/DC/TC 序列描述符的机器学习分类器，并结合 Open Targets、canSAR、Human Pathology Atlas、CGI/CADD 与 PLAPT 等多组学和结构信息，筛出 23 个关键可药癌驱动蛋白及 11 个相关药物。

## 创新边界

`这是一个以公共数据库整合和模型优先级排序为核心的计算框架，不足以单独证明全局新颖靶点或新化学实体。`。这不是全球首创性检索或独立复现结论。

## 研究问题

利用蛋白序列与多组学公共资源，识别癌症驱动蛋白中哪些属于可药靶点，并进一步优先排序可定位的候选蛋白与可重定位药物。

## 方法

- SVM 200个tri-amino-acid descriptors，结合target-disease score、cancer hallmark路径、结构ligandability、预后和oncogenic variome。

## 数据与基准

- druggable/hard-to-drug集合、TCGA PanCancer、多组学/PPI/结构数据。

## 比较基线

- 多种传统分类器及单证据排名。

## 结果证据

- 三折AUROC 0.975±0.003、accuracy 0.929±0.006；筛出79个候选、23个不良预后蛋白，均为计算/关联候选。

## 已知限制

- druggable外部标签稀缺，难以外部验证；预后关联非靶点因果/药效。

## 仍未知

- 独立外部可药蛋白集能否复现该 AUROC 仍未知
- PLAPT 亲和力排序是否能转化为真实结合尚未知
- 79/23/11 的优先级结果受数据库覆盖与阈值选择影响

## Pi 结构化证据摘录

- **baseline：** 作者不仅比较 13 种分类器与多种特征选择，还用正负集的 ChEMBL evidence score 作为一致性参照，发现 druggable cancer-driving proteins 显著高于 hard-to-drug proteins。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.4]；[doi:10.1038/s41598-024-68565-7, p.10]
- **baseline：** 模型限制分析里，作者用 2D PCA 把 200 维特征压缩展示三类点的混合分布，作为对分类边界复杂性的可视化基线，而不是独立外部验证。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.13]
- **data：** 训练集共有 885 条蛋白序列，class 1 为 666 个 druggable proteins，class 0 为 219 个 hard-to-drug proteins；最终把 2,339 个 cancer-driving proteins 作为全基因组扫描对象。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.4]
- **data：** 多组学与结构评估阶段还使用了 22,320 个变异、来自 76,156 个基因组的 gnomAD 数据，以及 2,466 个 ChEMBL approved drugs 和 217,776 个 HMDB molecules。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.6]
- **declared_resources：** 论文公开了脚本仓库 https://github.com/muntisa/machine-learning-for-druggable-proteins，并在补充材料中提供蛋白 FASTA、gene table、affinity tables 与各类辅助结果。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.1]；[doi:10.1038/s41598-024-68565-7, p.19]
- **declared_resources：** 资源依赖多种公共数据库与平台，包括 DrugBank、Drug Repurposing Hub、Open Targets、ChEMBL、canSAR、Human Protein Atlas、gnomAD、HMDB 与 CGI。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.4]；[doi:10.1038/s41598-024-68565-7, p.5]；[doi:10.1038/s41598-024-68565-7, p.6]
- **limitations：** 作者承认由于已知 druggable proteins 数量有限，无法构建独立外部可药蛋白集来验证最佳模型。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.12]；[doi:10.1038/s41598-024-68565-7, p.19]
- **limitations：** PLAPT 的结果只是亲和力预测，文中明确写明还需要 molecular docking、molecular dynamics 或其他 AI 交互预测进一步确认。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.18]；[doi:10.1038/s41598-024-68565-7, p.19]
- **method：** 先用 DrugBank 与 Drug Repurposing Hub 收集 666 个已知可药蛋白，并以 219 个 hard-to-drug phosphatase 作为负例；随后为序列计算 AC、DC、TC 三类组成描述符，比较 13 种分类器与 5 种特征选择方法。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.2]；[doi:10.1038/s41598-024-68565-7, p.4]
- **method：** 最终模型选用 LinearSVC 选出的 200 个 TC 特征，再配合非线性 SVM(RBF)；作者还用 permutation feature importance 分析最重要的三肽模式。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.7]；[doi:10.1038/s41598-024-68565-7, p.8]
- **method：** 后续优先级验证整合了 Open Targets/ChEMBL、CancerGeneNet、canSAR、Human Pathology Atlas、g:Profiler、CGI/CADD 与 PLAPT，用于 target-disease 证据、最短路径、ligandability、预后与亲和力评估。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.5]；[doi:10.1038/s41598-024-68565-7, p.6]
- **results：** 在分类器比较中，20 特征时最佳 AUROC 达 0.958，100 特征时升至 0.976，200 特征时 DC-PCA 方案可达 0.981；作者最终选用 200 TC + LinearSVC + non-linear SVM 的模型，三折 CV 下 AUROC 为 0.975±0.003、accuracy 为 0.929±0.006。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.7]
- **results：** 该模型将 2,339 个 cancer-driving proteins 中的 2,080 个判为可药，占 88.9%；其 ChEMBL evidence score 均值 0.706，高于 hard-to-drug 组的 0.596，并且 class 1 与 class 0 的差异显著。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.8]；[doi:10.1038/s41598-024-68565-7, p.10]
- **results：** Open Targets 汇总后，52 个可药癌驱动蛋白已进入晚期临床试验，另有 296 个尚未进入临床试验；对应的临床试验景观包含 257 个 trial events、94 个 drugs、38 种机制和 26 个癌种。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.10]
- **results：** 在 296 个未进入临床试验的候选中，184 个具有指向癌症 hallmarks 的最短路径，79 个 ligandability 高于 69.9%，并最终筛出 23 个关键靶点，覆盖 16 个 TCGA PanCancer types。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.11]
- **results：** 功能富集得到 64 个 GO biological processes 和 2 条 Reactome pathways；oncogenic variome 分析在这 23 个基因中识别出 1,598 个 oncogenic variants，其中 11 个已知、1,578 个新预测，且 252 个为 very high CADD、788 个 high、506 个 medium。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.11]
- **results：** PLAPT 给出了 11 个临床相关 FDA-approved drugs 的高亲和力候选，并对 HRAS 的 HMDB 分子筛得若干代谢物配体；作者明确建议后续再用 docking、molecular dynamics 或其他 AI 方法确认。
  - 证据：[doi:10.1038/s41598-024-68565-7, p.13]；[doi:10.1038/s41598-024-68565-7, p.18]

## 作者主张的创新点

作者提出并评估了一个基于 NSGA-II/NSGA-III 的多目标进化设计框架，把 ESM-1v 与 pMPNN 组合进 mutation operator，并以 AF2Rank、pMPNN 等分数作为目标函数，在 RfaH、PapD、CaM 上展示其相对 pMPNN-AD 与随机 baseline 的优势。

## 创新边界

`新意主要在模型编排与优化流程，而非训练新的蛋白基础模型；核心是把现有模型通过多目标进化搜索和信息化 mutation operator 连接起来。`。这不是全球首创性检索或独立复现结论。

## 研究问题

研究问题是：如何把多个异构深度学习模型（ProteinMPNN、AlphaFold2/AF2Rank、ESM-1v）直接纳入 protein sequence design 的生成流程，以便在多状态、目标冲突的设定下显式逼近 Pareto front，而不是只做事后筛选。

## Pi 结构化证据摘录

- **baseline：** 单纯降低 pMPNN temperature 从 0.3 到 0.1 能减少 variance/entropy 并提高 native recovery，但同时会加重 bias，且在 AF2Rank 空间里偏离 GA front。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.12]；[doi:10.1371/journal.pcbi.1011953, p.13]
- **baseline：** 调整 pMPNN state weights 只对少数位点有帮助，很多 native residue 无法通过重加权恢复，因此这条路不足以系统修正设计偏差。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.13]
- **baseline：** 对 pMPNN-AD 结果做 post hoc non-dominated sorting 只会损失样本、并不会像真正的多目标优化那样显著降低 sequence entropy。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.11]；[doi:10.1371/journal.pcbi.1011953, p.12]
- **data：** RfaH 结构来自 5OND 与 2LCL；PapD 来自 1N0L、1PDK、1QPP；CaM 使用表 1 中的 14 个 PDB 结构，并对缺失 loop/chain 做了选择性保留或删除。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.20]；[doi:10.1371/journal.pcbi.1011953, p.21]
- **data：** 设计位点分别是 RfaH C-terminal domain 119–154、PapD interface residues 1,3,4,5,6,7,8,31,91,104,105,106,107,108,109,110,112,152,154,163,164,166,170,194,200，以及 CaM 的 6–145 区间中除 Ca2+ binding residues 外的位点。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.21]
- **data：** 比较数据库来自 NusG-like sequences：从 15,195 条序列中筛出 645 条高置信 foldswitching 与 956 条 non-foldswitching 序列，并用 95% percentile normalized BLOSUM62 similarity 定义距离。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.25]
- **declared_resources：** 资金来源声明为 NIH R35 GM145236，以及 T.K. 的 Chan Zuckerberg Biohub Investigator 支持。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.2]
- **declared_resources：** 公开实现与分析代码声明可在 GitHub `https://github.com/luhong88/int_seq_des` 获取。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.1]
- **declared_resources：** 方法栈明确依赖 ProteinMPNN 1.0.1、ColabDesign 1.1.1、ESM-1v/pgen、pymoo、pygmoo、PyRosetta、Biopython、scikit-learn、SciPy、Logomaker 与 GETAREA 等工具。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.21]；[doi:10.1371/journal.pcbi.1011953, p.22]；[doi:10.1371/journal.pcbi.1011953, p.23]；[doi:10.1371/journal.pcbi.1011953, p.24]
- **limitations：** RfaH 与 PapD/CaM 的部分结构存在缺失残基、链长不一致或状态不完全可比的问题，因此某些结构分数和 hypervolume 只能在同一 state 内解释。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.21]
- **limitations：** CaM 的 nominal 14 维问题在 PCA/聚类下显示出更低 effective dimensionality，因此该 benchmark 的难度可能低于表面维数所示，结论不宜直接外推到所有高维问题。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.17]；[doi:10.1371/journal.pcbi.1011953, p.18]
- **limitations：** 如果 mutation operator 过于朴素，算法仍会产生 adversarial-like sequences；这说明性能高度依赖 informative mutation operator 的设计。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.18]；[doi:10.1371/journal.pcbi.1011953, p.19]
- **method：** RfaH 与 PapD 主要采用 NSGA-II：每轮通过 binary tournament selection、2-point crossover 和自定义 mutation operator 生成候选，再用 non-dominated sorting 与 crowding distance 选出下一代。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.22]；[doi:10.1371/journal.pcbi.1011953, p.23]
- **method：** 自定义 mutation operator 有 RND 与 ESM 两种选位方式：前者按 mutation rate 对 designable positions 做 Bernoulli 采样，后者先用 ESM-1v 单次前向传播给位点排序，再优先重设计最低分位点。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.22]；[doi:10.1371/journal.pcbi.1011953, p.23]
- **method：** 位点重设计可用 uniform random amino acid sampling 或 pMPNN-AD；目标函数包括 pMPNN-SD negative log likelihood、ESM-1v log likelihood 和 AF2Rank composite score。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.23]；[doi:10.1371/journal.pcbi.1011953, p.24]
- **method：** CaM 的 14 维问题改用 NSGA-III，并用基于 Riesz s-energy 的 reference directions；AF2Rank 由 AlphaFold2 的 pLDDT、pTM 与 template-prediction TM-score 乘积定义。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.23]
- **results：** 随机 resetting mutation operator 收敛很慢，native sequence recovery 明显落后于 pMPNN-AD，且即使 AF2Rank 分数接近 WT，sequence entropy 仍然很高，显示该 baseline 往往未收敛。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.5]；[doi:10.1371/journal.pcbi.1011953, p.6]
- **results：** 把 pMPNN 直接放进 mutation operator 后，GA 在部分 mutation rate 下可达到或超过 pMPNN-AD 的 native recovery 与 ESM-1v 分数，并在 hypervolume 上更优。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.7]
- **results：** 把 ESM-1v 用作选位器比把它直接当第三 objective 更有效；前者整体最好，后者因与其他目标冲突而降低 native recovery 和平均 ESM-1v 分数。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.8]
- **results：** GA[pMPNN]/GA[AF2Rank] 相比 pMPNN-AD 能压低 sequence entropy、集中到 WT residue types，并且 post hoc non-dominated sorting 不能复制这种 entropy reduction。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.10]；[doi:10.1371/journal.pcbi.1011953, p.11]；[doi:10.1371/journal.pcbi.1011953, p.12]
- **results：** 在 NusG-like 比较中，GA 设计序列整体更接近 foldswitching proteins 而不是 non-foldswitching proteins。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.13]；[doi:10.1371/journal.pcbi.1011953, p.14]
- **results：** 在 PapD 与 CaM 上，GA 仍普遍优于 pMPNN-AD；其中 CaM 的 GA[AF2Rank] native recovery 最好，而作者也判断其 objective space 具有较低的 effective dimensionality。
  - 证据：[doi:10.1371/journal.pcbi.1011953, p.14]；[doi:10.1371/journal.pcbi.1011953, p.16]；[doi:10.1371/journal.pcbi.1011953, p.17]；[doi:10.1371/journal.pcbi.1011953, p.18]

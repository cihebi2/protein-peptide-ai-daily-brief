# MVSO-PPIS: a structured objective learning model for protein-protein interaction sites prediction via multi-view graph information integration

- **论文 ID：** `EVIW-0665AE2922F1C927`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2025 Sep 1
- **DOI：** [10.1093/bioinformatics/btaf470](https://doi.org/10.1093/bioinformatics/btaf470)
- **范围标签：** `待 Pi 解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已专家复核，等待 Pi 解析

## 作者主张的创新点

论文声称MVSO-PPIS融合完整图和子图视角，并以Structured Objective Learning同时优化总体分类、边界结构和特定连续模式。

## 创新边界

`not_global_prior_art_verified`。这不是全球首创性检索或独立复现结论。

## 研究问题

提高PPI界面残基预测的逐残基准确率，同时让预测的连续片段边界和空间紧致性更符合真实界面结构。

## 方法

- 子图模块与增强图注意模块抽取互补结构特征，经多视图注意融合；SOL为01/10边界及010/101结构模式加入额外目标。

## 数据与基准

- PDB复合物构建的Train_335-1训练集，以及Test_60、Test_315-28、Btest_31-6和UBtest_31-6独立测试集。

## 比较基线

- AGAT-PPIS、GeoNet及其他序列/结构PPI位点预测器，另有无SOL和单视图消融。

## 结果证据

- 论文报告相对AGAT-PPIS，ACC/Precision/Recall/F1/MCC/AUROC/AUPRC分别提高1.2/3.5/2.7/3.2/3.9/0.6/0.9个百分点，并在多测试集改善边界模式与空间紧致性；均为计算评估。

# Multi-task bioassay pre-training for protein-ligand binding affinity prediction

- **论文 ID：** `EVIW-EC580540DF307D9E`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2023 Dec 11
- **DOI：** [10.1093/bib/bbad451](https://doi.org/10.1093/bib/bbad451)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文声称提出首个 PLBA pre-training framework MBP，并构建 ChEMBL-Dock 作为大规模预训练数据集；通过多任务回归 + assay 内排序来同时处理 label variety 与 label noise，从而提升下游 affinity prediction 的准确率与泛化性。

## 创新边界

`新意主要在 bioassay 级多任务 pre-training 与 ChEMBL-Dock 数据构建；它属于预测/表征学习，不是分子生成、优化或 docking ranking 的候选设计方法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何利用 ChEMBL 这类大规模但标签噪声重、测量类型不一致、且缺失真实 3D 构象的 bioassay 数据，预训练出更稳健、泛化更好的 structure-based protein-ligand binding affinity (PLBA) 预测模型。

## 方法

- protein-ligand 3D GNN，多任务回归+within-assay ranking pretext。

## 数据与基准

- ChEMBL-Dock >30万实验affinity、约280万docked structures及PDBBind下游。

## 比较基线

- PDBBind-only、scoring functions和pretraining baselines。

## 结果证据

- 论文报告预训练提高PLBA泛化；为计算预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- docked pose噪声、assay不一致与missing conformation；无实验新测。

## 仍未知

- 公开仓库中的实现细节、训练脚本和许可证是否与论文叙述一致，冻结证据中未核验。
- SMINA 生成的 docked poses 对不同靶点的误差分布及其对下游 affinity prediction 的影响，文本中未完全展开。
- 模型在更广泛的外部 assay、不同实验协议和不同靶点家族上的稳健性仍未知。

## Pi 结构化证据摘录

- **baseline：** 论文把 baseline 分成 ML-based、CNN-based、GraphDTA、GNN-based 四类，并与 LR、SVR、RF-Score、Pafnucy、OnionNet、GCN、GAT、GIN、GAT-GCN、SGCN、GNN-DTI、DimeNet、CMPNN、SIGN 逐一比较。
  - 证据：[doi:10.1093/bib/bbad451, p.8]；[doi:10.1093/bib/bbad451, p.9]
- **baseline：** 此外，论文还直接对比了 PLIG、PaxNet、GLI、KIDA、GraphscoreDTA、PLANET、GIGN、TANKBind 和 Transformer-M 的已发表结果。
  - 证据：[doi:10.1093/bib/bbad451, p.10]
- **data：** ChEMBL-Dock 最终包含 313224 个 protein-ligand pairs、21686 个 bioassays，以及约 2819016 个 docked poses；其中 IC50/Ki/Kd 分别为 231948/69127/12149 对。
  - 证据：[doi:10.1093/bib/bbad451, p.7]
- **data：** 构建数据时仅保留 STANDARD_TYPE 为 IC50/Ki/Kd、STANDARD_RELATION 为 '='、STANDARD_UNITS 为 nM、ASSAY_TYPE 为 B、TARGET_TYPE 为 SINGLE PROTEIN、COMPONENT_TYPE 为 PROTEIN、MOLECULE_TYPE 为 Small molecule、BAO_FORMAT 为 BAO_0000357 的记录，并剔除单样本和多 affinity type bioassays。
  - 证据：[doi:10.1093/bib/bbad451, p.7]
- **data：** 下游评测使用 PDBbind v2016 core/refined/general 和从 CSAR-HiQ 去重后得到的 135 样本独立测试集。
  - 证据：[doi:10.1093/bib/bbad451, p.8]
- **declared_resources：** 作者声明 MBP web-server 可免费使用，并提供代码与数据，地址包括 https://huggingface.co/spaces/jiaxianustc/mbp、https://anonymous.4open.science/r/MBP-03ED 和 GitHub 仓库。
  - 证据：[doi:10.1093/bib/bbad451, p.13]；[doi:10.1093/bib/bbad451, p.14]
- **declared_resources：** 实验资源写明使用 1 张 NVIDIA A100-PCIE-40GB 进行约 16 h pre-training，fine-tuning 约 1 h。
  - 证据：[doi:10.1093/bib/bbad451, p.17]
- **limitations：** ChEMBL-Dock 使用的是 docking poses 而不是真实 co-crystal 结构，作者也明确指出这些 3D 结构的质量不如 PDBbind 中的实验结构。
  - 证据：[doi:10.1093/bib/bbad451, p.7]
- **limitations：** 预训练阶段只使用 top-1 pose，作者把更多 poses 与 negative mining 视为未来工作，因此构象近似仍是主要限制。
  - 证据：[doi:10.1093/bib/bbad451, p.7]；[doi:10.1093/bib/bbad451, p.13]
- **limitations：** 方法当前主要验证于 PDBbind 与 CSAR-HiQ，跨靶点、跨 assay 标准和真实实验泛化边界未被冻结文本充分证明。
  - 证据：[doi:10.1093/bib/bbad451, p.8]；[doi:10.1093/bib/bbad451, p.13]
- **method：** MBP 采用 shared-bottom 架构，把 IC50 与 K={Ki,Kd} 拆成两类任务，并同时优化回归与组内 pairwise ranking，以缓解标签类型不一致和 bioassay 噪声。
  - 证据：[doi:10.1093/bib/bbad451, p.5]
- **method：** 输入被组织为 ligand graph、protein graph 和 protein-ligand interaction graph，边阈值分别设为 cutL=5.0Å、cutP=8.0Å、cutI=12.0Å，编码器可替换为 GCN、GIN、GAT、EGNN 或 AttentiveFP。
  - 证据：[doi:10.1093/bib/bbad451, p.6]
- **method：** 预训练时先从同一 bioassay 中抽取样本对，再用 RDKit 生成 ligand 3D 构象、从 PDBbind 提取 protein 结构，并用 SMINA 产生 docking poses 作为构象近似。
  - 证据：[doi:10.1093/bib/bbad451, p.4]；[doi:10.1093/bib/bbad451, p.7]
- **results：** 在 PDBbind core set 与 CSAR-HiQ 上，MBP-AttentiveFP 达到 1.263 RMSE / 0.825 R 和 1.624 RMSE / 0.791 R，整体优于 SIGN 和其他 baseline。
  - 证据：[doi:10.1093/bib/bbad451, p.9]
- **results：** 在更严格的表 3 对比中，MBP（PDBbind v2016 general 训练）在 core set 上取得 1.159 RMSE 与 0.855 R，优于 GIGN 的 1.190 RMSE 与 0.840 R。
  - 证据：[doi:10.1093/bib/bbad451, p.10]
- **results：** 作者还报告 MBP 在 PDBbind general set 上继续取得 RMSE 与 MAE 的最佳表现，并在 PDBbind 2019 holdout 上优于无 pre-training 版本。
  - 证据：[doi:10.1093/bib/bbad451, p.8]；[doi:10.1093/bib/bbad451, p.10]

## 作者主张的创新点

提出 DNABERT-Cap，将预训练 DNABERT 表征与 CNN、BiLSTM 和 capsule network 结合，用于 TFBS 预测，并通过消融实验、跨 cell line 评估和 TF 频率分析展示性能优势。

## 创新边界

`主要新意在模型集成与实验评估；DNABERT、BiLSTM、CNN 和 capsule network 本身都不是新概念，论文也没有新的湿实验或新的生物机制发现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在公开 ChIP-seq DNA 序列中，准确预测 transcription factor binding sites (TFBS)，并检验模型在不同 cell line 之间的泛化能力。

## Pi 结构化证据摘录

- **baseline：** 作者设置了三种内部基线：fine-tuned DNABERT、DNABERT+CL+BiLSTM+CE、DNABERT+CL+Capsule Layer，用来分解 transformer、BiLSTM 与 capsule 的贡献。
  - 证据：[doi:10.3390/ijms25094990, p.3]；[doi:10.3390/ijms25094990, p.4]
- **baseline：** 与 DeepARC、DeepTF、CNN-Zeng 和 DeepBind 的比较显示，DNABERT-Cap 在 accuracy、specificity、MCC 和 AUC 上最好，但 DeepARC 的 recall 略高。
  - 证据：[doi:10.3390/ijms25094990, p.4]；[doi:10.3390/ijms25094990, p.5]
- **baseline：** 作者明确指出，若只看 recall，去掉 capsule 的 baseline-3 在部分 cell line 上更高，因此他们强调 AUC 更适合作为主要判定指标。
  - 证据：[doi:10.3390/ijms25094990, p.4]
- **data：** 非跨 cell line 实验从 A549、GM12878、Hep-G2、H1-hESC 和 Hela 五个 cell lines 中各随机选取 500,000 sequences，并按 70%/20%/10% 划分训练、测试和验证集。
  - 证据：[doi:10.3390/ijms25094990, p.8]；[doi:10.3390/ijms25094990, p.9]
- **data：** 跨 cell line 评估扩展到 ten cell lines，共 404 datasets（352 + 52），用于检验模型从训练 cell line 迁移到未见 cell line 的能力。
  - 证据：[doi:10.3390/ijms25094990, p.8]；[doi:10.3390/ijms25094990, p.9]
- **data：** 作者还声明实验运行在 NVIDIA GA100 GPUs 上，且数据集与代码可通过 GitHub 获取。
  - 证据：[doi:10.3390/ijms25094990, p.9]；[doi:10.3390/ijms25094990, p.12]
- **declared_resources：** 实验数据来自 ENCODE 的 TF-690 ChIP-seq benchmark；非跨 cell line 使用 352 个 datasets，跨 cell line 扩展到 404 个 datasets。
  - 证据：[doi:10.3390/ijms25094990, p.8]；[doi:10.3390/ijms25094990, p.9]
- **declared_resources：** 论文的数据可用性声明给出 GitHub 地址：https://github.com/NimishaGhosh/DNABERT-Cap/tree/main。
  - 证据：[doi:10.3390/ijms25094990, p.12]
- **declared_resources：** 作者报告训练在配备 NVIDIA GA100 GPUs 的机器上完成，且超参数经实验调优。
  - 证据：[doi:10.3390/ijms25094990, p.9]；[doi:10.3390/ijms25094990, p.12]
- **limitations：** 论文没有新的 wet-lab 验证，全部证据来自公开 ChIP-seq benchmark 与计算实验，因此结论主要受数据集与标注策略所限制。
  - 证据：[doi:10.3390/ijms25094990, p.8]；[doi:10.3390/ijms25094990, p.9]；[doi:10.3390/ijms25094990, p.12]
- **limitations：** 作者把后续工作限定为加入其他特征嵌入参数、为特定 TF 设计专门模型，并扩展到 RNA–protein 和 DNA–protein binding 预测。
  - 证据：[doi:10.3390/ijms25094990, p.12]
- **limitations：** 频率与识别能力只有中等相关，说明模型并非仅靠 TF 出现频次即可解释，仍存在未建模因素。
  - 证据：[doi:10.3390/ijms25094990, p.6]；[doi:10.3390/ijms25094990, p.7]
- **method：** 作者使用 ENCODE/TF-690 ChIP-seq 数据构造 TFBS 任务，正样本取自 ChIP-seq peak 中心 101 bp 片段，负样本通过保持 dinucleotide frequencies 的重组生成。
  - 证据：[doi:10.3390/ijms25094990, p.8]；[doi:10.3390/ijms25094990, p.9]
- **method：** 模型先将 DNA 序列切成 6-mer tokens 输入预训练 DNABERT，再接 convolutional layer、BiLSTM、primary capsule、dynamic routing 与 TFBS capsule layer，最后用 margin loss 做二分类。
  - 证据：[doi:10.3390/ijms25094990, p.9]；[doi:10.3390/ijms25094990, p.10]；[doi:10.3390/ijms25094990, p.11]
- **method：** 论文给出的训练配置包括 DNABERT 的 12 层、768 hidden units 和 12 heads，卷积与 BiLSTM 各 64 units，kernel size 为 2，dropout 0.3，capsule length 16，routing 迭代 3 次，并使用 Adam 优化。
  - 证据：[doi:10.3390/ijms25094990, p.12]
- **results：** 在五个训练 cell lines 上，DNABERT-Cap 的平均 accuracy 为 84.21%、recall 为 80.99%、specificity 为 84.20%、MCC 为 0.686，并在这些指标上总体优于对比方法。
  - 证据：[doi:10.3390/ijms25094990, p.4]；[doi:10.3390/ijms25094990, p.5]
- **results：** 与 fine-tuned DNABERT 以及去掉 capsule 或去掉 BiLSTM 的消融基线相比，完整模型在 accuracy、specificity、MCC 和 AUC 上更好，说明 BiLSTM 与 capsule layer 都对性能有贡献。
  - 证据：[doi:10.3390/ijms25094990, p.3]；[doi:10.3390/ijms25094990, p.4]
- **results：** 跨 cell line 的 AUC 普遍较高，尤其在 DnD41 上达到 0.956–0.957；CTCF 子集也维持了非常高的跨 cell line AUC。
  - 证据：[doi:10.3390/ijms25094990, p.5]；[doi:10.3390/ijms25094990, p.6]
- **results：** TF 平均频率与识别 AUC 的 Pearson correlation 为 0.35，p < 0.001157；此外，一些在训练集中未出现的 TF 仍可被模型以较高 AUC 识别。
  - 证据：[doi:10.3390/ijms25094990, p.6]；[doi:10.3390/ijms25094990, p.7]；[doi:10.3390/ijms25094990, p.8]

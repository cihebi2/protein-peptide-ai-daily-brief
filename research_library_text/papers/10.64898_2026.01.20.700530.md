# ARID-sf: A physics-informed Deep Learning scoring function to improve Antibody-Antigen docking model ranking

- **DOI：** [10.64898/2026.01.20.700530](https://doi.org/10.64898/2026.01.20.700530)
- **批次：** mass-review-20260916 / strict-v2 高分通过（OA 补下全文）
- **质量分：** 75.0
- **检索通道：** C02-protein-inverse-folding、C03-protein-language-generation
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

抗体-抗原（Ab-Ag）对接模型排序困难：通用 PPI 评分函数在 Ab-Ag 上表现差（CDRH3 高变异、表位难预测），已有 Ab 专用评分函数（DLAB/CSM-AB/AbEpiScore）要么绑定特定对接软件、要么太慢无法高通量。需要一个不绑定对接工具、可每分钟处理数千模型、覆盖 Fab/Fv/sdAb 的专用重排序评分函数。

## 作者主张的贡献

提出 ARID-sf：经典力场相互作用势 + 界面结构/体积特征 + ESM 嵌入，经 self-attention transformer 预测 DockQ 做位姿重排序；在 >150 万 HADDOCK3 对接模型上训练，4 个独立测试集（806 案例、70 万+模型）评估，跨序列一致性/构象变化场景稳健超越现有评分函数；可并行、分钟级千模型；提出 Minimum Misclassification Rate (MCR) 新评估工具；代码/网络/管线全开放。

## 创新边界

DLAB（ZDOCK+3D grid CNN）与 CSM-AB（图表示预测亲和力）已开辟 Ab 专用评分函数方向，物理势+PLM 嵌入+注意力做接口打分的混合思路在其他 DL 评分函数中亦有先例；本文的增量在于不绑定对接器 + 高吞吐 + 以 DockQ 回归而非二分类 + 严格 20% 抗原序列一致性聚类防泄漏。属扎实的工程化组合创新，非全新范式。

## 创新点证据卡

- **[p4]** 力场相互作用势作为特征注入神经网络而非从头学习物理
  - 原文："incorporating physical potentials of interactions as features allows the neural network to leverage established biophysical principles"
- **[p3]** 对接工具无关、覆盖 Fab/Fv/sdAb 且高通量的 Ab-Ag 重排序评分函数
  - 原文："a highly specialized function able to accurately rank docking models from any source involving Fab, Fv, or sdAbs"
- **[p5]** 20% 抗原序列一致性聚类切分保证泛化评估严格性
  - 原文："no antigen sequence in the test or validation set shares more than 20% identity with any sequence in the training set"
- **[p10]** 提出 Minimum Misclassification Rate (MCR) 评分函数判别力指标
  - 原文："The Minimum Misclassification Rate is a new evaluation tool that helps identify the optimal score threshold"
- **[p5]** 以 DockQ 回归统一位姿质量排序目标
  - 原文："trained and validated on this feature representation to predict the DockQ score"

## 方法

- HADDOCK3 rigidbody/flexref/water 三模块生成训练用 decoy（正确/错误各约 50% 平衡）
- 特征矩阵：≤75 残基 × 4253 维（力场势、接触、体积性质、ESM 嵌入）
- self-attention transformer 回归 DockQ
- 按 20% 抗原序列一致性聚类划分（263 簇；train 997 案例/230 簇、val 34/18、test 15/15）防泄漏
- 评估：SR(topN)、Hit Rate(topN)、MCR（新提出的阈值-误分类率指标）
- 外部测试：co-folding（AF3/Boltz2 类）生成模型、Spd 轻扰动、Adb 需大构象变化的 unbound docking

## 数据与基准

- ANABAG 数据集 2151 个 Ab-Ag 复合物 → 去冗余 1046 案例
- >150 万 HADDOCK3 对接模型（训练）
- 4 个独立测试集共 806 案例、70 万+模型

## 结果证据

- 声称在愈发困难的对接场景下持续优于其他评分函数
- 跨序列一致性与构象变化幅度保持稳健泛化
- 高通量：每分钟可处理数千对接模型
- MCR 提供最优分类阈值

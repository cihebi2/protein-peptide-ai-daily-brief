# Prediction of blood–brain barrier penetrating peptides based on data augmentation with Augur

- **DOI：** [10.1186/s12915-024-01883-4](https://doi.org/10.1186/s12915-024-01883-4)
- **批次：** mass-review-20260916（wave3 多源 OA 补下）/ lane2-expansion
- **质量分：** 57.3
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

血脑屏障穿透肽(B3PP)预测中正样本稀缺(269条)且正负样本1:10严重不平衡，导致既有模型过拟合、Sn/Sp失衡与泛化能力差

## 作者主张的贡献

提出Augur：用Borderline-SMOTE+随机欠采样数据增强与信息增益(IG)特征选择结合随机森林，在不增加实验数据的前提下提升B3PP分类性能(训练AUC 0.932/独立测试0.931)

## 创新边界

方法组件(Boderline-SMOTE、IG、RF)均为已有技术，创新点仅在于组合应用于B3PP这一小样本不平衡任务；对比Augur vs MIMML在训练集仅高0.002、独立集反而低0.001(0.931 vs 0.930)，性能优势属于边际；且非深度学习方法，未涉及序列生成或校准

## 创新点证据卡

- **[p1]** 用Borderline-SMOTE边界过采样解决B3PP正样本稀缺与不平衡
  - 原文："a novel prediction model using borderline-SMOTE-based data augmentation and machine learning"
- **[p3]** 信息增益特征选择+三元搜索将2761维特征压缩到最优383维
  - 原文："used the ternary search algorithm to select the optimal number of features... best when it reached 383"
- **[p8]** 25%增强比例在独立测试集达平台AUC 0.931
  - 原文："when the data augmentation ratio is 25%, the model's performance reaches a plateau on the independent set (AUROC = 0.931)"
- **[p2]** B3PP显著富集精氨酸与酪氨酸，正电荷利于穿透负电BBB表面
  - 原文："the positive charge of arginine would be beneficial for B3PPs to penetrate the BBB"
- **[p9]** 在相同数据上重建并超越B3Pred/MIMML/SCMB3PP三个已发表工具
  - 原文："For a fair and stringent comparison, we rebuilt the models of these three tools"

## 方法

- 7种序列特征编码(AAC/APAAC/CTD/CKSAAP/ASDC/QSO等)融合为2761维特征集
- 信息增益(IG)特征排序+三元搜索算法确定最优383维特征子集
- Borderline-SMOTE对边界正样本过采样+随机欠采样(RUS)负样本，增强比例25%-100%网格
- 5种ML算法(RF/LightGBM/LR/SVM/KNN)五折交叉验证比较，最终选RF
- 独立测试集验证+与3个已发表工具在相同数据上重建对比

## 数据与基准

- B3Pdb数据库269条唯一B3PP正样本+2690条非B3PP负样本
- 划分训练集与独立测试集(具体划分比例未在所读页面明确)

## 结果证据

- 融合特征AUC 0.890优于任何单一编码(<0.881)；IG精选383维特征AUC 0.908优于全特征0.879
- RF在5种ML中最优：训练集AUC 0.885(增强前)/独立集0.924
- 增强比例25%时独立集达平台AUC 0.931，训练集随比例单调升至0.973(100%)
- 氨基酸组成分析：B3PP富集Arg和Tyr，Arg正电荷利于穿透带负电的BBB表面

## 比较基线

- B3Pred(训练AUC 0.930/独立0.900)
- MIMML(0.922/0.930)
- SCMB3PP(0.896/0.862)，三者均为作者在同一数据上重建

## 已知限制

- 对MIMML的优势可忽略(独立集0.931 vs 0.930)，提升主要来自数据增强而非算法创新
- 训练集增强至100%时AUC 0.973与独立集0.922差距大，SMOTE在特征空间插值可能引入乐观偏差
- 仅二分类，无概率校准、无回归端点、无生成能力
- 无公开web server，仅figshare存放代码数据
- 数据集绝对规模小(269正样本)，结论对更大数据集的外推未知

## 待复核未知项

- SMOTE特征空间插值样本是否对应可合成肽(化学合理性未验证)
- 独立测试集的具体构成与同源性去冗余方式(是否CD-HIT)未在所读页面说明
- 383维最优特征集在不同增强比例下是否稳定

# NanoBinder: a machine learning assisted nanobody binding prediction tool using Rosetta energy scores

## 作者主张的创新点

作者提出 NanoBinder：把 Rosetta energy scores 作为特征，结合 Random Forest、SHAP 和网页服务，对 nanobody-antigen binding probability 进行可解释预测，并在 49 个实验候选上做了验证。

## 创新边界

`创新主要在任务定制、特征筛选和实验验证；它复用 RosettaAntibody、Random Forest、SMOTETomek 和 Optuna 等现有组件，并未提出新的 nanobody 生成或序列优化框架。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在 nanobody-antigen 设计与筛选中，把 Rosetta 评分转化为更稳定的 binder/non-binder 过滤器，从而减少高通量实验中的误筛、漏筛和人工筛查成本。

## 方法

## Pi 结构化证据摘录

- **baseline：** 作者把 SVM、LR、AdaBoost、NB 和 DT 作为同一数据划分下的对照模型，RF 明显领先。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.5]
- **baseline：** 另一个外部对照是 GDockScore，使用同样的 0.5 阈值区分 binder 与 non-binder。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.11]
- **data：** 训练正样本来自 SAbDab 中仅保留 protein antigen 的 nanobody complexes，作者明确排除了 carbohydrates、peptides、haptens 和 nucleic acids。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]
- **data：** 负样本不是天然收集的，而是由 binding 复合物结构拼接生成的 synthetic non-binding complexes，因此负类分布带有构造痕迹。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]；[doi:10.1186/s13321-025-01040-1, p.13]
- **data：** 外部验证数据分为 Set 1、Set 2、Set 3，分别含 7、10 和 32 个 nanobody 候选，共覆盖 49 个实验样本。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.6]；[doi:10.1186/s13321-025-01040-1, p.7]；[doi:10.1186/s13321-025-01040-1, p.9]
- **declared_resources：** 论文公开了 NanoBinder web server，地址是 https://nsclbio.jbnu.ac.kr/tools/webserver/。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.3]
- **declared_resources：** 致谢中还明确提到 K-BDS 计算资源与技术支持，可作为运行支撑资源。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.15]
- **limitations：** 对高度相似的 nanobody 变体不够敏感，Set 1 中多处 false positive/false negative 说明小幅序列变化会干扰判断。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.11]；[doi:10.1186/s13321-025-01040-1, p.12]
- **limitations：** Rosetta 对 CDR loop 和 framework mutation 相关构象变化的刻画有限，真实 CDR 取向偏移可能未被完全捕捉。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]
- **limitations：** 模型对 binder 之间的细微 affinity 差异不敏感，更适合做 non-binder 过滤而不是精细排序。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.10]；[doi:10.1186/s13321-025-01040-1, p.11]；[doi:10.1186/s13321-025-01040-1, p.12]
- **limitations：** 作者建议扩充更丰富的 non-binder 负样本，并继续改进 feature engineering 与模型调参。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]
- **method：** 从 SAbDab 收集 1396 个 protein-antigen nanobody binding 复合物作为正样本。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]
- **method：** 通过 PyMOL 按 heavy chain 对齐，并在 RMSD 低于 2 Å 时交换链，合成 2570 个 non-binding 复合物。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]
- **method：** 对每个复合物执行去水、去配体、repack 和 relax，生成 40 个 Rosetta energy scores 作为初始特征。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.12]；[doi:10.1186/s13321-025-01040-1, p.13]
- **method：** 删除 packstat、sc_value 和 total_score 后，再用 Pearson 相关系数阈值 0.95 去冗余，最终保留 26 个特征。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.13]
- **method：** 在 stratified fivefold cross-validation 内，使用 SMOTETomek 处理 class imbalance，并用 Optuna 为 RF、SVM、DT、AdaBoost、LR、NB 调参。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.13]；[doi:10.1186/s13321-025-01040-1, p.14]
- **method：** 实验验证使用 BLI、ELISA、yeast surface display 和 FACS，对 49 个候选 nanobody 进行分阶段确认。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.6]；[doi:10.1186/s13321-025-01040-1, p.7]；[doi:10.1186/s13321-025-01040-1, p.9]；[doi:10.1186/s13321-025-01040-1, p.14]；[doi:10.1186/s13321-025-01040-1, p.15]
- **results：** RF 在五折交叉验证中表现最好，MCC 0.8203、F1 0.8806、ACC 0.9185、PRC 0.8253，优于其他五种基线分类器。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.5]
- **results：** SHAP 显示 dG_cross/dSASA × 100、dG_cross、Per_residue_energy_int 和 hbonds_int 是最重要的判别特征。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.6]
- **results：** 在三组实验验证中，Set 1/2/3 的预测-实验相关度约为 71%/80%/68%，合并后 non-binder 的识别接近完美，但 binder 的命中率只有 43%。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.10]；[doi:10.1186/s13321-025-01040-1, p.11]
- **results：** 与 GDockScore 相比，NanoBinder 在三组数据上分别达到 71.43%、80% 和 68.75% 的准确率，整体更擅长过滤非结合候选。
  - 证据：[doi:10.1186/s13321-025-01040-1, p.11]

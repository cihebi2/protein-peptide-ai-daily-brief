# SumoPred-PLM: human SUMOylation and SUMO2/3 sites Prediction using Pre-trained Protein Language Model

- **论文 ID：** `EVIW-342371DAB3074A41`
- **期刊 / 来源：** NAR Genom Bioinform
- **发表时间：** 2024 Feb 7
- **DOI：** [10.1093/nargab/lqae011](https://doi.org/10.1093/nargab/lqae011)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 SumoPred-PLM：基于 ProtT5 的 residue-level contextualized embedding 加 MLP 的位点预测框架，并宣称在多个SUMOylation/SUMO2/3基准上优于既有方法，且提供SUMO2/3特异性预测能力。

## 创新边界

`新意主要在 sequence-only 的 PLM 表征与分类器组合，以及 SUMO2/3 特异性位点预测；不涉及新蛋白候选生成、优化或 docking。`。这不是全球首创性检索或独立复现结论。

## 研究问题

利用蛋白序列去预测人类蛋白中的SUMOylation位点以及SUMO2/3特异性受体赖氨酸位点，以支持后续功能注释与设计相关分析。

## 方法

- 位点窗口ProtT5表示加分类器，比较特征/模型。

## 数据与基准

- CPLM4.0、SUMO2/3、GPS-SUMO。

## 比较基线

- GPS-SUMO及传统特征模型。

## 结果证据

- 独立集sensitivity 74.64%、specificity 73.36%、MCC约0.48、accuracy 74.00%；为计算位点。

## Pi 结构化证据摘录

- **baseline：** 作者用 LR、SVM、RF、XGBoost、NB、1D CNN 以及若干 RNN 变体作为内部基线，结果显示 MLP 在 ProtT5 表征上总体最强。
  - 证据：[doi:10.1093/nargab/lqae011, p.6]；[doi:10.1093/nargab/lqae011, p.8]
- **baseline：** 外部基线主要包括 GPS-SUMO、SUMOhydro、SUMOsp2.0、seeSUMO-SVM、seeSUMO-RF 和 JASSA，作者据此主张 SumoPred-PLM 在多个数据集上有竞争优势。
  - 证据：[doi:10.1093/nargab/lqae011, p.2]；[doi:10.1093/nargab/lqae011, p.8]；[doi:10.1093/nargab/lqae011, p.9]
- **data：** CPLM 4.0 训练集包含 5117 个蛋白、26911 个正样本和 201949 个负样本；独立测试集包含 578 个蛋白、2988 个正样本和 2988 个负样本。
  - 证据：[doi:10.1093/nargab/lqae011, p.2]；[doi:10.1093/nargab/lqae011, p.3]
- **data：** SUMO2/3 数据集训练集包含 2902 个蛋白、10684 个正样本以及从 131459 个负位点中下采样得到的 10684 个负样本；测试集包含 322 个蛋白、1269 个正样本和 1269 个负样本。
  - 证据：[doi:10.1093/nargab/lqae011, p.3]
- **data：** GPS-SUMO 数据集的训练部分来自 509 个蛋白，含 891 个正样本与 23371 个负样本并下采样到 891 个负样本；独立测试部分来自 39 个蛋白，含 71 个正样本和 1377 个负样本。
  - 证据：[doi:10.1093/nargab/lqae011, p.3]
- **declared_resources：** 论文声明程序与数据可通过 GitHub 仓库和 figshare DOI 获取。
  - 证据：[doi:10.1093/nargab/lqae011, p.10]
- **declared_resources：** 作者致谢使用了 BeoShock、Beocat 和 Sabine 三套 HPC 资源。
  - 证据：[doi:10.1093/nargab/lqae011, p.13]
- **declared_resources：** 文中点名依赖的外部资源包括 ProtT5-XL-UniRef50、Ankh、ESM2(3B)、CPLM 4.0、Hendriks et al. SUMO2/3、GPS-SUMO 与 dbPTM。
  - 证据：[doi:10.1093/nargab/lqae011, p.10]；[doi:10.1093/nargab/lqae011, p.13]
- **limitations：** 评估依赖去冗余和下采样后的平衡数据集，因此对真实世界里正负位点极端不平衡的泛化与校准仍不完全清楚。
  - 证据：[doi:10.1093/nargab/lqae011, p.2]；[doi:10.1093/nargab/lqae011, p.3]
- **limitations：** 当前方法是 sequence-only 表征，未引入结构或 MSA 特征；作者把 AlphaFold2-aware graph networks 作为后续提升方向。
  - 证据：[doi:10.1093/nargab/lqae011, p.10]
- **limitations：** 作者明确指出 SUMO1 proteomic 数据当前不可用，因此该平台先覆盖 SUMO2/3 特异性预测，而不是完整的 SUMO paralogue 覆盖。
  - 证据：[doi:10.1093/nargab/lqae011, p.10]
- **method：** 作者先对 CPLM 4.0、Hendriks et al. SUMO2/3 和 GPS-SUMO 三个基准集做 30% CD-HIT 去冗余，并在前两个数据集上用 under-sampling 平衡正负样本。
  - 证据：[doi:10.1093/nargab/lqae011, p.2]；[doi:10.1093/nargab/lqae011, p.3]
- **method：** 每个候选赖氨酸位点以 full-length protein 序列输入 ProtT5-XL-UniRef50，取最后 encoder 层的 1024 维 residue embedding；作者也比较了 Ankh 的 1536 维表示。
  - 证据：[doi:10.1093/nargab/lqae011, p.3]；[doi:10.1093/nargab/lqae011, p.4]
- **method：** 作者比较了 MLP、LR、SVM、RF、XGBoost、NB、1D CNN、BiLSTM、LSTM 等模型，并用 10-fold cross-validation、grid search、dropout、early stopping 和 reduce learning rate on plateau 选择最终 MLP。
  - 证据：[doi:10.1093/nargab/lqae011, p.4]；[doi:10.1093/nargab/lqae011, p.5]
- **results：** 在 CPLM 4.0 的 10-fold cross-validation 上，ProtT5+MLP 得到 MCC 0.478±0.010、SN 0.757±0.026、SP 0.720±0.026、ACC 0.738±0.005，为表中最佳。
  - 证据：[doi:10.1093/nargab/lqae011, p.6]
- **results：** 在 CPLM 4.0 独立测试集上，ProtT5+MLP 达到 MCC 0.4835、SN 74.02%、SP 74.32%、ACC 74.17%，AUC 为 0.895，并优于 GPS-SUMO 的 0.8629。
  - 证据：[doi:10.1093/nargab/lqae011, p.6]；[doi:10.1093/nargab/lqae011, p.8]
- **results：** 在 SUMO2/3 独立测试集上，ProtT5+MLP 的 MCC 为 0.4973，SN 为 75.88%，SP 为 73.83%，ACC 为 74.86%。
  - 证据：[doi:10.1093/nargab/lqae011, p.8]
- **results：** 在 GPS-SUMO 独立测试集上，模型报告 MCC 0.3752、SN 73.23%、SP 88.30%、ACC 87.56%，并在 SUMOhydro 基准上优于 JASSA、SUMOhydro、SUMOsp2.0、seeSUMO-SVM 与 seeSUMO-RF。
  - 证据：[doi:10.1093/nargab/lqae011, p.8]；[doi:10.1093/nargab/lqae011, p.9]

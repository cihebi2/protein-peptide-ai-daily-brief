# DrugAssist: a large language model for molecule optimization

- **DOI：** [10.1093/bib/bbae693](https://doi.org/10.1093/bib/bbae693)
- **批次：** mass-review-20260916（wave3 多源 OA 补下）/ strict-v2 高分通过（OA 补下全文）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

分子优化任务缺少 LLM 参与：现有端到端方法非交互、无法吸收专家经验与迭代反馈，且多数只关注单调提升/降低属性值而非真实场景的区间约束。

## 作者主张的贡献

提出 DrugAssist：基于 Llama2-7B-Chat + LoRA 指令微调的交互式人机对话分子优化模型，并公开大规模指令数据集 MolOpt-Instructions；在单/多属性优化上领先传统方法与 LLM 基线，支持区间型优化目标、多轮对话迭代优化与迁移。

## 创新边界

技术路线是标准指令微调（LoRA+多任务混入通用对话数据防遗忘），创新核心定位在'交互式分子优化'任务范式与 MolOpt-Instructions 数据集（loose/strict/range 三类指令）；属性计算依赖 iDrug 等外部预测器，优化效果以上游预测器为准而非实验；评估基于测试集 500 分子的成功率/有效性/相似度。

## 创新点证据卡

- **[p1]** 首个以人机对话交互方式做分子优化的 LLM 模型，支持专家多轮反馈迭代
  - 原文："we propose DrugAssist, an interactive molecule optimization model which performs optimization through human-machine dialogue"
- **[p1]** 公开 MolOpt-Instructions 大规模指令数据集，含 loose/strict/range 三类更贴近真实的区间型优化目标
  - 原文："we publicly release a large instruction-based dataset called 'MolOpt-Instructions' for fine-tuning language models on molecule optimization tasks"
- **[p1]** 多属性优化上持续领先传统 Seq2Seq/Transformer 与 ChatGPT/BioMedGPT 等 LLM 基线
  - 原文："DrugAssist has consistently achieved leading results in multi-property optimization, which is a less frequently addressed and more challenging task"
- **[p6]** 以通用指令数据复制混合的多任务学习策略防止微调中对话能力灾难性遗忘
  - 原文："we created the final dataset by replicating the Stanford Alpaca dataset five times and then mixing it with the Molopt-Instructions dataset"

## 方法

- MolOpt-Instructions 构建：ZINC 随机 100 万分子经 mmpdb 生成相似分子对，iDrug 计算属性值，ChatGPT 生成多样指令并人工精修，形成 loose/strict/range 三类优化指令
- 指令微调：Llama2-7B-Chat + LoRA（rank 64, alpha 128），10 epochs，batch 512，AdamW lr 1e-4 余弦衰减，8×A100
- 多任务学习防灾难性遗忘：MolOpt-Instructions 与 Stanford Alpaca 52k 通用指令按 1:5 复制比例混合，0.9/0.05/0.05 划分
- 多轮对话接口：专家可对初次生成的不完美分子继续给出反馈迭代优化

## 数据与基准

- MolOpt-Instructions（自建，公开）：基于 ZINC 100 万分子，Murcko 骨架分析平均每骨架 2.95 分子、93.7% 骨架含 ≤5 分子，结构/ADMET 属性分布广
- 评估集：测试集随机抽 500 分子，BBBP 与 Solubility 两属性优化对比

## 结果证据

- 单属性优化（BBBP/Solubility）：成功率、有效性、优化前后平均相似度综合优于 Mol-Seq2Seq 与 Mol-Transformer
- 多属性优化持续领先 ChatDrug(ChatGPT)、Llama2-7B-Chat、BioMedGPT-LM-7B 等 LLM 基线
- 区间型目标（属性落入给定范围）任务表现突出，更贴合真实药设需求
- 展示多轮对话迭代优化与跨属性迁移能力

## 比较基线

- Mol-Seq2Seq（attention Seq2Seq）与 Mol-Transformer（He 等 SOTA 翻译式优化）
- ChatDrug（ChatGPT GPT-3.5-turbo 提示工程）
- Llama2-7B-Chat 原始模型
- BioMedGPT-LM-7B

## 已知限制

- 优化成功以 iDrug 等计算属性为判据，属性预测器误差直接决定'成功'的可信度
- 基于 SMILES 文本空间，无 3D 结构/结合模式感知
- 测试仅 500 分子两属性，多属性组合空间覆盖有限
- 对话迭代依赖专家判断，评估中专家反馈质量未系统量化

## 待复核未知项

- 对肽/大环等非小分子 SMILES 的可扩展性
- 指令数据中 ChatGPT 生成指令的偏差对模型行为的固化
- 多轮对话中误差累积对相似度约束的影响

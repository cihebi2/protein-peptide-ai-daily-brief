# JASPAR 2026: expansion of transcription factor binding profiles and integration of deep learning models

- **论文 ID：** `EVIW-E4994E0304561D88`
- **期刊 / 来源：** Nucleic Acids Res
- **发表时间：** 2025 Dec 2
- **DOI：** [10.1093/nar/gkaf1209](https://doi.org/10.1093/nar/gkaf1209)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称发布 JASPAR 2026 这一年度更新：扩增 CORE/UNVALIDATED PFMs、更新 TFBS 预测与 genome tracks、加入 LLM 抽取的 TF-target 关系、整合 inMOTIFin 序列模拟工具，并首次提供基于 1259 个 BPNet 模型的 DL collection。[doi:10.1093/nar/gkaf1209, p.1][doi:10.1093/nar/gkaf1209, p.4][doi:10.1093/nar/gkaf1209, p.5][doi:10.1093/nar/gkaf1209, p.8]

## 创新边界

`主要创新边界是资源策展、模型汇编与界面整合，而不是新的 wet-lab 生成实验或以候选设计为主的算法论文。`。这不是全球首创性检索或独立复现结论。

## 研究问题

该文要解决的是：如何在维持 JASPAR 作为开放、人工策展、非冗余 TF binding profiles 资源的前提下，持续扩展覆盖范围，并把 deep learning TF-DNA 模型、TF-target 文献信息与序列模拟工具统一整合到同一数据库里。[doi:10.1093/nar/gkaf1209, p.1]

- JASPAR 2026 的新资源以现有 PFMs 与公开 ChIP-seq 数据为核心，未见独立外部任务级 benchmark。

## Pi 结构化证据摘录

- **baseline：** 与 JASPAR 2024 的 2346 个 CORE profiles 相比，2026 版的主要更新基线是更大的 CORE/UNVALIDATED 目录与更丰富的注释层。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **baseline：** 在 DL motif matching 中，作者把 JASPAR 2026 PFMs 或其他 in vitro-derived PFMs 作为最近匹配参考，而不是报告独立外部 benchmark。[doi:10.1093/nar/gkaf1209, p.7]
  - 证据：[doi:10.1093/nar/gkaf1209, p.7]
- **data：** CORE 2026 以 JASPAR 2024 的 2346 个 profiles 为基线，最终达到 2633 个 non-redundant PFMs；表中给出 265 个新 profiles、41 个从 UNVALIDATED 晋升、7 个移除、12 个降级和 13 个更新。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **data：** DL collection 收录 1259 个 BPNet models，覆盖 240 个 TF，并汇总出 353 个 motif patterns，其中 240 个 primary、113 个 alternative。[doi:10.1093/nar/gkaf1209, p.1][doi:10.1093/nar/gkaf1209, p.2][doi:10.1093/nar/gkaf1209, p.5]
  - 证据：[doi:10.1093/nar/gkaf1209, p.1]；[doi:10.1093/nar/gkaf1209, p.2]；[doi:10.1093/nar/gkaf1209, p.5]
- **data：** 论文同时更新了 8 个物种的 TFBS predictions 和 genome tracks，并为 human 与 mouse 的 vertebrate PFMs 提供 UCSC Genome Browser 原生轨道。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **data：** JASPAR 2026 还加入了 familial binding profiles、word clouds 与 TF-target 文献信息，以便在网页端统一检索和浏览。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **declared_resources：** JASPAR 2026 可通过网页界面和 RESTful API 访问。[doi:10.1093/nar/gkaf1209, p.9]
  - 证据：[doi:10.1093/nar/gkaf1209, p.9]
- **declared_resources：** pyJASPAR 和 JASPAR R/Bioconductor 包已更新，其中 R 包保存最新与前两版 release，并可经 AnnotationHub 访问。[doi:10.1093/nar/gkaf1209, p.9]
  - 证据：[doi:10.1093/nar/gkaf1209, p.9]
- **declared_resources：** inMOTIFin 提供网页端、CLI 与 Python 入口，论文同时给出其文档站点和 Bitbucket 仓库链接。[doi:10.1093/nar/gkaf1209, p.5]
  - 证据：[doi:10.1093/nar/gkaf1209, p.5]
- **declared_resources：** human 和 mouse 的 vertebrate TFBS tracks 还以 native tracks 形式接入 UCSC Genome Browser。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **limitations：** 作者明确指出 PFM/PWM 采用位置独立假设，不能充分表示邻近或远端碱基相互作用，也不直接建模 genomic context。[doi:10.1093/nar/gkaf1209, p.2]
  - 证据：[doi:10.1093/nar/gkaf1209, p.2]
- **limitations：** 人工寻找 orthogonal support 仍然耗时，而且不少 CAP-SELEX 二聚体 motif 缺乏足够文献证据可转入 CORE。[doi:10.1093/nar/gkaf1209, p.7][doi:10.1093/nar/gkaf1209, p.8]
  - 证据：[doi:10.1093/nar/gkaf1209, p.7]；[doi:10.1093/nar/gkaf1209, p.8]
- **limitations：** LLM-extracted TF-target 关系会出现错误，作者也只把 308 条正确关系保留到线上界面。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **limitations：** DL collection 目前只覆盖 Homo sapiens ENCODE ChIP-seq 数据，作者明确表示未来才计划扩展到其他物种和类群。[doi:10.1093/nar/gkaf1209, p.8]
  - 证据：[doi:10.1093/nar/gkaf1209, p.8]
- **method：** 作者从 HOCOMOCO、ModERN、CIS-BP、Codebook/GRECO-BIT、CAP-SELEX 以及多类 GEO 数据中收集并整理 PFMs/PWMs，再由人工策展决定进入 CORE 或 UNVALIDATED。[doi:10.1093/nar/gkaf1209, p.3]
  - 证据：[doi:10.1093/nar/gkaf1209, p.3]
- **method：** JASPAR curators 手工评估了 11,565 个 profiles，并依据文献中的 orthogonal support 执行新增、升级、降级、删除与 metadata 更新。[doi:10.1093/nar/gkaf1209, p.3][doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.3]；[doi:10.1093/nar/gkaf1209, p.4]
- **method：** DL collection 为每个 Homo sapiens ENCODE ChIP-seq dataset 训练一个 BPNet，然后用 DeepLIFT、TF-MoDISco 和 MotifCompendium 提取、聚类并比对 motif。[doi:10.1093/nar/gkaf1209, p.4][doi:10.1093/nar/gkaf1209, p.5]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]；[doi:10.1093/nar/gkaf1209, p.5]
- **method：** TF-target pipeline 使用 ChatGPT-5 与 ExTRI 文本句子，并结合 192 条人工标注句和 JSON schema 生成 TF-TG 关系及 modifier 标注。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **method：** inMOTIFin 允许在用户提供或随机 DNA 背景中插入 motif instances，并控制位置、间距、共现和频率，输出 FASTA 与 BED 结果。[doi:10.1093/nar/gkaf1209, p.5]
  - 证据：[doi:10.1093/nar/gkaf1209, p.5]
- **results：** 作者报告 CORE collection 相比上一版扩大 12%，对应 306 个新增或升级 profiles。[doi:10.1093/nar/gkaf1209, p.8]
  - 证据：[doi:10.1093/nar/gkaf1209, p.8]
- **results：** DL pipeline 最终为 240 个 TF 形成 summary profile pages，并得到 353 个 motif patterns；每个 TF 关联 1 到 7 个 motif patterns。[doi:10.1093/nar/gkaf1209, p.2][doi:10.1093/nar/gkaf1209, p.5]
  - 证据：[doi:10.1093/nar/gkaf1209, p.2]；[doi:10.1093/nar/gkaf1209, p.5]
- **results：** LLM 抽取的 TF-TG 标注经人工复核后，准确率为 88%（308/350），主要错误来自 Increased、Absent、Reduced modifiers 及假设性句子。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]
- **results：** familial binding profiles 也被更新并可下载，文中给出 504 个 familial profiles 的构建结果。[doi:10.1093/nar/gkaf1209, p.4]
  - 证据：[doi:10.1093/nar/gkaf1209, p.4]

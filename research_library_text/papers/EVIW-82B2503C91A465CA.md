## 作者主张的创新点

作者声称提出了首个 latent-space diffusion pLM：以 ESM-2 作为潜表示载体，用 AMP-Diffusion 直接生成新的 antimicrobial peptides，并用多项离线指标展示其优于若干生成基线。

## 创新边界

`贡献主要是 AMP 生成框架与离线评估，不包含湿实验验证，也未证明全球首创。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何把 protein language model 的连续潜空间与 diffusion 结合起来，实现 antimicrobial peptide 的 de novo 生成，并让生成序列在统计特征、理化性质和外部分类器评分上接近真实 AMP。

## 方法

- 将AMP序列映射到ESM-2潜表示，在连续潜空间进行高斯前向加噪和条件去噪，再解码为肽序列。

## 数据与基准

- 汇集dbAMP、AMP Scanner和DRAMP共195121条肽序列，并以实验验证AMP的分布作比较。

## 比较基线

- 条件VAE、GAN/BiCGAN及既有序列/结构/图扩散生成方法。

## 结果证据

- 论文报告生成肽在pseudo-perplexity、氨基酸多样性和理化性质上接近天然AMP；未报告合成、MIC或溶血实验。

## Pi 结构化证据摘录

- **baseline：** 对比基线主要是 HydrAMP、PepCV AE 和 AMPGAN；作者也把真实/训练 AMPs 作为参照组。
  - 证据：[doi:10.1101/2024.03.03.583201, p.3]；[doi:10.1101/2024.03.03.583201, p.4]
- **baseline：** 在 k-mer 相似度上，所有方法的 JS-3 都约为 0.99，但 AMP-Diffusion 的 JS-6 为 0.028，高于 HydrAMP 0.014、PepCV AE 0.020、AMPGAN 0.016。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]
- **baseline：** HydrAMP 外部分类器被用作验证工具，用来给生成序列打 Pamp 和 Pmic 分数，而不是作为生成模型本身。
  - 证据：[doi:10.1101/2024.03.03.583201, p.3]；[doi:10.1101/2024.03.03.583201, p.4]
- **data：** 训练数据来自 dbAMP、AMP Scanner 和 DRAMP，去重后共 195,121 条序列，长度上限 40 aa，不足部分用 padding token 补齐。
  - 证据：[doi:10.1101/2024.03.03.583201, p.3]
- **data：** 生成与评估阶段从 AMP-Diffusion、HydrAMP、PepCV AE、AMPGAN 各采样 50,000 条序列进行比较；生成长度随机在 15–40 aa 之间。
  - 证据：[doi:10.1101/2024.03.03.583201, p.3]；[doi:10.1101/2024.03.03.583201, p.8]
- **data：** 若序列含有 X，作者在 HydrAMP 分类器评估前将其替换为随机标准氨基酸。
  - 证据：[doi:10.1101/2024.03.03.583201, p.8]
- **declared_resources：** 训练使用 4 张 Nvidia A10 GPU，batch size 64，learning rate 9.93×10−4，Adam 优化器与 cosine learning rate schedule，并通过 100 次 Bayesian optimization 调参。
  - 证据：[doi:10.1101/2024.03.03.583201, p.7]
- **declared_resources：** 实现基于 PyTorch 2.01 和 Python 3.10.10；作者还致谢 Duke Compute Cluster、Oracle Cloud 和 Mark III Systems 的算力支持。
  - 证据：[doi:10.1101/2024.03.03.583201, p.5]；[doi:10.1101/2024.03.03.583201, p.7]
- **limitations：** 作者明确将湿实验验证列为 future work，因此当前证据只能支持候选 AMP 的 in silico 生成，而不能证明真实抗菌活性。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]
- **limitations：** DDIM 采样部分指出步数过小会产生重复区域，且作者承认还需要更系统的序列审查和更快采样算法。
  - 证据：[doi:10.1101/2024.03.03.583201, p.9]；[doi:10.1101/2024.03.03.583201, p.10]
- **limitations：** 结论中还提出需要进一步调参并加入 conditioning data 来优化性能与多样性。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]
- **method：** AMP-Diffusion 先用 ESM-2 将肽序列编码到连续 latent space，再在 forward diffusion 中逐步加入 Gaussian noise，训练 denoiser 在 reverse process 重建原始 embedding，最后通过 ESM-2 language model head 解码回序列。
  - 证据：[doi:10.1101/2024.03.03.583201, p.2]；[doi:10.1101/2024.03.03.583201, p.3]
- **method：** 去噪器采用预训练的 ESM-2-8M attention blocks，并将 positional encoding 作为 time embedding 融入蛋白表示，后接 MLP 进行输出映射。
  - 证据：[doi:10.1101/2024.03.03.583201, p.3]
- **method：** 训练目标是最小化预测 embedding 与原始 x0 之间的 l2 loss；采样时作者也讨论了 DDPM、DDIM 等 sampler。
  - 证据：[doi:10.1101/2024.03.03.583201, p.2]；[doi:10.1101/2024.03.03.583201, p.9]
- **results：** Table 1 中 AMP-Diffusion 的 perplexity 为 12.84±4.53，entropy 为 3.17±0.56，优于 HydrAMP、PepCV AE、AMPGAN；其 Pamp=0.81、Pmic=0.50，也处于四个模型中的较高水平。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]
- **results：** 与真实/训练 AMPs 相比，AMP-Diffusion 的 perplexity 更低（12.84 vs 16.23），entropy 略低于真实集（3.17 vs 3.23），说明生成分布接近但并不完全复现天然 AMPs。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]
- **results：** 理化性质上，生成肽的 pI 和 charge 分布与训练集更接近，而 HydrAMP 和 AMPGAN 的 pI/charge 偏高且部分落在天然分布之外；hydrophobicity 与 aromaticity 整体也与真实 AMPs 相近。
  - 证据：[doi:10.1101/2024.03.03.583201, p.4]；[doi:10.1101/2024.03.03.583201, p.5]
- **results：** PCA/t-SNE 显示生成嵌入与训练嵌入明显聚类重叠，最近邻平均 cosine similarity 为 0.098±0.048；单氨基酸频率里 K 在生成序列中偏高。
  - 证据：[doi:10.1101/2024.03.03.583201, p.8]；[doi:10.1101/2024.03.03.583201, p.9]

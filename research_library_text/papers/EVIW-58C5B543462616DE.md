# Advancing drug–target interaction prediction: a comprehensive graph-based approach integrating knowledge graph embedding and ProtBert pretraining

- **论文 ID：** `EVIW-58C5B543462616DE`
- **期刊 / 来源：** BMC Bioinformatics
- **发表时间：** 2023 Dec 19
- **DOI：** [10.1186/s12859-023-05593-6](https://doi.org/10.1186/s12859-023-05593-6)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 DTIOG：先从异构知识图谱学习 drug/target 的嵌入，再可选地引入 ProtBERT、SMILES 指纹和蛋白理化分组特征，随后通过近邻加权与分类器输出新的 DTI 预测；论文声称该框架在 ENZ、IC、GPCR 上优于若干既有方法，并能给出可验证的候选交互。[doi:10.1186/s12859-023-05593-6, p.1]

## 创新边界

`其新意主要在多源表示融合与基于 KG 的配对嵌入流程，不是新的湿实验平台，也不是直接生成药物分子的设计模型。[doi:10.1186/s12859-023-05593-6, p.4]`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知 drug–target interactions 稀疏、且许多靶标缺少实验结构信息的条件下，构建可利用知识图谱与序列信息的计算方法，以更准确地预测新的 DTI 并辅助药物再定位与候选筛选。[doi:10.1186/s12859-023-05593-6, p.1]

## 方法

- 从药物-靶点/疾病网络学习图嵌入，ProtBert编码序列，融合后以多种分类器预测相互作用。

## 数据与基准

- Enzyme、Ion Channel、GPCR及drug-virus/HDVD相关数据。

## 比较基线

- 图嵌入、异构网络和序列DTI方法及多分类器。

## 结果证据

- 论文报告跨三类靶点超过既有算法；为计算相互作用分类。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 知识图不完整、低相似药物表现有限，负样本与网络泄漏会影响评价。

## 仍未知

- Zenodo 归档是否包含完整可执行代码、环境锁定与数据预处理细节，冻结页未展开。
- 病例验证是否能在前瞻性或独立外部数据上保持同等效果，文中未给出。
- 不同数据集上最优分类器与相似度度量的稳定性仍不明确，尤其是低相似 pair 的召回。

## Pi 结构化证据摘录

- **baseline：** 论文明确把 iGRLDTI、DTI-HeNE、ALADIN、BLM-NII 作为主要对比方法，并以 DTIOG-DT 作为跨方法比较的代表变体。[doi:10.1186/s12859-023-05593-6, p.20]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.20]；[doi:10.1186/s12859-023-05593-6, p.31]
- **baseline：** 表格显示 DTIOG 内部最强的常是 DT 或 ETC，而 GradientBoosting、GaussianNB、SGD 往往显著落后，说明分类器选择对最终性能影响很大。[doi:10.1186/s12859-023-05593-6, p.22]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.22]；[doi:10.1186/s12859-023-05593-6, p.23]；[doi:10.1186/s12859-023-05593-6, p.24]；[doi:10.1186/s12859-023-05593-6, p.25]；[doi:10.1186/s12859-023-05593-6, p.27]；[doi:10.1186/s12859-023-05593-6, p.30]
- **baseline：** Table 10 把 DTIOG-DT-KGE/PRTB/FP 与基线并列，整体上 KGE 版本更有竞争力，但 IC 上部分基线（如 DTI-HeNE）也能达到接近甚至更高的单项指标。[doi:10.1186/s12859-023-05593-6, p.32]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.32]
- **data：** 基准数据集来自 Yamanishi 系列：ENZ 包含 346 个 drugs、657 个 proteins 和 2926 条 interactions；IC 为 169/204/1476；GPCR 为 188/94/634。[doi:10.1186/s12859-023-05593-6, p.20]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.20]
- **data：** 作者构建的知识图谱整合了 DrugBank、CTD、GNBR、Hetionet、STRING、UniProt 等来源，声明约有 29 million edges 和 131 类关系。[doi:10.1186/s12859-023-05593-6, p.17]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.17]；[doi:10.1186/s12859-023-05593-6, p.19]
- **data：** 实验以 AUPR、AUC、ACC、MCC、F1 为指标，并在 5 种相似度度量下比较 9 个 DTIOG 变体与多种基线。[doi:10.1186/s12859-023-05593-6, p.21]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.21]；[doi:10.1186/s12859-023-05593-6, p.22]
- **declared_resources：** 作者声明 source code 和 datasets 可通过 Zenodo DOI 10.5281/zenodo.10209331 获取，项目页标注 Linux、Python，并采用 BSD 3-Clause license。[doi:10.1186/s12859-023-05593-6, p.39]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.39]
- **declared_resources：** 致谢中明确提到复用了 DTI-HeNE、BLM-NII、iGRLDTI 和 ALADIN 的源代码，说明实现并非完全从零开始。[doi:10.1186/s12859-023-05593-6, p.39]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.39]
- **declared_resources：** 作者同时声明无外部 funding，且不存在 competing interests。[doi:10.1186/s12859-023-05593-6, p.39]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.39]
- **limitations：** 作者承认该方法依赖相似性和近邻聚合，这会缩小新 DTI 的搜索空间，导致低相似药物-靶标对更容易被漏掉。[doi:10.1186/s12859-023-05593-6, p.36]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.36]
- **limitations：** 作者还指出该框架是 transductive learning，新节点或新样本加入后通常需要重跑模型，而且计算开销高于 inductive 方法。[doi:10.1186/s12859-023-05593-6, p.37]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.37]
- **limitations：** 病例验证主要依赖后续更新的数据库和文献核验，而非新的湿实验，因此证据仍属于回顾性确认。[doi:10.1186/s12859-023-05593-6, p.31]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.31]；[doi:10.1186/s12859-023-05593-6, p.33]；[doi:10.1186/s12859-023-05593-6, p.34]；[doi:10.1186/s12859-023-05593-6, p.35]
- **method：** DTIOG 先把 DTI 网络扩展为加权异构知识图谱，并用 DistMult 学习 drug 和 target 的低维表示，再据此计算 drug–drug 与 target–target 相似度矩阵。[doi:10.1186/s12859-023-05593-6, p.8]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.8]；[doi:10.1186/s12859-023-05593-6, p.18]
- **method：** 在 contextual 路径里，作者把 ProtBERT 作为蛋白序列编码器；在 local 路径里，drug 由 RDKit/Avalon fingerprint 表示，protein 由滑动窗口和生化分组特征表示。[doi:10.1186/s12859-023-05593-6, p.9]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.9]；[doi:10.1186/s12859-023-05593-6, p.13]；[doi:10.1186/s12859-023-05593-6, p.14]
- **method：** 模型再用相似度矩阵和 bipartite DTI matrix 对最近邻加权，形成 Vd_intg、Vt_intg、Vd_test、Vt_test，并拼接成 pair embedding 供后续分类。[doi:10.1186/s12859-023-05593-6, p.10]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.10]；[doi:10.1186/s12859-023-05593-6, p.11]；[doi:10.1186/s12859-023-05593-6, p.15]
- **method：** 预测阶段使用多个分类器评估同一 pair embedding，包括 RF、DT、MLP、KNeighbors、Bagging、GradientBoosting、GaussianNB、SGD 和 ETC，并把任务形式化为二分类。[doi:10.1186/s12859-023-05593-6, p.12]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.12]；[doi:10.1186/s12859-023-05593-6, p.21]
- **results：** 在 KGE 设定下，DTIOG-DT 通常是 ENZ、IC、GPCR 三个数据集里最强或接近最强的变体；例如 cosine 下的 AUPR 分别达到 0.976、0.972、0.968。[doi:10.1186/s12859-023-05593-6, p.23]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.23]；[doi:10.1186/s12859-023-05593-6, p.24]；[doi:10.1186/s12859-023-05593-6, p.25]
- **results：** 在 ProtBERT 设定下，DTIOG-DT 对 ENZ 与 IC 仍保持很强表现，但 GPCR 上常由 DTIOG-ETC 领先；个别表格里不同分类器与相似度组合的最优项会变化。[doi:10.1186/s12859-023-05593-6, p.27]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.27]；[doi:10.1186/s12859-023-05593-6, p.28]；[doi:10.1186/s12859-023-05593-6, p.29]；[doi:10.1186/s12859-023-05593-6, p.30]
- **results：** 与 iGRLDTI、DTI-HeNE、ALADIN、BLM-NII 的比较中，DTIOG 的 KGE 版本整体更强，尤其在 AUPR 上经常占优，但并非所有数据集和全部指标都形成单向压制。[doi:10.1186/s12859-023-05593-6, p.31]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.31]；[doi:10.1186/s12859-023-05593-6, p.32]
- **results：** 病例研究里，ENZ、GPCR、IC 的 top-10 预测分别有 5、10、6 个被更新数据库或文献支持，说明该方法可产出若干可核验候选。[doi:10.1186/s12859-023-05593-6, p.31]
  - 证据：[doi:10.1186/s12859-023-05593-6, p.31]；[doi:10.1186/s12859-023-05593-6, p.33]；[doi:10.1186/s12859-023-05593-6, p.34]；[doi:10.1186/s12859-023-05593-6, p.35]

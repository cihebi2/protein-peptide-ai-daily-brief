# Enhancing cross-context generalization in drug perturbation prediction with a multimodal conditional diffusion framework

- **论文 ID：** `EVIW-22F27BE7269D0426`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2026 Jun 30
- **DOI：** [10.1093/bioinformatics/btag482](https://doi.org/10.1093/bioinformatics/btag482)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文提出 PertDiff：一个把 control expression、药物分子图表示和 LLM 生成的细胞语义描述联合起来的条件扩散框架，用于预测全转录组 perturbation，并将该预测结果用于药物敏感性分类、IC50 回归、癌症药物再定位和临床验证。

## 创新边界

`主要创新在于预测与表征层，不是直接生成或优化新分子候选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在给定对照基因表达和药物信息时，预测药物诱导的转录组扰动，并检验这种扰动表征能否支撑跨药物、跨细胞系泛化以及下游药物敏感性、再定位和临床响应分析。

## 方法

- 对LINCS处理后的978基因表达建模；以细胞文本嵌入为query、药物图表示和对照表达为条件，扩散生成扰动表达。

## 数据与基准

- CMAP LINCS 2020，plate-matched control经MODZ聚合；CTRP四细胞系267个未见药物、803个药物-细胞组合用于敏感性关联。

## 比较基线

- GEARS/scGen/ChemCPA类扰动预测器及去除细胞语义、药物图和扩散组件的消融。

## 结果证据

- 论文报告在多种未见药物/细胞拆分上优于所选基线，并用于胰腺癌转录签名反转和临床反应一致性分析；这些属于回顾性计算验证。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- LINCS仅测978 landmark基因；LLM细胞描述可能继承语料偏差，临床一致性不是前瞻试验证据；跨剂量/时间泛化仍有限。

## 仍未知

- LLM 生成并人工核验的 cell description 具体模板与标注标准未在正文展开。
- Supplementary Materials 中的超参数、筛选规则和完整重复实验结果未在当前页面中展示。
- 临床验证是回顾性分析，模型用于前瞻性患者分层的真实效果仍未知。

## Pi 结构化证据摘录

- **baseline：** 主 benchmark baselines 是 Prnet、CrossDiT、CatCrossDiT 和 TranSiGen，用于横向比较跨药物与跨细胞系泛化性能。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.6]
- **baseline：** Ablation baseline 为 PertDiff-no，即移除 cell description 后的同构版本，用来评估文本语义条件的贡献。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.6]
- **baseline：** 药物敏感性与 IC50 任务沿用同一类 RF 下游框架，但输入来自不同 perturbation model 生成的 DEGs，因此这些比较本质上是在比较不同生成模型的表征质量。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.4]；[doi:10.1093/bioinformatics/btag482, p.8]
- **data：** 核心训练与评测数据来自 CMAP LINCS 2020 的转录组扰动谱，作者明确说明使用 plate-matched controls、replicate aggregation 与 landmark gene 输入。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.2]
- **data：** 药物敏感性评估使用 CTRP 和 GDSC2：CTRP 覆盖 4 个 cell lines、267 个 unseen drugs 和 803 个 drug-cell pairs；GDSC2 对应 14 个 cell lines、114 个 drugs 和 1483 个 combinations。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.4]
- **data：** 药物再定位部分使用 1625 个 PRISM 候选药物和 TCGA-PAAD 派生的 pancreatic cancer query signature；临床验证部分使用 GSE20194、GSE32646 和 GSE25055 三个 GEO breast cancer cohorts。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.5]；[doi:10.1093/bioinformatics/btag482, p.9]
- **data：** 论文还明确给出 source code 和 data 的公开链接，分别指向 GitHub 仓库和 Zenodo 归档。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.1]
- **declared_resources：** 论文公开声明 source code 与 data 可通过 GitHub 仓库和 Zenodo 归档获取。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.1]
- **declared_resources：** 建模与评估依赖 pretrained MolGNet、all-MiniLM-L6-v2 Sentence-Transformers，以及 CMAP LINCS、CTRP、GDSC2、PRISM、TCGA-PAAD 和 GEO 等公开资源。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.2]；[doi:10.1093/bioinformatics/btag482, p.4]；[doi:10.1093/bioinformatics/btag482, p.5]；[doi:10.1093/bioinformatics/btag482, p.9]
- **declared_resources：** 作者还声明使用 ChatGPT 进行 language refinement，并在致谢中列出国家自然科学基金、陕西省和西安电子科技大学等资助来源。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.11]
- **limitations：** 作者明确指出，978 维 transcriptome 与有限的 164 个 cell lines 形成稀疏数据场景，且 cell-cycle fluctuation 与 batch effects 会增加噪声和随机性。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.11]
- **limitations：** 论文承认 LLM-derived cell descriptions 可能继承其训练语料中的偏差，这会影响表示学习的稳健性。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.11]
- **limitations：** 当前工作主要面向单药、bulk transcriptomics 和回顾性数据分析，作者把 single-cell 数据和 combination therapy 作为未来扩展方向。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.11]
- **method：** 作者使用 Broad 的 CMAP LINCS 2020 处理后数据，保留 10 μM、24 h 样本，采用 MODZ 聚合重复测量，并将表达矩阵缩放到 [-1,1]；最终得到 78,569 个 drug-cell 组合、164 个 cell lines、8,316 个 drugs 和 978 个 landmark genes。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.2]
- **method：** PertDiff 基于 DDPM 条件扩散框架，把控制表达、MolGNet 提取的药物图嵌入以及 LLM 生成并经 all-MiniLM-L6-v2 编码的细胞语义描述联合建模，并通过 cross-attention 与 conditional control network 注入 denoising 过程。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.2]；[doi:10.1093/bioinformatics/btag482, p.3]；[doi:10.1093/bioinformatics/btag482, p.4]
- **method：** 模型采用两阶段训练：先预训练 backbone 重建干净表达，再在引入条件模块后微调；采样阶段使用 1000 步 cosine schedule，并以 MSE 作为优化目标。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.4]
- **method：** 下游任务把 PertDiff 预测的 DEGs 作为特征，分别训练 Random Forest 分类器预测药物敏感性、训练 Random Forest 回归器预测 ln(IC50)，并在重定位场景下使用 Connectivity Map 风格的 connectivity score 排序候选药物。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.4]；[doi:10.1093/bioinformatics/btag482, p.5]
- **results：** 在 cross-drug、cross-cell 和 strict cross-cell 三种设置下，PertDiff 在 Δ-Pearson、Δ-PP@100 和 Δ-NP@100 上都优于 Prnet、CrossDiT、CatCrossDiT 和 TranSiGen。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.6]
- **results：** 论文给出的代表性数值包括 cross-drug 的 Δ-Pearson 0.629、cross-cell 的 0.337、strict cross-cell 的 0.334；作者还报告其相对 TranSiGen 的 R2 提升约 10.2%。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.6]
- **results：** 加入 cell description 后，PertDiff 相比 PertDiff-no 在多个场景持续增益，且 t-SNE/ARI 从 0.643 提升到 0.732，说明语义细胞信息确实改善了 cell-specific separation。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.6]
- **results：** 下游方面，PertDiff 预测的 DEGs 可以支持药物敏感性分类与 ln(IC50) 回归；临床队列中 pCR 样本的 E-distance 始终高于 RD 样本，支持其与真实药物响应的一致性。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.8]；[doi:10.1093/bioinformatics/btag482, p.9]
- **results：** 在 pancreatic cancer 重定位筛选中，前 17 个候选药物里有 10 个得到文献支持，包含多种 HDAC inhibitors 以及 gambogic acid、thiostrepton、BNTX 和 peruvoside。
  - 证据：[doi:10.1093/bioinformatics/btag482, p.9]；[doi:10.1093/bioinformatics/btag482, p.10]

# Accurate de novo design of heterochiral protein–protein interactions

- **论文 ID：** `EVIW-762DC9B38FFF15C5`
- **期刊 / 来源：** Cell Res
- **发表时间：** 2024 Aug 14
- **DOI：** [10.1038/s41422-024-01014-2](https://doi.org/10.1038/s41422-024-01014-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出并验证了一套 mirror-image 设计流程，可在 L-Pep-1、TrkA、IL-6 三个目标上从头设计 D-protein binders，并获得纳摩尔级亲和力、细胞抑制活性和 2.0 Å 晶体结构确认。

## 创新边界

`作者的创新边界主要是把既有蛋白设计、yeast display 和化学合成流程镜像化到 D-protein binders；冻结证据只支持该文的自洽演示，不能独立验证全球首创性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在缺乏异手性复合物结构先验的情况下，如何从目标 L-protein/L-peptide 结构出发，准确设计能结合指定表面区域的 D-protein binder。

## 方法

- 把L靶结构镜像为D靶；RifDock生成相互作用场并设计L-binder；展示筛选/亲和力优化后化学合成对应D-binder；结构与细胞功能验证。

## 数据与基准

- 人工L肽、TrkA D5和IL-6三个靶标；50–65 aa设计；PDB 8GQP和7YH8晶体结构。

## 比较基线

- 镜像噬菌体展示和传统L-protein binder设计作为背景；正文未提供同预算端到端算法基线。

## 结果证据

- 论文报告多个纳摩尔binder；D-19437/L肽晶体与设计模型Cα RMSD 0.6 Å；TrkA/IL-6 binder在细胞实验中抑制下游信号并显示高稳定性。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 靶点仅三个、设计长度最多65 aa；仍需要展示筛选和定向进化；更大靶点适用性只是作者展望。

## 仍未知

- Supplementary information 中的 Tables S1-S5 和 Dataset S1 未在页面文本中逐项展开，细节无法完全复核。
- D-TrkA 与 D-IL-6 的最终复合物缺少与 D-19437L-Pep-1 同等级的晶体结构验证。
- 作者自称为“first demonstration”，但冻结稿没有独立先验艺术核验。

## Pi 结构化证据摘录

- **baseline：** 作者先用已知 heterochiral PDB complexes 计算 Rosetta 指标，并发现其界面能量与几何度量大致落在 L-protein complexes 的范围内，作为设计可行性的经验基线。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]
- **baseline：** 文中把“直接合成并测试 D-binder 对 L-target”的路线作为对照，认为先在 mirror-image space 评估 L-binder 再镜像转化为 D-binder 更高通量。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]
- **baseline：** 与传统 mirror-image phage display 相比，本文强调的是针对指定表面区域的计算设计加 yeast display 筛选，而不是仅依赖随机库筛选。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.1]；[doi:10.1038/s41422-024-01014-2, p.2]
- **data：** 实验靶标包括人工设计的 L-Pep-1，以及人源 TrkA D5 domain 和 human IL-6；对应的 D-Pep-1、D-TrkA、D-IL-6 也被化学合成并加上 N-terminal biotin。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]；[doi:10.1038/s41422-024-01014-2, p.3]；[doi:10.1038/s41422-024-01014-2, p.9]
- **data：** 作者为三组靶标分别生成了 7703 个 Pep-1 候选、4642 个 TrkA 候选和 13,158 个 IL-6 候选，用于后续高通量筛选。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]；[doi:10.1038/s41422-024-01014-2, p.8]
- **data：** NGS 记录了各轮筛选后的富集序列数量，且数据支撑了后续命中体的选择、突变富集和细胞/生化验证。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.10]；[doi:10.1038/s41422-024-01014-2, p.11]
- **data：** 结构数据已提交到 PDB，条目为 8GQP 和 7YH8；设计脚本放在 Supplementary information 的 Dataset S1。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.11]
- **declared_resources：** PDB 结构条目已公开为 8GQP 和 7YH8，可作为结构复用资源。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.11]
- **declared_resources：** 作者声明设计脚本位于 Supplementary information 的 Dataset S1，主文同时称全部数据都可在正文或补充材料中找到。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.11]
- **limitations：** 本文实验展示的 D-protein binder 长度上限为 65 aa，因此虽然作者讨论了更大靶标，但当前证据仍主要覆盖 mini-protein scaffold。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.7]
- **limitations：** 冻结稿只对 D-19437L-Pep-1 / L-Pep-1 给出了高分辨率晶体结构，TrkA 和 IL-6 的最终 D-binder 缺少同等级结构验证。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.5]；[doi:10.1038/s41422-024-01014-2, p.6]
- **limitations：** 目标特异性并非绝对：D-57445-evoL-TrkA 与 L-Pep1 之间仍观察到一定交叉结合信号。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.5]
- **method：** 先将 L-protein target 进行坐标镜像得到 D-target，再用 RIF、RifDock、PatchDock、MotifGraft 和 Rosetta FastDesign 在镜像空间设计与优化 50–65 aa 的 miniprotein binders。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]；[doi:10.1038/s41422-024-01014-2, p.8]
- **method：** 针对 L-Pep-1、D-TrkA 和 D-IL-6 分别构建并筛选大规模 L-binder 库，随后把获得的高分子序列逆向化学合成为对应 D-binder。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.2]；[doi:10.1038/s41422-024-01014-2, p.3]；[doi:10.1038/s41422-024-01014-2, p.9]；[doi:10.1038/s41422-024-01014-2, p.10]
- **method：** 用 yeast display + 2–4 轮 FACS + NGS 对设计库进行高通量富集，再将命中序列在 E. coli 中表达纯化，并用 BLI、ITC、MST 和 SEC 复核结合。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.3]；[doi:10.1038/s41422-024-01014-2, p.4]；[doi:10.1038/s41422-024-01014-2, p.10]
- **method：** 对 TrkA 和 IL-6 的初始命中体进一步做 site saturation mutagenesis、组合突变和 error-prone PCR，以获得更高亲和力的 evolved binders。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.3]；[doi:10.1038/s41422-024-01014-2, p.10]
- **method：** 对 D-protein binders 进行化学合成、折叠、CD、热稳定性、蛋白酶耐受、细胞信号抑制和晶体学验证，以评估其构象与功能。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.4]；[doi:10.1038/s41422-024-01014-2, p.5]；[doi:10.1038/s41422-024-01014-2, p.6]；[doi:10.1038/s41422-024-01014-2, p.9]；[doi:10.1038/s41422-024-01014-2, p.10]
- **results：** 初始命中体的 BLI 亲和力分别为 L-19437D-Pep-1 22 nM、L-57445D-TrkA 152 nM、L-25367D-IL-6 25 nM。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.3]
- **results：** 定向进化后，L-57445-evoD-TrkA 和 L-25367-evoD-IL-6 的 BLI 亲和力提升到 7.8 nM 和 0.7 nM。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.3]
- **results：** 镜像合成后的 D-binder 与对应 L-target 的结合保持在纳摩尔到百纳摩尔范围内；其中 D-57445-evoL-TrkA 和 D-25367-evoL-IL-6 分别达到 1 nM 和 3 nM。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.4]
- **results：** D-protein binders 具有高热稳定性和强蛋白酶耐受性，且与对应 L-target 可在 SEC 中共洗脱，说明复合物在溶液中可形成。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.4]
- **results：** 细胞实验显示 D-57445-evoL-TrkA 可抑制 NGF-TrkA 下游 Akt/Erk 磷酸化并抑制 TF-1 增殖，EC50 约 120 nM；D-25367-evoL-IL-6 抑制 IL-6-IL-6R 信号，EC50 约 1 nM。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.5]；[doi:10.1038/s41422-024-01014-2, p.6]
- **results：** D-19437L-Pep-1/L-Pep-1 的 2.0 Å 晶体结构与设计模型高度一致，Cα RMSD 为 0.6 Å；对应镜像复合物也被 2.2 Å 结构支持。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.5]；[doi:10.1038/s41422-024-01014-2, p.6]
- **results：** 晶体结构表明 heterochiral helix–helix 接触可通过 hendecad motif 和 knobs-into-holes packing 实现，并给出作者所说的新型异手性螺旋配对模式。
  - 证据：[doi:10.1038/s41422-024-01014-2, p.6]

## 研究问题

蛋白-碳水化合物相互作用实验鉴定昂贵耗时，已有计算方法依赖结构或仅用进化特征（PSSM），性能不足。论文解决仅从蛋白一级序列在残基级分类碳水化合物结合位点。

## 作者主张的贡献

提出 StackCBEmbed：stacking 集成模型融合传统序列特征（PSSM、monogram、二肽组成、ASA/HSE/扭转角、理化性质）与 ProtT5-XL-U50 蛋白语言模型嵌入；声称首次将 pLM 用于蛋白-碳水化合物结合位点预测，客观搜索确定集成架构，集成随机欠采样处理不平衡；两个独立测试集上超越已有 SOTA。

## 创新边界

方法学上是标准的 stacking+特征工程套路，pLM 嵌入+传统特征的组合在其它结合位点预测任务中已被广泛使用，'首次用于碳水化合物' 属于领域迁移而非方法创新；数据集很小（训练 98 条蛋白、~700 结合残基），绝对性能有限（BACC 0.776/0.742）；性能提升幅度属增量。

## 创新点证据卡

- **[p1]** 首次将蛋白语言模型嵌入用于蛋白-碳水化合物结合位点残基级预测
  - 原文："ours is the first attempt to apply protein language model in predicting protein-carbohydrate binding interactions"
- **[p3]** stacking 集成架构通过客观搜索从基预测器集合中确定而非手工设计
  - 原文："The architecture of the ensemble is determined through an objective approach, searching from a set of base predictors"
- **[p3]** 集成随机欠采样缓解残基级严重类别不平衡（1:25）
  - 原文："we have applied an ensemble random undersampling approach for data balancing"

## 方法

- 特征：PSSM(PSI-BLAST 5迭代)、Monogram、DPC、SPIDER3 预测的 ASA/HSE/扭转角、7 种理化性质、ProtT5-XL-U50 残基级嵌入
- Yeo-Johnson 变换+标准化预处理
- stacking 集成：从一组基预测器中通过客观搜索确定架构
- 集成随机欠采样应对残基级类别不平衡（结合:非结合 ≈ 1:25）

## 数据与基准

- benchmark 数据集：98 蛋白（1014 结合残基/25705 非结合，30% 作验证）
- TS49：49 蛋白独立测试（508/13230）
- TS88：88 蛋白第二独立测试（688/26453）
- 源自 PROCARB+Glyco3d，30% 序列同一性去冗余，4.5Å 重原子距离定义结合残基

## 结果证据

- TS49：灵敏度 0.730 / 特异度 0.821 / 平衡准确率 0.776
- TS88：0.666 / 0.818 / 0.742
- 消融显示 pLM 嵌入优于其它单一特征
- 优于 SPRINT-CBH 等先前方法（同一数据集）

## 比较基线

- SPRINT-CBH、CBswing、Gattani et al. 等先前碳水结合位点预测器（文献数值）

## 已知限制

- 训练数据极小（98 蛋白），泛化能力受限
- 残基级二分类，无结构 pose/亲和力信息
- 绝对性能平庸（BACC<0.8）
- 未使用结构信息（AF2 结构现在易得）

## 待复核未知项

- stacking 的最终基预测器组合与元分类器细节
- 与结构基方法（如 AF3 界面预测）的对比缺失
- web server 是否提供

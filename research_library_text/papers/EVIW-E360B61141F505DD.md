## 作者主张的创新点

作者构建了一个模块化的描述符-随机森林评估管线，系统比较多种蛋白和化学描述符及其消融对照，给出不同数据规模与数据统计条件下的性能规律，并指出 esm-2 与化学 Rcpi 在相应场景下最有价值。

## 创新边界

`核心新意在系统性基准评测与消融分析，不在提出新的候选生成或优化算法；没有湿实验验证，也没有证据表明作者证明了全球最优新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在七个特定酶家族的既有活性数据上，比较蛋白与化学描述符对随机森林预测酶-化学相互作用/底物活性的帮助，并评估其在新关系、新酶和新化学三种设定下的泛化能力。

## Pi 结构化证据摘录

- **baseline：** LPOT/LCOT 使用 random model 和 activity model 作为无描述符基线，其中前者只按训练集活性比例随机输出，后者按训练集里化学物的总活性排序。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **baseline：** RF with no descriptor 是内部消融基线，用来检验去掉蛋白和化学信息后模型还能保留多少预测能力。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **baseline：** 作者还把默认 DLKcat 作为回归参照，但其 R2 被描述为接近 0，近似随机。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **data：** 数据来自原始文献与公开来源整理，连续活性值、SMILES/2D 化学结构以及蛋白序列或 accession 都被重新汇编进统一数据流程。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]
- **data：** 七个数据集分别是 esterase、hadsf、bkace、nitrilase、olea、fdh2 和 gt，规模从 12 个酶到 216 个酶、从 15 个化学物到 167 个化学物不等。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.2]
- **data：** 作者用 activity ratio、AOIE、AOIC、top-5 protein similarity 和 top-5 chemical similarity 描述数据集结构，并区分工业型与生理型底物库。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]
- **data：** 论文明确给出数据集与 curation scripts 的下载入口 `https://github.com/ZOOEEER/ECI-data`。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]
- **declared_resources：** 论文提供了 `https://github.com/ZOOEEER/ECI-data` 作为数据集与 curation scripts 的公开入口。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]
- **declared_resources：** 实现与特征生成依赖 iFeature、ESM-2、ProtDCal、Swiss-Model、ESM-Fold、Rcpi、scikit-learn、optuna、RDKit、PubChem 和 SciPy 等工具。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]；[doi:10.1016/j.synbio.2024.02.006, p.4]；[doi:10.1016/j.synbio.2024.02.006, p.5]
- **declared_resources：** 补充材料中还包含 descriptor pipeline、Protdcal 项目文件以及相关 R / Python 脚本说明，但正文未展开全部细节。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.4]；[doi:10.1016/j.synbio.2024.02.006, p.5]
- **limitations：** 作者明确指出定量预测仍然困难，回归任务整体表现不佳，部分数据集的 R2 偏低。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **limitations：** 论文认为当前蛋白结构嵌入方式还不够精细，ProtDCal 与序列描述符差异不大，融合后也没有继续提升。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.8]
- **limitations：** 作者在结论中承认模型泛化评估仍是开放问题，并建议把催化基序或 pocket 等结构信息更好地并入预训练序列模型。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.9]
- **method：** 研究采用文献整理的七个酶家族数据集，并用 10-fold cross-validation 分别模拟 LOOT、LPOT 和 LCOT 三种评估场景。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]
- **method：** 蛋白侧构建了 iFeature、ESM-2、ProtDCal、Swiss-Model、ESM-Fold 等描述符，并用 shuffle 与 permutation 生成随机化对照；化学侧使用 Rcpi。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.4]；[doi:10.1016/j.synbio.2024.02.006, p.5]
- **method：** 主模型是 scikit-learn 的 Random Forest，超参数用 optuna 优化；LPOT 和 LCOT 还加入 random model 与 activity model 作为无描述符基线。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **method：** LOOT 使用 R2 与 MAE 评估回归，用 AUPR 与 AUROC 评估分类；LPOT 和 LCOT 主要报告分类指标。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.3]；[doi:10.1016/j.synbio.2024.02.006, p.4]
- **results：** 在 LOOT 新关系评估中，RF with all descriptors 在 7 个数据集里的 5 个上取得最佳且显著更优的结果，说明蛋白与化学描述符的贡献依赖具体数据集。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.5]
- **results：** 在 LPOT 新酶评估中，蛋白描述符主要提升 esterase、hadsf 和 bkace 这三个较大数据集，而四个较小数据集的增益有限；化学描述符在该场景几乎无效。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.6]；[doi:10.1016/j.synbio.2024.02.006, p.7]
- **results：** 在 LCOT 新化学评估中，化学描述符在 esterase、hadsf、fdh2 和 gt 上明显改善性能，而蛋白描述符基本没有帮助。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.7]
- **results：** 在蛋白描述符比较中，esm-2 效果最好；shuffle 和 permutation 会明显破坏性能，t-SNE 也显示 esm-2、iFeature、ProtDCal 能较好聚类功能家族。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.8]
- **results：** 模型性能与数据集统计量存在相关性：LPOT 的 AUPR 与 top-5 protein similarity、AOIE、酶数量和 activity ratio 有关系，LCOT 则与 top-5 chemical similarity 和化学数量相关。
  - 证据：[doi:10.1016/j.synbio.2024.02.006, p.8]；[doi:10.1016/j.synbio.2024.02.006, p.9]

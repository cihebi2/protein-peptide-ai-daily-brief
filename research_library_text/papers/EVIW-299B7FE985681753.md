# A deep learning framework for comprehensive prediction of human RNA G-quadruplex-binding proteins

- **论文 ID：** `EVIW-299B7FE985681753`
- **期刊 / 来源：** Bioinformatics（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1093/bioinformatics/btag088](https://doi.org/10.1093/bioinformatics/btag088)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 G4REP：在多种编码与网络结构中比较后，选出 ESM-2 + LSTM 作为最佳分类器，并配套 residue-level 的 G4REP Score 与网页服务器，用于人类蛋白组中的 RG4BP 筛选和局部区域分析。

## 创新边界

`这是序列级 RG4BP 预测与区域提示，不是湿实验发现，也不是蛋白/配体生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

构建一个能够仅从蛋白质一级序列识别人类 RNA G-quadruplex-binding proteins（RG4BPs），并进一步定位潜在结合片段的深度学习框架。

## 方法

- 比较多种序列编码和神经网络，最佳组合使用ESM-2嵌入与LSTM；另结合无序预测及残基组成偏好生成区域评分。

## 数据与基准

- 正例来自文献与QUADRatlas，负例依据文献、UniProt注释和结构特征筛选；并对人蛋白组进行推断。

## 比较基线

- 多种编码/网络组合及既有G4结合蛋白识别思路。

## 结果证据

- 论文报告最佳模型分类准确率86%，并给出2160个高置信RG4BP候选；这些候选仍是计算预测。

## Pi 结构化证据摘录

- **baseline：** 与 OHE 相比，ESM-2 编码在所有架构上都表现更好，因此被视为主要性能基线。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]
- **baseline：** CNN-only 的 Model 5 没有优于 LSTM 相关架构，说明仅靠局部卷积特征不足以达到最佳区分性能。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]
- **baseline：** 作者认为加入 CNN 或 attention 的复杂结构没有带来可测增益，却增加计算成本，因此采用更简单的双层 LSTM 作为最终方案。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]；[doi:10.1093/bioinformatics/btag088, p.7]
- **baseline：** 文中还将 G4REP 与 QUADRatlas、G4FUNNIES 进行资源层面对照，指出前者不直接预测 RG4BP，后者只针对核蛋白且训练条件更窄。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.2]
- **data：** 正类最初由 240 个实验鉴定 RG4BP 和 895 个 QUADRatlas 条目组成，共 1135 条序列。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **data：** 负类由 2015 条高度不可能结合 G4 的蛋白构成，来源于文献搜索、UniProt 功能注释和结构特征筛选。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.2]；[doi:10.1093/bioinformatics/btag088, p.4]
- **data：** 最终平衡数据集为 2192 条序列，其中 1096 条正类和 1096 条负类。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **data：** 数据集划分为训练集 1748、验证集 174、测试集 270，并保持类内平衡。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **data：** 人类参考蛋白组包含 20,435 条 canonical 序列，SG 参考集包含 473 条人类蛋白。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **data：** ESM-2 采用的是 esm2_t33_650M_UR50D，输出 1280 维 embedding 向量。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]
- **declared_resources：** 源码公开在 GitHub：https://github.com/G4REP/G4REPmodel，并同时给出 Zenodo 归档 DOI。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.1]
- **declared_resources：** G4REP Server 通过 https://schubert.bio.uniroma1.it/g4/ 对外提供，文章也声明数据可在该站点获取。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.1]；[doi:10.1093/bioinformatics/btag088, p.9]
- **declared_resources：** 训练与分析流程使用 Python/PyTorch，并报告了 NVIDIA GeForce RTX 4070 以及服务器端 RTX 3070 + i9-12900KF 的运行环境。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **limitations：** 作者明确指出 ESM-2 embedding 不显式编码更高阶结构，而三维/四级结构可能对 RG4 结合特异性关键。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.8]
- **limitations：** 只有少数蛋白具有实验映射的 RG4 结合子区，因此 G4REP Score 的可解释性验证样本数量有限。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.6]
- **limitations：** G4REP Score 的阈值 T 是经验选择，局部区段筛选仍依赖人工设定的门控。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **limitations：** 负类来自规则化筛选而非实验性排除，这意味着标签边界仍主要依赖现有注释与文献证据。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.2]
- **method：** 作者先从已发表文献和 QUADRatlas 汇总正类 RG4BP，再用 UniProt 注释与胞外/分泌等特征筛出很不可能结合 G4 的负类蛋白。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.2]
- **method：** 数据在建模前先去重，再用 MMseqs2 做两轮同源性降冗余：先 90% identity/50% coverage，再 20% identity/50% coverage。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.2]；[doi:10.1093/bioinformatics/btag088, p.3]
- **method：** 作者比较了 OHE 与 ESM-2 两种序列表征，并在输入端对不同长度蛋白做 padding 以统一维度。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.3]；[doi:10.1093/bioinformatics/btag088, p.5]
- **method：** 共设计 5 种 DL 架构，核心以 LSTM 为主，部分变体加入 CNN 和 attention，输出层用 sigmoid 给出 RG4BP 分数。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.3]；[doi:10.1093/bioinformatics/btag088, p.4]
- **method：** 训练使用 Python/PyTorch、BCE loss、Adam（学习率 1e-5）和 batch size 16，并用 early stopping 抑制过拟合。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **method：** 作者还定义了 G4REP Score，把 disorder 预测与 G/S/Y/F/R 残基富集在滑窗中合并，用于提示潜在结合区段。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]
- **method：** 为做下游生物学推断，作者把模型应用到人类参考蛋白组和 473 个 stress granule 相关蛋白，并用 AlphaFold3 建模 FAM98B-RG4 复合物。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.4]；[doi:10.1093/bioinformatics/btag088, p.6]
- **results：** 在验证集上，ESM-2 模型平均 accuracy 为 0.83±0.003，作者最终选择最简单的双层 LSTM 方案作为 G4REP Model。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]；[doi:10.1093/bioinformatics/btag088, p.7]
- **results：** G4REP Model 在测试集上的平均 accuracy 为 0.84±0.013，AUROC 为 0.917±0.004。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]
- **results：** 在长度超出 50–2500 aa 的独立测试集上，性能仅有轻微变化，说明模型对序列长度波动具有一定鲁棒性。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]
- **results：** 将模型应用于人类蛋白组时，552/20,435（约 3%）蛋白得分 >0.95；其中 76% 含无序区，并且无序蛋白显著富集（odds ratio = 2.54，P = 5.7 × 10^-23）。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.5]；[doi:10.1093/bioinformatics/btag088, p.6]
- **results：** 在 473 个 SG 蛋白中，99 个被预测为 >0.95 的高置信 RG4BP，另有 387 个落在 0.5–0.95 区间，提示与 stress granule 存在明显关联。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.6]
- **results：** 高置信 RG4BP 的组成分析显示，除 Arg/Gly 外还富集 Asn/Gln、Phe/Tyr，并出现 GGY、GGF 等 triplets。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.6]
- **results：** AlphaFold3 对 FAM98B-RG4 的建模支持 cap-like 与 groove 交互模式，和已知 G4 识别机制一致。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.6]
- **results：** G4REP Score 能在 FMR1 的 RGG-box 以及 DHX36 的 N 端区域定位到已知 RG4 结合片段。
  - 证据：[doi:10.1093/bioinformatics/btag088, p.6]

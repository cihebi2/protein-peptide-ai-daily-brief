# UniKP: a unified framework for the prediction of enzyme kinetic parameters

- **论文 ID：** `EVIW-8DA30E5B97E9FAFF`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2023 Dec 11
- **DOI：** [10.1038/s41467-023-44113-1](https://doi.org/10.1038/s41467-023-44113-1)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 UniKP/EF-UniKP 统一框架：用预训练蛋白语言模型和 SMILES Transformer 表征酶与底物，再用 Extra Trees 与线性融合实现酶动力学参数预测；同时通过环境因子建模与样本重加权提升 kcat 预测，并将模型用于 TAL 挖掘与定向进化验证。

## 创新边界

`创新边界主要在预测框架统一、环境因素融合与候选筛选应用，不应解读为新的蛋白基础模型或新的实验测定平台。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何仅依据酶序列与底物结构，统一且更准确地预测 kcat、Km 和 kcat/Km，并在环境因素与长尾分布存在时仍能支持高活性酶候选筛选。

## 方法

- 预训练语言模型编码蛋白与底物；三类参数回归；EF-UniKP两层环境模型；四种重加权。

## 数据与基准

- UniProt序列与BRENDA、SABIO-RK实验动力学记录。

## 比较基线

- DLKcat等单参数模型、无环境因素模型、不同重加权策略。

## 结果证据

- 论文报告统一框架在三类参数任务上改善预测，并以EF-UniKP提升含pH/温度的kcat建模。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 实验参数稀缺且条件异质；论文承认现有模型对实际酶发现/定向进化影响仍有限。

## 仍未知

- 对其他酶家族和更广泛底物集合的泛化是否同样稳定，文中没有系统验证。
- TAL 之外的 wet-lab 候选筛选是否能保持相同命中率，证据仍有限。
- 公开代码与数据虽已给出，但完整复现实验流程所需的环境与随机种子细节未在正文中全部展开。

## Pi 结构化证据摘录

- **baseline：** 作者将 UniKP 与 16 个传统机器学习模型和 2 个深度学习模型比较，结果显示 Extra Trees 最优，而 CNN 和 RNN 明显较弱。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.2]；[doi:10.1038/s41467-023-44113-1, p.10]
- **baseline：** 在 Km 任务上，作者对照了先前的 state-of-the-art 模型；在 kcat/Km 任务上，则对照了由单独 kcat 与 Km 预测再相除的方案。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.6]；[doi:10.1038/s41467-023-44113-1, p.12]
- **baseline：** 作者还用 geometric mean 方法检查潜在数据泄漏，报告称 UniKP 仍然明显优于该对照。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.3]
- **data：** DLKcat 经过过滤后保留 16,838 条样本，覆盖 7,822 个蛋白、2,672 个底物，并按 90/10 比例随机划分且重复五次。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.1]；[doi:10.1038/s41467-023-44113-1, p.9]
- **data：** 作者新构建的环境数据集中，pH 数据集含 636 条样本、温度数据集含 572 条样本，Km 数据集含 11,722 条样本，kcat/Km 数据集含 910 条样本。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.4]；[doi:10.1038/s41467-023-44113-1, p.6]；[doi:10.1038/s41467-023-44113-1, p.9]
- **data：** 这些数据分别来自 UniProt、PubChem 和 BRENDA 等公开来源，且 pH 范围为 3–10.5、temperature 范围为 4–85。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.4]；[doi:10.1038/s41467-023-44113-1, p.12]
- **declared_resources：** 实现使用 torch v1.10.1+cu113 和 sklearn v0.24.2/1.1.1，并在 Ubuntu 20.04.5、64 核、4×NVIDIA GeForce RTX 3080 的服务器上训练。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.9]；[doi:10.1038/s41467-023-44113-1, p.10]
- **declared_resources：** 论文依赖 ProtT5-XL-UniRef50 与 SMILES Transformer 作为预训练表示资源，并引用 BRENDA、UniProt、PubChem、DLKcat 和 KM_prediction 等公开资源。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.1]；[doi:10.1038/s41467-023-44113-1, p.9]；[doi:10.1038/s41467-023-44113-1, p.12]
- **declared_resources：** 作者在 page 12 明确给出 GitHub 仓库与 Zenodo 归档，说明代码和数据均已公开提供。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.12]
- **limitations：** 作者明确指出当前 kcat 预测仍不够准确，主要受限于样本量不足和数据长尾偏斜。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.9]
- **limitations：** 作者也承认重加权只能带来有限改善，约 6.5%，因此需要更多实验测得的高质量动力学数据。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.5]；[doi:10.1038/s41467-023-44113-1, p.9]
- **limitations：** 作者提出未来可结合 transfer learning、reinforcement learning 和小样本学习，但这仍属于后续工作而非当前模型已验证能力。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.9]
- **method：** UniKP 先用 ProtT5-XL-UniRef50 编码酶序列、用 SMILES Transformer 编码底物 SMILES，再将两类 1024 维表示拼接后交给 Extra Trees 做回归预测。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.2]；[doi:10.1038/s41467-023-44113-1, p.9]；[doi:10.1038/s41467-023-44113-1, p.10]
- **method：** EF-UniKP 采用两层结构：基础层同时训练不含环境信息的 UniKP 与加入 pH 或 temperature 的 Revised UniKP，元层再用线性回归融合两者输出。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.4]；[doi:10.1038/s41467-023-44113-1, p.9]
- **method：** 作者还系统测试了 DMW、CSW、CBW 和 LDS 四类重加权方法，用来缓解 kcat 数据长尾分布对高值预测的影响。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.5]；[doi:10.1038/s41467-023-44113-1, p.10]；[doi:10.1038/s41467-023-44113-1, p.11]
- **results：** 在 DLKcat 上，UniKP 五次随机划分的平均 R2 达到 0.68，测试集 PCC 达到 0.85，并在更严格的未见酶/底物划分上仍保持 PCC 0.83。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.3]
- **results：** UniKP 对野生型与突变体都能较好区分，测试集 PCC 分别为 0.78 和 0.91，并且在不同 EC/底物组合上也优于对照方法。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.3]
- **results：** EF-UniKP 在 pH 和 temperature 数据上都优于单层模型，而 CBW 使高 kcat 子集的 RMSE 比初始 UniKP 下降 6.5%。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.4]；[doi:10.1038/s41467-023-44113-1, p.5]
- **results：** Km 预测达到 R2=0.530、PCC=0.73；kcat/Km 预测达到 R2=0.65、PCC=0.81、RMSE=1.07，而用独立 kcat 与 Km 模型组合计算出的 kcat/Km 仅有 PCC=-0.02。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.6]；[doi:10.1038/s41467-023-44113-1, p.9]
- **results：** 在 TAL 挖掘与定向进化实验中，AsTAL 的 kcat 达到 448.8 s^-1，RgTAL-489T 的 kcat/Km 达到 1150 mM^-1 s^-1；EF-UniKP 也筛出了 5 个都优于 TALclu 的候选。
  - 证据：[doi:10.1038/s41467-023-44113-1, p.7]；[doi:10.1038/s41467-023-44113-1, p.8]

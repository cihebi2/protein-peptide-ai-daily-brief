# Machine learning application to predict binding affinity between peptide containing non-canonical amino acids and HLA-A0201

- **论文 ID：** `EVIW-1064EC94E290F45D`
- **期刊 / 来源：** PLoS One
- **发表时间：** 2025 Jun 27
- **DOI：** [10.1371/journal.pone.0314833](https://doi.org/10.1371/journal.pone.0314833)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `肽与抗菌肽`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出了一套基于 tokenization、SMILES/RDKit、PCA 和 PLS 的机器学习流程，可对含 NCAAs 的 peptide-HLA-A*02:01 结合亲和力做数值预测，并与 36 个常见 regressors 做了比较。

## 创新边界

`新意主要在 NCAA 覆盖与结构化特征编码组合；它是 property prediction / representation 的应用，不是新 wet-lab 结果，也不是全新优化或 docking 算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在包含 non-canonical amino acids (NCAAs) 的 peptide 中，预测其与 HLA-A*02:01 的 binding affinity，并把该任务做成可用于 immunogenic peptide 设计的定量回归问题。

## 方法

- 从含NCAA肽构建分子/序列特征，训练多种回归模型，以五折交叉验证选择模型。

## 数据与基准

- 训练标签来自实验结合数据及IEDB等公开资源，聚焦HLA-A0201和含NCAA肽。

## 比较基线

- 常用机器学习回归器及已有MHC-I结合预测方法。

## 结果证据

- 论文报告五折交叉验证R2为0.477、RMSE为0.735；表现为中等计算拟合，不能宣称可靠设计命中。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 数据量与NCAA覆盖有限，只针对单个HLA等位基因；随机交叉验证可能不能代表新骨架/NCAA组合。

## 仍未知

- 仓库内容与论文结果是否逐行复现未知。
- 是否存在独立 external test set 未说明。
- 对其他 HLA allele 和更多 NCAA 化学空间的泛化未知。
- 不同 fold 的性能波动提示稳定性仍不确定。

## Pi 结构化证据摘录

- **baseline：** 作者把该方法与 NetMHCpan、MHCflurry 这类 sequence-based predictors 和 Rosetta FlexPepDock 这类 structure-based docking 方法做概念对比。
  - 证据：[doi:10.1371/journal.pone.0314833, p.2]；[doi:10.1371/journal.pone.0314833, p.6]
- **baseline：** 在实证比较中，PLS 还与 Lazy Predict 里的 36 个 regressors 逐折对照。
  - 证据：[doi:10.1371/journal.pone.0314833, p.5]
- **baseline：** 作者强调其方法无需提供完整 MHC structure，因此比 docking 风格流程更快、人工干预更少。
  - 证据：[doi:10.1371/journal.pone.0314833, p.6]
- **baseline：** 作者也指出，性能在不同 fold 上不稳定，单一模型并不总是最优。
  - 证据：[doi:10.1371/journal.pone.0314833, p.6]；[doi:10.1371/journal.pone.0314833, p.8]；[doi:10.1371/journal.pone.0314833, p.10]
- **data：** 论文声明相关数据可从 IEDB 和作者的 GitHub repository 获取。
  - 证据：[doi:10.1371/journal.pone.0314833, p.1]；[doi:10.1371/journal.pone.0314833, p.3]
- **data：** 训练集最终只保留 166 条 peptide-HLA-A*02:01-IC50 记录，且每条 peptide 至少含一个 NCAA。
  - 证据：[doi:10.1371/journal.pone.0314833, p.3]
- **data：** 数据中的 token 统计显示共有 20 个 canonical tokens 和 28 个 non-canonical tokens。
  - 证据：[doi:10.1371/journal.pone.0314833, p.4]
- **data：** 作者只使用 HLA-A*02:01 这一类 MHC 以保证一致性，没有扩展到其他 allele。
  - 证据：[doi:10.1371/journal.pone.0314833, p.3]；[doi:10.1371/journal.pone.0314833, p.7]
- **declared_resources：** 相关数据与代码被声明公开在 GitHub repository `https://github.com/meilerlab/ML_PLS_MHC_peptide_binding_pred`。
  - 证据：[doi:10.1371/journal.pone.0314833, p.1]
- **declared_resources：** 原始数据来自 IEDB 的公开导出表，而不是作者新生成的 wet-lab 数据。
  - 证据：[doi:10.1371/journal.pone.0314833, p.3]
- **declared_resources：** 特征生成依赖 RDKit、PCA 和 Lazy Predict 等现成工具。
  - 证据：[doi:10.1371/journal.pone.0314833, p.4]；[doi:10.1371/journal.pone.0314833, p.5]
- **declared_resources：** NCAA 结构的确认借助文献与 IEDB Epitope IRI，并用 SMILES 表示化学结构。
  - 证据：[doi:10.1371/journal.pone.0314833, p.4]
- **limitations：** 作者明确指出训练和测试数据规模都较小，可能限制模型性能与稳健性。
  - 证据：[doi:10.1371/journal.pone.0314833, p.7]
- **limitations：** IEDB 中带 quantitative binding values 且含 NCAA 的条目本来就很少，数据稀缺是核心瓶颈。
  - 证据：[doi:10.1371/journal.pone.0314833, p.7]
- **limitations：** 模型目前只覆盖 HLA-A*02:01，扩展到其他 MHC allele 仍是 future work。
  - 证据：[doi:10.1371/journal.pone.0314833, p.7]
- **limitations：** R2 会受到小测试集、低 y-value variance 和 outliers 影响，折间波动较明显。
  - 证据：[doi:10.1371/journal.pone.0314833, p.6]
- **method：** 从 IEDB 导出的 100,141 行表中筛选出至少含一个 NCAA、且有 quantitative measurement、HLA-A*02:01、Response Measured 为 IC50(nM) 的样本，最终得到 166 条数据。
  - 证据：[doi:10.1371/journal.pone.0314833, p.3]
- **method：** 把 peptide 序列按 amino acid tokenize，并把 NCAA 的结构经文献与 Epitope IRI 核实后转换为 SMILES，再用 RDKit 生成每个 token 的 208 维 physicochemical features。
  - 证据：[doi:10.1371/journal.pone.0314833, p.4]
- **method：** 对 208 维特征做 PCA，将维度降到 10 个主成分，作者称其覆盖 99.75% variance；9-mer peptide 通过补零统一成 100 维输入。
  - 证据：[doi:10.1371/journal.pone.0314833, p.4]
- **method：** 模型输出是 log-transformed IC50(nM)，训练时采用 5-fold cross-validation，并用 PLS 及 Lazy Predict 的 36 个 regressors 做对照。
  - 证据：[doi:10.1371/journal.pone.0314833, p.5]
- **results：** 在 2–10 个 PLS components 中，3 components 的 cross-validated R2 最好，为 0.477，RMSE 为 0.735。
  - 证据：[doi:10.1371/journal.pone.0314833, p.8]
- **results：** 作者报告 PLS 在 5-fold CV 的实际值与预测值之间存在清晰相关，训练集和测试集都表现出较强一致性。
  - 证据：[doi:10.1371/journal.pone.0314833, p.5]
- **results：** 在 36 个 regressors 的比较里，fold-specific 最优模型会变化，ExtraTrees、GradientBoosting、Tweedie 等多次进入前列。
  - 证据：[doi:10.1371/journal.pone.0314833, p.5]；[doi:10.1371/journal.pone.0314833, p.10]
- **results：** 表 3 显示某些单折 test R2 可达到约 0.69，但不同折之间波动较大。
  - 证据：[doi:10.1371/journal.pone.0314833, p.10]

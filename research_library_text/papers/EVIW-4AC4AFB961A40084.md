## 作者主张的创新点

本文提出 ProteinRG，一种层级式蛋白序列生成框架：先用预训练 protein LLM 学习序列表示，再用生成模型依次生成 latent representation 与最终功能蛋白序列，以在数据稀缺场景下提升条件一致性与生成质量。

## 研究问题

功能蛋白序列数据稀缺会限制深度生成模型训练；本文要解决的是在小规模标注数据下，如何生成满足指定功能且分布接近真实样本的 de novo 蛋白序列。

## 方法

- 先生成/扩增sequence representation，再按功能/GO层级条件生成完整蛋白。

## 数据与基准

- 多类功能蛋白；示例指出hexon仅711条unique full-length UniProt序列。

## 比较基线

- 传统生成LM和无regeneration/层级条件模型。

## 结果证据

- 以MSA、t-SNE和3D structure prediction评价生成序列；无表达/功能实验。

## Pi 结构化证据摘录

- **baseline：** 文中对比的基线包括 CVAE、ProGen、OpL-GAN、ProteoGAN，以及一个直接从 function 到 sequence 的 one-stage baseline。
  - 证据：[doi:10.1093/bib/bbag095, p.8]
- **baseline：** 作者将 CVAE 适配到 50 个标签并做 Bayesian optimization，对 ProGen 进行缩小重训，对 OpL-GAN 采用 50 个按标签分别训练的模型，对 ProteoGAN 使用离散标签条件。
  - 证据：[doi:10.1093/bib/bbag095, p.8]
- **baseline：** 这些基线主要用于与 ProteinRG 在 MMD、MRR、AED 和 distribution distance 上做定量比较。
  - 证据：[doi:10.1093/bib/bbag095, p.10]
- **data：** 主要案例数据来自 UniProtKB 的 Lysozyme 与 MDH 序列集，输入由蛋白序列和 keywords/GO annotations 组成；当关键词缺失时，作者用 GO 注释刻画功能。
  - 证据：[doi:10.1093/bib/bbag095, p.2]
- **data：** 为比较 CVAE、ProGen、OpL-GAN 和 ProteoGAN，作者还使用了 157,890 条、50 个 GO 功能标签的较大规模数据集。
  - 证据：[doi:10.1093/bib/bbag095, p.8]
- **data：** 数据可用性部分给出了 GitHub/data 链接，并说明相关数据来自公开域 UniProt 资源。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **declared_resources：** 作者声明计算资源来自 The Research Centre for the Mathematical Foundations of Generative AI (P0046811) at The Hong Kong Polytechnic University。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **declared_resources：** 作者还给出 GitHub/data 链接作为数据可用性说明，但冻结页未明确呈现可复用代码仓库与许可证。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **limitations：** 作者明确指出，若同时生成多个蛋白家族，就需要足够多的 GO 标签来支持 embedding 与分类，这会增加维度和成本。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **limitations：** 作者也承认 ESM-2 的 fine-tuning 方式仍有改进空间，当前流程未对其优化策略做更深入探索。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **limitations：** 对于药物靶向等具体应用，作者仍要求实验室验证生成结果，说明本文证据主要停留在计算与结构预测层面。
  - 证据：[doi:10.1093/bib/bbag095, p.11]
- **method：** ProteinRG 先把高维的 P(X|Y) 分解为 P(R|Y) 与 P(X|R,Y)，通过先生成中间表示 R 再生成序列 X，降低小样本条件生成难度。
  - 证据：[doi:10.1093/bib/bbag095, p.4]
- **method：** Module 1 采用 ESM-2 作为预训练 protein LLM，经过监督微调后从残差块提取 latent representation，并用交叉熵训练 GO 分类任务。
  - 证据：[doi:10.1093/bib/bbag095, p.4]
- **method：** Module 2 使用 DDPM 与 transformer-based network 学习 P(R|Y)，并采用 classifier-free guidance，训练时随机省略 10% 的条件输入。
  - 证据：[doi:10.1093/bib/bbag095, p.5]
- **method：** Module 3 以 CWGAN-GP 生成蛋白序列，并加入多类 auxiliary discriminative classifier 来增强条件一致性与类别区分。
  - 证据：[doi:10.1093/bib/bbag095, p.5]
- **results：** 在 Lysozyme 上，生成序列的 t-SNE 分布接近自然序列，MSA 与 Shannon entropy 也显示出与真实序列相近的保守性，3D 结构预测同样相似。
  - 证据：[doi:10.1093/bib/bbag095, p.5]
- **results：** 在 MDH 上，作者报告生成序列对测试集的 identity 最多可达 95%，局部窗口 identity 可低于 50%，同时 TM-score 与 DDG 分布总体保持一致。
  - 证据：[doi:10.1093/bib/bbag095, p.6]
- **results：** Table 1 显示 Ourmodel 的 MMD=0.034、MRR=0.603、AED=0.006、Distance=0.001，在这些指标上优于对照方法。
  - 证据：[doi:10.1093/bib/bbag095, p.10]
- **results：** 消融分析表明，引入 protein LLM representation 后性能提升，β=175 时最优，而单纯细化 ESM-2 微调并未显著改变生成质量。
  - 证据：[doi:10.1093/bib/bbag095, p.10]

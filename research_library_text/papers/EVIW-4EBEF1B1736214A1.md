# Human-in-the-loop active learning for goal-oriented molecule generation

## 作者主张的创新点

提出一个将 REINVENT 生成循环与 active learning 闭环交织的 HITL 框架，使用 EPIG 等 acquisition criterion 选择最有信息量的高分分子，由人类专家或模拟专家反馈来微调 property predictor，从而提升后续生成的预测对齐、drug-likeness 和 synthetic accessibility。

## 创新边界

`新意主要在闭环工作流、查询策略和反馈加权方式；它不是新的分子生成器，也不是新的 wet-lab assay，而是围绕 REINVENT、RF predictor、EPIG 和 Metis GUI 的方法组合与流程设计。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在小样本、分布漂移和生成优化闭环下，如何让用于 goal-oriented molecule generation 的 property predictor 持续对齐 oracle/真实评估，减少“高预测分但真实不成立”的失败模式，同时把 human feedback 高效并入迭代流程。

## Pi 结构化证据摘录

- **baseline：** 主要对照是 No Feedback，即 REINVENT 过程中 property predictor 保持静态、不做主动更新。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.7]；[doi:10.1186/s13321-024-00924-y, p.12]；[doi:10.1186/s13321-024-00924-y, p.13]
- **baseline：** 作者还比较了训练集相似性约束、预训练 generative agent，以及 DRD2 场景下的 Platt Scaling 预校准。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.10]；[doi:10.1186/s13321-024-00924-y, p.12]；[doi:10.1186/s13321-024-00924-y, p.16]
- **baseline：** Acquisition 层面的 baseline 包括 random sampling，用于和 EPIG、uncertainty、greedy 直接比较。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.5]；[doi:10.1186/s13321-024-00924-y, p.6]；[doi:10.1186/s13321-024-00924-y, p.12]；[doi:10.1186/s13321-024-00924-y, p.13]
- **data：** LogP 用例使用了从 ChEMBL 提取并清洗后的 250 条 SMILES 训练集、600 条 holdout 测试集，以及长度 2048 的 ECFP6 表示和 penalized LogP oracle。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.7]；[doi:10.1186/s13321-024-00924-y, p.22]
- **data：** DRD2 mono-objective 用例从 ExCAPE 选取 240 条 SMILES，并限制为两个 topological scaffolds，其中 62 条为 active、178 条为 inactive。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.8]；[doi:10.1186/s13321-024-00924-y, p.22]
- **data：** Multi-objective 与 human experiments 同时考虑 DRD2 bioactivity、hERG inactivity 和 QED；人类实验中每位 chemist 每轮评估 50 个分子，并通过 Metis GUI 给出 0–100% 的一致性反馈。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.9]；[doi:10.1186/s13321-024-00924-y, p.10]；[doi:10.1186/s13321-024-00924-y, p.17]
- **declared_resources：** 论文声明可复现 simulations 的 code and data 已公开，并给出 GitHub 仓库与 DRD2/hERG simulators 的 HuggingFace 下载地址。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.23]
- **limitations：** 方法依赖 human collaborators 的可用性与专业度，反馈本身带有主观性和波动性。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.20]
- **limitations：** 作者明确指出，加入 human feedback 会带来额外计算复杂度与流程开销，可能限制大规模 drug discovery 场景中的可扩展性。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.20]
- **limitations：** 真实人类实验里，chemist 1 和 2 对 GUI 问句理解偏差较大，说明 HITL 设计对提示措辞和任务定义非常敏感。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.17]；[doi:10.1186/s13321-024-00924-y, p.18]
- **method：** 方法采用两条交织循环：REINVENT loop 负责用 RNN+policy-gradient 优化 SMILES 生成器，Active Learning loop 在每轮后从高分分子池中选样，由专家评估后再微调 property predictor。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.4]；[doi:10.1186/s13321-024-00924-y, p.5]；[doi:10.1186/s13321-024-00924-y, p.7]
- **method：** 数据获取策略比较了 EPIG、greedy、uncertainty 和 random，其中 EPIG 被定义为面向未来目标分子的 prediction-oriented information gain。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.5]；[doi:10.1186/s13321-024-00924-y, p.6]
- **method：** property predictor 采用 Random Forest，并以 ECFP6 特征、树间方差或熵来表示 uncertainty；对 LogP 场景还使用 double sigmoid 将目标区间映射到 [0,1]。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.3]；[doi:10.1186/s13321-024-00924-y, p.4]；[doi:10.1186/s13321-024-00924-y, p.6]；[doi:10.1186/s13321-024-00924-y, p.22]
- **method：** 人类反馈在更新预测器时按置信度加权，低置信度输入会被降权，从而减轻噪声和含糊判断对 retraining 的影响。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.5]；[doi:10.1186/s13321-024-00924-y, p.10]
- **results：** 在 penalized LogP 场景中，AL 更新显著降低了 predicted 与 oracle 之间的 MAE；EPIG、uncertainty 和 greedy 都优于 No Feedback，且 EPIG 还优于 random sampling。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.12]；[doi:10.1186/s13321-024-00924-y, p.18]
- **results：** 在 DRD2 mono-objective 场景中，所有 acquisition strategy 都改善了 MAE；uncertainty 的 MAE 最好，但 EPIG 与其差异不显著，并且 EPIG 在 QED 和 SA 等实用指标上表现更平衡。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.13]；[doi:10.1186/s13321-024-00924-y, p.14]；[doi:10.1186/s13321-024-00924-y, p.19]
- **results：** 在真实 chemist 反馈实验中，chemist 3 带来最强对齐：DRD2 oracle score、QED 和 total oracle score 上升，MAE 明显下降，同时 novelty 和 uniqueness 保持在 1.0。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.17]；[doi:10.1186/s13321-024-00924-y, p.18]；[doi:10.1186/s13321-024-00924-y, p.19]
- **results：** 与 No Feedback 相比，HITL-AL 还能在多目标设定下保持或改善 internal diversity，并在部分场景下提升 Frag/SNN/FCD 等生成质量指标。
  - 证据：[doi:10.1186/s13321-024-00924-y, p.18]；[doi:10.1186/s13321-024-00924-y, p.19]

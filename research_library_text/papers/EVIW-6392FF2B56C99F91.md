# BPFun: a deep learning framework for bioactive peptide function prediction using multi-label strategy by transformer-driven and sequence rich intrinsic information

- **论文 ID：** `EVIW-6392FF2B56C99F91`
- **期刊 / 来源：** BMC Bioinformatics（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1186/s12859-025-06190-5](https://doi.org/10.1186/s12859-025-06190-5)
- **范围标签：** `Pi 已解析` / `核心相关` / `有静态审计仓库` / `肽与抗菌肽`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 BPFun，多路融合原始序列、one-hot、AAindex1、ProtT5 和 ESM-2 特征，并结合 CNN、Bi-LSTM、self-attention 与数据增强来完成七类 bioactive peptide 多标签功能预测，声称优于现有方法。

## 创新边界

`新颖性主要来自特征融合与多标签分类架构组合，不涉及新肽生成、候选优化或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在类别不平衡、且可能同时具有多种功能的人源 bioactive peptides 中，准确预测七类功能标签，并提升多标签识别与泛化表现。

## 方法

- 五类序列特征并行编码，CNN/BiLSTM融合后多标签输出，数据增强平衡类别。

## 数据与基准

- AMP、ACP、ADP、AHP、AIP、AAP、AOP七类公开数据。

## 比较基线

- MLBP、MPMABP和通用RBRL/MLDF/CLR/RAKEL。

## 结果证据

- 测试accuracy 0.6577、absolute true 0.6573；为多标签计算分类。

## Pi 结构化证据摘录

- **baseline：** 论文主要对比 MLBP、MPMABP、RBRL、MLDF、CLR 和 RAKEL；其中作者把 MLBP/MPMABP 视为最新的多功能 bioactive peptide 方法，前者用 CNN+GRU，后者基于 CNN 和 Bi-LSTM 并加入残差网络。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.2]；[doi:10.1186/s12859-025-06190-5, p.17]；[doi:10.1186/s12859-025-06190-5, p.18]
- **baseline：** 与这些基线相比，BPFun 在独立测试集上对 Precision、Coverage、Accuracy、F1、Absolute true、Absolute false、SEN 和 MCC 都更优；作者同时指出 RBRL、MLDF、CLR 和 RAKEL 在多标签肽预测上的专门性有限。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.18]；[doi:10.1186/s12859-025-06190-5, p.19]；[doi:10.1186/s12859-025-06190-5, p.21]
- **data：** 作者从人源 bioactive peptides 数据中筛出 AMP、ACP、ADP、AHP、AIP、AAP、AOP 七类；用 CD-HIT 0.9 去冗余，统一保留长度至少 5 的序列，并按 80/20 随机划分训练/测试集，最终样本分别为 2409、646、514、868、1678、134、318；其中还包含 154 条双功能肽，没有三重及以上功能样本。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.4]
- **data：** 为缓解类别不平衡，只在训练集上做数据增强：随机用特殊字符 X 替换序列中的一个氨基酸，把增强样本视为同类新序列，测试集不做任何改动。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.4]；[doi:10.1186/s12859-025-06190-5, p.5]
- **declared_resources：** 作者声明代码和数据都可在 GitHub `https://github.com/291357657/BPFun` 获取；训练/测试数据来自多个公开数据库或已发表资源，ProtT5 和 ESM-2 作为预训练特征提取器被直接调用。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.1]；[doi:10.1186/s12859-025-06190-5, p.5]；[doi:10.1186/s12859-025-06190-5, p.6]；[doi:10.1186/s12859-025-06190-5, p.26]
- **limitations：** 作者明确承认，bioactive peptides 数量稀缺且氨基酸组成不规则，单一特征向量不足以充分支持功能预测，因此模型仍依赖多特征融合。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.23]；[doi:10.1186/s12859-025-06190-5, p.24]
- **limitations：** 在分标签结果里，AAP 和 AOP 的表现相对弱于 AMP、AHP、AIP，个别 case study 也出现了 AOP 被误判的情况，说明泛化仍不均衡。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.20]；[doi:10.1186/s12859-025-06190-5, p.21]
- **limitations：** 论文当前主要停留在公开数据集上的计算实验层面，作者也把更高效的特征组合和更好的不平衡处理列为后续工作。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.1]；[doi:10.1186/s12859-025-06190-5, p.25]；[doi:10.1186/s12859-025-06190-5, p.26]
- **method：** BPFun把同一条肽序列同时表示为原始数值序列、one-hot、AAindex1、ProtT5 和 ESM-2 五路输入，并统一到长度 32；不足 5 个残基的序列被删除，超过 32 的序列从前端截断。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.5]；[doi:10.1186/s12859-025-06190-5, p.6]
- **method：** 每一路特征先经独立 CNN 提取局部模式，再接 MaxPooling、Dropout 和 Bi-LSTM；序列分支还保留 embedding 残差连接与 Transformer encoder，以减少信息丢失并捕获长程依赖。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.7]；[doi:10.1186/s12859-025-06190-5, p.8]；[doi:10.1186/s12859-025-06190-5, p.9]；[doi:10.1186/s12859-025-06190-5, p.10]；[doi:10.1186/s12859-025-06190-5, p.11]
- **method：** 五路特征拼接后进入 multi-head self-attention，再接 Bi-LSTM、Flatten 和全连接层，最后用 sigmoid 进行七标签多标签输出，阈值设为 0.5。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.10]；[doi:10.1186/s12859-025-06190-5, p.11]
- **method：** 训练使用 MSE、Adam、learning rate 1e-5 和 L2=0.001；评估指标包括 Precision、Coverage、Accuracy、F1、Absolute true、Absolute false、SEN、SPE 和 MCC。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.12]；[doi:10.1186/s12859-025-06190-5, p.13]
- **results：** 在独立测试集上，BPFun 的 Precision/Accuracy 均为 0.6577，F1 为 0.6578，Absolute true 为 0.6573，Absolute false 为 0.0823，SEN 为 0.6725，MCC 为 0.6369，优于所有对比方法。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.21]
- **results：** 五折交叉验证中，BPFun 也在九项指标上领先，Precision 为 0.658±0.011，MCC 为 0.625±0.013，明显高于 MLBP、MPMABP、RBRL、MLDF、CLR 和 RAKEL。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.19]
- **results：** ROC/PR 结果显示总体 AUC 为 0.923、AP 为 0.726；分标签看，AMP、AHP、AIP 的 AUC 分别为 0.891、0.940、0.926。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.18]；[doi:10.1186/s12859-025-06190-5, p.20]
- **results：** 作者还用 UMAP 和 case study 展示，五种特征联合时的类间分离更清晰，且在若干随机肽上 BPFun 比 MLBP/MPMABP 更稳定。
  - 证据：[doi:10.1186/s12859-025-06190-5, p.16]；[doi:10.1186/s12859-025-06190-5, p.21]

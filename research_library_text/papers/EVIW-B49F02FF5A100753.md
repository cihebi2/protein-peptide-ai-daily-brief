# EPIC-TRACE: predicting TCR binding to unseen epitopes using attention and contextualized embeddings

- **论文 ID：** `EVIW-B49F02FF5A100753`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2023 Dec 9
- **DOI：** [10.1093/bioinformatics/btad743](https://doi.org/10.1093/bioinformatics/btad743)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `有静态审计仓库`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 EPIC-TRACE：把 ProtBERT contextualized embeddings、1-D convolution、multi-head attention 与 TCR / epitope / MHC 的分类特征结合起来，用于 unseen epitope 的 TCR-pMHC 二分类预测，并报告加入低频 epitope 可提升泛化。

## 创新边界

`新意主要在全特征整合与 unseen epitope 设定上的建模，不在新的 wet-lab 实验或候选分子生成。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在训练集中未出现的 epitope 条件下，预测 TCR 是否与 pMHC 结合，并尽量利用 α/β 链、V/J 基因、epitope 序列和 MHC 信息。

## 方法

- 序列ProtBERT嵌入或one-hot；1D卷积提取CDR3/表位基序；多头注意力融合；针对α、β或双链设置三个输出头。

## 数据与基准

- VDJdb和IEDB的人MHC-I阳性对；按任务构造未见表位拆分；负样本由训练/测试内分别打乱TCR和pMHC生成。

## 比较基线

- TCRGP、ERGO、ImRex、TITAN、NetTCR、PanPep、TEIM-Seq等。

## 结果证据

- 论文报告相较多个SOTA模型总体有竞争力，并显示加入低样本表位有助未见表位预测；数值依TPP任务和数据子集而异。

## Pi 结构化证据摘录

- **baseline：** 与 ERGO-II、epiTCR、TITAN、ImRex 相比，EPIC-TRACE 在表 3 的 TPP2 和 TPP3 上整体最好或更优。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.7]
- **baseline：** 与 TCRconv 的 30-epitope 子集比较中，EPIC-TRACE 在三种频率分层上都更强，且 epitope 越稀有优势越明显。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.7]
- **baseline：** 在 yeast display 任务上，未经增强时 EPIC-TRACE 的 AUROC 0.485 仍高于 ERGO-II 的 0.195，但两者都说明该任务很难。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]
- **data：** 正样本来自 VDJdb 和 IEDB，只保留 human 的 MHC class I 数据；基础数据集 D_ab;b 至少包含 b-chain CDR3、epitope、bV/bJ 和 MHC 信息，α-chain 若可得则并入。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]
- **data：** 作者统一了 V/J gene 记法，去掉非功能基因与非规范 CDR3，并在重复样本中保留最精确信息。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]
- **data：** 数据分布高度不均衡：最常见的 3 个 epitope 就占了全部 datapoints 的四分之一以上；低频 epitope 约占 1301 个 epitope 的 75%，但只占 147,346 个 datapoints 中的 2994 个。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]；[doi:10.1093/bioinformatics/btad743, p.6]
- **data：** 外部 yeast display benchmark 使用 5 个经实验验证的 TCR、26 个 epitope、81 个正样本，并构造了 2000 个负样本。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]
- **declared_resources：** 计算资源来自 Aalto Science-IT Project。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]
- **declared_resources：** 数据来源为公开数据库 VDJdb 和 IEDB。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]；[doi:10.1093/bioinformatics/btad743, p.9]
- **declared_resources：** 论文声明预处理数据、D_ab;b 的 cross-validation splits 和 D_ab;a;b 的 full data 可在 GitHub 仓库获取。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.1]；[doi:10.1093/bioinformatics/btad743, p.8]
- **limitations：** 当前 TCR-pMHC 数据极度偏斜，unique TCR 远多于 pMHC，且少数高频 epitope 主导了整体评估。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]；[doi:10.1093/bioinformatics/btad743, p.7]
- **limitations：** 作者明确指出 unseen epitope 任务仍然很难，而且单纯的 minimum edit distance 只能粗略解释难度，不能作为具体 epitope 预测可靠性的精确估计。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.4]；[doi:10.1093/bioinformatics/btad743, p.9]
- **limitations：** yeast display benchmark 很苛刻，因为所有 datapoints 共享相同 HLA 和 V alleles，分类几乎只能依赖 peptide 和 CDR3 序列。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]
- **limitations：** 论文没有报告新的 wet-lab 生成实验，且若不加入少量任务相关正样本，外部 benchmark 的表现明显下降。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]
- **method：** 作者把问题拆成 TPP1–TPP4，并主要评估 TPP3（TCR 和 epitope 都未见）与 TPP2/TPP4 的泛化能力。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.2]；[doi:10.1093/bioinformatics/btad743, p.3]
- **method：** 输入同时包含 TCR 的 CDR3、V/J 基因、epitope 序列和 MHC allele；序列部分通过 ProtBERT 生成 contextualized 表示，再与 one-hot 特征拼接。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.3]；[doi:10.1093/bioinformatics/btad743, p.4]
- **method：** 模型先对 CDR3 和 epitope 做 1-D convolutions，再用 multi-head self-attention 建模交互，最后通过多层感知器输出三个 binary heads。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.4]
- **method：** 训练采用 weighted binary cross-entropy、validation AP 早停、SWA，以及针对 TPP2 和 TPP3 的不同 learning rate。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.4]
- **method：** 交叉验证使用 10-fold、重复 5 次；negative pairs 通过打乱 positive TCR-epitope 对并按 1:5 比例构造，同时按任务分别划分以避免 leakage。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.3]
- **results：** 最佳配置 ab(long)+VJ+MHC 在 TPP2 上达到 AUROC 0.906、AP 0.698，在 TPP3 上达到 AUROC 0.691、AP 0.291。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.6]
- **results：** 加入 VJ 与 MHC 通常比只用 CDR3 更好；其中 TPP3 对 MHC 的依赖尤为明显。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.6]
- **results：** 把低频 epitope 纳入训练可提升 TPP3 泛化，且在去掉 MHC 后仍能观察到相似趋势，说明收益不只是来自 MHC 变化。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.7]
- **results：** 在 yeast display 任务中，未做任务内增强时 AUROC 仅 0.485；加入少量 task-specific epitope 后，平均 AUROC 提升到 0.807，AP 为 0.303。
  - 证据：[doi:10.1093/bioinformatics/btad743, p.8]

## 作者主张的创新点

作者声称提出了一个模块化的、chemistry-first 的生成框架，将 ChemVAE latent space、KAL 打分器、Bayesian optimization 和 cluster-guided local neighborhood sampling 组合起来，用于从多家族 kinase ligand 空间中生成并改造 SRC kinase-like 分子，同时诊断 SMILES 表示的 representational gap。

## 创新边界

`创新主要在生成流程与诊断分析，不在新的生物物理验证或实验性抑制证据。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在不依赖湿实验验证的前提下，利用可解释的生成式机器学习，在 kinase 化学空间中定向重塑 scaffold，并尽可能恢复 SRC-like 的多环芳香骨架与家族选择性特征。

## Pi 结构化证据摘录

- **baseline：** 与 10 类 multiclass classifier 相比，binary KAL 在 SRC 识别上显著更优，说明简化目标比细粒度 kinome 分类更适合该任务。
  - 证据：[doi:10.3390/biom16020209, p.11]；[doi:10.3390/biom16020209, p.12]
- **baseline：** biased Bayesian optimization 相比 unbiased 版本并未带来整体优势，反而更容易陷入狭窄 local optimum，并重复命中少数已知参考分子。
  - 证据：[doi:10.3390/biom16020209, p.14]；[doi:10.3390/biom16020209, p.15]；[doi:10.3390/biom16020209, p.21]
- **baseline：** local sampling 相比随机采样更能保留 pharmacophoric complexity，并在 valid output 上约提升三倍。
  - 证据：[doi:10.3390/biom16020209, p.18]；[doi:10.3390/biom16020209, p.19]
- **data：** 训练与分析数据包含约 220,000 个 generic background molecules，以及约 60,000 个高置信 kinase ligands，覆盖 37 个 kinase families。
  - 证据：[doi:10.3390/biom16020209, p.4]；[doi:10.3390/biom16020209, p.5]；[doi:10.3390/biom16020209, p.8]
- **data：** 作者还为聚焦实验抽取了 3477 个 SRC-associated ligands 和 1883 个 ABL1 ligands，并以 1502 个 SRC positives 与约 23,530 个 negatives 训练 KAL。
  - 证据：[doi:10.3390/biom16020209, p.5]；[doi:10.3390/biom16020209, p.7]
- **data：** Bayesian optimization 的初始 latent set 采用 7000 个点；biased 版本以 2258 个已知 SRC ligands 加 4742 个随机点初始化。
  - 证据：[doi:10.3390/biom16020209, p.8]
- **declared_resources：** 作者声明数据、脚本、软件和模型可在 GitHub 站点获取，并在正文中给出仓库地址。
  - 证据：[doi:10.3390/biom16020209, p.6]；[doi:10.3390/biom16020209, p.22]
- **declared_resources：** 论文同时声明补充材料包含 Figure S1–S8，以及 Bayesian optimization 与 local sampling 生成分子的原始输出。
  - 证据：[doi:10.3390/biom16020209, p.22]
- **limitations：** 作者明确说明本文不做 binding mode、affinity 或 inhibitory efficacy 的生物物理验证，因此不能据此证明真实药理活性。
  - 证据：[doi:10.3390/biom16020209, p.4]；[doi:10.3390/biom16020209, p.21]
- **limitations：** SMILES-based VAE 在多环芳香拓扑上存在系统性失败，作者将其概括为 representation gap。
  - 证据：[doi:10.3390/biom16020209, p.4]；[doi:10.3390/biom16020209, p.16]；[doi:10.3390/biom16020209, p.20]；[doi:10.3390/biom16020209, p.21]
- **limitations：** KAL 只是化学相似/位置感知信号，不是活动度或结合能预测器；其结论仍受 kinase 家族高同源性影响。
  - 证据：[doi:10.3390/biom16020209, p.6]；[doi:10.3390/biom16020209, p.12]；[doi:10.3390/biom16020209, p.13]
- **method：** 使用 ChemVAE 将分子编码到 196 维连续 latent space，并结合 PCA 与 K-means 解析 kinase ligand 的 manifold 组织结构。
  - 证据：[doi:10.3390/biom16020209, p.4]；[doi:10.3390/biom16020209, p.5]；[doi:10.3390/biom16020209, p.8]；[doi:10.3390/biom16020209, p.9]
- **method：** 构建基于 20 个 RDKit descriptors 的 random forest 二分类 KAL classifier，用于区分 SRC 与 non-SRC 化学空间。
  - 证据：[doi:10.3390/biom16020209, p.6]；[doi:10.3390/biom16020209, p.7]；[doi:10.3390/biom16020209, p.11]；[doi:10.3390/biom16020209, p.12]
- **method：** 用 Gaussian Process + Matérn 5/2 kernel + Expected Improvement + L-BFGS-B 实现 Bayesian optimization，并对 latent point 做 1500 次 acquisition。
  - 证据：[doi:10.3390/biom16020209, p.7]；[doi:10.3390/biom16020209, p.8]；[doi:10.3390/biom16020209, p.13]
- **method：** 采用 3-cluster 的 centroid-directed local neighborhood sampling，使用插值系数 s=0.8 与小幅噪声 5.0 做 scaffold remodeling。
  - 证据：[doi:10.3390/biom16020209, p.5]；[doi:10.3390/biom16020209, p.6]；[doi:10.3390/biom16020209, p.17]；[doi:10.3390/biom16020209, p.18]
- **results：** latent space 中 kinase ligands 形成与 GDB 背景明显分离的高密度 manifold，SRC 与 LCK、ABL1、EGFR 等家族存在显著重叠。
  - 证据：[doi:10.3390/biom16020209, p.8]；[doi:10.3390/biom16020209, p.9]；[doi:10.3390/biom16020209, p.10]
- **results：** KAL binary model 的性能为 precision 0.71、recall 0.86、F1 0.78、macro F1 0.88，ROC-AUC 为 0.98；multiclass 版本明显更差。
  - 证据：[doi:10.3390/biom16020209, p.11]；[doi:10.3390/biom16020209, p.12]
- **results：** Bayesian optimization 生成的有效分子中，biased 运行得到 492 个 valid molecules、unbiased 得到 390 个；但二者都没有超过 0.75 的高相似阈值。
  - 证据：[doi:10.3390/biom16020209, p.13]；[doi:10.3390/biom16020209, p.14]
- **results：** Bayesian outputs 的芳香环复杂度显著不足，>80% 分子只有 0 或 1 个 aromatic ring，且没有分子超过 3 个 aromatic rings。
  - 证据：[doi:10.3390/biom16020209, p.15]；[doi:10.3390/biom16020209, p.16]
- **results：** cluster-guided local sampling 提高了有效输出并恢复了多环骨架；LCK 起始分子贡献约 40% 的高相似输出，且 ABL1/LCK/EGFR 来源候选常达到 >0.8 相似度。
  - 证据：[doi:10.3390/biom16020209, p.18]；[doi:10.3390/biom16020209, p.19]；[doi:10.3390/biom16020209, p.20]

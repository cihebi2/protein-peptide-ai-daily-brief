# SurfDock is a Surface-Informed Diffusion Generative Model for Reliable and Accurate Protein-ligand Complex Prediction

## 作者主张的创新点

作者声称提出 SurfDock：一个将 protein sequence、residue graph 与 surface 信息融合到同一表征中的 E(3)-equivariant diffusion docking 模型，并配套 SurfScore 评分模块与可选 post-docking minimization，用于提升 binding pose 生成、排序和 virtual screening 表现。

## 创新边界

`新意主要在 surface-informed、多模态、共享表征的 diffusion docking 与 scoring 组合；不属于新 wet-lab 发现，也不是通用蛋白生成或纯性质预测。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知蛋白口袋的结构基础药物设计场景中，如何更准确地生成、排序并筛选 ligand 的结合构象，同时兼顾物理合理性、对未见蛋白的泛化能力以及 virtual screening 可用性。

## 方法

- 在平移、旋转和扭转自由度上进行等变扩散生成，融合蛋白表面特征；随后以混合密度网络评分并可做能量最小化重评分。

## 数据与基准

- 使用PDBbind v2020、Astex Diverse、PoseBusters 428复合物等数据评估pose、物理合理性和虚拟筛选。

## 比较基线

- EquiBind、E3Bind、TANKBind、KarmaDock、DiffDock及传统对接/评分。

## 结果证据

- 论文声称对接成功率和物理约束优于既有方法；均为计算pose、评分和最小化结果，无新配体实验结合验证。

## 已知限制

- 依赖已知口袋与静态受体表示；表面计算、最小化和重评分增加成本，受体柔性和诱导契合仍未解决。

## 仍未知

- 冻结材料未独立验证 GitHub 仓库当前状态、提交内容与许可证细节。
- 不同 baseline 的部分结果来自既有文献或不同实验设置，严格同场可比性仍有边界。
- 对 peptides 等大分子性能退化的原因仅作推测，尚缺少专门消融与机制验证。

## Pi 结构化证据摘录

- **baseline：** PDBbind2020 time-split 评测中，作者把 SurfDock 与 EquiBind、TANKBind、DiffDock、E3Bind、KarmaDock、Uni-dock、Glide SP、GNINA、SMINA 和 Vina 进行比较。
  - 证据：[doi:10.1101/2023.12.13.571408, p.10]
- **baseline：** 在 Astex Diverse set 与 PoseBusters Benchmark set 上，部分 DL baseline（如 EquiBind、TANKBind、DiffDock、E3Bind）直接采用文献结果，而 Glide SP、GNINA、SMINA、Vina 与 SurfDock 则为作者自实现。
  - 证据：[doi:10.1101/2023.12.13.571408, p.12]；[doi:10.1101/2023.12.13.571408, p.13]
- **baseline：** DEKOIS2.0 实验中，作者对比了 KarmaDock 论文结果、Glide SP 与 Surflex-Dock 的 rescoring 表现，并用 SurfScore 重新评估传统方法生成的 poses。
  - 证据：[doi:10.1101/2023.12.13.571408, p.19]；[doi:10.1101/2023.12.13.571408, p.20]；[doi:10.1101/2023.12.13.571408, p.21]
- **data：** 主训练/评测数据基于 PDBbind2020 time-split test set，共 363 complexes；作者另分析了 144 complexes 的 unseen proteins 子集，且说明该集合包含 peptides 和 small molecules。
  - 证据：[doi:10.1101/2023.12.13.571408, p.10]；[doi:10.1101/2023.12.13.571408, p.11]
- **data：** 外部 benchmark 包括 Astex Diverse set（85 cases）、PoseBusters Benchmark set（428 complexes，2021 年后发布）以及 DEKOIS2.0（81 targets，每个 target 含 40 actives 和 1,200 decoys）。
  - 证据：[doi:10.1101/2023.12.13.571408, p.12]；[doi:10.1101/2023.12.13.571408, p.13]；[doi:10.1101/2023.12.13.571408, p.19]；[doi:10.1101/2023.12.13.571408, p.21]
- **data：** 数据可得性声明给出 PDBbind v2020、Astex Diverse set、PoseBusters Benchmark set 的公开来源/Zenodo 预处理地址，并声明代码以 MIT License 提供，GitHub 地址为 https://github.com/CAODH/SurfDock。
  - 证据：[doi:10.1101/2023.12.13.571408, p.31]
- **declared_resources：** 公开资源声明包括 PDBbind v2020、Astex Diverse set、PoseBusters Benchmark set 的预处理数据，以及 DEKOIS2.0 评测集；这些数据都被用于训练、验证或外部 benchmark。
  - 证据：[doi:10.1101/2023.12.13.571408, p.31]；[doi:10.1101/2023.12.13.571408, p.10]；[doi:10.1101/2023.12.13.571408, p.12]；[doi:10.1101/2023.12.13.571408, p.19]
- **declared_resources：** 方法依赖的外部工具与特征来源包括 RDKit、ESM-2、MaSIF、MSMS、PyMesh、OpenMM、AMBER ff14sb、Sage 和 GAFF。
  - 证据：[doi:10.1101/2023.12.13.571408, p.8]；[doi:10.1101/2023.12.13.571408, p.25]；[doi:10.1101/2023.12.13.571408, p.31]
- **declared_resources：** 作者声明代码采用 MIT License，并给出项目仓库 https://github.com/CAODH/SurfDock，表明该工作具有可复用的软件资源边界。
  - 证据：[doi:10.1101/2023.12.13.571408, p.31]
- **limitations：** 作者明确承认 SurfDock 对较大 ligand（例如 peptides）的处理仍有限，原因可能是 PDBbind 中大型 ligand 训练数据稀缺。
  - 证据：[doi:10.1101/2023.12.13.571408, p.18]
- **limitations：** 在 virtual screening 中，作者为了效率采用了较不精确的 docking-scoring-minimize-rescoring 流程，并表示通过进一步优化 workflow 仍可能继续提升性能。
  - 证据：[doi:10.1101/2023.12.13.571408, p.20]
- **method：** SurfDock 由两个主模块组成：一个用于 ligand pose 生成的 diffusion network，另一个用于 pose ranking 的 SurfScore；二者共享同一套 protein-pocket 与 ligand 表示，但采用不同 readout。
  - 证据：[doi:10.1101/2023.12.13.571408, p.7]；[doi:10.1101/2023.12.13.571408, p.8]；[doi:10.1101/2023.12.13.571408, p.28]
- **method：** Protein pocket 采用三层表示：sequence level、residue graph level 和 surface level；序列特征来自 ESM-2，surface mesh 由 MaSIF/MSMS/PyMesh 处理，且只使用距离 binding site 8Å 内的节点参与训练。
  - 证据：[doi:10.1101/2023.12.13.571408, p.8]；[doi:10.1101/2023.12.13.571408, p.25]
- **method：** 生成阶段在 translation、rotation 与 torsion 三个自由度上做 score-based diffusion，并把 docking 形式化为在 (m+6)-dimensional manifold 上学习条件分布；torsion 更新后还做 RMSD alignment 来稳定构象。
  - 证据：[doi:10.1101/2023.12.13.571408, p.23]；[doi:10.1101/2023.12.13.571408, p.24]；[doi:10.1101/2023.12.13.571408, p.27]；[doi:10.1101/2023.12.13.571408, p.30]
- **method：** SurfScore 采用与 docking 相同的输入表示，使用 mixture density network 拟合 ligand-target distance distribution（20-component Gaussian mixture），并加入 atom type 与 bond type 的 auxiliary tasks。
  - 证据：[doi:10.1101/2023.12.13.571408, p.28]；[doi:10.1101/2023.12.13.571408, p.29]；[doi:10.1101/2023.12.13.571408, p.30]
- **method：** 作者还提供可选的 post-docking energy minimization：用 OpenMM 与 AMBER ff14sb 处理 protein，small molecule 则用 Sage 或 GAFF，且固定 protein atoms、仅优化 ligand。
  - 证据：[doi:10.1101/2023.12.13.571408, p.22]；[doi:10.1101/2023.12.13.571408, p.31]
- **results：** 在 PDBbind2020 time-split test set 上，SurfDock 的 Top1 RMSD<2Å 达到 68.41%，Top1 RMSD<1Å 为 40.96%，中位 RMSD 为 1.18Å；加入 minimization 后，Top1 RMSD<1Å 提升到 46.01%。
  - 证据：[doi:10.1101/2023.12.13.571408, p.10]；[doi:10.1101/2023.12.13.571408, p.11]
- **results：** 作者报告 SurfDock 在 PoseBusters Benchmark set 与 Astex Diverse set 的 docking success rate 分别为 78% 和 93%，并称在低序列相似性（<30%）子集上仅出现轻微下降。
  - 证据：[doi:10.1101/2023.12.13.571408, p.13]；[doi:10.1101/2023.12.13.571408, p.14]
- **results：** sampling efficiency 分析显示，约 10 次采样后性能提升开始放缓；当使用 40 个 samples 并由 SurfScore 选 Top pose 时，success rate 可升至约 68%，而单样本约为 40%。
  - 证据：[doi:10.1101/2023.12.13.571408, p.14]；[doi:10.1101/2023.12.13.571408, p.15]；[doi:10.1101/2023.12.13.571408, p.16]；[doi:10.1101/2023.12.13.571408, p.17]
- **results：** 在 ligand flexibility 分析中，传统方法在约 15 个 rotatable bonds 或约 35 heavy atoms 之后明显退化；SurfDock 对 drug-like subset 的表现接近 80%，并被作者描述为较传统方法高出约 20%。
  - 证据：[doi:10.1101/2023.12.13.571408, p.17]；[doi:10.1101/2023.12.13.571408, p.18]
- **results：** 在 DEKOIS2.0 上，SurfDock 的 EF0.5% 达到 21.00；作者同时指出，SurfScore 对传统 docking 结果做 rescoring 后也能获得接近 SurfDock 的总体表现。
  - 证据：[doi:10.1101/2023.12.13.571408, p.19]；[doi:10.1101/2023.12.13.571408, p.20]；[doi:10.1101/2023.12.13.571408, p.21]

# Using deep learning and large protein language models to predict protein-membrane interfaces of peripheral membrane proteins

- **论文 ID：** `EVIW-90130005AA3C23BF`
- **期刊 / 来源：** Bioinform Adv
- **发表时间：** 2024 May 28
- **DOI：** [10.1093/bioadv/vbae078](https://doi.org/10.1093/bioadv/vbae078)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称这是首个 proof of concept：用 ProtTrans/ESM embeddings 结合分类器，在不依赖 3D structural data 的前提下，以更快速度和相近准确率预测 PMP 的 protein–membrane interfaces，并在 PDB 序列上提升鲁棒性。

## 创新边界

`属于 residue/interface prediction，不是候选分子生成；核心是现成 classifiers + pLM embeddings。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在缺乏完整 3D 结构和充足实验标注时，预测 peripheral membrane proteins 的 membrane-interacting amino acids 与 protein–membrane interfaces。

## 方法

- PLM残基嵌入输入分类模型，与DREAMM/PPM等比较。

## 数据与基准

- PePrMInt九个膜结合domain家族和第二个PMP集，标签部分由实验后结构对齐转移。

## 比较基线

- DREAMM、PPM及传统结构/序列模型。

## 结果证据

- 论文报告proof-of-concept；在训练未含的PMP superfamily仅约1/3正确。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 家族覆盖小，转移标签含噪，大模型受显存限制；OOD superfamily表现弱。

## 仍未知

- 未见更大规模、独立外部基准来验证对未知 PMP superfamilies 的稳定泛化。
- 3 Å 重新标注是否能系统性提升性能，尚未在正式重标注数据上验证。
- GitHub 仓库与补充材料中的实现细节、可复现实验脚本未在本次冻结证据中独立核验。

## Pi 结构化证据摘录

- **baseline：** 对照基线包括 DREAMM、MODA、PPM3 和 PMIpred，作者以四个测试蛋白进行逐例比较并报告预测时间。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]
- **baseline：** 讨论中明确将结果与 DREAMM 及 physics-based calculations 对比，并指出后者仍更 robust。
  - 证据：[doi:10.1093/bioadv/vbae078, p.6]
- **data：** 最终 UniProt 集合包含 443 个 PMP（411 from PePrMInt, 32 from DREAMM）和 325,943 个 amino acids；PDB 集合包含 450 个序列（418 + 32）和 76,084 个 amino acids。
  - 证据：[doi:10.1093/bioadv/vbae078, p.2]
- **data：** PePrMInt 初始包含 1963 PDB IDs / 674 UniProt IDs，而 DREAMM 提供 65 个已知 3D structure 的 PMP；两者合并后用于训练与外部测试。
  - 证据：[doi:10.1093/bioadv/vbae078, p.2]
- **data：** 作者指出训练数据中约 3% 的 amino acids 属于 membrane-interacting class，数据严重不平衡。
  - 证据：[doi:10.1093/bioadv/vbae078, p.3]
- **declared_resources：** 代码仓库由论文直接给出：https://github.com/zoecournia/pLM-PMI；作者同时声明所有数据见 Supplementary material。
  - 证据：[doi:10.1093/bioadv/vbae078, p.1]；[doi:10.1093/bioadv/vbae078, p.7]
- **declared_resources：** Funding 来自 H.F.R.I. [1780 to Z.C.]，并使用 GRNET ARIS HPC 计算资源（pr008033_gpu-Mem-Surf, pr008033_thin-Mem-Surf）。
  - 证据：[doi:10.1093/bioadv/vbae078, p.7]
- **limitations：** 模型对训练集中未出现的 PMP superfamilies 泛化不足；extra test set 中多数蛋白表现不佳。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]；[doi:10.1093/bioadv/vbae078, p.6]
- **limitations：** 实验标签本身有限，PDB/UniProt 对齐后未解析片段可能被误标为非 membrane-interacting；作者也认为 IBS 可能还应再向外扩展 3 Å。
  - 证据：[doi:10.1093/bioadv/vbae078, p.2]；[doi:10.1093/bioadv/vbae078, p.7]
- **limitations：** 对小于 35 aa 的蛋白和若干 transmembrane enzymes 的预测失败，显示模型仍有明显适用边界。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]；[doi:10.1093/bioadv/vbae078, p.5]
- **limitations：** 作者建议 future work 包括 fine-tuning pLMs 和结合 physicochemical features，说明当前模型仍未解决特征表达与泛化问题。
  - 证据：[doi:10.1093/bioadv/vbae078, p.6]；[doi:10.1093/bioadv/vbae078, p.7]
- **method：** 作者先从 PePrMInt 与 DREAMM 汇集 PMP 数据，并按 UniProt / PDB 两条流水线完成对齐、去冗余与 residue-level 标签构建。
  - 证据：[doi:10.1093/bioadv/vbae078, p.2]
- **method：** 使用 ProtTrans 与 ESM 生成 contextual embeddings，并将氨基酸类别 one-hot 后作为特征输入分类器。
  - 证据：[doi:10.1093/bioadv/vbae078, p.3]
- **method：** 训练 XGBoost、LGBM、Balanced Random Forest、Single-Layer Perceptron 和 Multi-Layer Perceptron，并用 Optuna 通过 F1 / MCC 选择最优超参数。
  - 证据：[doi:10.1093/bioadv/vbae078, p.3]
- **method：** 对 UniProt 与 PDB 序列分别切分 train/validation/test，并额外构造 DREAMM extra test set 做 qualitative evaluation。
  - 证据：[doi:10.1093/bioadv/vbae078, p.3]
- **results：** 在 UniProt test set 上，ProtTrans + MLP 取得最佳成绩，F1=0.68、MCC=0.65；ESM + MLP 的 F1=0.58、MCC=0.56。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]
- **results：** 在 PDB sequence 数据集上，ProtTrans + LGBM 达到 F1=0.80、MCC=0.77；ESM + LGBM 达到 F1=0.77、MCC=0.74。
  - 证据：[doi:10.1093/bioadv/vbae078, p.5]
- **results：** 作者观察到不少 false positive 位于真实界面附近，若把距离 3 Å 内的 FP 重标为 TP，precision 可显著提升；对未知超家族，PDB 模型比 UniProt 模型更稳健。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]；[doi:10.1093/bioadv/vbae078, p.5]
- **results：** 与 DREAMM、MODA、PPM3、PMIpred 的逐例比较表明，pLM 模型更快，并在若干案例中更准。
  - 证据：[doi:10.1093/bioadv/vbae078, p.4]

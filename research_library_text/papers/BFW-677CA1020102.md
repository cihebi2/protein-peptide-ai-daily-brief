# Atom-level enzyme active site scaffolding using RFdiffusion2

- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出 RFdiffusion2：一个基于 flow matching 的 all-atom 生成模型，能够直接条件化 atomic motif、unindexed motif、ligand RASA 和 partial ligand，并在 AME benchmark 与多项湿实验中证明其可用于 de novo enzyme scaffolding 与功能酶设计。[doi:10.1038/s41592-025-02975-x, p.2]

## 创新边界

`创新边界主要在于把原子级、无索引的 motif scaffolding 做成端到端生成模型；但其训练与评估仍建立在 PDB/M-CSA 的已知结构和已知催化位点上，全球新颖性并未在冻结证据中独立验证。[doi:10.1038/s41592-025-02975-x, p.4]`。这不是全球首创性检索或独立复现结论。

## 研究问题

论文聚焦于如何把原子级别的酶 active site/theozyme 直接转化为可折叠、可配序的蛋白 scaffolds，避免传统方法依赖预设残基顺序、inverse rotamer 枚举和 backbone-level motif 约束所带来的组合爆炸与表达受限。[doi:10.1038/s41592-025-02975-x, p.1]

## Pi 结构化证据摘录

- **baseline：** 基线对照是把原本的 atomic motif 预处理成 RFdiffusion 可接受的 indexed backbone motif，并用 inverse rotamer sampling 与 ligand 的 attractive–repulsive potential 进行适配。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.4]；[doi:10.1038/s41592-025-02975-x, p.11]
- **baseline：** 作者还将实验结果与既有设计文献对照，指出最优 cysteine esterase 高于先前 designed cysteine esterases，zinc hydrolase 也超过先前 designed zinc hydrolases。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.8]
- **data：** 训练数据来自 PDB，覆盖 protein、protein-small-molecule complex、protein-metal complex 和 covalent modification 结构，并过滤常见 solvent 与 crystallization additives。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.2]
- **data：** AME benchmark 由 958 个 M-CSA catalytic active sites 交叉 PARITY 筛到 41 个案例，覆盖 EC1–EC5，并用 residue islands 描述 motif 断裂复杂度。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.4]；[doi:10.1038/s41592-025-02975-x, p.11]
- **data：** 湿实验部分包含 5 个反应体系：retroaldolase、cysteine hydrolase，以及 3 个 metallohydrolase 设计情形，其中后者使用 DFT 求得的 transition-state geometry。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.6]；[doi:10.1038/s41592-025-02975-x, p.7]；[doi:10.1038/s41592-025-02975-x, p.8]
- **declared_resources：** 训练使用 24 张 A100 Nvidia GPUs，持续 17 天。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.2]
- **declared_resources：** 基准构建依赖公开资源 PDB、M-CSA 和 PARITY；序列设计与结构筛选使用 LigandMPNN 和 Chai-1。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.4]；[doi:10.1038/s41592-025-02975-x, p.11]
- **declared_resources：** 论文明确给出 RFdiffusion2 的 GitHub 仓库，并说明代码以 MIT open-source license 开放。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.11]
- **limitations：** 作者明确承认，尽管能够得到活性酶，这些设计的活性仍低于 native enzymes。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.8]
- **limitations：** AME benchmark 仍局限于 M-CSA/PDB 中可获得的已知催化位点，作者也指出扩展到 multiple transition states 或 non-PDB motifs 仍超出当前工作范围。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.8]；[doi:10.1038/s41592-025-02975-x, p.11]
- **limitations：** 主文只给出方法的 brief summary，关键训练超参、筛选阈值和实验流程细节主要放在 Supplementary Information，因此仅凭冻结主文难以完全复现全部操作细节。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.11]
- **method：** 模型以 RF All-Atom 架构为底座，采用 flow matching 训练，并从随机初始化开始优化，不依赖原版 RFdiffusion 那类 auxiliary losses 或 self-conditioning。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.2]；[doi:10.1038/s41592-025-02975-x, p.11]
- **method：** 训练样本由 PDB 结构经 motif extraction 构造，包含 atomized residues、unindexed residues、ligand 子图与部分 RASA 标签，并通过 stochastic centering 处理 motif 与 scaffold 的相对偏移。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.2]；[doi:10.1038/s41592-025-02975-x, p.3]
- **method：** 推理阶段可同时条件化 atomic motif、unindexed motif、ORI pseudo-atom、ligand RASA 和 partial ligand，再用 LigandMPNN 配序、Chai-1 做结构一致性筛选。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.3]；[doi:10.1038/s41592-025-02975-x, p.4]；[doi:10.1038/s41592-025-02975-x, p.11]
- **results：** 在 AME benchmark 上，RFdiffusion2 对 41/41 个案例至少找到一个通过筛选的 scaffold，而 RFdiffusion 仅为 16/41；作者还指出 RFdiffusion2 在 40/41 个案例上表现更好。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.4]；[doi:10.1038/s41592-025-02975-x, p.6]
- **results：** 在 rotamer 与 index 处理上，RFdiffusion2 通过 inference 同时推断两者优于 native 或 naive 方案；naive 在 4 residue islands 时没有任何 in silico success。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.5]；[doi:10.1038/s41592-025-02975-x, p.6]
- **results：** 实验验证显示，少于 96 个设计/反应即可找到活性 enzyme；最佳 retroaldolase 的 kcat/KM 为 6.34，cysteine hydrolase 为 248，zinc hydrolase 分别达到 77、16,000 和 53,000 M−1 s−1。
  - 证据：[doi:10.1038/s41592-025-02975-x, p.7]；[doi:10.1038/s41592-025-02975-x, p.8]

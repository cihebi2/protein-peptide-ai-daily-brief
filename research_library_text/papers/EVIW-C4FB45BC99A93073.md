# Computational design of class II MHC binding peptide with sequence-based evolution information

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `数据集/基准`
- **基础层：** Codex 辅助专家全文审阅

## 作者主张的创新点

作者提出一个以 Transformer 为核心、并辅以 Monte Carlo simulated annealing 的序列设计框架，利用单位点频率与位点对 joint frequency/coupling 从 MSA 中生成人工 MHCII binding cores；随后用 DeepMHCII、NetMHCIIpan-4.3 和 AlphaFold3 做纯计算验证，声称所得序列可接近天然肽的结合与结构特征。

## 创新边界

`新意主要在于把 sequence-based evolutionary information 直接用于 MHCII peptide inverse design；但证据仍是纯计算，且训练/验证依赖现成预测器，尚未通过湿实验确认。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何仅依赖序列进化信息，为特定 HLA class II 等位型 de novo 设计可结合 MHCII 的 9-mer binding core，并尽量保持天然配体的保守性与协同变异。

## 方法

- HLA/peptide sequence model与evolutionary search。

## 数据与基准

- MHC-II affinity datasets。

## 比较基线

- NetMHCIIpan/sequence optimization。

## 结果证据

- 论文报告预测binding提高；无明确assay则保持计算。

## Pi 结构化证据摘录

- **baseline：** random peptides 被用作主要负对照，在 affinity 和 pLDDT 上都明显弱于设计序列。
  - 证据：[doi:10.1093/bioadv/vbag090, p.7]；[doi:10.1093/bioadv/vbag090, p.8]
- **baseline：** native binding cores 作为参考基线，用来衡量 conservation、binding affinity 和结构置信度是否接近自然配体。
  - 证据：[doi:10.1093/bioadv/vbag090, p.7]；[doi:10.1093/bioadv/vbag090, p.8]
- **baseline：** MC1 与 MC2 的对比显示，仅优化 coupling 而不加入 frequency constraint 会带来较差的结构置信度；作者也指出 MCSA 比 Transformer 更费算力。
  - 证据：[doi:10.1093/bioadv/vbag090, p.9]
- **baseline：** NetMHCIIpan-4.3 与 DeepMHCII 被作为外部验证器，作者据此检查设计序列是否仍接近天然 binding 模式。
  - 证据：[doi:10.1093/bioadv/vbag090, p.6]；[doi:10.1093/bioadv/vbag090, p.7]；[doi:10.1093/bioadv/vbag090, p.8]
- **data：** 训练与设计数据来自 BD2020 和 Dset_pos 两个 IEDB 数据集，作者要求每个 MHCII molecule 至少保留 200 条 peptide 以支持建模。
  - 证据：[doi:10.1093/bioadv/vbag090, p.2]
- **data：** Dset_bc 是核心数据资产：它并非实验测得 binding core，而是由 NetMHCIIpan-4.1 从长 peptide 中推断出来，用作 MSA 与网络训练的输入。
  - 证据：[doi:10.1093/bioadv/vbag090, p.2]；[doi:10.1093/bioadv/vbag090, p.10]
- **data：** 验证阶段优先选取 NetMHCIIpan-4.1 预测 IC50 < 50 nM 的高亲和 binding cores，并在 HLA-DRB5*01:01 上从 native、FS、L1、L2 和 random 各抽 200 条做 pLDDT 统计。
  - 证据：[doi:10.1093/bioadv/vbag090, p.6]；[doi:10.1093/bioadv/vbag090, p.8]
- **data：** 作者还把 PDB 1HQR 作为结构模板，分析 HLA-DRB5*01:01、SPE-C 和 self-peptide 的三元复合体场景。
  - 证据：[doi:10.1093/bioadv/vbag090, p.8]
- **declared_resources：** 作者声明自定义 data 和 code 已公开在 GitHub 仓库 https://github.com/caoying2024-hue/peptide 。
  - 证据：[doi:10.1093/bioadv/vbag090, p.10]
- **declared_resources：** 作者致谢中明确提到使用了 High Performance Computing Center of Wenzhou Institute, University of Chinese Academy of Sciences 的计算资源。
  - 证据：[doi:10.1093/bioadv/vbag090, p.10]
- **limitations：** 作者明确承认 binding core 主要依赖 NetMHCIIpan-4.1 预测，而当前实验测得的 MHC-II binding core 结构数据非常稀缺。
  - 证据：[doi:10.1093/bioadv/vbag090, p.10]
- **limitations：** 整篇工作没有 wet-lab validation；作者也直接写明最终仍需要实验验证才能排除纯计算推断的局限。
  - 证据：[doi:10.1093/bioadv/vbag090, p.10]
- **limitations：** 训练数据与 DeepMHCII 训练集存在 overlap，虽然作者做了去重控制，但 predictive circularity 仍不能完全排除。
  - 证据：[doi:10.1093/bioadv/vbag090, p.10]
- **limitations：** MHCII binding core 只有 9-mer，作者自己也指出这会限制 pairwise coupling 在结构和设计上的额外收益。
  - 证据：[doi:10.1093/bioadv/vbag090, p.8]；[doi:10.1093/bioadv/vbag090, p.9]
- **method：** 先从 IEDB 派生的 BD2020 与 Dset_pos 汇总 27 个 HLA allotypes 的 46,145 条 peptide 序列，并过滤到 42,783 条，再用 NetMHCIIpan-4.1 预测每条复合体的 9-mer binding core，构成 Dset_bc。
  - 证据：[doi:10.1093/bioadv/vbag090, p.2]
- **method：** 用 KL divergence 定义 first-order conservation，用 joint frequency 与 coupling matrix 定义 second-order conservation，把这些统计量作为序列进化特征输入设计流程。
  - 证据：[doi:10.1093/bioadv/vbag090, p.3]
- **method：** Transformer 分支将 position-specific amino acid frequency 与 pairwise joint frequency 分别经 1D/2D CNN 编码，再经过 12-layer Transformer 与 Softmax 采样生成候选序列；训练使用 Loss1/Loss2、Adam、2000 epochs 和 λ=65，并重复训练 10 次检查稳定性。
  - 证据：[doi:10.1093/bioadv/vbag090, p.4]；[doi:10.1093/bioadv/vbag090, p.5]
- **method：** MCSA 分支以 coupling 差异为目标，分别生成 MC1 与 MC2；其中 MC2 结合 FS 初始化和频率约束，采用 Metropolis criterion 接受或拒绝突变。
  - 证据：[doi:10.1093/bioadv/vbag090, p.5]
- **results：** FS 只保留 first-order conservation，而 L1/L2 还能同时复现 second-order coupling；其中 L2 的 coupling matrix 与 native 最接近。
  - 证据：[doi:10.1093/bioadv/vbag090, p.7]
- **results：** DeepMHCII 预测显示，设计序列的 binding affinity 与 native 相近、显著高于 random；其中 L2 在 HLA-DRB5*01:01 上表现最好。
  - 证据：[doi:10.1093/bioadv/vbag090, p.7]；[doi:10.1093/bioadv/vbag090, p.8]
- **results：** AlphaFold3 的 pLDDT 表明设计序列与 native 的结构置信度相当且明显优于 random；L2 取得最高 pLDDT 且波动最小。
  - 证据：[doi:10.1093/bioadv/vbag090, p.8]
- **results：** 设计序列还能在 AlphaFold3 中形成与 MHCII-SPE-C 或 MHCII-TCR 的高置信 ternary complex，说明其不只是单纯的序列拟合。
  - 证据：[doi:10.1093/bioadv/vbag090, p.8]；[doi:10.1093/bioadv/vbag090, p.9]

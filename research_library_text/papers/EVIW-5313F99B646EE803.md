# MISATO: machine learning dataset of protein-ligand complexes for structure-based drug discovery

- **论文 ID：** `EVIW-5313F99B646EE803`
- **期刊 / 来源：** Nat Comput Sci
- **发表时间：** 2024 May 10
- **DOI：** [10.1038/s43588-024-00627-2](https://doi.org/10.1038/s43588-024-00627-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体` / `数据集/基准`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 MISATO，把约 2 万个实验 protein–ligand complexes 的 QM 性质、10 ns MD 轨迹、数据清洗流程和 AI baselines 整合成可直接用于 ML 的公开资源。[doi:10.1038/s43588-024-00627-2, p.1][doi:10.1038/s43588-024-00627-2, p.5][doi:10.1038/s43588-024-00627-2, p.10]

## 创新边界

`其新意主要在数据集构建、结构修正、特征补全和基线评估，不是新的候选分子生成或优化算法。[doi:10.1038/s43588-024-00627-2, p.1][doi:10.1038/s43588-024-00627-2, p.8][doi:10.1038/s43588-024-00627-2, p.10]`。这不是全球首创性检索或独立复现结论。

## 研究问题

结构基础药物发现缺少同时包含可靠静态结构、电子性质与动态信息的高质量 protein–ligand 数据，导致 AI 模型难以从裸结构中学到可泛化的表示。[doi:10.1038/s43588-024-00627-2, p.1][doi:10.1038/s43588-024-00627-2, p.2][doi:10.1038/s43588-024-00627-2, p.3]

## 方法

- PDB实验复合物清洗；配体QM计算；复合物MD；结构/数据质量验证；ML基线。

## 数据与基准

- 约20,000个实验蛋白-配体复合物及关联QM/MD轨迹和元数据。

## 比较基线

- 只用静态结构/常规特征的ML基线。

## 结果证据

- 论文用基线示例报告加入MISATO信息可提升部分预测准确度；核心贡献是数据基础设施而非一个通用药物模型。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- QM仅对配体执行；实验结构误差、质子化和MD设置带来系统偏差。

## 仍未知

- 外部复现时，结构清洗与人工修正边界是否完全稳定仍需验证。
- 仅 ligand 级 QM 与 10 ns MD 是否足以覆盖更长时标构象变化，仍不确定。
- 127 条亲和力 benchmark 能否代表更广泛的靶点与化学空间，仍然有限。

## Pi 结构化证据摘录

- **baseline：** 论文提供了三个可复用 baseline：QM property prediction、protein pocket adaptability prediction 和 binding affinity ranking。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.6]；[doi:10.1038/s43588-024-00627-2, p.9]
- **baseline：** 在 affinity 任务上，加入 MD-derived adaptabilities 与 QM charges 后，模型在五个 benchmark set 上都较不加特征的版本更好。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.7]
- **baseline：** 作者还把 AutoDock Vina 和未清洗的 original PDBbind 作为对照，MISATO features 版本整体表现更优。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.7]
- **data：** MISATO 以 PDBbind 2022 的 19,443 个实验结构为起点，最终对 3,930 个结构做了实质性修正，MD 实际覆盖 16,972 个复合物。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.2]；[doi:10.1038/s43588-024-00627-2, p.3]；[doi:10.1038/s43588-024-00627-2, p.5]
- **data：** QM 数据包含 electron affinity、chemical hardness、electronegativity、ionization potentials、logP、polarizability、partial charges、bond orders、hybridization、Fukui indices、softness 和电子密度。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.4]
- **data：** MD 侧同时存储 RMSDLigand、whole-complex RMSD、MMGBSA interaction energy、buried solvent accessible surface area、ligand–receptor center-of-mass distance 等元数据。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.5]
- **data：** 作者还构建了 127 个 ligand、5 个 protein set 的高质量 binding affinity benchmark，用于验证 affinity model。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.7]；[doi:10.1038/s43588-024-00627-2, p.9]
- **declared_resources：** 数据可从 Zenodo 下载，代码在 GitHub/Zenodo 公开，且提供 Python data loaders、container image 和 preprocessing scripts。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]；[doi:10.1038/s43588-024-00627-2, p.10]
- **declared_resources：** 论文还单独提供了 H5 格式的 QM/MD 数据、checkpoint files 和 source data，便于复用与继续训练。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]；[doi:10.1038/s43588-024-00627-2, p.10]
- **limitations：** 当前版本的 QM 只算 ligand，没有把 protein 一并纳入；作者也明确说更长时标的 MD 仍然需要。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]
- **limitations：** binding affinity 标签来自不同实验体系，噪声和不可比性很强，所以只构建了 127 个 ligand 的小型高质量 benchmark。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.3]；[doi:10.1038/s43588-024-00627-2, p.7]；[doi:10.1038/s43588-024-00627-2, p.9]
- **limitations：** 部分结构因 non-standard atoms、蛋白初始结构不一致或算法无法稳定收敛而被排除，说明清洗流程仍有边界。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.9]；[doi:10.1038/s43588-024-00627-2, p.10]
- **method：** 作者先用半经验 QM 和一致性测试检查原始结构，依据原子重叠、波函数收敛、HOMO–LUMO gap、八隅体规则和几何优化后的连接关系变化来筛查并修正配体。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]
- **method：** QM 计算使用 ULYSSES，方法包括 GFN2-xTB、AM1 和 PM6，并在 ALPB 隐式溶剂下处理 water 与 wet octanol。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]
- **method：** MD 计算使用 Amber20、gaff2、ff14SB 和 TIP3P，在八面体周期盒中做 10 ns NVT，前 2 ns 作为平衡丢弃，之后保留 100 个快照并提取 MMGBSA、bSASA、RMSD 等特征。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.8]
- **method：** AI baseline 采用 GNN/GCNConv；亲和力模型按 UniProt ID 与 affinity type 分簇后，用配对复合物的对数亲和力比值训练，并以 Spearman correlation 评估。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.9]
- **results：** 清洗阶段修改了约 20% 的原始结构，其中 3,905 例涉及 protonation state 调整、97 例涉及 heteroatom changes；约 75% 的修改来自 hydrogen removal。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.3]；[doi:10.1038/s43588-024-00627-2, p.4]
- **results：** QM baseline 对 electron affinity 和 chemical hardness 的 Pearson correlation 分别达到 0.75 和 0.77，MAE 分别约为 0.12 eV 和 0.13 eV。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.6]
- **results：** Adaptability model 的 mean Pearson correlation 为 0.66，平均能在每个复合物的 top 100 柔性原子中命中 42 个。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.6]
- **results：** Affinity GNN 在 MISATO features 加持下达到 mean Spearman correlation 0.64，优于无 MISATO features 的 0.50、Vina 的 0.51 和 non-curated 的 0.50。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.7]
- **results：** 实验验证中，B factors 与 MD RMSF 的平均相关为 0.59；PB2 的 adaptability 预测与 B factors 及 hetNOE 也保持较高一致性。
  - 证据：[doi:10.1038/s43588-024-00627-2, p.7]

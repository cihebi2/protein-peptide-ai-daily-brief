# Emerging opportunities of using large language models for translation between drug molecules and indications

- **论文 ID：** `EVIW-320290EBA410B89A`
- **期刊 / 来源：** Sci Rep
- **发表时间：** 2024 May 10
- **DOI：** [10.1038/s41598-024-61124-0](https://doi.org/10.1038/s41598-024-61124-0)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出一个新的 drug-to-indication / indication-to-drug 任务，并首次系统评估 MolT5 及其 custom tokenizer 变体在 DrugBank 与 ChEMBL 上的表现，同时比较模型规模、数据子集和 fine-tuning 设置。[doi:10.1038/s41598-024-61124-0, p.1][doi:10.1038/s41598-024-61124-0, p.3][doi:10.1038/s41598-024-61124-0, p.6]

## 创新边界

`主要新意在任务重述与实验迁移；冻结证据未显示全新生成算法或已验证的全局突破。[doi:10.1038/s41598-024-61124-0, p.6][doi:10.1038/s41598-024-61124-0, p.7]`。这不是全球首创性检索或独立复现结论。

## 研究问题

探索能否把 drug molecule 的 SMILES 与 indication 之间做双向“翻译”，从而让模型从疾病/症状描述生成候选药物，或从药物生成对应适应证。[doi:10.1038/s41598-024-61124-0, p.1][doi:10.1038/s41598-024-61124-0, p.2]

## 方法

- 将SMILES和indication文本作为序列到序列任务，在不同模型规模/方向上训练生成。

## 数据与基准

- ChEMBL与DrugBank两个公开drug-indication数据集。

## 比较基线

- 九种T5/MolT5变体。

## 结果证据

- 论文展示双向生成可行性并讨论模型规模差异；生成indication/molecule仍是候选，不具临床或化学验证。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 文本标签歧义、分子有效性和人类评审不足；作者建议human-in-the-loop。

## 仍未知

- 是否有公开代码仓库或可复现实验脚本未在论文中说明
- 自定义 tokenizer 预训练的全部超参数与训练时长未完全展开
- 数据划分随机种子与统计显著性检验未见明确报告
- 生成结果的人类可用性与真实药物发现价值未做人工验证

## Pi 结构化证据摘录

- **baseline：** 基线就是原始 MolT5 的 smiles-to-caption / caption-to-smiles 模型，在 FULL、SUB、FT 三种设置上分别评估。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.7]
- **baseline：** 作者把 small、base、large 三种 MolT5 结果并排比较，说明模型规模是最主要的 baseline 变量之一。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.4]；[doi:10.1038/s41598-024-61124-0, p.5]
- **baseline：** custom tokenizer 的实验只在最小 MolT5 上进行，可视为对 baseline 的模型内改造，而不是独立新模型族。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.7]
- **data：** DrugBank 提供 3004 对 drug-indication pairs，ChEMBL 提供 6127 对，Table 9 还汇总了 indication/SMILES 长度分布。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.7]
- **data：** DrugBank 需要申请访问，ChEMBL 需要本地建库后解析；作者最终把两套数据整理成 pickle 以便计算指标。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.7]
- **data：** 论文的数据可用性声明写明 ChEMBL 和 DrugBank 都是公开可用资源。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.8]
- **declared_resources：** 计算资源使用 Bridges-2 at Pittsburgh Supercomputing Center，并由 ACCESS program 与 NSF grants 支持。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.10]
- **declared_resources：** 外部资源包括 DrugBank、ChEMBL、RDKit、HuggingFace 上的 MolT5 权重，以及 ZINC-15 和 C4 预训练语料。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.7]；[doi:10.1038/s41598-024-61124-0, p.8]；[doi:10.1038/s41598-024-61124-0, p.10]
- **declared_resources：** 自定义 tokenizer 方案来自先前针对 SMILES 的 transformer 适配工作。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.7]
- **limitations：** 作者明确指出 SMILES 与 indications 之间缺少直接对应信号，类似 SMILES 可能对应完全不同的适应证。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.6]
- **limitations：** 数据稀缺是核心瓶颈，两个数据集加起来的 drug-indication pairs 仍少于 10000。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.6]；[doi:10.1038/s41598-024-61124-0, p.7]
- **limitations：** 论文没有做人类评估，完全依赖自动指标，作者也承认这些指标未必与 human judgment 一致。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.6]
- **limitations：** 作者还指出 transformer 的 O(n²) attention 复杂度可能限制扩展，并把 Mamba 类 SSM 视为未来方向。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.6]
- **method：** 以 MolT5（T5-based）作为主体模型，将 molecule-caption 预训练权重迁移到 drug-to-indication 与 indication-to-drug 两个生成任务，并分别做 FULL、SUB、FT 三类评估。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.7]
- **method：** drug-to-indication 使用 BLEU、ROUGE、METEOR 与 Text2Mol；indication-to-drug 使用 exact、Levenshtein、MACCS/RDK/Morgan、FCD、Text2Mol 和 Validity。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.5]
- **method：** custom tokenizer 版本只对 77M 参数的最小 MolT5 做了从头预训练，tokenizer 会把 SMILES 分解为语法有效片段，并在 ZINC 上用 span-masked LM objective 训练。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.7]
- **method：** 作者还把模型输出示例和表格结果并列展示，并用 RDKit 检查生成 SMILES 的合法性。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]
- **results：** 在 baseline MolT5 上，larger 版本在两个任务和多数指标上普遍优于 small/base。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.3]；[doi:10.1038/s41598-024-61124-0, p.4]；[doi:10.1038/s41598-024-61124-0, p.5]
- **results：** 原始 MolT5 的 fine-tuning 往往伤害性能，尤其 FT 行在 drug-to-indication 和 indication-to-drug 上普遍低于 SUB/FULL。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.4]；[doi:10.1038/s41598-024-61124-0, p.5]
- **results：** DrugBank 往往比 ChEMBL 更容易，作者把这归因于 DrugBank 的适应证描述更详细。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.4]；[doi:10.1038/s41598-024-61124-0, p.6]
- **results：** custom tokenizer 后，drug-to-indication 在 DrugBank 上较好，且 fine-tuning 不再像基线那样稳定退化，但 indication-to-drug 仍然很不稳定。
  - 证据：[doi:10.1038/s41598-024-61124-0, p.6]；[doi:10.1038/s41598-024-61124-0, p.7]

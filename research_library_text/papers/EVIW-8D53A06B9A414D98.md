# Bidirectional generation of structure and properties through a single molecular foundation model

- **论文 ID：** `EVIW-8D53A06B9A414D98`

- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`

## 作者主张的创新点

作者提出 SPMM，一个结构-性质双模态 molecular foundation model，把 SMILES 与 property vector 对齐到共享空间，并用同一套预训练模型实现结构/性质的双向生成与预测，同时可迁移到分子分类和反应预测。

## 创新边界

`核心创新在于把 property vector 当作独立模态来做双向生成训练；冻结证据只支持这是作者提出的新方案，不能证明其在全球范围内首次实现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

现有分子基础模型多偏单模态，难以在同一模型里同时理解 SMILES 结构与化学性质，并支持性质条件下的分子生成、性质反推和反应预测。

## 方法

- SMILES/PV双encoder+fusion，next token/property、matching与contrastive objectives联合预训练。

## 数据与基准

- 大规模分子/53属性预训练、PubChem未见1000 PV及多个下游。

## 比较基线

- 单模态分子PLM和任务特定模型。

## 结果证据

- PV-to-SMILES生成53项归一化平均RMSE 0.216；生成/性质一致性均为计算。

## Pi 结构化证据摘录

- **baseline：** MoleculeNet 对比对象包括 D-MPNN、N-GramRF/XGB、PretrainGNN、GROVERlarge、ChemRL-GEM、ChemBERTa-2 和 MolFormer；无预训练版本明显更弱，说明预训练贡献较大。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.8]
- **baseline：** DILI 对比基线包括 Ai et al. 的最佳单模型与 5-ensemble；SPMM 不仅优于无预训练版本，也超过 5-ensemble 的 AUROC。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.9]
- **baseline：** 反应预测对比了 Molecular Transformer、Augmented Transformer、Chemformerlarge、Graph2SMILES、MEGAN、LocalTransform、SCROP 和 Two-way Transformer；SPMM 在 forward 任务取得最高 top-1。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.9]
- **data：** 预训练数据来自 PubChem 的 50,000,000 条 SMILES；作者还用 RDKit 计算 53 个分子性质来构造属性模态。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.11]；[doi:10.1038/s41467-024-46440-3, p.12]
- **data：** 下游评测覆盖 1000 个未见的 PubChem/ZINC15 分子、MoleculeNet 的九个任务、DILI 数据集，以及 USPTO-480k 和 USPTO-50k 反应数据。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.3]；[doi:10.1038/s41467-024-46440-3, p.5]；[doi:10.1038/s41467-024-46440-3, p.6]；[doi:10.1038/s41467-024-46440-3, p.8]；[doi:10.1038/s41467-024-46440-3, p.9]；[doi:10.1038/s41467-024-46440-3, p.12]
- **declared_resources：** 论文声明 PubChem、ZINC15、DeepChem/MoleculeNet、DILI 预处理来源，以及 USPTO-480k 和 USPTO-50k 数据集都可获取，并提供 Source data。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.12]
- **declared_resources：** 源码、53 个 properties 列表、实验代码和数据集都托管在 GitHub 仓库与 Zenodo DOI 上。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.12]
- **limitations：** 作者明确承认 SMILES 表达本身有局限，图表示可能更合适；当前使用的 53 个性质也不含立体化学信息。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.7]；[doi:10.1038/s41467-024-46440-3, p.8]
- **limitations：** 作者认为性能还受属性集合设计和语料规模限制：53 个性质是为了尽量覆盖广度而非最优组合，50M 预训练数据相对其他大规模方法仍偏小。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.7]
- **limitations：** 作者还指出需要 wet-lab experiments 来验证模型生成或预测的性质，这是本工作尚未覆盖的后续方向。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.8]
- **method：** SPMM 采用双流 Transformer：分别用 SMILES encoder 和 PV encoder 做单模态 self-attention，再通过 fusion encoder 用 cross-attention 建模两种模态的对应关系。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.2]；[doi:10.1038/s41467-024-46440-3, p.3]；[doi:10.1038/s41467-024-46440-3, p.10]；[doi:10.1038/s41467-024-46440-3, p.11]
- **method：** 预训练同时优化 contrastive learning、Next Word Prediction、Next Property Prediction 和 SMILES-PV Matching，并引入 momentum teacher 与 hard-negative mining。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.10]；[doi:10.1038/s41467-024-46440-3, p.11]
- **method：** PV 被整理为 53 个 RDKit 属性的序列，先做线性 value encoding，再随机 50% mask 成 [UNK]，并加可学习 positional embedding 作为输入。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.8]；[doi:10.1038/s41467-024-46440-3, p.9]；[doi:10.1038/s41467-024-46440-3, p.10]
- **results：** 在 PV-to-SMILES 生成中，确定性采样对 1000 个未见 PV 达到 99.5% 有效率、0.999 去重率、0.961 新颖率和 0.216 normalized RMSE；随机采样下多数场景也保持较高有效性。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.3]；[doi:10.1038/s41467-024-46440-3, p.4]
- **results：** 在 SMILES-to-PV 生成中，作者报告 1000 个 ZINC15 分子上的 53 项属性预测平均 r2 为 0.924，且注意力可视化显示模型学到了结构-性质对应关系。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.5]
- **results：** 在单模态基准上，SPMM 被作者称为 MoleculeNet 九个任务中五个最佳；DILI 上达到 84.4% Acc 和 92.6% AUROC；反应预测上 forward top-1 为 91.5%，retro top-1 为 53.4%。
  - 证据：[doi:10.1038/s41467-024-46440-3, p.6]；[doi:10.1038/s41467-024-46440-3, p.8]；[doi:10.1038/s41467-024-46440-3, p.9]

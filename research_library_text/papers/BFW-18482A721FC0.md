# ProteinDJ: A high-performance and modular protein design pipeline

- **期刊 / 来源：** Protein Sci

- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 ProteinDJ，一个基于 Nextflow 和 Apptainer 的模块化 protein design pipeline，串联 RFdiffusion/BindCraft、ProteinMPNN/FAMPNN、AlphaFold2 Initial Guess/Boltz-2，并加入 Bindsweeper、统一元数据、模式化参数校验与结果排序能力。

## 创新边界

`主要新意在工作流编排、HPC 并行、参数扫描和统一封装，不在于提出新的底层生成式蛋白模型。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何把现有 de novo protein binder design 工具链封装成可在 HPC 上高并行、易配置、可复现输入输出、并能系统比较不同软件组合的开源工作流。

## 方法

- 可配置Nextflow modes串联生成、sequence、cofold、filter、压缩metadata和uncropped target恢复。

## 数据与基准

- PD-L1 1000 binder benchmark及各模块效率/过滤输出。

## 比较基线

- 原工具独立运行与不同模块组合。

## 结果证据

- 论文报告高性能并行与标准文件/metadata管理；只是计算工作流，不证明binder实验成功。

## 已知限制

- 依赖上游工具、权重/HPC和in-silico过滤；成功率仍需大量GPU与实验筛选。

## 仍未知

- 文中没有湿实验结果，无法判断计算优势是否稳定转化为体外成功率。
- 与同期其他 pipeline 的真正增量贡献主要是工程整合，缺少独立第三方复现对比。
- 作者声明未来才支持对称寡聚体和小分子设计，当前适用范围仍有限。

## Pi 结构化证据摘录

- **baseline：** 并行效率的对照基线是单 GPU 串行运行；ProteinDJ 相对该基线在 2、4、8 GPU 上保持 97.0%、93.6% 和 86.5% 的效率。
  - 证据：[doi:10.1002/pro.70464, p.4]；[doi:10.1002/pro.70464, p.15]
- **baseline：** 方法对照覆盖 RFdiffusion、BindCraft、ProteinMPNN、FAMPNN、AlphaFold2 Initial Guess、Boltz-2，以及文中讨论的 BinderFlow、RFdiffusion2/3、BoltzGen 和 Ovo。
  - 证据：[doi:10.1002/pro.70464, p.2]；[doi:10.1002/pro.70464, p.3]；[doi:10.1002/pro.70464, p.9]；[doi:10.1002/pro.70464, p.10]
- **data：** 用于 benchmark 的 target 来自 RFdiffusion 论文中的五个蛋白，并在 PD-L1 上做了比较；fold conditioning 的 scaffold 也来自已发表的 minibinder 数据集。
  - 证据：[doi:10.1002/pro.70464, p.8]；[doi:10.1002/pro.70464, p.14]
- **data：** 性能测试使用 1、2、4、8 张 NVIDIA A30 GPU 和 SLURM 运行记录，runtime 以实际 compute time 统计，不含 queue time。
  - 证据：[doi:10.1002/pro.70464, p.14]；[doi:10.1002/pro.70464, p.15]
- **data：** 成功率过滤依赖 AlphaFold2 Initial Guess 的三项阈值：af2_max_rmsd_binder_bndaln、af2_max_pae_interaction 和 af2_min_plddt_total。
  - 证据：[doi:10.1002/pro.70464, p.15]
- **data：** ProteinDJ 通过 fold_id 和 seq_id 追踪每个设计的 PDB 与 JSON metadata，以便最后合并为 CSV 并保留全流程记录。
  - 证据：[doi:10.1002/pro.70464, p.5]
- **declared_resources：** 代码仓库公开在 https://github.com/PapenfussLab/proteindj，论文还说明容器镜像托管在 GitHub Container Repository。
  - 证据：[doi:10.1002/pro.70464, p.15]
- **declared_resources：** 论文声明支撑结果的数据位于补充材料和 Data S1，便于复核 benchmark 与筛选结果。
  - 证据：[doi:10.1002/pro.70464, p.15]
- **declared_resources：** 作者还提供了详细文档与示例，并在正文中说明这些资源用于不同设计任务的上手。
  - 证据：[doi:10.1002/pro.70464, p.9]；[doi:10.1002/pro.70464, p.15]
- **limitations：** 作者明确指出该管线采用线性设计流程，不做 recycling；自动迭代可能有用，但需要避免 combinatorial explosion。
  - 证据：[doi:10.1002/pro.70464, p.9]
- **limitations：** 当前版本只做单蛋白链的 amino acid design，未启用对称寡聚体设计，因为 ProteinMPNN 和 FAMPNN 的对称序列设计仍需大量重编程。
  - 证据：[doi:10.1002/pro.70464, p.9]
- **limitations：** FastRelax 能提高 in silico success rate，但会显著增加 runtime；论文也明确说是否能提升 in vitro 成功率仍需进一步实验验证。
  - 证据：[doi:10.1002/pro.70464, p.9]
- **limitations：** 作者把小分子与更新版本的工具留作未来工作，说明当前适用范围仍主要限于单链蛋白 binder 设计。
  - 证据：[doi:10.1002/pro.70464, p.9]；[doi:10.1002/pro.70464, p.10]
- **method：** ProteinDJ 把 fold design、sequence design、structure prediction 和 analysis/reporting 串成四阶段 Nextflow 工作流，并用 Apptainer 容器化部署到 HPC/SLURM。
  - 证据：[doi:10.1002/pro.70464, p.2]；[doi:10.1002/pro.70464, p.3]；[doi:10.1002/pro.70464, p.10]；[doi:10.1002/pro.70464, p.11]
- **method：** 工作流可在 RFdiffusion、BindCraft、ProteinMPNN、FAMPNN、AlphaFold2 Initial Guess 和 Boltz-2 之间切换，并通过 centralized configuration 控制 GPU/CPU 资源、排序与输出。
  - 证据：[doi:10.1002/pro.70464, p.3]；[doi:10.1002/pro.70464, p.11]；[doi:10.1002/pro.70464, p.14]
- **method：** 作者为 RFdiffusion/BindCraft 设计了 monomer、binder、de novo、fold conditioning、partial diffusion 和 motif scaffolding 等模式，并对 contig、hotspot 和输入格式做了校验。
  - 证据：[doi:10.1002/pro.70464, p.5]；[doi:10.1002/pro.70464, p.7]；[doi:10.1002/pro.70464, p.11]；[doi:10.1002/pro.70464, p.12]
- **method：** Bindsweeper 被实现为 Python 命令行工具，可生成参数组合矩阵、批量运行多个 ProteinDJ 配置，并汇总成功率与最佳参数组合。
  - 证据：[doi:10.1002/pro.70464, p.7]；[doi:10.1002/pro.70464, p.8]
- **results：** 在 8 张 A30 GPU 上，ProteinDJ 生成并评估 500 个 binder folds 和 4000 个 unique sequences 用时 2h26m，单 GPU 为 16h55m，8 GPU 并行效率为 86.5%。
  - 证据：[doi:10.1002/pro.70464, p.4]
- **results：** 在 PD-L1 benchmark 上，RFdiffusion 平均每个 fold 54.9 s，BindCraft 620.5 s；ProteinMPNN 1.3 s/sequence，FastRelax 后 56.9 s；FAMPNN 4.8 s/sequence；Boltz-2 8.6 s/prediction，AlphaFold2 Initial Guess 16.4 s。
  - 证据：[doi:10.1002/pro.70464, p.4]
- **results：** Bindsweeper 的比较显示，加入 FastRelax 后 ProteinMPNN 的 success rate 明显提升，SolMPNN 在 5 个 target 中有 3 个优于 vanilla，FAMPNN 则表现更不稳定。
  - 证据：[doi:10.1002/pro.70464, p.8]；[doi:10.1002/pro.70464, p.10]
- **results：** 表 1 中，ProteinMPNN(Soluble)+FastRelax 在各 target 上给出最高或并列最高的 in silico success rate，PD-L1 最高达到 52.3%。
  - 证据：[doi:10.1002/pro.70464, p.10]

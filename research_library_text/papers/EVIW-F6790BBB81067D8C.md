# Biosensor and machine learning-aided engineering of an amaryllidaceae enzyme

- **论文 ID：** `EVIW-F6790BBB81067D8C`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Mar 7
- **DOI：** [10.1038/s41467-024-46356-y](https://doi.org/10.1038/s41467-024-46356-y)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

论文声称构建了一个由定向进化 biosensor 与结构基础机器学习组成的工程链条：先把 RamR 进化成对 4NB 高选择性的传感器 4NB2.1，再开发可处理 protein-ligand interface 的 MutComputeX 3DResNet，借此筛得 Nb4OMT 变体 E36P/G40E/A53M；该变体带来更高产量、更高催化活性、更少副产物，并且作者还解析了对应晶体结构。

## 创新边界

`新意主要在于把可进化 biosensor 与显式包含配体原子的结构驱动 ML 结合起来做酶工程；它不是在提出全新的 Amaryllidaceae 通路，也不是在做从头路径重构的完整商业化体系。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：如何为 Amaryllidaceae 生物碱生物制造建立可高通量监测的高选择性 biosensor，并用结构化机器学习加速关键酶 Nb4OMT 的工程优化，从而提高 4′-O-methylnorbelladine 及相关通路的微生物生产效率。

## 方法

- 先定向进化代谢物生物传感器，再由结构残差网络生成活性富集变体，使用生物传感器和定量实验筛选，并以晶体结构解释突变。[doi:10.1038/s41467-024-46356-y, p.1][doi:10.1038/s41467-024-46356-y, p.4]

## 数据与基准

- 以植物 norbelladine-4-O-methyltransferase 的结构、序列和突变实验为核心，结合 GNINA 对接、传感器读出及酶学/产物数据。[doi:10.1038/s41467-024-46356-y, p.2][doi:10.1038/s41467-024-46356-y, p.12]

## 比较基线

- 与野生型和随机/定向进化筛选比较；早期筛选未找到优于野生型的变体，MutComputeX 用作互补设计策略。[doi:10.1038/s41467-024-46356-y, p.4]

## 结果证据

- 功能变体在本文体系中实现产物滴度提高 60%、催化活性约 2 倍、非目标区域异构体约降低 3 倍，并由晶体结构支持关键突变机制。[doi:10.1038/s41467-024-46356-y, p.1]

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 只验证一个植物甲基转移酶及特定底物/宿主；模型增益可能依赖结构质量、传感器动态范围和当前突变分布。[doi:10.1038/s41467-024-46356-y, p.1][doi:10.1038/s41467-024-46356-y, p.4]

## 仍未知

- 补充材料中的具体筛选分布与更多负结果未在正文页文本中完整展开。
- MutComputeX 对其他酶、其他配体和更复杂界面的外推能力尚未独立验证。
- 工作尚未展示从头完整 galantamine 通路的端到端微生物生产。

## Pi 结构化证据摘录

- **baseline：** 与 WT RamR 相比，第一轮变体 4NB1.2 已把 4NB/norbelladine 选择性提升到约 20-fold，但仍不如后续 4NB2.1。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.2]；[doi:10.1038/s41467-024-46356-y, p.3]
- **baseline：** 作者明确写到，仅靠 error-prone PCR 随机突变的 Nb4OMT 筛选并没有找到优于 WT 的变体。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]
- **baseline：** 旧版 MutCompute 3DCNN 不能纳入非蛋白原子，在 protein-ligand interface 上的 wild-type accuracy 明显低于 MutComputeX。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.10]
- **baseline：** WT Nb4OMT 在基线实验中仍留下明显 norbelladine，并产生 3′-O-methyl-norbelladine 副产物，说明原始酶的活性与专一性都不足。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.5]
- **data：** WT RamR 对 4NB 和 norbelladine 都有弱响应，荧光分别约上升 3.8 倍和 4.4 倍。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.2]
- **data：** 4NB2.1 对 4NB 的检测下限约为 2.5 μM，并且相对 norbelladine 具有超过 80-fold 的偏好。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.3]
- **data：** 作者报告 biosensor 可辨别的 4NB 范围约为 2.5–250 μM，而 HPLC 方法约为 25–1000 μM。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]
- **data：** MutComputeX 的训练数据来自 22,584 条蛋白链和 2,569,256 个 microenvironments，覆盖 22,584 protein sequences。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.10]
- **data：** 22 个经实验验证的设计中，A53M 在多种条件下始终优于 WT，而 E36P/G40E/A53M 进一步提高了稳定性。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.5]；[doi:10.1038/s41467-024-46356-y, p.6]；[doi:10.1038/s41467-024-46356-y, p.7]
- **data：** Nb4OMT E36P/G40E/A53M 的晶体结构以 2.4 Å 分辨率解析，并显示该蛋白在晶体中形成 homodimer。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.7]；[doi:10.1038/s41467-024-46356-y, p.12]
- **declared_resources：** 实验宿主与基础系统主要是 E. coli DH10B 和 BL21(DE3)，培养基使用 LB，核心质粒包括 pReg-RamR、Pramr-GFP、pSELIS-RamR 与 pSens4NB2.1。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.9]；[doi:10.1038/s41467-024-46356-y, p.10]
- **declared_resources：** 化学与生化资源包括合成 norbelladine、商业 4′-O-methylnorbelladine、SAH/SAM、tyramine、3,4-dihydroxybenzaldehyde 及相关溶剂试剂。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.9]；[doi:10.1038/s41467-024-46356-y, p.11]
- **declared_resources：** 作者声明的结构与数据资源包括 Addgene 216231/216232、PDB 8UKE、PubChem 416247，以及用于对接的 PDB 1SUI。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.12]；[doi:10.1038/s41467-024-46356-y, p.13]
- **declared_resources：** 代码资源在正文中明确给出，包括 github.com/simonsnitz/plotting 与 github.com/danny305/MutComputeX。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.12]；[doi:10.1038/s41467-024-46356-y, p.13]
- **limitations：** 作者自己也指出，Amaryllidaceae 完整生物合成通路尚未在微生物中完全重构，上游底物与后续酶步骤仍是主要瓶颈。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.8]；[doi:10.1038/s41467-024-46356-y, p.9]
- **limitations：** MutComputeX 的设计依赖 AlphaFold2 与 GNINA 的建模结果，而且作者承认实验结构与 AlphaFold2 模型会因缺少 metal ions、ligands 和 cofactors 而偏离。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.8]
- **limitations：** 论文没有证明工业规模发酵或商业可行性，只展示了可加速工程的工具链与单酶层面的提升。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.8]；[doi:10.1038/s41467-024-46356-y, p.9]
- **limitations：** A53M 和 triple mutant 存在 substrate inhibition，因此稳态动力学参数只能给出部分上下限。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.11]
- **method：** 作者以 TetR-family 调控蛋白 RamR 为起点，使用 SELIS 对三个 inward-facing 三残基位点库进行两轮定向进化，得到对 4NB 更敏感且更专一的 biosensor 变体。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.2]；[doi:10.1038/s41467-024-46356-y, p.3]；[doi:10.1038/s41467-024-46356-y, p.9]
- **method：** 作者结合 GNINA 对 RamR 与 4NB 的结合模式做对接，并用 4NB2.1 的荧光响应与 HPLC 测量对比其可用于高通量筛选的动态范围。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.2]；[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.10]
- **method：** 作者将 MutCompute 扩展为 MutComputeX，加入 P 与 halogen 通道，并用约 2.57M microenvironments 和 3D residual network 训练模型，使其可用于 protein-ligand interface。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.10]
- **method：** 作者先用 AlphaFold2 为 Nb4OMT 建模，再把 SAH 与 norbelladine 用 GNINA 对接到活性位点，生成 ternary complex 供 MutComputeX 预测可接受的氨基酸替换。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.5]；[doi:10.1038/s41467-024-46356-y, p.10]；[doi:10.1038/s41467-024-46356-y, p.11]
- **method：** 作者在 E. coli 中把 biosensor 与 Nb4OMT 变体联用，并通过荧光、HPLC、LC/MS、动力学测定、DSF 和 X-ray crystallography 验证设计结果。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.5]；[doi:10.1038/s41467-024-46356-y, p.6]；[doi:10.1038/s41467-024-46356-y, p.7]；[doi:10.1038/s41467-024-46356-y, p.11]；[doi:10.1038/s41467-024-46356-y, p.12]
- **results：** 4NB2.1 让 4NB 与 norbelladine 的选择性拉到超过 80-fold，足以用于监测 pathway activity。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.3]；[doi:10.1038/s41467-024-46356-y, p.4]
- **results：** A53M 使 4NB 产量提高约 60%，残余 norbelladine 降低约 17-fold，同时 3′-O-methyl-norbelladine 约降低 3-fold。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.6]
- **results：** A53M 将 kcat/Km 提高约 2 倍、kcat 提高超过 2.1-fold，并把 Tm 提高 1.7 °C；三突变体把 Tm 再提高到比 WT 高 5.6 °C。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.6]；[doi:10.1038/s41467-024-46356-y, p.7]
- **results：** 晶体结构支持作者对 A53M 的解释：该位点填充了疏水 pocket，并可能通过 sulfur-π 作用限制底物构象，从而提升专一性。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.7]；[doi:10.1038/s41467-024-46356-y, p.8]
- **results：** MutComputeX 在作者挑选的 3DResNet 中对 wild-type residue prediction 表现优于旧模型，且在 protein-ligand interface 上没有明显掉点。
  - 证据：[doi:10.1038/s41467-024-46356-y, p.4]；[doi:10.1038/s41467-024-46356-y, p.10]

# Enhancing efficiency of protein language models with minimal wet-lab data through few-shot learning

- **论文 ID：** `EVIW-6C65D455AB73D2E8`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Jul 2
- **DOI：** [10.1038/s41467-024-49798-6](https://doi.org/10.1038/s41467-024-49798-6)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 FSFP，将 meta-transfer learning、LoRA 和 learning-to-rank 结合起来，用仅几十个目标蛋白的单点突变标签即可强化 PLM，并在 ProteinGym 与 Phi29 上验证其少样本适配能力。

## 创新边界

`主要创新在训练范式组合与少样本适配流程，而不是新的 PLM backbone 或新的实验平台。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在湿实验标注极少的条件下，如何有效微调蛋白语言模型，以更准确地排序蛋白突变适应度并支持定向进化。

## 方法

- 从ProteinGym检索相近任务并生成MSA伪标签；MAML式元学习、ranking loss和LoRA；用Monte Carlo交叉验证决定小样本训练步数。

## 数据与基准

- ProteinGym 87个DMS集合；每任务随机20至100条单突变训练；湿实验用少量Phi29 DNA聚合酶候选。

## 比较基线

- ESM-1v、ESM-2、SaProt零样本/直接微调、ridge regression、一热+进化分数及FSFP各模块消融。

## 结果证据

- 20条标签时平均Spearman最高提升约0.1；论文报告聚合酶top-20候选正例率提升25%，并提高平均Tm。

## 已知限制

- 性能依赖检索到的相关任务和伪标签；小样本验证分数不稳定；实验只覆盖一个目标，且多位点外推仍受训练分布影响。

## Pi 结构化证据摘录

- **baseline：** 少样本主基线是 ridge regression，输入为 one-hot residue features 与 evolutionary probability density feature。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.4]
- **baseline：** 作者还比较了 zero-shot inference、MSE、MSE+LoRA、LTR+LoRA、LTR+LoRA+MTL（no MSA）等训练策略，以分离各组件的贡献。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.4]；[doi:10.1038/s41467-024-49798-6, p.5]
- **baseline：** 在更全面的比较中，作者增加了 GEMME 与 GEMME+ridge 作为 MSA-based baselines，并将其与 ESM-1v、ESM-2、SaProt 的 FSFP 版本对照。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.5]；[doi:10.1038/s41467-024-49798-6, p.6]
- **data：** ProteinGym substitution benchmark 约含 150 万个 missense variants，来自 87 个 DMS assays，其中 11 个数据集含 multi-site mutants；作者按 20/40/60/80/100 个 single-site mutants 构建少样本训练集，并重复 5 次随机划分。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.4]；[doi:10.1038/s41467-024-49798-6, p.10]
- **data：** 在 SaProt 的输入构建中，作者需要蛋白结构，并说明结构可来自 AlphaFold2 或 AlphaFoldDB；Benchmark 的具体结果以 Supplementary Data 1/2 和 Source data 形式提供。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.10]；[doi:10.1038/s41467-024-49798-6, p.11]
- **data：** Phi29 wet-lab 部分先用 ESM-1v zero-shot 选出 top 20 single-site mutants，测定其 Tm 作为训练标签，再用 FSFP 训练后继续筛选下一轮 top 20 变体。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.7]；[doi:10.1038/s41467-024-49798-6, p.8]；[doi:10.1038/s41467-024-49798-6, p.11]
- **declared_resources：** Benchmark 数据与详细结果通过 ProteinGym、Supplementary Data 1/2 以及 Source data 提供。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.10]；[doi:10.1038/s41467-024-49798-6, p.11]
- **declared_resources：** FSFP 源代码公开在 GitHub：https://github.com/ai4protein/FSFP。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.11]
- **limitations：** 作者明确承认，zero-shot PLM 并不总是优于 MSA 方法，且对 non-natural catalytic properties 的预测能力仍有限。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.2]；[doi:10.1038/s41467-024-49798-6, p.6]
- **limitations：** FSFP 对辅助任务的质量与规模有依赖；作者指出，当辅助任务规模足够大且与目标蛋白更相近时，meta-learning 效果更好。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.8]；[doi:10.1038/s41467-024-49798-6, p.9]
- **limitations：** 不同 backbone 在不同数据集上优势不同，因此模型选择需要按目标蛋白与任务类型谨慎决定，不能预设统一最优。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.8]；[doi:10.1038/s41467-024-49798-6, p.9]
- **limitations：** 本篇 wet-lab 仅展示了 Phi29 DNA polymerase 一个验证案例，外推到其他蛋白仍需额外实证。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.7]；[doi:10.1038/s41467-024-49798-6, p.8]
- **method：** FSFP 通过 LoRA 冻结预训练 PLM 的原始参数，只训练低秩适配矩阵，并将更新限制在自注意力层和前馈层中的少量可训练参数上。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.2]；[doi:10.1038/s41467-024-49798-6, p.9]
- **method：** FSFP 将 fitness 预测改写为 ranking problem，采用 ListMLE/Plackett-Luce 形式的损失，并以突变体与野生型的对数似然差作为打分函数。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.2]；[doi:10.1038/s41467-024-49798-6, p.9]
- **method：** FSFP 先构建三个辅助任务：从 ProteinGym 检索两个与目标蛋白相似的 DMS 数据集，再用 GEMME 基于目标蛋白 MSA 生成伪标签；随后用 MAML 对 LoRA 初始化做 meta-training，再迁移到目标 few-shot 任务。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.2]；[doi:10.1038/s41467-024-49798-6, p.3]；[doi:10.1038/s41467-024-49798-6, p.9]；[doi:10.1038/s41467-024-49798-6, p.10]
- **method：** 迁移阶段用 Monte Carlo cross-validation 选择 early stopping 步数；内层优化用 SGD，外层 meta-optimization 用 Adam。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.10]
- **results：** 在 ESM-2 的 ablation 中，直接全量 MSE 微调会明显退化；加入 LoRA 可缓解过拟合，但性能仍弱于包含 LTR 与 MTL 的 FSFP。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.4]；[doi:10.1038/s41467-024-49798-6, p.5]
- **results：** FSFP 在 87 个数据集上对 single-site 和 multi-site mutants 都稳定优于 zero-shot、ridge regression 以及 GEMME 系列基线，且 SaProt (FSFP) 是总体最强的配置。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.5]；[doi:10.1038/s41467-024-49798-6, p.6]
- **results：** 作者报告 FSFP 在仅 20 个标注样本时即可把平均 Spearman correlation 提升到约 0.1 的量级，相比 zero-shot 有明显增益。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.1]；[doi:10.1038/s41467-024-49798-6, p.2]；[doi:10.1038/s41467-024-49798-6, p.5]
- **results：** Phi29 实验显示，经 FSFP 训练后的 ESM-1v 所选 top 20 变体平均 Tm 提升超过 1 °C，positive rate 提升 25%。
  - 证据：[doi:10.1038/s41467-024-49798-6, p.8]

# CPL‐Diff: A Diffusion Model for De Novo Design of Functional Peptide Sequences with Fixed Length

- **论文 ID：** `EVIW-466228B7D151118B`
- **期刊 / 来源：** Adv Sci (Weinh)
- **发表时间：** 2025 Apr 15
- **DOI：** [10.1002/advs.202412926](https://doi.org/10.1002/advs.202412926)
- **范围标签：** `Pi 已解析` / `核心相关` / `有静态审计仓库` / `肽与抗菌肽` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文声称提出了基于 ESM-2 latent space 的 Transformer diffusion model CPL-Diff，通过 attention mask 直接控制生成长度、用 classifier-free conditional generation 指定肽类别，并结合 interpretability analysis 与 simulated docking 来评估生成序列的质量与结构关联。

## 创新边界

`本稿的创新边界主要在于把 attention mask 用作固定长度控制，并与 ESM-2 latent diffusion 及 conditional generation 组合起来；冻结证据足以支持其方法新意，但不足以验证相对于全部外部文献的全球首创性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

论文要解决的是：在 functional peptide de novo design 中，如何在生成 AMP、AFP、AVP 等候选序列时同时控制序列长度，因为长度会显著影响理化性质、活性与治疗效果，而现有生成模型大多不能稳定控制长度。

## 方法

- 将肽序列映射到连续嵌入，条件去噪网络接收长度/类型标签，再解码生成固定长度序列。

## 数据与基准

- 整合APD3、dbAMP、DRAMP、DBAASP、LAMP2、SATPdb等AMP/AFP/AVP数据；仓库包含多类FASTA/CSV。

## 比较基线

- RNN/VAE/GAN及其他条件扩散/蛋白生成方法。

## 结果证据

- 论文报告生成序列在类别性质和计算评价上优于比较模型；未证明抗菌、抗真菌或抗病毒实验活性。

## Pi 结构化证据摘录

- **baseline：** 比较对象包括 LSTM-RNN、AMPGAN、HydrAMP 和 ProGen；为了公平比较，基线在采样时使用统一的长度抽样策略，而 CPL-Diff 则显式控制长度。
  - 证据：[doi:10.1002/advs.202412926, p.8]；[doi:10.1002/advs.202412926, p.9]
- **baseline：** 文中还说明 HydrAMP 因依赖特定生物知识，直接采用其团队提供的生成序列；并给出了不同 guidance strength 的补充比较。
  - 证据：[doi:10.1002/advs.202412926, p.9]；[doi:10.1002/advs.202412926, p.10]
- **data：** 训练数据来自 APD3、CAMPR4、dbAMP2、LAMP2、DRAMP 3.0、DBAASP v3 和 GRAMPA 等公开数据库。
  - 证据：[doi:10.1002/advs.202412926, p.8]
- **data：** 作者筛掉长度 5–50 aa 之外的序列，并排除 U、Z、O、B、J 以及含 X 的条目，去重后得到 23,465 条可用序列，再按 8:2 划分训练与测试。
  - 证据：[doi:10.1002/advs.202412926, p.8]
- **data：** 数据分布为 antimicrobial 11,347/2,837、antifungal 4,658/1,165、antiviral 2,767/691，且作者把 antibacterial 与 antimicrobial 合并处理。
  - 证据：[doi:10.1002/advs.202412926, p.8]
- **data：** 实现细节包括单张 NVIDIA Tesla A100 80G、batch size 64、ESM2-8M 冻结编码、6 层注意力块、20 heads、hidden size 320、T=2000，以及 0.1 的条件丢弃概率。
  - 证据：[doi:10.1002/advs.202412926, p.9]
- **declared_resources：** 论文首页明确给出代码仓库链接：https://github.com/luozhenjie1997/CPL-Diff。
  - 证据：[doi:10.1002/advs.202412926, p.1]
- **declared_resources：** 作者声明数据可在合理请求下由通讯作者提供。
  - 证据：[doi:10.1002/advs.202412926, p.21]
- **declared_resources：** 论文声明该工作获得国家自然科学基金和海南省“南海新星”创新平台资助。
  - 证据：[doi:10.1002/advs.202412926, p.21]
- **limitations：** 作者明确指出 DDPM 需要大量迭代才能得到最终结果，因此生成过程计算开销较大，并建议后续改用 DDIM 等更高效的采样策略。
  - 证据：[doi:10.1002/advs.202412926, p.21]
- **limitations：** 作者也承认类别不平衡会导致不同 peptide 类别学习不均，计划通过样本平衡和调整 conditional/unconditional mixing weights 来缓解。
  - 证据：[doi:10.1002/advs.202412926, p.21]
- **limitations：** 论文还提出后续要扩展到 anticancer peptides，并尝试同时生成序列与对应结构构象。
  - 证据：[doi:10.1002/advs.202412926, p.21]
- **method：** 先用预训练 ESM-2 把肽序列映射到连续 latent space，再在该空间上按 DDPM 的 forward process 加噪、reverse process 去噪，训练 denoiser 直接回归原始 embedding。
  - 证据：[doi:10.1002/advs.202412926, p.4]；[doi:10.1002/advs.202412926, p.7]
- **method：** 去噪器采用 Transformer backbone，内部包含 multi-head attention、RoPE、FiLM、layer normalization 和 timestep encoding，并同时接收 noisy embedding、timestep、Attention mask 与类别标签。
  - 证据：[doi:10.1002/advs.202412926, p.5]；[doi:10.1002/advs.202412926, p.6]；[doi:10.1002/advs.202412926, p.7]
- **method：** 长度控制不是靠拟合长度分布，而是把目标长度写入 Attention mask；mask 中的 1 对应序列有效位置，并额外覆盖 CLS 与 EOS 两个特殊 token。
  - 证据：[doi:10.1002/advs.202412926, p.6]；[doi:10.1002/advs.202412926, p.7]
- **method：** 训练时以 0.1 的概率将类别标签置空，从而把 conditional 和 unconditional diffusion 合并到一个网络里；采样时再线性组合 conditional 与 unconditional 预测以调节 guidance strength。
  - 证据：[doi:10.1002/advs.202412926, p.5]；[doi:10.1002/advs.202412926, p.7]；[doi:10.1002/advs.202412926, p.8]
- **results：** 在 AMPs、AFPs 和 AVPs 三项生成任务上，CPL-Diff 的 perplexity 分别达到 10.8500、10.5346 和 13.4048，均优于文中所有 baseline。
  - 证据：[doi:10.1002/advs.202412926, p.9]；[doi:10.1002/advs.202412926, p.10]
- **results：** 三类任务的 activity 也都是最佳，分别为 0.9631、0.8822 和 0.7596，说明模型能较稳定地产生被外部分类器判为活性的序列。
  - 证据：[doi:10.1002/advs.202412926, p.9]；[doi:10.1002/advs.202412926, p.10]
- **results：** 与 real peptides 相比，CPL-Diff 生成序列的 pI、charge、hydrophobicity 和 aromaticity 整体分布较接近，部分任务还呈现更高的上四分位或更宽的取值范围。
  - 证据：[doi:10.1002/advs.202412926, p.10]；[doi:10.1002/advs.202412926, p.11]
- **results：** Ablation 结果显示，去掉 pLM、condition 或 mask control 都会明显恶化 perplexity、pLDDT、instability 与 activity；其中去掉 pLM 时性能接近随机序列。
  - 证据：[doi:10.1002/advs.202412926, p.16]
- **results：** 长度控制实验表明 attention matrix 会明显关注 CLS 和 EOS，且同一初始噪声可以在不同目标长度下生成不同序列，而不是简单在短序列尾部追加残基。
  - 证据：[doi:10.1002/advs.202412926, p.16]；[doi:10.1002/advs.202412926, p.17]；[doi:10.1002/advs.202412926, p.18]；[doi:10.1002/advs.202412926, p.19]

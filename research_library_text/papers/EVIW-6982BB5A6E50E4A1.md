# EnzyACT: A Novel Deep Learning Method to Predict the Impacts of Single and Multiple Mutations on Enzyme Activity

- **论文 ID：** `EVIW-6982BB5A6E50E4A1`
- **期刊 / 来源：** J Chem Inf Model
- **发表时间：** 2024 Jul 22
- **DOI：** [10.1021/acs.jcim.4c00920](https://doi.org/10.1021/acs.jcim.4c00920)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文提出 EnzyACT，把 ProtT5-XL-Uniref50 的 sequence embedding、mutation 周围的结构邻接图和若干 knowledge-based features 结合起来，用 GCN 处理单点突变、用 SVC 处理多点突变；作者声称该方法在多个独立数据集上优于现有基线，并可用于 P450 案例分析与 trade-off 机制解释。

## 创新边界

`其主要新意是特征融合、数据清洗/增强和单点到多点的分层预测流程；它是一个突变效应预测工具，而不是直接生成或优化 enzyme 候选的设计器。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：如何用通用、快速且准确的深度学习方法预测 enzyme 单点与多点 mutation 对 activity 的影响，以支持 enzyme engineering，并帮助理解 activity-stability trade-off。

- 实验条件/酶类偏差，epistasis数据少。

## 仍未知

- 多点突变的有效样本仍偏少，作者自己也提示需要更多实验数据，尤其是 activity-increasing 变体。
- 现有对比主要围绕 SCANEER 和少数 baseline，未能覆盖所有可能的同类方法。
- P450 个案的 trade-off 解释是否可推广到其他 enzyme，冻结证据无法确认。

## Pi 结构化证据摘录

- **baseline：** 单点部分主要对比 SCANEER，这是一种基于 MSA 和 coevolution 的方法，但作者指出它只覆盖约 47% 可评估变体。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]；[doi:10.1021/acs.jcim.4c00920, p.4]
- **baseline：** 多点部分使用 baseline1（把多个 single-point 概率取平均）和 baseline2（Montanucci/DDGun 风格公式）作为参照，并把 SCANEER 也改造成多点版本进行比较。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.7]
- **baseline：** 作者还测试了若干 shallow machine learning 方法以及 GraphConv、SAGEConv、GINConv、GATConv、ChebConv 和 MultiGraphConv，结果显示 GraphConv 最佳。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.4]；[doi:10.1021/acs.jcim.4c00920, p.8]
- **data：** 单点训练集 S10998 最终包含 10998 条记录、1303 个 proteins；原始数据中 5279 条是 activity decreased，220 条是 activity increased。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]
- **data：** 多点训练集 M576 来自 BRENDA，并通过约 30% 的随机划分和低于 32% sequence identity 的约束构成更严格的测试设置。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]
- **data：** 独立单点测试集包含 S2814 的 2814 条变体、420 个 proteins；P450 DMS 测试集包含 3289 条 single mutations。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]
- **data：** 多点 blind test set M167 包含 167 条记录、95 个 proteins，并且所有数据据称可在 Supporting Information 中获得。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]；[doi:10.1021/acs.jcim.4c00920, p.8]
- **declared_resources：** 训练与测试数据主要来自 D3DistalMutation、BRENDA 和若干文献数据集，作者同时给出 GitHub repository 与 Supporting Information 作为数据与结果入口。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]；[doi:10.1021/acs.jcim.4c00920, p.8]
- **declared_resources：** 序列表征与图学习资源包括 ProtT5-XL-Uniref50、ProtTrans 体系和 DGL。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.3]
- **declared_resources：** 结构与动力学分析资源包括 AlphaFold2、PyMOL Mutagenesis Wizard、NAMD、Amber ff19SB 和 AmberTools21。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]；[doi:10.1021/acs.jcim.4c00920, p.3]
- **declared_resources：** 论文在 Data Availability Statement 中声明了 https://github.com/GenScript-IBDPE/EnzyACT。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.8]
- **limitations：** 作者明确承认，多点任务里用 hypothetical inverse mutations 做增强会引入 uncertainty，而且 direct-data 训练在 M167 上比 symmetrical-data 训练更好。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.7]
- **limitations：** 单点和多点模型在 blind set 上的 recall 都不高，文中也直接说这可能意味着会漏掉不少 positive samples。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.6]；[doi:10.1021/acs.jcim.4c00920, p.8]
- **limitations：** 作者还写明，未来需要更多 case studies 来验证 generalizability，因此 P450 例子更像是案例级解释而非全局证明。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.8]
- **method：** 单点突变部分采用 DGL 实现的 GCN，把 ProtT5-XL-Uniref50 的 protein embedding、mutation 位点附近的空间邻接矩阵以及知识特征一起输入模型。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.3]
- **method：** 多点突变部分改用 SVC，并把 single-point 预测输出与补充特征一起作为训练输入，以减轻过拟合。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.3]
- **method：** 训练集从 D3DistalMutation 和 BRENDA 等来源抽取，经过 canonical label 归一化、去冗余、去 neutral mutation、去冲突标签，并用 inverse mutations 做平衡增强。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.2]
- **method：** P450 案例还进行了 0.5 μs all-atom MD simulation，使用 NAMD 和 Amber ff19SB，并用 RMSD、MMGBSA/MMPBSA 以及 DCCM 分析结构与动力学变化。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.3]；[doi:10.1021/acs.jcim.4c00920, p.6]
- **results：** 五折交叉验证中，single-point 模型的 accuracy 为 0.95、AUC 为 0.98；multiple-point 模型的 accuracy 为 0.83、AUC 为 0.83。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.3]
- **results：** 在 S2814 blind set 上，EnzyACT 的总体 accuracy 为 0.70、AUC 为 0.69；在去除高相似序列后的设置中可到 0.71/0.71，并优于 SCANEER。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.4]
- **results：** 在 P450 数据集上，EnzyACT 的 accuracy 为 0.93、AUC 为 0.80，预测分数与实验分数的 Spearman ρ 为 0.55（p < 0.0001）。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.4]；[doi:10.1021/acs.jcim.4c00920, p.5]
- **results：** 在多点测试集 M167 上，EnzyACT 的 accuracy 为 0.80、AUC 为 0.73；baseline1 和 baseline2 的 AUC 分别只有 0.49 和 0.56。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.7]
- **results：** P450 案例还定位到六个关键 substrate regions，并把 A291V 作为同时改善 activity 和 stability 的代表性变体。
  - 证据：[doi:10.1021/acs.jcim.4c00920, p.5]；[doi:10.1021/acs.jcim.4c00920, p.6]

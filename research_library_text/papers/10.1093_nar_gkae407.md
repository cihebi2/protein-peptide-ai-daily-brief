# Next-generation IEDB tools: a platform for epitope prediction and analysis

- **DOI：** [10.1093/nar/gkae407](https://doi.org/10.1093/nar/gkae407)

## 研究问题

IEDB 分析资源（IEDB-AR）20 年来工具分散在约30 个网页、界面不一、组合分析与结果共享困难。论文重构工具网站以统一界面、降低交互成本并支持流水线式表位预测分析。

## 作者主张的贡献

Next-Generation IEDB Tools（https://nextgen-tools.iedb.org）：整合 HLA class I 相关全部工具（MHC 结合、洗脱、免疫原性、加工）为单一应用并可同输入并发执行；新增 PEPMatch（在策展蛋白质组中查找高度相似表位）与表位聚类工具；支持工具间输出→输入的数据流水线、REST API/JSON、网页/API/独立版界面统一；多数任务点击次数减半以上。

## 创新边界

论文明确『重实现既有算法接口而非开发新算法』；预测算法（NetMHCpan EL 等）、IEDB 数据库均为既有资源；新颖性限于平台工程（整合、流水线、可用性）。

## 创新点证据卡

- **[p1]** HLA class I 全工具单应用整合与并发执行
  - 原文："consolidation of all tools related to HLA class I epitopes (MHC binding, elution, immunogenicity, and processing)"
- **[p1]** 工具间输出→输入的可复用数据流水线
  - 原文："The NG Tools site allows users to build data pipelines by sending the output of one tool as input for the next"
- **[p1]** PEPMatch 在策展蛋白质组中检索高度相似表位
  - 原文："the PEPMatch tool for identifying highly similar epitopes in a set of curated proteomes"
- **[p2]** 交互成本大幅降低：代表性任务点击从19次降到3次
  - 原文："requires 19 clicks on the legacy site as opposed to just 3 on NG"

## 方法

- 工具套件整合：TC1 套件统一肽:MHC 结合/洗脱/免疫原性/加工预测
- 数据流水线：一个工具的输出可过滤后作为下一工具输入
- REST API+JSON 统一输入输出格式，网页/API/standalone 一致
- 可用性专家参与界面设计，预填默认值实现一键预测

## 数据与基准

- IEDB 数据库实验数据（训练预测工具）
- PEPMatch 策展蛋白质组集合

## 结果证据

- 常见任务点击次数减少一半以上（如 NetMHCpan EL 4.1 长度8-11 预测从19 次点击降至3 次）
- 新旧站点结果一致（仅舍入精度差异）
- 日活用户600+ 的社区基础

## 比较基线

- 旧版 IEDB Tools 网站（约30 个分散页面）

## 已知限制

- 首个发布仅覆盖 HLA class I 套件，class II、B 细胞表位等工具待迁移
- 平台性质，无新预测算法贡献

## 待复核未知项

- PEPMatch 的匹配算法细节
- 流水线的可编程批量接口限制

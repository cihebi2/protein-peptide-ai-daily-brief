# DeepProSite: structure-aware protein binding site prediction using ESMFold and pretrained language model

- **论文 ID：** `EVIW-8C02585678F47251`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2023 Nov 28
- **DOI：** [10.1093/bioinformatics/btad718](https://doi.org/10.1093/bioinformatics/btad718)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 DeepProSite：把 ESMFold 预测结构、ProtT5 序列表示与 Graph Transformer 结合，用残基级图分类来预测结合位点，并声称可扩展到 DNA、RNA、ATP、HEME 和金属离子等多类配体。

## 创新边界

`可确认的边界是：该文把 ESMFold 预测结构引入结合位点预测，并在同一框架内融合结构与语言模型表示；但是否构成全局首创、以及与最新未纳入对比方法相比的绝对新颖性，当前冻存证据无法独立验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在蛋白序列可得而三维结构常常缺失的情况下，如何更准确地预测 protein–protein、peptide 以及其他配体的结合残基，同时弥补纯序列方法缺少空间信息、纯结构方法依赖已知结构的局限。

## 方法

- 从序列生成ESMFold结构和PLM嵌入，将残基图节点分类为界面/非界面，并扩展到蛋白、肽、核酸及其他配体位点。

## 数据与基准

- 沿用既有研究的结合位点训练/基准集合，并评估bound与unbound结构。

## 比较基线

- 既有序列位点预测器与依赖实验/输入结构的结构方法。

## 结果证据

- 作者报告在蛋白-蛋白/肽位点多数指标上优于序列和结构基线，在unbound结构上相对保持性能，并展示跨配体类型泛化。

## 可用资源与代码关系

## 已知限制

- 结构来自ESMFold，错误会传递；位点分类性能不等于生成的结合物具有真实亲和力，基准复用还需检查同源隔离。

## 仍未知

- GitHub 仓库中的代码、训练脚本与数据处理流程是否可直接复现文中数值。
- 多项 baseline 结果来自原文转引，是否存在预处理或划分差异无法在冻存证据内完全确认。
- ESMFold 结构误差在更广泛蛋白家族与真实部署场景中的影响仍需外部验证。

## Pi 结构化证据摘录

- **baseline：** 作者以同输入、同超参数的 Transformer 作为 geometry-agnostic baseline，用于分离空间信息带来的增益。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.5]
- **baseline：** 肽位点对比包括 SPRINT-Seq、PepBind、Visual、PepNN-Seq、PepBCL、PepSite、Peptimap、SPRINT-Str 和 PepNN-Struct。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.7]；[doi:10.1093/bioinformatics/btad718, p.8]
- **baseline：** 蛋白位点对比包括 PSIVER、SCRIBER、DLPred、ProNA2020、DELPHI、SPPIDER、DeepPPISP、MaSIF-site、GraphPPIS 与 RGN。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.7]；[doi:10.1093/bioinformatics/btad718, p.8]；[doi:10.1093/bioinformatics/btad718, p.9]
- **baseline：** 配体位点对比包括 TargetS、S-SITE、COACH、IonCom、ATPbind、DELIA 和 GraphBind。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.9]；[doi:10.1093/bioinformatics/btad718, p.11]
- **data：** 肽结合数据集来自 BioLiP/SPRINT-Seq 体系，1279 个 PBP 被划分为 Pep_Train_1154、Pep_Test_125、Pep_Train_640 和 Pep_Test_639，结合残基按与肽原子距离小于 3.5 Å 定义。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.2]；[doi:10.1093/bioinformatics/btad718, p.3]
- **data：** 蛋白-蛋白数据融合自 Pro_Dset_186、Pro_Dset_164 和 Pro_Dset_72，去冗余后得到 395 个蛋白，并形成 Pro_Train_335、Pro_Test_60、Pro_Test_315 以及 31 个 unbound 蛋白测试集。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.3]
- **data：** 作者还将模型重训并评估到 DNA、RNA、ATP、HEME、carbohydrate、Mg2+、Ca2+ 和 Mn2+ 等多类配体数据集，以检验泛化能力。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.9]；[doi:10.1093/bioinformatics/btad718, p.11]
- **declared_resources：** 论文在摘要和数据可用性部分给出 GitHub 仓库与 online server，说明代码、数据与可视化服务对外公开。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.1]；[doi:10.1093/bioinformatics/btad718, p.10]；[doi:10.1093/bioinformatics/btad718, p.13]
- **declared_resources：** 可复用资源的直接地址包括 https://github.com/WeiLab-Biology/DeepProSite 与 https://inner.wei-group.net/DeepProSite/。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.1]；[doi:10.1093/bioinformatics/btad718, p.10]；[doi:10.1093/bioinformatics/btad718, p.13]
- **limitations：** 作者明确指出方法性能对 ESMFold 结构质量敏感，GDT 越高通常对应更好的 AUPRC。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.9]
- **limitations：** 论文也承认模型只能基于蛋白相关信息识别可能的结合残基，不能直接预测特定配体的结合模式。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.13]
- **limitations：** 作者把进一步增强结构鲁棒性、加入 heterogeneity maps 和 multitask learning 列为后续改进方向。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.13]
- **method：** 作者将结合位点预测建模为 residue-level node classification，在蛋白图上联合利用残基特征与三维坐标。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.3]
- **method：** 结构分支使用 ESMFold 直接从序列预测蛋白三维结构，再用 DSSP 提取 RSA、secondary structure 和 backbone torsion angles 等结构属性。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.3]
- **method：** 序列分支使用 ProtT5 生成每个残基 1024 维 embedding，并与 DSSP 特征拼接作为节点输入。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.3]
- **method：** 边特征显式编码残基间距离、方向、旋转与序列位置差，Graph Transformer 通过注意力聚合邻域节点和边信息，最后由 MLP 输出结合概率。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.4]；[doi:10.1093/bioinformatics/btad718, p.5]
- **results：** 在肽数据上，DeepProSite 在 Pep_Test_125 的 AUC/AUPRC 达到 0.883/0.480，在 Pep_Test_639 达到 0.861/0.411，优于所列对比方法。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.8]
- **results：** 在蛋白数据上，DeepProSite 在 Pro_Test_60 与 Pro_Test_315 的 AUC/AUPRC 分别达到 0.813/0.490 和 0.805/0.432，并取得更高 MCC。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.8]；[doi:10.1093/bioinformatics/btad718, p.9]
- **results：** 对 31 个 unbound 结构，竞争性 structure-based 方法性能明显下降，而 DeepProSite 基本保持稳定，说明其对构象变化更鲁棒。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.8]
- **results：** 在多配体任务上，DeepProSite 相比 GraphBind 的 MCC 与 AUC 分别提升约 0.023–0.107 和 0.011–0.068。
  - 证据：[doi:10.1093/bioinformatics/btad718, p.11]

# Deepstacked-AVPs: predicting antiviral peptides using tri-segment evolutionary profile and word embedding based multi-perspective features with deep stacking model

- **DOI：** [10.1186/s12859-024-05726-5](https://doi.org/10.1186/s12859-024-05726-5)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

抗病毒肽(AVPs)是AMP的子类，湿实验筛选昂贵耗时；如何用机器学习从序列准确区分AVP与非AVP。

## 作者主张的贡献

提出Deepstacked-AVPs：三段式PSSM(PSSM-TS)进化特征+word2vec语义特征+CTDT理化特征融合，信息增益(IG)特征选择后用stacking集成分类器；训练集准确率96.60%/AUC 0.98，独立集95.15%/AUC 0.97，声称超过现有模型约2-4个百分点。

## 创新边界

AVP预测器已有多个（AVPpred、AntiVPP1.0、Chang等），且使用同一基准数据集；'特征融合+IG选择+stacking'是生物信息学标准配方，创新仅在PSSM三段切分(PSSM-TS)这一编码细节；在951条小样本上约2-4%的精度提升可能是同分布冗余，不能当范式首创。

## 创新点证据卡

- **[p4]** 提出PSSM三段切分(PSSM-TS)编码以捕获序列局部残基顺序信息
  - 原文："The PSSM information is divided into three segments by row with equal dimension size"
- **[p1]** PSSM-TS+word2vec+CTDT三视角特征融合并用信息增益选择最优子集
  - 原文："the fused vector is formed using PSSM-TS features, semantic information, and CTDT descriptors... Information gain (IG) is applied to choose the optimal feature set"
- **[p1]** 独立集准确率95.15%/AUC 0.97，声称超越现有AVP预测器约2个百分点
  - 原文："our model obtained an accuracy of 95.15%, an AUC of 0.97... outperformed existing models with a ~4% and ~2% higher accuracy"
- **[p8]** 采用重复50次的5折分层交叉验证降低随机划分方差
  - 原文："selected the mean value of the fold-CV test by repeating the stratified loop procedure 50 times"

## 方法

- PSSM-TS：将PSSM按行等分为三段分别提取局部进化特征
- word2vec skip-gram将k-mer当作词训练100维语义嵌入
- CTDT理化特征（13种性质，39维）
- 三种特征融合后用信息增益做特征选择
- stacking集成（RF/ETC/XGB/DNN作基学习器）
- 5折分层交叉验证重复50次取均值

## 数据与基准

- 训练集：AVPpred构建的951条（544 AVP/407非AVP）
- 独立测试集：120条（60 AVP/60非AVP）

## 结果证据

- 训练集：准确率96.60%、AUC 0.98、PR 0.97
- 独立集：准确率95.15%、AUC 0.97、PR 0.97
- 声称比现有模型训练/独立集分别高约4%/2%准确率
- 单特征消融显示融合优于单一编码

## 比较基线

- AVPpred
- AntiVPP 1.0
- Chang等模型
- RF/ETC/XGB/DNN单模型

## 已知限制

- 数据集极小（951+120），类别定义依赖AVPpred原标注质量
- 非AVP负样本来源与同源性去偏未充分说明，存在数据泄漏/冗余风险
- 仅二分类，无抗病毒谱/活性强度预测，无外部队列验证
- Windows单机实现，工程成熟度有限

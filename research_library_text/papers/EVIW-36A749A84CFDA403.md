# Pocket Crafter: a 3D generative modeling based workflow for the rapid generation of hit molecules in drug discovery

- **论文 ID：** `EVIW-36A749A84CFDA403`
- **期刊 / 来源：** Journal of Cheminformatics（DOI 前缀识别）
- **发表时间：** 未记录
- **DOI：** [10.1186/s13321-024-00829-w](https://doi.org/10.1186/s13321-024-00829-w)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 Pocket Crafter：以 Pocket2Mol 为核心的3D生成式 hit 发现工作流，并结合理化过滤、SAscore/QED/GBVI/WSA ΔG 二次筛选、SAR 富集、ROCS 库检索及后续 QC/溶解度筛选；在 WDR5 WBM pocket 案例中最终得到 2029 个待测化合物并验证出 3 个具有活性的新增骨架。

## 创新边界

`更像是端到端 workflow / pipeline 的整合与案例验证，而不是训练一个全新的生成模型。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知蛋白口袋三维结构的前提下，如何把3D生成式分子设计、可合成性/药性过滤、SAR富集与库检索串成一条可操作流程，以快速产出可测试的 hit 分子。

## 方法

- pocket-conditioned generation与多stage virtual screening。

## 数据与基准

- protein pockets与molecular benchmarks。

## 比较基线

- Pocket2Mol/TargetDiff等。

## 结果证据

- 论文报告高score hit candidates；为计算。

## Pi 结构化证据摘录

- **baseline：** 与 Novartis diverse library 的实验 HTRF screen 相比，Pocket Crafter 在更小的 2029 化合物集合里获得了更高 hit rate。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.11]
- **baseline：** 论文还用 WM-662、Compound 1、Compound 12 和 MYC MbIIIb peptide 的已知结合模式作结构对照，以说明新命中不是简单复制已有 scaffold。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.7]；[doi:10.1186/s13321-024-00829-w, p.12]；[doi:10.1186/s13321-024-00829-w, p.13]
- **data：** 案例靶点是 WDR5 的 WBM pocket，使用的蛋白结构为 PDB: 8F1G；Pocket2Mol 生成了 543,491 个有效结构。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.7]；[doi:10.1186/s13321-024-00829-w, p.8]
- **data：** 经过理化过滤后剩余 352,820 个结构，继续按二次过滤后得到 9,531 个 virtual hits。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.8]
- **data：** 随后通过 ROCS 与附加筛选压缩为 2,029 个待测化合物，用于后续 WDR5-MYC HTRF 实验。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.10]
- **data：** 对照数据包括 Novartis diverse library 的 1,101,793 个化合物 HTRF screen，以及 WM-662、Compound 1、Compound 12 和 MYC MbIIIb peptide 等已知参考物。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.8]；[doi:10.1186/s13321-024-00829-w, p.9]；[doi:10.1186/s13321-024-00829-w, p.11]；[doi:10.1186/s13321-024-00829-w, p.12]
- **declared_resources：** Pocket2Mol 的 source code 和 models 在 GitHub 上公开；作者还把 Pocket Crafter 的 sample code 和 example dataset 放在 supplementary material 中。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.3]；[doi:10.1186/s13321-024-00829-w, p.16]
- **declared_resources：** 流程依赖 MOE、Pipeline Pilot、OpenEye/ROCS 以及 RDKit、R 等工具，其中前者属于商业软件，后者为开源组件。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.3]；[doi:10.1186/s13321-024-00829-w, p.6]；[doi:10.1186/s13321-024-00829-w, p.16]
- **declared_resources：** 实验与结构资源还包括公开 PDB 结构、Novartis internal diverse library 以及附录中的 HTRF/SMILES 数据表。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.8]；[doi:10.1186/s13321-024-00829-w, p.9]；[doi:10.1186/s13321-024-00829-w, p.16]
- **limitations：** 作者明确指出，de novo 分子可能结构复杂、含有不常见官能团，合成会遇到多步反应、专用试剂和规模化成本问题，因此需要借助 archived/virtual library searching 作为中间策略。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.6]
- **limitations：** 仅靠生成会产生很大的后续负担：第二层筛选前仍有 352,820 个结构，说明流程必须依赖额外 QC、可得数量和溶解度筛选才能落到可测试集合。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.8]；[doi:10.1186/s13321-024-00829-w, p.10]
- **method：** 以蛋白口袋三维结构和口袋中心坐标作为输入，先用 MOE QuickPrep 准备受体，再把 Pocket2Mol 接入流程进行逐原子、逐键的3D分子生成。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.3]
- **method：** 在 WDR5 案例中，将 Pocket2Mol 的采样参数提高到 2000，并用 300 个不同随机种子重复采样，累计生成超过 50 万个 de novo 化合物。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.3]
- **method：** 第一层过滤按 molecular weight、AlogP、Molecular_PolarSurfaceArea 和 Num_RotatableBonds 的阈值筛掉不合格结构，以保留更像药物分子的候选物。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.3]；[doi:10.1186/s13321-024-00829-w, p.4]
- **method：** 第二层 hit calling 使用 SAscore≤4、QED≥0.5 和 GBVI/WSA ΔG≤-6，并用 Bemis-Murcko 片段与 ECFP_6/最大距离0.625 做聚类和 SAR 富集。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.4]；[doi:10.1186/s13321-024-00829-w, p.5]
- **method：** 对通过筛选的 top scaffold，作者再用 ROCS 在 Novartis archived library、Enamine REAL 和自定义枚举库中搜索，并结合可得数量、LC-QC 与溶解度/ML 过滤压缩成测试集合。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.6]
- **method：** 生物验证采用 WDR5-MYC HTRF 单点筛选、剂量反应曲线和 WDR5 DSF 作为正交实验读出。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.7]
- **results：** 2029 个化合物中有 7 个在 40 μM 时对 WDR5-MYC HTRF 信号抑制超过 40%，相较 1,101,793 化合物的历史筛选，命中率从 0.025% 提升到 0.345%，约高 12.8 倍。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.11]
- **results：** PC-1、PC-2、PC-3 的 HTRF IC50 分别为 35.6、27.5、28.5 μM，且 counter assay 均大于 75 μM，支持其对 WDR5-MYC 作用的特异性。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.11]；[doi:10.1186/s13321-024-00829-w, p.12]
- **results：** DSF 显示 PC-1 和 PC-2 分别带来 -4.2 °C 与 -1.2 °C 的 Tm shift，而 WM-662 为 3.2 °C，说明这些命中具有直接蛋白结合信号。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.11]；[doi:10.1186/s13321-024-00829-w, p.12]
- **results：** 作者认为这些命中呈现与已知 WBM binder 不同的 binding mode，并在 PLIF 中覆盖 Ser223、Pro224、Asn225、Lys227、Lys272、Leu288、Tyr228 等残基，提示可继续做化学优化。
  - 证据：[doi:10.1186/s13321-024-00829-w, p.12]；[doi:10.1186/s13321-024-00829-w, p.15]

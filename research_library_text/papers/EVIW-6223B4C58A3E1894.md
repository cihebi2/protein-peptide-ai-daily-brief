# Illuminating protein space with a programmable generative model

- **论文 ID：** `EVIW-6223B4C58A3E1894`
- **期刊 / 来源：** Nature
- **发表时间：** 2023 Nov 15
- **DOI：** [10.1038/s41586-023-06728-8](https://doi.org/10.1038/s41586-023-06728-8)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 Chroma：一个面向蛋白与蛋白复合物的生成式模型，结合 correlated diffusion、sub-quadratic graph neural network、可组合 conditioners 与低温采样，可在无需重训练的情况下按对称性、motif、shape、fold class 乃至自然语言提示进行条件采样，并通过 310 个蛋白的实验与晶体学结果验证其可实现性。

## 创新边界

`本稿的边界在于把全复合物生成、条件采样和实验验证整合为单一系统；冻结稿足以支持方法与结果抽取，但不足以独立验证全球首创性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在不依赖逐步迭代搜索的前提下，直接生成满足结构、对称性、子结构和语义约束的可设计蛋白及蛋白复合物，并尽可能保证其可表达、可折叠与可实验验证。

## 方法

- 对蛋白骨架实施符合聚合物统计的扩散生成，再进行条件序列与侧链解码；将外部约束作为贝叶斯推断中的条件，并以计算指标和实验表征检查样本。

## 数据与基准

- 训练数据基于公开蛋白结构集合（详细清单见论文数据声明/Zenodo）；实验表征共 310 个生成设计，另公开两条解析结构 PDB 8TNM、8TNO。

## 比较基线

- 对照传统迭代搜索式蛋白设计、既有结构生成和序列设计模型；论文重点不在统一基准排行榜，而在可编程生成与实验抽样验证。

## 结果证据

- 论文报告 310 个设计总体呈现较好表达、折叠和生物物理性质；两条晶体结构与生成模型骨架 RMSD 分别约 1.1 Å 和 1.0 Å。作者在严格只计两条晶体结构成功时给出约 3% 的保守成功率。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 模型似然对第一批条件样本的实验成功仅有弱预测，在更长的第二批不再成立；条件样本存在结构预测重折叠；只有两条解析晶体结构，不能支持任意功能条件下的广泛实验成功。

## 仍未知

- 未见完整训练超参数、算力预算和训练时长。
- 自然语言条件生成对稀有类别的可重复性与功能准确性仍不清楚。
- 实验主要验证表达、折叠与晶体结构，未系统证明具体功能性能。

## Pi 结构化证据摘录

- **baseline：** 作者用三种 state-of-the-art 结构预测器评估 sequence-structure refolding，并据此作为生成序列是否回折到目标 backbone 的对照。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.4]
- **baseline：** 新颖性与记忆化通过 nearest-neighbour TM score、CATH 覆盖式 novelty score，以及与 PDB 最近结构的对比来衡量。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.3]；[doi:10.1038/s41586-023-06728-8, p.4]
- **baseline：** 论文还报告了对七种模型配置的 ablation，说明所引入的 diffusion、架构和采样组件会提升 likelihood 与 in silico refolding。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.2]
- **baseline：** 与常见的蛋白设计工作流不同，作者刻意没有用 structure-prediction filter 或 energetic filtering 先行筛选候选。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]；[doi:10.1038/s41586-023-06728-8, p.8]
- **data：** 无条件采样部分生成了 100,000 个单链蛋白和 20,000 个蛋白复合物，覆盖 v.0 与 v.1 两个版本。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.3]
- **data：** 实验验证总计覆盖 310 个蛋白，其中包括 172 个初始无条件设计、额外 96 个无条件设计，以及 42 个受条件控制的设计。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]；[doi:10.1038/s41586-023-06728-8, p.7]
- **data：** 训练数据由 PDB、UniProt 2022_01 和 PFAM 35 构建，且训练、测试与验证集的 PDB IDs 另存于 Zenodo 数据集。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.10]
- **data：** 实验解析出的结构包括 PDB 8TNM 与 8TNO 两个晶体结构，它们作为该工作的结构性输出被公开存档。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]；[doi:10.1038/s41586-023-06728-8, p.10]
- **declared_resources：** 实验工作使用了 MIT Structural Biology Core Facility 与 MIT Biophysical Instrumentation Facility 的资源。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.10]
- **declared_resources：** 论文明确声明了训练数据来源与公开存档位置，包括 PDB、UniProt 2022_01、PFAM 35，以及 Zenodo 上的训练/测试/验证 ID 列表。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.10]
- **declared_resources：** 实验结构 8TNM 与 8TNO 已提交到 PDB，作为该工作可复核的结构资源。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.10]
- **declared_resources：** 代码资源公开在 GitHub：https://github.com/generatebio/chroma，并标注 Apache 2.0 许可。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.10]
- **limitations：** 语义条件生成并不总是精确；例如 Ig fold 与 β-barrel fold 的输出只部分满足预期特征，caption 对齐也只是间歇性出现。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.5]
- **limitations：** 实验成功率随长度变差，split-GFP 得分与长度存在负相关；而在长度校正后，refolding 与实验可行性之间并无稳定对应。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.7]
- **limitations：** 模型 likelihood 只在第一批条件集里对实验成功有弱预测力，在扩展到更长序列的第二批设计中不再稳健。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.7]
- **limitations：** 按作者自身的保守口径，若只把纯化且在溶液中表征过的蛋白算作成功，则整体成功率约为 3%。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.8]
- **method：** Chroma 采用一种相关的 polymer diffusion 过程，而不是独立高斯噪声，以匹配天然蛋白的距离统计并学习反向去噪过程。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.2]
- **method：** 模型使用带长程随机连接的 graph neural network 与几何求解器，使计算可达到 O(N) 或 O(NlogN) 的准线性扩展。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.2]
- **method：** 作者提出 diffusion-conditioner framework，把固定子结构、距离约束、motif graft、symmetry、shape、分类器语义和自然语言提示编成可组合的采样约束。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.3]；[doi:10.1038/s41586-023-06728-8, p.5]
- **method：** 实验设计流程是先低温采样 backbone，再用 design network 生成序列与 side-chain，最后按 likelihood 选取子集进入实验。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]
- **results：** 无条件样本在 secondary-structure、contact order、radius of gyration 等统计上与 PDB 总体分布一致，并呈现随长度增加而扩大的新颖性。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.3]；[doi:10.1038/s41586-023-06728-8, p.4]
- **results：** in silico refolding 显示大量样本可被结构预测器重新折叠，且这一现象甚至出现在超过 800 residues 的长蛋白上。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.4]
- **results：** 在 split-GFP assay 中，172 个初始无条件设计全部高于阴性对照；后续验证中又有 19/20 的高分样本、9/10 的第二批高分样本被 western blot 证实可溶表达。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]
- **results：** 42 个条件设计中有 40 个（95%）在 split-GFP 中高于阴性对照；CD、DSC 与模型预测也支持其折叠状态与 secondary structure 分布。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.7]
- **results：** UNC_079 与 UNC_239 的晶体结构分别以 1.1 Å 和 1.0 Å RMSD 与设计模型一致，且其最近 PDB 命中并不构成简单记忆复制。
  - 证据：[doi:10.1038/s41586-023-06728-8, p.6]；[doi:10.1038/s41586-023-06728-8, p.7]

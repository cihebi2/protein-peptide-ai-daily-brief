# Structure prediction of alternative protein conformations

- **论文 ID：** `EVIW-2A54D144D5FCB54F`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2024 Aug 26

- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `结构预测`
- **基础层：** Codex 辅助专家全文审阅

## 作者主张的创新点

作者提出 Cfold：先对 PDB 做 conformational split，再训练一个去掉 template track 的 AlphaFold2-like 结构网络，并在推理时用 dropout 或 MSA clustering 采样多种 coevolutionary representation，从而生成训练集中未见的 alternative conformations。

## 创新边界

`本文的边界主要是“构象级划分训练/评估”与“多次 MSA 采样生成 alternative conformations”；它没有独立证明全球首创，也没有新湿实验来验证这些构象在细胞中的诱发机制。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在不泄漏已知构象的前提下，能否仅凭序列/MSA 可靠预测同一蛋白的多个 alternative conformations，并判断这些输出是泛化而不是记忆回放？

## 方法

- 对 PDB 多构象蛋白按构象拆分训练结构预测网络，并在推理时使用 dropout 或 MSA 聚类增加输出多样性。[doi:10.1038/s41467-024-51507-2, p.1][doi:10.1038/s41467-024-51507-2, p.3]

## 数据与基准

- 从 PDB 提取具有明显构象差异的非冗余蛋白，并将不同构象分置训练/测试；评估报告涉及 155 个可预测同折叠体系。[doi:10.1038/s41467-024-51507-2, p.1][doi:10.1038/s41467-024-51507-2, p.3]

## 比较基线

- 比较 MSA 聚类与推理时 dropout，并以已知替代 PDB 构象的 TM-score 为主要参照。[doi:10.1038/s41467-024-51507-2, p.3]

## 结果证据

- MSA 聚类得到 81 个 TM-score>0.8 的替代构象预测，dropout 得到 76 个；论文据此认为可高效探索单体构象空间。[doi:10.1038/s41467-024-51507-2, p.3]

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 构象变化超过约 0.4 TM-score 时准确率很差；方法依赖共进化信息，且训练集包含问题仍需严格看构象级拆分。[doi:10.1038/s41467-024-51507-2, p.5]

## 仍未知

- Zenodo 数据包和 GitHub 仓库未在本次审阅中实际下载核查。
- 未见独立湿实验结果来证明预测构象在真实条件下可被诱导。
- 内部 embedding 与构象差异无关的结论仍是相关性分析，机制仍未解决。

## Pi 结构化证据摘录

- **baseline：** 相较于此前基于 AlphaFold2 的多构象采样工作，作者强调先前评估只覆盖 5–8 个结构，而本工作把评估扩展到 155 个可比目标。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.1]；[doi:10.1038/s41467-024-51507-2, p.5]
- **baseline：** 本文的主要 inference baseline 是 dropout 对比 MSA clustering；作者明确报告 MSA clustering 的结果稍好，因此采用它作为默认生成策略。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.3]；[doi:10.1038/s41467-024-51507-2, p.10]
- **baseline：** 作者把 AlphaFold2 视为参照而非直接替代对象，并指出若不做构象分割，AF2 类模型会因训练时见过大量类似结构而难以公平评估。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.1]；[doi:10.1038/s41467-024-51507-2, p.3]
- **data：** 最终评估集包含 244 个 alternative conformations；用于验证/测试的结构来自 222 个结构簇、4263 条序列，而训练集为 6474 个结构簇、59946 条序列。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.1]；[doi:10.1038/s41467-024-51507-2, p.8]
- **data：** 作者还构建了 315 个随机验证结构簇，307 个可实际评估；这部分用于跟踪训练过程中的 TM-score 和 lDDT。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.9]
- **data：** 构象生成评估只针对 155 个能在训练态上达到 TM-score≥0.6 的目标进行，其中 dropout 成功覆盖 145 个、MSA clustering 成功覆盖 154 个。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.3]；[doi:10.1038/s41467-024-51507-2, p.10]
- **data：** 资源与代码数据来自作者声明：训练数据和预测文件已放在 Zenodo，代码提供为本地 GitHub 仓库和 Google Colab notebook。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.11]
- **declared_resources：** 训练与推理依赖 8×NVIDIA A100 GPUs、JAX/Optax/Adam，整轮训练约 17 天。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.9]
- **declared_resources：** 作者声明训练数据和用于作图的预测文件已发布到 Zenodo，并在正文中提供 Source Data。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.11]
- **declared_resources：** 作者还声明 Cfold 可通过 GitHub 仓库和 Google Colab notebook 使用。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.11]
- **limitations：** 当构象变化幅度更大时，准确率快速下降，说明该方法对 drastic conformational change 仍不稳。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.5]
- **limitations：** 作者明确没有做湿实验验证，认为用 X-ray crystallography 等方式验证预测构象需要大量资源，超出本文范围。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.6]
- **limitations：** Cfold 不能捕捉 NMR ensemble 式动态，也没有证据表明它学到了构象转换过程，只能说明能生成若干静态状态。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.6]
- **limitations：** 作者还指出，很多构象变化依赖细胞环境或配体条件，若不知道精确条件，就很难系统枚举；multimeric extension 也只是未来方向。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.6]；[doi:10.1038/s41467-024-51507-2, p.7]
- **method：** 作者先从 PDB 单链结构构建构象分割：只保留 X-ray/EM、分辨率≤5 Å、长度>50、非规则氨基酸比例<80% 的条目，再用 30% 序列一致性聚类和 TM-score≥0.8 的结构聚类识别 alternative conformations。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.7]；[doi:10.1038/s41467-024-51507-2, p.8]
- **method：** Cfold 基本复制 AlphaFold2 的单体结构网络，但移除 template track，仅保留 MSA/pair tracks，并以结构簇级的一对一映射进行训练。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.8]；[doi:10.1038/s41467-024-51507-2, p.9]
- **method：** 推理阶段使用两种采样策略：dropout 与 MSA clustering；每个靶标大约做 100 次采样，再以最佳 TM-score 选择候选构象。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.3]；[doi:10.1038/s41467-024-51507-2, p.10]
- **method：** 训练采用 8×NVIDIA A100、batch size 24、crop size 256、Adam/JAX、学习率 1e-3、74,000 steps，最佳权重在 10,000 steps 选定。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.9]
- **results：** MSA clustering 略优于 dropout：前者在 154 个目标中有 81 个测试构象达到 TM-score>0.8，后者在 145 个目标中有 76 个达到该阈值。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.3]
- **results：** 在 52 个同时对 train/test 构象都能高精度预测的蛋白中，37% 的样本更接近 test conformation，33% 更接近 train，30% 两者都不匹配，说明输出带有明显随机采样成分。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.3]
- **results：** 构象差异越大，预测越难：native conformations 间的 TM-score 差异与预测准确率呈负相关（Pearson R=-0.62），尤其当差异超过 0.4 TM-score 时性能明显下降。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.5]
- **results：** plDDT 不能有效区分 alternative conformations（TM-score vs plDDT Pearson R=0.52），而内部 embedding 差异与结构结果几乎无关（Spearman R=0.02）。
  - 证据：[doi:10.1038/s41467-024-51507-2, p.4]；[doi:10.1038/s41467-024-51507-2, p.5]

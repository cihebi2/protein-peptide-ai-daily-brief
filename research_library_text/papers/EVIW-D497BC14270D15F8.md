# StructuralDPPIV: a novel deep learning model based on atom structure for predicting dipeptidyl peptidase-IV inhibitory peptides

- **论文 ID：** `EVIW-D497BC14270D15F8`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Feb 1
- **DOI：** [10.1093/bioinformatics/btae057](https://doi.org/10.1093/bioinformatics/btae057)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

提出 StructuralDPPIV，将 TextCNN 序列分支与基于 SMILES 的结构分支融合，并用 CAM/perturbation 解析重要位点和原子特征，在独立测试和湿实验数据集上优于现有方法。

## 创新边界

`新增的是序列-结构联合编码与可解释评测框架；未见新湿实验、de novo 生成或优化候选肽的算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在有限的肽数据上，如何联合利用序列信息与原子结构/理化特征，更准确地识别 DPP-IV 抑制肽并解释模型依据。

## 方法

- 每个氨基酸原子结构图编码后与肽序列特征融合二分类，CAM/扰动分析特征贡献。

## 数据与基准

- 训练/独立集及已发表Pentapeptide、Tripeptide湿实验数据用于外部评估。

## 比较基线

- iDPPIV-SCM等DPP-IV inhibitory peptide预测器及特征消融。

## 结果证据

- 论文报告在独立集和两个既有湿实验数据集上超过SOTA；模型本身未新做抑制实验。

## Pi 结构化证据摘录

- **baseline：** 比较基线包括 DT、iDPPIV-SCM、RF、NB、KNN、fKNN、SVM、StackDPPIV 与 BERT-DPPIV。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.5]
- **baseline：** 单模块消融中，TextCNN only 的 ACC/MCC 为 0.8346/0.6869，Structural only 为 0.8909/0.7918，完整模型为 0.9098/0.8218。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.5]
- **baseline：** 在 wet experiment 对照中，BERT-DPPIV 预测 14/22 个 pentapeptides，而 StructuralDPPIV 预测 21/22 个。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.6]
- **data：** 模型开发与评测使用 Charoenkwan et al. 数据集，共 665 个 positive 和 665 个 negative；其中 benchmark set 为 532/532，independent test set 为 113/113。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]
- **data：** 额外验证使用 BERT-DPPIV 论文中的 Pentapeptide 与 Tripeptide wet experiment datasets。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]；[doi:10.1093/bioinformatics/btae057, p.6]
- **data：** 输入表示同时依赖 peptide sequence 与其 SMILES/atom-structure 特征，而不是单一序列特征。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]；[doi:10.1093/bioinformatics/btae057, p.3]；[doi:10.1093/bioinformatics/btae057, p.4]
- **declared_resources：** 计算资源为 NVIDIA RTX 3090 GPU（24 GB），训练过程约 8 分钟。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.4]
- **declared_resources：** 作者将中间 SE/TE tensors 预处理后以 pickle（.pkl）文件持久化存储，以加速训练和测试。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.4]
- **declared_resources：** 论文声明代码与复现实验步骤可在 GitHub 仓库 Structural-DPP-IV 获取。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.1]；[doi:10.1093/bioinformatics/btae057, p.9]
- **limitations：** 作者指出数据集长度从 2 到 90 不等，padding 只是标准化张量形状，且尝试的数据增强式 padding 未带来明显提升。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.8]
- **limitations：** Permutation importance 中 hybridization 可能因单一整数编码而被高估，说明特征重要性存在编码偏差风险。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.8]
- **limitations：** 论文未报告新的 wet-lab 实验，而是复用了先前公开的湿实验数据集来做验证。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]；[doi:10.1093/bioinformatics/btae057, p.6]
- **method：** 模型由 Structural encoding module 与 TextCNN encoding module 组成，最后用 element-wise multiplication 融合两个二维向量后进入分类器。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]；[doi:10.1093/bioinformatics/btae057, p.4]
- **method：** 结构分支先把肽序列转成 SMILES，经 RDKit 提取 21 个原子特征，再经 GCN 与 residual blocks 编码。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.2]；[doi:10.1093/bioinformatics/btae057, p.3]
- **method：** 序列分支采用 TextCNN、embedding、卷积与 max-pooling，且 embedding 采用 non-static channels，可在训练中更新。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.4]
- **method：** 训练使用 NVIDIA RTX 3090 GPU（24 GB），batch size 32、learning rate 0.000005、最多 150 epochs，并采用 Focal Loss 和 Adam。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.4]
- **results：** 在 independent test dataset 上，StructuralDPPIV 达到 ACC 0.9098、MCC 0.8218、Sn 0.9474、Sp 0.8722、AUC 0.9656。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.5]
- **results：** 与 BERT-DPPIV 相比，作者报告 ACC 和 MCC 分别提升 1.58% 与 3.18%。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.5]
- **results：** 在 Pentapeptide 数据集上模型命中 21/22 个抑制肽；在 Tripeptide 数据集上准确率为 90%。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.6]
- **results：** CAM 与 perturbation 分析一致指出头部位点、Y/F/E 等氨基酸及部分 R groups 更重要。
  - 证据：[doi:10.1093/bioinformatics/btae057, p.6]；[doi:10.1093/bioinformatics/btae057, p.7]；[doi:10.1093/bioinformatics/btae057, p.8]

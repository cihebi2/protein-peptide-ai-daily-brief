# ifDEEPre: large protein language-based deep learning enables interpretable and fast predictions of enzyme commission numbers

- **论文 ID：** `EVIW-79348126FDC75CF4`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2024 Jun 28
- **DOI：** [10.1093/bib/bbae225](https://doi.org/10.1093/bib/bbae225)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 ifDEEPre，将 self-guided attention、residual CNN/FNN 和 ESM-1b 预训练蛋白语言模块结合起来，在多个 EC 层级上实现更快、更可解释且更准确的酶功能预测，并提供 web server。

## 创新边界

`论文声称首次把 large protein language model 作为酶功能预测深度框架的核心模块，并配套新型 self-guided attention；但冻结证据中没有独立 prior-art 核验，因此这里只记录作者主张，不确认全球新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何仅用 raw protein sequence，在不依赖昂贵 PSSM 或大量手工特征的前提下，快速、可解释地预测 enzyme commission (EC) numbers，并提升对 enzyme / non-enzyme、main class 和 subclass 的功能注释能力。

## 方法

- PLM嵌入、domain特征与层级分类网络逐级预测EC；attention给出残基/特征解释。

## 数据与基准

- 带完整实验EC注释蛋白及NEW独立数据。

## 比较基线

- DEEPre、同源/结构/深度EC预测器。

## 结果证据

- NEW数据F1提高>14.22%，比DEEPre快50倍、存储小12.89倍；仍为功能预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- EC标签层级和冗余控制敏感；解释attention非因果，web版去掉结构工具有小幅性能损失。

## 仍未知

- 是否能在独立外部数据集上维持同等优势尚不清楚。
- level 4 EC 的直接学习能力没有被证明，作者采用了 phmmer 兜底。
- 公开 GitHub 仓库的实现细节、训练脚本和复现难度未在本次冻结证据中核验。
- 去掉 RaptorX 后的 web 版本在更广任务上的精度损失没有完全量化。

## Pi 结构化证据摘录

- **baseline：** NEW/KNN 主要对比 SVM、LR、RF、AdaBoost、NN、ResNet、LSTM、EzyPred、SVM-Prot、ProPythia、ABLE、DEEPre。
  - 证据：[doi:10.1093/bib/bbae225, p.6]；[doi:10.1093/bib/bbae225, p.7]；[doi:10.1093/bib/bbae225, p.8]
- **baseline：** COFACTOR 跨集对比还包括 COFACTOR 原方法、DEEPre、EzyPred、SVM-PrePssm、NN-Raw 等。
  - 证据：[doi:10.1093/bib/bbae225, p.11]；[doi:10.1093/bib/bbae225, p.12]
- **baseline：** web/server 版本只与 DEEPre 比较速度和存储，突出 PSSM 依赖带来的代价。
  - 证据：[doi:10.1093/bib/bbae225, p.17]；[doi:10.1093/bib/bbae225, p.18]；[doi:10.1093/bib/bbae225, p.19]
- **data：** NEW、KNN 作为主基准集；NEW 有 22,168 个 non-enzymes 和 22,168 个 enzymes，KNN 有 9,850 个 non-enzymes 和 9,832 个 enzymes；两者都采用 80/10/10 划分。
  - 证据：[doi:10.1093/bib/bbae225, p.3]
- **data：** COFACTOR 作为第三方独立测试集，去除与训练集重叠序列后剩 281 个 enzymes，且与训练集相似度限制在 30% 以下。
  - 证据：[doi:10.1093/bib/bbae225, p.3]；[doi:10.1093/bib/bbae225, p.11]
- **data：** 作者还用 peroxidase、exonuclease 两个单蛋白案例，以及 yeast sub-species 轨迹分析做解释性验证。
  - 证据：[doi:10.1093/bib/bbae225, p.15]；[doi:10.1093/bib/bbae225, p.16]；[doi:10.1093/bib/bbae225, p.17]
- **declared_resources：** ESM-1b 与 UniParc（250M sequences, 86B amino acids）作为预训练资源。
  - 证据：[doi:10.1093/bib/bbae225, p.3]；[doi:10.1093/bib/bbae225, p.4]
- **declared_resources：** HMMER、RaptorX、MMseqs2、CD-HIT、AlphaFold、MEME、UMAP、VIA、phmmer 等外部工具被用于特征提取、结构解析、去冗余、motif 和 trajectory 分析。
  - 证据：[doi:10.1093/bib/bbae225, p.9]；[doi:10.1093/bib/bbae225, p.11]；[doi:10.1093/bib/bbae225, p.15]；[doi:10.1093/bib/bbae225, p.16]；[doi:10.1093/bib/bbae225, p.17]；[doi:10.1093/bib/bbae225, p.18]；[doi:10.1093/bib/bbae225, p.20]
- **declared_resources：** 公开服务包括 ifDEEPre web server 和 GitHub repository。
  - 证据：[doi:10.1093/bib/bbae225, p.1]；[doi:10.1093/bib/bbae225, p.17]
- **limitations：** level 4 EC 由于每个 sub-sub-subclass 样本太少，作者没有直接训练，而是改用 phmmer 搜索第四位数字。
  - 证据：[doi:10.1093/bib/bbae225, p.18]
- **limitations：** 当 COFACTOR 与训练集相似度降到 30% 时只剩 3 个蛋白，作者因此排除了该结果以避免偏置。
  - 证据：[doi:10.1093/bib/bbae225, p.11]
- **limitations：** practical web server 为提速省略了 RaptorX，并只保留 transformer features 和 functional domain，说明速度与完整特征之间存在折中。
  - 证据：[doi:10.1093/bib/bbae225, p.17]；[doi:10.1093/bib/bbae225, p.18]
- **limitations：** 作者也承认未来需进一步整合 3D structures、优化 HMMER/RaptorX、并改进 level 4 的小样本学习。
  - 证据：[doi:10.1093/bib/bbae225, p.20]
- **method：** 模型同时学习 sequence-length-dependent 特征（sequence encoding、secondary structure、solvent accessibility）和 sequence-length-independent 特征（functional domain、transformer features），再用融合分类器输出 EC 预测。
  - 证据：[doi:10.1093/bib/bbae225, p.3]；[doi:10.1093/bib/bbae225, p.5]
- **method：** 作者为 1D/2D 表征分别设计 self-guided attention，并在 CNN/FNN 信号通道中加入 residual short-cut 结构以稳定训练。
  - 证据：[doi:10.1093/bib/bbae225, p.4]；[doi:10.1093/bib/bbae225, p.5]
- **method：** transformer features 由 ESM-1b 在 UniParc 的 2.5 亿条序列上通过 masked language modeling 预训练得到。
  - 证据：[doi:10.1093/bib/bbae225, p.3]；[doi:10.1093/bib/bbae225, p.4]
- **results：** 在 level 0 enzyme detection 上，ifDEEPre 在 NEW/KNN 分别达到 F1 0.996/0.920，并全面优于 DEEPre、ABLE、ProPythia 等基线。
  - 证据：[doi:10.1093/bib/bbae225, p.6]；[doi:10.1093/bib/bbae225, p.7]；[doi:10.1093/bib/bbae225, p.8]
- **results：** 在 level 1 main-class annotation 上，NEW 的 Recall/F1 为 0.934/0.934，KNN 的 Accuracy/Kappa/Precision/F1 为 0.941/0.921/0.938/0.920。
  - 证据：[doi:10.1093/bib/bbae225, p.6]；[doi:10.1093/bib/bbae225, p.7]；[doi:10.1093/bib/bbae225, p.8]
- **results：** 在 level 2 subclass annotation 上，NEW 的平均 Recall/F1 为 0.890/0.890，KNN 的 Accuracy/Kappa/Precision/F1 为 0.936/0.917/0.886/0.920。
  - 证据：[doi:10.1093/bib/bbae225, p.6]；[doi:10.1093/bib/bbae225, p.8]
- **results：** 在 COFACTOR 跨数据集评测中，ifDEEPre 对 level 1 的 Accuracy 相比 COFACTOR 提升 16.92%，level 2 的 F1/Recall 达到 0.852/0.864。
  - 证据：[doi:10.1093/bib/bbae225, p.11]；[doi:10.1093/bib/bbae225, p.12]
- **results：** 消融显示 transformer features 贡献最大，去除后 NEW 的 enzyme detection accuracy 从 0.996 降到 0.942，subclass accuracy 从 0.949 降到 0.879。
  - 证据：[doi:10.1093/bib/bbae225, p.8]；[doi:10.1093/bib/bbae225, p.9]
- **results：** UMAP 可视化显示 ifDEEPre 的 embedding 比 OneHot、OneHot+FunD 和 Random 更能分离 enzyme families/sub-families；VIA 轨迹分析与已知 yeast evolutionary relations 一致。
  - 证据：[doi:10.1093/bib/bbae225, p.13]；[doi:10.1093/bib/bbae225, p.14]；[doi:10.1093/bib/bbae225, p.15]
- **results：** peroxidase 和 exonuclease 的 attention maps 与 MEME motifs 高度对齐，说明模型能定位关键 residues/fragments。
  - 证据：[doi:10.1093/bib/bbae225, p.16]；[doi:10.1093/bib/bbae225, p.17]
- **results：** ifDEEPre-web 相对 DEEPre 报告 58.96x 更快、约 13.10x 更省存储，且保持较高性能。
  - 证据：[doi:10.1093/bib/bbae225, p.18]；[doi:10.1093/bib/bbae225, p.19]

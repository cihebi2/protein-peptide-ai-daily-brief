# PepCNN deep learning tool for predicting peptide binding residues in proteins using sequence, structural, and language model features

- **论文 ID：** `EVIW-932468299F5C923F`
- **期刊 / 来源：** Sci Rep
- **发表时间：** 2023 Nov 28
- **DOI：** [10.1038/s41598-023-47624-5](https://doi.org/10.1038/s41598-023-47624-5)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `有静态审计仓库` / `肽与抗菌肽` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

论文提出 PepCNN，将 ProtT5 语言模型 embedding、PSI-BLAST 导出的 PSSM 与 HSE 结构特征融合到 1D CNN 中，做 binding/non-binding 残基分类，并声称在 TE125 与 TE639 两个基准集上优于既有方法。

## 创新边界

`创新主要在特征融合与残基级分类器，不是候选肽/蛋白生成或优化；冻结证据只支持预测任务边界内的增量方法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

面向 protein–peptide 相互作用，逐残基预测蛋白序列中的 peptide binding residues，以支持结合位点定位和后续设计分析。

## 方法

- 卷积/深度分类器；序列、结构和语言模型特征融合；标准蛋白-肽复合物训练/测试集。

## 数据与基准

- 公开蛋白-肽复合物数据集；软件与数据声明公开。

## 比较基线

- 既有序列和结构位点预测器、不同特征消融。

## 结果证据

- 论文报告优于若干既有位点预测方法；本轮不把位点概率解释为真实结合或肽设计成功。

## Pi 结构化证据摘录

- **baseline：** 论文比较的基线包括 Pepsite、Peptimap、SPRINT-Seq、SPRINT-Str、PepBind、Visual、PepNN-Seq、PepBCL 与 SPPPred。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]
- **baseline：** 作者直接引用这些方法在 TE125 与 TE639 上的已发表结果，而不是在本文中重新统一训练全部 baseline。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]；[doi:10.1038/s41598-023-47624-5, p.5]
- **baseline：** 在论文给出的对比中，PepBCL 是最强的历史基线之一，但 PepCNN 在 AUC、specificity 和 precision 上进一步超过它。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]；[doi:10.1038/s41598-023-47624-5, p.5]
- **data：** 训练与测试数据来自 BioLiP 派生基准集；binding residue 的定义是任一 heavy atom 距离 peptide heavy atom 不超过 3.5 Å。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.2]
- **data：** Dataset 1 的 TE125 含 125 个 proteins、30,870 个 residues，其中 1,716 个为 binding residues；对应训练集 TR1115 含 1,115 个 proteins。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]
- **data：** Dataset 2 的 TE639 含 639 个 proteins、150,330 个 residues，其中 8,490 个为 binding residues；对应训练集 TR640 含 640 个 proteins。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]
- **data：** 训练集存在严重类别不平衡，作者对 TR1115 与 TR640 做 random under-sampling，分别把残基数压缩到 37,355 和 20,647。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.2]；[doi:10.1038/s41598-023-47624-5, p.4]
- **declared_resources：** 论文声明数据集可从 GitHub 下载，代码也以 Python 形式公开在同一 GitHub 仓库。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.12]
- **declared_resources：** 实现与实验使用了 ProtT5、PSI-BLAST、HSEpred、TensorFlow、Keras Tuner、PyMOL 和 Inkscape 等工具。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.3]；[doi:10.1038/s41598-023-47624-5, p.8]；[doi:10.1038/s41598-023-47624-5, p.9]；[doi:10.1038/s41598-023-47624-5, p.10]；[doi:10.1038/s41598-023-47624-5, p.11]；[doi:10.1038/s41598-023-47624-5, p.12]
- **declared_resources：** 论文声明获得 Australian Research Council Grant DP180102727 以及 Griffith University HPC Cluster 支持。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.14]
- **limitations：** 论文明确说明部分指标受 probability threshold 影响，因此单看 Sensitivity、Specificity、Precision 和 MCC 不如 AUC 稳健。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.8]
- **limitations：** 训练数据存在约 1:17 到 1:18 的类别失衡，作者不得不用 random under-sampling，意味着大量训练残基被丢弃。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.2]；[doi:10.1038/s41598-023-47624-5, p.4]
- **limitations：** 作者把 DeepInsight 与 2D CNN/transfer learning 作为 future work，说明当前版本尚未覆盖这一路线。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.7]
- **method：** 整体流程先做 feature extraction、residue extraction、模型训练与测试，再对每个残基输出 binding/non-binding 预测。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.3]
- **method：** 每个残基由 ProtT5 embedding、PSSM 和 HSE 三类特征组合成 1×1047 向量，其中 embedding 为 1024 维、PSSM 为 20 维、HSE 为 3 维。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.8]；[doi:10.1038/s41598-023-47624-5, p.9]；[doi:10.1038/s41598-023-47624-5, p.10]；[doi:10.1038/s41598-023-47624-5, p.11]
- **method：** 作者用 1D CNN 训练分类器，结构为 3 个卷积层和 2 个全连接层，采用 ReLU、sigmoid、Adam(1e-6)、binary crossentropy、early stopping，并用 Bayesian Optimization 调参。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.11]
- **method：** 评估时使用 Sensitivity、Specificity、Precision、MCC 与 AUC，并把结果与 9 个既有方法在同一测试集上比较。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]；[doi:10.1038/s41598-023-47624-5, p.8]
- **results：** 在 TE125 上，PepCNN 的 Sensitivity、Specificity、Precision、MCC 和 AUC 分别为 0.254、0.988、0.55、0.350 和 0.843。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]
- **results：** 在 TE639 上，PepCNN 的 Sensitivity、Specificity、Precision、MCC 和 AUC 分别为 0.217、0.986、0.479、0.297 和 0.826。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.5]
- **results：** 论文称 PepCNN 相比 PepBCL 的 AUC 在 TE125 上提升 3.4%，在 TE639 上提升 2.7%，且在多数指标上达到更优表现。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.4]；[doi:10.1038/s41598-023-47624-5, p.5]
- **results：** 三个 case study 中，1dpuA、2bugA、1uj0A 的 binding sites 命中数分别为 6/11、6/9、8/9，同时 non-binding sites 的 specificity 也较高。
  - 证据：[doi:10.1038/s41598-023-47624-5, p.5]；[doi:10.1038/s41598-023-47624-5, p.6]

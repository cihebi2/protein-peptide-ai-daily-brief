# Benchmarking residue-resolution protein coarse-grained models for simulations of biomolecular condensates

- **论文 ID：** `EVIW-D5F88398E446356B`
- **期刊 / 来源：** PLoS Comput Biol
- **发表时间：** 2025 Jan 13
- **DOI：** [10.1371/journal.pcbi.1012737](https://doi.org/10.1371/journal.pcbi.1012737)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

本文系统比较了 HPS、HPS-cation–π、HPS-Urry、CALVADOS2、Mpipi 和 Mpipi-Recharged 六种模型在 A1-LCD 七个变体上的相分离热力学与材料性质预测，并据此把性能差异归因到 cation–π 与 π–π 相互作用的参数化方式。

## 创新边界

`这是模型基准评估与机理解释，不是新蛋白设计、新算法优化或新湿实验。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要回答的是：对 hnRNPA1 的 A1-LCD 及其芳香残基突变体，哪几种 residue-resolution coarse-grained 模型能够同时较好复现相图、饱和浓度和黏度，并且这些差异对应哪些关键的分子间作用力。

## Pi 结构化证据摘录

- **baseline：** 本文的直接基线是实验相图、Csat 和 viscosity 数据，以及六种现有 CG 力场之间的横向比较，而不是训练一个新模型。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.6]；[doi:10.1371/journal.pcbi.1012737, p.9]；[doi:10.1371/journal.pcbi.1012737, p.11]；[doi:10.1371/journal.pcbi.1012737, p.13]
- **baseline：** 模型基线之间的差异主要来自参数化：HPS 家族用 hydrophobicity scale 与 Debye-Hückel，CALVADOS2 通过 Bayesian learning 调 λ_i，Mpipi/Mpipi-Recharged 则采用 pair-specific residue-residue interaction。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.5]；[doi:10.1371/journal.pcbi.1012737, p.19]
- **baseline：** 作者明确指出，CALVADOS2 原本不是为 critical solution temperature 或 condensate coexistence lines 设计的，因此这里的相图比较属于更严格的外推基线。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.7]
- **data：** 研究对象是 hnRNPA1 A1-LCD 的七个变体：WT+NLS、allF、allY、allW、YtoW、FtoW 和 W−，且突变只改变芳香残基的化学身份而保留 sequence patterning。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.4]
- **data：** 实验对照中，WT+NLS、allF 和 allY 有温度-浓度相图数据；七个变体都有 298 K 下的 saturation concentration，且文中还使用了对应的 viscosity 测量作对照。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.6]；[doi:10.1371/journal.pcbi.1012737, p.7]；[doi:10.1371/journal.pcbi.1012737, p.9]；[doi:10.1371/journal.pcbi.1012737, p.11]；[doi:10.1371/journal.pcbi.1012737, p.13]
- **data：** 作者声明提供 Supplementary Material、GitHub repository、各模型的 LAMMPS input scripts、A1-LCD mutants 的 configuration file，以及代表性轨迹视频。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.1]；[doi:10.1371/journal.pcbi.1012737, p.20]；[doi:10.1371/journal.pcbi.1012737, p.24]
- **declared_resources：** 作者声明开放了 Supplementary Material 和 GitHub 仓库 https://github.com/Reshiiii/hnRNPA1_Data_Scripts，其中包含 LAMMPS 输入脚本、A1-LCD 变体配置文件与部分补充材料。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.1]；[doi:10.1371/journal.pcbi.1012737, p.20]
- **declared_resources：** 作者还提供了 Direct Coexistence、viscosity 和蛋白构象的示例视频，并说明主要计算资源来自 Cambridge Tier-2 与 Mare Nostrum 5。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.24]
- **limitations：** 只有 WT+NLS、allF 和 allY 有直接测得的 temperature-vs-concentration phase diagrams；其余判断更多依赖 C_sat 和 viscosity 的交叉验证。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.6]；[doi:10.1371/journal.pcbi.1012737, p.10]；[doi:10.1371/journal.pcbi.1012737, p.11]
- **limitations：** Direct Coexistence 在 dilute phase 的采样很难，尤其低温下更明显，因此 C_sat 的估计既耗时又噪声大。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.10]
- **limitations：** 所有 residue-resolution CG 模型都系统性低估绝对 viscosity 多个数量级，作者把这归因于 implicit solvent/ions 和 bead-level coarse graining。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.13]
- **limitations：** 由于 computational constraints，原始 CALVADOS、KH 和 FB-HPS 等模型未纳入比较，所以基准并不穷尽全部可选方法。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.18]
- **method：** 作者把每个 A1-LCD 序列表示为 one-bead-per-amino-acid 的 residue-resolution CG 系统，并比较六种现有力场；其中 HPS、HPS-cation–π、HPS-Urry 和 CALVADOS2 主要基于 Ashbaugh-Hatch + Debye-Hückel，而 Mpipi 与 Mpipi-Recharged 使用 pair-specific 的 Wang-Frenkel，后者再用 pair-specific Yukawa 处理静电项。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.5]；[doi:10.1371/journal.pcbi.1012737, p.19]
- **method：** 相图通过 LAMMPS 中的 Direct Coexistence NVT MD 计算：每个体系放置 200 个蛋白，在细长盒子中形成 condensed/diluted 两相界面，并用 rectilinear diameters 与 critical exponents 拟合得到 T_c 和 ρ_c。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.20]；[doi:10.1371/journal.pcbi.1012737, p.21]
- **method：** 接触图在约 0.95 T_c 下从 DC trajectories 计算，使用 sequence-dependent cutoff 1.2σ_ij，并用模型中的 hydrophobic/electrostatic potential 之和定义 contact strength。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.21]；[doi:10.1371/journal.pcbi.1012737, p.22]
- **method：** 黏度通过 Green-Kubo 关系由 shear stress relaxation modulus G(t) 积分得到，长时间尾部再用 Maxwell modes 拟合后解析积分，以减小蛋白凝聚体系中的噪声。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.22]
- **method：** 作者还定义了对数尺度上的平均偏差 D，用于量化 simulated vs experimental 的 C_sat 与 viscosity 偏离程度，并同时报告 Pearson correlation coefficient r。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.23]
- **results：** 在 T_c 预测上，HPS 系统性低估实验值且相关性较差；HPS-Urry 能给出正确的相对排序，但绝对值平均仍低约 20%。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.6]；[doi:10.1371/journal.pcbi.1012737, p.7]
- **results：** HPS-cation–π 则明显高估 T_c，平均约高 30%，说明该模型对 cation–π 作用的增强过头。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.7]；[doi:10.1371/journal.pcbi.1012737, p.17]
- **results：** CALVADOS2 的 T_c 接近实验，约 5% 误差，但三个变体的相对排序有偏差；Mpipi 约高估 6% 且顺序正确；Mpipi-Recharged 的 T_c 与实验最接近，偏差小于 3%。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.7]；[doi:10.1371/journal.pcbi.1012737, p.8]
- **results：** 对 C_sat，Mpipi-Recharged 在归一化对比中最好（D=0.63, r=0.9947）；Mpipi 次之（D=0.97, r=0.8766）；CALVADOS2 也能跟随趋势但更弱（D=1.26, r=0.7549）。在绝对值对比里，CALVADOS2 的平均误差最小，但相关性仍不如 Mpipi-Recharged。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.11]
- **results：** 对 viscosity，Mpipi-Recharged 仍是最好模型（r=0.8819, D=0.7314），Mpipi 与 CALVADOS2 分别较弱（r=0.6308/0.5281）且误差更大；作者还指出 allW 的黏度变化可接近两个数量级，并与实验趋势一致。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.13]
- **results：** 接触图显示，WT+NLS 的关键稳定作用主要是 cation–π（R–Y、R–F）和 π–π（F–F、Y–F、Y–Y）；allF 以 R–F、Y–F、F–F 和 N 相关接触为主，allW 则强化 W–W、W–R 以及末端区域的协同相互作用。
  - 证据：[doi:10.1371/journal.pcbi.1012737, p.15]；[doi:10.1371/journal.pcbi.1012737, p.16]

# Machine learning coarse-grained potentials of protein thermodynamics

- **论文 ID：** `EVIW-1CF3E7A2D828542E`
- **期刊 / 来源：** Nat Commun
- **发表时间：** 2023 Sep 15
- **DOI：** [10.1038/s41467-023-41343-1](https://doi.org/10.1038/s41467-023-41343-1)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者声称提出了基于 TorchMD-GN 的可迁移 machine learning coarse-grained potential，并用单一模型覆盖 12 个结构多样蛋白，还能对少量突变体给出可用的结构预测。

## 创新边界

`页内证据支持“多蛋白单模型”的方法主张，但无法独立核验“首次真正 transferable”或更广泛全球新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

学习一种可跨蛋白复用的 coarse-grained 势能，使有限的全原子 MD 轨迹也能重建蛋白热力学、折叠路径与稳定态，而不只是拟合单一目标蛋白。

## 方法

- 以全原子轨迹学习粗粒化神经势，分别训练蛋白特异和多蛋白模型，再比较构象宏态及相对能量。[doi:10.1038/s41467-023-41343-1, p.1][doi:10.1038/s41467-023-41343-1, p.3]

## 数据与基准

- 约 9 毫秒、12 种不同二级结构组合蛋白的无偏全原子 MD 数据，另检查突变蛋白的实验结构特征。[doi:10.1038/s41467-023-41343-1, p.1]

## 比较基线

- 以对应全原子体系的构象和自由能/结构分布作为参照，并区分蛋白特异势与共享多蛋白势。[doi:10.1038/s41467-023-41343-1, p.3]

## 结果证据

- 作者报告动力学加速超过三个数量级，同时保留主要热力学分布；单个多蛋白势可恢复 12 个体系的相关结构态及突变体实验特征。[doi:10.1038/s41467-023-41343-1, p.1]

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 当前无偏 MD 仍难描述更长时间事件、大蛋白和多蛋白复合物；12 个训练蛋白不足以证明普适粗粒化势。[doi:10.1038/s41467-023-41343-1, p.2]

## 仍未知

- 是否真能推广到更大蛋白或更广序列空间仍不清楚。
- 作者未提供独立 hold-out test set，外部泛化边界有限。
- β-sheet 富集体系的失败原因主要是数据偏置还是模型结构限制，页内证据不能完全区分。
- 代码仓库的实际可复现性与许可证边界未在冻结页内独立核验。

## Pi 结构化证据摘录

- **baseline：** 主要参照是 all-atom MD 参考自由能面与实验晶体结构；作者以它们评估 coarse-grained 模型是否重建正确的 macrostates 与结构。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.1]；[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.4]；[doi:10.1038/s41467-023-41343-1, p.5]
- **baseline：** 论文将结果与作者先前的单蛋白 coarse-grained / NNP 工作对照，并把传统 coarse-graining 文献作为方法背景，强调这里的单模型多蛋白学习。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.2]；[doi:10.1038/s41467-023-41343-1, p.11]；[doi:10.1038/s41467-023-41343-1, p.12]
- **data：** 数据覆盖 Chignolin、Trp-Cage、BBA、WW-Domain、Villin、NTL9、BBL、Protein B、Homeodomain、Protein G、α3D、λ-repressor，序列长度约 10–80 aa，总聚合模拟时间约 9 ms。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.8]
- **data：** 起始结构来自 PDB；作者还测试了 1BAL、1GAB、2N35、1DU0、1P7I、1P7J、2HOS、6M3D、2MTQ、1LLI、3KZ3 等突变体，用于检验序列外泛化。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.7]；[doi:10.1038/s41467-023-41343-1, p.10]；[doi:10.1038/s41467-023-41343-1, p.11]；[doi:10.1038/s41467-023-41343-1, p.12]
- **data：** 论文公开了模型、数据与代码仓库，并给出 GitHub/Zenodo 链接作为可复用资源。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.10]；[doi:10.1038/s41467-023-41343-1, p.11]；[doi:10.1038/s41467-023-41343-1, p.12]
- **declared_resources：** 作者使用 ACEMD、GPUGRID.net、TorchMD、TorchMD-Net、PyTorch Geometric、PyTorch Lightning，以及 Nvidia GeForce RTX 2080 GPU 来生成数据、训练网络并运行 coarse-grained simulations。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.8]；[doi:10.1038/s41467-023-41343-1, p.9]；[doi:10.1038/s41467-023-41343-1, p.10]
- **declared_resources：** 公开资源包括 github.com/torchmd/torchmd-protein-thermodynamics、github.com/torchmd/torchmd、github.com/torchmd/torchmd-net 及其 Zenodo 存档，外加所用 PDB 起始结构列表。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.10]；[doi:10.1038/s41467-023-41343-1, p.11]；[doi:10.1038/s41467-023-41343-1, p.12]
- **limitations：** 作者明确指出 force-matching 不保 kinetics，因此 energy barriers 与 transition rates 不应被解读为精确。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.5]
- **limitations：** 多蛋白模型对 β-sheet 蛋白表现较弱，NTL9 和 WW-Domain 在随机线团起点下难以稳定回到 native state。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.5]；[doi:10.1038/s41467-023-41343-1, p.6]
- **limitations：** 训练仍依赖昂贵的全原子 MD 数据，且作者没有提供 hold-out test set；更大蛋白或更宽序列空间上的可迁移性仍未知。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.7]；[doi:10.1038/s41467-023-41343-1, p.10]
- **method：** 采用 α-carbon coarse-graining：每个残基保留一个 Cα bead，并以 21 类 bead type 表示氨基酸身份；网络在 TorchMD-Net 上训练，输出力场并叠加键合、排斥和二面角 prior 以限制非物理构象。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.2]；[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.8]；[doi:10.1038/s41467-023-41343-1, p.9]
- **method：** 训练集来自 12 个 fast-folding proteins 的无偏全原子 MD；作者使用 adaptive sampling、ACEMD、CHARMM22*、TIP3P，并在 350 K 下累计生成约 9 ms 数据。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.2]；[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.8]
- **method：** 粗粒化模拟通过 TorchMD 执行，使用 32 条并行轨迹从参考自由能面上的构象启动；MSM、TICA 与 PCCA 用于重建自由能面、识别 macrostates 并选取 native macrostate。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.4]；[doi:10.1038/s41467-023-41343-1, p.10]
- **results：** 蛋白特异模型在 12 个目标上都能重建实验结构；较简单体系的 native macrostate RMSD 可低至 0.7 Å，且折叠/展开转变被加速到比 all-atom MD 快 3 个数量级以上。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.3]；[doi:10.1038/s41467-023-41343-1, p.4]
- **results：** 多蛋白模型对大多数蛋白仍能恢复 native structure，但对 NTL9 和 WW-Domain 失败；在 Trp-Cage 和 Protein B 上，多蛋白模型甚至优于蛋白特异模型。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.5]；[doi:10.1038/s41467-023-41343-1, p.6]
- **results：** 突变体测试显示，少量突变的 α-螺旋蛋白通常仍可恢复 native conformation，但含 β-sheet 或改动较大的序列泛化明显更差。
  - 证据：[doi:10.1038/s41467-023-41343-1, p.7]

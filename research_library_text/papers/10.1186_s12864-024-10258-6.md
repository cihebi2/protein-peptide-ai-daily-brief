# Machine learning assists prediction of genes responsible for plant specialized metabolite biosynthesis by integrating multi-omics data

- **DOI：** [10.1186/s12864-024-10258-6](https://doi.org/10.1186/s12864-024-10258-6)
- **批次：** mass-review-20260916 / PMC 存量批次（未入 strict-v2 清单）
- **审阅方式：** LLM 全文分页精读（创新卡带页码与 ≤25 词原文摘录）

## 研究问题

植物特化代谢物(PSM) biosynthetic 基因的候选空间巨大、传统共表达分析分辨率有限；如何整合多组学特征用自动机器学习预测负责萜类/生物碱/酚类生物合成的酶基因并跨物种泛化。

## 作者主张的贡献

用AutoGluon-Tabular自动ML集成（RF/LightGBM/CatBoost/XGBoost/NN等堆叠）整合拟南芥基因组/蛋白组/转录组/表观组特征预测三类PSM酶基因；发现基因组+蛋白组特征贡献最大，仅用这两类即可超过全特征模型；跨物种验证（番茄/玉米/葡萄/罂粟）显示多物种训练的种间模型可达甚至超过种内预测性能。

## 创新边界

AutoGluon为现成自动ML框架，特征类型（蛋白domain、共表达、序列k-mer频率）均为文献常规；创新点在'跨物种PSM酶基因预测的系统验证'与'蛋白/基因组特征比转录组更关键'的实证结论，属于应用层面的新知识而非新方法。

## 创新点证据卡

- **[p1]** 实证基因组+蛋白组特征是PSM酶基因预测最关键的两类，精简特征反超全组学模型
  - 原文："Using only these key features, we built a new model in Arabidopsis, which performed better than models built with more features"
- **[p1]** 多物种联合训练的种间模型达到与种内预测相当或更优的跨物种泛化
  - 原文："models tested for maize and trained with data from two other species exhibited either equivalent or superior performance to intraspecies predictions"
- **[p4]** AutoGluon-Tabular自动堆叠集成AUC 0.891优于所有内置单模型，小样本下深度模型最差
  - 原文："the final ensemble model of AutoGluon-Tabular yielded an average AUC-ROC of 0.891... higher than all the built-in conventional ML algorithms"
- **[p4]** 构建仅含PMID实验验证基因的金标准数据集并证明其与计算注释集性能差异微小
  - 原文："models built with experimentally validated genes only showed minor, if any, advantage over models when computationally annotated genes were included"

## 方法

- AutoGluon-Tabular多模型线性堆叠集成
- 三类分类（萜类/生物碱/酚类酶基因）+两两二分类
- 特征体系：120个序列特征、28表达/共表达、9染色质可及性、43蛋白domain
- 金标准(GS)数据集仅保留PMID实验验证基因
- 5次随机划分重复+种间/种内/多物种模型对比

## 数据与基准

- 拟南芥GS数据集：146萜类/212生物碱/236酚类基因
- 番茄467、玉米544个PSM酶（Plant Metabolic Network PMN, plantcyc.org）
- 葡萄与罂粟外部验证集

## 结果证据

- AutoGluon集成AUC-ROC 0.891（GS三分类）优于全部内置单模型；深度模型因样本小表现最差
- 仅基因组+蛋白组特征AUC 0.885，加表达等更多组学反而略低；两特征组合并的正特征集AUC 0.905±0.025
- 种内预测a-a AUC 0.924；单物种种间s-a降至0.785
- 双物种训练的种间模型显著优于单物种种间模型，多物种纳入可达到与种内相当或更优

## 比较基线

- AutoGluon内置各基学习器（RF/LightGBM/CatBoost/ExtraTrees/XGBoost/NN）
- 全特征模型vs精简特征模型互为对照

## 已知限制

- GS正样本规模仅数百基因，类别不平衡问题未详述
- 负样本定义（非PSM基因）可能含未注释的假阴性
- 深度学习表现差归因于小样本，未尝试预训练蛋白语言模型特征

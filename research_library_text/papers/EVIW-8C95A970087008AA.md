# SwissDock 2024: major enhancements for small-molecule docking with Attracting Cavities and AutoDock Vina

- **期刊 / 来源：** Nucleic Acids Res
- **发表时间：** 2024 Apr 30

## 作者主张的创新点

作者将 SwissDock 升级为 SwissDock 2024，集成 Attracting Cavities 2.0 与 AutoDock Vina，重做 Web 界面与 command-line 访问，扩展了配体/靶标输入、数据库检索、共价对接与结果交互展示能力。

## 创新边界

`主要创新在服务工程集成与工作流升级，不是提出新的核心 docking 算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何把成熟的小分子分子对接能力做成一个更易用、可扩展、支持多输入与共价模式的在线服务，以便直接用于候选分子的 docking 与排序。

## Pi 结构化证据摘录

- **baseline：** 相较于 2011 版 SwissDock 基于 EADock DSS 的设计，2024 版改用 AC 2.0 与 AutoDock Vina；作者同时声称 Vina 更快、AC 更准确。
  - 证据：[doi:10.1093/nar/gkae300, p.1]；[doi:10.1093/nar/gkae300, p.2]
- **baseline：** 旧版站点仍至少保留六个月，说明新旧 SwissDock 在过渡期内并行，而不是瞬间替换。
  - 证据：[doi:10.1093/nar/gkae300, p.7]
- **data：** 配体高级检索把 PDB chemical component dictionary 与完整 ChEBI 合并，并以 pH 7.4 的预质子化形式提供可检索小分子。
  - 证据：[doi:10.1093/nar/gkae300, p.3]
- **data：** 靶标既可上传 PDB/PDBQT，也可从 PDBe、SWISS-MODEL 或 AlphaFold Protein Structure Database 直接检索，并可按 chain 与 heteroatom 选择保留内容。
  - 证据：[doi:10.1093/nar/gkae300, p.3]；[doi:10.1093/nar/gkae300, p.4]
- **data：** 结果包包含 prepared ligand/target 文件、parameter file、Dock4 文件，以及用于后处理的 PDB 和 PDBQT pose 文件。
  - 证据：[doi:10.1093/nar/gkae300, p.6]
- **declared_resources：** 配体准备依赖 SwissParam、ChemAxon JChem Microservices、OpenBabel、RDKit 与 Meeko，这些都是明确列出的外部工具链。
  - 证据：[doi:10.1093/nar/gkae300, p.3]
- **declared_resources：** 靶标准备依赖 AutoDockFR、CHARMM36/CHARMM36m 及相关 topology/parameter 资源，展示层使用 NGL Viewer。
  - 证据：[doi:10.1093/nar/gkae300, p.3]；[doi:10.1093/nar/gkae300, p.4]
- **declared_resources：** 前后端栈还明确列出 HTML5、PHP 7.4.3、JavaScript、web.py 0.62、Python 3.8、Slurm 19.05.5 与 sumoselect。
  - 证据：[doi:10.1093/nar/gkae300, p.3]；[doi:10.1093/nar/gkae300, p.4]
- **limitations：** 系统对估计计算时间设定硬阈值：Vina 必须少于 10 分钟、AC 少于 1 小时，超过时需要缩小搜索空间或调整目标大小。
  - 证据：[doi:10.1093/nar/gkae300, p.5]
- **limitations：** 结果仅在服务器上保留至少一周后删除，因此长期可追溯性和重复下载并不保证。
  - 证据：[doi:10.1093/nar/gkae300, p.6]；[doi:10.1093/nar/gkae300, p.7]
- **method：** SwissDock 2024 用 Attracting Cavities 2.0 或 AutoDock Vina 取代旧版 EADock DSS，并把配体、靶标准备和打分流程封装为服务器端对接服务。
  - 证据：[doi:10.1093/nar/gkae300, p.1]；[doi:10.1093/nar/gkae300, p.2]；[doi:10.1093/nar/gkae300, p.3]
- **method：** Attracting Cavities 2.0 通过 cavity cloud points、placement/rotation 采样、random initial conditions 与几何优化完成 docking，排序时使用 AC docking score 或 SwissParam score。
  - 证据：[doi:10.1093/nar/gkae300, p.2]
- **method：** AutoDock Vina 通过 Python library 1.2.5 集成，使用 Vina scoring function、grid map 插值和 postprocessing minimization，并按 Vina score 排序。
  - 证据：[doi:10.1093/nar/gkae300, p.3]
- **method：** 前端/后端实现包括 HTML5、PHP、JavaScript、web.py、Python 3.8 与 Slurm 队列，配合 NGL Viewer 提供交互式 3D 展示、作业监控和结果浏览。
  - 证据：[doi:10.1093/nar/gkae300, p.3]；[doi:10.1093/nar/gkae300, p.4]；[doi:10.1093/nar/gkae300, p.5]；[doi:10.1093/nar/gkae300, p.6]
- **results：** 新界面支持 SMILES、Mol2、PDB、PDBQT、草图编辑与搜索空间可视化定义，并允许用户监控、停止作业以及在结果页交互式查看 pose 和相互作用。
  - 证据：[doi:10.1093/nar/gkae300, p.4]；[doi:10.1093/nar/gkae300, p.5]；[doi:10.1093/nar/gkae300, p.6]
- **results：** SwissDock 2024 同时支持 non-covalent 与 covalent small-molecule docking；命令行还允许保留 crystallographic water molecules。
  - 证据：[doi:10.1093/nar/gkae300, p.1]；[doi:10.1093/nar/gkae300, p.7]
- **results：** 结果页还能一键联动 SwissParam、SwissSimilarity、SwissTargetPrediction、SwissADME 与 SwissBioisostere，形成较完整的药物发现工作流。
  - 证据：[doi:10.1093/nar/gkae300, p.6]；[doi:10.1093/nar/gkae300, p.7]

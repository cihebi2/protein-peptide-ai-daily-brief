# A conditional protein diffusion model generates artificial programmable endonuclease sequences with enhanced activity

- **论文 ID：** `EVIW-C01A245FD055519A`
- **期刊 / 来源：** Cell Discov
- **发表时间：** 2024 Sep 10
- **DOI：** [10.1038/s41421-024-00728-2](https://doi.org/10.1038/s41421-024-00728-2)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出 CPDiffusion，一种条件蛋白离散扩散模型，在 backbone、secondary structure 与保守残基约束下生成新型蛋白序列，并在 KmAgo/PfAgo 上获得高成功率的活性增强候选。

## 创新边界

`本稿的新意主要是把条件离散扩散用于多域 pAgo 序列生成与体外验证；冻结证据支持其在 KmAgo/PfAgo 上有效，但不足以证明对更广蛋白设计领域的全球首创。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在训练数据有限、结构复杂、长度接近 800 aa 的多域 pAgo 酶上，自动生成仍保留催化功能且能提升活性/热稳定性的全新蛋白序列。

## 方法

- 先以约20,000个CATH 4.2结构训练通用逆折叠基模，再从694条pAgo家族总集中排除模板，以693条序列学习保守模式；条件反向扩散生成KmAgo/PfAgo序列，经结构预测和筛选后表达、纯化，并测ssDNA切割、可溶性、热稳定性、CD/SAXS及部分MD。

## 数据与基准

- 通用训练约20,000个CATH结构；pAgo家族总集694条，排除模板后训练使用693条；实验检查27个Km-AP和15个Pf-AP，序列相对模板约50%-70%一致、与其他NCBI野生型多低于40%。

## 比较基线

- 论文在CATH 4.2、TS50、T500上与现有逆折叠基线比较，并用通用基模对比加入pAgo家族信息后的条件模型；湿实验基线是Km-WT和Pf-WT。

## 结果证据

- 27个Km设计中24个有37摄氏度ssDNA切割活性，20个优于Km-WT，Km-AP23约为WT的9倍；15个Pf设计均可表达且可溶，在45摄氏度有明确切割活性，多数优于WT；催化DEDD/DEDH基序在生成序列中保持。

## 已知限制

- pAgo 总集只有694条，排除模板后训练使用693条，且实验只覆盖两个模板，尚不能证明对一般复杂酶家族通用。 实验候选经过结构与序列筛选，论文报告的是筛选后成功率，不是所有生成序列的无条件成功率。 作者未给出正式局限章节；对脱靶切割、长期稳定性、细胞内性能和更广底物谱的证据有限。 相关发明存在临时专利申请，后续许可和自由实施需单独核查。

## 仍未知

- 冻结证据未核验作者 GitHub 仓库的实际内容、许可证与可复现性。
- 未见细胞内或体内实验，生理场景有效性未知。
- 对其它蛋白家族与其它长度/域架构的泛化仍未证明。

## Pi 结构化证据摘录

- **baseline：** 与 ProteinMPNN 相比，CPDiffusion 更能保留 polar AAs 和 PIWI catalytic tetrads；ProteinMPNN 在这些位点上会误生成带相反电荷的残基。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]
- **baseline：** 作者还以仅含 CATH 4.2 的 base model 作为通用对照，并在 CATH 4.2、TS50、T500 inverse folding benchmark 上验证其生成能力。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]
- **baseline：** 无 pAgo 数据的 ablation 版本失去 DEDX motif 和保守位点，说明 family-specific pAgo 数据是关键对照。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.7]
- **data：** 训练数据由约 20,000 个 CATH 4.2 结构和 694 个 pAgo 蛋白组成，后者覆盖 short、long-A、long-B 类型，且多数来自 mesophilic pAgo。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.10]
- **data：** 设计模板是约 800 aa、六个结构域的 KmAgo 与 PfAgo；前者可用 DNA/RNA 作为 guide，后者主要是 DNA-guided 且偏高温工作。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.2]；[doi:10.1038/s41421-024-00728-2, p.3]
- **data：** KmAgo 路线生成 100 个候选并筛出 27 个，PfAgo 路线生成 50 个候选并筛出 15 个进入实验。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.4]
- **data：** 作者还对 WT KmAgo、WT PfAgo 以及多种其他 WT pAgo/非 pAgo 序列做了对照和结构分析。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.6]；[doi:10.1038/s41421-024-00728-2, p.7]
- **declared_resources：** Shanghai Jiao Tong University 高性能计算中心提供了计算资源，用于模型训练与分析。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.11]
- **declared_resources：** Shanghai Synchrotron Radiation Facility 的 BL19U2 beamline 用于 SAXS 测量。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.11]
- **declared_resources：** Tierra Bioscience cell-free expression platform 用于 Km-WT 与 Km-APs 的 cell-free expression 和提取。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.11]
- **declared_resources：** 分析链路还明确使用 AlphaFold2/3、GROMACS 2020.4、MUSCLE v5、IQ-TREE v1.6、PyMOL 与 Chimera。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.10]；[doi:10.1038/s41421-024-00728-2, p.11]
- **limitations：** 作者指出训练集主要由 mesophilic pAgo 构成，因此 Pf-AP 虽能在中温下更活跃，但 Tm 从约 100°C 降到约 50°C，说明温度适应性受训练分布限制。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.6]
- **limitations：** 当前冻结证据只覆盖 KmAgo 与 PfAgo 两个模板，且验证主要停留在体外表达、纯化和生化测定层面，未见细胞内或体内功能实验。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.4]；[doi:10.1038/s41421-024-00728-2, p.5]；[doi:10.1038/s41421-024-00728-2, p.6]；[doi:10.1038/s41421-024-00728-2, p.11]
- **method：** CPDiffusion 将蛋白表示为残基图，并用 SE(3) 等变图神经网络参数化逆向去噪，在采样中加入 backbone、secondary structure、transition matrix 与保守位点约束。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.2]；[doi:10.1038/s41421-024-00728-2, p.10]
- **method：** 作者先用约 20,000 个 CATH 4.2 晶体结构训练 base model，再加入 693 个 WT pAgo 形成 family-specific bias；生成时排除 template，并对关键位点做 inpainting 约束。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.10]
- **method：** 生成候选先经 AlphaFold2 的 pLDDT、残基级波动、RMSD/TM 筛选，再进入 E. coli 表达、纯化、SAXS、CD、cleavage、DSF、EMSA、FP 与 MD 验证。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.4]；[doi:10.1038/s41421-024-00728-2, p.10]；[doi:10.1038/s41421-024-00728-2, p.11]
- **method：** PfAgo 与 KmAgo 使用同一套流程分别生成候选，最终保留 27 个 Km-AP 和 15 个 Pf-AP 进入湿实验。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.3]；[doi:10.1038/s41421-024-00728-2, p.4]
- **results：** 27 个 Km-AP 全部可溶表达；其中 24 个表现出 ssDNA cleavage activity，20 个优于 WT KmAgo，最佳 Km-AP23 约为 WT 的 9 倍。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.5]；[doi:10.1038/s41421-024-00728-2, p.6]
- **results：** 10 个 Km-AP 的 thermostability 优于 WT，且 Km-AP5 与 Km-AP14 同时在 activity 和 thermostability 上提升。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.6]
- **results：** 15 个 Pf-AP 全部具有 ssDNA cleavage activity，在 45°C 下都优于 WT PfAgo；其中 6 个在 45°C 的活性甚至超过 WT PfAgo 在 95°C 的水平。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.6]
- **results：** 序列与结构分析显示生成序列保留 DEDD/DEDH motif、保守位点和电荷分布，并在进化空间中靠近 pAgo 家族；去掉 pAgo 数据会破坏这些保守模式。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.7]；[doi:10.1038/s41421-024-00728-2, p.9]
- **results：** 作者报告在 pAgo 任务上的生成成功率超过 90%，且单步可改变多达近 400 aa。
  - 证据：[doi:10.1038/s41421-024-00728-2, p.1]；[doi:10.1038/s41421-024-00728-2, p.9]

# A Robust Drug–Target Interaction Prediction Framework with Capsule Network and Transfer Learning

- **期刊 / 来源：** Int J Mol Sci
- **发表时间：** 2023 Sep 14

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 CapBM-DTI：用 ProtBert 编码蛋白、用 MPNN 编码分子，再用 capsule network 做 DTI 二分类，并声称在多个实验验证数据集上表现优于现有方法。[doi:10.3390/ijms241814061, p.1][doi:10.3390/ijms241814061, p.3][doi:10.3390/ijms241814061, p.17]

## 创新边界

`可确认的是组合式框架与实验验证负样本数据集；“首个使用 capsule network 分类 DTI”等全球新颖性仅是作者自述，冻结材料未独立验证。[doi:10.3390/ijms241814061, p.3][doi:10.3390/ijms241814061, p.11][doi:10.3390/ijms241814061, p.17]`。这不是全球首创性检索或独立复现结论。

## 研究问题

DTI 预测中常见问题是负样本缺乏实验验证、随机采负样本会引入噪声，以及蛋白/分子表示与分类器不足导致对未见样本泛化差。[doi:10.3390/ijms241814061, p.1][doi:10.3390/ijms241814061, p.11]

## 方法

- 分别编码compound和protein，capsule聚合层级interaction特征，并在实验验证DTI集迁移训练。

## 数据与基准

- human、worm四个实验验证DTI集及new compound/new protein/new pair子集。

## 比较基线

- AI-Bind等DTI模型和多种transfer/capsule消融。

## 结果证据

- 论文报告超过SOTA；为计算DTI分类。

## Pi 结构化证据摘录

- **baseline：** 内部消融比较使用 7 个基线组合，交叉 BERT/one-hot、MPNN/fingerprint、dense/capsule，以检验三个模块各自贡献。[doi:10.3390/ijms241814061, p.3]
  - 证据：[doi:10.3390/ijms241814061, p.3]
- **baseline：** 外部方法比较包含 DeepConv-DTI、CPI_prediction、TransformerCPI 与 IIFDTI，并在四个数据集上使用相同 8:2 切分对比。[doi:10.3390/ijms241814061, p.7][doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.7]；[doi:10.3390/ijms241814061, p.8]
- **baseline：** 作者还把方法放到 new compounds、new proteins 和 new pairs 的设置中，与前作比较以检验泛化能力。[doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.8]
- **data：** Dataset 1 包含 6602 个 compounds、1900 个 proteins、16627 个 positive interactions 与 11768 个 negative interactions；Dataset 2 包含 14737 compounds、2709 proteins、32013/32013 正负样本。[doi:10.3390/ijms241814061, p.8][doi:10.3390/ijms241814061, p.11]
  - 证据：[doi:10.3390/ijms241814061, p.8]；[doi:10.3390/ijms241814061, p.11]
- **data：** Dataset 3 与 Dataset 4 分别是 H. sapiens 和 C. elegans 数据集，正负样本数为 3364/3364 与 3893/3893。[doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.8]
- **data：** new compounds、new proteins、new pairs 三个子集都采用 8:2 切分，并保证测试集与训练集在相应实体上无交集。[doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.8]
- **declared_resources：** 作者在结论中声明源代码与数据可在 GitHub 的 https://github.com/huangyixian666/CapBM-DTI 获取。[doi:10.3390/ijms241814061, p.17]
  - 证据：[doi:10.3390/ijms241814061, p.17]
- **declared_resources：** 训练与实现资源包括 TensorFlow/Keras、NVIDIA A1000 40GB GPUs，以及 grid search 和 early stopping 流程。[doi:10.3390/ijms241814061, p.12]
  - 证据：[doi:10.3390/ijms241814061, p.12]
- **limitations：** 作者也指出，BERT 类模型并不能直接恢复高分辨率 3D 结构，更多是捕捉序列相关的局部结构信号，因此表示能力仍有边界。[doi:10.3390/ijms241814061, p.13]
  - 证据：[doi:10.3390/ijms241814061, p.13]
- **limitations：** 正文的主要证据来自离线基准测试与 DrugBank 虚拟筛选案例，未见新的 wet-lab 实验来直接验证预测命中。[doi:10.3390/ijms241814061, p.10][doi:10.3390/ijms241814061, p.17]
  - 证据：[doi:10.3390/ijms241814061, p.10]；[doi:10.3390/ijms241814061, p.17]
- **method：** 作者构建了四个 DTI 数据集，其中 Dataset 1 和 Dataset 2 分别来自 KinaseSARfari/IUPHAR 与 PubChem BioAssay，Dataset 3 和 Dataset 4 取自 Liu et al. 的基准集。[doi:10.3390/ijms241814061, p.11][doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.11]；[doi:10.3390/ijms241814061, p.8]
- **method：** 蛋白序列先经 ProtBert 生成 1024 维上下文向量，再经全连接层与 batch normalization 压缩为 200 维表示。[doi:10.3390/ijms241814061, p.12][doi:10.3390/ijms241814061, p.13]
  - 证据：[doi:10.3390/ijms241814061, p.12]；[doi:10.3390/ijms241814061, p.13]
- **method：** 药物以 2-D atomic graph 输入 MPNN，节点用原子化学信息初始化，消息传递后通过 transformer encoder 加 average pooling 做 readout，得到图级表示。[doi:10.3390/ijms241814061, p.13][doi:10.3390/ijms241814061, p.14]
  - 证据：[doi:10.3390/ijms241814061, p.13]；[doi:10.3390/ijms241814061, p.14]
- **method：** 蛋白与药物表示拼接后送入 capsule network，模型使用 dynamic routing、squash 与 margin loss 完成二分类。[doi:10.3390/ijms241814061, p.15][doi:10.3390/ijms241814061, p.16]
  - 证据：[doi:10.3390/ijms241814061, p.15]；[doi:10.3390/ijms241814061, p.16]
- **method：** 训练实现基于 TensorFlow/Keras，采用 Adam、batch size 64、learning rate 0.0001，并使用 early stopping 与 grid search 调参。[doi:10.3390/ijms241814061, p.12]
  - 证据：[doi:10.3390/ijms241814061, p.12]
- **results：** 在 Dataset 1 独立测试中，CapBM-DTI 达到 accuracy 0.893、F1 0.901、auROC 0.946、auPRC 0.970。[doi:10.3390/ijms241814061, p.5][doi:10.3390/ijms241814061, p.6]
  - 证据：[doi:10.3390/ijms241814061, p.5]；[doi:10.3390/ijms241814061, p.6]
- **results：** 在四个数据集总体对比中，CapBM-DTI 多数指标优于 DeepConv-DTI、CPI_prediction、TransformerCPI 与 IIFDTI，但 Dataset 2 的 AUC、Dataset 3 的 AUPR 和 Dataset 4 的 accuracy 不是最优。[doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.8]
- **results：** 在 new compounds/new proteins/new pairs 三种设置下，CapBM-DTI 的 accuracy 分别为 0.788/0.906/0.725，F1 分别为 0.766/0.874/0.615。[doi:10.3390/ijms241814061, p.8]
  - 证据：[doi:10.3390/ijms241814061, p.8]
- **results：** 作者还报告 6 个文献支持的 COVID-19 候选药物被模型高分预测，DTI probability 范围为 0.83505136–0.9957441。[doi:10.3390/ijms241814061, p.10]
  - 证据：[doi:10.3390/ijms241814061, p.10]
- **results：** 特征分析中，t-SNE 与聚类结果显示 DTI 与 non-DTI 在 capsule 层输出上更容易分离。[doi:10.3390/ijms241814061, p.6][doi:10.3390/ijms241814061, p.9]
  - 证据：[doi:10.3390/ijms241814061, p.6]；[doi:10.3390/ijms241814061, p.9]

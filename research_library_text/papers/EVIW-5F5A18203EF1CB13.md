# Evaluating BindCraft for Generative Design of High-Affinity Peptides

- **论文 ID：** `EVIW-5F5A18203EF1CB13`
- **期刊 / 来源：** ACS Chem Biol
- **发表时间：** 2025 Nov 18
- **DOI：** [10.1021/acschembio.5c00774](https://doi.org/10.1021/acschembio.5c00774)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称首次从终端用户视角系统评估 BindCraft 用于短肽 binder 设计；在 MDM2 与 WDR5-MYC 位点获得了纳摩尔到亚微摩尔级结合肽，并展示结构预测可直接指导 stapling 以进一步提升亲和力。

## 创新边界

`新意主要是工具迁移与实验验证，不是新算法或模型重训。`。这不是全球首创性检索或独立复现结论。

## 研究问题

评估 BindCraft 这类结构引导生成平台，能否在不改模型、仅凭靶标结构的条件下，直接生成可实验验证的 ≤20 aa 短肽配体，并观察其在 MDM2、WDR5 和 PD-1/PD-L1 等靶点上的可迁移性。

## 方法

- 原版BindCraft、不改代码/不重训；多个蛋白靶点；合成与竞争结合测定；部分肽stapling/修饰。

## 数据与基准

- 多个靶点的计算设计与体外结合测定；WDR5候选用于一步化学优化。

## 比较基线

- 典型虚拟筛选微摩尔命中、展示技术；BindCraft原始miniprotein用途作为参照。

## 结果证据

- 论文报告部分靶点获得高亲和肽；一个WDR5 binder经修饰提高6倍至KD=39 nM；stapling不能挽救原本无活性的肽。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 并非所有设计有活性，化学修饰救援具条件性；用户侧评估不能证明广泛靶点成功率。

## 仍未知

- 这些候选短肽在细胞内稳定性、递送性和药代性质如何，文中没有回答。
- BindCraft 对更大靶点集合和更多复杂蛋白-蛋白界面的可迁移性仍不清楚。
- 对 WDR5 WIN site 或 PD-1/PD-L1，是否存在其他后处理策略能挽救 binding 仍未知。

## Pi 结构化证据摘录

- **baseline：** MDM2 的竞争实验以 p53-derived peptide 作为参考，验证设计肽是否能抑制原生 MDM2-p53 相互作用。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]
- **baseline：** WDR5 优化部分以 native Myc_B1 与 scrambled sequence 作为对照，用来评估 stapling 带来的增益。
  - 证据：[doi:10.1021/acschembio.5c00774, p.5]
- **baseline：** 文中展示的主要基准是已知天然/参考肽和竞争实验对照，而不是与其他 peptide-design 算法的系统 head-to-head benchmark。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]；[doi:10.1021/acschembio.5c00774, p.5]
- **data：** 在 MDM2 案例中，BindCraft 生成了 70 个 unique peptides；作者从中选 20 条，最终 15 条成功纯化并进入 BLI。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]
- **data：** 在 WDR5 案例中，WIN site 与 MYC site 各生成 100 个候选；分别测试 top 10 / top 9，PD-1/PD-L1 则各合成 6 条候选用于验证。
  - 证据：[doi:10.1021/acschembio.5c00774, p.4]；[doi:10.1021/acschembio.5c00774, p.5]
- **data：** 数据可得性声明称，支撑结论所需数据已包含在正文和 Supporting Information 中，额外数据可向作者索取。
  - 证据：[doi:10.1021/acschembio.5c00774, p.6]
- **declared_resources：** 论文明确使用了外部 BindCraft GitHub 仓库，并在 in-house server 与 single GPU 上运行；计算资源主要来自现成工具。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]；[doi:10.1021/acschembio.5c00774, p.6]
- **declared_resources：** 实验资源包括 Octet R4、HPLC、MS、His-SUMO-WDR5 表达纯化体系，以及合成与 stapling 所需的化学试剂。
  - 证据：[doi:10.1021/acschembio.5c00774, p.5]；[doi:10.1021/acschembio.5c00774, p.6]
- **declared_resources：** 致谢中列出 NWO OCENW.M.23.152、Oncode Institute 和 H. J. M. Roels 的支持。
  - 证据：[doi:10.1021/acschembio.5c00774, p.7]
- **limitations：** BindCraft 在 WDR5 WIN site 与 PD-1/PD-L1 上都未产出可验证结合肽，说明并非所有界面都能被当前流程覆盖。
  - 证据：[doi:10.1021/acschembio.5c00774, p.4]；[doi:10.1021/acschembio.5c00774, p.5]；[doi:10.1021/acschembio.5c00774, p.6]
- **limitations：** 作者指出短肽缺少稳定三级结构、熵代价更高、且结合面更线性，因此比 miniprotein 更难设计。
  - 证据：[doi:10.1021/acschembio.5c00774, p.2]；[doi:10.1021/acschembio.5c00774, p.6]
- **limitations：** 研究只做了体外 BLI/competition assays，并且没有修改或重训模型，所以泛化性仍需要更大范围验证。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]；[doi:10.1021/acschembio.5c00774, p.6]
- **method：** 作者使用公开的 BindCraft GitHub 版本，在本地单 GPU 服务器上启用 peptide-specific 参数组合，并将设计长度限制为 10–20 aa 后按排名挑选候选肽进行验证。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]；[doi:10.1021/acschembio.5c00774, p.6]
- **method：** 所有待测肽都加入 N-terminal Lys(biotin) 与 β-alanine spacer；WDR5 还以 His-SUMO 融合蛋白在 E. coli BL21 中表达纯化，结合测定使用 Octet R4 BLI 与 1:1 kinetic model。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]；[doi:10.1021/acschembio.5c00774, p.6]
- **method：** 针对 WDR5 的 Myc_B1 设计，作者进一步选取 helix backside 的 i, i+4 位点做 cysteine stapling，并用 1,3-bis(bromomethyl)-benzene 构建 meta-xylene staple。
  - 证据：[doi:10.1021/acschembio.5c00774, p.5]；[doi:10.1021/acschembio.5c00774, p.6]
- **results：** MDM2 上有 7 条肽显示清晰结合，KD 为 65–165 nM；其中 3 条优于 p53 peptide，对照 p53 peptide 的 KD 为 123 nM。
  - 证据：[doi:10.1021/acschembio.5c00774, p.3]
- **results：** WDR5 的 MYC-binding site 上 6/9 条肽出现可检测结合，KD 为 219–650 nM；而 WIN site 的测试肽均未检测到结合。
  - 证据：[doi:10.1021/acschembio.5c00774, p.4]
- **results：** stapled Myc_B1 的 KD 提升到 39 nM，约比未 stapled 版本强 6 倍，并把最大抑制提高到 55.3%；PD-1/PD-L1 候选均未测到可检测结合。
  - 证据：[doi:10.1021/acschembio.5c00774, p.5]

# Predicting peroxisome proliferator-activated receptor gamma potency of small molecules: a synergistic consensus model and deep learning binding affinity approach powered by Enalos Cloud Platform

- **论文 ID：** `EVIW-00CA1038713C40D3`
- **期刊 / 来源：** Mol Divers
- **发表时间：** 2025 Jun 14
- **DOI：** [10.1007/s11030-025-11230-6](https://doi.org/10.1007/s11030-025-11230-6)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `蛋白-配体`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出了两条互补的 in silico 流程：一个基于 docking score 的 NN 结合强/弱 binder 分类器，以及一个由 RF、SVM 和 kNN 组成的 consensus antagonist predictor，并将其部署到 Enalos Cloud Platform 与 API。

## 创新边界

`创新主要在于把既有的 docking、ECFP、Mold2、RF/SVM/kNN 与 web deployment 串成可用工作流；更像是应用整合与封装，而不是全新基础算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

构建面向 PPARγ 的小分子虚拟筛选模型，分别预测结合亲和力与 antagonistic activity，以支持候选化合物的优先排序与风险评估。

## 方法

- 分子描述符和QSAR用于拮抗分类，docking-derived标签训练强/弱binder网络，并按OECD原则定义适用域。

## 数据与基准

- NuRA及PPARγ相关assay数据，含较多PFAS化合物。

## 比较基线

- RF、SVM、kNN单模型与既有PPARγ QSAR。

## 结果证据

- 论文称两模型经OECD式验证具泛化和少数类检测能力；核心仍为回顾性计算预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- docking分数不是实验亲和力，PFAS比例与assay来源可能限制化学域；无前瞻实验验证。

## 仍未知

- 补充信息 S1-S5 未展开，完整超参数网格与部分特征子集无法逐项核对。
- 网页应用与 REST API 可访问，但源码仓库与可重用许可证边界不清楚。
- PFAS 案例中 34 个化合物的完整选择依据与各性质可靠度细节主要依赖补充材料。

## Pi 结构化证据摘录

- **baseline：** 在结合亲和力任务中，RF 与 kNN 的测试集 accuracy 分别为 0.744 和 0.694，整体弱于 NN。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.7]
- **baseline：** 在拮抗活性任务中，三种单模型的测试集 balanced accuracy 低于 consensus，说明 majority vote 带来稳定增益。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.8]
- **baseline：** 作者还给出一个始终预测多数类 inactive 的 baseline，其 overall accuracy 仅 33.22%，balanced accuracy 为 50%。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.8]
- **data：** 训练数据来自 Tox21 的 qHTS assay AID 743199；作者从 PubChem Bioassay 提取 6587 个唯一化合物，去重、去盐并过滤少于 4 个原子的分子后保留，其中 220 个被标记为 PFAS。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.3]
- **data：** 对接后，结合能为正的样本被当作 outliers 删除，剩余 6538 个化合物进入结合亲和力建模。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.4]
- **data：** 拮抗活性数据在去重后严重不平衡，活性率约 6.5%；作者用随机下采样把数据压到 1230 个样本，其中 410 个 active、820 个 inactive。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.5]
- **data：** 案例研究额外筛选了 34 个 commercially available PFAS，并通过 ChemPharos 提供的 ds9 数据集及 Enalos/Titania 工作流评估其扩展性质。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.10]；[doi:10.1007/s11030-025-11230-6, p.13]
- **declared_resources：** 作者声明计算资源来自 The Cyprus Institute 的 Cyclone supercomputer，项目编号 pro24a01。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.13]
- **declared_resources：** 资金来源为 EU H2020 project SCENARIOS，Grant Agreement No. 101037509。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.13]
- **declared_resources：** 数据通过 ChemPharos 的 ds9 公开提供，模型则通过 Enalos Cloud Platform 的网页应用和 REST API 对外服务。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.10]；[doi:10.1007/s11030-025-11230-6, p.13]
- **limitations：** 作者明确指出 docking score 不能唯一决定 binding pose，也不能直接判断该 pose 是否对应 activation 或 inhibition，因此 strong binder 不等于 antagonist。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.12]
- **limitations：** PFAS 在初始数据集中只占 220 个，且在训练集中的代表性不足，作者也承认这会影响 generalisability 和 prediction confidence。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.11]；[doi:10.1007/s11030-025-11230-6, p.13]
- **limitations：** 代码可用性受限于 proprietary licensing agreement，正文未公开可直接复用的源码仓库。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.13]
- **method：** 先用 Enalos Asclepios KNIME pipeline 结合 Vina-GPU 对 PPARγ LBD（PDB 5YCP）做分子对接，并把正 binding energy 的化合物视为离群点剔除。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.3]；[doi:10.1007/s11030-025-11230-6, p.4]
- **method：** 结合 ECFP（radius 4, 2048 bits）训练 fully connected NN，用 k-means 在 -8.06 与 -5.49 kcal/mol 两个簇中心上把结合亲和力分成 strong/weak 两类。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.4]
- **method：** 抗拮抗活性任务使用 Mold2 777 descriptors，经低方差过滤、RUS、BestFirst/InfoGain 特征选择后，再用 RF、SVM、kNN 进行 majority vote consensus。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.5]；[doi:10.1007/s11030-025-11230-6, p.6]
- **results：** NN 在结合亲和力测试集上的表现优于 RF 和 kNN，测试集 accuracy 为 0.821，MCC 为 0.628，五折 CV 的 ROC-AUC 为 0.893 ± 0.014。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.7]
- **results：** consensus antagonist model 在测试集取得 balanced accuracy 0.835、F1 0.781、accuracy 0.858、kappa 0.676，并在十折交叉验证中保持较稳定表现。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.8]
- **results：** 34 个 PFAS 在 case study 中全部被预测为 inactive antagonist；其中对 binding 的分类虽有 strong/weak 差异，但并未转化为 antagonist 活性。
  - 证据：[doi:10.1007/s11030-025-11230-6, p.11]；[doi:10.1007/s11030-025-11230-6, p.12]

# ADME-drug-likeness: enriching molecular foundation models via pharmacokinetics-guided multi-task learning for drug-likeness prediction

- **论文 ID：** `EVIW-8DEF05D4191F5455`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2025 Jul 15
- **DOI：** [10.1093/bioinformatics/btaf259](https://doi.org/10.1093/bioinformatics/btaf259)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `语言模型`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 ADME-DL：先对 21 个 ADME endpoint 做 sequential multi-task learning，学习 ADME-informed embedding，再用 MLP 进行 drug-likeness 二分类，并声称该顺序设计符合 A→D→M→E 的 PK 流程。

## 创新边界

`边界主要是表征学习与分类提升，不是生成新分子，也不直接优化候选结构。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在早期药物筛选中，如何把 ADME/PK 依赖关系显式纳入 molecular foundation model，以更准确地区分 approved drugs 与 non-drugs，而不是只依赖结构特征。

## 方法

- 先分析ADME任务依赖，再按药代顺序进行多任务表示学习；第二阶段以ADME增强嵌入区分已批准药物和化学库负例。

## 数据与基准

- 整合吸收、分布、代谢和排泄任务数据，并在三个drug-likeness基准上比较；背景资源包括DrugMAP、PubChem和ZINC。

## 比较基线

- 结构指纹/描述符模型、常规多任务学习及多个分子基础模型。

## 结果证据

- 论文报告ADME增强嵌入在三个基准上超过结构导向方法；这是回顾性分类，不证明临床可开发性。

## Pi 结构化证据摘录

- **baseline：** 对照包含经典 fingerprint 分类器 Random Forest、MLP、SVM，以及 MolCLR、MAT、GraphMVP 等 molecular foundation models。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]
- **baseline：** 还比较了 DGCAN、DeepDL、DBPP-Predictor 等近年 drug-likeness 方法，并与 naïve MTL、reverse-Sequential MTL 和 vanilla MFM 做了对照。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]；[doi:10.1093/bioinformatics/btaf259, p.7]
- **data：** ADME 训练数据覆盖 21 个 endpoint，既包含 classification 也包含 regression，涉及 permeability、transporter、CYP450、clearance 等多类 PK 任务。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.3]
- **data：** drug-likeness 正例来自 DrugMAP 的 1963 个 approved drugs；负例分别从 ZINC20、PubChem、ChEMBL 各随机采样 10000 个，形成三套 benchmark。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.4]
- **data：** 每套 benchmark 都做了五折交叉验证，并保留 label distribution；作者还将重叠化合物合并，缺失标签记为 None。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.3]；[doi:10.1093/bioinformatics/btaf259, p.4]
- **declared_resources：** Source code 已公开在 GitHub 仓库 https://github.com/eugenebang/ADME-DL。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.1]；[doi:10.1093/bioinformatics/btaf259, p.10]
- **declared_resources：** 数据来自公开资源：DrugMAP、ZINC20、PubChem、ChEMBL 和 TDC。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.3]；[doi:10.1093/bioinformatics/btaf259, p.4]；[doi:10.1093/bioinformatics/btaf259, p.10]
- **limitations：** 作者明确把 toxicity 以及更广泛的 ADMET 扩展留作 future work，说明当前框架仍主要覆盖 21 个 ADME endpoint。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.3]；[doi:10.1093/bioinformatics/btaf259, p.9]
- **limitations：** 药物判别评估只覆盖 DrugMAP 与 ZINC20、PubChem、ChEMBL 这三类公开负例场景，向其他化学空间的外推仍未被直接证明。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.4]
- **method：** 整体框架分两步：先用 ADME-MTL 预训练 molecular foundation models，随后把得到的 embedding 送入 MLP 进行药物/非药物分类。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.2]；[doi:10.1093/bioinformatics/btaf259, p.4]
- **method：** 21 个 ADME endpoint 来自 TDC，并按 Absorption、Distribution、Metabolism、Excretion 四组组织，分别对应 8、3、8、2 个任务。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.3]；[doi:10.1093/bioinformatics/btaf259, p.5]
- **method：** 组内采用并行 multi-task learning，并用 PCGrad 缓解梯度冲突；组间则按 A→D→M→E 顺序串联训练，循环直到收敛。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]
- **method：** 作者先用 naïve MTL 枚举任务组合，定义 task improvement rate (TIR) 比较 STL 与 MTL 的 loss 差异，再据此构建 task dependency graph。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]；[doi:10.1093/bioinformatics/btaf259, p.6]
- **method：** 该框架是 model-agnostic 的，可接入 Fingerprint+MLP、GraphMVP、MolCLR、MAT 等 backbone，并在 ADME-MTL 阶段 fine-tune MFM 参数。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.4]
- **results：** 在 DrugMAP-ZINC 上，ADME-DL 的 MCC/F1/AUPRC 达到 0.850/0.852/0.912，整体优于 DBPP-Predictor 的 0.831/0.824/0.891。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]
- **results：** 在 DrugMAP-PubChem 与 DrugMAP-ChEMBL 上，ADME-DL 也保持最优或接近最优，尤其在 ChEMBL 上 F1 达到 0.347，明显高于多数基线。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.5]
- **results：** Sequential ADME MTL 相比 vanilla MFM 和 naïve MTL 通常进一步提升性能；GraphMVP、MAT、MolCLR、FP-MLP 在 A→D→M→E 下都得到增益。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.7]
- **results：** task dependency analysis 显示 Absorption 对其他任务普遍有正向帮助，而 Distribution、Metabolism、Excretion 之间存在更复杂的相互促进与干扰。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.6]；[doi:10.1093/bioinformatics/btaf259, p.7]
- **results：** 案例研究中，SeqADME 对 warfarin、atorvastatin、omeprazole、phenytoin、ibuprofen 的 ADME 标签和 drug-likeness 打分更贴近专家注释；tSNE silhouette score 也从 0.11 提升到 0.20。
  - 证据：[doi:10.1093/bioinformatics/btaf259, p.8]；[doi:10.1093/bioinformatics/btaf259, p.9]

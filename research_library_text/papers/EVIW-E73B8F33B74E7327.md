# FLAb: Benchmarking deep learning methods for antibody fitness prediction

- **论文 ID：** `EVIW-E73B8F33B74E7327`

- **范围标签：** `Pi 已解析` / `核心相关` / `有静态审计仓库` / `数据集/基准`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者构建 FLAb（Fitness Landscape for Antibodies），汇总多项公开抗体实验数据并系统比较多种蛋白语言模型、结构条件模型与 Rosetta 在六类抗体性质上的相关性表现。

## 创新边界

`创新边界主要在 benchmark 组装、评测协议与比较分析，不在新算法生成、候选优化或新 wet-lab 实验。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何用统一基准评估深度学习与物理模型对抗体 fitness landscape 的预测能力，并判断这些模型能否为 therapeutic antibody 设计提供可靠筛选信号。

## 方法

- 用各模型score/embedding关联多个实验fitness datasets并分析wild type/architecture/training/evolution effects。

## 数据与基准

- 多项独立抗体实验fitness数据，多数数据集样本很小。

## 比较基线

- 上述六个DL模型和Rosetta。

## 结果证据

- 没有模型跨所有property/dataset稳定相关；benchmark是主要贡献。

## 已知限制

- 许多数据集<30点、实验条件跨研究不一致；预印本。

## 仍未知

- 各公开研究之间的 assay 条件差异是否会系统性改变相关性排名，论文未做统一校正。
- 部分数据集样本量极小，个别相关系数可能受离群点和分组方式显著影响。
- 论文未提供 antigen 信息，因此 binding affinity 与部分结构方法的上限可能仍被低估。

## Pi 结构化证据摘录

- **baseline：** 对照对象覆盖了 antibody 专用生成模型、通用蛋白语言模型、结构条件逆折叠模型，以及 Rosetta 这一传统物理/经验能量函数，形成了较完整的比较框架。
  - 证据：[doi:10.1101/2024.01.13.575504, p.1]；[doi:10.1101/2024.01.13.575504, p.3]；[doi:10.1101/2024.01.13.575504, p.10]；[doi:10.1101/2024.01.13.575504, p.11]
- **baseline：** 与以往以 native sequence recovery 为主的 antibody 设计评估不同，作者强调 FLAb 直接用实验 fitness/biophysical readout 来评估模型与真实 developability 的对应关系。
  - 证据：[doi:10.1101/2024.01.13.575504, p.1]；[doi:10.1101/2024.01.13.575504, p.2]
- **data：** FLAb 汇总了来自 8 项公开研究的抗体实验数据，覆盖 expression、thermostability、immunogenicity、aggregation、polyreactivity 和 binding affinity 六类 developability/fitness 性质。
  - 证据：[doi:10.1101/2024.01.13.575504, p.2]；[doi:10.1101/2024.01.13.575504, p.3]；[doi:10.1101/2024.01.13.575504, p.8]；[doi:10.1101/2024.01.13.575504, p.9]
- **data：** 作者声称该集合包含 17 个 mutational landscapes、13,384 个 fitness metrics，并给出各数据集的样本数分布；其中有些任务如 aggregation 和 polyreactivity 只来自少数来源。
  - 证据：[doi:10.1101/2024.01.13.575504, p.3]；[doi:10.1101/2024.01.13.575504, p.16]
- **data：** 数据来源包括 Koenig、Hie、Marks、Rosace、Shanehsazzadeh、Warszawski、Wittrup 以及 GSK/作者相关数据，且论文提供了可公开访问的 GitHub 仓库链接。
  - 证据：[doi:10.1101/2024.01.13.575504, p.3]；[doi:10.1101/2024.01.13.575504, p.6]；[doi:10.1101/2024.01.13.575504, p.8]；[doi:10.1101/2024.01.13.575504, p.9]
- **declared_resources：** 论文声明 FLAb 的数据与模型打分方法可在 GitHub 仓库 https://github.com/Graylab/FLAb 获取，并允许继续贡献新增数据。
  - 证据：[doi:10.1101/2024.01.13.575504, p.1]；[doi:10.1101/2024.01.13.575504, p.8]
- **declared_resources：** 补充材料进一步说明了 scoring pipeline、各类模型公式与相关性计算方式，便于复核 benchmark 设定。
  - 证据：[doi:10.1101/2024.01.13.575504, p.9]；[doi:10.1101/2024.01.13.575504, p.10]；[doi:10.1101/2024.01.13.575504, p.11]
- **limitations：** 作者明确指出许多标注数据集很小，常常少于 30 个点；在 1872 个相关性里只有 515 个达到 p < 0.05，因此统计稳定性有限。
  - 证据：[doi:10.1101/2024.01.13.575504, p.16]；[doi:10.1101/2024.01.13.575504, p.17]
- **limitations：** 不同公开研究的实验条件并不一致，尤其 binding affinity 可能受溶液条件等差异影响，因此跨研究比较存在不可忽略的系统偏差。
  - 证据：[doi:10.1101/2024.01.13.575504, p.17]
- **limitations：** 作者也提醒 FLAb 目前不适合直接训练新模型，后续若用这些 embedding 或 likelihood 做泛化分析，需要特别谨慎。
  - 证据：[doi:10.1101/2024.01.13.575504, p.6]；[doi:10.1101/2024.01.13.575504, p.17]
- **method：** 以抗体 variable region 的序列或结构作为输入，对每个模型计算 perplexity 或 pseudo-perplexity，再与实验 fitness 做 Pearson、Spearman 和 Kendall tau 相关性分析。
  - 证据：[doi:10.1101/2024.01.13.575504, p.2]；[doi:10.1101/2024.01.13.575504, p.10]；[doi:10.1101/2024.01.13.575504, p.11]
- **method：** 序列模型包含 decoder-only 的 ProGen2、IgLM、ProtGPT2，以及 encoder-only 的 AntiBERTy；结构条件模型包含 ProteinMPNN 与 ESM-IF；此外还计算 Rosetta energy 作为物理/经验 baseline。
  - 证据：[doi:10.1101/2024.01.13.575504, p.2]；[doi:10.1101/2024.01.13.575504, p.10]；[doi:10.1101/2024.01.13.575504, p.11]
- **method：** 对结构条件模型，作者先用 IgFold 预测抗体结构，再进行 inverse folding 或 Rosetta 打分；所有模型均直接使用既有预训练权重，未做额外 fine-tuning。
  - 证据：[doi:10.1101/2024.01.13.575504, p.9]；[doi:10.1101/2024.01.13.575504, p.10]；[doi:10.1101/2024.01.13.575504, p.11]
- **results：** 作者报告 ProGen2-Small 在 7 个数据集上是 top performer，而 ProGen2-Medium、ProGen2-OAS、ESM-IF 和 Rosetta Energy 各在 6 个数据集上并列第二，但没有任何模型能覆盖全部六类性质。
  - 证据：[doi:10.1101/2024.01.13.575504, p.4]；[doi:10.1101/2024.01.13.575504, p.12]
- **results：** 总体上，intrinsic biophysical properties 比 extrinsic properties 更容易被捕捉；作者给出的例子显示 intrinsic 相关性的绝对值平均可超过 0.6，而 binding affinity、expression、immunogenicity 更低。
  - 证据：[doi:10.1101/2024.01.13.575504, p.4]；[doi:10.1101/2024.01.13.575504, p.13]；[doi:10.1101/2024.01.13.575504, p.18]；[doi:10.1101/2024.01.13.575504, p.19]；[doi:10.1101/2024.01.13.575504, p.20]；[doi:10.1101/2024.01.13.575504, p.21]；[doi:10.1101/2024.01.13.575504, p.22]；[doi:10.1101/2024.01.13.575504, p.23]
- **results：** 模型在 intra-family 数据集上通常优于 inter-family 数据集；例如 Hie thermostability 的 intra-family 绝对 PCC 约 0.77，而 Jain/clinical-stage inter-family thermostability 约 0.12。
  - 证据：[doi:10.1101/2024.01.13.575504, p.4]；[doi:10.1101/2024.01.13.575504, p.13]；[doi:10.1101/2024.01.13.575504, p.15]
- **results：** 作者观察到参数规模往往比 architecture 或 pretraining data composition 更影响性能，且较大 ProGen2 在 polyreactivity 与 thermostability 上有更明显提升。
  - 证据：[doi:10.1101/2024.01.13.575504, p.5]；[doi:10.1101/2024.01.13.575504, p.14]
- **results：** sequence-based 方法平均上优于 structure-based 方法，但在 binding affinity 上未加入 antigen 信息，作者因此认为该任务可能被低估。
  - 证据：[doi:10.1101/2024.01.13.575504, p.5]；[doi:10.1101/2024.01.13.575504, p.9]；[doi:10.1101/2024.01.13.575504, p.15]

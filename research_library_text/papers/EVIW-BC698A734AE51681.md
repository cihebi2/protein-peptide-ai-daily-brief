# Assessing the potential of deep learning for protein-ligand docking

- **基础层：** Codex 辅助专家全文审阅

## 作者主张的创新点

作者声称提出了 PoseBench 这一统一基准与工具集，外加新整理的数据集、评测流程和 PLIF-WM 指标，用来系统比较 conventional、DL docking 与 DL cofolding 方法。[doi:10.1038/s42256-025-01160-1, p.1][doi:10.1038/s42256-025-01160-1, p.6][doi:10.1038/s42256-025-01160-1, p.8]

## 创新边界

`新意主要在 benchmark / metric / dataset 设计，不在新的 docking 生成模型本身。`。这不是全球首创性检索或独立复现结论。

## 研究问题

评估现有 deep learning 蛋白-配体 docking / cofolding 方法在真实、未知或多配体场景中的泛化能力，特别是 apo 结构、无已知 binding pocket、以及 multiligand 复合物情况下的结构准确性与化学特异性。[doi:10.1038/s42256-025-01160-1, p.1][doi:10.1038/s42256-025-01160-1, p.2]

## 方法

- 比较多DL/经典docking，按时间/结构/口袋分层和PoseBusters。

## 数据与基准

- PoseBusters/DockGen等。

## 比较基线

- AF3/DiffDock/TankBind等与经典docking。

## 结果证据

- 论文揭示benchmark与OOD差距；为计算评估。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 数据泄漏/已知口袋/pose物理性，benchmark不能替代prospective screen。

## 仍未知

- 不同方法的训练数据、输入特征和推理配置并不完全统一，横向可比性仍有限。
- 冻结证据无法独立复现全部数据预处理、对齐和评分细节。
- CASP15 与 DockGen-E 的样本量和分布都偏窄，因此对真正未见 pocket 的结论更适合作趋势判断。

## Pi 结构化证据摘录

- **baseline：** 作者将 P2Rank+AutoDock Vina 作为 conventional blind baseline，并比较 DiffDock-L、DynamicBind、NeuralPLexer、RFAA、Chai-1、Boltz-1 和 AF3 等 DL 方法。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.8]
- **baseline：** 实验上还保留 single-sequence 版本，并对 AF3 与 Boltz-1 采用截至 2021-09-30 的训练上限来保持时间切分一致性。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.6]；[doi:10.1038/s42256-025-01160-1, p.8]
- **data：** PoseBench 预处理并发布了四个数据集：Astex Diverse (85)、DockGen-E (122)、PoseBusters Benchmark (130/308 子集) 和 CASP15 (19 个复合物、共 102 个 ligand)。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.6]；[doi:10.1038/s42256-025-01160-1, p.7]
- **data：** Astex Diverse 主要来自 2007 年前的 PDB；PoseBusters Benchmark 主要覆盖 2019 年后的条目；DockGen-E 则通过恢复原始 DockGen 的 first bioassembly 得到更具生物学相关性的 122 个复合物。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.6]；[doi:10.1038/s42256-025-01160-1, p.7]
- **data：** CASP15 数据集保留了 2022 年后发布且通过筛选的 19 个 PLI complexes，专门用于检验 multiligand 与 fragment-ligand 场景。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.7]
- **declared_resources：** 作者声明 PoseBench datasets 和 benchmark results 发布于 Zenodo，codebase、documentation 与 tutorial notebooks 发布于 GitHub 与 Zenodo，许可分别为 CC BY 4.0 和 MIT。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.8]；[doi:10.1038/s42256-025-01160-1, p.10]
- **declared_resources：** 论文还声明计算资源来自 NERSC 与 University of Missouri-Columbia 的研究基础设施，并获得 NSF 与 NIH 资助。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.10]
- **limitations：** 作者明确指出，DL 方法在新的或 uncommon PLI pockets 上仍难以同时兼顾 structural accuracy 与 chemical specificity。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.1]；[doi:10.1038/s42256-025-01160-1, p.6]
- **limitations：** 多处分析显示性能与 training-data similarity 相关，因此对真正未见复合物的泛化不能视为稳健已解。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.5]；[doi:10.1038/s42256-025-01160-1, p.14]
- **limitations：** CASP15 样本量较小，且部分结论高度依赖 MSA 输入配置，所以对 multiligand 泛化的判断仍偏趋势性。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.4]；[doi:10.1038/s42256-025-01160-1, p.6]
- **method：** PoseBench 将评测统一拆成 primary ligand blind docking 与 multiligand blind docking，并同时比较 conventional、DL docking 和 DL cofolding 三类方法。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.7]
- **method：** 默认流程是先用 AF3 或 ESMFold 预测 apo protein 结构，再用 PyMOL 按 binding site 做结构对齐，然后评估 ligand pose。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.6]；[doi:10.1038/s42256-025-01160-1, p.7]
- **method：** 作者沿用 r.m.s.d.、lDDT 和 PB-Valid，并新提出 PLIF-EMD 与归一化后的 PLIF-WM 来衡量 interaction fingerprint 的连续匹配程度。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.3]；[doi:10.1038/s42256-025-01160-1, p.7]；[doi:10.1038/s42256-025-01160-1, p.8]
- **results：** 在 Astex Diverse 上，DL cofolding methods 整体优于 conventional P2Rank-Vina，但只有 Chai-1、Boltz-1 与 AF3 同时兼顾较好的结构准确性、化学有效性与 PLIF-WM。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.3]
- **results：** 在 DockGen-E 上，只有最新 DL cofolding methods 能命中相当一部分正确 poses，但 AF3 仍对超过 75% 的 complexes 无法给出结构和化学都合格的预测。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.3]
- **results：** 在 PoseBusters Benchmark 上，Chai-1 和带 MSAs 的 AF3 表现最强；single-sequence AF3 明显退化，而且 prediction accuracy 与 training-set similarity 呈显著相关。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.4]；[doi:10.1038/s42256-025-01160-1, p.5]；[doi:10.1038/s42256-025-01160-1, p.14]
- **results：** 在 CASP15 multiligand 任务上，大多数方法失败；AF3 在有 MSAs 时最好，但结构准确性提升会伴随 chemical specificity 下降。
  - 证据：[doi:10.1038/s42256-025-01160-1, p.4]

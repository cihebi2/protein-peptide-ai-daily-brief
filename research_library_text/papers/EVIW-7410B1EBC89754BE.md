# A Novel Weighted Ensemble Framework of Transformer and Deep Q-Network for ATP-Binding Site Prediction Using Protein Language Model Features

- **论文 ID：** `EVIW-7410B1EBC89754BE`
- **期刊 / 来源：** Int J Mol Sci

- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出了一个结合 ESM-2 特征、local-global Transformer、DQN 与 weighted ensemble 的混合框架，并通过消融、独立测试集、残基组成分析、家族分析和真实蛋白案例展示其性能与生物解释性。

## 创新边界

`新意主要在序列级预测框架与模块组合优化；它不生成候选分子，也没有湿实验验证，且未见独立 prior-art 核验来支持全球新颖性判断。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在蛋白序列信息为主、ATP-binding 位点极度类别不平衡的条件下，提升残基层面 ATP-binding site prediction 的准确性、泛化能力与可解释性，从而支持后续功能注释与设计分析。

## 方法

- ESM-2产生残基嵌入，Transformer同时建模局部和长程上下文；另一分支将残基分类视作序列决策，再加权集成。

## 数据与基准

- 在ATP-41等独立测试集上评价并处理正负位点失衡。

## 比较基线

- ATPbind、SVM集成、单Transformer、单DQN和同质集成。

## 结果证据

- 论文报告ATP-41测试AUC 0.902、MCC 0.642；属于序列位点预测。

## Pi 结构化证据摘录

- **baseline：** 论文将 NsitePred、TargetATPsite、TargetNUC、ATPseq、S-DCNN、Song’s Method、Zhang’s Method 以及单独的 DQN/Transformer 作为主要比较基线。
  - 证据：[doi:10.3390/ijms27073097, p.12]；[doi:10.3390/ijms27073097, p.13]
- **baseline：** 与这些基线相比，作者报告 ensemble 在两套独立测试集上均取得最佳或并列最佳的 AUC 与 MCC。
  - 证据：[doi:10.3390/ijms27073097, p.12]；[doi:10.3390/ijms27073097, p.13]
- **baseline：** 论文也把 local-only、global-only 和 traditional transformer 作为消融/对照基线，用来证明双注意力设计和融合策略的增益。
  - 证据：[doi:10.3390/ijms27073097, p.4]；[doi:10.3390/ijms27073097, p.6]
- **data：** 论文使用经典基准 ATP-227/ATP-17，其中 ATP-227 含 227 条蛋白链、3393 个结合残基和 80,409 个非结合残基，ATP-17 为独立测试集。
  - 证据：[doi:10.3390/ijms27073097, p.18]；[doi:10.3390/ijms27073097, p.19]
- **data：** 论文还使用 ATP-388/ATP-41，其中 ATP-388 作为训练集包含 388 条蛋白链、5657 个结合残基和 142,086 个非结合残基，ATP-41 为独立测试集。
  - 证据：[doi:10.3390/ijms27073097, p.18]；[doi:10.3390/ijms27073097, p.19]
- **data：** ATP-binding 残基的标注标准基于原子距离阈值：任一非氢原子与 ATP 分子原子距离小于 3.9 Å 即定义为结合残基。
  - 证据：[doi:10.3390/ijms27073097, p.18]
- **declared_resources：** 作者在正文和数据可用性声明中给出 GitHub 仓库 https://github.com/tlsjz/ATPbindingEnsemble，声称源码与数据可获得。
  - 证据：[doi:10.3390/ijms27073097, p.3]；[doi:10.3390/ijms27073097, p.25]
- **declared_resources：** 基础表示资源是预训练 protein language model ESM-2，具体采用 esm2_t33_650M_UR50D，33 层、650M 参数、1280 维隐藏状态。
  - 证据：[doi:10.3390/ijms27073097, p.19]
- **declared_resources：** 真实案例可视化使用 PyMOL 3.0.0，属于作者明确点名的分析工具。
  - 证据：[doi:10.3390/ijms27073097, p.17]
- **limitations：** 单独的 local-only 或 global-only 模型都明显弱于 dual-attention 版本，说明仅靠单一局部或全局视角仍会遗漏部分结合信号。
  - 证据：[doi:10.3390/ijms27073097, p.5]；[doi:10.3390/ijms27073097, p.6]
- **limitations：** 作者指出把 DQN 换成更复杂的网络并未带来显著提升，暗示瓶颈更多来自任务本身和奖励建模，而非网络容量。
  - 证据：[doi:10.3390/ijms27073097, p.22]
- **limitations：** kinases 上的性能明显较低，说明对结构异质性更强的家族仍存在泛化瓶颈。
  - 证据：[doi:10.3390/ijms27073097, p.15]；[doi:10.3390/ijms27073097, p.16]
- **limitations：** 论文的后续方向是引入 multi-source features 和 adaptive ensemble strategies，说明当前框架仍有跨家族泛化空间。
  - 证据：[doi:10.3390/ijms27073097, p.25]
- **method：** 先使用 ESM-2 的 esm2_t33_650M_UR50D，把每个氨基酸残基编码为 1280 维深度特征，作为后续分类输入。
  - 证据：[doi:10.3390/ijms27073097, p.19]
- **method：** Transformer 分支采用 local-global dual-attention：global attention 处理整条序列，local attention 以 window size=32 捕捉短程残基相互作用，再用可学习权重融合。
  - 证据：[doi:10.3390/ijms27073097, p.20]
- **method：** Transformer 还加入 contrastive learning branch，并结合 Focal Loss、MCC penalty、Adam、cosine annealing、过采样和轻度增强来应对类别不平衡。
  - 证据：[doi:10.3390/ijms27073097, p.20]
- **method：** DQN 分支把二分类建模成 sequential decision-making，使用 ε-greedy、experience replay、target network 和 reward 机制学习策略。
  - 证据：[doi:10.3390/ijms27073097, p.21]；[doi:10.3390/ijms27073097, p.22]
- **method：** 最终预测通过 weighted ensemble 融合 Transformer 与 DQN 的输出，权重在五折交叉验证中优化确定。
  - 证据：[doi:10.3390/ijms27073097, p.10]；[doi:10.3390/ijms27073097, p.11]；[doi:10.3390/ijms27073097, p.23]
- **results：** 在 ATP-388 五折交叉验证中，Local-Global Transformer 优于 traditional transformer，MCC 从 0.557 提升到 0.585，AUC 从 0.897 提升到 0.917。
  - 证据：[doi:10.3390/ijms27073097, p.4]；[doi:10.3390/ijms27073097, p.6]
- **results：** contrastive learning 使 ATP-41 上的 Transformer 指标提升，MCC 从 0.601 升至 0.625，AUC 从 0.897 升至 0.916。
  - 证据：[doi:10.3390/ijms27073097, p.9]；[doi:10.3390/ijms27073097, p.10]
- **results：** 最终 ensemble 在 ATP-41 上达到 AUC 0.919、MCC 0.656，在 ATP-17 上达到 AUC 0.935、MCC 0.663，均优于单模型。
  - 证据：[doi:10.3390/ijms27073097, p.12]；[doi:10.3390/ijms27073097, p.13]
- **results：** 真实蛋白 5D9H_B 的 case study 中，ensemble 识别出 20 个 TP、2 个 FP 和 2 个 FN，较单模型更贴近已知结合口袋。
  - 证据：[doi:10.3390/ijms27073097, p.17]；[doi:10.3390/ijms27073097, p.18]
- **results：** 家族分析显示 AAA+ ATPases 表现最好（MCC 0.781，AUC 0.949），kinases 最差（MCC 0.412，AUC 0.580），说明泛化性能具有家族依赖性。
  - 证据：[doi:10.3390/ijms27073097, p.15]；[doi:10.3390/ijms27073097, p.16]

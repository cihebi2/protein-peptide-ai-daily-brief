# Structure-based prediction of protein-nucleic acid binding using graph neural networks

- **论文 ID：** `EVIW-778F0D9B754DA725`
- **期刊 / 来源：** Biophys Rev
- **发表时间：** 2024 Jun 26

## 作者主张的创新点

作者提出 PNAbind：把蛋白分子表面离散为 mesh，并用 graph neural network 同时做全局 binding function 分类和局部 binding site 分割；模型还能区分 DNA-binding 与 RNA-binding，并通过 feature/spatial attribution 提供机制解释。

## 创新边界

`创新主要在表面 mesh 表示、多尺度物化/几何特征和可解释 GNN 预测；它不属于 de novo 候选生成、对接或序列优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在缺乏高质量蛋白-核酸复合体结构时，如何仅凭蛋白未结合态或预测结构，准确判断蛋白是否结合 DNA/RNA，并定位核酸结合位点，同时保持可解释性。

## 方法

- 残基/原子图GNN和pooling。

## 数据与基准

- protein-DNA/RNA complexes与negatives。

## 比较基线

- SVM/RF/sequence/structure methods。

## Pi 结构化证据摘录

- **baseline：** 与 PST-PRNA、GraphBind、GraphSite、GeoBind、EquiPNAS、NucleicNet 等近期方法相比，PNAbindA 在多个基准集上取得最高 AUROC/MCC 或接近最好。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.13]
- **baseline：** 作者还把 monomer 作为对照基线；相较之下，包含完整 biological assembly 的输入通常更优。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.13]
- **baseline：** 消融实验显示，去掉 PSSM、HMM、化学、几何或电静力任一组特征都会降低 AUROC，说明全特征集最强。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.14]
- **data：** 分类训练集通过关键词、GO 术语、结构质量阈值和序列聚类，从具有 AlphaFold2 结构的 UniProt 条目中筛得高置信 DBP/RBP/nBP。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.5]；[doi:10.1007/s12551-024-01201-w, p.7]
- **data：** 位点预测基准来自已发表的 PDB 复合体数据集；作者以 biological assembly 作为结构单位，并在训练/测试时屏蔽额外链以公平比较。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.5]；[doi:10.1007/s12551-024-01201-w, p.12]；[doi:10.1007/s12551-024-01201-w, p.13]
- **data：** APOBEC3G 案例使用 Macaca mulatta 全长 A3G 二聚体/单体结构（PDB 6P3X、6P3Y、6P3Z）以及 Yang et al. 的突变和 RNA 结合实验数据。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.15]
- **declared_resources：** 论文声明 PNAbind 的 data、source code 和 documentation 已公开在 Zenodo 与 GitHub。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.16]
- **limitations：** 位点标签训练仍依赖实验复合体结构，目前没有可靠替代方案；因此高精度位点预测仍受结构标签稀缺限制。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.16]
- **limitations：** AF2 unbound 与实验 bound 结构之间存在序列/构象差异，作者也指出实验结构中的改造会带来少量映射偏差。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.14]
- **limitations：** 负对照只覆盖“已知无 NA 结合功能”的蛋白，仍不能完全穷尽真实的非结合蛋白空间。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.14]
- **method：** 将蛋白结构用 NanoShaper 转成 solvent-excluded molecular surface mesh，并补全缺失原子后把化学、几何、电静力和序列 profile 特征映射到 vertex/edge 上。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.3]；[doi:10.1007/s12551-024-01201-w, p.4]；[doi:10.1007/s12551-024-01201-w, p.6]
- **method：** 分类与分割都采用 graph U-Net 风格 GNN：使用 crystal-graph convolution、farthest-point sampling pooling、KNN unpooling 和 global attention pooling；训练用 ADAM 与五折交叉验证。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.4]；[doi:10.1007/s12551-024-01201-w, p.5]；[doi:10.1007/s12551-024-01201-w, p.6]
- **method：** 分类数据集来自 Swiss-Prot/UniProt/AlphaFold2 过滤构建的 DnP-6784、RnP-6046、RDP-6046；分割数据集使用 DNA-573、DNA-181、DNA-129、RBP09、RBP61、RNA-495、RNA-117 及负对照 nBP。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.5]；[doi:10.1007/s12551-024-01201-w, p.6]；[doi:10.1007/s12551-024-01201-w, p.7]
- **method：** 解释阶段用 feature permutation 评估特征组重要性，并用 Grad-CAM 做空间归因，把高归因区域与已知 binding site 对照。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.10]；[doi:10.1007/s12551-024-01201-w, p.11]
- **results：** 在 AF2 结构的分类任务中，DnP-6784、RnP-6046、RDP-6046 的 AUROC 分别为 0.943、0.945、0.920，AUPRC 分别为 0.940、0.935、0.899。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.9]
- **results：** 特征归因显示：DBP/RBP 区分中 HB、AF、EP 重要；DNA vs RNA 区分中几何特征，尤其 HKS 和 edge features，更关键。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.10]；[doi:10.1007/s12551-024-01201-w, p.11]
- **results：** 位点预测在四个测试集上 PNAbindA 的 AUROC 为 0.916–0.953，且在 RBP61、RNA-117、DNA-129、DNA-181 上总体优于或不劣于近期方法。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.13]
- **results：** full biological assembly 的位点预测优于 monomer；bound/unbound（AF2）预测 AUROC 的整体 Pearson 相关系数为 0.76，负对照的 false positive rate 更低。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.13]；[doi:10.1007/s12551-024-01201-w, p.14]
- **results：** APOBEC3G 案例中，模型给出跨 CD1-CD1 二聚化界面的 RNA 结合区域，并与实验突变和 RNA 依赖二聚化结论相符。
  - 证据：[doi:10.1007/s12551-024-01201-w, p.15]

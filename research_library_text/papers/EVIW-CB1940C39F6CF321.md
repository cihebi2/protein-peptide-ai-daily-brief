# Sample efficient reinforcement learning with active learning for molecular design

- **论文 ID：** `EVIW-CB1940C39F6CF321`
- **期刊 / 来源：** Chem Sci
- **发表时间：** 2024 Feb 8
- **DOI：** [10.1039/d3sc04653b](https://doi.org/10.1039/d3sc04653b)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 RL-AL 双循环框架、加权 wDAP 更新和 probabilistic MPO acquisition，并在 ROCS 与 AutoDock Vina 上报告显著的 oracle-call efficiency 提升。

## 创新边界

`新意主要集中在 RL 与 AL 的闭环耦合、加权 RL 更新和 MPO 概率化 acquisition；证据仅限于 in silico oracle 评测，未验证真实实验新颖性。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在分子生成 RL 中用 AL 降低昂贵 oracle 调用，同时保持 hit 丰度、化学多样性与 MPO 质量。

## 方法

- RL生成、定期oracle标签、surrogate/acquisition更新，MPO避免只优化代理。

## 数据与基准

- 10万REINVENT分子、COX2 shape/pharmacophore与结构oracle。

## 比较基线

- baseline REINVENT RL和不同acquisition。

## 结果证据

- 固定预算hit提升5–66倍，达到固定hits时间降低4–64倍；为计算oracle。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- surrogate exploitation/score bias；无实验。

## 仍未知

- 对真实合成/生物测定的外部有效性未知
- 对更大或不同化学空间的泛化能力未知
- MPO acquisition 在其他项目上的稳定收益未知

## Pi 结构化证据摘录

- **baseline：** 论文的 brute-force 基线是对 100000 分子库直接打分，ROCS 仅得到 30 个 unique Murcko scaffolds，而 docking 得到 364 个。
  - 证据：[doi:10.1039/d3sc04653b, p.2]
- **baseline：** 与 VS-AL 和 baseline RL 相比，作者把 RL-AL 视为提高 oracle-call efficiency 的核心对照对象，并以 equal-weights 更新作为关键对照。
  - 证据：[doi:10.1039/d3sc04653b, p.3]；[doi:10.1039/d3sc04653b, p.4]；[doi:10.1039/d3sc04653b, p.5]
- **baseline：** random acquisition 被明确作为 AL 基线，而在 zero-weight 设定下它等价于不使用 AL。
  - 证据：[doi:10.1039/d3sc04653b, p.6]；[doi:10.1039/d3sc04653b, p.12]
- **data：** 主评测库来自 REINVENT prior 采样的 100000 个分子，prior 训练目标是模仿 ChEMBL。
  - 证据：[doi:10.1039/d3sc04653b, p.2]；[doi:10.1039/d3sc04653b, p.10]
- **data：** 两类 oracle 分别是针对 COX2 的 ROCS 查询（SC-558, PDB 1CX2）和针对 RXRa 的 AutoDock Vina docking（PDB 7B88）。
  - 证据：[doi:10.1039/d3sc04653b, p.2]；[doi:10.1039/d3sc04653b, p.10]
- **data：** 主实验通常采用 batch size 256、Nacquired=128、triplicate 运行，并启用 diversity filter 与 experience replay。
  - 证据：[doi:10.1039/d3sc04653b, p.3]；[doi:10.1039/d3sc04653b, p.8]；[doi:10.1039/d3sc04653b, p.10]
- **data：** hit 的判定基于相对 native ligand 的阈值：ROCS combo score 0.6，以及 docking affinity -11.4 kcal mol^-1。
  - 证据：[doi:10.1039/d3sc04653b, p.2]；[doi:10.1039/d3sc04653b, p.10]
- **declared_resources：** 作者在 Data availability 中声明，RL-AL 代码已公开到 GitHub，且复现实验所需输入与数据文件收录于 ESI。
  - 证据：[doi:10.1039/d3sc04653b, p.12]
- **declared_resources：** 方法部分明确依赖 REINVENT、RDKit、OpenEye ROCS/OMEGA、AutoDock Vina 与 Icolos 等组件。
  - 证据：[doi:10.1039/d3sc04653b, p.10]；[doi:10.1039/d3sc04653b, p.11]
- **limitations：** 作者自己强调，研究只按 reward function 的效率评估生成模型，合成可行性与最终化学质量仍然关键但没有被充分解决。
  - 证据：[doi:10.1039/d3sc04653b, p.1]；[doi:10.1039/d3sc04653b, p.9]
- **limitations：** 性能对 surrogate 噪声和 RL/AL 超参数非常敏感；如果把 surrogate 预测直接用于 RL 更新，效果会明显变差。
  - 证据：[doi:10.1039/d3sc04653b, p.3]；[doi:10.1039/d3sc04653b, p.4]
- **limitations：** ADV 体现出与其他 MPO component 的竞争关系，因此提高单一 oracle score 不一定同步提升整体 MPO score。
  - 证据：[doi:10.1039/d3sc04653b, p.8]；[doi:10.1039/d3sc04653b, p.9]
- **limitations：** 作者也指出，不同 oracle 可能需要 bespoke optimization，当前结果主要覆盖 ROCS 与 docking 两种 in silico 场景。
  - 证据：[doi:10.1039/d3sc04653b, p.9]
- **method：** 系统采用 REINVENT 外层 RL 生成 SMILES，内层 AL 用 surrogate 预测、acquisition 选样、oracle 标注并回传训练的双循环框架。
  - 证据：[doi:10.1039/d3sc04653b, p.10]；[doi:10.1039/d3sc04653b, p.11]
- **method：** 作者引入加权 wDAP loss，用 w(x) 控制 surrogate 预测分子对 RL 更新的贡献，而 oracle 标注分子的权重固定为 1。
  - 证据：[doi:10.1039/d3sc04653b, p.10]；[doi:10.1039/d3sc04653b, p.11]
- **method：** surrogate 采用 random forest，输入为 RDKit physiochemical descriptors，并使用最近 1000 个 oracle 结果的 sliding window 训练池。
  - 证据：[doi:10.1039/d3sc04653b, p.11]
- **method：** acquisition 比较 random、greedy 与 UCB；在 MPO 版本中，作者通过 Monte Carlo 采样把 MPO 视为概率分布并据此做 acquisition。
  - 证据：[doi:10.1039/d3sc04653b, p.11]；[doi:10.1039/d3sc04653b, p.12]
- **results：** VS-AL 相比 brute-force screening 有明显提速：仅用 5000 次 oracle calls 就恢复约 42% 的 ROCS hit SMILES 和 35% 的 docking hit SMILES。
  - 证据：[doi:10.1039/d3sc04653b, p.3]
- **results：** naive RL-AL 只带来有限增益，30 000 次调用后 ROCS 约 134±23 个 hits、dockings 约 48±7 个 hits，明显弱于优化后的配置。
  - 证据：[doi:10.1039/d3sc04653b, p.3]
- **results：** 把 surrogate 预测权重降到 0 后，ROCS hits 从 48±6 提升到 147±14，说明 RL 更依赖高质量 oracle 例子而非 surrogate 预测值。
  - 证据：[doi:10.1039/d3sc04653b, p.4]；[doi:10.1039/d3sc04653b, p.5]
- **results：** 系统性调参后，作者建议 Nloops=2、Nacquired=64、Nbatch=512；更大的 batch 或更小的 Nacquired 都能显著提高 hit 数。
  - 证据：[doi:10.1039/d3sc04653b, p.6]；[doi:10.1039/d3sc04653b, p.7]
- **results：** 优化后的 RL-AL 在 30 000 次调用内把 ROCS 与 docking 的 hit 产量分别提升到约 20-fold 和 66-fold，并显著缩短首次产出 hit 的时间。
  - 证据：[doi:10.1039/d3sc04653b, p.8]
- **results：** MPO acquisition 还能进一步提高整体 MPO score，尤其在 ADV 情形下接近把平均 MPO score 翻倍，但可能以部分 raw hit 密度为代价。
  - 证据：[doi:10.1039/d3sc04653b, p.8]；[doi:10.1039/d3sc04653b, p.9]

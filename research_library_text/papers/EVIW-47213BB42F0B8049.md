# pMHChat, characterizing the interactions between major histocompatibility complex class II molecules and peptides with large language models and deep hypergraph learning

- **论文 ID：** `EVIW-47213BB42F0B8049`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2025 Jul 7
- **DOI：** [10.1093/bib/bbaf321](https://doi.org/10.1093/bib/bbaf321)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 pMHChat，将 fine-tuned LLMs（ESM-MSA-1b、ESM-2）与深度 hypergraph learning 结合，用于 MHC class II–peptide binding reactivity、binding affinity 以及 residue contact profiling。

## 创新边界

`新意主要在 LLM 微调、超图建模与后验解释流程的组合，不体现新的湿实验或新数据生成。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在 MHC class II–peptide 结合数据稀疏且残基级相互作用难以显式建模的条件下，同时预测结合反应性与亲和力，并尽量给出可解释的结合界面信息。

## 方法

- 分别微调MHC pseudo-sequence和peptide LLM，融合顺序编码与HyperConv高阶残基关系，并输出分类、回归和接触图。

## 数据与基准

- BD2016训练/交叉验证与IEDB 2024独立集，另发布模型权重Zenodo。

## 比较基线

- NetMHCIIpan及序列DL/GNN模型与组件消融。

## 结果证据

- 五折中反应性AUROC 0.8744、AUPR 0.8390，亲和力Pearson 0.7311；均为计算预测。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- MHC-II实验数据有限，短肽长度使表示容量匹配受限；接触谱未替代结构实验。

## 仍未知

- 摘要与结果节的 AUPR 记载略不一致，可能是四舍五入或排版问题。
- ESM-2 预测 contact maps 的偏差程度未量化，难以判断其对 hypergraph 的实际影响。
- 未见独立第三方复现或湿实验验证来确认 residue contact profiling 的生物学精度。

## Pi 结构化证据摘录

- **baseline：** BD2016 五折对比基线包括 DeepMHCII、STMHCpan 和 MHCAttnNet。
  - 证据：[doi:10.1093/bib/bbaf321, p.5]
- **baseline：** BD2024 独立测试还比较了 DeepMHCII、STMHCpan、MHCAttnNet、NetMHCIIPan-3.2 和 NetMHCIIPan-4.1。
  - 证据：[doi:10.1093/bib/bbaf321, p.6]
- **baseline：** 消融实验替换了 no fine-tuning、no separate feature encoder、one-hot、CBOW，以及 GCN、GAT、GraphSAGE、GIN 等对照模块。
  - 证据：[doi:10.1093/bib/bbaf321, p.6]；[doi:10.1093/bib/bbaf321, p.7]
- **data：** BD2016 含 134,281 条 MHC class II–peptide affinity 记录，覆盖 36 HLA-DR、27 HLA-DQ、9 HLA-DP 和 8 H-2；reactivity 标签以 log50k 归一化 IC50，阈值 0.426 划分。
  - 证据：[doi:10.1093/bib/bbaf321, p.3]
- **data：** BC2015 包含 51 个带晶体结构注释的 pMHC complexes，可用于 binding core 与 residue-level 分析。
  - 证据：[doi:10.1093/bib/bbaf321, p.3]；[doi:10.1093/bib/bbaf321, p.9]
- **data：** BD2024 为 2024-02-09 的独立测试集，过滤掉 BD2016 重叠后得到 1,893 条 affinity pairs 和 2,885 条 reactivity pairs。
  - 证据：[doi:10.1093/bib/bbaf321, p.3]
- **data：** LOMO 实验从 BD2016 中筛出 61 个 MHC molecules（每个 molecule 需超过 40 个观测且至少 3 条 binding peptides）。
  - 证据：[doi:10.1093/bib/bbaf321, p.6]
- **declared_resources：** fine-tuned model weights are available at Zenodo record 15057065。
  - 证据：[doi:10.1093/bib/bbaf321, p.4]
- **declared_resources：** BD2016 可从 DTU NetMHCIIpan-3.2 页面获取。
  - 证据：[doi:10.1093/bib/bbaf321, p.3]
- **declared_resources：** BD2024 和 BC2015，以及 pMHChat 的 Python scripts，都在 GitHub 仓库链接中公开给出。
  - 证据：[doi:10.1093/bib/bbaf321, p.10]
- **limitations：** 作者承认模型受限于 MHC 覆盖范围，且当前主要面向 MHC class II，并未直接解决 TCR epitope 识别。
  - 证据：[doi:10.1093/bib/bbaf321, p.10]
- **limitations：** ESM-2 预测的 contact maps 可能带偏差，从而影响下游 hypergraph 构造与结果稳定性。
  - 证据：[doi:10.1093/bib/bbaf321, p.10]
- **limitations：** binding core identification 并非显式训练目标，因此相关解释结果仍属于后验分析而非专门监督任务。
  - 证据：[doi:10.1093/bib/bbaf321, p.10]
- **method：** 先在 BD2016 上微调 ESM-MSA-1b 与 ESM-2，解冻末层并接入 MLP，以绑定反应性任务生成 MHC position embeddings、peptide residue embeddings 和 peptide contact map。
  - 证据：[doi:10.1093/bib/bbaf321, p.4]
- **method：** 对 MHC 表征使用 BiLSTM 建模长程依赖；对 peptide 端将 contact map 按 50% ratio 阈值构建 hypergraph，再用 HyperConv 传播高阶残差信息。
  - 证据：[doi:10.1093/bib/bbaf321, p.4]
- **method：** 将更新后的 MHC 与 peptide 表征做 max pooling 和 inner product 融合，再通过 classification/regression MLP heads 输出 binding probability 与 affinity。
  - 证据：[doi:10.1093/bib/bbaf321, p.4]
- **method：** 下游解释结合 ESM-2 attention、GNNExplainer 和长度为 9 的滑窗，定位 peptide binding core 并生成 residue contact profiling。
  - 证据：[doi:10.1093/bib/bbaf321, p.9]
- **results：** BD2016 五折交叉验证中，reactivity 的 AUC 为 0.8744、AUPR 为 0.8380；摘要处另写 0.8390，存在轻微数值不一致。
  - 证据：[doi:10.1093/bib/bbaf321, p.1]；[doi:10.1093/bib/bbaf321, p.5]
- **results：** 同一设置下，binding affinity 预测的 PCC 为 0.7311 ± 0.0028。
  - 证据：[doi:10.1093/bib/bbaf321, p.1]；[doi:10.1093/bib/bbaf321, p.5]
- **results：** BD2024 独立测试上，reactivity 的 AUC 为 0.7676、AUPR 为 0.8752，affinity 结果也优于 DeepMHCII、STMHCpan、MHCAttnNet、NetMHCIIPan-3.2 和 NetMHCIIPan-4.1。
  - 证据：[doi:10.1093/bib/bbaf321, p.6]
- **results：** LOMO 中，pMHChat 的 mean AUC 为 0.8405 ± 0.0770、AUPR 为 0.7644 ± 0.1931、PCC 为 0.5705 ± 0.1604；对 DeepMHCII 在 61 个 molecule 中分别于 55/55/57 个 molecule 上更优。
  - 证据：[doi:10.1093/bib/bbaf321, p.6]
- **results：** 在 BC2015 上，35/51 个 binding cores 被完全命中，另 11 个仅有 1–2 个 residue shift。
  - 证据：[doi:10.1093/bib/bbaf321, p.9]
- **results：** 2Q6W 与 3PDO 的 residue contact profiling 与 PyMOL 中观察到的 hydrogen bonds 和 hydrophobic interactions 大体一致。
  - 证据：[doi:10.1093/bib/bbaf321, p.9]

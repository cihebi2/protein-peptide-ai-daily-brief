## 作者主张的创新点

作者声称提出 HLApollo：一个基于 transformer 的 pan-allelic pMHC-I presentation model，能够同时处理 peptide、MHC-I 序列、flanks 与 source protein/表达特征，并通过 negative-set switching、in-model MA deconvolution 和 OOT 泛化建模来提升预测性能与覆盖度。[doi:10.1038/s41467-024-54887-7, p.1][doi:10.1038/s41467-024-54887-7, p.2][doi:10.1038/s41467-024-54887-7, p.3][doi:10.1038/s41467-024-54887-7, p.4][doi:10.1038/s41467-024-54887-7, p.8][doi:10.1038/s41467-024-54887-7, p.10]

## 创新边界

`创新边界主要在“预测/排序与表征学习”，不是直接生成或优化候选分子；核心贡献是 pMHC-I 呈递预测、MA 去卷积和泛化评估，wet-lab 结果主要用于验证与建库。[doi:10.1038/s41467-024-54887-7, p.1][doi:10.1038/s41467-024-54887-7, p.6][doi:10.1038/s41467-024-54887-7, p.10][doi:10.1038/s41467-024-54887-7, p.12]`。这不是全球首创性检索或独立复现结论。

## 研究问题

在癌症免疫治疗中，需要更准确地预测肽是否会被 MHC-I 呈递，以便筛选个体化新抗原；现有方法在 pan-allelic 泛化、多等位基因(MA)数据去卷积，以及对伪阴性负样本噪声的处理上仍较依赖启发式规则。[doi:10.1038/s41467-024-54887-7, p.1][doi:10.1038/s41467-024-54887-7, p.2]

## 方法

- pan-allele sequence/structure/PLM模型，presentation与immunopeptidome训练。

## 数据与基准

- HLA ligand/affinity与cancer peptide datasets。

## 比较基线

- NetMHCpan/MHCflurry等。

## 结果证据

- 论文报告presentation/target prioritization提升；为计算。

- presentation不等于T-cell immunogenicity，allele/肿瘤偏差。

## Pi 结构化证据摘录

- **baseline：** BM1 的对照包括 BigMHC、Sherpa、MixMHCpred、MHCflurry、NetMHCpanEL、HLAthena、NetMHCpanBA，以及作者自建 FFNN。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.4]
- **baseline：** tissue holdout 比较对象包括 BigMHC EL、Sherpa、MixMHCpred、MHCflurry、NetMHCpanEL、HLAthena、NetMHCpanBA。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.6]
- **baseline：** immunogenicity 比较对象还包括 HLAthena MSiCE、HLAthena MSi、NetMHCpanEL、NetMHCpanBA、MHCNuggets、TransPHLA 等。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.7]
- **baseline：** deconvolution 与 OOT 分析中，作者分别以 SA-only、Sarkizova holdout、MA-only，以及不同 OOT allele 模型作为内部基线。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.6]；[doi:10.1038/s41467-024-54887-7, p.8]；[doi:10.1038/s41467-024-54887-7, p.13]
- **data：** 作者汇总公开 ligandome 与 IEDB，建立了 953,693 个 unique {peptide, genotype} tuples、347 个 HLA-I genotypes、305,646 个 peptides、171 个 alleles，并收集到 43.8% matched RNAseq。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.2]；[doi:10.1038/s41467-024-54887-7, p.10]
- **data：** BM1 作为主基准：从 SA/MA elution data 的 10% holdout 构建测试集，并把测试负样本设为 99:1 或 4999:1 比例，避免 train/test tuple 泄漏。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.2]；[doi:10.1038/s41467-024-54887-7, p.11]
- **data：** BM3、BM4、BM5、BM6、BM7、BM8 分别覆盖 tissue holdout、cancer neoantigen immunogenicity、synthetic MA deconvolution、Sarkizova holdout 与 infectious disease antigen。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.5]；[doi:10.1038/s41467-024-54887-7, p.6]；[doi:10.1038/s41467-024-54887-7, p.7]；[doi:10.1038/s41467-024-54887-7, p.11]；[doi:10.1038/s41467-024-54887-7, p.12]
- **data：** 实验部分还生成了 stable monoallelic cell lines，并在 500 million cells 规模上做 pMHC-I immunoprecipitation 与 Orbitrap LC-MS/MS。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.10]；[doi:10.1038/s41467-024-54887-7, p.11]
- **declared_resources：** Data availability 声称所有 datasets、mhcDB sqlite3 database、merged table 与 source data 都发布在 Zenodo DOI 10.5281/zenodo.7951717；训练与测试集在该仓库 version 2。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.14]
- **declared_resources：** Code availability 提供 GitHub `https://github.com/Genentech/HLApollo` 与 Code Ocean DOI `https://doi.org/10.24433/CO.4653665.v1`，并附可执行示例，但许可限制为内部教学与非商业学术研究。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.14]；[doi:10.1038/s41467-024-54887-7, p.16]
- **declared_resources：** Supplementary information 和 figure source data 也作为随文资源公开，可用于核对图表与基准结果。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.14]；[doi:10.1038/s41467-024-54887-7, p.16]
- **limitations：** 模型参数量较大，且大量参数用于嵌入 MHC pseudosequence；作者自己也指出这可能导致 overfitting，尽管泛化仍然不错。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.9]；[doi:10.1038/s41467-024-54887-7, p.13]
- **limitations：** 作者不做 allele-level % rank normalization，认为 HLA-C 与 HLA-A/B 的生物学呈递差异真实存在；但也承认 antibody pulldown 之类的内在偏差可能仍留在 MA 数据中。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.9]
- **limitations：** 在部分任务上并非最优，例如 infectious disease antigen 上 MixMHCpred 略优于 HLApollo；此外 expression 与 ESMMHC-I 的收益也未表现出协同。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.7]；[doi:10.1038/s41467-024-54887-7, p.10]
- **limitations：** 证据主要来自 retrospective benchmark 与 published datasets，未见前瞻性临床试验或真实部署验证。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.5]；[doi:10.1038/s41467-024-54887-7, p.7]；[doi:10.1038/s41467-024-54887-7, p.10]
- **method：** 构建 mhcDB SQLite 数据库，统一整理 ligandome 与配对 RNAseq，并按样本、基因型、实验和搜索参数做严格元数据追踪。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.1]；[doi:10.1038/s41467-024-54887-7, p.10]；[doi:10.1038/s41467-024-54887-7, p.11]
- **method：** HLApollo 采用 transformer：分别编码 peptide+flanks 与 MHC pseudosequence，再与 BOS token 拼接，经多层 encoder 和 FC 头输出呈递 logit。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.4]；[doi:10.1038/s41467-024-54887-7, p.13]
- **method：** 训练时使用 negative-set switching，每个 epoch 从 500 组互斥负样本中重新采样，以减少伪阴性重复暴露与过拟合。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.3]；[doi:10.1038/s41467-024-54887-7, p.13]
- **method：** 对 MA 数据，模型并不先做独立启发式拆分，而是并行输入所有候选 allele，并用最大似然对应的 allele 参与损失与反向传播，实现端到端去卷积。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.3]；[doi:10.1038/s41467-024-54887-7, p.4]；[doi:10.1038/s41467-024-54887-7, p.13]
- **method：** 在序列特征之外，作者将 gene expression、GO 细胞定位和 ESM1b 生成的 ESMMHC-I 表征接入 logistic regression 或 FFNN 进行扩展；另用 multilinear regression 预测 OOT allele AP 和 genotype coverage。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.5]；[doi:10.1038/s41467-024-54887-7, p.8]；[doi:10.1038/s41467-024-54887-7, p.10]；[doi:10.1038/s41467-024-54887-7, p.14]
- **method：** 方法中还包括作者自建 mono-allelic C1R 细胞系、HLA enrich、LC-MS/MS 与 PEAKS 搜索，用于补充验证和 motif 观察。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.10]；[doi:10.1038/s41467-024-54887-7, p.11]；[doi:10.1038/s41467-024-54887-7, p.12]
- **results：** 在 BM1 上，未集成的 HLApollo AP 为 74.83%，10 模型 ensemble 后达到 78.7%，作者报告比次优模型高 12.65%；自建 FFNN 版本则低 14.5%。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.2]；[doi:10.1038/s41467-024-54887-7, p.4]
- **results：** 加入 gene expression 后，BM2 上 AP 提升 6.03%；在另一负样本增强测试集上，HLApollo + expression 比 HLAthena 高 23.93%。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.2]；[doi:10.1038/s41467-024-54887-7, p.5]
- **results：** 加入 ESMMHC-I 后，在 Schmidt 数据集和 Wells 数据集上分别获得 0.5% 与 2.0% 的 AP 增益，且通常优于 GO 特征。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.5]；[doi:10.1038/s41467-024-54887-7, p.10]
- **results：** 在 tissue holdout 与 cancer neoantigen immunogenicity 评估中，HLApollo 整体优于比较模型，但在 infectious disease antigen 上 MixMHCpred 反而略高于 HLApollo，说明任务边界并非处处占优。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.5]；[doi:10.1038/s41467-024-54887-7, p.7]
- **results：** 在 synthetic MA benchmark 中，MA-only 模型与 SA 模型表现几乎一致，作者称 93.9% 的 allele 被正确指派；对 hard allele B*51:05 仍可达到约 82% AP。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.6]；[doi:10.1038/s41467-024-54887-7, p.8]
- **results：** OOD allele 分析显示 median AP drop 为 9.6%，a priori regression 预测 untrained AP 的 Pearson 相关约 67%，并可把 genotype coverage 增加 791 个 allele。
  - 证据：[doi:10.1038/s41467-024-54887-7, p.8]；[doi:10.1038/s41467-024-54887-7, p.10]

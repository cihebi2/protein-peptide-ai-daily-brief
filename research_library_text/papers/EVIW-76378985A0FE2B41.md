# An Interpretable Multi-Objective Machine Learning Framework for In Silico Prioritization of Anti-Staphylococcus aureus Antimicrobial Peptides

## 作者主张的创新点

提出一个基于 538 维透明特征、同源感知交叉验证、SHAP/k-mer 解释和多目标打分的 in silico 框架，用于优先排序 anti-Staphylococcus aureus antimicrobial peptides，并输出 20 条低预测溶血的优化候选。

## 创新边界

`边界在于解释性与排序流程，不是从头发现全新序列；核心是对已知骨架做优化与筛选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

如何在同源冗余明显、标签噪声较大的文献来源 anti-S. aureus AMP 数据上，构建一个同时兼顾抗菌活性与溶血风险、并能诚实估计泛化能力的可解释候选优先排序框架。

## 方法

- 多个property predictors、Pareto/weighted prioritization与SHAP。

## 数据与基准

- S. aureus AMP/activity datasets。

## 比较基线

- single-objective predictors。

## 结果证据

- 候选为in silico prioritization，无实验。

## Pi 结构化证据摘录

- **baseline：** 作者把随机 5-fold CV 作为常规基线，并证明与同源感知 CV 相比会系统性高估性能，尤其在 potency 分类上更明显。
  - 证据：[doi:10.3390/diagnostics16152430, p.5]
- **baseline：** 线性模型（logistic regression、linear SVM、ridge、linear SVR）整体不如树模型（Random Forest、XGBoost、LightGBM），因此树集成是主要基线赢家。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]；[doi:10.3390/diagnostics16152430, p.5]
- **baseline：** SMOTE 与 class weighting 的表现被作者认为统计上无明显差异，因此最终选择 class weighting 以避免引入合成的生物学上不一定合理的特征向量。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **data：** 最终建模数据集包含 4007 条 S. aureus peptide 记录；potency 分类中有 2278 条 potent 与 515 条 weak，hemolysis 二分类保留 582 条无歧义标签。
  - 证据：[doi:10.3390/diagnostics16152430, p.3]
- **data：** 数据的典型尺度为中位长度 17 aa、中位 MIC 7.07 µM；hemolysis 原始整合集合包含 1273 条 peptide-concentration 记录，但因实验异质性被二值化为 hemolytic 与 non-hemolytic。
  - 证据：[doi:10.3390/diagnostics16152430, p.3]
- **data：** 同源聚类显示数据存在明显冗余：potency 序列由 2793 条压缩为 1264 个簇，hemolysis 序列由 582 条压缩为 297 个簇，MIC 序列由 4007 条压缩为 1683 个簇。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **declared_resources：** Supplementary Materials 明确列出 Table S1–S6 与 Figure S1，覆盖完整候选列表、SHAP 排名、特征名、k-mer 富集、模型诊断、排名敏感性与逐候选 nearest-neighbor 细节。
  - 证据：[doi:10.3390/diagnostics16152430, p.10]
- **declared_resources：** 作者声明 data、models 与 scripts 可在正文与 Supplementary Materials 中获取，且研究未获外部 funding。
  - 证据：[doi:10.3390/diagnostics16152430, p.10]
- **declared_resources：** 实现环境显式给出为 Python 3.11.8、scikit-learn 1.4.1.post1、XGBoost 2.0.3、LightGBM 4.3.0、SHAP 0.45.0、imbalanced-learn 0.12.0、BioPython 1.83 与 UMAP-learn 0.5.5。
  - 证据：[doi:10.3390/diagnostics16152430, p.5]
- **limitations：** 全部结果均为计算分析；未进行 antimicrobial、antibiofilm、cytotoxicity、serum-stability 或 synthesis 实验，因此 20 条候选只是 future testing hypotheses。
  - 证据：[doi:10.3390/diagnostics16152430, p.9]
- **limitations：** 优先候选是已知 scaffold 的优化变体，身份相似度 80%–100%，所以该框架体现的是 lead optimization 而不是 de novo discovery。
  - 证据：[doi:10.3390/diagnostics16152430, p.7]；[doi:10.3390/diagnostics16152430, p.9]
- **limitations：** 候选的近零预测 hemolysis 主要来自筛选条件而非独立安全证据，而且 hemolysis 模型未必能外推到这些 cationic、tryptophan-rich 序列。
  - 证据：[doi:10.3390/diagnostics16152430, p.7]；[doi:10.3390/diagnostics16152430, p.9]
- **limitations：** 模型只训练于 anti-S. aureus activity，没有跨物种信息，因此不能据此证明对其他细菌的选择性；作者也承认 MIC 回归较弱，只能用于排序。
  - 证据：[doi:10.3390/diagnostics16152430, p.9]；[doi:10.3390/diagnostics16152430, p.5]
- **limitations：** 作者为保持可解释性而避免使用 protein-language-model embeddings，但这也以一定 ceiling accuracy 为代价。
  - 证据：[doi:10.3390/diagnostics16152430, p.9]；[doi:10.3390/diagnostics16152430, p.4]
- **method：** 从 dbAMP استخراج anti-staphylococcal AMP 记录，仅保留标准氨基酸且长度 5–50 aa 的序列；对重复序列若 MIC 不同则保留最低 MIC，最终得到 4007 条 distinct S. aureus 序列，且菌株注释只作元数据不作训练标签。
  - 证据：[doi:10.3390/diagnostics16152430, p.3]
- **method：** 构建了 538 维可解释特征表示，包含 AAC、DPC、13 个全局理化描述子以及 105 个 CTD 特征，用于刻画电荷、疏水性、两亲性与局部组成模式。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **method：** 在 potency、MIC、hemolysis 与 NHI 四个端点上比较了 logistic regression、linear SVM、Random Forest、XGBoost、LightGBM 及相应回归器，并在训练折内标准化特征、用 class weighting 处理不平衡。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **method：** 采用两种 5-fold CV：常规随机划分与同源感知划分；后者先以 3-mer overlap-coefficient greedy 聚类，再用 StratifiedGroupKFold/GroupKFold 将整簇分配到单一折，以避免 scaffold 泄漏。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **method：** 用 SHAP、氨基酸组成差异、Fisher-exact k-mer enrichment（k=2/3）和 UMAP 对模型行为进行解释，其中 UMAP 只作为可视化而不作机制或新颖性推断。
  - 证据：[doi:10.3390/diagnostics16152430, p.4]
- **method：** 以独立训练的多头打分而非 multi-task 方式进行多目标优先排序，候选由点突变已知高活性骨架与随机长度匹配采样生成，并用 D(x)=p(potent|x)·(1-p(hemo|x))·exp(-max(0,MIC_pred(x))/4) 排名。
  - 证据：[doi:10.3390/diagnostics16152430, p.5]
- **results：** 在同源感知验证下，potency 分类的 honest 估计约为 Random Forest AUROC 0.705，而随机 CV 为 0.797；hemolysis 分类由 LightGBM 达到 AUROC 0.904，95% CI 为 0.88–0.93，sensitivity 0.79、specificity 0.87。
  - 证据：[doi:10.3390/diagnostics16152430, p.5]
- **results：** MIC 回归仅表现为中等到偏弱的排序信号（同源感知 R2 0.165、Spearman ρ 0.389），NHI 回归更弱（R2 0.239），因此作者明确不把这些输出解释为精确定量预测。
  - 证据：[doi:10.3390/diagnostics16152430, p.5]
- **results：** SHAP 显示 potency 主要受分子量、正电荷、KK/LK 等阳离子二肽以及二级结构/溶剂可及性描述子驱动；hemolysis 主要受总体疏水性和暴露的非极性表面驱动。
  - 证据：[doi:10.3390/diagnostics16152430, p.6]
- **results：** 组成分析与 k-mer 分析进一步支持解释性结论，其中 CYR 是唯一在 Bonferroni 校正后仍显著的 trimer，提示与 cysteine-stabilized motif 相关。
  - 证据：[doi:10.3390/diagnostics16152430, p.6]
- **results：** 从生成候选池中保留了 20 条优先序列；其最近邻身份为 80%–100%，中位数 95%，说明这些更像已知骨架的优化变体而非全新 peptide。
  - 证据：[doi:10.3390/diagnostics16152430, p.7]
- **results：** 多目标排序对评分函数扰动较稳健，改变 MIC 尺度或指数后仍可保留 top-20 中的 16–20 条，且与原始排名的 Spearman ρ 至少为 0.92。
  - 证据：[doi:10.3390/diagnostics16152430, p.7]

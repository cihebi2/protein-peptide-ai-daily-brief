# Protein language models meet reduced amino acid alphabets

- **论文 ID：** `EVIW-6C82FA785A104FF8`
- **期刊 / 来源：** Bioinformatics
- **发表时间：** 2024 Feb 3
- **DOI：** [10.1093/bioinformatics/btae061](https://doi.org/10.1093/bioinformatics/btae061)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型` / `结构预测`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称系统比较了多种 reduced alphabets 对 PLM 预训练、分类/回归下游任务和 ESMFold 结构预测的影响，并进一步提出了基于 PLM 聚类与疏水性的字母表变体 UNIPROT18 和 WASS14。

## 创新边界

`主要新意是把既有 reduced amino acid alphabets 系统性接到 PLM 预训练与 ESMFold 输入端；它更像跨方法比较与经验验证，而不是提出新的基础模型或新的结构预测算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

研究问题是：当蛋白质语言模型使用 reduced amino acid alphabets 进行预训练或推理时，表示学习质量、下游预测性能以及单序列结构预测能力会如何变化。

## 方法

- 按物化性质合并残基，UniRef90上预训练PLM，比较下游与reduced-sequence folding。

## 数据与基准

- UniRef90 76,215,872序列、酶/同源/三个工程集及CASP14。

## 比较基线

- full alphabet PLM与不同reduction schemes。

## 结果证据

- 部分任务改善，但full alphabet大模型保留的细节在工程单点效应中不可替代。

## Pi 结构化证据摘录

- **baseline：** 作者把 ESM-1b 作为 fold/enzyme 对照，把 CARP-640M 作为 FLIP 对照，把原始 UNIPROT20 作为结构预测和表示学习的主要参照。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.3]；[doi:10.1093/bioinformatics/btae061, p.5]
- **baseline：** 结构预测中，UNIPROT20 与各 reduced alphabets 的翻译序列被直接比较，以判断压缩输入是否影响 ESMFold。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.5]；[doi:10.1093/bioinformatics/btae061, p.6]
- **data：** 预训练集为 UniRef90；其中非标准氨基酸 U/O 分别映射为 C/K，B/Z/X 归为 X。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.2]
- **data：** enzyme classification 数据集包含 29,215/2,562/5,651 条训练/验证/测试链，覆盖 384 个酶类；remote homology 数据集包含 16,712 条蛋白和 1,195 个 folds。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.2]
- **data：** protein engineering 评估使用 FLIP 的 GB1、AAV 与 Meltome；CASP14 部分使用 51 个测试目标并去掉 T1044。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.2]
- **declared_resources：** 作者声明 trained models、code 和 data 都可在 GitHub 仓库获得。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.1]；[doi:10.1093/bioinformatics/btae061, p.8]
- **limitations：** 字母表内的突变会被折叠成相同 token，因此 reduced alphabets 无法区分 cluster 内 mutation，对 protein engineering 尤其不利。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.4]
- **limitations：** 过小的字母表会损失 long-range dependencies 与协同进化信息，导致下游性能和 perplexity 同时受损。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.4]；[doi:10.1093/bioinformatics/btae061, p.7]
- **limitations：** ESMFold 的少数增益无法被 MSA depth 或 pseudo-perplexity 单独解释，机制仍不清楚。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.6]；[doi:10.1093/bioinformatics/btae061, p.7]
- **method：** 作者用 masked token prediction 预训练一个 3 层 BiLSTM PLM，并用 attention-pooling 加单隐层 MLP 完成下游分类或回归。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.2]；[doi:10.1093/bioinformatics/btae061, p.3]
- **method：** 预训练语料来自 UniRef90 的 76,215,872 条蛋白序列；训练时使用 10% masking、batch size 1024、Adam，以及约 240k steps。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.2]
- **method：** 作者将多种 reduced alphabets 施加到蛋白序列上，包括 UNIPROT18、WASS14、HSDM17、MMSEQS12、SDM12、GBMR4/7 与 WWMJ5。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.1]；[doi:10.1093/bioinformatics/btae061, p.2]；[doi:10.1093/bioinformatics/btae061, p.3]
- **method：** 在结构预测部分，作者把 CASP14 序列先按字母表压缩，再输入 ESMFold v0（3B 参数），并用 LDDT-Ca 与 pseudo-perplexity 评估效果。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.1]；[doi:10.1093/bioinformatics/btae061, p.5]；[doi:10.1093/bioinformatics/btae061, p.6]；[doi:10.1093/bioinformatics/btae061, p.7]
- **results：** 在 enzyme 和 remote homology 任务上，UNIPROT20 总体最好；HSDM17、MMSEQS12、SDM12 仍接近全字母表，而 GBMR4/7 与 WWMJ5 明显退化。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.3]；[doi:10.1093/bioinformatics/btae061, p.4]
- **results：** 在 FLIP 上，reduced alphabets 并非总是更差；WASS14 在 AAV 的 2/7-versus-many 分裂、MMSEQS12 在 7-versus-many 分裂上超过 UNIPROT20，并与 CARP-640M 形成可比基线。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.5]
- **results：** 在 CASP14 上，ESMFold 使用 reduced sequences 时有 10/50 个目标的 LDDT-Ca 提升，最高可达 19%；而 <10 clusters 的字母表多数目标 LDDT-Ca 低于 50。
  - 证据：[doi:10.1093/bioinformatics/btae061, p.1]；[doi:10.1093/bioinformatics/btae061, p.5]；[doi:10.1093/bioinformatics/btae061, p.6]；[doi:10.1093/bioinformatics/btae061, p.8]

# IDP-LM: Prediction of protein intrinsic disorder and disorder functions based on language models

- **论文 ID：** `EVIW-2DE697E431AB06B3`
- **期刊 / 来源：** PLoS Comput Biol
- **发表时间：** 2023 Nov 22
- **DOI：** [10.1371/journal.pcbi.1011657](https://doi.org/10.1371/journal.pcbi.1011657)
- **范围标签：** `Pi 已解析` / `可迁移方法` / `论文声明资源` / `语言模型`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 IDP-LM，将 ProtBERT、ProtT5 与 disorder-specific 的 IDP-BERT 表征融合，并通过 Bi-LSTM 与迁移学习完成无序区、完全无序蛋白、无序结合位点和四类无序功能预测。

## 创新边界

`创新边界在于蛋白语言模型表征组合与无序专用预训练/迁移；它是性质预测方法，不是候选生成、优化或对接。`。这不是全球首创性检索或独立复现结论。

## 研究问题

基于蛋白序列同时预测 intrinsic disorder 及其常见 disorder functions，以缓解无序区域标注稀缺与功能注释不足。

## 方法

- protein LM embeddings与multi-task site heads。

## 数据与基准

- DisProt/MobiDB function labels。

## 比较基线

- IUPred/NetSurfP/PLM methods。

## Pi 结构化证据摘录

- **baseline：** CAID DisProt 的主要对比方法包括 fIDPnn、fIDPlr、RawMSA、ESpritz-D、DisoMine、SPOT-Disorder2、AUCpreD 等。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.10]
- **baseline：** CAID DisProt-PDB 的强基线包括 SPOT-Disorder2、SPOT-Disorder1、AUCpreD、RawMSA、DISOPRED-3.1 等。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.10]
- **baseline：** DisProt-binding 的比较对象包括 ANCHOR-2、DisoRDPbind-protein、MoRFchibi-light/web、OPAL、DISOPRED-3.1-binding 等。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.12]
- **baseline：** 四类 disorder function 的比较对象主要是 flDPnn、DisoRDPbind、ANCHOR-2、DFLpred 与 fMoRFpred。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.13]
- **data：** 监督训练的无序数据来自 DisProt，去除与独立测试集序列相似度高于 25% 的条目后，得到 412 条训练序列和 90 条验证序列。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.4]
- **data：** 独立测试评估使用 CAID 与 TE176；但正文前文写 TE176，而表 5-8 标注 TE167，存在命名不一致。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.4]；[doi:10.1371/journal.pcbi.1011657, p.13]
- **data：** CAID 评估覆盖 DisProt、DisProt-PDB 与 DisProt-binding 三个子任务。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.9]；[doi:10.1371/journal.pcbi.1011657, p.10]；[doi:10.1371/journal.pcbi.1011657, p.12]
- **declared_resources：** Data Availability Statement 给出 GitHub 源码仓库与 stand-alone package 链接。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.1]；[doi:10.1371/journal.pcbi.1011657, p.14]
- **declared_resources：** IDP-BERT 预训练数据下载页与所有数据集下载链接都指向 http://bliulab.net/IDP_LM/download/。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.4]
- **declared_resources：** 模型实现使用 PyTorch，并在单张 NVIDIA GeForce RTX 3080 GPU（10GB）上训练。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.5]
- **limitations：** 作者明确指出，带功能注释的无序序列数量较少，是 disorder function 预测的关键难点，因此采用 transfer learning。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.6]
- **limitations：** 本文只覆盖四类常见 disorder functions，功能范围仍然有限。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.6]；[doi:10.1371/journal.pcbi.1011657, p.14]
- **limitations：** 正文对 TE176/TE167 的命名不一致，说明冻结稿内部存在一个需要人工复核的文本问题。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.4]；[doi:10.1371/journal.pcbi.1011657, p.13]
- **method：** IDP-BERT 采用 BERT/Transformer 进行 restrictive masked language modeling，重点学习序列头尾常见的无序模式。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.5]
- **method：** IDP-BERT 的预训练语料由 MobiDB 的 68,700 条无序序列与 PDB 的 36,148 条高分辨率全有序序列组成，共 104,848 条。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.4]
- **method：** IDP-LM 将 ProtBERT、ProtT5 和 IDP-BERT 的 residue embeddings 输入三路 Bi-LSTM，并用 GA 学得的权重融合输出。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.5]
- **method：** 作者把已训练的无序预测头迁移到 protein binding、DNA binding、RNA binding 和 flexible linker 四类功能头。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.6]
- **results：** 在 CAID DisProt 上，IDP-LM 达到 AUC 0.833、Fmax 0.516、MCC 0.415、BAC 0.762。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.10]
- **results：** 在 CAID DisProt-PDB 上，IDP-LM 达到 AUC 0.910、Fmax 0.766、MCC 0.662、BAC 0.836，属于顶尖水平但 AUC 略低于 SPOT-Disorder2/1。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.10]
- **results：** 在 fully disordered proteins 识别上，IDP-LM 的 Fmax 0.680、MCC 0.657、BAC 0.851。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.12]
- **results：** 在 DisProt-binding 上，IDP-LM 的 AUC 0.792、Fmax 0.260、MCC 0.239、BAC 0.730。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.12]
- **results：** 在 TE167/TE176 功能评估中，protein binding、DNA binding、RNA binding、flexible linker 的 AUC 分别为 0.824、0.897、0.883、0.748。
  - 证据：[doi:10.1371/journal.pcbi.1011657, p.13]

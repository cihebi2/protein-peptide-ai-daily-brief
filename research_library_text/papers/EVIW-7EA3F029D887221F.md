# Integration of pre-trained protein language models with equivariant graph neural networks for peptide toxicity prediction

- **论文 ID：** `EVIW-7EA3F029D887221F`
- **期刊 / 来源：** BMC Biology（DOI 前缀识别）

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `语言模型` / `图与几何学习`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者提出 StrucToxNet，把 ProtT5 序列嵌入、ESMFold 预测结构、结构图表示、E(3) EGNN 和对比学习组合起来，用于肽毒性二分类，并声称其在独立测试集上优于现有方法。

## 创新边界

`创新点属于毒性属性预测与表示学习，不涉及候选肽生成、优化或湿实验验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

论文聚焦于肽类治疗开发中的毒性筛查问题，目标是在类别不平衡条件下，结合序列与三维结构信息提升毒性肽/非毒性肽判别能力。

## 方法

- ProtT5编码序列，ESMFold产生肽结构并构图，等变GNN提取空间特征后与序列表示联合分类毒性。

## 数据与基准

- 使用肽毒性训练/独立测试集，并与通用蛋白毒性及肽专用模型比较。

## 比较基线

- CSM-Toxin、ToxinPred2、ToxinPred3、ToxIBTL、CAPTP及CNN/LSTM/仅ProtT5消融。

## 结果证据

- 论文报告独立测试集上的balanced accuracy、AUC和整体指标优于五个序列基线；全部为计算分类。

## Pi 结构化证据摘录

- **baseline：** 论文对比的主要方法包括 CSM-Toxin、ToxinPred2、ToxinPred3、ToxIBTL 和 CAPTP。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.3]
- **baseline：** 在 ProtT5 嵌入上还比较了 RF、XGBoost、LightGBM、SVM、CNN 和 LSTM 等传统与神经网络基线。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.4]
- **data：** 训练集包含 1818 个 ToxPs 和 4569 个 non-ToxPs，独立测试集包含 320 个 ToxPs 和 806 个 non-ToxPs。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]
- **data：** 论文明确说明数据源自先前的 CAPTP 工作，因此本研究主要复用既有基准，而非重新构建新实验队列。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]
- **data：** 所有肽的三维结构均由 ESMFold 预测，作者还用 pLDDT 作为结构置信度指标筛除低质量样本。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.5]；[doi:10.1186/s12915-025-02329-1, p.7]
- **declared_resources：** 论文声明数据与代码已发布在 Zenodo 和 GitHub。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.9]
- **declared_resources：** 实现资源包括 PyTorch 2.4.1、PyTorch Geometric 2.6.1 以及 NVIDIA A100 GPU 训练环境。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.7]
- **limitations：** 模型依赖 ESMFold 预测结构，因此对短肽和柔性肽可能更敏感，低置信结构会拖累性能。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.5]；[doi:10.1186/s12915-025-02329-1, p.6]
- **limitations：** 当前框架只覆盖线性肽，未处理环肽和翻译后修饰残基。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]
- **limitations：** 方法只做总体毒性二分类，没有区分溶血性、免疫毒性或神经毒性等具体机制。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]
- **limitations：** 作者也承认模型仍偏黑箱，可解释性不足。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]
- **method：** 模型先将肽序列送入 ProtT5 提取残基级上下文嵌入，再用 ESMFold 预测三维结构并构建残基图，随后用三层 EGNN 联合更新节点表示与坐标。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.2]；[doi:10.1186/s12915-025-02329-1, p.7]；[doi:10.1186/s12915-025-02329-1, p.8]
- **method：** 结构节点特征由二级结构、相对溶剂可及性、局部几何、残基方向、相对序列位置、相对空间位置、虚拟表面积和接触数组成，共 45 维。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.8]
- **method：** 作者使用 CAPTP 论文提供的训练/测试划分，并通过 5-fold cross-validation 搜索超参数；实现基于 PyTorch 2.4.1 与 PyTorch Geometric 2.6.1，在 NVIDIA A100 上训练，最长 200 epochs。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.6]；[doi:10.1186/s12915-025-02329-1, p.7]
- **method：** 为缓解类别不平衡，模型还引入了沿用 CAPTP 框架的对比学习策略。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.7]
- **results：** 在独立测试集上，StrucToxNet 的 BACC/AUC/SN/SP/MCC 分别为 93.18/0.968/91.56/94.79/0.852，优于 CAPTP 的 91.59/0.959/90.63/92.56/0.811。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.3]
- **results：** 与 RF、XGBoost、LightGBM、SVM、CNN、LSTM 等序列基线相比，StrucToxNet 取得最高 BACC 93.18 和 MCC 0.852，且 AUC 保持在 0.968。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.4]
- **results：** 消融实验显示，去掉 PLM 会使 BACC 下降 4.3 个百分点、MCC 下降 9.7 个百分点；去掉结构特征或对比学习也会削弱性能。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.5]
- **results：** 当过滤掉 pLDDT<60 的低置信结构后重新训练，BACC 提升到 94.98%、AUC 提升到 0.977，说明结构质量对结果影响明显。
  - 证据：[doi:10.1186/s12915-025-02329-1, p.5]；[doi:10.1186/s12915-025-02329-1, p.6]

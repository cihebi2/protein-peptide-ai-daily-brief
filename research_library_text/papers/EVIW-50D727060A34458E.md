# Optimizing drug design by merging generative AI with a physics-based active learning framework

- **论文 ID：** `EVIW-50D727060A34458E`

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `扩散/生成`
- **Pi 状态：** 已完成结构化解析

## 作者主张的创新点

作者声称提出了一个把SMILES-VAE嵌入双层active learning的生成式工作流：内层用QED/SA/相似性筛选，外层用Glide、PELE和ABFE逐级回训与排序，并在CDK2和KRAS上产生新骨架与可验证候选。

## 创新边界

`新意主要在双层AL与多级化学/物理oracle的整合；全局 prior art 与可推广性未在本文内独立验证。`。这不是全球首创性检索或独立复现结论。

## 研究问题

现有分子生成模型常在目标结合、合成可及性和泛化能力上受限；作者要构建一个能在低数据或复杂靶点条件下，持续生成、筛选并优化具新骨架且可合成的小分子候选的工作流。

## 方法

- 生成器提出候选，物理simulation/score标注小批，surrogate与acquisition迭代。

## 数据与基准

- 目标特异分子库与物理计算标签。

## 比较基线

- 随机/one-shot generation和无AL。

## 结果证据

- 论文报告更少oracle调用提高目标score；为计算优化。

## 已知限制

- 物理oracle仍近似且昂贵，无合成/活性。

## 仍未知

- KRAS 仅有 ABFE 等 in silico 验证，缺少湿实验确认。
- 本文未独立核查其相对既有 generative active learning / physics-based rescoring 工作的全局新颖性。
- 工作流对阈值设定、目标结构选择和初始特异集质量较敏感。

## Pi 结构化证据摘录

- **baseline：** PELE rescoring 在 CDK2 benchmark 中把与实验亲和力的相关性从 Glide gscore 的0.56提升到0.67。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.11]
- **baseline：** 在 KRAS benchmark 中，PELE BFE 与 ABFE ΔG 的相关系数为0.64，而 Glide gscore 仅为 -0.10。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.11]
- **data：** general training set 包含从 ChEMBL 30 经过 drug-like 过滤得到的247,119条SMILES。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.8]
- **data：** CDK2 initial-specific training set 由1061个不同分子组成，IC50范围为0.2到100 μM，并从 ChEMBL 与 PDBbind 中整理。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.8]
- **data：** KRAS unknown initial-specific training set 由1891个分子构成，来源于对500K Enamine REAL 子集的 Glide HTVS，并带有基本胺和构象/位点约束。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.8]
- **data：** 目标结构筛选先从PDB收集高分辨率晶体结构，再用TMalign、SiteMap和聚类选出 CDK2 与 KRAS G12D 的代表性受体。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.9]
- **declared_resources：** 生成分子及其 docking scores 已公开到 figshare 仓库，PELE、ABFE 和实验结果则放在 Supplementary Data 文档中。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.11]
- **declared_resources：** GM workflow 源代码与分子分析脚本分别公开在 GitHub；前者声明为 academic non-commercial license (CC BY-NC-SA 4.0)。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.11]
- **limitations：** 作者承认嵌套AL与附加建模工具可能传播误差，尽管他们认为该流程可减少假阳性。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.7]
- **limitations：** KRAS 的 known-specific set 过于同质，生成时出现 broken bicycles 或更大环等异常结构，说明低数据/复杂 scaffold 会扭曲生成分布。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.7]
- **limitations：** KRAS 的 Glide protocol 不能像 CDK2 那样做系统比较，因为可用实验数据太少且活性范围太窄。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.10]
- **limitations：** CDK2 中有4个候选虽然理论上可合成，但被判定需要过多合成步骤，说明最终实验推进仍受合成可及性限制。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.7]
- **method：** 生成器是以SMILES one-hot输入的LSTM-VAE，latent space 为128维。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.10]
- **method：** 内层AL循环对生成分子施加QED>0.6、SA<7.0和Tanimoto similarity阈值，并把通过者累积到 temporal-specific set。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.3]；[doi:10.1038/s42004-025-01635-7, p.10]
- **method：** 外层AL循环对 temporal-specific set 做Glide docking；CDK2使用XP Glide加LEU83氢键约束，KRAS使用SP Glide加ASP12与疏水约束。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.10]
- **method：** 候选选择阶段先用更严格的 similarity 与 gscore 过滤，再用PELE rescoring 和 ABFE 进行精细排序与验证。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.5]；[doi:10.1038/s42004-025-01635-7, p.6]；[doi:10.1038/s42004-025-01635-7, p.10]；[doi:10.1038/s42004-025-01635-7, p.11]
- **method：** CDK2 与 KRAS 分别使用不同初始特异集：CDK2 为1061个实验抑制剂；KRAS known set 为73个KRAS G12D分子加13个截短warhead的KRAS G12C分子，unknown set 来自500K Enamine HTVS得到的1891个分子。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.3]；[doi:10.1038/s42004-025-01635-7, p.8]；[doi:10.1038/s42004-025-01635-7, p.9]
- **results：** CDK2 第一轮 outer AL 生成49,796个分子，其中30.3%通过内层阈值，1.8%通过外层阈值；第五轮生成36,465个分子，并扩展到4,627个 gscore 优于 -8.0 kcal·mol−1 的分子。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.4]；[doi:10.1038/s42004-025-01635-7, p.5]
- **results：** CDK2 候选选择后以 gscore≤-10 和 similarity<0.3 留下324个分子，随后挑出10个进入合成与ABFE验证。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.5]；[doi:10.1038/s42004-025-01635-7, p.6]
- **results：** 在9个实际测试的 CDK2 分子中，8个显示体外活性（IC50<50 μM），其中1个达到71 nM；ABFE 与 pIC50 的相关系数为 -0.75，去除两个 analogs 后为 -0.88。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.6]；[doi:10.1038/s42004-025-01635-7, p.7]
- **results：** KRAS unknown 流程生成23,488个 gscore<-8.0 的分子，最终19个进入ABFE，其中4个被预测为 Kd<15 μM；known 与 unknown 两条流程在UMAP上分成两个簇。
  - 证据：[doi:10.1038/s42004-025-01635-7, p.7]；[doi:10.1038/s42004-025-01635-7, p.9]

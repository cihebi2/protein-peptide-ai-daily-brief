# Attention-based approach to predict drug-target interactions across seven target superfamilies

- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

论文声称提出了 MMAtt-DTA：一种基于 attention 的回归框架，结合多类 compound/protein descriptors、LASSO 特征选择和 Transformer encoder，在七个 superfamilies 上同时预测 pChEMBL 与 DTP interaction score，并用于独立验证和 approved drugs 的缺失 bioactivity 补全。[doi:10.1093/bioinformatics/btae496, p.1][doi:10.1093/bioinformatics/btae496, p.3][doi:10.1093/bioinformatics/btae496, p.11]

## 创新边界

`新意主要在于超家族特异的多模态 descriptor + FT-Transformer 式回归 DTI 框架；它是计算预测与排序方法，不是 de novo 生成、对接或实验筛选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：在七个 human target superfamilies 上，利用现有 bioactivity 数据补全和预测 drug-target interactions，以支持 drug repurposing、机制解释和已知药物的靶点谱扩展。[doi:10.1093/bioinformatics/btae496, p.1][doi:10.1093/bioinformatics/btae496, p.2]

## 方法

- 药物与蛋白编码经多模态attention交互，按超家族优化并回归bioactivity。

## 数据与基准

- 六个手工整理DTI数据库、七个超家族和ChEMBL-V33 185,676个非训练bioactivities。

## 比较基线

- 14种ML/DL/图模型，包括MolTrans等。

## 结果证据

- 测试中6/7超家族Spearman>0.72；ChEMBL-V33多数超家族>0.57（P<0.001）。均为回顾性计算验证。

## Pi 结构化证据摘录

- **baseline：** 论文把 MolTrans、DTITR、KronRLS、GraphDTA 及其变体、SimBoost、Sim-CNN-DTA、DeepDTA、DeepCDA 作为 Davis kinase 基准上的主要对照。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.1]；[doi:10.1093/bioinformatics/btae496, p.10]
- **baseline：** 在同一 Davis 切分下，作者认为本方法与 DTITR 表现接近，但在 Spearman correlation 和 concordance index 上优于其余比较方法。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.10]
- **baseline：** 对更近的 2023–2024 方法，作者直接引用文献报告值并声称本方法在 CI 与 RMSE 上更好。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.10]；[doi:10.1093/bioinformatics/btae496, p.11]
- **data：** 训练集由 DTP、ChEMBL 与 PubChem 组合而成，清洗后得到 947,195 条 interaction，覆盖 452,296 个 compounds 和 1,251 个 targets。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.2]
- **data：** 作者把 active 定义为 pChEMBL >5 或 DTP >0，并将 PubChem 标记为 Inactive、pChEMBL ≤5 且 DTP =0 的样本纳入负类。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.2]
- **data：** 独立 validation set 来自 ChEMBL-V33 中训练集未覆盖的条目，最终包含 185,676 条 interaction、119,034 个 compounds 和 1,681 个 targets。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.8]
- **data：** 用于 kinase 基准比较的 Davis 数据集按既定流程筛成 423 个 proteins 和 69 个 compounds，对应 31,824 条 interaction 的比较任务。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.10]
- **data：** 作者还对 3,492 个 approved drugs 和 1,411 个 human targets 做了全矩阵式的缺失 bioactivity 预测。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.11]；[doi:10.1093/bioinformatics/btae496, p.12]
- **declared_resources：** 作者声明代码、训练/测试/验证数据和 user guides 均已放在 GitHub：https://github.com/AronSchulman/MMAtt-DTA。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.11]
- **declared_resources：** 独立验证集被作为 Supplementary File S1 提供，预测得到的 approved-drug × target 结果被整理为 Supplementary File S2。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.8]；[doi:10.1093/bioinformatics/btae496, p.11]
- **declared_resources：** 训练在 4 张 Nvidia Volta V100 GPU 和 40 个 Intel Xeon Gold 6230 CPU 上完成。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.4]
- **declared_resources：** 模型权重以每轮 checkpoint 保存，并保留测试损失最低的 5 个 checkpoint 做 ensemble 推断。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.4]；[doi:10.1093/bioinformatics/btae496, p.8]
- **limitations：** 作者明确指出 test set 同时被用于 hyperparameter tuning，因此测试结果可能偏乐观，尽管后续又做了独立验证。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.8]
- **limitations：** epigenetic regulator 的性能偏低，作者将其归因于训练标签向 inactive 倾斜的分布偏差。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.9]
- **limitations：** 最难的 unseen compound + unseen target 场景在多数 superfamilies 上仍然困难，而且文中也说明 known compounds + unknown proteins 这一情形因数据不足而被省略。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.9]；[doi:10.1093/bioinformatics/btae496, p.10]
- **limitations：** 超参数搜索采用单次 80/20 split 而不是更稳健的交叉验证，作者把原因归结为时间与算力限制。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.6]
- **method：** 作者把数据按七个 target superfamilies 划分，并为每个超家族分别训练 pChEMBL 与 DTP 两套回归模型。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.2]；[doi:10.1093/bioinformatics/btae496, p.3]
- **method：** 输入特征来自九类 descriptor，先用 LASSO 做超家族特异的特征选择，再把维度压到约 1000 维以降低计算量和过拟合风险。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.6]；[doi:10.1093/bioinformatics/btae496, p.7]
- **method：** 模型主体是改造后的 FT-Transformer：连续特征用 periodic activation 加 Linear/ReLU embedding，离散特征用 lookup table，随后通过带 CLS token 的 Transformer encoder 聚合。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.4]
- **method：** 训练采用 log-cosh loss、AdamW、最多 500 epochs 和 early stopping；超参数搜索使用 HEBO 并结合 Hyperband。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.4]；[doi:10.1093/bioinformatics/btae496, p.6]
- **results：** 测试集上，七个 superfamilies 里有六个的 Spearman correlation 超过 0.72，唯独 epigenetic regulator 只有 0.470。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.9]
- **results：** 独立验证中，模型在 bioactivity imputation 和 new compounds 场景总体表现较好，但 new compounds + new targets 场景明显更难。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.9]；[doi:10.1093/bioinformatics/btae496, p.10]
- **results：** 作者报告 kinase 模型在 Davis 基准上与 DTITR 相近，并在 Spearman correlation 和 CI 上优于多数对比方法；对 2023–2024 的更新方法也保持了有竞争力的 CI 与 RMSE。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.10]；[doi:10.1093/bioinformatics/btae496, p.11]
- **results：** 对 3492 个 approved drugs 的推断得到新的、此前未测试的 bioactive interactions，用于补全 3492×1411 的 DTI matrix。
  - 证据：[doi:10.1093/bioinformatics/btae496, p.11]；[doi:10.1093/bioinformatics/btae496, p.12]

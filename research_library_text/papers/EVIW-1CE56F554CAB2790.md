# Barlow Twins deep neural network for advanced 1D drug-target interaction prediction

## 作者主张的创新点

作者提出 BarlowDTI/BarlowDTIXXL：用 Barlow Twins 自监督表示学习提取药物与蛋白特征，再以 XGBoost 作为最终预测器，同时加入 SHAP 与基于样本影响力的解释分析，并提供网页接口。

## 创新边界

`主要创新在序列级 DTI 预测管线、基准比较和解释性分析，不是新湿实验、分子生成或对接算法。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在仅使用 SMILES 和蛋白序列等 1D 输入的条件下，如何更准确、更高效地预测 drug-target interaction，并在数据稀缺的基准与真实应用场景中保持可解释性。

## 方法

- SMILES/protein encoders、Barlow Twins loss与DTI classifier。

## 数据与基准

- 多个DTI benchmark/cold splits。

## 比较基线

- DeepDTA/contrastive models。

## Pi 结构化证据摘录

- **baseline：** 作者新增并强调 XGBoost 作为 DTI baseline，输入为 ECFP 与 PLM embedding 的拼接，在多个数据集上表现具竞争力。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.7]；[doi:10.1186/s13321-025-00952-2, p.12]
- **baseline：** 对比基线覆盖 Kang et al., MolTrans, DLM-DTI, ConPLex, DrugBAN, PSICHIC, STAMP-DPI 等方法，并使用 Welch t-test 加 Benjamini-Hochberg 进行显著性比较。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.4]；[doi:10.1186/s13321-025-00952-2, p.5]
- **baseline：** 论文还把未使用 Barlow Twins 或未做超参优化的管线作为消融基线，用于检验核心模块带来的增益。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.7]
- **data：** 分类基准包括 BioSNAP、BindingDB、DAVIS 和 Human，均使用预定义 split；回归基准为 PDBBind v2016 与 v2020。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.4]；[doi:10.1186/s13321-025-00952-2, p.10]
- **data：** 所有 SMILES 经 ChEMBL curation pipeline 清洗，重复项和无法解析的错误分子/蛋白信息被移除。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.10]
- **data：** BarlowDTI 的预训练联合数据来自 BioSNAP、BindingDB、DAVIS 和 DrugBank，作者移除了重复项并使用 15% validation split。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.11]
- **data：** BarlowDTIXXL 进一步整合 Golts 等的大型 curated DTI 数据与三套训练 split，最终形成 3,653,631 对样本。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.12]
- **data：** 案例研究使用了 PDB 中的 5T8U、8CRI、8CRL 结构，并结合 Dienemann 等报告的 ITC 数据来分析 affinity 与预测概率的对应关系。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.8]；[doi:10.1186/s13321-025-00952-2, p.9]
- **declared_resources：** 作者声明代码、BarlowDTIXXL 训练数据和 benchmark 数据都已放在 GitHub，并提供了可自由访问的 web interface。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.12]；[doi:10.1186/s13321-025-00952-2, p.13]
- **declared_resources：** 实现与分析依赖 PyTorch、XGBoost、Optuna、TreeExplainer、BLASTP、PyMOL 和 RoseTTAFold-AllAtom 等工具。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.11]；[doi:10.1186/s13321-025-00952-2, p.12]
- **declared_resources：** 作者披露的计算资源包括 AMD Ryzen Threadripper PRO 5995WX、1024GB RAM 和 NVIDIA RTX 4090 GPU。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.13]
- **limitations：** 作者明确指出，DTI 任务受限于数据稀缺；BarlowDTIXXL 之所以面向真实场景，是因为它需要 360 多万对样本来训练。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.3]；[doi:10.1186/s13321-025-00952-2, p.12]
- **limitations：** 作者也提到，在 DAVIS 上优化后的 GBM 可能存在对 test set 过拟合的风险。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.7]
- **limitations：** 证据边界主要来自静态 benchmark、结构案例和 in silico screening；冻结文本中没有新的湿实验结果。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.8]；[doi:10.1186/s13321-025-00952-2, p.9]；[doi:10.1186/s13321-025-00952-2, p.10]
- **method：** 将分子 SMILES 转为 ECFP，并将蛋白序列用 ProtTrans、ProtT5、ProstT5 等 PLM 编码；作者也评估了 one-hot 表示。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.10]；[doi:10.1186/s13321-025-00952-2, p.11]
- **method：** 采用双编码器加共享 projector 的 Barlow Twins 架构，通过 cross-correlation loss 同时约束表示不变性与去冗余。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.11]
- **method：** 先在联合 DTI 数据上预训练，再抽取两种模态的 embedding 并拼接，最后训练 XGBoost GBM 作为预测器。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.11]；[doi:10.1186/s13321-025-00952-2, p.12]
- **method：** 分类任务用 Optuna 以 ROC AUC 与 PR AUC 的组合为目标做超参搜索，回归任务则以 -ρ 与 MAE 作为验证目标。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.11]
- **method：** 解释性分析中，作者用 TreeExplainer 计算 SHAP 值，并用 GBM 叶节点索引的 Jaccard 相似度寻找最有影响力的训练样本。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.12]
- **results：** 在四个分类基准上，BarlowDTI 的总体表现优于所有对比模型；作者报告 BioSNAP 上相对 DLM-DTI 的 PR AUC 提升约 6%，BindingDB 上超过 14%，DAVIS 上相对 ConPLex 提升约 21%。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.5]；[doi:10.1186/s13321-025-00952-2, p.6]
- **results：** 在 Koh splits 上，BarlowDTI 在 BioSNAP 的 unseen protein 与 random、BindingDB 的 unseen ligand 与 unseen protein、Human 的 unseen protein 与 random 中表现领先或次优。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.5]；[doi:10.1186/s13321-025-00952-2, p.6]
- **results：** 回归任务上，BarlowDTI 在 PDBBind v2016 排名第三、在 v2020 排名第二；作者也指出 XGBoost baseline 同样具有竞争力。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.6]
- **results：** 消融实验证明，去掉超参数优化、去掉 Barlow Twins、以及两者同时去掉都会显著降低性能，说明各组件都对最终结果有贡献。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.7]
- **results：** BarlowDTIXXL 的预测与 ITC 测量呈相关，并能捕捉甲基化导致的 interaction likelihood 下降；在虚拟筛选中也能优先筛出 kinase inhibitors。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.8]
- **results：** 影响力分析显示，LIPT1 是 lplA1 与 LipL1 的最有影响力训练样本之一，且活性位点残基替换会引起预测显著变化，支持其识别 ligand-binding residues 的能力。
  - 证据：[doi:10.1186/s13321-025-00952-2, p.8]；[doi:10.1186/s13321-025-00952-2, p.10]

# De Novo Antimicrobial Peptide Design with Feedback Generative Adversarial Networks

- **论文 ID：** `EVIW-9D1944506B9DAEA2`
- **期刊 / 来源：** Int J Mol Sci
- **发表时间：** 2024 May 18

- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源` / `肽与抗菌肽` / `扩散/生成`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

作者提出基于 k-mers 和 ESM2-t12 的两个 AMP 分类器，并将其嵌入 FBGAN，形成 FBGAN-kmers 与 FBGAN-ESM2；作者声称这能优于原始 FBGAN，并与 AMPGAN、HydrAMP 竞争。

## 创新边界

`创新边界主要是分类器替换与反馈集成，而不是新的 GAN 训练目标；作者自称 k-mers 首次用于 DNA 序列 AMP 分类，但该首创性未被独立核验。`。这不是全球首创性检索或独立复现结论。

## 研究问题

研究反馈式 GAN 框架中分类器质量是否会显著影响 AMP de novo 设计的生成质量、统计逼近度与外部 AMP 命中率。

## 方法

- 在反馈 GAN 训练中用改进分类器对生成候选评分并回灌；以分类准确率、precision、recall、F1，以及生成集合的唯一性、相似性、组成分布和多个外部分类器得分评估。

## 数据与基准

- 使用公开 AMP/非 AMP 序列数据训练分类器与生成模型；正文指出数据规模相对模型容量偏小，并用多个外部分类型作交叉评估。

## 比较基线

- 原始 FBGAN 为直接基线，生成对比包括 AMPGAN 与 HydrAMP；外部评估使用 RF、SVM 和 ANN 分类器。

## 结果证据

- ESM2 分类器报告 accuracy 91.5%、F1 91.6%，相对原 FBGAN 分类器约提高 10 个百分点；生成评估中 FBGAN-ESM2 的三外部分类器平均阳性比例约 57.8%，与 AMPGAN 58.3% 接近且方差更小，优于 HydrAMP 48.1%。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 所有生成质量仍主要由预测器判定，外部分类型本身 accuracy 约 82.2%–86.5% 并含偏差；大模型配置出现过拟合迹象；缺少湿实验确认，因此不能把分类为 AMP 当作真实效力。

## 仍未知

- 未见湿实验或真实杀菌活性验证。
- GitHub 仓库虽在文中给出，但本冻结任务未直接检视仓库内容。
- CAMPR4、AMPGAN、HydrAMP 的比较依赖作者选取的公开序列和筛选规则。

## Pi 结构化证据摘录

- **baseline：** 原始 FBGAN 是主要基线；为公平比较，作者把 Gupta and Zou 的代码和本工作所有模型重跑 20 次，而不是只沿用单次结果。
  - 证据：[doi:10.3390/ijms25105506, p.15]
- **baseline：** 生成基线包括 AMPGAN（bidirectional conditional GAN）和 HydrAMP（conditional VAE）；外部评估基线来自 CAMPR4 的 RF、SVM 和 ANN。
  - 证据：[doi:10.3390/ijms25105506, p.3]；[doi:10.3390/ijms25105506, p.17]
- **baseline：** 论文将 vanilla WGAN 作为历史参照，说明 FBGAN 属于 WGAN-GP 加 feedback 机制的延伸，但当前对照重点仍是 AMP 生成模型之间的比较。
  - 证据：[doi:10.3390/ijms25105506, p.15]；[doi:10.3390/ijms25105506, p.16]
- **data：** AMP classification dataset 含 5200 条序列，其中 2600 条来自 APD3 的 AMP，2600 条来自 UniProt 的随机蛋白；GAN dataset 含 3655 条 UniProt 蛋白，长度 5-50 aa 且序列相似性大于 0.5。
  - 证据：[doi:10.3390/ijms25105506, p.10]
- **data：** 作者将氨基酸序列转换为互补 DNA 序列，并统一 padding 到 156；分类器实验重复 20 次，生成器比较时每个模型随机抽取 5000 条长度小于 50 aa 的序列。
  - 证据：[doi:10.3390/ijms25105506, p.10]；[doi:10.3390/ijms25105506, p.15]；[doi:10.3390/ijms25105506, p.17]
- **data：** 与 HydrAMP 的比较使用了其作者公开的 unconstrained simulation 生成序列，并且本文不对这些生成肽再做额外生物过滤。
  - 证据：[doi:10.3390/ijms25105506, p.17]
- **declared_resources：** 实现使用 PyTorch，并在配备 NVIDIA Quadro P4000 的 desktop computer 上训练/测试；分类器和 GAN 的关键超参数均有明确设定。
  - 证据：[doi:10.3390/ijms25105506, p.13]；[doi:10.3390/ijms25105506, p.16]
- **declared_resources：** 作者声明数据和 software 托管在 GitHub：https://github.com/aretiz/de_novo_design_GAN.git；并使用 ESM2-t12 与 CAMPR4 作为外部资源。
  - 证据：[doi:10.3390/ijms25105506, p.14]；[doi:10.3390/ijms25105506, p.18]
- **declared_resources：** 经费来自 TITAN ERA Chair project 和 HFRI Ph.D. Fellowship。
  - 证据：[doi:10.3390/ijms25105506, p.18]
- **limitations：** 作者承认 k=5 可能因参数量过大而 overfitting，且不同运行之间波动更大，因此更大 k 并不必然更好。
  - 证据：[doi:10.3390/ijms25105506, p.4]；[doi:10.3390/ijms25105506, p.14]
- **limitations：** CAMPR4 的 RF/SVM/ANN 对真实 AMP 的准确率只有 86.5/84.1/82.2%，作者也明确提示外部分类器偏差会影响结论。
  - 证据：[doi:10.3390/ijms25105506, p.7]
- **limitations：** FBGAN 的 classifier 并未进入正式优化目标，本文也把将 classifier 影响显式纳入 loss 作为 future work。
  - 证据：[doi:10.3390/ijms25105506, p.15]；[doi:10.3390/ijms25105506, p.17]
- **limitations：** 冻结材料中的证据主要是 in silico 评估与数据库/平台验证，未给出湿实验抗菌活性结果。
  - 证据：[doi:10.3390/ijms25105506, p.6]；[doi:10.3390/ijms25105506, p.7]；[doi:10.3390/ijms25105506, p.18]
- **method：** 先在与 Gupta and Zou 相同的数据设置上训练 AMP 分类器，并用 60/20/20 的 stratified 划分重复 20 次，比较原始 FBGAN classifier、k-mers 与 ESM2 方案。
  - 证据：[doi:10.3390/ijms25105506, p.10]；[doi:10.3390/ijms25105506, p.15]
- **method：** k-mers 方案把 DNA 序列切成 2-5-mer，构建 4^k 字典后进行 one-hot encoding 和 zero padding，再用 GRU+Dense 做分类。
  - 证据：[doi:10.3390/ijms25105506, p.11]；[doi:10.3390/ijms25105506, p.12]；[doi:10.3390/ijms25105506, p.13]
- **method：** ESM2 方案使用 ESM2-t12 生成蛋白序列 embedding，再用两层 MLP 分类；作者选择 t12 是为了在参数量与算力之间折中。
  - 证据：[doi:10.3390/ijms25105506, p.12]；[doi:10.3390/ijms25105506, p.14]
- **method：** FBGAN 训练采用 WGAN-GP 和 feedback loop；每轮采样 960 条序列，由外部分类器筛选 P(AMP)≥0.8 的样本回流到判别器数据集。
  - 证据：[doi:10.3390/ijms25105506, p.15]；[doi:10.3390/ijms25105506, p.16]
- **method：** 生成评估包括每个模型 5000 条样本、normalized edit distance、Needleman-Wunsch 相似性、KLD、CAMPR4 外部验证以及 charge/pI/aromaticity/hydrophobicity 分析。
  - 证据：[doi:10.3390/ijms25105506, p.6]；[doi:10.3390/ijms25105506, p.7]；[doi:10.3390/ijms25105506, p.8]；[doi:10.3390/ijms25105506, p.9]；[doi:10.3390/ijms25105506, p.16]；[doi:10.3390/ijms25105506, p.17]
- **results：** 分类器准确率从 FBGAN 的 81.4% 提升到 k=2/3/4 的 85.7/85.6/85.3%，ESM2 达到 91.5%；作者最终选 k=4 作为后续 FBGAN 组件。
  - 证据：[doi:10.3390/ijms25105506, p.4]；[doi:10.3390/ijms25105506, p.5]
- **results：** FBGAN-kmers 与 FBGAN-ESM2 在 edit distance 上优于 FBGAN 和 HydrAMP，且 FBGAN-ESM2 对真实数据分布的贴近度最好。
  - 证据：[doi:10.3390/ijms25105506, p.6]；[doi:10.3390/ijms25105506, p.9]
- **results：** CAMPR4 平均 AMP 命中率为 FBGAN 32.6%、FBGAN-kmers 55.1%、FBGAN-ESM2 57.8%、AMPGAN 58.3%、HydrAMP 48.1%；AMPGAN 在 RF 最强，而 FBGAN-ESM2 在 SVM/ANN 更稳。
  - 证据：[doi:10.3390/ijms25105506, p.7]
- **results：** KLD 显示 FBGAN-ESM2 为 0.061、FBGAN 为 0.065、FBGAN-kmers 为 0.068，均明显低于 AMPGAN 的 0.24 和 HydrAMP 的 0.21；FBGAN-ESM2 也呈现更高 charge。
  - 证据：[doi:10.3390/ijms25105506, p.8]；[doi:10.3390/ijms25105506, p.9]
- **results：** 作者总体结论是更强的分类器会实质提升 FBGAN 生成质量，且 FBGAN-ESM2 在多数指标上优于 HydrAMP，并接近 AMPGAN。
  - 证据：[doi:10.3390/ijms25105506, p.9]；[doi:10.3390/ijms25105506, p.10]；[doi:10.3390/ijms25105506, p.17]

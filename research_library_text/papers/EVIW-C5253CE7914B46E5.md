## 作者主张的创新点

作者声称，基于 LASSO 的 feature selection 可以从 propy、tripeptide composition 和 N-gram 特征中筛出最关键的 TCR-peptide 判别信号；在 2B4、226、5cc7 三个数据集上，这种做法既提升了分类表现，也给出了可解释的 motif 线索。

## 创新边界

`新意主要在现有序列特征的筛选与解释，不是新的 wet-lab 平台，也不是生成或优化新的 peptide 候选。`。这不是全球首创性检索或独立复现结论。

## 研究问题

作者要解决的是：在特定 TCR 场景下，如何仅用 peptide 序列与理化特征更准确地区分 strong binders 与 weak binders，并从中找出真正有判别力的短 motif。

## 方法

- sequence/physicochemical/embedding特征选择与ML分类。

## 数据与基准

- TCR-peptide/pMHC interaction datasets。

## 比较基线

- 传统ML/无筛选。

## Pi 结构化证据摘录

- **baseline：** 分类基线是使用 LASSO 选中特征后的 Logistic Regression，并以 10-fold cross-validation 和 80/20 train/test split 报告指标。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.9]
- **baseline：** 对照方法还包括 RACER：作者用它来设定阈值、做位点级能量验证，并将自己的 sequence-only 结果与其 hybrid sequence+structure 思路比较。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.3]；[doi:10.3389/fimmu.2024.1510435, p.10]
- **data：** 数据来自 yeast-displayed peptide-MHC libraries，覆盖 2B4、226 和 5cc7 三个 murine TCR 系统；peptide 长度固定为 13 aa，并经过 five rounds of selection 与 deep sequencing。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.3]
- **data：** 作者依据 post-selection enrichment score 与 read counts，把 peptide 分成 strong binders 和 weak binders，并用 RACER 导出的阈值进行分割。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.3]
- **data：** 论文的 Data availability statement 给出了两个 GitHub 资源：RACER/raw_data 以及作者自己的 Feature_Selection_TCR-Specific_Interaction 仓库。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.12]
- **declared_resources：** 作者声明可用数据与资源见 GitHub：RACER/raw_data 以及 Feature_Selection_TCR-Specific_Interaction。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.12]
- **limitations：** 作者明确承认，纯 sequence-driven 方法可能漏掉罕见或非典型 motif，并且在极端 cross-reactivity 场景下会受限。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.12]
- **limitations：** 论文指出，结果来自相对有限的一组 TCR-peptide 交互，因此对更广泛 TCR 的泛化性仍不确定。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.12]
- **limitations：** 作者还承认当前模型没有充分处理 MHC residue 或 MHC polymorphism 的影响，这部分被留作未来的 hybrid model 扩展。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.12]
- **method：** 作者先从三组 murine TCR 数据中抽取 peptide 序列特征，覆盖 propy 的理化属性、tripeptide composition，以及 N-gram 的 unigram/bigram/trigram 表示。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.3]；[doi:10.3389/fimmu.2024.1510435, p.4]；[doi:10.3389/fimmu.2024.1510435, p.5]
- **method：** 为避免信息泄漏，归一化是在训练/测试切分之后进行；随后作者用 LASSO 和交叉验证选择正则强度，并把系数压到 0 的特征视为无关或冗余。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.5]；[doi:10.3389/fimmu.2024.1510435, p.6]
- **method：** 作者用 RACER 生成 Z-score 阈值来划分 strong/weak binders，再对 weak binders 做 controlled undersampling，最后用 StratifiedShuffleSplit 下的 Logistic Regression 评估分类性能。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.3]；[doi:10.3389/fimmu.2024.1510435, p.9]
- **method：** 作者还把筛出的 dipeptide 和 tripeptide motif 送入 RACER 的 in silico mutation 分析，以检查位点级 binding energy 变化并生成 heatmap。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.10]；[doi:10.3389/fimmu.2024.1510435, p.11]
- **results：** LASSO 在不同特征族中反复选出重叠 motif：2B4 里主要是 AF、FF、TK、LK；226 里是 TK、FF、AF、ATK、AFF、FFK；5cc7 里是 PY、FL、FK、FR、VAF、LKA、FLK。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.6]；[doi:10.3389/fimmu.2024.1510435, p.8]；[doi:10.3389/fimmu.2024.1510435, p.9]
- **results：** Logistic Regression 的结果显示：2B4 达到 0.94–0.96 accuracy 和最高 0.98 AUC；226 为 0.73–0.77 accuracy、0.66–0.78 AUC；5cc7 为 0.82–0.85 accuracy、0.83–0.87 AUC。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.9]
- **results：** 作者报告这些 motif 与 RACER 的能量分析和实验位点偏好一致，尤其 2B4 中的 AFF 等 motif 在位点级 mutation 下表现出更有利的预测 binding energy。
  - 证据：[doi:10.3389/fimmu.2024.1510435, p.10]；[doi:10.3389/fimmu.2024.1510435, p.11]

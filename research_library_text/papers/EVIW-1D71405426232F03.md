## 作者主张的创新点

作者构建了一个基于 transgenic rabbits 免疫与 NGS 数据的 neural network，可从 VH 序列预测 polyspecificity，并通过特征重要性分析解释哪些位置与理化属性最相关。

## 创新边界

`新意主要在序列级预测框架、实验数据构建与可解释分析，不在候选分子的直接生成或优化。`。这不是全球首创性检索或独立复现结论。

## 研究问题

从 antibody heavy-chain variable region (VH) 序列中预测 polyspecificity，并识别与该性质相关的关键理化特征。

## 方法

- CDR/sequence descriptors与ML分类/回归。

## 数据与基准

- antibody polyspecificity assays。

## 比较基线

- rule-based/传统models。

## 结果证据

- 论文报告预测能力；为回顾性模型。

## Pi 结构化证据摘录

- **baseline：** 在 class imbalance 条件下，模型的 F1 约为 0.042（random split）和 0.031（random subsampling），高于随机分类器预期的 0.017 和 0.013。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.14]
- **data：** 作者在 3 个免疫原、每组 3 只兔子、4 个 post-immunization time points 的设计下，累计得到约 5200 万条 unique VH sequences，并将 preimmune / bleed0 以及跨组共享序列作为 holdout。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.8]
- **data：** 监督训练集中约 1500 万条序列被归为 antigen-specific，约 13.4 万条被归为 polyspecific，显示出严重的 class imbalance。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.8]
- **data：** 作者还使用了已发表外部数据集（Jain et al., 2017；Shehata et al., 2019）来检验预测分数与实验理化性质及 maturation stage 的关联，并公开了数据编号 PRJNA1052988。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.10]；[doi:10.3389/fbinf.2023.1286883, p.11]；[doi:10.3389/fbinf.2023.1286883, p.15]
- **declared_resources：** 公开数据已提交到 NCBI BioProject: PRJNA1052988。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.15]
- **declared_resources：** 实验平台使用了 Roche proprietary transgenic rabbits expressing a humanized antibody repertoire and common human light chain。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.3]；[doi:10.3389/fbinf.2023.1286883, p.8]
- **declared_resources：** 计算流程声明使用了 FastQC、FLASH、UMAP、Keras/TensorFlow 等工具栈。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.5]；[doi:10.3389/fbinf.2023.1286883, p.6]
- **limitations：** 随机划分的 cross-validation 可能高估泛化能力，因此作者同时报告了按 animal / antigen 分块的更严格结果，而这些结果明显更低。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]；[doi:10.3389/fbinf.2023.1286883, p.12]
- **limitations：** 独立的 bleed 3 验证集非常小，只有 HSA 和 TNFα 各 4 个 polyspecific 克隆、TWEAK 为 0，作者明确指出该集合不足以可靠评估模型。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]
- **limitations：** polyantigen assay 可能只覆盖 polyspecificity 的部分机制，而且结果会受抗原组合、cutoff 和环境条件影响，因而难以给出 universal prediction。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.14]
- **limitations：** 模型只使用 VH 序列，且 bulk sequencing 不能直接配对 VH/VL，因此 light-chain 影响并未被单独建模。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.8]；[doi:10.3389/fbinf.2023.1286883, p.12]
- **method：** 使用 Roche proprietary transgenic rabbits（共用 human light chain）对 HSA、TNFα、TWEAK 各进行 3 只兔子的免疫，并在免疫后对 antigen 与 polyantigen mix 进行 panning，以标注 antigen-specific 与 polyspecific 克隆。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.3]；[doi:10.3389/fbinf.2023.1286883, p.8]
- **method：** 对 MiSeq paired-end reads 做 FastQC 质控与 FLASH 合并，再用 WolfGuy numbering 对 VH 区域对齐并提取固定长度的序列表示。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.5]
- **method：** 用 aaindex1 的理化指标经 PCA 压缩，取前 6 个 principal components 作为每个位点编码，形成 882 维输入；神经网络采用 3 层全连接隐藏层（6/3/2 单元）+ batch normalization + ELU + dropout 0.5。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.5]；[doi:10.3389/fbinf.2023.1286883, p.6]
- **method：** 训练时使用 binary cross-entropy、Adam、learning rate 6×10^-7、batch size 128 和 balanced minibatch sampling；变量重要性用 permutation-based dropout loss ratio，并回溯到原始 physico-chemical features。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.6]；[doi:10.3389/fbinf.2023.1286883, p.9]
- **results：** 随机 10-fold cross-validation 的 AUROC 为 0.800（SD 0.005），10 次 repeated subsampling 的 AUROC 为 0.792（SD 0.010）。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]
- **results：** 更严格的 blocked cross-validation 仍高于随机，但性能下降：按 animal 划分 AUROC 0.668，按 antigen 划分 AUROC 0.634。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]
- **results：** 在 bleed 3 的独立筛选集中，模型在 HSA 组对已标记 polyspecific 克隆给出更高概率，但 TNFα 组未再现这一趋势；作者也指出该集合过小，难以稳健评估。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]
- **results：** 特征重要性主要集中在 Framework3，其次是 CDR3；回溯分析显示 accessible surface area、flexibility indices 和 average weighted degree 等属性较重要。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.9]；[doi:10.3389/fbinf.2023.1286883, p.10]
- **results：** 在外部数据集中，hydrophobicity 与预测的 polyspecificity 总体呈负相关，而 affinity matured clones 的预测 polyspecificity 低于 naive/early clones。
  - 证据：[doi:10.3389/fbinf.2023.1286883, p.10]；[doi:10.3389/fbinf.2023.1286883, p.11]

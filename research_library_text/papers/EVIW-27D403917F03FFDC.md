# Investigating the volume and diversity of data needed for generalizable antibody–antigen ΔΔG prediction

- **论文 ID：** `EVIW-27D403917F03FFDC`
- **期刊 / 来源：** Nat Comput Sci
- **发表时间：** 2025 Jul 8
- **DOI：** [10.1038/s43588-025-00823-8](https://doi.org/10.1038/s43588-025-00823-8)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 Graphinity 这一基于结构的 equivariant graph neural network，并用 AB-Bind、SKEMPI 2.0 及大规模 FoldX/Flex ddG synthetic datasets 系统分析 antibody–antigen ΔΔG 预测的数据需求与泛化边界。

## 创新边界

`主要创新在于结构驱动的 ΔΔG 预测框架与数据需求分析；它不直接生成或优化候选抗体/抗原序列，因此属于 transfer 而非 core。`。这不是全球首创性检索或独立复现结论。

## 研究问题

评估是否能够对 antibody–antigen 结合 ΔΔG 做出可泛化、可稳健的预测，并量化实现这种预测所需的数据规模、数据多样性与噪声容忍度。

## 方法

- 将野生型与突变体抗体–抗原复合物表示为三维图，使用等变图神经网络回归 ΔΔG；采用按 CDR/抗原相似性聚类的严格拆分，并与 FoldX、Flex ddG、DGCddG、RDE-PPI 等比较。

## 数据与基准

- Synthetic_FoldX_ΔΔG_942723 含 942,723 个突变、1,471 个复合物；Synthetic_FlexddG_ΔΔG_20829 含 20,829 个突变、1,302 个复合物；另整理 Experimental_ΔΔG_608。

## 比较基线

- 主要基线包括 FoldX、Rosetta Flex ddG、DGCddG、RDE-PPI 及结构知情的树模型；论文特别强调相似性隔离后的公平比较。

## 结果证据

- 宽松实验拆分下测试 Pearson 最高可达 0.87，但论文同时显示性能不稳健于更严格 train–test 截断；作者结论是现有实验数据不足，可能需要多数量级更多且更具多样性的数据。Flex ddG 在 Experimental_ΔΔG_608 上 Pearson 0.46，FoldX 为 0.20。

## 可用资源与代码关系

- 论文中声明存在资源，但尚未建立与论文身份精确匹配的静态审计仓库。

## 已知限制

- 少量实验点导致过拟合；SKEMPI 派生数据存在复合物类型、重复和突变分布偏斜问题；合成标签受 FoldX/Flex ddG 本身近似误差限制，不能替代实验真值。

## 仍未知

- 真实 experimental ΔΔG 的最优数据量是否会因 assay 类型、抗原家族和测量噪声而显著变化，文中无法最终确定。
- Graphinity 是否能在前瞻性、外部独立数据上稳定指导 antibody design，冻结证据未直接证明。
- synthetic 与 experimental 分布差异的精确影响幅度仍不明确。

## Pi 结构化证据摘录

- **baseline：** 作者指出，先前方法在小型实验集上随机划分时可报到约 0.76 的相关性，但一旦引入更严格的 train-test cutoff，性能会明显塌缩。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]；[doi:10.1038/s43588-025-00823-8, p.7]
- **baseline：** 在 synthetic FoldX 数据上，简单的 contact-count baseline 只有 0.42，而 Graphinity/Equiformer 分别达到 0.87/0.89。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]
- **baseline：** 重训后的 DGCddG 和 RDE-PPI Network 在 Experimental_ΔΔG_645 的 90% CDR cutoff 下分别只有 0.26 和 0.22，明显低于 Graphinity。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]
- **baseline：** 在 trastuzumab 任务上，作者的 Graphinity 表现接近先前的 sequence-based CNN（ROC AUC 0.91、AP 0.83），说明该任务本身可由较简单基线较强地解决。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.5]
- **data：** AB-Bind 数据集包含 645 个单点突变，来自 29 个 complexes；作者还报告了 27 个 non-binder 以及若干重复/非 antibody-antigen 条目带来的局限。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.7]
- **data：** 过滤后的 Experimental_ΔΔG_608 包含 608 个单点突变，来自 44 个 complexes。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.7]
- **data：** Synthetic_FoldX_ΔΔG_942723 覆盖 1,471 个 complexes、1,409 个 PDBs；Synthetic_FlexddG_ΔΔG_20829 覆盖 1,302 个 complexes。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.8]
- **data：** trastuzumab 数据集包含 36,391 个 CDRH3 variants，其中 11,277 个标注为 binding，且突变位点集中在 10 个 amino acid positions。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.10]
- **declared_resources：** 作者声明代码与 synthetic datasets 公开在 GitHub 与 Zenodo；Graphinity code 可通过 GitHub 和 Zenodo 获取，数据也通过 GitHub/Zenodo 与项目下载页提供。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.11]
- **declared_resources：** 实现与训练依赖 Python、PyTorch、PyTorch Geometric、FoldX 5、Rosetta 2020.08+、ANARCI、CD-HIT、ESM2、BLAST 与 HHblits；训练硬件包括 NVIDIA RTX 6000 和 A100 80GB。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.8]；[doi:10.1038/s43588-025-00823-8, p.9]；[doi:10.1038/s43588-025-00823-8, p.10]；[doi:10.1038/s43588-025-00823-8, p.11]
- **limitations：** 作者明确认为，小型 experimental ΔΔG 数据上的高分数主要来自 overfitting，而不是稳健泛化。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]；[doi:10.1038/s43588-025-00823-8, p.7]
- **limitations：** synthetic FoldX/Flex ddG 数据来自同一套软件，因而更 self-consistent、噪声更低；因此由它推导出的数据规模结论只能视为 lower bound。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.7]
- **limitations：** 实验数据本身仍然稀缺、噪声较大，且在 substitution type 上明显偏斜；作者也承认 exact required dataset size 取决于 dataset diversity 与 ML method。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.5]；[doi:10.1038/s43588-025-00823-8, p.7]
- **limitations：** 作者没有展示新的 wet-lab 实验来前瞻性验证 Graphinity 的候选设计能力，且 modeled structure 输入的表现很差。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.3]；[doi:10.1038/s43588-025-00823-8, p.11]
- **method：** Graphinity 将 WT 与 mutant antibody–antigen 复合物转成原子级图，使用 3 层 E(n) EGC/EGNN，对两者嵌入做差后回归 ΔΔG。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]；[doi:10.1038/s43588-025-00823-8, p.9]
- **method：** 实验数据方面，作者以 AB-Bind 的 645 个单点突变为起点，并额外构建了基于 SKEMPI 2.0 过滤后的 Experimental_ΔΔG_608 基准集。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.7]
- **method：** 大规模 synthetic 数据由 SAbDab 结构出发，通过 FoldX exhaustive interface mutagenesis 生成 942,723 个突变，并用 Rosetta Flex ddG 生成 20,829 个突变。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.8]
- **method：** 作者用 CDR/antigen sequence identity cutoff、数据规模扫描、diversity 扫描与 label noise 扫描来评估泛化，并与 Equiformer、FLAML、CNN、DGCddG、RDE-PPI 等方法比较。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.8]；[doi:10.1038/s43588-025-00823-8, p.9]；[doi:10.1038/s43588-025-00823-8, p.10]
- **results：** 在 Experimental_ΔΔG_645 上，随机划分时 Graphinity 的 Pearson correlation 最高可达 0.87，但在严格 CDR identity cutoff 下平均下降约 63%。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]
- **results：** 在 Synthetic_FoldX_ΔΔG_942723 上，Graphinity 在 90% length-matched CDR cutoff 的 10-fold CV 中达到 0.89；当训练数据至少约 90,000 条时，test Pearson correlation 才开始接近 0.85。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.2]；[doi:10.1038/s43588-025-00823-8, p.4]
- **results：** 数据多样性显著影响 predictiveness：最小 sequence diversity 和 substitution type diversity 的模型，其 standard deviation ratio 分别比对应最大多样性设置低 23% 和 60%。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.5]
- **results：** 在 trastuzumab variants 上，Graphinity 达到 ROC AUC 0.90、AP 0.82；在 modeled structure inputs 上则几乎失效，Pearson correlation 仅 0.02。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.5]；[doi:10.1038/s43588-025-00823-8, p.3]
- **results：** 对训练/验证标签做 0–60% shuffling 时，Pearson correlation 仍大致维持在 0.85 左右；加入 Gaussian noise 也显示出一定鲁棒性。
  - 证据：[doi:10.1038/s43588-025-00823-8, p.5]；[doi:10.1038/s43588-025-00823-8, p.6]

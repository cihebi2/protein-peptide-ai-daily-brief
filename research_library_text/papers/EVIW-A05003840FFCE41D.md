# EGPDI: identifying protein-DNA binding sites based on multi-view graph embedding fusion

- **论文 ID：** `EVIW-A05003840FFCE41D`
- **期刊 / 来源：** Brief Bioinform
- **发表时间：** 2024 Jul 8
- **DOI：** [10.1093/bib/bbae330](https://doi.org/10.1093/bib/bbae330)
- **范围标签：** `Pi 已解析` / `核心相关` / `论文声明资源`
- **基础层：** Codex 辅助专家全文审阅
- **增强层：** Pi 证据解析已完成

## 作者主张的创新点

提出 EGPDI，将蛋白–DNA binding site 预测建模为图节点分类；融合手工特征与 protein language model embeddings，并通过 GCNII 与 EGNN 双路编码后，用 gated multi-head attention 进行多视图图表示融合。

## 创新边界

`作者自述这是首次将 multi-view graph embedding fusion 用于 protein–DNA binding site prediction；这一“首次”仅来自论文内陈述，未做外部 prior-art 核验。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在已知蛋白序列与三维结构信息的条件下，准确识别蛋白上哪些残基属于 DNA binding site，并验证模型在独立测试集上的泛化能力。

## 方法

- 把蛋白残基构成图节点，分别学习等变几何和深层图卷积表示，再进行注意力融合与节点分类。[doi:10.1093/bib/bbae330, p.2][doi:10.1093/bib/bbae330, p.3]

## 数据与基准

- 使用三个公开基准和独立测试集，论文报告五折交叉验证及独立评估。[doi:10.1093/bib/bbae330, p.2]

## 比较基线

- 既有模板、机器学习、混合结构方法及EGPDI消融变体。[doi:10.1093/bib/bbae330, p.2][doi:10.1093/bib/bbae330, p.7]

## 结果证据

- 论文报告在关键指标上优于比较方法；属于结合位点预测，未等同实验DNA结合验证。[doi:10.1093/bib/bbae330, p.1][doi:10.1093/bib/bbae330, p.7]

## Pi 结构化证据摘录

- **baseline：** 外部比较基线包括 COACH-D、NucBind、GraphSite、GLMSite 和 EquiPNAS，用于检验 EGPDI 的相对性能。
  - 证据：[doi:10.1093/bib/bbae330, p.7]
- **baseline：** 消融比较还使用 BiLSTM、EGNN & BiLSTM、GCNII & BiLSTM 三个变体，以分离序列分支与图分支的贡献。
  - 证据：[doi:10.1093/bib/bbae330, p.5]；[doi:10.1093/bib/bbae330, p.7]
- **data：** 训练集为 DNA_573_Train（573 proteins），测试集为 DNA_129_Test（129 proteins），独立测试集为 DNA_181_Test（181 proteins），分别来自 GraphBind 与 GraphSite。
  - 证据：[doi:10.1093/bib/bbae330, p.2]
- **data：** 数据划分经过 CD-HIT 过滤，确保训练集内部以及训练/测试之间不存在超过 30% sequence identity 的冗余蛋白。
  - 证据：[doi:10.1093/bib/bbae330, p.2]
- **data：** 正样本定义为 DNA 分子与目标残基之间的最小原子距离小于 0.5 Å；节点特征总维度被整理为 6524 维。
  - 证据：[doi:10.1093/bib/bbae330, p.2]；[doi:10.1093/bib/bbae330, p.3]
- **declared_resources：** 论文声明 datasets、precomputed features 与 source code 可在 GitHub repository https://github.com/HaaZheng/EGPDI 获取。
  - 证据：[doi:10.1093/bib/bbae330, p.1]；[doi:10.1093/bib/bbae330, p.9]
- **declared_resources：** 论文使用公开 benchmark datasets（GraphBind 与 GraphSite 来源）并给出对应的数据可用性说明，强调其资源可复用性。
  - 证据：[doi:10.1093/bib/bbae330, p.2]；[doi:10.1093/bib/bbae330, p.9]
- **limitations：** 论文明确指出方法受 AlphaFold2 预测结构质量影响，不过作者认为加入手工特征与 pLMs embeddings 后这一影响已有所缓解。
  - 证据：[doi:10.1093/bib/bbae330, p.8]
- **limitations：** 当前只使用 scalar edge features，作者认为这不足以完整描述蛋白分子的复杂几何性质，计划未来加入 vector-based edge features。
  - 证据：[doi:10.1093/bib/bbae330, p.8]
- **limitations：** 模型尚未纳入 DNA structural information，作者将其列为后续工作方向。
  - 证据：[doi:10.1093/bib/bbae330, p.8]
- **method：** 将每个蛋白序列转为图节点分类问题，残基作为节点；节点特征融合 PSSM、HMM、one-hot、AF、SS、MSA、ESM-2 和 ProtTrans，边则按 17 Å 距离阈值构图，并额外使用欧氏距离与夹角余弦作为边特征。
  - 证据：[doi:10.1093/bib/bbae330, p.2]；[doi:10.1093/bib/bbae330, p.3]；[doi:10.1093/bib/bbae330, p.4]
- **method：** GCNII 分支用于提取局部信息，论文实现为 4 层、hidden dimension 128，并通过 initial residual connections 与 identity mapping 缓解 over-smoothing。
  - 证据：[doi:10.1093/bib/bbae330, p.3]；[doi:10.1093/bib/bbae330, p.4]
- **method：** EGNN 分支用于提取全局信息，论文实现为 2 层、hidden dimension 512，并在 EGCL 中加入 initial residual connection 和 identity mapping 以保留原始特征。
  - 证据：[doi:10.1093/bib/bbae330, p.3]；[doi:10.1093/bib/bbae330, p.4]
- **method：** 两路图嵌入先经 16-head attention，再通过 8 个独立 gated multi-head attention 模块融合，最后送入 MLP 输出 binding-site 概率。
  - 证据：[doi:10.1093/bib/bbae330, p.5]
- **results：** 在训练集五折交叉验证中，融合特征优于单独的 handcrafted features 和 pLMs features，作者报告 MCC、AUC、AUPR 都进一步提升。
  - 证据：[doi:10.1093/bib/bbae330, p.6]
- **results：** 在训练集上，EGPDI 相比单独的 GCNII 或 EGNN 分支取得更好的整体表现，论文报告其 MCC 为 0.637、AUC 为 0.956、AUPR 为 0.690。
  - 证据：[doi:10.1093/bib/bbae330, p.6]
- **results：** 在 DNA_129_Test 上，EGPDI 达到 Specificity 0.961、Recall 0.612、Precision 0.503、F1 0.549、AUC 0.941、MCC 0.522。
  - 证据：[doi:10.1093/bib/bbae330, p.7]
- **results：** 在 DNA_181_Test 上，EGPDI 达到 Specificity 0.952、Recall 0.558、Precision 0.346、F1 0.424、AUC 0.914、MCC 0.407。
  - 证据：[doi:10.1093/bib/bbae330, p.7]
- **results：** 与 COACH-D、NucBind、GraphSite、GLMSite 和 EquiPNAS 比较时，EGPDI 在两个测试集上的 F1、AUC 和 MCC 都是最优或并列最优。
  - 证据：[doi:10.1093/bib/bbae330, p.7]
- **results：** case study 中，EGPDI 在 6g1t_A 与 6fwr_A 上分别比 EquiPNAS 多预测 6 个和 68 个真实 binding residues。
  - 证据：[doi:10.1093/bib/bbae330, p.8]

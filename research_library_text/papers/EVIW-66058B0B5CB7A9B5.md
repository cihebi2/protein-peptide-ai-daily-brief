## 作者主张的创新点

提出 ECEP：在 TurNuP 风格的 kcat 预测流程上加入 ESM 序列表示、反应指纹特征、CNN/XGBoost 双路线建模，以及加权均值集成，以提升预测精度并优于 TurNuP 与 DLKcat。

## 创新边界

`创新主要停留在 kcat 回归预测层面的特征工程、模型组合与加权集成；未涉及湿实验、候选生成或新的生物机制发现。`。这不是全球首创性检索或独立复现结论。

## 研究问题

在实验 kcat 数据稀缺、噪声较大且来源分散的情况下，如何仅凭酶序列与化学反应信息更准确地回归预测 enzyme catalytic efficiency / kcat。

## Pi 结构化证据摘录

- **baseline：** 核心基线是 TurNuP 和 DLKcat，文中以 R2、MSE 与 Pearson coefficient 进行并列比较。
  - 证据：[doi:10.3389/frai.2024.1446063, p.8]；[doi:10.3389/frai.2024.1446063, p.13]
- **baseline：** 方法上还特意把 TurNuP 的简单均值集成当作对照，强调本研究改用 weighted mean。
  - 证据：[doi:10.3389/frai.2024.1446063, p.2]；[doi:10.3389/frai.2024.1446063, p.7]
- **data：** kcat 数据整合自 BRENDA、UniProt、Sabio-RK，并声称公开存放于 Zenodo。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]
- **data：** 作者给出的样本划分为训练集 3,391 条、测试集 874 条。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]
- **data：** 预处理包括按 EC 号和 protein identifier 对齐、去除缺失/重复/异常值，以及 Z-score 归一化。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]
- **data：** 论文明确把原始序列、反应信息和预训练蛋白表示都作为输入特征来源。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]；[doi:10.3389/frai.2024.1446063, p.5]
- **declared_resources：** 论文在 data availability 中直接给出 GitHub 仓库 https://github.com/misharisaud/ECEP 用于代码与结果生成。
  - 证据：[doi:10.3389/frai.2024.1446063, p.13]
- **declared_resources：** 作者同时提供高质量图件的 figshare 链接，并声明数据集来源于 BRENDA、UniProt 与 Sabio-RK。
  - 证据：[doi:10.3389/frai.2024.1446063, p.13]；[doi:10.3389/frai.2024.1446063, p.4]
- **declared_resources：** 文中还把 Zenodo 作为数据集公开存放位置。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]
- **limitations：** 作者指出酶动力学数据稀疏且噪声大，BRENDA 记录与原始论文之间可出现约 20% 偏差。
  - 证据：[doi:10.3389/frai.2024.1446063, p.10]
- **limitations：** 深度学习与超参数优化的计算开销较高，尤其在大数据集上会限制实际部署。
  - 证据：[doi:10.3389/frai.2024.1446063, p.9]；[doi:10.3389/frai.2024.1446063, p.10]
- **limitations：** 文中把 future work 指向更多数据、特征工程和高性能计算，说明当前模型在可扩展性上仍有限。
  - 证据：[doi:10.3389/frai.2024.1446063, p.9]；[doi:10.3389/frai.2024.1446063, p.10]
- **method：** 作者将 ECEP 设为以 kcat 回归为核心的监督学习任务，主干由 XGBoost 与 CNN 两类模型组成。
  - 证据：[doi:10.3389/frai.2024.1446063, p.1]；[doi:10.3389/frai.2024.1446063, p.6]；[doi:10.3389/frai.2024.1446063, p.7]
- **method：** 序列侧使用 ESM-1b 与其 fine-tuned 版本 ESM_1b_ts 生成 1,280 维表示，并与反应指纹拼接。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]；[doi:10.3389/frai.2024.1446063, p.5]
- **method：** 反应侧构造 structural、differential 和 difference fingerprint，其中前两者长度分别为 4,096 与 2,048。
  - 证据：[doi:10.3389/frai.2024.1446063, p.4]；[doi:10.3389/frai.2024.1446063, p.5]
- **method：** 训练阶段对 XGBoost 用 hyperOpt 搜索超参数，并对 CNN 采用随机搜索、early stopping 和 3 模型加权平均集成。
  - 证据：[doi:10.3389/frai.2024.1446063, p.6]；[doi:10.3389/frai.2024.1446063, p.7]
- **results：** 总体对比中，ECEP 报告 R2=0.54、MSE=0.46、Pearson=0.73，优于 TurNuP 与 DLKcat。
  - 证据：[doi:10.3389/frai.2024.1446063, p.8]；[doi:10.3389/frai.2024.1446063, p.13]
- **results：** CNN 集成在 legacy features 下从单模型的 R2=0.49、MSE=0.51 提升到 ensemble 的 R2=0.54、MSE=0.46。
  - 证据：[doi:10.3389/frai.2024.1446063, p.10]
- **results：** XGBoost 集成在 new features 下把 R2 从 0.43 提升到 0.47，并把 MSE 从 0.77 降到 0.71。
  - 证据：[doi:10.3389/frai.2024.1446063, p.7]
- **results：** 摘要还声称相对 TurNuP 的 MSE 从 0.81 降到 0.46，R2 从 0.44 提升到 0.54。
  - 证据：[doi:10.3389/frai.2024.1446063, p.1]
